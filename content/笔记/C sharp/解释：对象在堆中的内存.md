# 一句话通俗理解
**new 出来的实例对象，数据本体都存放在堆内存里**

---
## 1. 先分清两块常用内存
- **栈内存**：存放局部变量、方法参数、引用地址，自动分配释放，空间小存取快
- **堆内存**：存放实实在在的对象实体、成员字段，手动管理回收，空间大

## 2. 代码对照看懂
```csharp
// 1. Person p 是引用变量，存在栈里
Person p = new Person();
// 2. new Person() 创建对象本体，本体数据存在堆里
```
- 栈里只存一个**地址编号**，指向堆中的对象
- 类的字段、属性真实数据，全部扎根在堆内存

## 3. 结合你之前的代码举例
```csharp
class A
{
    int _a1;
    int _a2;
    object _syncObj;
}
A obj = new A();
```
1. `obj` 引用变量 → 栈内存
2. `new A()` 生成的对象整体 → **堆内存**
3. `_a1`、`_a2`、`_syncObj` 这些成员数据 → 全都在堆里

## 4. 关键特点
1. 多个引用变量，可以同时指向堆里同一个对象
2. 对象不会随方法结束立刻销毁，等待GC垃圾回收清理
3. 访问对象成员，都是通过栈地址，寻址到堆中取值赋值

## 5. 极简总结
对象本身肉身驻扎在堆，栈只放指向它的门牌号。
