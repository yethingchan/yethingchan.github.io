# C# ASP.NET Core 路由映射详解

## 一、C# 与 Java Spring Boot 路由对比
| 特性         | Java Spring Boot                | C# ASP.NET Core               |
| ---------- | ------------------------------- | ----------------------------- |
| 类级别路由      | `@RequestMapping("/api/users")` | `[Route("api/[controller]")]` |
| GET 请求     | `@GetMapping("/{id}")`          | `[HttpGet("{id}")]`           |
| POST 请求    | `@PostMapping`                  | `[HttpPost]`                  |
| PUT 请求     | `@PutMapping("/{id}")`          | `[HttpPut("{id}")]`           |
| DELETE 请求  | `@DeleteMapping("/{id}")`       | `[HttpDelete("{id}")]`        |
| RESTful 风格 | 原生支持                            | 完全支持（机制相同）                    |

---

## 二、C# 路由标记说明

### 1. 类级别路由（Controller 上方）
```csharp
[Route("api/[controller]")]  // [controller] = 控制器名称（自动去掉 Controller 后缀）
[ApiController]              // 启用 API 增强特性
public class UsersController : ControllerBase
```
- `UsersController` → 自动生成路由 `/api/Users`

### 2. 方法级别路由（Action 上方）
```csharp
[HttpGet]             // GET 请求，继承类路由
[HttpGet("{id}")]     // GET 请求，带路由参数
[HttpPost]            // POST 请求
[HttpPut("{id}")]     // PUT 请求
[HttpDelete("{id}")]  // DELETE 请求
```

### 3. 命名路由
```csharp
[HttpGet(Name = "GetUser")]  // 给路由命名，供 CreatedAtRoute 使用
```

## 三、项目中两种路由模式

### 模式 1：无 api 前缀
```csharp
[Route("[controller]")]
[ApiController]
public class WmsMaterialOutController : ControllerBase
{
    [HttpPost]
    public async Task<IActionResult> CreateOutOrder([FromBody] WmsOutOrderDto outDto) { ... }
}
```
**访问路径：** `POST /WmsMaterialOut`

---

### 模式 2：带 api 前缀（推荐）
```csharp
[Route("api/[controller]")]
[ApiController]
public class UsersController : ControllerBase
{
    [HttpGet]       public async Task<IActionResult> GetUser(...)
    [HttpPost]      public async Task<IActionResult> AddUser(...)
    [HttpPut]       public async Task<IActionResult> UpdateUser(...)
    [HttpDelete]    public async Task<IActionResult> DeleteUser(...)
}
```
**访问路径：**
- `GET /api/Users`
- `POST /api/Users`
- `PUT /api/Users/{UserID}`
- `DELETE /api/Users/{UserID}`

## 五、标准 RESTful 路由写法
```csharp
[HttpGet]          // 获取列表  → GET    /api/Users
[HttpGet("{id}")]  // 获取单个  → GET    /api/Users/1
[HttpPost]         // 新增     → POST   /api/Users
[HttpPut("{id}")]  // 修改     → PUT    /api/Users/1
[HttpDelete("{id}")]// 删除    → DELETE /api/Users/1
```

### Spring Boot 等价写法
```java
@GetMapping
@GetMapping("/{id}")
@PostMapping
@PutMapping("/{id}")
@DeleteMapping("/{id}")
```

## 六、参数绑定对比
| C# 特性 | Java 注解 | 说明 |
|--------|-----------|------|
| `[FromBody]` | `@RequestBody` | 从请求体读取 JSON |
| `[FromQuery]` | `@RequestParam` | 从 URL 查询参数读取 |
| `[FromRoute]` | `@PathVariable` | 从路由地址读取 |
| `[FromHeader]` | `@RequestHeader` | 从请求头读取 |

## 七、问题与建议
1. **路由前缀不统一**
   - 部分控制器带 `api/`，部分不带
   - **建议统一使用 `[Route("api/[controller]")]`**

2. **RESTful 规范**
   - `UsersController`、`LinesController` 已符合 RESTful
   - 其他控制器可补充完整 CRUD

3. **路由命名**
   - 建议需要重定向的路由加上 `Name` 属性

---

## 八、总结
ASP.NET Core 路由机制 **与 Spring Boot 高度相似**，只是注解语法不同。
项目已采用 RESTful 风格，只需统一路由前缀即可更规范。
