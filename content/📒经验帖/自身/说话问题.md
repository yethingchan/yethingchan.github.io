- [ ] 没有提前过滤问题并整理打腹稿
- [ ] 没有主题
- [ ] 急切并且想完整描述
- [ ] 没有换位思考，没有拎清对方想要什么
- [ ] 语气词很多，前后关系词乱用
- [ ] 很容易为了找补而编造虚假事情
- [ ] 声音不稳定，鼻音重，吐字不清晰
- [ ] 不判断对方的情绪 想听什么，习惯性的去推脱什么
- [ ] 说话做事不讲究细节

**解决方案：**
- [ ] 说话前，想好主题，言简意赅，判断情绪，判断需求，不提别人
- [ ] 说话中，想着主题，不要跑题，语速适中，声音洪亮
- [ ] 说话后，反思一下，点是否齐，是否清晰
