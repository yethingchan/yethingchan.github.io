## 2. `quartz/styles/base.scss`

### 操作：修改（4 处）

### 2.1 `.page` 最大宽度

```diff
  .page {
-   max-width: calc(#{map.get($breakpoints, desktop)} + 300px);
+   max-width: 100%;
    margin: 0 auto;
```

**目的**：原值 `calc(1200px + 300px) = 1500px` 在大屏上会导致右侧出现大片空白。改为 `100%` 后布局自动填满视口宽度。

---

### 2.2 `#quartz-body` 成为滚动容器

```diff
  & > #quartz-body {
    display: grid;
    ...
    grid-template-areas: #{map.get($desktopGrid, templateAreas)};
+   // 桌面/平板端：让 #quartz-body 成为滚动容器，使内部 sticky 正常工作
+   @media all and not ($mobile) {
+     overflow-y: auto;
+     height: 100dvh;
+   }
```

**目的**：这是本次修改的核心。CSS Grid 布局中，`position: sticky` 的元素需要其滚动祖先容器有正确的高度差才能生效。原来 `#quartz-body` 的 `overflow` 是 `visible`，滚动发生在 `<body>` 上，导致 grid row 被长文章撑高后 sticky 失效（侧栏跟着页面滚走）。

将 `#quartz-body` 设为 `overflow-y: auto; height: 100dvh` 后，它成为滚动容器，内部 sidebar 的 `position: sticky` 就能正确工作了——滚动时侧栏固定在视口顶部，正文独立滚动。

---

### 2.3 `.sidebar` 通用样式

```diff
  & .sidebar {
    ...
    display: flex;
-   height: 100vh;
+   height: 100dvh;
    position: sticky;
+   min-height: 0;
  }
```

**目的**：
- `100vh` → `100dvh`：使用动态视口高度，避免移动端浏览器地址栏收缩时高度计算不准确。
- 新增 `min-height: 0`：允许 flex 子元素收缩到小于内容高度，配合 `overflow: hidden` 使 explorer-content 可以独立滚动。

---

### 2.4 `.sidebar.left` 样式

```diff
  & .sidebar.left {
    z-index: 1;
    grid-area: grid-sidebar-left;
    flex-direction: column;
+   overflow: hidden;
    @media all and ($mobile) {
      ...
      height: unset;
+     overflow: visible;
      flex-direction: row;
      ...
    }
  }
```

**目的**：
- 新增 `overflow: hidden`（桌面端）：防止 explorer 内容溢出 sidebar 边界，配合 explorer-content 的 `overflow-y: auto` 实现目录独立滚动。
- 移动端新增 `overflow: visible`：确保移动端布局不受影响。

---

### 2.5 `.sidebar.right` 样式

```diff
  & .sidebar.right {
    ...
    @media all and not ($desktop) {
      position: initial;
      height: unset;
+     overflow: visible;
      ...
    }
  }
```

**目的**：非桌面端（平板/手机）恢复 `overflow: visible`，避免内容被裁剪。

---

## 3. `quartz/styles/custom.scss`

### 操作：修改（2 处）

### 3.1 `html` 滚动控制

```diff
  html {
    overflow-y: scroll;
    scrollbar-gutter: stable;
+   // 桌面/平板端：禁止 html/body 滚动，由 #quartz-body 内部滚动
+   @media (min-width: 801px) {
+     overflow-y: hidden;
+     height: 100dvh;
+   }
  }
```

**目的**：桌面端禁止 `<html>` 滚动。因为滚动现在由 `#quartz-body`（`overflow-y: auto`）处理，如果 `<html>` 仍然可滚动，会导致双重滚动条和 sticky 失效。移动端保持 `overflow-y: scroll` 不变。

---

### 3.2 `body` 滚动控制

```diff
  body {
    min-height: 100%;
    width: 100%;
    max-width: 100%;
    overflow-x: hidden;
+   @media (min-width: 801px) {
+     overflow-y: hidden;
+     height: 100dvh;
+   }
  }
```

**目的**：同上，桌面端禁止 `<body>` 滚动，将滚动职责完全交给 `#quartz-body`。

---

## 4. `quartz/components/styles/explorer.scss`

### 操作：修改（2 处）

### 4.1 `.explorer` flex 布局

```diff
  .explorer {
    display: flex;
    flex-direction: column;
    overflow-y: hidden;

-   min-height: 1.2rem;
-   flex: 0 1 auto;
+   flex: 1 1 auto;
+   min-height: 0;
```

**目的**：
- `flex: 0 1 auto` → `flex: 1 1 auto`：允许 explorer 在 sidebar 内部弹性增长，占据剩余空间。
- `min-height: 1.2rem` → `min-height: 0`：允许 flex 子元素收缩，使 explorer-content 可以获得正确的滚动区域。

---

### 4.2 `.explorer-content` 滚动

```diff
  .explorer-content {
    list-style: none;
-   overflow: hidden;
    overflow-y: auto;
+   overflow-x: hidden;
    margin-top: 0.5rem;
+   flex: 1 1 auto;
+   min-height: 0;
+   max-height: 100%;
+   overscroll-behavior: contain;
+   scrollbar-gutter: stable;
```

**目的**：
- `overflow: hidden` → `overflow-y: auto`：目录内容超出时显示滚动条，可以独立滚动。
- 新增 `overflow-x: hidden`：防止水平溢出。
- 新增 `flex: 1 1 auto; min-height: 0`：让 explorer-content 占满 explorer 的剩余空间，并允许收缩。
- 新增 `max-height: 100%`：限制最大高度不超过父容器。
- 新增 `overscroll-behavior: contain`：防止目录滚动到边界时带动外层滚动。
- 新增 `scrollbar-gutter: stable`：始终保留滚动条空间，避免滚动条出现/消失时布局抖动。

### 17.1 新增滚动容器检测函数

```diff
+ /* =========================
+    获取滚动容器（桌面端为 #quartz-body，移动端为 window）
+ ========================= */
+ function getScrollContainer() {
+   const quartzBody = document.querySelector('.page > #quartz-body');
+   if (quartzBody && getComputedStyle(quartzBody).overflowY === 'auto') {
+     return quartzBody;
+   }
+   return window;
+ }
+
+ function getScrollTop() {
+   const c = getScrollContainer();
+   return c === window ? window.scrollY : c.scrollTop;
+ }
+
+ function getScrollHeight() {
+   const c = getScrollContainer();
+   if (c === window) return document.body.scrollHeight;
+   return c.scrollHeight;
+ }
+
+ function getClientHeight() {
+   const c = getScrollContainer();
+   if (c === window) return window.innerHeight;
+   return c.clientHeight;
+ }
+
+ function scrollToTop() {
+   const c = getScrollContainer();
+   if (c === window) {
+     window.scrollTo({ top: 0, behavior: "smooth" });
+   } else {
+     c.scrollTo({ top: 0, behavior: "smooth" });
+   }
+ }
+
+ function scrollToBottom() {
+   const c = getScrollContainer();
+   if (c === window) {
+     window.scrollTo({ top: document.body.scrollHeight, behavior: "smooth" });
+   } else {
+     c.scrollTo({ top: c.scrollHeight, behavior: "smooth" });
+   }
+ }
```

**目的**：第一轮优化中，为了让左侧栏 `position: sticky` 生效，将滚动容器从 `window/body` 改为了 `#quartz-body`（`overflow-y: auto; height: 100dvh`）。但 BackToTop 脚本中所有滚动操作仍然使用 `window`，导致功能全部失效。新增的辅助函数会自动检测当前滚动容器，桌面端使用 `#quartz-body`，移动端回退到 `window`。
