## 三、核心实现详解

### 3.1 数据权限实现（最精彩）

**问题**: 如何实现不同角色看到不同范围的数据？

**传统方案**: 在每个SQL中手动添加WHERE条件

**RuoYi方案**: AOP切面自动注入

```java
// Service层只需一个注解
@DataScope(deptAlias = "d", userAlias = "u")
public List<SysUser> selectUserList(SysUser user) {
    return userMapper.selectUserList(user);
}
```

**AOP切面自动生成SQL**:

```java
// 根据角色的data_scope字段
if (DATA_SCOPE_DEPT.equals(dataScope)) {
    // 本部门
    sql.append(" OR d.dept_id = ").append(currentDeptId);
} else if (DATA_SCOPE_DEPT_AND_CHILD.equals(dataScope)) {
    // 本部门及以下
    sql.append(" OR d.dept_id IN (")
       .append("SELECT dept_id FROM sys_dept ")
       .append("WHERE find_in_set(").append(currentDeptId)
       .append(", ancestors))");
}

// 注入到params
params.put(DATA_SCOPE, " AND (" + sql.substring(4) + ")");
```

**XML中使用**:

```xml
<select id="selectUserList">
    select ... from sys_user u
    left join sys_dept d on u.dept_id = d.dept_id
    where u.del_flag = '0'
    
    <!-- 自动注入数据权限SQL -->
    ${params.dataScope}
</select>
```

**优势**:
- 业务代码无感知
- 集中管理，易于维护
- 灵活扩展，支持5种数据范围

### 3.2 Token自动续期机制

**问题**: Token有效期短影响体验，长则不安全

**RuoYi方案**: 滑动窗口续期

```java
public void verifyToken(LoginUser loginUser) {
    long expireTime = loginUser.getExpireTime();
    long currentTime = System.currentTimeMillis();
    
    // 剩余不足20分钟，自动续期
    if (expireTime - currentTime <= MILLIS_MINUTE_TWENTY) {
        refreshToken(loginUser);  // 重置为30分钟
    }
}
```

**效果**:
- 活跃用户Token永不过期
- 非活跃用户30分钟后过期
- 平衡安全性和用户体验

### 3.3 字典缓存与转换

**问题**: 字典数据频繁查询影响性能

**RuoYi方案**: Redis缓存 + 双向转换

```java
// 导出时：值 → 标签
String label = DictUtils.getDictLabel("sys_user_sex", "0");
// 返回: "男"

// 导入时：标签 → 值
String value = DictUtils.getDictValue("sys_user_sex", "男");
// 返回: "0"

// 缓存机制
public static String getDictLabel(String dictType, String dictValue) {
    // 从Redis获取
    List<SysDictData> datas = getDictCache(dictType);
    
    // 构建Map并查找
    Map<String, String> dictMap = datas.stream()
        .collect(Collectors.toMap(
            SysDictData::getDictValue, 
            SysDictData::getDictLabel
        ));
    
    return dictMap.get(dictValue);
}
```

**优势**:
- 一次查询，多次使用
- 修改后清除缓存即可
- 导出导入自动转换

### 3.4 异步日志记录

**问题**: 记录日志不应影响主业务流程

**RuoYi方案**: 线程池异步执行

```java
// Controller中添加注解
@Log(title = "用户管理", businessType = BusinessType.INSERT)
@PostMapping
public AjaxResult add(@RequestBody SysUser user) {
    return toAjax(userService.insertUser(user));
}

// AOP切面异步记录
@AfterReturning(pointcut = "@annotation(controllerLog)")
public void doAfterReturning(JoinPoint joinPoint, Log controllerLog) {
    // 构建日志对象
    OperLogEvent operLog = buildOperLog(joinPoint, controllerLog);
    
    // 异步保存
    AsyncManager.me().execute(AsyncFactory.recordOper(operLog));
}

// 异步工厂
public class AsyncFactory {
    public static TimerTask recordOper(final OperLogEvent operLog) {
        return new TimerTask() {
            @Override
            public void run() {
                // 插入数据库
                SpringUtils.getBean(ISysOperLogService.class)
                    .insertOperlog(operLog);
            }
        };
    }
}
```

**优势**:
- 不阻塞主流程
- 日志失败不影响业务
- 线程池统一管理

### 3.5 防重复提交

**问题**: 用户快速点击导致重复提交

**RuoYi方案**: Redis + 注解

```java
// Controller添加注解
@RepeatSubmit(interval = 5000)  // 5秒内不允许重复提交
@PostMapping
public AjaxResult add(@RequestBody SysUser user) {
    return toAjax(userService.insertUser(user));
}

// AOP切面实现
@Around("@annotation(repeatSubmit)")
public Object around(ProceedingJoinPoint joinPoint, RepeatSubmit repeatSubmit) {
    String key = generateKey(request);
    
    // 尝试设置Redis，5秒过期
    Boolean flag = redisCache.setIfAbsent(key, "1", interval, MILLISECONDS);
    
    if (!flag) {
        throw new ServiceException("不允许重复提交");
    }
    
    return joinPoint.proceed();
}
```
