# 并发与多线程学习路线

> 对应 Java 全栈路线思维导图「基础核心」第三叶。高阶分水岭，面试重灾区。

## 一、学习阶段

### 入门：能开线程
- 三种创建：Thread / Runnable / Callable+Future
- 线程生命周期（新建→就绪→运行→阻塞→死亡）
- 同步基础：synchronized、volatile
- 线程协作：wait/notify、join、sleep

### 进阶：懂锁与容器
- synchronized 锁升级（无锁→偏向→轻量→重量）
- JUC：ReentrantLock、读写锁、AQS 思想
- 并发工具：CountDownLatch / CyclicBarrier / Semaphore
- 线程池：7 参数、执行流程、拒绝策略、Executors 的坑
- 并发集合（ConcurrentHashMap、CopyOnWriteArrayList、阻塞队列）

### 高级：能排错与设计
- CAS 与 ABA、原子类
- ThreadLocal（原理与内存泄漏）
- CompletableFuture 异步编排
- happens-before、JMM 内存模型
- 死锁定位（jstack）、线程池调优

## 二、关键要点与常见坑
- volatile 不保证原子性（i++ 非原子）
- 线程池别用 Executors.newFixed 无界队列（OOM 风险），手动 ThreadPoolExecutor
- ThreadLocal 用完 remove，尤其线程池复用场景
- 死锁四条件：互斥/占有等待/不可剥夺/循环等待

## 三、实战
- 入门：多线程下载、生产者消费者
- 进阶：用线程池 + CompletableFuture 并发调多个接口

## 六、心法
1. 并发的难不在"开线程"，在"不出错、可预测"。
2. 先理解 happens-before，再写任何共享变量。
3. 能用线程池就别 new Thread；能异步编排就别嵌套回调。
