# 集合框架学习路线

> 对应 Java 全栈路线思维导图「基础核心」第二叶。面试与日常最高频，必须源码级。

## 一、学习阶段

### 入门：会用常见集合
- List：ArrayList（数组、扩容 1.5×）、LinkedList（链表）
- Set：HashSet、TreeSet
- Map：HashMap、TreeMap
- 工具类：Collections、Arrays、Comparator

### 进阶：懂原理与选型
- ArrayList vs LinkedList 适用场景
- HashMap：哈希扰动、负载因子、树化（8）/退化（6）、resize 高低位拆分
- ConcurrentHashMap：分段→CAS+锁桶（JDK8）
- 泛型与 PECS（Producer Extends / Consumer Super）、类型擦除

### 高级：能手写与优化
- 手写 LRU（LinkedHashMap 访问顺序）
- 交集/差集/TopN
- 阻塞队列（ArrayBlockingQueue 等）、延迟队列 DelayQueue
- 读懂《Java 集合框架知识库》全部源码分析

## 二、关键要点与常见坑
- 遍历时删除用 Iterator，别用 for 里 remove（ConcurrentModificationException）
- 作为 HashMap key 的对象必须重写 hashCode/equals
- 初始容量设好，避免频繁扩容
- 多线程用并发集合，别用普通集合

## 三、实战
- 入门：用 Map 统计词频、用 List 排序
- 进阶：手写 LRU 缓存、用 BitSet 去重
