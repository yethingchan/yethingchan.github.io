# Java 语法与 OOP 学习路线

> 对应 Java 全栈路线思维导图「基础核心」第一叶。一切 Java 能力的地基，地基不牢后面全晃。

## 一、学习阶段

### 入门：能写基础程序
- 环境：JDK 安装、IDEA、第一个 HelloWorld、编译运行流程（javac/java）
- 基础语法：变量/数据类型/运算符/流程控制（if/for/while/switch）
- 数组、字符串（String 不可变、StringBuilder 区别）
- 方法：重载、可变参数、递归

### 进阶：能用对象建模真实事物
- OOP 四特性：封装 / 继承 / 多态 / 抽象
- 类与对象、构造器、this/super
- 接口 vs 抽象类、默认方法、枚举 enum
- 内部类（成员/局部/匿名/静态）

### 高级：写得优雅可维护
- 泛型、注解、反射基础
- Lambda 与函数式接口、Stream 基础
- 设计原则入门（SOLID 中的单一职责/开闭）

## 二、关键要点与常见坑
- String 不可变 → 频繁拼接用 StringBuilder
- `==` 比地址，`equals` 比内容；重写 equals 必须重写 hashCode
- 多态向下转型前先 `instanceof`，否则 ClassCastException
- 基础类型 vs 包装类（Integer 缓存 -128~127）

## 三、实战
- 入门：控制台版学生信息增删改查
- 进阶：用类建模一个小系统（图书/订单），体现封装与继承

## 六、心法
1. 语法是工具，OOP 是思维方式。
2. 先学会"用对象建模真实事物"，再回头抠语法细节。
3. 写不顺 = 没真懂；能给别人讲清 = 过关。
