# 项目实战与源码调优学习路线

> 对应 Java 全栈路线思维导图「架构与实战」第四叶。把前面所有栈串起来，并往深里钻。

## 一、学习阶段

### 入门：做一个能跑的项目
- 选型：SpringBoot + MyBatis + MySQL + 前端
- 做透一个：博客 / 商城后台 / 学生管理
- 要求：分层架构清晰、能部署、写 README

### 进阶：做有难度的项目
- 加缓存（Redis）、加 MQ（异步）、加登录鉴权（JWT）
- 做秒杀/商城：高并发雏形
- 微服务版：多服务 + 网关 + 注册

### 高级：读源码 + 做调优
- 源码：Spring IoC/AOP、MyBatis、HashMap、线程池
- 调优：JVM 参数、SQL、缓存策略、并发
- 输出：架构图、复盘文档、故障库

## 二、关键要点与常见坑
- 项目不在多，在一个能讲透；能答"为什么这么设计"才算懂
- 源码别通读，带着问题读（如"Spring 怎么解决循环依赖"）
- 调优先测后改，留前后对比数据
- 复盘文档 = 把经验变资产（呼应《思考力》外化日志）

## 三、实战梯度
- 入门：个人博客（增删改查 + 部署）
- 进阶：电商（缓存+MQ+鉴权+分页）
- 高级：秒杀/微服务电商（高并发+分布式事务+链路追踪）

## 四、衔接
- 汇总全栈路线全部技术栈；联动《思考力》《主体意识》（复盘/不乱）
- 深度源码参考各专项手册（集合/并发/事务）

## 五、资源
- GitHub 优质开源项目；各框架源码；极客时间/掘金实战专栏

## 六、心法
1. 做一个能跑的 > 看十个教程。
2. 源码是"为什么"的终极答案，带着问题去读才进得去。
3. 项目结束写复盘，经验才真正变成你的。
