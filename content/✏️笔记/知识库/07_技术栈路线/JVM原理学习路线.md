# JVM 原理学习路线

> 对应 Java 全栈路线思维导图「基础核心」第四叶。调优与排障的底层，高级岗必懂。

## 一、学习阶段

### 入门：知道 JVM 在干嘛
- 内存结构：堆 / 栈 / 方法区(元空间) / 程序计数器 / 本地方法栈
- 对象创建流程、对象内存布局（头/实例/对齐）
- 类加载：加载→链接→初始化、双亲委派

### 进阶：懂 GC
- 判断对象存活：引用计数 vs 可达性分析
- GC 算法：标记清除 / 复制 / 标记整理
- 分代收集：年轻代（Eden/Survivor）、老年代
- 收集器：Serial → CMS → G1 → ZGC，各自特点

### 高级：会调优与排障
- 常用参数：-Xms/-Xmx/-Xmn/-XX:MetaspaceSize
- GC 日志分析与调优思路
- 工具：jps / jstat / jmap / jstack / jinfo / Arthas
- OOM/CPU 飙高定位套路
- 字节码基础（javap）、JIT 初步

## 二、关键要点与常见坑
- 堆外内存（NIO DirectBuffer、元空间）也会 OOM
- 频繁 Full GC 多半是老年代空间不足或内存泄漏
- 调优先看现象（GC 日志）再定参，别盲抄
- Arthas 线上排障神器：watch/trace/thread

## 三、实战
- 入门：写个内存泄漏 demo，用 jmap/jstack 定位
- 进阶：压测一个服务，读 GC 日志做参数调优
