# 直接给你讲透：自动化现场 交换机、PLC、触摸屏、设备主机、扫码枪 组网原理
## 一、先给结论
**全部插在同一个交换机 → 就是一个独立小型局域网**
和家里路由器下面连手机、电脑原理一模一样，只是**没有路由器上网，纯内网设备互相通信**。

---

## 二、现场所有设备身份
- 设备主机：工控机 / 工业电脑
- PLC：控制器
- 触摸屏：人机界面 HMI
- 扫码枪：工业读码器
- 全部网线插**同一个工业交换机**

👉 所有设备**在同一个局域网、同一个网段**（基本都是 192.168.x.x）

---

## 三、内部数据通信到底是怎么跑的？
### 1. 本质
所有设备都有**独立固定IP**，交换机只做一件事：
**转发数据包，让设备之间互相发消息**，不用经过外网。

### 2. 两两通信场景（实际工作流程）
1. **触摸屏 ↔ PLC**
   触摸屏发指令、读PLC寄存器数据（D区、M区、Y输出），显示画面、手动控制。

2. **设备主机（工控机） ↔ PLC**
   主机下发配方、生产参数、启停信号；PLC回传设备状态、报警、产量。

3. **扫码枪 ↔ 设备主机 / PLC**
   扫码枪读到条码 → 把条码字符串**通过网线发给工控机或PLC**，做比对、入库、防重、追溯。

4. 所有设备**互相能ping通**，同网段IP直接通信。

---

## 四、和你刚才问的 `ipconfig` / `arp -a` 对应关系
1. 你把电脑也插到这个工业交换机上
2. 电脑设成同网段 192.168.x.x
3. **ipconfig**：看你自己电脑IP
4. **arp -a**：直接能扫出
   - PLC IP+MAC
   - 触摸屏 IP+MAC
   - 工控机 IP+MAC
   - 扫码枪 IP+MAC

**就是一个封闭的工业小局域网**，和家用局域网结构完全一样，只是**不连外网、全是工业设备**。

---

## 五、关键特点总结
1. 同交换机 = **同一个局域网**
2. 全部设备必须**设置同一段 192.168 内网IP**，才能通信
3. 交换机只做**数据转发**，不分配IP、不做路由
4. 所有设备通信都是**内网IP之间点对点**，不走互联网
5. 你电脑接入这个交换机，就能直接监听、ping、调试每一台设备

---

## 六、额外实用小知识
工业现场标准做法：
- 所有设备**手动固定静态IP**，不自动获取
- 一般网段统一：如 `192.168.1.xxx`
- PLC、触摸屏、工控机、扫码枪最后一位IP设成不一样，避免冲突
- **URL 里的 IP 是谁，谁就是服务端（提供接口、被调用）**
- **你去访问这个 URL，你就是客户端（主动调用别人）**
