# Vue 3 后台管理系统从0到1 完整教程

## 技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3 (Composition API) | 组合式API，逻辑复用更灵活 |
| 构建工具 | Vite | 极速开发体验 |
| UI 组件库 | Element Plus | 最主流的 Vue 3 后台 UI 库 |
| 路由 | Vue Router 4 | 官方路由方案 |
| 状态管理 | Pinia | Vue 3 官方推荐 |
| HTTP 请求 | Axios | 最成熟的请求库 |
| CSS 预处理 | SCSS | 组件样式管理 |

## 推荐学习路线

```
新手路线（从零理解全貌）:
01 → 02 → 07a → 03 → 04a → 04b → 05a → 05b → 06a → 06b → 07b → 08a → 08b → 08c → 09 → 10 → 11

速成路线（已有基础 → 快速上手）:
01 → 02 → 08a → 08b → 08c（跟着实战走，遇到不会的回头查对应章节）→ 10 → 11

按功能模块路线:
01 → 02（基础设施）→ 04a → 04b（布局）→ 05a → 05b（核心功能）→ 08a → 08b → 08c（整合）→ 11

前后端联调路线:
完成基础搭建后 → 10（Mock 数据与后端对接）→ 11（打包部署与上线）
```

## 标准项目目录结构

```
vue-admin/
├── public/                  # 静态资源（不经过构建）
├── src/
│   ├── api/                 # API 接口定义
│   │   ├── user.js          # 用户相关接口（第3、7章）
│   │   └── system/          # 系统管理接口
│   │       └── user.js      # 用户管理 CRUD（第8章）
│   ├── assets/              # 静态资源（经过构建）
│   │   ├── images/
│   │   └── styles/
│   │       ├── variables.scss    # SCSS 全局变量（第4章）
│   │       ├── reset.scss        # 样式重置（第4章补充）
│   │       └── global.scss       # 全局样式（第1章）
│   ├── components/          # 通用组件
│   │   ├── Breadcrumb/      # 面包屑（第4章）
│   │   ├── Pagination/      # 分页封装（第5章）
│   │   ├── Table/           # 表格封装（第5章）
│   │   ├── TreeTable/       # 树形表格（第6章）
│   │   └── SvgIcon/         # 图标组件（第4章补充）
│   ├── directives/          # 自定义指令
│   │   └── permission.js    # v-permission 权限指令（第7章）
│   ├── hooks/               # 组合式函数
│   │   ├── useTable.js      # 表格逻辑（第5章）
│   │   └── usePermission.js # 权限判断（第7章）
│   ├── layout/              # 布局组件（第4章）
│   │   ├── index.vue        # 主布局
│   │   ├── Sidebar/         # 侧边栏
│   │   │   ├── index.vue
│   │   │   ├── Logo.vue
│   │   │   ├── SidebarItem.vue  # 递归菜单项
│   │   │   └── Link.vue         # 菜单链接封装
│   │   ├── Header/          # 顶部导航
│   │   │   ├── index.vue
│   │   │   └── UserDropdown.vue
│   │   └── AppMain.vue      # 主内容区
│   ├── router/              # 路由配置（第3章）
│   │   └── index.js
│   ├── store/               # Pinia 状态（第3章）
│   │   ├── modules/
│   │   │   ├── user.js      # 用户状态
│   │   │   ├── app.js       # 应用状态（折叠、设备等）
│   │   │   └── permission.js # 权限路由状态
│   │   └── index.js
│   ├── utils/               # 工具函数（第2章）
│   │   ├── request.js       # Axios 封装
│   │   ├── auth.js          # Token 管理
│   │   ├── validate.js      # 校验函数
│   │   ├── storage.js       # 本地存储封装
│   │   ├── index.js         # 通用工具（deepClone、debounce 等）
│   │   ├── progress.js      # NProgress 配置（第3章）
│   │   └── tree.js          # 树形数据工具函数（第6章）
│   ├── views/               # 页面视图
│   │   ├── login/           # 登录页（第7章）
│   │   ├── dashboard/       # 首页仪表盘（第1章）
│   │   ├── profile/         # 个人中心（第4章补充）
│   │   ├── password/        # 修改密码（第4章补充）
│   │   ├── error-page/      # 错误页面
│   │   │   └── 404.vue      # 404 页面（第3章补充）
│   │   └── system/          # 系统管理
│   │       ├── user/        # 用户管理（第8章）
│   │       └── dept/        # 部门管理（第6章）
│   ├── App.vue
│   ├── main.js
│   └── permission.js        # 路由守卫（第3、7章）
├── .env.development         # 开发环境变量（第1章）
├── .env.production          # 生产环境变量（第1章）
├── vite.config.js           # 构建配置（第1章）
```

## 组件创建顺序（标准流程）

```
第1步：项目初始化 + 依赖安装
       ↓
第2步：工具类封装（request → auth → storage → validate）
       ↓
第3步：全局样式 + SCSS 变量
       ↓
第4步：路由配置 + 布局组件骨架
       ↓
第5步：登录页面 + Token 认证
       ↓
第6步：侧边栏（可折叠）+ 顶部导航 + 面包屑
       ↓
第7步：通用组件封装（Table → Pagination → TreeTable）
       ↓
第8步：业务页面开发（CRUD）
       ↓
第9步：权限控制 + 菜单动态加载
       ↓
第10步：优化与收尾
```
