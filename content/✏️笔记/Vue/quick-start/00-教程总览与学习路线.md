# Vue 3 后台管理系统从0到1 完整教程

## 技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3 (Composition API) | 组合式API，逻辑复用更灵活 |
| 构建工具 | Vite | 极速开发体验 |
| UI 组件库 | Element Plus | 最主流的 Vue 3 后台 UI 库 |
| 路由 | Vue Router 4 | 官方路由方案 |
| 状态管理 | Pinia | Vue 3 官方推荐 |
| HTTP 请求 | Axios | 最成熟的请求库 |
| CSS 预处理 | SCSS | 组件样式管理 |

## 推荐学习路线

```
新手路线（最复杂 → 理解全貌）:
01 → 02 → 07 → 03 → 04 → 05 → 06 → 08 → 09

速成路线（已有基础 → 快速上手）:
01 → 02 → 08（跟着实战走，遇到不会的回头查对应章节）

按功能模块路线:
01 → 02（基础设施）→ 04（布局）→ 05（核心功能）→ 08（整合）
```

## 组件创建顺序（标准流程）

```
第1步：项目初始化 + 依赖安装
       ↓
第2步：工具类封装（request → auth → storage → validate）
       ↓
第3步：全局样式 + SCSS 变量
       ↓
第4步：路由配置 + 布局组件骨架
       ↓
第5步：登录页面 + Token 认证
       ↓
第6步：侧边栏（可折叠）+ 顶部导航 + 面包屑
       ↓
第7步：通用组件封装（Table → Pagination → TreeTable）
       ↓
第8步：业务页面开发（CRUD）
       ↓
第9步：权限控制 + 菜单动态加载
       ↓
第10步：优化与收尾
```
