## 七、用户下拉菜单 `src/layout/Header/UserDropdown.vue`

位于顶部导航栏右侧，展示用户头像和下拉操作菜单。

```vue
<!-- src/layout/Header/UserDropdown.vue -->
<template>
  <el-dropdown trigger="click" class="user-dropdown" @command="handleCommand">
    <!-- ==================== 头像区域（触发器） ==================== -->
    <div class="avatar-wrapper">
      <el-avatar
        :size="30"
        :src="avatar"
        class="user-avatar"
      >
        <!-- 无头像时显示用户名首字母 -->
        <span>{{ userInitial }}</span>
      </el-avatar>
      <!--
        caret: 下拉箭头图标
        可以用 Element Plus 内置的 el-icon 或自定义 CSS
      -->
      <el-icon class="el-icon--right">
        <ArrowDown />
      </el-icon>
    </div>

    <!-- ==================== 下拉菜单选项 ==================== -->
    <template #dropdown>
      <el-dropdown-menu>
        <!-- 个人中心 -->
        <el-dropdown-item command="profile">
          <el-icon><User /></el-icon>
          个人中心
        </el-dropdown-item>

        <!-- 修改密码 -->
        <el-dropdown-item command="password">
          <el-icon><Lock /></el-icon>
          修改密码
        </el-dropdown-item>

        <!-- 分割线 -->
        <el-dropdown-item divided command="logout">
          <el-icon><SwitchButton /></el-icon>
          退出登录
        </el-dropdown-item>
      </el-dropdown-menu>
    </template>
  </el-dropdown>
</template>

<script setup>
/**
 * 用户下拉菜单组件
 *
 * 职责：
 * 1. 展示用户头像和用户名
 * 2. 提供下拉操作菜单：个人中心、修改密码、退出登录
 * 3. 处理退出登录逻辑（清除 Token、跳转登录页）
 *
 * 数据来源：
 * - user store: name, avatar
 * - user store actions: logout(), resetState()
 */
import { computed } from 'vue'
import { useRouter } from 'vue-router'
import { ElMessageBox, ElMessage } from 'element-plus'
import { User, Lock, SwitchButton, ArrowDown } from '@element-plus/icons-vue'
import { useUserStore } from '@/store/modules/user'

const router = useRouter()
const userStore = useUserStore()

// 用户头像
const avatar = computed(() => userStore.avatar)

// 用户名首字母（无头像时的兜底方案）
const userInitial = computed(() => {
  const name = userStore.name || 'Admin'
  return name.charAt(0).toUpperCase()
})

/**
 * 处理下拉菜单命令
 * @param {string} command - 菜单命令：profile / password / logout
 */
const handleCommand = (command) => {
  switch (command) {
    case 'profile':
      // 跳转到个人中心页面
      router.push('/profile')
      break
    case 'password':
      // 跳转到修改密码页面
      router.push('/password')
      break
    case 'logout':
      handleLogout()
      break
  }
}

/**
 * 退出登录
 * 1. 弹出确认对话框
 * 2. 调用登出接口（清除服务端 session）
 * 3. 清除本地 Token 和用户状态
 * 4. 跳转到登录页
 */
const handleLogout = () => {
  ElMessageBox.confirm(
    '确定要退出登录吗？',
    '提示',
    {
      confirmButtonText: '确定',
      cancelButtonText: '取消',
      type: 'warning'
    }
  ).then(async () => {
    try {
      // 调用登出接口
      await userStore.logout()
      ElMessage.success('退出登录成功')
    } catch (error) {
      // 即使登出接口失败，也继续清除本地状态
      console.warn('登出接口调用失败，但仍清除本地状态')
    } finally {
      // 清除本地状态并跳转登录页
      userStore.resetState()
      router.push(`/login?redirect=${router.currentRoute.value.fullPath}`)
    }
  }).catch(() => {
    // 用户取消，不做任何操作
  })
}
</script>

<style lang="scss" scoped>
.user-dropdown {
  cursor: pointer;
  display: flex;
  align-items: center;

  // 头像容器
  .avatar-wrapper {
    display: flex;
    align-items: center;

    // 用户头像
    .user-avatar {
      background-color: #409eff;
      color: #fff;
      font-size: 14px;
      font-weight: 600;
    }

    // 下拉箭头
    .el-icon--right {
      margin-left: 6px;
      font-size: 12px;
      color: #7a7b7e;
      transition: transform 0.3s;
    }
  }

  // hover 效果
  &:hover .el-icon--right {
    transform: rotate(180deg);
  }
}
</style>
```

**核心要点：**

- 使用 `ElMessageBox.confirm` 弹出二次确认，避免用户误触退出
- 退出登录的 `finally` 块确保无论接口是否成功，都会清除本地状态
- `router.push('/login?redirect=...')` 记录当前页面路径，登录后可跳回

## 八、面包屑 `src/components/Breadcrumb/index.vue`

面包屑根据当前路由自动生成，支持多级层级、图标和点击跳转。

```vue
<!-- src/components/Breadcrumb/index.vue -->
<template>
  <el-breadcrumb class="breadcrumb" separator="/">
    <!--
      过渡组：当路由变化时，面包屑项平滑切换
    -->
    <transition-group name="breadcrumb">
      <!--
        遍历面包屑项
        - 每个项包含 title、path、icon
        - 最后一项是当前页面，不可点击（高亮显示）
      -->
      <el-breadcrumb-item
        v-for="(item, index) in breadcrumbs"
        :key="item.path"
      >
        <!-- 非最后一项：可点击跳转 -->
        <span
          v-if="index < breadcrumbs.length - 1"
          class="breadcrumb-link"
          @click="handleLink(item)"
        >
          <!-- 图标 -->
          <el-icon v-if="item.icon" class="breadcrumb-icon">
            <component :is="item.icon" />
          </el-icon>
          <!-- 文字 -->
          <span>{{ item.meta?.title }}</span>
        </span>

        <!-- 最后一项：当前页面，不可点击 -->
        <span v-else class="breadcrumb-current">
          <el-icon v-if="item.icon" class="breadcrumb-icon">
            <component :is="item.icon" />
          </el-icon>
          <span>{{ item.meta?.title }}</span>
        </span>
      </el-breadcrumb-item>
    </transition-group>
  </el-breadcrumb>
</template>

<script setup>
/**
 * 面包屑导航组件
 *
 * 职责：
 * 1. 根据当前路由自动生成面包屑（首页 > 一级 > 二级）
 * 2. 支持点击面包屑项跳转到对应页面
 * 3. 支持 meta.breadcrumb: false 隐藏某个路由
 * 4. 支持 meta.icon 显示图标
 *
 * 原理：
 * - 通过 route.matched 获取路由匹配链
 * - 从匹配链中提取每个层级的信息
 * - 过滤掉不需要显示的路由（redirect 路由、hidden 面包屑）
 */
import { ref, watch, onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { compile } from 'path-to-regexp'

const route = useRoute()
const router = useRouter()

// 面包屑数据
const breadcrumbs = ref([])

/**
 * 获取面包屑数据
 * - 从 route.matched 中获取完整的路由匹配链
 * - 过滤掉 redirect 路由和 hidden 面包屑
 * - 添加首页作为默认第一项
 */
const getBreadcrumb = () => {
  const matched = route.matched.filter(
    (item) => item.meta && item.meta.title
  )

  // 过滤掉设置了 breadcrumb: false 的路由
  const filtered = matched.filter(
    (item) => item.meta && item.meta.breadcrumb !== false
  )

  // 如果第一个面包屑不是首页，则在前面添加首页
  const first = filtered[0]
  if (first && first.path !== '/dashboard') {
    filtered.unshift({
      path: '/dashboard',
      meta: { title: '首页', icon: 'HomeFilled' }
    })
  }

  breadcrumbs.value = filtered
}

/**
 * 点击面包屑项跳转
 * - 使用 path-to-regexp 解析动态路径参数
 * - 支持 /user/:id 这类动态路由
 */
const handleLink = (item) => {
  const { redirect, path } = item

  // 如果有 redirect，跳转到 redirect 地址
  if (redirect) {
    router.push(redirect)
    return
  }

  // 解析路径中的动态参数
  router.push(path)
}

// 监听路由变化，重新生成面包屑
watch(
  () => route.path,
  () => {
    getBreadcrumb()
  }
)

onMounted(() => {
  getBreadcrumb()
})
</script>

<style lang="scss" scoped>
.breadcrumb {
  line-height: $headerHeight;
  padding: 0 8px;

  // 面包屑链接（可点击）
  .breadcrumb-link {
    display: inline-flex;
    align-items: center;
    cursor: pointer;
    color: #97a8be;
    font-weight: normal;
    transition: color 0.2s;

    &:hover {
      color: #409eff;
    }

    // 图标
    .breadcrumb-icon {
      margin-right: 4px;
      font-size: 14px;
    }
  }

  // 当前页面（不可点击）
  .breadcrumb-current {
    display: inline-flex;
    align-items: center;
    color: #606266;
    font-weight: 500;

    .breadcrumb-icon {
      margin-right: 4px;
      font-size: 14px;
    }
  }
}

// 面包屑过渡动画
.breadcrumb-enter-active,
.breadcrumb-leave-active {
  transition: all 0.3s ease;
}

.breadcrumb-enter-from,
.breadcrumb-leave-to {
  opacity: 0;
  transform: translateX(10px);
}

// 离开动画保持位置（避免其他面包屑项跳动）
.breadcrumb-leave-active {
  position: absolute;
}
</style>
```

```

]

生成的面包屑：

  (可点击)  (可点击)  (当前页面，不可点击)
```

## 九、主内容区 `src/layout/AppMain.vue`

主内容区包裹 `router-view`，提供页面切换的过渡动画和可选的 `keep-alive` 缓存。

```vue
<!-- src/layout/AppMain.vue -->
<template>
  <div class="app-main">
    <!--
      router-view 渲染当前路由对应的页面组件

      可选：使用 keep-alive 缓存页面组件
      - include: 指定需要缓存的组件名称列表
      - max: 最大缓存数量
      - 通过路由 meta.noCache 控制是否缓存

      注意：使用 keep-alive + transition 需要给 router-view 加 key
      否则相同路由切换时不会触发过渡动画
    -->
    <router-view v-slot="{ Component, route: currentRoute }">
      <transition name="fade-transform" mode="out-in">
        <!--
          keep-alive 缓存：排除 noCache 的页面
          如果项目不需要缓存，去掉 keep-alive 包裹即可
        -->
        <keep-alive :exclude="cachedViews">
          <component
            :is="Component"
            :key="currentRoute.path"
            class="page-component"
          />
        </keep-alive>
      </transition>
    </router-view>
  </div>
</template>

<script setup>
/**
 * 主内容区组件
 *
 * 职责：
 * 1. 包裹 router-view，提供页面渲染区域
 * 2. 通过 keep-alive 缓存页面状态（可选）
 * 3. 提供页面切换的过渡动画
 *
 * keep-alive 说明：
 * - exclude: 排除不需要缓存的组件（通过组件名称匹配）
 * - 需要缓存：保持表单输入、滚动位置等状态
 * - 不需要缓存：实时数据页面、每次进入都需要刷新的页面
 */
import { computed } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()

/**
 * 不需要缓存的组件名称列表
 * - 通过路由 meta.noCache 控制
 * - noCache: true 的页面不缓存
 */
const cachedViews = computed(() => {
  // 返回需要排除缓存的路由的组件名
  // keep-alive 的 exclude 属性接收组件名称数组
  const noCacheRoutes = []
  const allRoutes = route.matched
  allRoutes.forEach(r => {
    if (r.meta?.noCache && r.components?.default?.name) {
      noCacheRoutes.push(r.components.default.name)
    }
  })
  return noCacheRoutes
})
</script>

<style lang="scss" scoped>
.app-main {
  // 主内容区域
  flex: 1;
  min-height: calc(100vh - #{$headerHeight});
  padding: 16px;
  background-color: $appMainBg;
  overflow: hidden;
  position: relative;

  // 页面组件基础样式
  .page-component {
    width: 100%;
    min-height: 100%;
  }
}

// ==================== 过渡动画 ====================
// fade-transform：淡入 + 轻微位移
.fade-transform-enter-active,
.fade-transform-leave-active {
  transition: all 0.25s ease;
}

.fade-transform-enter-from {
  opacity: 0;
  transform: translateX(-10px);
}

.fade-transform-leave-to {
  opacity: 0;
  transform: translateX(10px);
}
</style>
```

**关于 keep-alive 的注意事项：**

1. **组件必须有 name**：`keep-alive` 通过组件的 `name` 属性匹配，使用 `<script setup>` 时需要额外添加：

```vue
<script>
export default {
  name: 'UserManagement' // 必须与 keep-alive 的 include/exclude 匹配
}
</script>

<script setup>
// 组件逻辑...
</script>
```

2. **替代方案（推荐）**：如果不使用 keep-alive，简化为：

```vue
<template>
  <div class="app-main">
    <router-view v-slot="{ Component }">
      <transition name="fade-transform" mode="out-in">
        <component :is="Component" />
      </transition>
    </router-view>
  </div>
</template>
```

3. **max 属性**：限制最大缓存数量，超出时淘汰最早的缓存组件：

```vue
<keep-alive :max="10">
  <component :is="Component" :key="route.fullPath" />
</keep-alive>
```

```
│  ├── Header (Header/index.vue)                                │
│  │   ├── Hamburger: isActive ──→ sidebar.opened                │
│  │   │   └── @toggle-click ──→ appStore.toggleSidebar()       │
│  │   ├── Breadcrumb: route.matched ──→ 自动生成               │
│  │   └── UserDropdown: name/avatar ──→ 展示用户信息           │
│  │       └── logout ──→ userStore.logout() + resetState()     │
│  │                                                                │
│  └── AppMain: router-view ──→ 渲染当前页面                     │
└───────────────────────────────────────────────────────────────┘
```

### 10.2 用户操作触发的数据流

```
用户点击 Hamburger
  → emit('toggleClick')
  → Header 调用 appStore.toggleSidebar()
  → app store 中 sidebar.opened 取反
  → Sidebar 响应式更新：
      → el-menu :collapse 变化（折叠/展开动画）
      → Logo 显示/隐藏文字
      → Layout 的 sidebar-container class 变化（宽度过渡）

用户点击菜单项
  → router.push(path)
  → 路由跳转
  → route.matched 更新
  → Breadcrumb 重新生成面包屑
  → AppMain 切换页面（带过渡动画）
  → Sidebar 的 el-menu :default-active 更新（高亮当前菜单）

用户点击退出登录
  → UserDropdown handleCommand('logout')
  → ElMessageBox.confirm 二次确认
  → userStore.logout()（调用接口）
  → userStore.resetState()（清除 Token 和用户信息）
  → router.push('/login?redirect=...')
```

## 十一、本章小结

本章实现了后台管理系统的完整布局体系，共 8 个核心组件：

| 组件 | 文件路径 | 核心功能 |
|------|----------|---------|
| 主布局 | `src/layout/index.vue` | Flex 骨架，组合 sidebar + header + app-main，响应式适配 |
| 侧边栏容器 | `src/layout/Sidebar/index.vue` | Logo + el-menu 菜单，配置折叠/展开 |
| Logo | `src/layout/Sidebar/Logo.vue` | 折叠时隐藏文字只显示图标，点击回首页 |
| 菜单项 | `src/layout/Sidebar/SidebarItem.vue` | 递归组件，支持多级嵌套、单子项优化、外链处理 |
| 顶部导航 | `src/layout/Header/index.vue` | Hamburger + 面包屑 + 用户功能区 |
| 用户下拉 | `src/layout/Header/UserDropdown.vue` | 头像 + 下拉菜单（个人中心/修改密码/退出登录） |
| 面包屑 | `src/components/Breadcrumb/index.vue` | 自动根据路由生成，支持点击跳转和图标 |
| 主内容区 | `src/layout/AppMain.vue` | router-view + keep-alive + 过渡动画 |

**关键设计要点：**

1. **响应式折叠**：侧边栏的折叠状态由 Pinia `app store` 统一管理，Hamburger 按钮、窗口 resize、移动端都可以触发折叠
2. **递归菜单**：SidebarItem 通过递归调用自身处理无限层级嵌套，单子项时自动扁平化减少层级
3. **自动面包屑**：基于 `route.matched` 路由匹配链自动生成，无需手动维护
4. **数据流清晰**：所有跨组件状态通过 Pinia Store 共享，组件间通过 props/emit 通信，避免了复杂的跨层级传递
