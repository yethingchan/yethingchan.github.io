# 第四章（上）：主布局与侧边栏组件

> 本章目标：实现后台管理系统的完整布局 UI，包括可折叠侧边栏（含多级递归菜单）、顶部导航栏（含面包屑与用户下拉菜单）、以及带 keep-alive 缓存的主内容区。所有组件均可直接运行，注释详尽。

## 二、主布局 `src/layout/index.vue`

主布局是整个后台的骨架，使用 `flex` 水平排列左侧 sidebar 与右侧区域，右侧区域再使用 `flex-direction: column` 垂直排列 header 和 AppMain。

```vue
<!-- src/layout/index.vue -->
<template>
  <div class="app-wrapper" :class="{ 'mobile': device === 'mobile' }">
    <!--
      侧边栏
      - class 根据 sidebar.opened 动态切换，控制宽度
      - v-if 在移动端控制显示/隐藏
    -->
    <sidebar
      class="sidebar-container"
      :class="{ 'is-collapse': !sidebar.opened }"
    />

    <!--
      右侧主区域
      - 包含顶部导航栏 + 主内容区
      - 使用 flex-column 垂直排列
    -->
    <div class="main-container" :class="{ 'is-collapse': !sidebar.opened }">
      <!-- 顶部导航栏：hamburger + 面包屑 + 用户下拉 -->
      <header-bar />

      <!-- 主内容区：路由视图 + 过渡动画 -->
      <app-main />
    </div>
  </div>
</template>

<script setup>
/**
 * 主布局组件 - 后台管理系统的骨架
 *
 * 职责：
 * 1. 组合 sidebar、header、app-main 三个子区域
 * 2. 读取 app store 的 sidebar 状态，控制折叠/展开
 * 3. 监听窗口尺寸变化，自动判断设备类型
 */
import { computed, watch, onMounted, onBeforeUnmount } from 'vue'
import Sidebar from './Sidebar/index.vue'
import HeaderBar from './Header/index.vue'
import AppMain from './AppMain.vue'
import { useAppStore } from '@/store/modules/app'

const appStore = useAppStore()

// 从 store 中解构需要的状态
const sidebar = computed(() => appStore.sidebar)
const device = computed(() => appStore.device)

// 移动端侧边栏宽度断点（与 Element Plus 的断点一致）
const MOBILE_BREAKPOINT = 992

/**
 * 监听窗口宽度变化
 * - 宽度 < 992px 时判定为移动设备，自动折叠侧边栏
 * - 宽度 >= 992px 时恢复桌面模式
 */
const handleResize = () => {
  const isMobile = window.innerWidth < MOBILE_BREAKPOINT
  appStore.setDevice(isMobile ? 'mobile' : 'desktop')

  // 移动端自动折叠侧边栏
  if (isMobile) {
    appStore.closeSidebar(true)
  }
}

// 监听路由变化：移动端跳转路由后自动关闭侧边栏
watch(
  () => appStore.sidebar.opened,
  (newVal) => {
    // 移动端打开侧边栏时，添加遮罩层
    const wrapper = document.querySelector('.app-wrapper')
    if (appStore.device === 'mobile') {
      if (newVal) {
        wrapper?.classList.add('mobile-sidebar-active')
      } else {
        wrapper?.classList.remove('mobile-sidebar-active')
      }
    }
  }
)

onMounted(() => {
  handleResize()
  window.addEventListener('resize', handleResize)
})

onBeforeUnmount(() => {
  window.removeEventListener('resize', handleResize)
})
</script>

<style lang="scss" scoped>
.app-wrapper {
  // 整体使用 flex 水平排列
  display: flex;
  width: 100%;
  height: 100%;

  // ==================== 侧边栏 ====================
  .sidebar-container {
    width: $sideBarWidth;
    height: 100%;
    // 固定在左侧，不随内容滚动
    position: fixed;
    top: 0;
    left: 0;
    bottom: 0;
    z-index: 1001;
    // 折叠/展开的过渡动画
    transition: width $sidebarTransition ease;
    overflow: hidden;

    // 折叠状态：变窄
    &.is-collapse {
      width: $sideBarCollapsedWidth;
    }
  }

  // ==================== 右侧主区域 ====================
  .main-container {
    // 右侧区域 = 总宽度 - 侧边栏宽度
    margin-left: $sideBarWidth;
    min-height: 100vh;
    display: flex;
    flex-direction: column;
    transition: margin-left $sidebarTransition ease;
    position: relative;

    // 折叠状态：margin-left 同步缩小
    &.is-collapse {
      margin-left: $sideBarCollapsedWidth;
    }
  }

  // ==================== 移动端适配 ====================
  &.mobile {
    .sidebar-container {
      // 移动端侧边栏覆盖在内容上方
      width: $sideBarWidth !important;
      transition: transform $sidebarTransition ease;

      // 默认隐藏（向左滑出）
      &:not(.is-collapse) {
        // 移动端展开状态：显示侧边栏
        transform: translateX(0);
      }

      &.is-collapse {
        // 移动端折叠状态：隐藏侧边栏（向左滑出）
        transform: translateX(-$sideBarWidth);
      }
    }

    .main-container {
      // 移动端右侧区域占满宽度
      margin-left: 0 !important;
    }
  }

  // 移动端侧边栏激活状态：显示半透明遮罩
  &.mobile-sidebar-active {
    &::before {
      content: '';
      position: fixed;
      top: 0;
      left: 0;
      right: 0;
      bottom: 0;
      background: rgba(0, 0, 0, 0.3);
      z-index: 1000;
    }
  }
}
</style>
```

**核心要点：**

- 使用 `computed` 从 Pinia store 中获取响应式状态，避免直接解构丢失响应性
- `handleResize` 通过监听 `window.resize` 事件自动判断设备类型，移动端自动折叠侧边栏
- 侧边栏使用 `position: fixed` 固定定位，右侧区域通过 `margin-left` 让出空间
- 移动端侧边栏使用 `transform: translateX` 实现滑入滑出效果，而不是改变宽度

## 三、侧边栏 `src/layout/Sidebar/index.vue`

侧边栏容器组件，包含 Logo 和菜单两部分，负责从 permission store 读取路由数据并传递给 SidebarItem 渲染。

```vue
<!-- src/layout/Sidebar/index.vue -->
<template>
  <div class="sidebar">
    <!-- ==================== Logo 区域 ==================== -->
    <logo class="sidebar-logo" :collapse="!sidebar.opened" />

    <!--
      el-menu 菜单组件
      - collapse: 控制折叠/展开
      - collapse-transition: Element Plus 内置折叠动画
      - background-color / text-color / active-text-color: 菜单主题色
      - unique-opened: 保持只有一个子菜单展开
      - default-active: 当前激活菜单项（与路由 path 对应）
    -->
    <el-scrollbar>
      <el-menu
        :default-active="activeMenu"
        :collapse="!sidebar.opened"
        :collapse-transition="false"
        :unique-opened="true"
        background-color="#304156"
        text-color="#bfcbd9"
        active-text-color="#409eff"
      >
        <!--
          遍历路由表，渲染每个菜单项
          - SidebarItem 是递归组件，支持多级嵌套
          - 将 route 对象和根路径作为 props 传入
        -->
        <sidebar-item
          v-for="route in permissionRoutes"
          :key="route.path"
          :item="route"
          :base-path="route.path"
        />
      </el-menu>
    </el-scrollbar>
  </div>
</template>

<script setup>
/**
 * 侧边栏容器组件
 *
 * 职责：
 * 1. 展示 Logo
 * 2. 渲染 el-menu 菜单，配置折叠/展开
 * 3. 遍历路由表，将每个路由传递给 SidebarItem 递归渲染
 */
import { computed } from 'vue'
import { useRoute } from 'vue-router'
import Logo from './Logo.vue'
import SidebarItem from './SidebarItem.vue'
import { useAppStore } from '@/store/modules/app'
import { usePermissionStore } from '@/store/modules/permission'

const route = useRoute()
const appStore = useAppStore()
const permissionStore = usePermissionStore()

// 侧边栏折叠状态
const sidebar = computed(() => appStore.sidebar)

// 权限路由表（用于渲染侧边栏菜单）
const permissionRoutes = computed(() => permissionStore.routes)

/**
 * 当前激活的菜单路径
 * - 基于当前路由的 path，用于 el-menu 的高亮
 * - 如果路由配置了 activeMenu（用于详情页高亮列表页菜单），则使用它
 */
const activeMenu = computed(() => {
  const { meta, path } = route
  if (meta?.activeMenu) {
    return meta.activeMenu
  }
  return path
})
</script>

<style lang="scss" scoped>
.sidebar {
  height: 100%;
  display: flex;
  flex-direction: column;
  background-color: #304156;

  // Logo 区域固定在顶部
  .sidebar-logo {
    flex-shrink: 0;
  }

  // 菜单区域占据剩余空间
  :deep(.el-scrollbar) {
    flex: 1;
    overflow: hidden;

    // el-menu 隐藏默认的右边框
    .el-menu {
      border-right: none;
      height: 100%;
    }
  }
}
</style>
```

**核心要点：**

- `el-menu` 的 `collapse` 属性接受布尔值，为 `true` 时自动折叠为图标模式
- `collapse-transition` 设为 `false`，因为折叠动画由父组件的 CSS `transition: width` 控制，避免两种动画叠加
- `activeMenu` 使用 `computed` 实时跟踪当前路由变化，确保菜单高亮正确
- `el-scrollbar` 组件让菜单区域内容超出时可滚动，且滚动条样式统一

## 四、侧边栏菜单项 `src/layout/Sidebar/SidebarItem.vue`

这是整个侧边栏菜单系统的核心——一个**递归组件**。它能处理多级嵌套菜单，支持单子项优化显示、hidden 菜单隐藏、外链菜单特殊处理。

```vue
<!-- src/layout/Sidebar/SidebarItem.vue -->
<template>
  <!--
    递归组件说明：
    - 当路由有可见子项时，自身递归调用处理嵌套
    - 只有一个可见子项时，直接渲染为 el-menu-item（减少层级）
    - 没有子项时，渲染为叶子菜单项
  -->

  <!-- ==================== 隐藏菜单项 ==================== -->
  <!-- meta.hidden 为 true 的路由不在侧边栏显示 -->
  <template v-if="!item.meta || !item.meta.hidden">

    <!--
      情况一：只有一个可见子项（或无子项）→ 直接渲染为 el-menu-item
      常见场景：系统管理下只有一个子菜单时，不需要再展开一层
    -->
    <template v-if="hasOneShowingChild(item)">
      <!-- 外链菜单：使用 a 标签跳转 -->
      <app-link v-if="onlyOneChild.meta?.link" :to="resolvePath(onlyOneChild.path)">
        <el-menu-item :index="resolvePath(onlyOneChild.path)">
          <el-icon v-if="onlyOneChild.meta?.icon || item.meta?.icon">
            <component :is="onlyOneChild.meta?.icon || item.meta?.icon" />
          </el-icon>
          <template #title>
            {{ onlyOneChild.meta?.title }}
          </template>
        </el-menu-item>
      </app-link>

      <!-- 普通菜单项：使用 router-link 跳转 -->
      <app-link v-else :to="resolvePath(onlyOneChild.path)">
        <el-menu-item :index="resolvePath(onlyOneChild.path)">
          <el-icon v-if="onlyOneChild.meta?.icon || item.meta?.icon">
            <component :is="onlyOneChild.meta?.icon || item.meta?.icon" />
          </el-icon>
          <template #title>
            {{ onlyOneChild.meta?.title }}
          </template>
        </el-menu-item>
      </app-link>
    </template>

    <!--
      情况二：有多个可见子项 → 渲染为 el-sub-menu（可展开的子菜单）
      el-sub-menu 内递归调用 SidebarItem 处理嵌套
    -->
    <el-sub-menu
      v-else-if="showingChildren.length > 0"
      :index="resolvePath(item.path)"
    >
      <template #title>
        <el-icon v-if="item.meta?.icon">
          <component :is="item.meta.icon" />
        </el-icon>
        <span>{{ item.meta?.title }}</span>
      </template>

      <!-- 递归渲染子菜单项 -->
      <sidebar-item
        v-for="child in showingChildren"
        :key="child.path"
        :item="child"
        :base-path="resolvePath(child.path)"
      />
    </el-sub-menu>

    <!--
      情况三：无子项且非叶子菜单 → 渲染为 el-menu-item
      如：Layout 级别的路由，本身不渲染，children 才是实际页面
      但如果 children 为空或全部 hidden，则渲染自身
    -->
    <app-link v-else :to="resolvePath(item.path)">
      <el-menu-item :index="resolvePath(item.path)">
        <el-icon v-if="item.meta?.icon">
          <component :is="item.meta.icon" />
        </el-icon>
        <template #title>
          {{ item.meta?.title }}
        </template>
      </el-menu-item>
    </app-link>
  </template>
</template>

<script setup>
/**
 * 侧边栏菜单项 - 递归组件
 *
 * 职责：
 * 1. 判断路由是否只有一个可见子项，优化渲染层级
 * 2. 多个子项时使用 el-sub-menu 展开显示
 * 3. 支持外链菜单（meta.link）
 * 4. 递归处理无限层级的嵌套菜单
 *
 * Props:
 * - item: 路由对象（包含 path、meta、children 等）
 * - basePath: 父级路径，用于拼接完整的子路由路径
 */
import { ref, computed } from 'vue'
import AppLink from './Link.vue'
import { isExternal } from '@/utils/validate'

const props = defineProps({
  item: {
    type: Object,
    required: true
  },
  basePath: {
    type: String,
    default: ''
  }
})

// 记录只有一个子项时的那个子项
const onlyOneChild = ref(null)

/**
 * 过滤出可见的子路由
 * 排除 hidden: true 的路由
 * 注意：使用 computed 而非普通函数，这样模板中可以直接使用 showingChildren.length
 */
const showingChildren = computed(() => {
  if (props.item.children) {
    return props.item.children.filter(child => {
      if (child.meta?.hidden) return false
      return true
    })
  }
  return []
})

/**
 * 判断是否只有一个可见子项
 * 如果只有一个子项（或子项路径与父路径相同），则不需要展开子菜单
 */
const hasOneShowingChild = (parent) => {
  const children = showingChildren.value

  // 过滤后没有子项：使用父路由自身作为菜单项
  if (children.length === 0) {
    onlyOneChild.value = { ...parent, path: '' }
    return true
  }

  // 只有一个子项
  if (children.length === 1) {
    onlyOneChild.value = children[0]
    return true
  }

  // 多个子项：不使用单子项优化
  return false
}

/**
 * 解析完整路径
 * - 将子路由的相对路径与 basePath 拼接为完整路径
 * - 如果是外部链接，直接返回
 */
const resolvePath = (routePath) => {
  if (isExternal(routePath)) {
    return routePath
  }
  if (isExternal(props.basePath)) {
    return props.basePath
  }

  // 拼接路径：确保路径以 / 开头
  const base = props.basePath.endsWith('/')
    ? props.basePath
    : props.basePath + '/'
  const path = routePath.startsWith('/')
    ? routePath.substring(1)
    : routePath

  return base + path
}
</script>

<style lang="scss" scoped>
// el-menu-item 的图标与文字间距
:deep(.el-menu-item) {
  .el-icon {
    margin-right: 12px;
    width: 24px;
    text-align: center;
    font-size: 18px;
  }
}

// el-sub-menu 的图标与文字间距
:deep(.el-sub-menu) {
  .el-icon {
    margin-right: 12px;
    width: 24px;
    text-align: center;

  }

  // 子菜单项缩进
  .el-menu {

    }
    .el-sub-menu .el-menu-item {
      padding-left: 74px !important;  // 三级缩进
    }
  }
}
</style>
```

### 4.1 辅助工具函数 `src/utils/validate.js`

SidebarItem 依赖的 URL 校验工具：

```js
// src/utils/validate.js

/**
 * 判断是否是外部链接（http: / https: / mailto: / tel:）
 * @param {string} path
 * @returns {boolean}
 */
export function isExternal(path) {
  return /^(https?:|mailto:|tel:)/.test(path)
}
```

### 4.2 Link 组件 `src/layout/Sidebar/Link.vue`

用于区分普通路由跳转（`router-link`）和外链跳转（`a` 标签）：

```vue
<!-- src/layout/Sidebar/Link.vue -->
<template>
  <!-- 外部链接：使用 a 标签在新窗口打开 -->
  <a v-if="isExternalLink" :href="to" target="_blank" rel="noopener">
    <slot />
  </a>
  <!-- 内部路由：使用 router-link -->
  <router-link v-else :to="to">
    <slot />
  </router-link>
</template>

<script setup>
/**
 * 路由链接封装组件
 *
 * 职责：
 * 1. 区分外部链接和内部路由
 * 2. 外部链接用 <a> 标签，内部路由用 <router-link>
 */
import { computed } from 'vue'
import { isExternal } from '@/utils/validate'

const props = defineProps({
  to: {
    type: String,
    required: true
  }
})

const isExternalLink = computed(() => {
  return isExternal(props.to)
})
</script>
```

**SidebarItem 递归逻辑详解：**

```
路由数据：
{
  path: '/system',
  meta: { title: '系统管理', icon: 'Setting' },
  children: [
    { path: 'user', meta: { title: '用户管理', icon: 'User' } },
    { path: 'role', meta: { title: '角色管理', icon: 'UserFilled' } }
  ]
}

渲染结果：
┌─ el-sub-menu [系统管理]
│  ├─ el-menu-item [用户管理]    ← SidebarItem 递归渲染
│  └─ el-menu-item [角色管理]    ← SidebarItem 递归渲染
└─

特殊情况：只有一个子项时
{
  path: '/system',
  meta: { title: '系统管理', icon: 'Setting' },
  children: [
    { path: 'user', meta: { title: '用户管理', icon: 'User' } }
  ]
}

渲染结果（扁平化，减少一级）：
┌─ el-menu-item [用户管理]        ← 直接显示，不需要展开
└─
```

## 五、Logo 组件 `src/layout/Sidebar/Logo.vue`

Logo 组件显示在侧边栏顶部，折叠时隐藏文字只显示图标，点击可回到首页。

```vue
<!-- src/layout/Sidebar/Logo.vue -->
<template>
  <div class="sidebar-logo" :class="{ collapse: collapse }">
    <!--
      点击 Logo 跳转首页
      - 折叠时隐藏文字，只显示图标
      - 展开时显示图标 + 文字
    -->
    <router-link to="/">
      <!-- Logo 图标区域 -->
      <div class="sidebar-logo-icon">
        <svg-icon icon-class="logo" />
      </div>

      <!-- Logo 文字区域（折叠时隐藏） -->
      <h1 v-if="!collapse" class="sidebar-logo-title">
        {{ title }}
      </h1>
    </router-link>
  </div>
</template>

<script setup>
/**
 * Logo 组件
 *
 * Props:
 * - collapse: 是否折叠状态
 *
 * 职责：
 * 1. 展示系统 Logo 和名称
 * 2. 折叠时隐藏文字只保留图标
 * 3. 点击回到首页
 */
defineProps({
  collapse: {
    type: Boolean,
    default: false
  }
})

// 系统名称（可从环境变量或配置文件中读取）
const title = 'Vue Admin'
</script>

<style lang="scss" scoped>
.sidebar-logo {
  height: $headerHeight;
  line-height: $headerHeight;
  padding: 0 16px;
  overflow: hidden;
  background-color: #2b2f3a;
  // 折叠时居中
  text-align: center;

  a {
    display: flex;
    align-items: center;
    height: 100%;
    width: 100%;
    text-decoration: none;
  }

  // Logo 图标
  .sidebar-logo-icon {
    width: 32px;
    height: 32px;
    flex-shrink: 0;
    display: flex;
    align-items: center;
    justify-content: center;
    color: #fff;
    font-size: 28px;

    :deep(.svg-icon) {
      width: 32px;
      height: 32px;
    }
  }

  // Logo 标题文字
  .sidebar-logo-title {
    margin: 0;
    margin-left: 10px;
    font-size: 14px;
    font-weight: 600;
    color: #fff;
    // 文字溢出隐藏
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
    transition: opacity $sidebarTransition ease;
  }

  // 折叠状态
  &.collapse {
    a {
      justify-content: center; // 图标居中
    }

    .sidebar-logo-title {
      display: none; // 隐藏文字
    }
  }
}
</style>
```

**关于 SvgIcon 组件的说明：**

如果项目还没有封装 `SvgIcon` 组件，可以用 Element Plus 的图标替代。将模板中的 `<svg-icon icon-class="logo" />` 替换为：

```vue
<!-- 使用 Element Plus 图标替代 -->
<div class="sidebar-logo-icon">
  <el-icon :size="28" color="#fff">
    <Monitor />
  </el-icon>
</div>
```

并在 `<script setup>` 中引入：

```js
import { Monitor } from '@element-plus/icons-vue'
```
