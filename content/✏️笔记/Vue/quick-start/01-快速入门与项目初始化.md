# 第1章 快速入门与项目初始化

> 手把手带你从零创建一个 Vue 3 后台管理系统项目，完成基础骨架搭建。

本章目标：创建项目、安装依赖、配置环境变量和构建工具，得到一个干净可用的项目骨架。

---

## 1.1 创建项目

打开终端，执行以下命令。Vite 会以 Vue 模板创建一个新项目：

```bash
npm create vite@latest vue-admin -- --template vue
```

命令说明：
- `npm create vite@latest`：使用最新版本的 Vite 脚手架创建项目
- `vue-admin`：项目名称
- `--template vue`：指定使用 Vue 模板（不是 Vue + TypeScript）

创建完成后进入项目：

```bash
cd vue-admin
```

此时项目结构如下：

```
vue-admin/
├── public/
│   └── vite.svg
├── src/
│   ├── assets/
│   │   └── vue.svg
│   ├── components/
│   │   └── HelloWorld.vue
│   ├── App.vue
│   ├── main.js
│   └── style.css
├── .gitignore
├── index.html
├── package.json
└── vite.config.js
```

先安装默认依赖，确保项目能跑起来：

```bash
npm install
```

启动开发服务器验证：

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`，看到 Vite + Vue 的默认页面就说明项目创建成功。确认无误后 `Ctrl+C` 停止服务器。

## 1.2 安装核心依赖

接下来安装后台管理系统需要的全部核心依赖。一次性复制执行即可：

```bash
# UI 组件库 + 图标
npm install element-plus @element-plus/icons-vue

# 路由 + 状态管理
npm install vue-router@4 pinia

# HTTP 请求
npm install axios

# CSS 预处理器（SCSS 支持）
npm install -D sass

# 路由切换进度条
npm install nprogress

# 路径解析（面包屑组件需要）
npm install path-to-regexp
```

安装完成后，`package.json` 的 `dependencies` 中应包含：

```json
{
  "dependencies": {
    "@element-plus/icons-vue": "^2.3.1",
    "axios": "^1.7.0",
    "element-plus": "^2.9.0",
    "nprogress": "^0.2.0",
    "path-to-regexp": "^8.2.0",
    "pinia": "^2.3.0",
    "vue": "^3.5.0",
    "vue-router": "^4.5.0"
  },
  "devDependencies": {
    "sass": "^1.80.0",
    "@vitejs/plugin-vue": "^5.2.0",
    "vite": "^6.0.0"
  }
}
```

> **各依赖说明：**
> - **element-plus**：Element Plus，Vue 3 最主流的后台管理 UI 组件库
> - **@element-plus/icons-vue**：Element Plus 官方图标库，提供丰富的 SVG 图标
> - **vue-router@4**：Vue 官方路由，用于页面跳转和导航守卫
> - **pinia**：Vue 3 官方推荐的状态管理方案，替代 Vuex
> - **axios**：基于 Promise 的 HTTP 请求库，用于与后端 API 通信
> - **sass**：SCSS 预处理器，提供变量、嵌套、混入等高级 CSS 功能
> - **nprogress**：页面顶部细进度条，用于路由切换时的加载反馈

## 1.3 配置 main.js

打开 `src/main.js`，替换为以下完整代码：

```js
// src/main.js

import { createApp } from 'vue'
import { createPinia } from 'pinia'

// Element Plus
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
import zhCn from 'element-plus/es/locale/lang/zh-cn'

// 全局样式（后续创建）
import '@/assets/styles/global.scss'

// 路由（后续创建）
import router from '@/router'

// App 根组件
import App from './App.vue'

// 创建 Vue 应用实例
const app = createApp(App)

// 注册 Pinia 状态管理
const pinia = createPinia()
app.use(pinia)

// 注册 Vue Router
app.use(router)

// 注册 Element Plus（中文语言包）
app.use(ElementPlus, {
  locale: zhCn, // 全局中文
})

// 全局注册所有 Element Plus 图标
// 这样可以在模板中直接使用 <Edit />、<Delete /> 等图标组件
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

// 挂载应用
app.mount('#app')
```

要点说明：
- `locale: zhCn` 设置 Element Plus 的日期选择器、分页等组件显示中文
- 全局注册图标后，任意 `.vue` 文件中都可以直接使用 `<Delete />`、`<Search />` 等图标
- `@/` 是别名，指向 `src/` 目录，在下一节 vite.config.js 中配置

## 1.4 环境变量配置

在项目根目录创建两个环境变量文件，用于区分开发环境和生产环境。

### `.env.development`（开发环境）

```env
# .env.development

# 环境标识
VITE_APP_ENV = development

# 接口基础地址（开发环境指向后端本地服务）
VITE_APP_BASE_API = /api

# 应用标题
VITE_APP_TITLE = Vue Admin 后台管理系统
```

### `.env.production`（生产环境）

```env
# .env.production

# 环境标识
VITE_APP_ENV = production

# 接口基础地址（生产环境填写真实后端域名）
VITE_APP_BASE_API = https://api.yourdomain.com

# 应用标题
VITE_APP_TITLE = Vue Admin 后台管理系统
```

> **关键规则：**
> - Vite 环境变量必须以 `VITE_` 开头，否则不会被暴露到客户端代码中
> - 在代码中通过 `import.meta.env.VITE_APP_BASE_API` 访问
> - `npm run dev` 自动加载 `.env.development`，`npm run build` 自动加载 `.env.production`
> - 不要在环境变量中存放密码、密钥等敏感信息

## 1.5 配置 vite.config.js

打开 `vite.config.js`，替换为以下完整代码：

```js
// vite.config.js

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import path from 'path'

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    vue(),
  ],

  // 路径别名配置
  resolve: {
    alias: {
      // @ 指向 src 目录
      '@': path.resolve(__dirname, 'src'),
    },
  },

  // 开发服务器配置
  server: {
    // 端口号
    port: 5173,

    // 启动时自动打开浏览器
    open: true,

    // 代理配置 —— 解决开发环境跨域问题
    proxy: {
      // 把 /api 开头的请求代理到后端服务
      '/api': {
        target: 'http://localhost:8080', // 后端服务地址
        changeOrigin: true,             // 改变请求头的 origin
        rewrite: (path) => path.replace(/^\/api/, ''), // 移除 /api 前缀
      },
    },
  },
})
```

要点说明：
- **`@` 别名**：配置后，`import '@/utils/request'` 等同于 `import './src/utils/request'`，路径更简洁
- **代理的作用**：开发时前端在 `localhost:5173`，后端在 `localhost:8080`，直接请求会跨域。通过 `/api` 前缀代理，浏览器以为请求的是同域，实际 Vite 在服务端转发给了后端
- **`rewrite` 规则**：例如请求 `/api/user/login` 会被代理到 `http://localhost:8080/user/login`（去掉了 `/api` 前缀）
