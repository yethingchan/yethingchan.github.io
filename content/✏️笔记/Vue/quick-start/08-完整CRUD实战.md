# 第八章：完整 CRUD 实战 -- 用户管理页面

> **本章是整个教程最核心的章节。** 我们将从零开始，一步步搭建一个完整的"用户管理"页面，涵盖后台管理系统中最常见的所有功能：搜索筛选、表格展示、分页、新增/编辑弹窗、删除（单条 + 批量）、状态切换、导出。学完本章，你就掌握了后台管理系统 80% 以上的页面开发能力。

---

本章将以"用户管理"页面为例，完整演示后台管理系统中最常见的 CRUD 页面开发流程。你将逐步实现以下功能：

- API 接口文件定义
- 页面骨架搭建（搜索栏 + 工具栏 + 表格 + 分页）
- 搜索与重置功能
- 表格列配置、状态开关、操作列
- 分页联动
- 新增/编辑弹窗（含表单校验）
- 单条删除与批量删除（含智能页码回退）
- 导出功能（Blob 文件下载）
- 完整可运行代码 + 模拟数据版本

由于内容较多，本章拆分为三个子章节，请按顺序阅读：

| 8b | [08b-弹窗操作与删除.md](./08b-弹窗操作与删除.md) | 分页联动、新增/编辑弹窗（含表单校验）、单条与批量删除 |
| 8c | [08c-高级功能与完整代码.md](./08c-高级功能与完整代码.md) | 导出功能、完整可运行代码、模拟数据版本、路由配置 |
