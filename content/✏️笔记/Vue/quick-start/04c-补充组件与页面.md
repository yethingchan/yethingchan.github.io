## 补充一：SvgIcon 组件 `src/components/SvgIcon/index.vue`

Logo.vue 中使用了 `<svg-icon icon-class="logo" />`，以下是该组件的完整实现。这个组件封装了 SVG 图标的使用方式，支持通过 `icon-class` 属性指定图标名称，也支持直接使用 Element Plus 图标组件作为降级方案。

```vue
<!-- src/components/SvgIcon/index.vue -->
<template>
  <el-icon v-if="iconClass" :class="['svg-icon', $attrs.class]" :style="{ ...$attrs.style }">
    <component :is="iconClass" />
  </el-icon>
</template>

<script setup>
/**
 * SVG 图标组件
 * 统一封装图标渲染，支持 Element Plus 图标组件名
 *
 * Props:
 * - iconClass: Element Plus 图标组件名（如 'HomeFilled', 'User'）
 *
 * 用法：
 *   <SvgIcon icon-class="HomeFilled" />
 *   <SvgIcon icon-class="Setting" style="font-size: 20px" />
 *
 * 注意：本教程使用 Element Plus 内置图标替代自定义 SVG sprite。
 * 如果需要自定义 SVG 图标（如公司 logo），可以：
 *   1. 安装 vite-plugin-svg-icons
 *   2. 将 SVG 文件放入 src/assets/icons/ 目录
 *   3. 修改本组件使用 <svg><use :href="'#icon-' + iconClass" /></svg> 方式
 */
defineProps({
  iconClass: {
    type: String,
    default: '',
  },
})
</script>

<style scoped>
.svg-icon {
  font-size: inherit;
  color: inherit;
  vertical-align: middle;
}
</style>
```

> **关于自定义 SVG 图标**：如果项目需要使用自定义 SVG 图标（如设计师提供的 logo），推荐使用 `vite-plugin-svg-icons` 插件。安装后将 SVG 文件放入 `src/assets/icons/` 目录，组件自动注册为全局组件。本教程为保持简洁，使用 Element Plus 内置图标作为替代方案。

## 补充二：全局样式重置 `src/assets/styles/reset.scss`

项目目录结构中规划了 `reset.scss`，用于清除浏览器默认样式。以下是完整代码，在 `main.js` 中通过 `import '@/assets/styles/reset.scss'` 引入。

```scss
*::after {

  margin: 0;
  padding: 0;

  font-size: 14px;
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  -webkit-text-size-adjust: 100%;

    'Helvetica Neue', Arial, 'Noto Sans', sans-serif;
  color: #333;
  background-color: #f5f5f5;
}

a {
  color: inherit;
  text-decoration: none;
}

img {
  max-width: 100%;
  height: auto;
  vertical-align: middle;
}

ul,
ol {
  list-style: none;
}

input,
button,
textarea,
select {
  font: inherit;

// 滚动条美化（Webkit 浏览器）

  width: 6px;

  background-color: rgba(144, 147, 153, 0.3);

  }

  background-color: transparent;
}
```

> 在 `main.js` 中确保引入了此文件：

> import '@/assets/styles/reset.scss'
> ```

## 补充三：个人中心页面 `src/views/profile/index.vue`

UserDropdown 组件中包含"个人中心"菜单项，跳转到 `/profile` 路由。以下是基础的页面实现：

```vue
<!-- src/views/profile/index.vue -->
<template>
  <div class="page-container">
    <el-card>
      <template #header>
        <span>个人中心</span>
      </template>

      <el-descriptions :column="2" border>
        <el-descriptions-item label="用户名">{{ userInfo.username }}</el-descriptions-item>
        <el-descriptions-item label="昵称">{{ userInfo.nickname }}</el-descriptions-item>
        <el-descriptions-item label="手机号">{{ userInfo.phone || '未设置' }}</el-descriptions-item>
        <el-descriptions-item label="邮箱">{{ userInfo.email || '未设置' }}</el-descriptions-item>
        <el-descriptions-item label="部门">{{ userInfo.deptName || '未分配' }}</el-descriptions-item>
        <el-descriptions-item label="角色">
          <el-tag
            v-for="role in userInfo.roles"
            :key="role"
            size="small"
            style="margin-right: 6px"
          >
            {{ role }}
          </el-tag>
        </el-descriptions-item>
        <el-descriptions-item label="创建时间">{{ userInfo.createTime }}</el-descriptions-item>
        <el-descriptions-item label="最后登录">{{ userInfo.lastLoginTime || '-' }}</el-descriptions-item>
      </el-descriptions>
    </el-card>
  </div>
</template>

<script setup>
import { computed } from 'vue'
import { useUserStore } from '@/store/modules/user'

const userStore = useUserStore()
const userInfo = computed(() => userStore.userInfo || {})
</script>

<style scoped>
.page-container {
  padding: 20px;
}
</style>
```

## 补充四：修改密码页面 `src/views/password/index.vue`

UserDropdown 组件中包含"修改密码"菜单项，跳转到 `/password` 路由。以下是基础的页面实现：

```vue
<!-- src/views/password/index.vue -->
<template>
  <div class="page-container">
    <el-card style="max-width: 500px">
      <template #header>
        <span>修改密码</span>
      </template>

      <el-form
        ref="formRef"
        :model="form"
        :rules="rules"
        label-width="100px"
        size="large"
      >
        <el-form-item label="旧密码" prop="oldPassword">
          <el-input
            v-model="form.oldPassword"
            type="password"
            show-password
            placeholder="请输入旧密码"
          />
        </el-form-item>

        <el-form-item label="新密码" prop="newPassword">
          <el-input
            v-model="form.newPassword"
            type="password"
            show-password
            placeholder="请输入新密码（至少6位）"
          />
        </el-form-item>

        <el-form-item label="确认密码" prop="confirmPassword">
          <el-input
            v-model="form.confirmPassword"
            type="password"
            show-password
            placeholder="请再次输入新密码"
          />
        </el-form-item>

        <el-form-item>
          <el-button type="primary" @click="handleSubmit" :loading="loading">
            确认修改
          </el-button>
          <el-button @click="handleReset">重置</el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script setup>
import { ref, reactive } from 'vue'
import { ElMessage } from 'element-plus'

const formRef = ref(null)
const loading = ref(false)

const form = reactive({
  oldPassword: '',
  newPassword: '',
  confirmPassword: '',
})

// 确认密码校验
const validateConfirm = (rule, value, callback) => {
  if (value !== form.newPassword) {
    callback(new Error('两次输入的密码不一致'))
  } else {
    callback()
  }
}

const rules = {
  oldPassword: [{ required: true, message: '请输入旧密码', trigger: 'blur' }],
  newPassword: [
    { required: true, message: '请输入新密码', trigger: 'blur' },
    { min: 6, message: '密码长度不能少于6位', trigger: 'blur' },
  ],
  confirmPassword: [
    { required: true, message: '请再次输入新密码', trigger: 'blur' },
    { validator: validateConfirm, trigger: 'blur' },
  ],
}

const handleSubmit = async () => {
  try {
    await formRef.value.validate()
    loading.value = true

    // TODO: 调用修改密码 API
    // await changePassword({ oldPassword: form.oldPassword, newPassword: form.newPassword })

    ElMessage.success('密码修改成功，请重新登录')
    // 修改成功后可跳转到登录页
    // router.push('/login')
  } catch (error) {
    if (error !== false) {
      console.error('修改密码失败:', error)
    }
  } finally {
    loading.value = false
  }
}

const handleReset = () => {
  formRef.value?.resetFields()
}
</script>

<style scoped>
.page-container {
  padding: 20px;
}
</style>
```

> **注意**：修改密码功能需要后端提供对应的 API 接口。上方代码中标注了 `TODO` 的位置，实际使用时替换为真实的接口调用。同时需要在路由配置中注册 `/profile` 和 `/password` 路由（使用 Layout 布局），并在 `asyncRoutes` 或 `constantRoutes` 中添加。
