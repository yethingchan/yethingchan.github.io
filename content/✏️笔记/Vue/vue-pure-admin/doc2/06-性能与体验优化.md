## 第六阶段：性能 & 体验优化 — 进阶拔高

> 本文是 vue-pure-admin 八阶段深度教程的第六篇，分析项目在加载优化、运行时优化、打包体积优化和用户体验兜底方面的实践。

---

### 一、加载优化

#### 1.1 路由懒加载

```typescript
// 静态路由 — 每个页面组件都是独立的 chunk
component: () => import("@/views/system/user/index.vue")

// 动态路由 — 通过 Glob Import 实现
const modulesRoutes = import.meta.glob("/src/views/**/*.{vue,tsx}");
```

效果：首屏只加载首页组件的代码（~50KB），其他页面在访问时才加载。

#### 1.2 依赖预构建

```typescript
// build/optimize.ts
const include = [
  "qs", "mitt", "xlsx", "dayjs", "axios", "pinia",
  "vue-i18n", "vxe-table", "@vueuse/core", ...
];  // 50+ 个依赖预构建
```

预构建将 ES Module 格式的依赖打包为单个文件，开发环境下的浏览器请求数从数百个减少到几十个。

#### 1.3 客户端文件预热

```typescript
// vite.config.ts
server: {
  warmup: {
    clientFiles: ["./index.html", "./src/{views,components}/*"]
  }
}
```

Vite 在启动时预先处理这些文件，用户首次访问时不需要等待编译。

#### 1.4 CDN 外置

```typescript
// build/cdn.ts — 7 个大型库从 CDN 加载
modules: [
  { name: "vue",          var: "Vue" },
  { name: "vue-router",   var: "VueRouter" },
  { name: "vue-i18n",     var: "VueI18n" },
  { name: "element-plus", var: "ElementPlus" },
  { name: "axios",        var: "axios" },
  { name: "dayjs",        var: "dayjs" },
  { name: "echarts",      var: "echarts" }
]
```

CDN 加载的优势：浏览器并行下载 + CDN 边缘节点缓存 + 不占用服务器带宽。

### 二、运行时优化

#### 2.1 响应式优化

```typescript
// 使用 shallowRef 代替 ref — 避免深度响应式的性能开销
const tableData = shallowRef([]);
// 更新时需要整体替换，而非 push
tableData.value = [...newData];

// 使用 markRaw 标记不需要响应式的对象
const chartInstance = markRaw(echarts.init(el));
```

#### 2.2 keep-alive 缓存

```vue
<router-view v-slot="{ Component }">
  <keep-alive :include="permissionStore.cachePageList">
    <component :is="Component" :key="route.fullPath" />
  </keep-alive>
</router-view>
```

缓存已访问的页面组件，切换标签页时无需重新创建组件和请求数据。

#### 2.3 防抖与节流

```typescript
// 搜索输入防抖
import { useDebounceFn } from "@vueuse/core";
const handleSearch = useDebounceFn((keyword) => {
  searchApi(keyword);
}, 300);

// 窗口 resize 节流
import { useThrottleFn } from "@vueuse/core";
const handleResize = useThrottleFn(() => {
  updateLayout();
}, 200);
```

#### 2.4 虚拟滚动

```vue
<!-- VxeTable 虚拟滚动 — 超过 50 行自动启用 -->
<vxe-table :scroll-y="{ enabled: true, gt: 50 }" />

<!-- vue-virtual-scroller — 自定义列表虚拟滚动 -->
<RecycleScroller :items="bigList" :item-size="50">
  <template #default="{ item }">
    <div class="list-item">{{ item.name }}</div>
  </template>
</RecycleScroller>
```

### 三、打包体积优化

#### 3.1 产物体积分析

```bash
# 生成可视化分析报告
pnpm report
# 打开 report.html 查看各模块体积
```

使用 `rollup-plugin-visualizer` 生成交互式的 treemap 图表，一眼看出哪些模块占用空间最大。

#### 3.2 Gzip / Brotli 压缩

| 压缩方式 | 体积减少 | 浏览器支持 |
|----------|----------|-----------|
| **Gzip** | ~70% | 所有浏览器 |
| **Brotli** | ~80% | 现代浏览器 |
| **Both** | 取最优 | 根据 Accept-Encoding 协商 |

#### 3.3 代码分割策略

```typescript
// vite.config.ts 的 Rolldown 输出配置
rolldownOptions: {
  output: {
    chunkFileNames: "static/js/[name]-[hash].js",
    entryFileNames: "static/js/[name]-[hash].js",
    assetFileNames: "static/[ext]/[name]-[hash].[ext]"
  }
}
```

Rolldown 自动进行代码分割，每个路由页面和大型依赖都是独立的 chunk。

#### 3.4 移除 console.log

```typescript
// build/plugins.ts
removeConsole({ external: ["src/assets/iconfont/iconfont.js"] })
```

生产构建自动移除所有 `console.log`，减少代码体积和避免信息泄露。保留 iconfont.js 中的 console（图标字体脚本需要）。

```typescript
router.beforeEach((to, from, next) => {

  // ...

});
```

```typescript
// HTTP 响应拦截器中
if (!navigator.onLine) {
```

### 六、小结

- **加载优化**：路由懒加载 + 依赖预构建 + CDN 外置 + 文件预热，四管齐下
- **运行时优化**：shallowRef / markRaw + keep-alive + 防抖节流 + 虚拟滚动
- **打包优化**：Gzip/Brotli + 代码分割 + console 移除 + 体积分析
- **体验兜底**：Loading + 空状态 + 错误页 + 进度条 + 网络检测 + 版本更新提示
