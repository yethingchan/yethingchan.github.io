### 一、页面执行流程

#### 1.1 单个页面的生命周期

一个典型页面从加载到交互的完整流程：

```
用户点击菜单
  │
  ▼
路由守卫 (beforeEach)
  ├── 检查 Token
  ├── 检查权限
  └── 放行
  │
  ▼
路由匹配 → 懒加载组件
  │  import("@/views/system/user/index.vue")
  │
  ▼
组件实例化 (setup)
  ├── 定义响应式状态
  ├── 注册 Composable（useTable 等）
  ├── onMounted → 发起数据请求
  └── 返回模板绑定
  │
  ▼
模板渲染
  ├── 搜索表单渲染
  ├── 表格骨架屏 / Loading
  └── 分页组件渲染
  │
  ▼
数据返回 → 更新状态
  ├── tableData.value = result.list
  ├── pagination.total = result.total
  └── loading.value = false
  │
  ▼
交互响应
  ├── 搜索 → 重置分页 → 重新请求
  ├── 新增 → 打开弹窗 → 提交 → 刷新
  ├── 编辑 → 回填数据 → 修改 → 刷新
  └── 删除 → 确认 → 请求 → 刷新
```

#### 1.2 页面模块组织

```
src/views/
├── system/
```

### 二、表单处理

#### 2.1 表单校验体系

vue-pure-admin 使用 Element Plus 内置的表单校验系统，配合自定义规则：

```vue
<script setup lang="ts">
import { reactive, ref } from "vue";

const formRef = ref();
const formData = reactive({
  username: "",
  email: "",
  phone: "",
  role: ""
});

const rules = {
  username: [
    { required: true, message: "请输入用户名", trigger: "blur" },
    { min: 2, max: 20, message: "长度在 2-20 个字符", trigger: "blur" }
  ],
  email: [
    { required: true, message: "请输入邮箱", trigger: "blur" },
    { type: "email", message: "邮箱格式不正确", trigger: "blur" }
  ],
  phone: [
    { pattern: /^1[3-9]\d{9}$/, message: "手机号格式不正确", trigger: "blur" }
  ],
  role: [
    { required: true, message: "请选择角色", trigger: "change" }
  ]
};

// 自定义异步校验
const asyncCheckUsername = async (rule, value, callback) => {
  if (!value) return callback();
  const exists = await checkUsernameExistsApi(value);
  exists ? callback(new Error("用户名已存在")) : callback();
};
</script>

<template>
  <el-form ref="formRef" :model="formData" :rules="rules" label-width="100px">
    <el-form-item label="用户名" prop="username">
      <el-input v-model="formData.username" />
    </el-form-item>
    <!-- 其他表单项... -->
  </el-form>
</template>
```

#### 2.2 复杂表单 — Schema Form

vue-pure-admin 集成了 `plus-pro-components` 的 Schema Form，支持 JSON 配置驱动的表单：

```typescript
const columns = [
  {
    label: "用户名",
    prop: "username",
    valueType: "input",
    rules: [{ required: true, message: "请输入用户名" }]
  },
  {
    label: "角色",
    prop: "role",
    valueType: "select",
    options: [
      { label: "管理员", value: "admin" },
      { label: "普通用户", value: "user" }
    ]
  },
  {
    label: "状态",
    prop: "status",
    valueType: "switch",
    props: { activeValue: 1, inactiveValue: 0 }
  }
];
```

Schema Form 的优势：表单结构通过数据驱动，便于动态配置和后端控制。

### 三、列表/表格处理

#### 3.1 表格分页模式

```vue
<script setup lang="ts">
import { ref, reactive, onMounted } from "vue";

const loading = ref(false);
const tableData = ref([]);
const pagination = reactive({
  currentPage: 1,
  pageSize: 10,
  total: 0,
  pageSizes: [10, 20, 50, 100]
});

async function loadData() {
  loading.value = true;
  try {
    const result = await getListApi({
      page: pagination.currentPage,
      pageSize: pagination.pageSize
    });
    tableData.value = result.data.list;
    pagination.total = result.data.total;
  } finally {
    loading.value = false;
  }
}

function handlePageChange(page: number) {
  pagination.currentPage = page;
  loadData();
}

function handleSizeChange(size: number) {
  pagination.pageSize = size;
  pagination.currentPage = 1;  // 切换每页条数时回到第一页
  loadData();
}

onMounted(() => loadData());
</script>

<template>
  <el-table v-loading="loading" :data="tableData" :border="true">
    <el-table-column prop="name" label="名称" />
    <el-table-column prop="status" label="状态">
      <template #default="{ row }">
        <el-tag :type="row.status === 1 ? 'success' : 'danger'">
          {{ row.status === 1 ? "启用" : "禁用" }}
        </el-tag>
      </template>
    </el-table-column>
    <el-table-column label="操作" width="200">
      <template #default="{ row }">
        <el-button link type="primary" @click="handleEdit(row)">编辑</el-button>
        <el-button link type="danger" @click="handleDelete(row)">删除</el-button>
      </template>
    </el-table-column>
  </el-table>

  <el-pagination
    v-model:current-page="pagination.currentPage"
    v-model:page-size="pagination.pageSize"
    :page-sizes="pagination.pageSizes"
    :total="pagination.total"
    layout="total, sizes, prev, pager, next, jumper"
    @current-change="handlePageChange"
    @size-change="handleSizeChange"
  />
</template>
```

#### 3.2 VxeTable 大数据表格

对于超过 1000 条数据的表格，项目使用 VxeTable 的虚拟滚动：

```vue
<template>
  <vxe-table
    :data="tableData"
    :scroll-y="{ enabled: true, gt: 50 }"
    :columns="columns"
    height="500"
  />
</template>
```

`gt: 50` 表示超过 50 行时自动启用虚拟滚动，只渲染可视区域内的行。

#### 3.3 表格拖拽排序

```typescript
import Sortable from "sortablejs";

function setupDragSort() {
  const el = document.querySelector(".el-table__body-wrapper tbody");
  Sortable.create(el, {
    animation: 150,
    onEnd: ({ oldIndex, newIndex }) => {
      const item = tableData.value.splice(oldIndex, 1)[0];
      tableData.value.splice(newIndex, 0, item);
    }
  });
}
```

### 四、弹窗与抽屉

#### 4.1 ReDialog 编程式调用

```typescript
import { addDialog, closeDialog } from "@/components/ReDialog";

// 打开新增弹窗
function openAddDialog() {
  addDialog({
    title: "新增用户",
    width: "600px",
    props: {
      type: "add"
    },
    contentRenderer: () => h(UserForm, { ref: formRef }),
    beforeSure: (done, { options }) => {
      const formData = options.props.formRef.getFormData();
      addUserApi(formData).then(() => {
        ElMessage.success("新增成功");
        done();           // 关闭弹窗
        loadData();       // 刷新列表
      });
    }
  });
}

// 打开编辑弹窗
function openEditDialog(row: UserType) {
  addDialog({
    title: "编辑用户",
    width: "600px",
    props: {
      type: "edit",
      formData: { ...row }
    },
    contentRenderer: () => h(UserForm, {
      ref: formRef,
      modelValue: row
    }),
    beforeSure: (done, { options }) => {
      const formData = options.props.formRef.getFormData();
      updateUserApi({ ...row, ...formData }).then(() => {
        ElMessage.success("修改成功");
        done();
        loadData();
      });
    }
  });
}
```

### 五、文件上传与下载

#### 5.1 文件上传

```vue
<template>
  <el-upload
    :action="uploadUrl"
    :headers="{ Authorization: `Bearer ${token}` }"
    :before-upload="beforeUpload"
    :on-success="onUploadSuccess"
    :on-error="onUploadError"
    accept=".jpg,.png,.pdf"
  >
    <el-button type="primary">上传文件</el-button>
  </el-upload>
</template>

<script setup lang="ts">
const uploadUrl = `${import.meta.env.VITE_PROXY_DOMAIN_REAL}/api/upload`;

function beforeUpload(file: File) {
  const isLt10M = file.size / 1024 / 1024 < 10;
  if (!isLt10M) {
    ElMessage.warning("文件大小不能超过 10MB");
  }
  return isLt10M;
}
</script>
```

#### 5.2 文件下载

```typescript
async function handleExport() {
  const response = await exportApi({ ...searchParams });
  const blob = new Blob([response], { type: "application/vnd.ms-excel" });
  const url = URL.createObjectURL(blob);
  const link = document.createElement("a");
  link.href = url;
  link.download = `导出数据_${dayjs().format("YYYY-MM-DD")}.xlsx`;
  link.click();
  URL.revokeObjectURL(url);
}
```

### 六、水印功能

```typescript
// App.vue 中的水印实现
import { useWatermark } from "@pureadmin/utils";

const { setWatermark, clear } = useWatermark();

watch(
  [watermarkEnable, watermarkText, () => route.name],
  async ([enable, text, name]) => {
    await nextTick();
    if (enable && name !== "Login") {
      setWatermark(text, { verticalOffset: 170 });
    } else {
      clear();
    }
  },
  { immediate: true }
);
```

水印基于 Canvas 绘制，覆盖在整个页面上，不可通过 CSS 隐藏（会定期检测并重新添加）。

### 八、小结

- **页面执行流程**遵循"守卫 → 懒加载 → setup → 请求 → 渲染 → 交互"的标准化路径
- **表单校验**以 Element Plus 内置校验为主，支持异步校验和 Schema Form
- **表格分页**是标准模式，大数据量用 VxeTable 虚拟滚动
- **ReDialog 编程式弹窗**统一管理，路由切换时自动清理
- **水印和版本检测**是企业级应用的必备功能，项目内置支持
