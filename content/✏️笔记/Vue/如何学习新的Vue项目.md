# Vue 前端项目拿到手怎么学？给你一套**最清晰、最落地**的学习角度（新手直接照做）

我给你**纯实战、不绕弯**的思路，你拿到任何 Vue2/Vue3 项目，按下面这些**角度**去拆，1 天就能看懂项目结构，3 天能改页面，7 天能加功能。

我分成 **3 大阶段 + 10 个学习角度**，你照着看就行。

---

# 一、拿到 Vue 项目第一步：先搞懂【项目整体】（2 个角度）
## 角度 1：看项目结构（知道文件夹是干嘛的）
Vue 标准结构你必须一眼认出来：
```
项目根目录
├── public/         # 静态资源（不打包）
├── src/            # 核心代码（99% 都在这里）
│   ├── api/        # 接口请求（调后端）
│   ├── assets/     # 图片、样式
│   ├── components/ # 公共组件（按钮、表格、弹窗）
│   ├── router/     # 路由（页面跳转）
│   ├── store/      # 全局状态（Vuex/Pinia）
│   ├── utils/      # 工具函数
│   ├── views/      # 页面（真正的业务页面）
│   ├── App.vue     # 根组件
│   └── main.js     # 入口文件
├── package.json    # 依赖 + 启动命令
└── vite.config.js / vue.config.js # 配置
```

**你要做的：**
不看代码，先认文件夹，知道**页面在哪、接口在哪、路由在哪**。

---

## 角度 2：看 package.json（项目怎么跑起来）
打开 `package.json` 只看 3 个东西：
1. **scripts**
   - `dev` / `serve` → 启动命令
   - `build` → 打包
2. **dependencies**
   看用了哪些库：
   - `vue`
   - `axios`（请求）
   - `element-plus` / `ant-design-vue`（UI 库）
   - `vue-router`（路由）
   - `pinia` / `vuex`（状态）
3. 是 Vue2 还是 Vue3
   一眼就能区分。

**你要做的：**
先把项目**跑起来**，能打开浏览器看到页面 = 成功一半。

---

# 二、第二阶段：搞懂【页面 + 路由 + 接口】（4 个角度）
这是前端最核心的部分，**80% 业务都在这里**。

## 角度 3：看路由（知道页面怎么跳转）
打开 `router/index.js`

你能看到：
```js
const routes = [
  { path: '/login', component: Login },
  { path: '/home', component: Home },
]
```

**你要做的：**
知道**网址对应哪个页面文件**，以后想改哪个页面，直接通过路由找到 .vue 文件。

---

## 角度 4：看页面文件（Vue 三件套）
每个 `.vue` 文件都固定三部分：
```vue
<template>   → 页面结构（HTML）
<script>     → 逻辑（JS/TS）
<style>      → 样式（CSS）
```

学习顺序：
1. 先看 `<template>` 长什么样
2. 再看 `<script>` 数据从哪来
3. 最后看样式

**不要一上来就啃逻辑！先看页面长啥样。**

---

## 角度 5：看 API 接口（前端怎么调后端）
打开 `api/` 文件夹，里面全是接口：
```js
export function getUserList(params) {
  return request({
    url: '/user/list',
    method: 'get'
  })
}
```

**你要做的：**
知道页面**数据从哪个接口来**，参数是什么，返回什么。

---

## 角度 6：看请求封装（utils/request.js）
所有 Vue 项目都有统一的 axios 封装：
- 请求头
-  token
-  状态码判断
-  错误提示

看懂这个，你就懂**前端所有接口怎么工作**。

---

# 三、第三阶段：搞懂【逻辑 + 组件 + 状态】（4 个角度）
## 角度 7：看公共组件（提高复用能力）
`components/` 里的都是公共组件：
- 表格
- 搜索框
- 弹窗
- 表单

你要学会：
- 怎么用
- 怎么传值（props）
- 怎么触发事件（emit）

**看懂公共组件 = 你能快速改任何页面**

---

## 角度 8：看全局状态（Pinia/Vuex）
如果项目有登录、用户信息、主题切换，一定在这里。

你只需要搞懂：
- 存了什么数据
- 怎么存
- 怎么取

不用一开始深入。

---

## 角度 9：看工具函数（utils/）
比如：
- 格式化时间
- 防抖节流
- 本地存储
- 正则校验

这些都是**通用轮子**，看懂换项目也能用。

---

## 角度 10：从一个页面入手，逆向追踪（最有效学习法）
不要乱看！
**选一个简单页面（比如用户列表），按这个流程走一遍：**

```
页面（views/user/list.vue）
→ 触发方法（script）
→ 调用接口（api/user.js）
→ 后端返回数据
→ 页面渲染展示
```

**走通一个页面 = 你懂整个项目**

---

# 四、给你一套最快速的学习步骤（照着做就行）
1. 跑起项目
2. 看路由 → 找到页面文件
3. 看页面结构（template）
4. 看页面逻辑（script）
5. 看接口（api）
6. 看公共组件
7. 自己改一个文字、改一个样式、加一个按钮
8. 自己加一个简单页面（成功=学会）

---

# 五、一句话总结学习角度
**看结构 → 跑项目 → 看路由 → 看页面 → 看接口 → 看组件 → 动手改。**

---

### 总结
你学习 Vue 项目，只需要抓 **10 个角度**：
1. 项目结构
2. package.json
3. 路由
4. 页面结构
5. 页面逻辑
6. 接口
7. 请求封装
8. 公共组件
9. 全局状态
10. 工具类

按这个顺序，**任何 Vue 项目你都能快速吃透**。
