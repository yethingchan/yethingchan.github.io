**Controller编写规范**:

```java
@RestController                              // 标记为REST控制器
@RequestMapping("/system/user")              // 统一路径前缀
public class SysUserController extends BaseController  // 继承基类
{
    @Autowired
    private ISysUserService userService;     // 注入Service
    
    @PreAuthorize("@ss.hasPermi('system:user:list')")  // 权限校验
    @GetMapping("/list")                     // GET请求
    public TableDataInfo list(SysUser user)  // 返回分页数据
    {
        startPage();                         // 开启分页
        List<SysUser> list = userService.selectUserList(user);
        return getDataTable(list);           // 封装返回结果
    }
    
    @Log(title = "用户管理", businessType = BusinessType.INSERT)  // 记录日志
    @PreAuthorize("@ss.hasPermi('system:user:add')")
    @PostMapping                             // POST请求
    public AjaxResult add(@RequestBody SysUser user)
    {
        return toAjax(userService.insertUser(user));
    }
}
```

**关键点**:
- 继承 `BaseController` 获得通用方法（分页、响应封装等）
- 使用 `@PreAuthorize` 进行权限控制
- 使用 `@Log` 自动记录操作日志
- 返回 `TableDataInfo`（分页）或 `AjaxResult`（普通响应）

**SecurityConfig.java - 安全配置（核心）**:

```java
@Configuration
@EnableMethodSecurity(prePostEnabled = true, securedEnabled = true)
public class SecurityConfig {
    
    @Autowired
    private JwtAuthenticationTokenFilter authenticationTokenFilter;
    
    @Bean
    protected SecurityFilterChain filterChain(HttpSecurity httpSecurity) 
            throws Exception {
        return httpSecurity
            // CSRF禁用（因为使用JWT）
            .csrf(csrf -> csrf.disable())
            // 无状态Session
            .sessionManagement(session -> 
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            // 认证错误处理
            .exceptionHandling(exception -> 
                exception.authenticationEntryPoint(unauthorizedHandler))
            // 退出登录
            .logout(logout -> logout.logoutUrl("/logout")
                .logoutSuccessHandler(logoutSuccessHandler))
            // URL权限配置
            .authorizeHttpRequests((requests) -> {
                requests.requestMatchers("/login", "/register", "/captchaImage")
                    .permitAll()  // 允许匿名访问
                    .requestMatchers(HttpMethod.GET, "/", "/*.html", "/**.html", 
                        "/**.css", "/**.js", "/profile/**")
                    .permitAll()
                    .requestMatchers("/swagger-ui.html", "/v3/api-docs/**", 
                        "/swagger-ui/**", "/druid/**")
                    .permitAll()
                    .anyRequest().authenticated();  // 其他请求需要认证
            })
            // CORS跨域配置
            .cors(cors -> cors.configurationSource(corsConfigurationSource()))
            // 添加JWT过滤器
            .addFilterBefore(authenticationTokenFilter, 
                UsernamePasswordAuthenticationFilter.class)
            .build();
    }
    
    @Bean
    public BCryptPasswordEncoder bCryptPasswordEncoder() {
        return new BCryptPasswordEncoder();  // 密码加密
    }
    
    @Bean
    public AuthenticationManager authenticationManager(
            AuthenticationConfiguration authConfig) throws Exception {
        return authConfig.getAuthenticationManager();
    }
}
```

**配置要点**:
1. **禁用CSRF**: JWT无状态认证不需要CSRF保护
2. **STATELESS Session**: 不创建HttpSession
3. **匿名URL白名单**: 登录、注册、验证码等无需认证
4. **JWT过滤器**: 在UsernamePasswordAuthenticationFilter之前执行
5. **BCrypt加密**: 密码使用强哈希算法

**LogAspect.java - 操作日志记录**:

```java
@Aspect
@Component
public class LogAspect {
    
    @Autowired
    private AsyncManager asyncManager;
    
    @Pointcut("@annotation(controllerLog)")
    public void logPointCut(Log controllerLog) {}
    
    @AfterReturning(pointcut = "logPointCut(controllerLog)", 
                    returning = "jsonResult")
    public void doAfterReturning(JoinPoint joinPoint, Log controllerLog, 
                                  Object jsonResult) {
        handleLog(joinPoint, controllerLog, null, jsonResult);
    }
    
    @AfterThrowing(value = "logPointCut(controllerLog)", throwing = "e")
    public void doAfterThrowing(JoinPoint joinPoint, Log controllerLog, 
                                 Exception e) {
        handleLog(joinPoint, controllerLog, e, null);
    }
    
    protected void handleLog(JoinPoint joinPoint, Log controllerLog, 
                             Exception e, Object jsonResult) {
        try {
            // 获取当前登录用户
            LoginUser loginUser = SecurityUtils.getLoginUser();
            
            // 构建操作日志对象
            OperLogEvent operLog = new OperLogEvent();
            operLog.setTenantId(loginUser.getTenantId());
            operLog.setOperIp(IpUtils.getIpAddr());
            operLog.setOperUrl(ServletUtils.getRequest().getRequestURI());
            operLog.setOperName(loginUser.getUsername());
            operLog.setDeptName(loginUser.getDept().getDeptName());
            
            // 设置方法信息
            Method method = ((MethodSignature) joinPoint.getSignature()).getMethod();
            operLog.setTitle(controllerLog.title());
            operLog.setBusinessType(controllerLog.businessType().ordinal());
            
            // 处理请求参数
            if (controllerLog.isSaveRequestData()) {
                operLog.setOperParam(JSON.toJSONString(argsArrayToString(joinPoint.getArgs())));
            }
            
            // 处理返回参数
            if (controllerLog.isSaveResponseData() && StringUtils.isNotNull(jsonResult)) {
                operLog.setJsonResult(JSON.toJSONString(jsonResult));
            }
            
            // 设置执行时间
            operLog.setCostTime(System.currentTimeMillis() - startTime);
            
            // 异步保存日志
            asyncManager.execute(AsyncFactory.recordOper(operLog));
            
        } catch (Exception exp) {
            log.error("记录操作日志异常", exp);
        }
    }
}
```

**工作流程**:
1. Controller方法添加 `@Log` 注解
2. 方法执行后触发 `@AfterReturning` 或 `@AfterThrowing`
3. 收集请求参数、返回结果、执行时间等信息
4. 异步保存到 `sys_oper_log` 表

**JwtAuthenticationTokenFilter.java - JWT过滤器**:

```java
@Component
public class JwtAuthenticationTokenFilter extends OncePerRequestFilter {
    
    @Autowired
    private TokenService tokenService;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
            HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        
        // 1. 从请求中获取LoginUser
        LoginUser loginUser = tokenService.getLoginUser(request);
        
        // 2. 如果用户存在且未认证
        if (StringUtils.isNotNull(loginUser) && 
            StringUtils.isNull(SecurityUtils.getAuthentication())) {
            
            // 3. 验证Token有效期（不足20分钟自动刷新）
            tokenService.verifyToken(loginUser);
            
            // 4. 创建认证对象
            UsernamePasswordAuthenticationToken authenticationToken = 
                new UsernamePasswordAuthenticationToken(
                    loginUser, null, loginUser.getAuthorities());
            
            authenticationToken.setDetails(
                new WebAuthenticationDetailsSource().buildDetails(request));
            
            // 5. 设置到Security上下文
            SecurityContextHolder.getContext().setAuthentication(authenticationToken);
        }
        
        chain.doFilter(request, response);
    }
}
```

**每个请求的执行流程**:
```
请求进入 → JWT过滤器 → 解析Token → 从Redis获取用户 → 设置SecurityContext → Controller
```

```java
@Service
public class SysUserServiceImpl implements ISysUserService {
    
    @Autowired
    private SysUserMapper userMapper;
    
    @Autowired
    private SysRoleMapper roleMapper;
    
    @Autowired
    private SysPostMapper postMapper;
    
    @Autowired
    private SysUserRoleMapper userRoleMapper;
    
    @Autowired
    private SysUserPostMapper userPostMapper;
    
    /**
     * 根据条件分页查询用户列表
     */
    @Override
    @DataScope(deptAlias = "d", userAlias = "u")  // 数据权限过滤
    public List<SysUser> selectUserList(SysUser user) {
        return userMapper.selectUserList(user);
    }
    
    /**
     * 新增用户信息（事务控制）
     */
    @Override
    @Transactional  // 事务注解
    public int insertUser(SysUser user) {
        // 1. 新增用户基本信息
        int rows = userMapper.insertUser(user);
        
        // 2. 新增用户角色关联
        insertUserRole(user);
        
        // 3. 新增用户岗位关联
        insertUserPost(user);
        
        return rows;
    }
    
    /**
     * 修改用户信息
     */
    @Override
    @Transactional
    public int updateUser(SysUser user) {
        Long userId = user.getUserId();
        
        // 1. 删除用户与角色关联
        userRoleMapper.deleteUserRoleByUserId(userId);
        
        // 2. 新增用户与角色关联
        insertUserRole(user);
        
        // 3. 删除用户与岗位关联
        userPostMapper.deleteUserPostByUserId(userId);
        
        // 4. 新增用户与岗位关联
        insertUserPost(user);
        
        // 5. 更新用户基本信息
        return userMapper.updateUser(user);
    }
    
    /**
     * 新增用户角色信息
     */
    public void insertUserRole(SysUser user) {
        this.insertUserRole(user.getUserId(), user.getRoleIds());
    }
    
    public void insertUserRole(Long userId, Long[] roleIds) {
        if (StringUtils.isNotNull(roleIds)) {
            // 批量插入
            List<SysUserRole> list = new ArrayList<>();
            for (Long roleId : roleIds) {
                SysUserRole ur = new SysUserRole();
                ur.setUserId(userId);
                ur.setRoleId(roleId);
                list.add(ur);
            }
            if (!list.isEmpty()) {
                userRoleMapper.batchUserRole(list);
            }
        }
    }
}
```

**Service层设计要点**:
1. **@Service注解**: 标记为Spring服务Bean
2. **@Transactional**: 事务控制，保证数据一致性
3. **@DataScope**: 数据权限切面，自动注入SQL过滤条件
4. **关联表处理**: 先删后增策略，简化更新逻辑

```javascript
import axios from 'axios'
import { Notification, MessageBox, Message } from 'element-ui'
import store from '@/store'
import { getToken } from '@/utils/auth'

// 创建axios实例
const service = axios.create({
  baseURL: process.env.VUE_APP_BASE_API,  // API基础路径
  timeout: 50000  // 超时时间
})

// 请求拦截器
service.interceptors.request.use(config => {
  // 是否需要Token
  const isToken = (config.headers || {}).isToken === false
  
  if (getToken() && !isToken) {
    config.headers['Authorization'] = 'Bearer ' + getToken()
  }
  
  // GET请求参数处理
  if (config.method === 'get' && config.params) {
    let url = config.url + '?' + tansParams(config.params)
    url = url.slice(0, -1)
    config.params = {}
    config.url = url
  }
  
  return config
}, error => {
  Promise.reject(error)
})

// 响应拦截器
service.interceptors.response.use(res => {
  const code = res.data.code || 200
  const msg = res.data.msg || '未知错误'
  
  // 二进制数据直接返回
  if (res.request.responseType === 'blob' || res.request.responseType === 'arraybuffer') {
    return res.data
  }
  
  if (code === 401) {
    // Token过期，跳转登录
    MessageBox.confirm('登录状态已过期，请重新登录', '系统提示', {
      confirmButtonText: '重新登录',
      cancelButtonText: '取消',
      type: 'warning'
    }).then(() => {
      store.dispatch('LogOut').then(() => {
        location.href = '/index'
      })
    })
  } else if (code !== 200) {
    Notification.error({ title: msg })
    return Promise.reject(new Error(msg))
  } else {
    return res.data
  }
}, error => {
  Message({ message: error.message, type: 'error', duration: 5000 })
  return Promise.reject(error)
})

export default service
```

#### (2) 路由守卫

**文件**: `src/permission.js`

```javascript
import router from './router'
import store from './store'
import { Message } from 'element-ui'
import NProgress from 'nprogress'
import { getToken } from '@/utils/auth'

NProgress.configure({ showSpinner: false })

// 白名单
const whiteList = ['/login', '/register']

router.beforeEach((to, from, next) => {
  NProgress.start()
  
  if (getToken()) {
    // 已登录
    if (to.path === '/login') {
      next({ path: '/' })
      NProgress.done()
    } else {
      // 判断是否已获取用户信息
      if (store.getters.roles.length === 0) {
        // 获取用户信息和动态路由
        store.dispatch('GetInfo').then(() => {
          store.dispatch('GenerateRoutes').then(accessRoutes => {
            // 动态添加路由
            router.addRoutes(accessRoutes)
            next({ ...to, replace: true })
          })
        }).catch(err => {
          store.dispatch('LogOut').then(() => {
            Message.error(err)
            next({ path: '/' })
          })
        })
      } else {
        next()
      }
    }
  } else {
    // 未登录
    if (whiteList.indexOf(to.path) !== -1) {
      next()
    } else {
      next(`/login?redirect=${to.fullPath}`)
      NProgress.done()
    }
  }
})

router.afterEach(() => {
  NProgress.done()
})
```

#### (3) 权限指令

**文件**: `src/directive/permission/hasPermi.js`

```javascript
import store from '@/store'

export default {
  inserted(el, binding, vnode) {
    const { value } = binding
    const all_permission = "*:*:*"
    const permissions = store.getters && store.getters.permissions
    
    if (value && value instanceof Array && value.length > 0) {
      const permissionFlag = value
      
      const hasPermissions = permissions.some(permission => {
        return all_permission === permission || permissionFlag.includes(permission)
      })
      
      if (!hasPermissions) {
        el.parentNode && el.parentNode.removeChild(el)
      }
    } else {
      throw new Error(`请设置操作权限标签值`)
    }
  }
}
```

**使用方式**:

```vue
<template>
  <!-- 按钮权限控制 -->
  <el-button 
    v-hasPermi="['system:user:add']"
    @click="handleAdd">
    新增
  </el-button>
  
  <!-- 多个权限之一 -->
  <el-button 
    v-hasPermi="['system:user:edit', 'system:user:update']">
    修改
  </el-button>
</template>
```

### 5.1 模块职责总结

| 模块 | 职责 | 关键技术 |
|------|------|----------|
| **ruoyi-admin** | Web入口，Controller层 | Spring MVC, RESTful API |

| **ruoyi-quartz** | 定时任务调度 | Quartz |

| **ruoyi-ui** | Vue前端项目 | Vue.js, Element UI, Vuex |
