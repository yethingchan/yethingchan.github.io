# 二、文件上传（最常用）
## 1. 实现方式
### 前端 Vue
- `el-upload` 组件
- 上传到 SpringBoot 接口
- 返回 URL 回显

### 后端 SpringBoot
- `MultipartFile` 接收
- 保存到：
  - 本地磁盘
  - 阿里云 OSS / 腾讯 COS
  - MinIO（自建文件服务）

## 2. 难点
1. **大文件上传卡顿、超时**
2. **跨域问题**
3. **文件名重复、中文乱码**
4. **文件大小限制**
5. **图片恶意篡改（.png 改成 .exe）**

## 3. 解决方案
- **小文件（<10MB）**：直接上传
- **大文件（>10MB）**：**分片上传**（前端切片，后端合并）
- **安全**：校验文件头、文件类型、文件大小
- **存储**：企业优先 **OSS/MinIO**，不存本地

## 4. 最优方案
**Vue + el-upload + SpringBoot + MinIO/OSS**
稳定、安全、扩容方便、不占应用服务器空间。

# 三、文件下载 / Excel 导出
## 1. 实现方式
### 方式A（最常用）
- 后端：`OutputStream` 输出流
- 设置响应头：
  ```
  Content-Disposition: attachment; filename=xxx.xlsx
  ```
- 前端直接访问 URL 下载

### 方式B
- 后端返回 byte[]
- 前端 `Blob` 接收并下载

## 2. 难点
1. **中文文件名乱码**
2. **大数据量导出 OOM 内存溢出**
3. **导出时间过长，前端超时**
4. **样式复杂（合并单元格、图片）难处理**

## 3. 解决方案
- **乱码**：URLEncoder 编码
- **大数据**：**分页查询 + 流式生成 SXSSF**
- **超时**：**异步导出 + 消息通知**
- **复杂样式**：使用模板填充（EasyExcel）

## 4. 最优方案
**Alibaba EasyExcel（强烈推荐）**
- 不占内存
- 超稳定
- 代码极少
- 若依、Jeecg、所有企业都用它

# 四、Excel 导入（上传并解析）
## 1. 实现方式
1. Vue `el-upload` 选择文件
2. SpringBoot 接收文件
3. **EasyExcel** 读取内容
4. 校验 → 入库 → 返回结果

## 2. 难点
1. **Excel 格式不规范**
2. **数据量大导致解析慢**
3. **批量插入数据库慢**
4. **错误数据如何回传提示**

## 3. 解决方案
- **EasyExcel** 流式读取
- **校验**：Bean Validation（@NotBlank…）
- **批量插入**：MyBatis-Plus 批量 / JDBC 批处理
- **错误回显**：返回错误行号+原因

## 4. 最优方案
**Vue el-upload + SpringBoot + EasyExcel**
行业标准方案。

# 五、打印（页面 / 单据 / 报表 / A4 / 小票）
## 分 3 种打印场景
---

## 场景1：简单页面打印（清单、列表）
### 实现
- `window.print()`
- CSS 控制打印样式

### 难点
- 样式错乱
- 不需要的按钮、导航也被打印

### 解决
- `@media print { 隐藏不需要的元素 }`

---

## 场景2：单据/报表打印（最常用：订单、发货单）
### 实现方式
1. **Vue 打印组件（print-js / vue-print-nb）**
2. 隐藏DOM打印
3. 后台生成PDF → 前端打印

### 难点
- 格式要求严格
- 分页、页眉页脚
- 条码/二维码

### 最优方案
**前端打印插件 + 专门写打印页面（隐藏导航）**
简单、快、稳定。

---

## 场景3：复杂报表、PDF打印（合同、票据）
### 实现
- 后端模板（itext / freemarker / poi）生成PDF
- 前端预览 + 打印

### 优点
格式绝对统一
### 缺点
开发慢
