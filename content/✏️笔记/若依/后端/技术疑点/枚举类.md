# 一、枚举是什么？（一句话）
**枚举 = 把固定不变的常量（如性别、状态、类型）封装成类，方便全局使用。**

比如：
- 性别：男、女
- 状态：正常、停用
- 业务类型：新增、删除、修改
- 操作状态：成功、失败

不用到处写 `0` `1` `"男"` `"女"`，**用枚举更安全、更清晰、不易写错**。

### 带值、带描述的枚举（最常用！）
```java
/**
 * 性别枚举
 */
public enum SexEnum
{
    MALE("0", "男"),
    FEMALE("1", "女"),
    UNKNOWN("2", "未知");

    private final String code;
    private final String name;

    SexEnum(String code, String name)
    {
        this.code = code;
        this.name = name;
    }

    public String getCode()
    {
        return code;
    }

    public String getName()
    {
        return name;
    }
}
```

# 五、枚举在若依的**使用细节**

## 1）枚举是常量，不能 new
```java
// ✅ 正确
SexEnum male = SexEnum.MALE;

// ❌ 错误
SexEnum male = new SexEnum();
```

## 2）枚举可以获取 code/name
```java
String code = SexEnum.MALE.getCode(); // 0
String name = SexEnum.MALE.getName(); // 男
```

## 3）枚举可以遍历
```java
for (SexEnum sex : SexEnum.values()) {
    System.out.println(sex.getCode() + " : " + sex.getName());
}
```

## 4）根据 code 获取枚举
工具类方法：
```java
public static SexEnum getByCode(String code) {
    for (SexEnum sex : SexEnum.values()) {
        if (sex.getCode().equals(code)) {
            return sex;
        }
    }
    return null;
}
```

使用：
```java
SexEnum sex = SexEnum.getByCode("0");
```

# 七、若依枚举**注意点（踩坑大全）**

## 1）枚举不能重复
```java
MALE("0","男"),
MALE("1","女") // 错误！名字不能重复
```

## 2）枚举命名规范
- 全部大写
- 单词下划线分隔
```java
USER_STATUS
BUSINESS_TYPE
```

## 3）数据库存的是 code，不是枚举名
```java
// 数据库存 0/1，不是存 MALE/FEMALE
```

## 4）前端传值要传 code，后端自动转
```java
@RequestParam SexEnum sex
```
前端传 `0` → 后端自动变成 `SexEnum.MALE`

## 5）不要在枚举里写复杂逻辑
枚举只做：
- 存常量
- 存code/name
不做业务计算！

## 6）枚举是单例，线程安全
全局唯一，随便用。

## 7）不要频繁创建枚举
枚举在类加载时就创建好了，**不占内存**。
