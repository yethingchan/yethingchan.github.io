# 若依(RuoYi-Vue)字典全解（全场景、后端+前端+注解+Excel+原理+踩坑）
## 一、字典核心概念&两张底层数据表
### 1、作用
**数据库存数字/编码（0、1、2），页面展示中文（正常、停用、男、女）；统一管理下拉选项，改配置不用改代码**。
- dictLabel：**前端展示文字**（正常/男）
- dictValue：**数据库存储值**（0/1）
- dictType：**字典唯一标识（全局主键），全系统靠这个绑定**

### 2、两张数据库表（一对多）
#### ① sys_dict_type【字典类型表：分类】
|字段|说明|示例|
|----|----|----|
|dict_id|主键ID|自增|
|dict_name|字典中文名称|用户状态、性别|
|dict_type|**字典编码(唯一，全系统使用)**|sys_normal_disable、sys_user_sex|
|status|状态0启用1停用|0|



#### ② sys_dict_data【字典数据表：具体键值对，依附dict_type】
|字段|说明|示例|
|----|----|----|
|dict_code|主键|自增|
|dict_sort|排序序号|1、2（下拉框排序）|
|dict_label|展示文本|正常、停用|
|dict_value|存储值|0、1|
|dict_type|关联上面字典类型编码|sys_normal_disable|
|list_class|表格标签样式|tag-success/tag-danger（绿标红标）|
|is_default|是否默认选中Y/N|Y默认选中下拉|



> **操作第一步：系统菜单→系统管理→字典管理，先新增字典类型，再在类型下新增字典数据**

## 二、五大使用场景（重点，项目全覆盖）
### 场景1：后端实体 @Dict注解（接口返回JSON自动翻译，最常用）
**作用：后端查询数据库存的数字，返回前端自动多出XXLabel字段，中文翻译，不用手动代码转换**
#### 1、@Dict注解源码属性
```java
@Dict(
        type = "sys_normal_disable", // 必填：字典类型编码（sys_normal_disable）
        dictText = "statusName"      // 可选：自定义生成翻译字段名；不写默认原字段+Label
)
private String status; // 数据库存：0/1
```
- 不加`dictText`：自动生成`statusLabel:"正常"`
- 加`dictText="statusName"`：生成`statusName:"正常"`

#### 2、实体示例
```java
public class User {
    private Long userId;
    // 数据库存0/1，字典sys_normal_disable：0=正常，1=停用
    @Dict(type = "sys_normal_disable")
    private String status;
    // 性别字典sys_user_sex：1男，2女
    @Dict(type = "sys_user_sex",dictText = "sexName")
    private String sex;
}
```
**接口返回JSON自动追加翻译字段：**
```json
{
    "userId":1,
    "status":"0",
    "statusLabel":"正常", // 自动生成
    "sex":"1",
    "sexName":"男"        // 自定义名称
}
```
> 原理：**DictAspect切面环绕Controller，返回JSON前自动翻译字典，Redis缓存字典数据**

### 场景2：前端Vue页面使用（下拉框+表格回显，分Vue2/Vue3两种写法）
> 前端字典数据存Vuex，优先读缓存，无缓存请求后端`/system/dict/data/{dictType}`接口

#### ① Vue2(若依老版本，主流写法dicts数组自动加载)
```vue
<script>
export default {
  // 【核心】声明需要的字典，页面初始化自动拉取字典存入dict.xxx
  dicts: ['sys_normal_disable','sys_user_sex'],
  data(){
    return { form:{} }
  }
}
</script>

<template>
<!--1、新增/编辑下拉框：el-select下拉 -->
<el-select v-model="form.status" placeholder="请选择">
  <el-option
    v-for="item in dict.sys_normal_disable"
    :key="item.dictValue"
    :label="item.dictLabel"
    :value="item.dictValue"
  ></el-option>
</el-select>

<!--2、表格列表回显（推荐内置dict-tag组件，自带list_class颜色标签） -->
<el-table-column label="用户状态" prop="status">
  <template slot-scope="scope">
    <dict-tag :options="dict.sys_normal_disable" :value="scope.row.status"/>
  </template>
</el-table-column>
</template>
```

#### ② Vue3(setup语法糖，useDict)
```vue
<script setup>
import { useDict } from '@/utils/dict'
// 传入多个字典类型，直接解构
const { sys_normal_disable, sys_user_sex } = useDict('sys_normal_disable','sys_user_sex')
</script>

<template>
<el-select v-model="form.status">
  <el-option v-for="item in sys_normal_disable" :label="item.dictLabel" :value="item.dictValue"/>
</el-select>
<dict-tag :options="sys_normal_disable" :value="row.status"/>
</template>
```

#### ③ 手动获取字典（不推荐，老项目遗留）

### 场景3：@Excel注解导出Excel自动字典翻译（你之前学的Excel注解联动）
**导出Excel数据库数字自动变成中文，导入中文自动转回数字**
```java
public class User{
    // dictType绑定字典，导出自动翻译
    @Excel(name = "用户状态", dictType = "sys_normal_disable")
    private String status;
}
```
- 导出：数据库0 → Excel单元格：正常
- 导入：Excel填正常 → 入库自动转为0

### 场景4：后端Java代码手动翻译（Service/工具类硬编码转换）
**不用注解，代码里手动拿字典翻译值，工具类DictUtils**
```java
@Autowired
private ISysDictTypeService dictTypeService;

//1、根据【字典类型+存储值】→ 获取中文标签
String label = dictTypeService.getDictLabel("sys_normal_disable","0");
// label = "正常"

//2、根据【字典类型+中文】→ 获取存储值
String value = dictTypeService.getDictValue("sys_normal_disable","停用");
// value = "1"

//3、获取字典全量键值列表
List<SysDictData> list = dictTypeService.selectDictDataByType("sys_user_sex");
```

### 场景5：代码生成器一键自动生成字典代码（开发最快方式）
1. 系统→代码生成→编辑字段
2. **字典类型填入对应dictType编码**（如sys_normal_disable）
3. 生成代码后：
   - 实体自动生成`@Dict(type="xxx")`
   - 前端vue自动写入`dicts:['xxx']`、下拉框、dict-tag标签
> 新项目首选，零手写字典代码

## 三、字典缓存机制（重要，修改字典不生效原因）
1. **字典全量缓存Redis**，新增/修改字典数据**不会自动刷新缓存**
2. 修改字典后生效操作：
   - 方式1：字典管理页面右上角【刷新缓存】按钮
   - 方式2：后端代码`DictUtils.clearDictCache()`清空指定字典缓存
3. 前端：字典存入Vuex，刷新页面才重新请求后端

## 四、字典常用内置编码（系统自带字典）
|字典类型dictType|含义|
|----|----|
|sys_normal_disable|0正常 1停用（通用状态）|

## 五、高频踩坑&注意事项
1. **dictValue数据类型必须和数据库字段一致**
   - 数据库status存Integer(0/1) → dictValue填数字`0`，不能填字符串`"0"`，否则翻译失败
2. 修改字典后**必须刷新缓存**，否则新旧数据混杂
3. 一个dictType全局唯一，**多个业务表字段可共用同一个字典**（比如所有表状态都用sys_normal_disable）
4. dict-tag颜色不生效：配置sys_dict_data的`list_class`（tag-success/tag-warning/tag-danger）
5. @Dict不生效：
   - 检查Controller是否被AOP拦截（若依默认切面拦截所有Controller返回值）
   - dictType拼写错误、字典状态停用

## 六、最简实操步骤（新建自定义字典全流程）
1. 字典管理→新增字典类型：字典名称`订单状态`，dictType`order_status`
2. 新增字典数据：
   - label:待付款 value:0 sort:1
   - label:已付款 value:1 sort:2
3. 实体字段加注解`@Dict(type="order_status")`
4. 前端vue `dicts:['order_status']`，下拉框&表格直接使用
5. 测试：数据库存0，接口返回`orderStatusLabel:"待付款"`
