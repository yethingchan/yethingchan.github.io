# 私有方法是什么？类里怎么自定义方法？

## 私有方法 private

**只能在当前类内部使用，外面不能调用。**

作用：

- 抽取重复代码
- 隐藏内部逻辑
- 安全、封装

例子：

java

运行

```
public class UserService {

    // 公开方法：外面能调用
    public void add() {
        check();  // 调用私有方法
    }

    // 私有方法：只有自己能用
    private void check() {
        System.out.println("检查参数");
    }
}
```

## 一个类里可以怎么写方法？

随便写！你可以自定义：

java

运行

```
// 无返回无参数
private void a() {}

// 有返回有参数
private int b(int x, int y) {
    return x + y;
}

// 公开
public void c() {}

// 静态
public static void d() {}
```

**想怎么写就怎么写，私有就是给自己用的工具方法。**

私有方法 = 类内部专用工具方法
