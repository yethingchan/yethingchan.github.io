# 二、逐行超通俗解释
```java
public class SensitiveJsonSerializer extends StdSerializer<String>
```
- **继承 StdSerializer**：自定义JSON输出规则
- **<String>**：只对**字符串类型**字段生效

---

```java
private final DesensitizedType desensitizedType;
```
- 脱敏类型：手机号/身份证/邮箱/银行卡 等

---

```java
public SensitiveJsonSerializer() {
    super(String.class);
    this.desensitizedType = null;
}
```
- 空构造，默认不脱敏

---

```java
public SensitiveJsonSerializer(DesensitizedType desensitizedType) {
    super(String.class);
    this.desensitizedType = desensitizedType;
}
```
- 带脱敏类型的构造器

---

```java
@Override
public void serialize(String value, JsonGenerator gen, SerializationContext ctxt) {
    if (desensitizedType != null && desensitization()) {
        // 脱敏：把真实值变成 ****
        gen.writeString(desensitizedType.desensitizer().apply(value));
    } else {
        // 不脱敏：直接输出原值
        gen.writeString(value);
    }
}
```
**核心方法：把值转成JSON时执行**
- 需要脱敏 + 不是管理员 → 隐藏显示
- 否则 → 原样输出

---

```java
@Override
public ValueSerializer<?> createContextual(...) {
    // 拿到字段上的 @Sensitive 注解
    Sensitive annotation = property.getAnnotation(Sensitive.class);
    if (annotation != null) {
        // 根据注解里的脱敏类型，创建序列化器
        return new SensitiveJsonSerializer(annotation.desensitizedType());
    }
}
```
作用：
**读取字段上的 @Sensitive 注解，知道要对什么类型脱敏**

---

```java
private boolean desensitization() {
    LoginUser user = SecurityUtils.getLoginUser();
    // 管理员不脱敏！
    return !user.getUser().isAdmin();
}
```
**规则：超级管理员看到完整信息，普通用户必须脱敏**

# 四、重点回答你：序列化的意义是什么？
## 一句话：
**序列化 = 把 Java 对象 → 变成 JSON 字符串**

## 为什么要做？
Java 内存里的对象：
```java
User{ name="张三", phone="13812345678" }
```

**前端看不懂！**

所以必须**序列化**变成：
```json
{
    "name": "张三",
    "phone": "138****1234"
}
```

## 序列化的意义：
1. **让Java对象能在网络上传输**（给前端/别的服务）
2. **让数据变成通用格式（JSON）**
3. **可以在传输过程中修改数据（脱敏、格式化、加密）**
4. **SpringBoot 接口返回数据，底层全是序列化**

你写的接口：
```java
@GetMapping("/user")
public User getUser() {
    return user;
}
```
**底层自动执行序列化 → 变成JSON返回给前端**

# 五、这个脱敏序列化的意义
**在序列化过程中偷偷把敏感信息隐藏**
- 手机号
- 身份证
- 银行卡
- 邮箱
- 地址

**不影响业务代码，只改JSON输出，安全又干净！**
