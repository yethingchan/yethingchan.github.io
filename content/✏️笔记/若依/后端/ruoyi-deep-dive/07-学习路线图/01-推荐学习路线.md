# 推荐学习路线

> 本路线图将 43 篇文档组织为 **8 个学习步骤**，按照从整体到细节、从基础到进阶的顺序，帮助你系统性地掌握 RuoYi-Vue 项目的架构设计与实现原理。
>
> 预计总学习时长：**26-34 小时**

---

## 第一步：看整体 -- 模块划分、技术栈、启动方式、环境配置

> **核心目标**：能独立启动项目，理解项目骨架

| 项目 | 内容 |
|------|------|
| **对应文档** | `01-工程整体梳理/` 全部 5 篇 |
| **预计时间** | 2-3 小时 |

### 学习内容

- 项目整体架构与功能模块划分
- Maven 多模块结构与模块间依赖关系
- Spring Boot 启动入口与环境配置方式
- `application.yml` 等配置文件的深度解析
- Maven 构建工具使用与项目打包部署

### 自检清单

- [ ] 我能独立把项目在本地跑起来吗？（后端 + 前端 + 数据库 + Redis）
- [ ] 我能说出项目有哪些 Maven 模块，以及它们之间的依赖关系吗？
- [ ] 我知道项目的启动类在哪里，启动流程是怎样的吗？
- [ ] 我能找到并修改数据库连接、Redis 连接、服务端口等核心配置吗？
- [ ] 我能使用 Maven 打包项目并部署吗？

### 重点提示

- **这一步最重要**：务必亲手把项目跑通，不要只看不练
- 如果启动失败，优先检查数据库和 Redis 是否已安装并启动
- 建议使用 IntelliJ IDEA 导入项目，利用其 Maven 集成能力

---

## 第二步：吃透基础组件 -- Web 统一处理、异常、拦截器、返回体

> **核心目标**：理解请求处理全流程

| 项目 | 内容 |
|------|------|
| **对应文档** | `02-核心基础组件/` 的 01-04 篇 |
| **预计时间** | 3-4 小时 |

### 学习内容

- 统一返回体 `AjaxResult` / `R` 的设计思路与使用方式
- 全局异常处理器 `GlobalExceptionHandler` 的实现原理
- Servlet 过滤器链的组成与执行顺序
- Spring MVC 拦截器机制与自定义拦截器实现

### 自检清单

- [ ] 我能解释一个 HTTP 请求从进入到返回的完整处理链路吗？
- [ ] 我知道 `AjaxResult` 的结构设计，以及为什么要统一返回格式吗？
- [ ] 我能说全局异常处理是如何捕获并统一处理异常的吗？
- [ ] 我理解 Filter 和 Interceptor 的区别以及各自的适用场景吗？
- [ ] 我能自己写一个自定义拦截器并注册到项目中吗？

### 重点提示

- 建议在 `GlobalExceptionHandler` 中打断点，发送一个会触发异常的请求，观察异常是如何被捕获和处理的
- 理解统一返回体是理解整个 API 设计风格的基础
- Filter 和 Interceptor 的区别是面试高频问题，务必搞清楚

---

## 第三步：学习数据层 -- 数据库配置、ORM、实体分层、事务

> **核心目标**：掌握 MyBatis 使用和实体分层

| 项目 | 内容 |
|------|------|
| **对应文档** | `02-核心基础组件/` 的 05-06 篇 |
| **预计时间** | 2-3 小时 |

### 学习内容

- MyBatis 在项目中的集成方式与配置
- Mapper XML 的编写规范与动态 SQL 技巧
- 实体类（Entity / BO / VO / DTO）的分层设计思想
- 数据源配置与事务管理机制

### 自检清单

- [ ] 我能找到项目中 MyBatis 的核心配置位置吗？
- [ ] 我理解 Entity、BO、VO、DTO 各自的职责和使用场景吗？
- [ ] 我能独立编写一个 Mapper 接口和对应的 XML 文件吗？
- [ ] 我知道项目中 PageHelper 分页是如何实现的吗？
- [ ] 我理解 `@Transactional` 注解的使用方式和注意事项吗？

### 重点提示

- RuoYi 使用了 MyBatis（非 MyBatis-Plus），重点理解 XML 映射文件的编写方式
- 实体分层设计是本项目的一大亮点，理解 `BaseEntity` 的继承体系
- 建议对照数据库表结构来理解实体类的字段设计

## 第四步：梳理分层架构 -- Controller / Service / Mapper 职责，理解分层思想

> **核心目标**：能独立开发一个 CRUD 模块

| 项目 | 内容 |
|------|------|
| **对应文档** | `03-业务分层架构/` 全部 8 篇 |
| **预计时间** | 4-5 小时 |

### 学习内容

- 项目分层架构总览（Controller -> Service -> Mapper）
- Controller 层的设计规范与参数校验
- Service 层的业务逻辑组织与事务控制
- Mapper 层的 SQL 编写规范
- 用户管理、角色权限管理、登录认证、代码生成器等核心业务流程

### 自检清单

- [ ] 我能清晰描述 Controller、Service、Mapper 三层各自的职责吗？
- [ ] 我知道 Controller 层的参数校验是如何实现的吗？
- [ ] 我理解 Service 层为什么需要接口 + 实现类的双层结构吗？
- [ ] 我能完整走通一个从请求到数据库再到响应的调用链路吗？
- [ ] 我能参考现有模块，独立开发一个全新的 CRUD 业务模块吗？

### 重点提示

- **强烈建议动手练习**：选择一个简单的业务表，从 Controller 到 Mapper 完整实现一遍
- 代码生成器可以自动生成 CRUD 代码，先手动写一遍再对比生成代码，理解差异
- 注意观察 Service 层中事务边界的划分方式

## 第五步：逐个拆解中间件 -- Redis、权限、定时任务等

> **核心目标**：掌握每个中间件的配置和使用

| 项目 | 内容 |
|------|------|
| **对应文档** | `04-中间件与增强组件/` 全部 10 篇 |
| **预计时间** | 5-6 小时 |

### 学习内容

- Redis 缓存体系（缓存工具类、缓存注解、缓存策略）
- Spring Security 权限框架的集成与配置
- JWT 认证与 Token 机制（生成、验证、刷新）
- 数据权限的实现原理（行级数据过滤）
- Quartz 定时任务体系（任务配置、调度管理）
- 日志体系（操作日志、登录日志）
- 接口文档与 API 管理（Swagger/Knife4j）
- 文件上传下载服务
- 线程池与异步任务
- 验证码与数据脱敏

### 自检清单

- [ ] 我能说出 Redis 在项目中的所有使用场景吗？
- [ ] 我理解 Spring Security 的认证和授权流程吗？
- [ ] 我知道 JWT Token 是如何生成、存储、验证和刷新的吗？
- [ ] 我能配置一个新的定时任务并让它正常运行吗？
- [ ] 我理解数据权限的实现原理，知道如何为业务表添加数据权限过滤吗？

### 重点提示

- Redis 在项目中的使用非常广泛，建议逐个场景梳理：登录缓存、验证码、限流、字典缓存等
- Spring Security + JWT 的组合是本项目安全体系的核心，务必深入理解
- 数据权限是 RuoYi 的特色功能，理解其 SQL 拼接原理对二次开发非常重要

## 第六步：通读核心业务代码 -- 逐功能走流程，理解业务规则

> **核心目标**：理解 RBAC 权限模型和核心业务流程

| 项目 | 内容 |
|------|------|
| **对应文档** | `03-业务分层架构/` 的 05-08 篇（业务流程篇） |
| **预计时间** | 3-4 小时 |

### 学习内容

- 用户管理业务流程（用户增删改查、导入导出、重置密码）
- 角色与权限管理业务流程（RBAC 模型、角色分配、权限标识）
- 登录认证完整流程（用户名密码登录、验证码校验、Token 签发）

### 自检清单

- [ ] 我能完整画出用户登录的时序图吗？（从前端请求到 Token 返回）
- [ ] 我理解 RBAC 权限模型中用户、角色、菜单三者的关系吗？
- [ ] 我知道权限校验（`@PreAuthorize`）是如何工作的吗？
- [ ] 我能说出代码生成器从读取表结构到生成代码的完整流程吗？
- [ ] 我理解用户-角色-菜单的数据流转和关联关系吗？

### 重点提示

- 建议使用 Debug 模式，从前端发起一个登录请求，逐步跟踪到数据库再返回
- RBAC（基于角色的访问控制）是后台管理系统的核心模型，务必彻底理解
- 代码生成器是 RuoYi 提高开发效率的关键功能，理解其模板机制有助于自定义生成

## 附加建议

### 适合人群

- 有 Java 基础，了解 Spring Boot 基本用法
- 希望系统学习企业级后台管理系统架构
- 需要基于 RuoYi 进行二次开发的工程师
- 准备面试，希望深入理解后台管理系统设计思路的开发者

### 学习工具推荐

- **IDE**：IntelliJ IDEA（推荐）或 Eclipse
- **数据库工具**：Navicat、DBeaver 或 DataGrip
- **API 调试**：Postman 或 Apifox
- **Redis 客户端**：RedisInsight 或 Another Redis Desktop Manager
- **画图工具**：Draw.io、ProcessOn（用于绘制架构图和时序图）

### 进阶方向

完成本学习路线后，可以进一步探索以下方向：

1. **二次开发实战** -- 基于代码生成器快速开发新业务模块
2. **微服务改造** -- 将单体架构拆分为 Spring Cloud 微服务
3. **前端深入** -- 深入学习 Vue 前端架构和组件设计
4. **DevOps 实践** -- 结合 Docker、Jenkins 实现 CI/CD 流水线
5. **性能调优** -- 结合 JMeter 等工具进行压力测试和性能优化

---

> **最后提醒**：学习最重要的是坚持和动手。每完成一个步骤，建议回头总结，用自己的话复述学到的知识。如果遇到不理解的地方，多看源码、多打断点调试、多画图梳理，相信你一定能系统掌握 RuoYi-Vue 项目的精髓。
