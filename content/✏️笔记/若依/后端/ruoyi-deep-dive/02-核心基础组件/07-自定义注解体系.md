## 二、核心设计思想

RuoYi-Vue 的自定义注解体系遵循 **"声明式编程"** 思想，通过注解 + AOP 切面的组合实现横切关注点：

```
注解（声明） + 切面（执行） = 功能
```

9个注解按功能分为4大类：
- **日志审计**：@Log
- **数据控制**：@DataScope、@DataSource
- **安全防护**：@RateLimiter、@RepeatSubmit、@Anonymous
- **数据输出**：@Excel、@Excels、@Sensitive

## 三、各注解详解

### 3.1 @Log -- 操作日志记录

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/Log.java
@Target({ ElementType.PARAMETER, ElementType.METHOD })
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface Log
{
    public String title() default "";                                    // 模块名称
    public BusinessType businessType() default BusinessType.OTHER;      // 操作类型
    public OperatorType operatorType() default OperatorType.MANAGE;      // 操作人类别
    public boolean isSaveRequestData() default true;                     // 是否保存请求参数
    public boolean isSaveResponseData() default true;                    // 是否保存响应参数
    public String[] excludeParamNames() default {};                      // 排除的参数名
}
```

**切面处理**（LogAspect）：
```java
@Aspect
@Component
public class LogAspect
{
    public static final String[] EXCLUDE_PROPERTIES = { "password", "oldPassword", "newPassword" };

    @Before(value = "@annotation(controllerLog)")
    public void doBefore(JoinPoint joinPoint, Log controllerLog)
    {
        TIME_THREADLOCAL.set(System.currentTimeMillis());
    }

    @AfterReturning(pointcut = "@annotation(controllerLog)", returning = "jsonResult")
    public void doAfterReturning(JoinPoint joinPoint, Log controllerLog, Object jsonResult)
    {
        handleLog(joinPoint, controllerLog, null, jsonResult);
    }

    @AfterThrowing(value = "@annotation(controllerLog)", throwing = "e")
    public void doAfterThrowing(JoinPoint joinPoint, Log controllerLog, Exception e)
    {
        handleLog(joinPoint, controllerLog, e, null);
    }
}
```

**使用示例**：
```java
@Log(title = "用户管理", businessType = BusinessType.INSERT)
@PostMapping("/add")
public AjaxResult add(@RequestBody SysUser user) { ... }
```

**设计要点**：
- `EXCLUDE_PROPERTIES` 默认排除 password 等敏感字段
- 使用 `ThreadLocal` 计算方法执行耗时
- 异步保存日志（`AsyncManager.me().execute(AsyncFactory.recordOper(operLog))`），不影响主流程性能
- 参数最大长度限制 2000 字符

### 3.2 @DataScope -- 数据权限过滤

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/DataScope.java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface DataScope
{
    public String userAlias() default "";                    // 用户表别名
    public String deptAlias() default "";                    // 部门表别名
    public String userField() default "user_id";            // 用户字段名
    public String deptField() default "dept_id";            // 部门字段名
    public String permission() default "";                    // 权限字符
}
```

**切面处理**（DataScopeAspect）：
```java
@Before("@annotation(controllerDataScope)")
public void doBefore(JoinPoint point, DataScope controllerDataScope) throws Throwable
{
    clearDataScope(point);  // 先清空，防止注入
    handleDataScope(point, controllerDataScope);
}
```

**核心逻辑**：根据用户角色的数据权限范围，动态拼接 SQL 条件，注入到 `BaseEntity.params.dataScope` 中。

**使用示例**：
```java
@DataScope(deptAlias = "d", userAlias = "u")
public List<SysUser> selectUserList(SysUser user);
```

**数据权限级别**：
```
1 = 全部数据权限
2 = 自定义数据权限（通过 sys_role_dept 配置）
3 = 本部门数据权限
4 = 本部门及以下数据权限
5 = 仅本人数据权限
```

### 3.3 @DataSource -- 数据源切换

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/DataSource.java
@Target({ ElementType.METHOD, ElementType.TYPE })
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Inherited
public @interface DataSource
{
    public DataSourceType value() default DataSourceType.MASTER;
}
```

**切面处理**（DataSourceAspect）：
```java
@Aspect
@Order(1)  // 最高优先级
@Component
public class DataSourceAspect
{
    @Around("dsPointCut()")
    public Object around(ProceedingJoinPoint point) throws Throwable
    {
        DataSource dataSource = getDataSource(point);
        if (StringUtils.isNotNull(dataSource))
        {
            DynamicDataSourceContextHolder.setDataSourceType(dataSource.value().name());
        }
        try { return point.proceed(); }
        finally { DynamicDataSourceContextHolder.clearDataSourceType(); }
    }
}
```

**使用示例**：
```java
@DataSource(DataSourceType.SLAVE)  // 切换到从库
public List<SysUser> selectUserList(SysUser user) { ... }
```

**设计要点**：
- `@Order(1)` 确保在所有切面之前执行
- 方法注解优先于类注解
- `@Inherited` 允许子类继承

### 3.4 @RateLimiter -- 接口限流

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/RateLimiter.java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface RateLimiter
{
    public String key() default CacheConstants.RATE_LIMIT_KEY;  // 限流key前缀
    public int time() default 60;                                // 限流时间窗口(秒)
    public int count() default 100;                              // 时间窗口内最大请求数
    public LimitType limitType() default LimitType.DEFAULT;      // 限流类型
}
```

**切面处理**（RateLimiterAspect）：
```java
@Before("@annotation(rateLimiter)")
public void doBefore(JoinPoint point, RateLimiter rateLimiter) throws Throwable
{
    int time = rateLimiter.time();
    int count = rateLimiter.count();
    String combineKey = getCombineKey(rateLimiter, point);
    Long number = redisTemplate.execute(limitScript, keys, count, time);
    if (StringUtils.isNull(number) || number.intValue() > count)
    {
        throw new ServiceException("访问过于频繁，请稍候再试");
    }
}
```

**使用示例**：
```java
@RateLimiter(time = 10, count = 5)  // 10秒内最多5次请求
@GetMapping("/list")
public AjaxResult list() { ... }
```

**限流类型**：
- `DEFAULT`：全局限流（所有用户共享计数）
- `IP`：按 IP 限流（每个 IP 独立计数）

### 3.5 @RepeatSubmit -- 防重复提交

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/RepeatSubmit.java
@Inherited
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface RepeatSubmit
{
    public int interval() default 5000;  // 间隔时间(ms)
    public String message() default "不允许重复提交，请稍候再试";
}
```

**使用示例**：
```java
@RepeatSubmit(interval = 3000)  // 3秒内不允许重复提交
@PostMapping("/add")
public AjaxResult add(@RequestBody SysUser user) { ... }
```

### 3.6 @Excel -- Excel导出注解

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/Excel.java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface Excel
{
    public int sort() default Integer.MAX_VALUE;     // 排序
    public String name() default "";                  // 列名
    public String dateFormat() default "";             // 日期格式
    public String dictType() default "";              // 字典类型
    public String readConverterExp() default "";       // 读取转换表达式
    public double width() default 16;                  // 列宽
    public String defaultValue() default "";           // 默认值
    public boolean isExport() default true;           // 是否导出
    public ColumnType cellType() default ColumnType.STRING;  // 单元格类型
    public Type type() default Type.ALL;              // 字段类型（导入导出/仅导出/仅导入）
    // ... 更多属性
}
```

**使用示例**：
```java
public class SysUser extends BaseEntity
{
    @Excel(name = "用户编号", cellType = ColumnType.NUMERIC)
    private Long userId;

    @Excel(name = "用户名称")
    private String userName;

    @Excel(name = "部门名称", dictType = "sys_user_sex")
    private String sex;

    @Excel(name = "创建时间", dateFormat = "yyyy-MM-dd")
    private Date createTime;
}
```

### 3.7 @Anonymous -- 匿名访问

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/Anonymous.java
@Target({ ElementType.METHOD, ElementType.TYPE })
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface Anonymous
{
}
```

**设计要点**：
- 标记注解，无属性
- 可标注在方法或类上
- SecurityConfig 中通过 `PermitAllUrlProperties` 扫描所有标注了 `@Anonymous` 的接口，自动添加到白名单

### 3.8 @Sensitive -- 数据脱敏

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/annotation/Sensitive.java
@Retention(RetentionPolicy.RUNTIME)
@Target({ ElementType.FIELD, ElementType.METHOD })
@JacksonAnnotationsInside
@JsonSerialize(using = SensitiveJsonSerializer.class)
public @interface Sensitive
{
    DesensitizedType desensitizedType();
}
```

**使用示例**：
```java
public class SysUser extends BaseEntity
{
    @Sensitive(desensitizedType = DesensitizedType.PHONE)
    private String phonenumber;

    @Sensitive(desensitizedType = DesensitizedType.ID_CARD)
    private String idCard;
}
```

**脱敏类型**：
- `USERNAME`：姓名脱敏（张*明）
- `PASSWORD`：密码全部替换为 *
- `ID_CARD`：身份证中间10位替换
- `PHONE`：手机号中间4位替换（138****1234）
- `EMAIL`：邮箱脱敏（t****@example.com）
- `BANK_CARD`：银行卡号保留后4位

## 五、细节留神

1. **@Log 的 excludeParamNames 与 EXCLUDE_PROPERTIES 的关系**：LogAspect 会将两者合并，默认排除 password 等字段，注解中可以额外指定排除字段。

2. **@DataScope 的 SQL 注入风险**：`${params.dataScope}` 使用 `${}` 注入 SQL 片段，虽然内容由切面控制，但仍需注意安全性。

3. **@DataSource 的 @Order(1)**：确保数据源切换在 @DataScope 之前执行，否则数据权限查询可能使用错误的数据源。

4. **@RateLimiter 基于 Redis Lua 脚本**：限流使用 Redis 的原子操作保证准确性，但 Redis 不可用时会导致所有限流接口异常。

5. **@Excel 的 dictType 属性**：配合字典管理实现数据转换，如 `dictType = "sys_user_sex"` 会将 0/1 转换为 男/女。

6. **@Anonymous 的扫描机制**：通过 `PermitAllUrlProperties` 在启动时扫描所有 Controller，将标注了 `@Anonymous` 的接口添加到 Spring Security 白名单。

## 六、提问方向

1. **如果要新增一个 @OperationLock（分布式锁）注解，你会如何设计注解属性和切面处理逻辑？需要考虑哪些边界情况？**

2. **@DataScope 的 SQL 注入使用 `${}` 而非 `#{}`，虽然内容由切面控制，但如果 params Map 被恶意篡改，是否存在安全风险？你会如何加固？**

3. **@Log 注解使用异步方式保存日志，如果异步任务失败，日志会丢失。你会如何设计可靠的操作日志记录机制？**

4. **@RateLimiter 基于 Redis 实现限流，如果 Redis 集群出现网络分区，会产生什么问题？你会如何设计降级策略？**

5. **@Excel 注解功能非常丰富（30+属性），如果需要支持动态列（运行时决定导出哪些列），你会如何扩展？**

6. **@Anonymous 通过启动时扫描 Controller 来构建白名单，如果使用动态路由或 Feign 调用，这种机制是否还能正常工作？**

7. **@Sensitive 使用 Jackson 的 `@JsonSerialize` 实现脱敏，如果需要在日志中记录脱敏前的原始值，你会如何设计？**

8. **如果要将这些注解抽取为独立的 Starter 模块供其他项目复用，你会如何设计模块的自动配置和依赖管理？**
