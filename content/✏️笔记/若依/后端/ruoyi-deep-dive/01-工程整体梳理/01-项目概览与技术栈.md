# 01 - 项目概览与技术栈

## 一、项目介绍

**RuoYi-Vue（若依管理系统）** 是一套基于 Spring Boot 的轻量级后台管理系统，采用前后端分离架构。项目版本为 **3.9.2**，是目前国内 Java 后台管理系统中使用最广泛的开源脚手架之一。

### 核心定位

- **快速开发脚手架**：提供完整的用户管理、角色管理、菜单管理、部门管理等基础功能
- **前后端分离**：后端提供 RESTful API，前端通过 Vue2 + Element UI 构建交互界面
- **权限管控**：基于 Spring Security + JWT 实现细粒度的 RBAC 权限控制
- **开箱即用**：集成代码生成器，可一键生成前后端代码

### 源码位置

项目根目录 `pom.xml` 中的项目描述：

```xml
<!-- 根 pom.xml -->
<groupId>com.ruoyi</groupId>
<artifactId>ruoyi</artifactId>
<version>3.9.2</version>
<name>ruoyi</name>
<url>http://www.ruoyi.vip</url>
<description>若依管理系统</description>
```

## 三、版本选型分析

### 3.1 为什么选择 Spring Boot 4.0.3？

**源码依据**（根 `pom.xml`）：

```xml
<properties>
    <spring-boot.version>4.0.3</spring-boot.version>
    <java.version>17</java.version>
</properties>
```

**选型考量**：

1. **长期支持（LTS）**：Spring Boot 4.x 是基于 Spring Framework 7 的重大版本，对 JDK 17+ 有原生支持
2. **Jakarta EE 迁移**：Spring Boot 3.x+ 全面迁移到 Jakarta EE 命名空间（`javax.*` -> `jakarta.*`），本项目中的 `jakarta.servlet-api` 即是体现
3. **性能提升**：Spring Boot 4.x 在启动速度、内存占用方面有显著优化
4. **生态兼容**：Druid 提供了 `druid-spring-boot-4-starter` 适配包，MyBatis 提供 `mybatis-spring-boot-starter 4.0.1`，说明核心中间件已完成适配

**注意**：本项目使用的是 Spring Boot 4.0.3，而非常见的 2.x 或 3.x 版本，这是一个相对较新的版本选择。

### 3.2 为什么选择 JDK 17？

1. **LTS 版本**：JDK 17 是 Oracle 官方长期支持版本，维护周期至 2029 年
2. **语法增强**：支持 Records、Sealed Classes、Pattern Matching、Switch 表达式等新特性
3. **Spring Boot 4.x 要求**：Spring Boot 4.x 最低要求 JDK 17
4. **性能优化**：ZGC 垃圾收集器的改进、改进的空指针异常信息（Helpful NPE）

### 3.3 为什么选择 MyBatis 而非 JPA/Hibernate？

1. **SQL 可控性**：后台管理系统需要精确控制 SQL，便于优化复杂查询
2. **学习成本低**：国内 Java 开发者对 MyBatis 更熟悉
3. **XML 映射灵活**：通过 XML 映射文件可以灵活编写动态 SQL
4. **与 PageHelper 配合**：PageHelper 对 MyBatis 的分页支持非常成熟

### 4.2 请求处理流程

```
浏览器请求
  -> Vue Router 路由分发
  -> Axios 发送 HTTP 请求（携带 JWT Token）
  -> Spring Security 过滤器链（JWT 认证）
  -> Controller 层处理
  -> Service 层业务逻辑
  -> Mapper 层数据访问
  -> MySQL 数据库
  -> 返回 JSON 响应
```

## 五、快速启动步骤

### 5.1 环境准备

```bash
# 1. 安装 JDK 17
java -version  # 确认版本 >= 17

# 2. 安装 Maven
mvn -version

# 3. 安装 MySQL（建议 5.7+ / 8.0）
# 4. 安装 Redis
redis-server
```

### 5.2 数据库初始化

```sql
-- 创建数据库
CREATE DATABASE `ry-vue` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
-- 导入 SQL 脚本（项目 doc/sql 目录下）
```

### 5.3 后端启动

```bash
# 方式一：使用 bin 脚本
cd bin
run.bat

# 方式二：Maven 命令
mvn spring-boot:run -pl ruoyi-admin

# 方式三：IDE 中直接运行 RuoYiApplication.main()
```

### 5.4 前端启动

```bash
cd ruoyi-ui
npm install
npm run dev
```

## 七、细节留神

1. **Spring Boot 4.x 的 Jakarta 迁移**：项目中使用的是 `jakarta.servlet-api` 而非 `javax.servlet-api`，这是 Spring Boot 3.x+ 的标志性变化。如果看到旧版教程使用 `javax.*`，需要注意替换
2. **Druid 适配包名称**：使用的是 `druid-spring-boot-4-starter`（注意后缀是 `-4-starter`），而非旧版的 `druid-spring-boot-starter`，说明专门为 Spring Boot 4.x 做了适配
3. **JWT 版本较旧**：`jjwt 0.9.1` 是一个较老的版本，新项目建议升级到 `0.12.x` 系列
4. **POI 版本**：使用的是 `4.1.2`，而非最新的 5.x，注意 API 差异
5. **前端 Vue2**：当前 Vue 已发展到 Vue3，本项目仍使用 Vue2，如需升级需考虑 Element Plus 等替代方案

## 八、提问方向

以下问题可用于面试准备或技术讨论：

1. **"RuoYi-Vue 项目为什么选择 Spring Boot 4.0.3 + JDK 17 这个版本组合？与 Spring Boot 2.x 相比有哪些核心差异？"**

   > 参考思路：Jakarta EE 迁移、性能提升、JDK 17 LTS 支持等

2. **"项目中同时使用了 Jackson 和 FastJson2 两种 JSON 库，它们各自的职责是什么？是否存在冗余？"**

   > 参考思路：Jackson 用于 Spring MVC 默认序列化，FastJson2 用于特定场景（如 Redis 序列化），查看 `ruoyi-common/pom.xml` 中两者的引入

3. **"为什么选择 MyBatis 而非 Spring Data JPA？在后台管理系统场景下各自的优劣是什么？"**

   > 参考思路：SQL 可控性、动态 SQL、学习成本、国内生态

4. **"项目的 Token 有效期配置为 30 分钟，这个值是否合理？在生产环境中应该如何调整？"**

   > 参考思路：查看 `application.yml` 中 `token.expireTime` 配置，结合安全性和用户体验讨论

5. **"Springdoc 3.0.2 替代了传统的 Swagger 2，它们之间有哪些关键差异？为什么项目做了这个选择？"**

   > 参考思路：Springdoc 基于 OpenAPI 3 规范，Swagger 2 基于 OpenAPI 2（Swagger），Spring Boot 3.x+ 不再内置 Swagger 2 支持

6. **"如果要将项目从 JDK 17 升级到 JDK 21，需要关注哪些兼容性问题？"**

   > 参考思路：虚拟线程（Virtual Threads）、Record 类、Pattern Matching 的进一步改进

7. **"项目使用了内嵌 Tomcat，在生产环境中如何根据实际负载调整 Tomcat 参数？"**

   > 参考思路：查看 `application.yml` 中 `server.tomcat.threads.max`（800）和 `min-spare`（100）的配置
