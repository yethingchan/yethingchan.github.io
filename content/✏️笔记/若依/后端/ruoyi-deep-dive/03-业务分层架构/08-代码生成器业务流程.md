> 本文档深入剖析 RuoYi-Vue 代码生成器的完整业务流程，涵盖导入数据库表、读取表结构、配置生成参数、Velocity 模板渲染、生成代码和下载 ZIP 的全链路分析。

## 二、导入数据库表流程

### 2.1 流程图

```
前端 GET /tool/gen/db/list?tableName=sys
    → 查询数据库中所有表（未导入的）
    → 展示表列表供用户选择

前端 POST /tool/gen/importTable  Body: tables="sys_user,sys_role" & tplWebType="element-plus"
    │
    ▼
GenController.importTableSave(@RequestParam String tables, @RequestParam String tplWebType)
    → @PreAuthorize("@ss.hasPermi('tool:gen:import')")
    → @Log(title = "代码生成", businessType = BusinessType.IMPORT)
    │
    ├─ 1. Convert.toStrArray(tables) → String[] tableNames
    ├─ 2. genTableService.selectDbTableListByNames(tableNames)
    │     → 从 information_schema 查询表基本信息（表名、注释、引擎等）
    ├─ 3. genTableService.importGenTable(tableList, tplWebType, operName)
    │     │
    │     ▼
    │   GenTableServiceImpl.importGenTable(...)
    │     → @Transactional
    │     → for 循环每个表：
    │         ├─ GenUtils.initTable(table, operName)
    │         │   → 设置默认值（模块名、业务名、类名、包名等）
    │         ├─ genTableMapper.insertGenTable(table)
    │         │   → 插入 gen_table 表
    │         └─ genTableColumnMapper.selectDbTableColumnsByName(tableName)
    │             → 从 information_schema 查询列信息
    │             → for 循环每列：
    │                 ├─ GenUtils.initColumnField(column, table)
    │                 │   → 根据列类型推断 Java 类型、查询方式、表单类型等
    │                 └─ genTableColumnMapper.insertGenTableColumn(column)
    │                     → 插入 gen_table_column 表
    │
    └─ 4. return success()
```

### 2.2 关键源码引用

```java
// Controller 层
@PreAuthorize("@ss.hasPermi('tool:gen:import')")
@Log(title = "代码生成", businessType = BusinessType.IMPORT)
@PostMapping("/importTable")
public AjaxResult importTableSave(@RequestParam("tables") String tables,
        @RequestParam("tplWebType") String tplWebType) {
    String[] tableNames = Convert.toStrArray(tables);
    List<GenTable> tableList = genTableService.selectDbTableListByNames(tableNames);
    genTableService.importGenTable(tableList, tplWebType, SecurityUtils.getUsername());
    return success();
}

// Service 层 - 导入表
@Override
@Transactional
public void importGenTable(List<GenTable> tableList, String tplWebType, String operName) {
    try {
        for (GenTable table : tableList) {
            String tableName = table.getTableName();
            table.setTplWebType(tplWebType);
            GenUtils.initTable(table, operName);           // 初始化表信息
            int row = genTableMapper.insertGenTable(table);  // 保存表信息
            if (row > 0) {
                List<GenTableColumn> genTableColumns =
                    genTableColumnMapper.selectDbTableColumnsByName(tableName);  // 查询列信息
                for (GenTableColumn column : genTableColumns) {
                    GenUtils.initColumnField(column, table);  // 初始化列信息
                    genTableColumnMapper.insertGenTableColumn(column);  // 保存列信息
                }
            }
        }
    } catch (Exception e) {
        throw new ServiceException("导入失败：" + e.getMessage());
    }
}
```

### 4.2 关键源码引用

```java
// Service 层 - 预览代码
@Override
public Map<String, String> previewCode(Long tableId) {
    Map<String, String> dataMap = new LinkedHashMap<>();
    GenTable table = genTableMapper.selectGenTableById(tableId);
    setSubTable(table);
    setPkColumn(table);
    VelocityInitializer.initVelocity();

    VelocityContext context = VelocityUtils.prepareContext(table);
    List<String> templates = VelocityUtils.getTemplateList(table);
    for (String template : templates) {
        StringWriter sw = new StringWriter();
        Template tpl = Velocity.getTemplate(template, Constants.UTF8);
        tpl.merge(context, sw);
        dataMap.put(template, sw.toString());
    }
    return dataMap;
}
```

public static VelocityContext prepareContext(GenTable genTable) {
    VelocityContext velocityContext = new VelocityContext();
    velocityContext.put("tableName", genTable.getTableName());
    velocityContext.put("functionName", genTable.getFunctionName());
    velocityContext.put("ClassName", genTable.getClassName());       // 大驼峰
    velocityContext.put("className", StringUtils.uncapitalize(...));   // 小驼峰

    velocityContext.put("BusinessName", StringUtils.capitalize(...));
    velocityContext.put("businessName", genTable.getBusinessName());
    velocityContext.put("basePackage", getPackagePrefix(packageName));
    velocityContext.put("packageName", packageName);
    velocityContext.put("author", genTable.getFunctionAuthor());
    velocityContext.put("datetime", DateUtils.getDate());
    velocityContext.put("pkColumn", genTable.getPkColumn());
    velocityContext.put("columns", genTable.getColumns());
    velocityContext.put("table", genTable);
    velocityContext.put("permissionPrefix", getPermissionPrefix(moduleName, businessName));
    velocityContext.put("importList", getImportList(genTable));
    velocityContext.put("dicts", getDicts(genTable));

### 5.2 模板列表选择

```java
// 文件：VelocityUtils.java
public static List<String> getTemplateList(GenTable table) {
    String tplWebType = table.getTplWebType();
    String tplCategory = table.getTplCategory();

    List<String> templates = new ArrayList<String>();
    // 基础模板（所有类型都有）
    templates.add("vm/java/domain.java.vm");
    templates.add("vm/java/mapper.java.vm");
    templates.add("vm/java/service.java.vm");
    templates.add("vm/java/serviceImpl.java.vm");
    templates.add("vm/java/controller.java.vm");
    templates.add("vm/xml/mapper.xml.vm");
    templates.add("vm/sql/sql.vm");
    templates.add(apiTemplate);  // vm/js/api.js.vm 或 vm/ts/api.ts.vm

    // 根据模板类型添加
    if (TPL_CRUD.equals(tplCategory)) {
        templates.add(useWebType + "/index.vue.vm");
    } else if (TPL_TREE.equals(tplCategory)) {
        templates.add(useWebType + "/index-tree.vue.vm");
    } else if (TPL_SUB.equals(tplCategory)) {
        templates.add(useWebType + "/index.vue.vm");
        templates.add("vm/java/sub-domain.java.vm");
    }

    // 详情页
    if (isView) {
        templates.add(useWebType + "/view.vue.vm");
    }
    return templates;
}
```

## 十、细节留神

1. **代码生成器是独立的 Maven 模块**：`ruoyi-generator` 有自己的 Controller、Service、Mapper，不依赖 `ruoyi-system`，体现了模块隔离设计
2. **生成代码到项目路径需要配置允许覆盖**：`GenConfig.isAllowOverwrite()` 默认不允许，防止误操作覆盖已有代码
3. **Velocity 模板使用 `vm` 目录**：模板文件位于 `resources/vm/` 下，按类型分为 java/xml/vue/js/ts/sql 子目录
4. **前端类型支持多种**：支持 Element UI (vue2)、Element Plus (vue3)、Element Plus TypeScript 三种前端模板
5. **批量生成时 index-bak.ts 文件会合并**：多个表的 TypeScript 导出会合并到一个文件中，避免冲突
6. **同步数据库会保留用户配置**：已有的查询方式、字典类型等用户自定义配置不会被覆盖

## 十一、提问方向

1. **代码生成器使用 Velocity 模板引擎，而不是更流行的 FreeMarker 或 Thymeleaf。为什么选择 Velocity？Velocity 与 FreeMarker 在代码生成场景下各有什么优劣？**

2. **`GenTableServiceImpl.importGenTable` 方法使用 `@Transactional`，如果导入 10 张表，第 5 张表的列信息插入失败，前 4 张表的数据会回滚吗？这种"全有或全无"的设计在导入场景下是否合理？**
