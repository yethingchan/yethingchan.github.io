## 一、模板方法模式（Template Method Pattern）

### 1.1 场景一：RepeatSubmitInterceptor -> SameUrlDataInterceptor

**设计思路**：抽象拦截器定义了防重复提交的通用流程（检查注解 -> 判断重复 -> 返回错误），子类实现具体的重复判断逻辑。

```java
// 文件：ruoyi-framework/src/main/java/com/ruoyi/framework/interceptor/RepeatSubmitInterceptor.java
@Component
public abstract class RepeatSubmitInterceptor implements HandlerInterceptor
{
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception
    {
        if (handler instanceof HandlerMethod)
        {
            HandlerMethod handlerMethod = (HandlerMethod) handler;
            Method method = handlerMethod.getMethod();
            RepeatSubmit annotation = method.getAnnotation(RepeatSubmit.class);
            if (annotation != null)
            {
                // 模板方法：检查注解 -> 调用抽象方法 -> 处理结果
                if (this.isRepeatSubmit(request, annotation))
                {
                    AjaxResult ajaxResult = AjaxResult.error(annotation.message());
                    ServletUtils.renderString(response, JSON.toJSONString(ajaxResult));
                    return false;
                }
            }
            return true;
        }
        return true;
    }

    // 抽象方法：由子类实现具体的重复判断逻辑
    public abstract boolean isRepeatSubmit(HttpServletRequest request, RepeatSubmit annotation);
}
```

### 1.2 场景二：AbstractQuartzJob -> QuartzJobExecution / QuartzDisallowConcurrentExecution

**设计思路**：抽象任务定义了执行前记录时间 -> 执行任务 -> 执行后记录日志的模板，子类只需实现具体的任务调用。

```java
// 文件：ruoyi-quartz/src/main/java/com/ruoyi/quartz/util/AbstractQuartzJob.java
public abstract class AbstractQuartzJob implements Job
{
    private static ThreadLocal<Date> threadLocal = new ThreadLocal<>();

    @Override
    public void execute(JobExecutionContext context)
    {
        SysJob sysJob = new SysJob();
        BeanUtils.copyBeanProp(sysJob, context.getMergedJobDataMap().get(ScheduleConstants.TASK_PROPERTIES));
        try
        {
            before(context, sysJob);     // 模板步骤1：执行前准备
            if (sysJob != null)
            {
                doExecute(context, sysJob);  // 模板步骤2：执行任务（抽象方法）
            }
            after(context, sysJob, null);    // 模板步骤3：执行后记录日志
        }
        catch (Exception e)
        {
            after(context, sysJob, e);         // 异常时也记录日志
        }
    }

    protected void before(JobExecutionContext context, SysJob sysJob) {
        threadLocal.set(new Date());
    }

    protected void after(JobExecutionContext context, SysJob sysJob, Exception e) {
        // 统一的日志记录逻辑：记录任务名称、耗时、状态、异常信息
        Date startTime = threadLocal.get();
        threadLocal.remove();
        final SysJobLog sysJobLog = new SysJobLog();
        sysJobLog.setJobName(sysJob.getJobName());
        sysJobLog.setStartTime(startTime);
        sysJobLog.setEndTime(new Date());
        long runMs = sysJobLog.getEndTime().getTime() - sysJobLog.getStartTime().getTime();
        sysJobLog.setJobMessage(sysJobLog.getJobName() + " 总共耗时：" + runMs + "毫秒");
        if (e != null) {
            sysJobLog.setStatus(Constants.FAIL);
            sysJobLog.setExceptionInfo(StringUtils.substring(ExceptionUtil.getExceptionMessage(e), 0, 2000));
        } else {
            sysJobLog.setStatus(Constants.SUCCESS);
        }
        SpringUtils.getBean(ISysJobLogService.class).addJobLog(sysJobLog);
    }

    // 抽象方法：由子类实现
    protected abstract void doExecute(JobExecutionContext context, SysJob sysJob) throws Exception;
}
```

## 二、策略模式（Strategy Pattern）

### 2.1 场景一：DataScopeAspect 中根据 dataScope 拼接不同 SQL

```java
// 文件：ruoyi-framework/src/main/java/com/ruoyi/framework/aspectj/DataScopeAspect.java
for (SysRole role : user.getRoles())
{
    String dataScope = role.getDataScope();
    // 策略选择：根据不同的 dataScope 值执行不同的SQL拼接策略
    if (Constants.Dept.DATA_SCOPE_ALL.equals(dataScope))
    {
        // 策略1：全部数据权限，不拼接任何条件
        sqlString = new StringBuilder();
        conditions.add(dataScope);
        break;
    }
    else if (Constants.Dept.DATA_SCOPE_CUSTOM.equals(dataScope))
    {
        // 策略2：自定义数据权限，通过 sys_role_dept 表关联查询
        sqlString.append(StringUtils.format(
            " OR {}.{} IN ( SELECT dept_id FROM sys_role_dept WHERE role_id = {} ) ",
            deptAlias, deptField, role.getRoleId()));
    }
    else if (Constants.Dept.DATA_SCOPE_DEPT.equals(dataScope))
    {
        // 策略3：本部门数据权限
        sqlString.append(StringUtils.format(" OR {}.{} = {} ", deptAlias, deptField, user.getDeptId()));
    }
    else if (Constants.Dept.DATA_SCOPE_DEPT_AND_CHILD.equals(dataScope))
    {
        // 策略4：本部门及以下部门数据权限
        sqlString.append(StringUtils.format(
            " OR {}.{} IN ( SELECT dept_id FROM sys_dept WHERE dept_id = {} or find_in_set( {} , ancestors ) )",
            deptAlias, deptField, user.getDeptId(), user.getDeptId()));
    }
    else if (Constants.Dept.DATA_SCOPE_SELF.equals(dataScope))
    {
        // 策略5：仅本人数据权限
        sqlString.append(StringUtils.format(" OR {}.{} = {} ", userAlias, userField, user.getUserId()));
    }
}
```

```java
public class AsyncFactory
{
    // 静态工厂方法：创建登录信息记录任务
    public static TimerTask recordLogininfor(final String username, final String status,
            final String message, final Object... args)
    {
```

```java
public class AsyncManager
```

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/filter/XssHttpServletRequestWrapper.java
// 装饰器：包装 HttpServletRequest，增强参数获取方法（XSS过滤）
public class XssHttpServletRequestWrapper extends HttpServletRequestWrapper
{
    public XssHttpServletRequestWrapper(HttpServletRequest request) {
        super(request);  // 持有原始请求的引用
    }

    @Override
    public String[] getParameterValues(String name)
    {
        String[] values = super.getParameterValues(name);  // 调用原始方法
        if (values != null)
        {
            String[] escapesValues = new String[values.length];
            for (int i = 0; i < values.length; i++)
            {
                escapesValues[i] = EscapeUtil.clean(values[i]).trim();  // 增强：XSS过滤
            }
            return escapesValues;
        }
        return super.getParameterValues(name);
    }

    @Override
    public ServletInputStream getInputStream() throws IOException
    {
        if (!isJsonRequest()) { return super.getInputStream(); }
        String json = IOUtils.toString(super.getInputStream(), "utf-8");
        if (StringUtils.isEmpty(json)) { return super.getInputStream(); }
        json = EscapeUtil.clean(json).trim();  // 增强：JSON body XSS过滤
        byte[] jsonBytes = json.getBytes("utf-8");
        final ByteArrayInputStream bis = new ByteArrayInputStream(jsonBytes);
        return new ServletInputStream() { /* 返回过滤后的输入流 */ };
    }
}
```

```java
// 文件：ruoyi-framework/src/main/java/com/ruoyi/framework/aspectj/LogAspect.java
@Aspect
@Component
public class LogAspect
{
    // 观察正常返回结果
    @AfterReturning(pointcut = "@annotation(controllerLog)", returning = "jsonResult")
    public void doAfterReturning(JoinPoint joinPoint, Log controllerLog, Object jsonResult)

        handleLog(joinPoint, controllerLog, null, jsonResult);
    }

    public void doAfterThrowing(JoinPoint joinPoint, Log controllerLog, Exception e)
    {
        handleLog(joinPoint, controllerLog, e, null);
    }

    protected void handleLog(final JoinPoint joinPoint, Log controllerLog, final Exception e, Object jsonResult)
    {
        try
        {
            LoginUser loginUser = SecurityUtils.getLoginUser();
            SysOperLog operLog = new SysOperLog();
            operLog.setStatus(BusinessStatus.SUCCESS.ordinal());
            operLog.setOperIp(IpUtils.getIpAddr());
            operLog.setOperUrl(StringUtils.substring(ServletUtils.getRequest().getRequestURI(), 0, 255));
            if (e != null) {
                operLog.setStatus(BusinessStatus.FAIL.ordinal());
                operLog.setErrorMsg(StringUtils.substring(
                    Convert.toStr(e.getMessage(), ExceptionUtil.getExceptionMessage(e)), 0, 2000));
            }
            operLog.setMethod(joinPoint.getTarget().getClass().getName() + "." + joinPoint.getSignature().getName() + "()");
            operLog.setCostTime(System.currentTimeMillis() - TIME_THREADLOCAL.get());
            // 异步记录日志
            AsyncManager.me().execute(AsyncFactory.recordOper(operLog));
        }
        catch (Exception exp) {
            log.error("异常信息:{}", exp.getMessage());
        }
        finally {
            TIME_THREADLOCAL.remove();
        }
    }
}
```

```java
// 文件：ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java
@Bean
protected SecurityFilterChain filterChain(HttpSecurity httpSecurity) throws Exception
{
    return httpSecurity
        .csrf(csrf -> csrf.disable())
        .exceptionHandling(exception -> exception.authenticationEntryPoint(unauthorizedHandler))
        .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
```

### 8.1 场景一：Spring AOP 代理 -- 四大切面

### 8.2 场景二：JwtAuthenticationTokenFilter 代理认证信息

```java
// 文件：ruoyi-framework/src/main/java/com/ruoyi/framework/security/filter/JwtAuthenticationTokenFilter.java
@Component
public class JwtAuthenticationTokenFilter extends OncePerRequestFilter
{
    @Autowired
    private TokenService tokenService;

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException
    {
        LoginUser loginUser = tokenService.getLoginUser(request);
        if (StringUtils.isNotNull(loginUser) && StringUtils.isNull(SecurityUtils.getAuthentication()))
        {
            tokenService.verifyToken(loginUser);
            // 代理设置认证信息到 SecurityContext
            UsernamePasswordAuthenticationToken authenticationToken =
                new UsernamePasswordAuthenticationToken(loginUser, null, loginUser.getAuthorities());
            authenticationToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
            SecurityContextHolder.getContext().setAuthentication(authenticationToken);
        }
        chain.doFilter(request, response);
    }
}
```

### 10.1 场景一：LoginUser 适配 Spring Security UserDetails

```java
// 文件：ruoyi-common/src/main/java/com/ruoyi/common/core/domain/model/LoginUser.java
// LoginUser 实现了 Spring Security 的 UserDetails 接口
// 将系统内部的 SysUser 适配为 Spring Security 认证体系所需的 UserDetails
public class LoginUser implements UserDetails
{
    private Long userId;
    private Long deptId;
    private String token;
    private Long loginTime;
    private Long expireTime;
    private String ipaddr;
    private String loginLocation;
    private String browser;
    private String os;
    private Set<String> permissions;
    private SysUser user;  // 持有系统内部用户对象

    @JSONField(serialize = false)
    @Override
    public String getPassword() { return user.getPassword(); }

    @Override
    public String getUsername() { return user.getUserName(); }

    @Override
    public boolean isAccountNonExpired() { return true; }

    @Override
    public boolean isAccountNonLocked() { return true; }

    @Override
    public boolean isCredentialsNonExpired() { return true; }

    @Override
    public boolean isEnabled() { return true; }

    @Override
    @JSONField(serialize = false)
    public Collection<? extends GrantedAuthority> getAuthorities()
    {
        if (permissions == null || permissions.isEmpty()) {
            return Collections.emptyList();
        }
        return permissions.stream()
            .filter(Objects::nonNull)
            .map(SimpleGrantedAuthority::new)  // 将字符串权限适配为 GrantedAuthority
            .collect(Collectors.toList());
    }
}
```

## 细节留神

1. **模板方法模式中**，`AbstractQuartzJob` 使用 `ThreadLocal` 保存开始时间，这是因为在 Quartz 中多个任务可能在不同线程中执行，`ThreadLocal` 确保线程安全。
2. **策略模式中**，`DataScopeAspect` 的策略选择是通过 if-else 链实现的，如果新增数据权限类型需要修改切面代码。可以考虑使用策略模式+工厂进一步优化。
3. **工厂模式中**，`AsyncFactory` 的静态方法在调用时捕获了 `ServletUtils.getRequest()` 的引用，如果在异步线程中执行时请求已经结束，可能会出现问题。
4. **装饰器模式中**，`RepeatedlyRequestWrapper` 在构造时就缓存了整个请求体到内存中，对于大文件上传场景可能导致内存溢出。
5. **代理模式中**，`DataSourceAspect` 使用了 `@Order(1)` 确保最高优先级，因为数据源切换必须在其他切面（如数据权限）之前执行。
6. **适配器模式中**，`LoginUser` 的 `getAuthorities()` 方法每次调用都会创建新的 `SimpleGrantedAuthority` 对象，可以考虑缓存优化。
