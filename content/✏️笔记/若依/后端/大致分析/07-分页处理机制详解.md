# RuoYi-Vue 分页处理机制详解

## 一、分页概述

RuoYi-Vue基于 **PageHelper** 实现物理分页，通过简单的`startPage()`调用即可自动在SQL后添加LIMIT子句。

**核心特性**:
- 无侵入式分页（无需修改SQL）
- 自动COUNT查询
- SQL注入防护
- 支持排序
- 前后端参数自动映射

## 二、后端分页实现

### 2.1 标准分页流程

```java
@GetMapping("/list")
public TableDataInfo list(SysUser user) {
    startPage();                              // 步骤1：开启分页
    List<SysUser> list = userService.selectUserList(user);  // 步骤2：执行查询
    return getDataTable(list);                // 步骤3：返回分页结果
}
```

**三步走模式**:
1. `startPage()` - 从请求参数提取pageNum/pageSize，设置到PageHelper
2. 执行MyBatis查询 - PageHelper自动添加LIMIT
3. `getDataTable()` - 封装为TableDataInfo返回

### 2.2 核心类说明

#### PageUtils - 分页工具类

```java
public class PageUtils extends PageHelper {
    
    public static void startPage() {
        PageDomain pageDomain = TableSupport.buildPageRequest();
        Integer pageNum = pageDomain.getPageNum();
        Integer pageSize = pageDomain.getPageSize();
        String orderBy = SqlUtil.escapeOrderBySql(pageDomain.getOrderBy());
        Boolean reasonable = pageDomain.getReasonable();
        
        PageHelper.startPage(pageNum, pageSize, orderBy)
            .setReasonable(reasonable);
    }
}
```

#### TableDataInfo - 分页响应结构

```java
public class TableDataInfo implements Serializable {
    private long total;      // 总记录数
    private List<?> rows;    // 当前页数据
    private int code;        // 状态码
    private String msg;      // 消息
}
```

#### BaseController - 控制器基类

```java
public class BaseController {
    
    protected void startPage() {
        PageUtils.startPage();
    }
    
    protected TableDataInfo getDataTable(List<?> list) {
        TableDataInfo rspData = new TableDataInfo();
        rspData.setCode(HttpStatus.SUCCESS);
        rspData.setMsg("查询成功");
        rspData.setRows(list);
        rspData.setTotal(new PageInfo(list).getTotal());
        return rspData;
    }
}
```

### 2.3 分页参数传递

**前端请求**:
```
GET /system/user/list?pageNum=1&pageSize=10&userName=admin
```

**后端接收**:
```java
// ServletUtils自动从请求中提取

String orderByColumn = ServletUtils.getParameter("orderByColumn");
String isAsc = ServletUtils.getParameter("isAsc");
```

### 2.4 带排序的分页

**前端传参**:
```javascript
queryParams: {
  pageNum: 1,
  pageSize: 10,
  orderByColumn: "create_time",
  isAsc: "desc"
}
```

**后端自动处理**:
```java
@GetMapping("/list")
public TableDataInfo list(SysUser user) {
    startPage();  // 自动读取orderByColumn和isAsc
    List<SysUser> list = userService.selectUserList(user);
    return getDataTable(list);
}
```

**生成的SQL**:
```sql
SELECT * FROM sys_user 
WHERE del_flag = '0' 
ORDER BY create_time DESC 
LIMIT 0, 10
```

## 三、前端分页实现

### 3.1 Pagination组件

**文件**: `src/components/Pagination/index.vue`

```vue
<template>
  <el-pagination
    :current-page.sync="currentPage"
    :page-size.sync="pageSize"
    :total="total"
    :page-sizes="[10, 20, 30, 50]"
    layout="total, sizes, prev, pager, next, jumper"
    @size-change="handleSizeChange"
    @current-change="handleCurrentChange"
  />
</template>

<script>
export default {
  props: {
    total: { type: Number, required: true },
    page: { type: Number, default: 1 },
    limit: { type: Number, default: 10 }
  },
  methods: {
    handleSizeChange(val) {
      this.$emit('pagination', { page: 1, limit: val })
    },
    handleCurrentChange(val) {
      this.$emit('pagination', { page: val, limit: this.pageSize })
    }
  }
}
</script>
```

### 3.2 页面中使用

```vue
<template>
  <div>
    <!-- 数据表格 -->
    <el-table :data="userList">
      <el-table-column label="用户名" prop="userName" />
    </el-table>
    
    <!-- 分页组件 -->
    <pagination 
      v-show="total > 0"
      :total="total"
      :page.sync="queryParams.pageNum"
      :limit.sync="queryParams.pageSize"
      @pagination="getList"
    />
  </div>
</template>

<script>
import { listUser } from "@/api/system/user"

export default {
  data() {
    return {
      total: 0,
      userList: [],
      queryParams: {
        pageNum: 1,
        pageSize: 10,
        userName: null
      }
    }
  },
  created() {
    this.getList()
  },
  methods: {
    getList() {
      listUser(this.queryParams).then(response => {
        this.userList = response.rows
        this.total = response.total
      })
    },
    handleQuery() {
      this.queryParams.pageNum = 1  // 搜索时重置到第一页
      this.getList()
    }
  }
}
</script>
```

## 四、PageHelper工作原理

```
1. startPage(pageNum, pageSize)
   ↓ 将分页参数存入ThreadLocal
   
2. MyBatis执行查询
   ↓ PageHelper拦截器拦截SQL
   
3. 自动改写SQL
   ├─ 添加 SELECT COUNT(*) 获取总数
   └─ 原SQL后添加 LIMIT offset, pageSize
   
4. 返回分页结果
   ↓ PageInfo包装
   
5. 从PageInfo获取total
```

## 五、常见场景

### 5.1 仅排序不分页

```java
@GetMapping("/list")
public TableDataInfo list(SysUser user) {
    startOrderBy();  // 只设置排序
    List<SysUser> list = userService.selectUserList(user);
    return getDataTable(list);
}
```

### 5.2 导出全部数据（不分页）

```java
@PostMapping("/export")
public void export(HttpServletResponse response, SysUser user) {
    // 不调用startPage()，获取全部数据
    List<SysUser> list = userService.selectUserList(user);
    ExcelUtil<SysUser> util = new ExcelUtil<>(SysUser.class);
    util.exportExcel(response, list, "用户数据");
}
```

### 5.3 手动构建TableDataInfo

```java
@GetMapping("/list")
public TableDataInfo list() {
    List<SysUser> list = userService.selectAll();
    
    TableDataInfo dataInfo = new TableDataInfo();
    dataInfo.setRows(list);
    dataInfo.setTotal(list.size());
    return dataInfo;
}
```

## 六、配置与优化

### 6.1 application.yml配置

```yaml
pagehelper:
  helperDialect: mysql           # 数据库方言
  supportMethodsArguments: true  # 支持方法参数
  params: count=countSql         # count查询参数
```

### 6.2 分页合理化

```java
// 开启合理化
PageHelper.startPage(pageNum, pageSize).setReasonable(true);

// 效果：
// pageNum <= 0 → 查询第一页
// pageNum > pages → 查询最后一页
```

### 6.3 SQL注入防护

```java
// SqlUtil.escapeOrderBySql()
// 只允许：字母、数字、下划线、空格、逗号、小数点
public static final String SQL_PATTERN = "[a-zA-Z0-9_\\ \\,\\.]+";

if (!value.matches(SQL_PATTERN)) {
    throw new UtilException("参数不符合规范");
}
```
