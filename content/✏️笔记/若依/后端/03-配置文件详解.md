# RuoYi-Vue 配置文件详解

## 一、配置文件概览

RuoYi-Vue 使用 Spring Boot 的配置体系，主要配置文件位于 `ruoyi-admin/src/main/resources/` 目录：

```
resources/
├── application.yml              # 主配置文件（通用配置）
├── application-druid.yml        # 数据源配置（Druid连接池）
├── mybatis/mybatis-config.xml   # MyBatis全局配置
├── logback.xml                  # 日志框架配置
├── banner.txt                   # 启动Banner
└── i18n/                        # 国际化资源文件
    └── messages.properties
```

### 2.2 配置项详细说明

#### (1) 项目配置 (ruoyi)

```yaml
ruoyi:
  name: RuoYi                      # 项目名称，显示在页面标题
  version: 3.9.2                   # 版本号
  copyrightYear: 2026              # 版权年份
  profile: D:/ruoyi/uploadPath     # 文件上传根路径
  addressEnabled: false            # 是否启用IP地址查询（需要第三方API）
  captchaType: math                # 验证码类型：math=数学计算, char=字符
```

**profile 配置说明**:
- Windows: `D:/ruoyi/uploadPath` 或 `C:/ruoyi/uploadPath`
- Linux: `/home/ruoyi/uploadPath` 或 `/opt/ruoyi/uploadPath`
- 所有上传的文件（头像、Excel等）都存储在此目录下

**captchaType 配置**:
- `math`: 数学计算验证码，如 "1+2=?"，答案 "3"
- `char`: 字符验证码，如 "ABCD"

#### (2) 服务器配置 (server)

```yaml
server:
  port: 8080                       # HTTP端口号
  servlet:
    context-path: /                # 应用上下文路径
  tomcat:
    uri-encoding: UTF-8            # URI编码，防止中文乱码
    accept-count: 1000             # 请求队列最大长度
    threads:
      max: 800                     # 最大工作线程数
      min-spare: 100               # 最小空闲线程数
```

**端口修改**:
- 如果8080端口被占用，可改为其他端口如 8888
- 前端需同步修改 `.env.development` 中的 `VUE_APP_BASE_API`

**线程池调优**:
- `max`: 根据CPU核心数和业务类型调整
  - CPU密集型：CPU核心数 + 1
  - IO密集型：CPU核心数 * 2
- `min-spare`: 保持一定数量的空闲线程，避免频繁创建销毁

#### (3) 用户密码配置 (user.password)

```yaml
user:
  password:
    maxRetryCount: 5               # 密码最大错误次数
    lockTime: 10                   # 锁定时间（分钟）
```

**工作机制**:
1. 用户连续输错密码5次后，账号被锁定10分钟
2. 锁定期间无法登录，即使输入正确密码
3. 10分钟后自动解锁，错误计数清零
4. 存储在Redis中，Key格式：`pwd_err_cnt:{username}`

#### (4) Redis配置 (spring.data.redis)

```yaml
spring:
  data:
    redis:
      host: localhost              # Redis服务器地址
      port: 6379                   # Redis端口
      database: 0                  # 数据库索引（0-15）
      password:                    # Redis密码（如果有）
      timeout: 10s                 # 连接超时时间
      lettuce:
        pool:
          min-idle: 0              # 最小空闲连接
          max-idle: 8              # 最大空闲连接
          max-active: 8            # 最大活跃连接
          max-wait: -1ms           # 最大等待时间（-1表示无限制）
```

**Redis用途**:
- 存储登录Token（Key: `login_tokens:{uuid}`）
- 存储验证码（Key: `captcha_codes:{uuid}`）
- 缓存字典数据（Key: `sys_dict:{dictType}`）
- 缓存参数配置（Key: `sys_config:{configKey}`）
- 密码错误计数（Key: `pwd_err_cnt:{username}`）

**连接池配置建议**:
- 单机应用：`max-active: 8` 足够
- 高并发场景：根据QPS调整，公式：`max-active = QPS * 平均响应时间`

#### (5) Token配置

```yaml
token:
  header: Authorization            # Token在请求头中的名称
  secret: abcdefghijklmnopqrstuvwxyz  # JWT签名密钥
  expireTime: 30                   # Token有效期（分钟）
```

**header配置**:
- 前端发送请求时携带：`Authorization: Bearer {token}`
- 后端从请求头读取并解析

**secret配置**:
- **生产环境必须修改**，使用随机字符串
- 建议使用至少32位复杂字符串
- 生成方式：`openssl rand -base64 32`

**expireTime配置**:
- 默认30分钟，可根据安全需求调整
- 实际实现中有自动续期机制（剩余20分钟内访问会自动刷新）

#### (6) MyBatis配置

```yaml
mybatis:
  typeAliasesPackage: com.ruoyi.**.domain    # 实体类包扫描
  mapperLocations: classpath*:mapper/**/*Mapper.xml  # Mapper XML位置
  configLocation: classpath:mybatis/mybatis-config.xml  # MyBatis配置文件
```

**typeAliasesPackage**:
- 支持通配符 `**` 匹配多级目录
- 配置后XML中可直接使用类名，无需写全路径
- 例如：`resultMap type="SysUser"` 而非 `com.ruoyi.system.domain.SysUser`

**mapperLocations**:
- `classpath*:` 表示扫描所有jar包中的mapper文件
- `mapper/**/*Mapper.xml` 匹配任意子目录下的Mapper文件

#### (7) PageHelper分页配置

```yaml
pagehelper:
  helperDialect: mysql             # 数据库方言
  supportMethodsArguments: true    # 支持方法参数传递分页
  params: count=countSql           # 自定义count查询参数
```

**helperDialect可选值**:
- `mysql`: MySQL数据库
- `oracle`: Oracle数据库
- `postgresql`: PostgreSQL数据库
- `sqlserver`: SQL Server数据库

#### (8) Swagger文档配置 (springdoc)

```yaml
springdoc:
  api-docs:
    path: /v3/api-docs             # OpenAPI JSON地址
  swagger-ui:
    path: /swagger-ui.html         # Swagger UI地址
  info:
    title: 若依系统接口文档
    description: 若依系统接口描述
    version: 3.9.2
  packages-to-scan: com.ruoyi.web.controller  # 扫描的Controller包
```

**访问地址**:
- Swagger UI: http://localhost:8080/swagger-ui.html
- API Docs JSON: http://localhost:8080/v3/api-docs

**生产环境建议禁用**:
```yaml
springdoc:
  api-docs:
    enabled: false
  swagger-ui:
    enabled: false
```

#### (9) XSS防护配置

```yaml
xss:
  enabled: true                    # 是否启用XSS过滤
  excludes: /system/notice         # 排除的URL（富文本编辑器需要HTML）
  urlPatterns: /system/*,/monitor/*,/tool/*  # 需要过滤的URL模式
```

**XSS攻击示例**:
```html
<!-- 恶意脚本注入 -->
<script>alert('XSS')</script>
<img src=x onerror=alert('XSS')>
```

**过滤效果**:
- `<script>` → `&lt;script&gt;`
- 特殊字符被转义，防止脚本执行

**excludes配置**:
- 通知公告需要保存HTML格式，所以排除过滤
- 其他接口正常过滤

### 3.2 配置项详细说明

#### (1) 主库数据源 (master)

```yaml
master:
  url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
  username: root
  password: password
```

**URL参数解释**:
- `useUnicode=true`: 使用Unicode字符集
- `characterEncoding=utf8`: 字符编码为UTF-8
- `zeroDateTimeBehavior=convertToNull`: 零日期转换为NULL（MySQL的 `0000-00-00` 问题）
- `useSSL=true`: 启用SSL加密连接
- `serverTimezone=GMT%2B8`: 服务器时区为东八区（北京时间）

**修改步骤**:
1. 修改 `localhost` 为实际数据库服务器IP
2. 修改 `ry-vue` 为实际数据库名
3. 修改 `username` 和 `password` 为实际账号密码

#### (2) 从库数据源 (slave)

```yaml
slave:
  enabled: false                   # 默认关闭
  url: 
  username: 
  password: 
```

**读写分离架构**:
```
应用 → Druid → 写操作 → 主库 (Master)
              → 读操作 → 从库 (Slave)
```

**启用从库步骤**:
1. 设置 `enabled: true`
2. 配置从库URL、用户名、密码
3. 代码中使用 `@DataSource(DataSourceType.SLAVE)` 注解切换数据源

**使用示例**:
```java
@Service
public class SysUserServiceImpl implements ISysUserService {
    
    // 默认使用主库
    @Transactional
    public int insertUser(SysUser user) {
        return userMapper.insertUser(user);
    }
    
    // 显式指定从库（只读操作）
    @DataSource(DataSourceType.SLAVE)
    public List<SysUser> selectUserList(SysUser user) {
        return userMapper.selectUserList(user);
    }
}
```

#### (3) 连接池配置

```yaml
initialSize: 5                     # 初始连接数
minIdle: 10                        # 最小空闲连接
maxActive: 20                      # 最大活跃连接
maxWait: 60000                     # 获取连接最大等待时间（毫秒）
```

**连接池工作原理**:
```
应用启动 → 创建5个初始连接 → 放入连接池
    ↓
用户请求 → 从池中获取连接 → 执行SQL → 归还连接
    ↓
连接不足 → 创建新连接（最多20个）
    ↓
空闲过多 → 回收连接（保持最少10个）
```

**参数调优建议**:

| 场景 | initialSize | minIdle | maxActive |
|------|-------------|---------|-----------|
| 开发环境 | 1 | 1 | 5 |
| 小型应用 | 5 | 10 | 20 |
| 中型应用 | 10 | 20 | 50 |
| 大型应用 | 20 | 50 | 100+ |

**计算公式**:
- `maxActive = (QPS * 平均响应时间) + 缓冲余量`
- 例如：QPS=1000，响应时间=10ms → maxActive ≈ 10-20

#### (4) 连接健康检查

```yaml
timeBetweenEvictionRunsMillis: 60000       # 检测间隔（60秒）
minEvictableIdleTimeMillis: 300000         # 最小空闲时间（5分钟）
maxEvictableIdleTimeMillis: 900000         # 最大空闲时间（15分钟）
validationQuery: SELECT 1 FROM DUAL        # 检测SQL
testWhileIdle: true                        # 空闲时检测
testOnBorrow: false                        # 借出时不检测
testOnReturn: false                        # 归还时不检测
```

**检测策略**:
- `testWhileIdle=true`: 定时检测空闲连接，性能最优
- `testOnBorrow=false`: 借出时不检测，避免每次请求都执行检测SQL
- `validationQuery`: 简单的SELECT语句，快速判断连接是否有效

#### (5) Druid监控配置

```yaml
statViewServlet:
  enabled: true                    # 启用监控页面
  allow:                           # IP白名单（空表示允许所有）
  url-pattern: /druid/*            # 监控页面路径
  login-username: ruoyi            # 登录用户名
  login-password: 123456           # 登录密码
```

**监控页面功能**:
- 数据源监控：连接池使用情况
- SQL监控：执行次数、耗时、慢SQL
- URL监控：接口访问统计
- Session监控：在线用户
- Spring监控：Bean调用关系

**访问地址**: http://localhost:8080/druid/login.html

**生产环境安全配置**:
```yaml
statViewServlet:
  enabled: true
  allow: 127.0.0.1,192.168.1.100  # 只允许特定IP访问
  login-username: admin            # 修改默认用户名
  login-password: 强密码            # 使用强密码
```

#### (6) 慢SQL监控

```yaml
filter:
  stat:
    enabled: true
    log-slow-sql: true             # 记录慢SQL
    slow-sql-millis: 1000          # 慢SQL阈值（1秒）
    merge-sql: true                # 合并相同SQL
```

**慢SQL日志示例**:
```
2024-01-01 12:00:00 [slow sql] [1234ms] select * from sys_user where ...
```

**优化建议**:
- 开发环境设置为 100ms，便于发现性能问题
- 生产环境设置为 1000ms，避免日志过多
- 定期查看Druid监控页面，优化慢SQL

## 四、mybatis-config.xml MyBatis配置

**文件位置**: `ruoyi-admin/src/main/resources/mybatis/mybatis-config.xml`

### 4.1 配置内容

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
"http://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
    <!-- 全局参数 -->
    <settings>
        <!-- 使全局的映射器启用或禁用缓存 -->
        <setting name="cacheEnabled"             value="true"   />
        <!-- 允许JDBC支持自动生成主键 -->
        <setting name="useGeneratedKeys"         value="true"   />
        <!-- 配置默认的执行器 -->
        <setting name="defaultExecutorType"      value="SIMPLE" />
        <!-- 指定MyBatis所用日志的具体实现 -->
        <setting name="logImpl"                  value="SLF4J"  />
        <!-- 使用驼峰命名法转换字段 -->
        <!-- <setting name="mapUnderscoreToCamelCase" value="true"/> -->
    </settings>
</configuration>
```

### 4.2 配置项说明

#### (1) cacheEnabled - 二级缓存

```xml
<setting name="cacheEnabled" value="true" />
```

**作用**: 启用MyBatis二级缓存（跨Session缓存）

**注意事项**:
- RuoYi实际未使用MyBatis二级缓存，而是使用Redis
- 如需启用，需在Mapper XML中添加 `<cache/>` 标签

#### (2) useGeneratedKeys - 自动生成主键

```xml
<setting name="useGeneratedKeys" value="true" />
```

**作用**: 允许JDBC自动生成主键（自增ID）

**使用示例**:
```xml
<insert id="insertUser" useGeneratedKeys="true" keyProperty="userId">
    insert into sys_user (...) values (...)
</insert>
```

插入后，`user.getUserId()` 会自动赋值为生成的ID。

#### (3) defaultExecutorType - 执行器类型

```xml
<setting name="defaultExecutorType" value="SIMPLE" />
```

**可选值**:
- `SIMPLE`: 普通执行器，每次执行创建新Statement（默认）
- `REUSE`: 复用执行器，重用Statement
- `BATCH`: 批处理执行器，适合批量操作

**批量操作示例**:
```java
// 使用BATCH执行器
SqlSession session = sqlSessionFactory.openSession(ExecutorType.BATCH);
for (SysUser user : userList) {
    userMapper.insertUser(user);
}
session.commit();
```

#### (4) logImpl - 日志实现

```xml
<setting name="logImpl" value="SLF4J" />
```

**作用**: 使用SLF4J输出MyBatis日志

**日志级别配置** (application.yml):
```yaml
logging:
  level:
```

## 五、logback.xml 日志配置

**文件位置**: `ruoyi-admin/src/main/resources/logback.xml`

### 5.1 配置内容

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <!-- 日志存放路径 -->
    <property name="log.path" value="/home/ruoyi/logs" />
    <!-- 日志输出格式 -->
    <property name="log.pattern" value="%d{HH:mm:ss.SSS} [%thread] %-5level %logger{20} - [%method,%line] - %msg%n" />

    <!-- 控制台输出 -->
    <appender name="console" class="ch.qos.logback.core.ConsoleAppender">
        <encoder>
            <pattern>${log.pattern}</pattern>
        </encoder>
    </appender>

    <!-- 系统日志输出 -->
    <appender name="file_info" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <file>${log.path}/sys-info.log</file>
        <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
            <fileNamePattern>${log.path}/sys-info.%d{yyyy-MM-dd}.log</fileNamePattern>
            <maxHistory>60</maxHistory>
        </rollingPolicy>
        <encoder>
            <pattern>${log.pattern}</pattern>
        </encoder>
        <filter class="ch.qos.logback.classic.filter.LevelFilter">
            <level>INFO</level>
            <onMatch>ACCEPT</onMatch>
            <onMismatch>DENY</onMismatch>
        </filter>
    </appender>

    <appender name="file_error" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <file>${log.path}/sys-error.log</file>
        <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
            <fileNamePattern>${log.path}/sys-error.%d{yyyy-MM-dd}.log</fileNamePattern>
            <maxHistory>60</maxHistory>
        </rollingPolicy>
        <encoder>
            <pattern>${log.pattern}</pattern>
        </encoder>
        <filter class="ch.qos.logback.classic.filter.LevelFilter">
            <level>ERROR</level>
            <onMatch>ACCEPT</onMatch>
            <onMismatch>DENY</onMismatch>
        </filter>
    </appender>

    <!-- Spring日志级别控制  -->
    <logger name="org.springframework" level="warn" />

    <root level="info">
        <appender-ref ref="console" />
    </root>

    <!-- 系统模块日志级别控制  -->
    <logger name="com.ruoyi" level="info" />
    <!-- 减少nacos心跳日志 -->
    <logger name="com.alibaba.nacos" level="error" />
</configuration>
```

### 5.2 配置说明

#### (1) 日志输出格式

```
%d{HH:mm:ss.SSS} [%thread] %-5level %logger{20} - [%method,%line] - %msg%n
```

**格式解释**:
- `%d{HH:mm:ss.SSS}`: 时间（时分秒.毫秒）
- `[%thread]`: 线程名
- `%-5level`: 日志级别（左对齐5字符）
- `%logger{20}`: Logger名称（最长20字符）
- `[%method,%line]`: 方法名和行号
- `%msg`: 日志消息
- `%n`: 换行

**输出示例**:
```
12:00:00.123 [http-nio-8080-exec-1] INFO  c.r.w.c.s.SysUserController - [list,50] - 查询用户列表
```

#### (2) 滚动策略

```xml
<rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
    <fileNamePattern>${log.path}/sys-info.%d{yyyy-MM-dd}.log</fileNamePattern>
    <maxHistory>60</maxHistory>
</rollingPolicy>
```

**作用**:
- 按天分割日志文件
- 保留最近60天的日志
- 文件名格式：`sys-info.2024-01-01.log`

#### (3) 日志级别过滤

```xml
<filter class="ch.qos.logback.classic.filter.LevelFilter">
    <level>INFO</level>
    <onMatch>ACCEPT</onMatch>
    <onMismatch>DENY</onMismatch>
</filter>
```

**日志级别** (从低到高):
- TRACE < DEBUG < INFO < WARN < ERROR

**过滤规则**:
- `file_info`: 只记录INFO级别日志
- `file_error`: 只记录ERROR级别日志

## 七、配置最佳实践

### 7.1 多环境配置

**推荐方案**: 使用Spring Profile

```yaml
# application.yml (通用配置)
spring:
  profiles:
    active: @profiles.active@  # Maven占位符

---
# application-dev.yml (开发环境)
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://localhost:3306/ry-vue?...
        username: root
        password: root

---
# application-prod.yml (生产环境)
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://prod-server:3306/ry-vue?...
        username: prod_user
        password: 强密码
```

**Maven配置** (pom.xml):
```xml
<profiles>
    <profile>
        <id>dev</id>
        <properties>
            <profiles.active>dev</profiles.active>
        </properties>
        <activation>
            <activeByDefault>true</activeByDefault>
        </activation>
    </profile>
    <profile>
        <id>prod</id>
        <properties>
            <profiles.active>prod</profiles.active>
        </properties>
    </profile>
</profiles>
```

**打包命令**:
```bash
# 开发环境
mvn package -P dev

# 生产环境
mvn package -P prod
```

### 7.2 敏感信息保护

**不要将密码提交到Git**:

1. 使用环境变量
```yaml
spring:
  datasource:
    druid:
      master:
        username: ${DB_USERNAME:root}
        password: ${DB_PASSWORD:password}
```

2. 使用配置中心（Nacos/Apollo）

3. 使用Jasypt加密
```yaml
spring:
  datasource:
    password: ENC(加密后的密码)
```

Spring Boot配置优先级（从高到低）:

8. jar包外部的application.yml

## 八、常见问题

### Q1: 如何修改数据库连接？

**A**: 编辑 `application-druid.yml`，修改master节点的url、username、password

### Q2: Redis连接失败怎么办？

**A**: 
1. 确认Redis服务已启动
2. 检查 `application.yml` 中的host和port配置
3. 测试连接：`redis-cli -h localhost -p 6379 ping`

### Q3: 如何查看执行的SQL语句？

**A**: 在 `application.yml` 中配置：
```yaml
logging:
  level:
    com.ruoyi.system.mapper: debug
```

### Q4: 如何禁用Swagger？

**A**: 在 `application.yml` 中添加：
```yaml
springdoc:
  api-docs:
    enabled: false
```

### Q5: 文件上传路径在哪配置？

**A**: 修改 `application.yml` 中的 `ruoyi.profile`
