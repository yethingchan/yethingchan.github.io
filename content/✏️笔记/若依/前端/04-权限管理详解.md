# RuoYi-Vue3 权限管理详解（重点）

## 一、权限管理概述

RuoYi-Vue3 实现了完整的 RBAC（基于角色的访问控制）权限模型，包括：

1. **用户管理**：管理系统用户
2. **角色管理**：定义角色并分配权限
3. **菜单管理**：配置系统菜单和按钮权限
4. **部门管理**：组织架构管理

权限控制分为三个层级：
- **路由级**：控制页面访问权限
- **菜单级**：控制菜单显示
- **按钮级**：控制按钮/操作权限

### 3.2 路由守卫详解

**文件位置**：`src/permission.js`

```javascript
import router from './router'
import { getToken } from '@/utils/auth'
import useUserStore from '@/store/modules/user'
import usePermissionStore from '@/store/modules/permission'

// 白名单路由（无需登录）
const whiteList = ['/login', '/register']

router.beforeEach(async (to, from) => {
  NProgress.start()  // 开启进度条
  
  if (getToken()) {
    // ========== 已登录 ==========
    if (to.path === '/login') {
      // 已登录时访问登录页，重定向到首页
      return { path: '/' }
    }
    
    if (useUserStore().roles.length === 0) {
      // 角色信息为空，需要获取用户信息
      try {
        // 1. 获取用户信息
        await useUserStore().getInfo()
        
        // 2. 生成动态路由
        const accessRoutes = await usePermissionStore().generateRoutes()
        
        // 3. 动态添加路由
        accessRoutes.forEach(route => {
          router.addRoute(route)
        })
        
        // 4. 重新导航（确保动态路由已注册）
        return { ...to, replace: true }
      } catch (err) {
        // 获取失败，退出登录
        await useUserStore().logOut()
        return { path: '/' }
      }
    }
    return true
  } else {
    // ========== 未登录 ==========
    if (whiteList.includes(to.path)) {
      // 白名单路由，直接进入
      return true
    }
    // 其他路由，重定向到登录页
    return `/login?redirect=${to.fullPath}`
  }
})
```

getInfo() {

      this.nickName = user.nickName

    })

generateRoutes() {
  return new Promise(resolve => {
    // 1. 从后端获取路由数据
    getRouters().then(res => {
      const sdata = JSON.parse(JSON.stringify(res.data))
      const rdata = JSON.parse(JSON.stringify(res.data))
      
      // 2. 转换为组件对象
      const sidebarRoutes = filterAsyncRouter(sdata)
      const rewriteRoutes = filterAsyncRouter(rdata, false, true)
      
      // 3. 处理动态路由权限
      const asyncRoutes = filterDynamicRoutes(dynamicRoutes)
      asyncRoutes.forEach(route => { router.addRoute(route) })
      
      // 4. 保存路由状态
      this.setRoutes(rewriteRoutes)
      this.setSidebarRouters(constantRoutes.concat(sidebarRoutes))
      
      resolve(rewriteRoutes)
    })
  })

### 5.3 路由转换函数

```javascript
// 将后端路由字符串转换为组件对象
function filterAsyncRouter(asyncRouterMap) {
  return asyncRouterMap.filter(route => {
    if (route.component) {
      // 特殊组件处理
      if (route.component === 'Layout') {
        route.component = Layout
      } else if (route.component === 'ParentView') {
        route.component = ParentView
      } else if (route.component === 'InnerLink') {
        route.component = InnerLink
      } else {
        // 动态加载组件
        route.component = loadView(route.component)
      }
    }
    
    // 递归处理子路由
    if (route.children && route.children.length) {
      route.children = filterAsyncRouter(route.children)
    }
    return true
  })
}

// 动态加载视图组件
export const loadView = (view) => {
  // 匹配 views 目录下所有 .vue 文件
  const modules = import.meta.glob('./../../views/**/*.vue')
  
  for (const path in modules) {
    const dir = path.split('views/')[1].split('.vue')[0]
    if (dir === view) {
      return () => modules[path]()
    }
  }
}
```

## 六、权限指令

### 6.1 v-hasPermi 权限指令

**文件位置**：`src/directive/permission/hasPermi.js`

```javascript
import useUserStore from '@/store/modules/user'

export default {
  mounted(el, binding, vnode) {
    const { value } = binding
    const all_permission = "*:*:*"  // 超级权限
    const permissions = useUserStore().permissions
    
    if (value && value instanceof Array && value.length > 0) {
      const permissionFlag = value
      
      // 检查是否拥有权限
      const hasPermissions = permissions.some(permission => {
        return all_permission === permission || permissionFlag.includes(permission)
      })
      
      // 无权限则移除元素
      if (!hasPermissions) {
        el.parentNode && el.parentNode.removeChild(el)
      }
    } else {
      throw new Error(`请设置操作权限标签值`)
    }
  }
}
```

**使用方式**：
```vue
<!-- 单个权限 -->
<el-button v-hasPermi="['system:user:add']">新增</el-button>

<!-- 多个权限（满足其一即可） -->
<el-button v-hasPermi="['system:user:add', 'system:user:edit']">操作</el-button>
```

## 七、权限验证插件

**文件位置**：`src/plugins/auth.js`

```javascript
import useUserStore from '@/store/modules/user'

// 验证权限
function authPermission(permission) {
  const all_permission = "*:*:*"
  const permissions = useUserStore().permissions
  
  if (permission && permission.length > 0) {
    return permissions.some(v => {
      return all_permission === v || v === permission
    })
  }
  return false
}

// 验证角色
function authRole(role) {
  const super_admin = "admin"
  const roles = useUserStore().roles
  
  if (role && role.length > 0) {
    return roles.some(v => {
      return super_admin === v || v === role
    })
  }
  return false
}

export default {
  // 验证用户是否具备某权限
  hasPermi(permission) {
    return authPermission(permission)
  },
  
  // 验证用户是否含有指定权限（只需包含其中一个）
  hasPermiOr(permissions) {
    return permissions.some(item => authPermission(item))
  },
  
  // 验证用户是否含有指定权限（必须全部拥有）
  hasPermiAnd(permissions) {
    return permissions.every(item => authPermission(item))
  },
  
  // 验证用户是否具备某角色
  hasRole(role) {
    return authRole(role)
  },
  
  // 验证用户是否含有指定角色（只需包含其中一个）
  hasRoleOr(roles) {
    return roles.some(item => authRole(item))
  },
  
  // 验证用户是否含有指定角色（必须全部拥有）
  hasRoleAnd(roles) {
    return roles.every(item => authRole(item))
  }
}
```

**使用方式**：
```javascript
// 在组件中使用
const { proxy } = getCurrentInstance()

// 验证单个权限
if (proxy.$auth.hasPermi('system:user:add')) {
  // 有权限
}

// 验证多个权限（满足其一）
if (proxy.$auth.hasPermiOr(['system:user:add', 'system:user:edit'])) {
  // 有权限
}

// 验证多个权限（必须全部满足）
if (proxy.$auth.hasPermiAnd(['system:user:add', 'system:user:edit'])) {
  // 有权限
}
```

## 十一、权限管理最佳实践

### 11.1 权限命名规范

```
模块:资源:操作

示例：
- system:user:list     系统模块-用户-查询
- system:user:add      系统模块-用户-新增
- system:user:edit     系统模块-用户-修改
- system:user:remove   系统模块-用户-删除
- system:user:export   系统模块-用户-导出
```

### 11.2 权限控制原则

1. **最小权限原则**：只授予必要的权限
2. **职责分离**：不同角色赋予不同权限
3. **默认拒绝**：没有明确授权的默认拒绝访问
4. **定期审计**：定期检查权限分配是否合理

### 11.3 常见问题解决

**问题1**：刷新页面后权限丢失

**原因**：Vuex/Pinia 状态丢失

**解决**：在路由守卫中重新获取用户信息

**问题2**：动态路由不生效

**原因**：路由未正确注册

**解决**：使用 `router.addRoute()` 后需要 `return { ...to, replace: true }`
