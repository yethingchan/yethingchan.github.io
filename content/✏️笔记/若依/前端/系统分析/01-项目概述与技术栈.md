# RuoYi-Vue3 项目概述与技术栈

## 一、项目简介

RuoYi-Vue3 是一个基于 Vue3 + Element Plus 的后台管理系统，是若依（RuoYi）框架的前端实现。该项目采用最新的前端技术栈，提供了完整的权限管理、系统监控、代码生成等功能。

- **项目名称**：若依管理系统
- **版本**：3.9.2
- **作者**：若依
- **许可证**：MIT

## 三、技术栈使用方式

### 3.1 Vue 3 Composition API

项目全面采用 Vue 3 的 Composition API，使用 `<script setup>` 语法糖：

```vue
<script setup>
import { ref, computed, watch } from 'vue'

// 响应式数据
const loading = ref(false)
const userList = ref([])

// 计算属性
const total = computed(() => userList.value.length)

// 侦听器
watch(loading, (newVal) => {
  console.log('loading changed:', newVal)
})
</script>
```

**文件位置**：所有 `.vue` 文件都使用此模式

### 3.2 Pinia 状态管理

Pinia 是 Vue 3 推荐的状态管理库，使用 `defineStore` 定义状态：

```javascript
// src/store/modules/user.js
const useUserStore = defineStore('user', {
  state: () => ({
    token: getToken(),
    name: '',
    roles: [],
    permissions: []
  }),
  actions: {
    login(userInfo) { /* ... */ },
    getInfo() { /* ... */ },
    logOut() { /* ... */ }
  }
})
```

**使用方式**：
```javascript
import useUserStore from '@/store/modules/user'
const userStore = useUserStore()
userStore.login(userInfo)
```

### 3.3 Vue Router 4

使用 `createWebHistory` 创建路由实例，支持 HTML5 History 模式：

```javascript
// src/router/index.js
import { createWebHistory, createRouter } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: constantRoutes,
  scrollBehavior(to, from, savedPosition) {
    if (savedPosition) return savedPosition
    return { top: 0 }
  }
})
```

### 3.4 Element Plus 组件库

全局注册 Element Plus，并配置中文语言包：

```javascript
// src/main.js
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import locale from 'element-plus/es/locale/lang/zh-cn'

app.use(ElementPlus, {
  locale: locale,
  size: Cookies.get('size') || 'default'
})
```

### 3.5 Axios 请求封装

项目对 Axios 进行了深度封装，添加了请求/响应拦截器：

```javascript
// src/utils/request.js
const service = axios.create({
  baseURL: import.meta.env.VITE_APP_BASE_API,
  timeout: 10000
})

// 请求拦截器 - 自动添加 Token
service.interceptors.request.use(config => {
  if (getToken() && !isToken) {
    config.headers['Authorization'] = 'Bearer ' + getToken()
  }
  return config
})

// 响应拦截器 - 统一错误处理
service.interceptors.response.use(res => {
  const code = res.data.code || 200
  if (code === 401) {
    // 处理登录过期
  }
  return res.data
})
```

### 3.6 Vite 构建配置

Vite 配置了路径别名、代理、构建优化等：

```javascript
// vite.config.js
export default defineConfig(({ mode, command }) => ({

        rewrite: (p) => p.replace(/^\/dev-api/, '')

    }
  }

```

## 四、跨域配置

### 4.1 开发环境跨域

在开发环境中，使用 Vite 的代理功能解决跨域问题：

```javascript
// vite.config.js
server: {
  port: 80,
  host: true,
  open: true,
  proxy: {
    '/dev-api': {
      target: 'http://localhost:8080',  // 后端服务地址
      changeOrigin: true,               // 改变请求头中的 Origin
      rewrite: (p) => p.replace(/^\/dev-api/, '')  // 重写路径
    }
  }
}
```

**工作原理**：
1. 前端请求 `/dev-api/system/user/list`
2. Vite 代理将其转发到 `http://localhost:8080/system/user/list`
3. 后端响应返回给 Vite，再由 Vite 返回给前端

### 4.2 环境变量配置

```bash
# .env.development
VITE_APP_BASE_API = '/dev-api'

# .env.production
VITE_APP_BASE_API = '/prod-api'
```

### 4.3 生产环境跨域

生产环境通常通过以下方式解决：
1. **Nginx 反向代理**：将前端和后端部署在同一域名下
2. **后端 CORS 配置**：后端配置允许跨域请求

## 五、页面结构

### 5.1 整体布局

页面采用经典的左侧菜单 + 顶部导航 + 内容区域布局：

```
┌─────────────────────────────────────────────┐
│                    Navbar                    │
├──────────┬──────────────────────────────────┤
│          │           TagsView               │
│ Sidebar  ├──────────────────────────────────┤
│          │                                   │
│          │           AppMain                 │
│          │         (路由视图)                │
│          │                                   │
└──────────┴──────────────────────────────────┘
```

**核心文件**：
- `src/layout/index.vue` - 主布局组件
- `src/layout/components/Navbar.vue` - 顶部导航栏
- `src/layout/components/Sidebar/index.vue` - 左侧菜单
- `src/layout/components/AppMain.vue` - 内容区域
- `src/layout/components/TagsView/index.vue` - 标签页

### 5.2 布局组件说明

```vue
<!-- src/layout/index.vue -->
<template>
  <div class="app-wrapper">
    <!-- 侧边栏 -->
    <sidebar class="sidebar-container" />
    
    <!-- 主内容区 -->
    <div class="main-container">
      <!-- 顶部导航 + 标签页 -->
      <div class="fixed-header">
        <navbar />
        <tags-view />
      </div>
      <!-- 路由视图 -->
      <app-main />
    </div>
  </div>
</template>
```

### 5.3 路由视图

`AppMain` 组件使用 `<router-view>` 渲染当前路由匹配的组件：

```vue
<!-- src/layout/components/AppMain.vue -->
<template>
  <section class="app-main">
    <router-view v-slot="{ Component, route }">
      <transition name="fade-transform" mode="out-in">
        <keep-alive :include="cachedViews">
          <component :is="Component" :key="route.path" />
        </keep-alive>
      </transition>
    </router-view>
  </section>
</template>
```

**特点**：
- 使用 `<keep-alive>` 缓存组件状态
- 支持路由切换动画
- 标签页多开功能
