# RuoYi-Vue3 项目结构精细分类

> 本文档基于对项目全部源码文件的逐一阅读，按功能职责进行最细粒度的分类。
> 每个文件均标注了精确路径和功能说明。

---

## 第一层：项目根目录

```
RuoYi-Vue3/
├── index.html                  # HTML 入口模板（含加载动画）
├── package.json                # 项目依赖与脚本命令
├── vite.config.js              # Vite 构建配置（别名/代理/打包/插件）
├── .env.development            # 开发环境变量（API 前缀 /dev-api）
├── .env.production             # 生产环境变量（API 前缀 /prod-api + gzip 压缩）
├── .env.staging                # 预发布环境变量（API 前缀 /stage-api + gzip 压缩）
├── .gitignore                  # Git 忽略规则
├── LICENSE                     # MIT 开源协议
├── README.md                   # 项目说明文档
│
├── bin/                        # Windows 批处理脚本
├── html/                       # IE 兼容跳转页
├── public/                     # 不经构建的静态资源
├── vite/                       # Vite 插件配置目录
└── src/                        # ★ 全部业务源码
```

---

## 第二层：`src/` 源码总览

```
src/
├── main.js                     # 【入口】Vue 应用创建、插件注册、全局组件/方法挂载
├── App.vue                     # 【根组件】仅包含 <router-view> + 初始化主题样式
├── permission.js               # 【路由守卫】登录校验、动态路由加载、锁屏检查
├── settings.js                 # 【全局默认设置】标题/主题/导航模式/标签页/暗黑模式等
│
├── api/                        # 【API 接口层】所有后端 HTTP 请求定义
├── assets/                     # 【静态资源】图标/图片/样式文件
├── components/                 # 【公共组件】可复用的 UI 组件
├── directive/                  # 【自定义指令】Vue 指令定义与注册
├── layout/                     # 【布局框架】整体页面骨架
├── plugins/                    # 【插件层】全局功能插件（挂载到 $xxx）
├── router/                     # 【路由层】路由配置
├── store/                      # 【状态管理】Pinia Store
├── utils/                      # 【工具函数】通用工具方法
└── views/                      # 【页面视图】业务页面
```

### 一、`src/api/` — API 接口层（19 个文件）

所有接口基于 `src/utils/request.js` 封装的 axios 实例，统一携带 Token、处理错误。

#### 1.1 通用接口（2 个文件）

| 文件 | 功能 |
|------|------|
| `login.js` | 登录/注册/登出/获取验证码/获取用户信息/解锁屏幕 |
| `menu.js` | 获取后端动态路由菜单数据（GET /getRouters） |

#### 1.2 系统管理模块接口（10 个文件）

| 文件 | 功能 |
|------|------|
| `system/user.js` | 用户 CRUD、密码重置、状态修改、头像上传、角色授权、部门树选择 |
| `system/role.js` | 角色 CRUD、数据权限配置、角色菜单树、已授权/未授权用户列表、取消授权 |
| `system/menu.js` | 菜单 CRUD、菜单下拉树、角色菜单树、菜单排序保存 |
| `system/dept.js` | 部门 CRUD、排除指定节点的部门列表、部门排序保存 |
| `system/post.js` | 岗位 CRUD |
| `system/config.js` | 系统参数 CRUD、按键名查询参数值、刷新缓存 |
| `system/notice.js` | 公告 CRUD、首页公告列表、标记已读/批量已读、已读用户列表 |
| `system/dict/type.js` | 字典类型 CRUD、刷新缓存、下拉选择列表 |
| `system/dict/data.js` | 字典数据 CRUD、按字典类型查询字典数据列表 |

#### 1.3 系统监控模块接口（7 个文件）

| 文件 | 功能 |
|------|------|
| `monitor/cache.js` | Redis 缓存详情/名称/键名/内容查询、按名称/键名/全部清理缓存 |
| `monitor/server.js` | 获取服务器运行信息（CPU/内存/JVM/磁盘） |
| `monitor/online.js` | 在线用户列表查询、强制下线 |
| `monitor/job.js` | 定时任务 CRUD、状态修改、立即执行一次 |
| `monitor/jobLog.js` | 调度日志列表查询、删除、清空 |
| `monitor/logininfor.js` | 登录日志列表查询、删除、解锁账户、清空 |
| `monitor/operlog.js` | 操作日志列表查询、删除、清空 |

#### 1.4 系统工具模块接口（1 个文件）

| 文件 | 功能 |
|------|------|
| `tool/gen.js` | 代码生成：表列表查询、导入/创建表、预览/下载代码、同步数据库、删除表 |
