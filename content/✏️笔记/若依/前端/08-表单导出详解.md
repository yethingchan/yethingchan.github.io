# RuoYi-Vue3 表单导出详解（重点）

## 一、导出功能概述

RuoYi-Vue3 提供了完善的导出功能，支持：

1. **Excel 导出**：将表格数据导出为 Excel 文件
2. **文件下载**：下载服务器上的文件
3. **ZIP 打包下载**：批量下载打包为 ZIP

---

## 二、导出相关文件清单

| 文件路径 | 作用 |
|----------|------|
| `src/plugins/download.js` | 下载插件 |
| `src/utils/request.js` | 通用下载方法 |
| `src/components/ExcelImportDialog/index.vue` | Excel 导入组件 |

## 三、下载插件详解

**文件位置**：`src/plugins/download.js`

### 3.1 完整源码

```javascript
import axios from 'axios'
import { ElLoading, ElMessage } from 'element-plus'
import { saveAs } from 'file-saver'
import { getToken } from '@/utils/auth'
import errorCode from '@/utils/errorCode'
import { blobValidate } from '@/utils/ruoyi'

const baseURL = import.meta.env.VITE_APP_BASE_API
let downloadLoadingInstance

export default {
  /**
   * 下载文件（根据文件名）
   * @param {String} name - 文件名
   * @param {Boolean} isDelete - 是否删除临时文件
   */
  name(name, isDelete = true) {
    var url = baseURL + "/common/download?fileName=" + encodeURIComponent(name) + "&delete=" + isDelete
    axios({
      method: 'get',
      url: url,
      responseType: 'blob',
      headers: { 'Authorization': 'Bearer ' + getToken() }
    }).then((res) => {
      const isBlob = blobValidate(res.data)
      if (isBlob) {
        const blob = new Blob([res.data])
        this.saveAs(blob, decodeURIComponent(res.headers['download-filename']))
      } else {
        this.printErrMsg(res.data)
      }
    })
  },
  
  /**
   * 下载资源文件
   * @param {String} resource - 资源路径
   */
  resource(resource) {
    var url = baseURL + "/common/download/resource?resource=" + encodeURIComponent(resource)
    axios({
      method: 'get',
      url: url,
      responseType: 'blob',
      headers: { 'Authorization': 'Bearer ' + getToken() }
    }).then((res) => {
      const isBlob = blobValidate(res.data)
      if (isBlob) {
        const blob = new Blob([res.data])
        this.saveAs(blob, decodeURIComponent(res.headers['download-filename']))
      } else {
        this.printErrMsg(res.data)
      }
    })
  },
  
  /**
   * 下载 ZIP 文件
   * @param {String} url - 下载地址
   * @param {String} name - 文件名
   */
  zip(url, name) {
    var url = baseURL + url
    downloadLoadingInstance = ElLoading.service({ 
      text: "正在下载数据，请稍候", 
      background: "rgba(0, 0, 0, 0.7)" 
    })
    axios({
      method: 'get',
      url: url,
      responseType: 'blob',
      headers: { 'Authorization': 'Bearer ' + getToken() }
    }).then((res) => {
      const isBlob = blobValidate(res.data)
      if (isBlob) {
        const blob = new Blob([res.data], { type: 'application/zip' })
        this.saveAs(blob, name)
      } else {
        this.printErrMsg(res.data)
      }
      downloadLoadingInstance.close()
    }).catch((r) => {
      console.error(r)
      ElMessage.error('下载文件出现错误，请联系管理员！')
      downloadLoadingInstance.close()
    })
  },
  
  /**
   * 保存文件
   * @param {Blob} text - Blob 数据
   * @param {String} name - 文件名
   * @param {Object} opts - 选项
   */
  saveAs(text, name, opts) {
    saveAs(text, name, opts)
  },
  
  /**
   * 打印错误信息
   * @param {Blob} data - 响应数据
   */
  async printErrMsg(data) {
    const resText = await data.text()
    const rspObj = JSON.parse(resText)
    const errMsg = errorCode[rspObj.code] || rspObj.msg || errorCode['default']
    ElMessage.error(errMsg)
  }
}
```

### 3.2 方法列表

| 方法名 | 参数 | 功能说明 |
|--------|------|----------|
| `name(name, isDelete)` | 文件名, 是否删除 | 下载临时文件 |
| `resource(resource)` | 资源路径 | 下载资源文件 |
| `zip(url, name)` | 下载地址, 文件名 | 下载 ZIP 文件 |
| `saveAs(text, name, opts)` | Blob, 文件名, 选项 | 保存文件 |

## 四、通用下载方法

**文件位置**：`src/utils/request.js`

```javascript
import { saveAs } from 'file-saver'

/**
 * 通用下载方法
 * @param {String} url - 下载地址
 * @param {Object} params - 请求参数
 * @param {String} filename - 文件名
 * @param {Object} config - 配置项
 */
export function download(url, params, filename, config) {
  downloadLoadingInstance = ElLoading.service({ 
    text: "正在下载数据，请稍候", 
    background: "rgba(0, 0, 0, 0.7)" 
  })
  
  return service.post(url, params, {
    transformRequest: [(params) => { return tansParams(params) }],
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    responseType: 'blob',  // 响应类型为 blob
    ...config
  }).then(async (data) => {
    const isBlob = blobValidate(data)
    if (isBlob) {
      const blob = new Blob([data])
      saveAs(blob, filename)
    } else {
      const resText = await data.text()
      const rspObj = JSON.parse(resText)
      const errMsg = errorCode[rspObj.code] || rspObj.msg || errorCode['default']
      ElMessage.error(errMsg)
    }
    downloadLoadingInstance.close()
  }).catch((r) => {
    console.error(r)
    ElMessage.error('下载文件出现错误，请联系管理员！')
    downloadLoadingInstance.close()
  })
}
```

## 五、导出功能使用方式

### 5.1 基本导出（使用全局方法）

```vue
<template>
  <el-button type="warning" icon="Download" @click="handleExport">
    导出
  </el-button>
</template>

<script setup>
import { getCurrentInstance } from 'vue'

const { proxy } = getCurrentInstance()

// 查询参数
const queryParams = reactive({
  userName: undefined,
  status: undefined
})

/** 导出按钮操作 */
function handleExport() {
  proxy.$modal.confirm('是否确认导出所有用户数据项？').then(() => {
    proxy.download('/system/user/export', {
      ...queryParams
    }, 'user_${new Date().getTime()}.xlsx')
  }).catch(() => {})
}
</script>
```

### 5.3 使用下载插件

```javascript

// 下载临时文件

```

## 七、后端接口规范

### 7.1 导出接口

**请求**：
```
POST /system/user/export
Content-Type: application/x-www-form-urlencoded

userName=admin&status=0
```

**响应**：
```
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename=user.xlsx

[Excel 文件二进制数据]
```

### 7.2 导入接口

**请求**：
```
POST /system/user/importData
Content-Type: multipart/form-data

file: [Excel 文件]
updateSupport: true/false
```

**响应**：
```json
{
  "code": 200,
  "msg": "导入成功",
  "data": {
    "successNum": 10,
    "failureNum": 2,
    "failureMsg": "第3行用户名已存在；第5行邮箱格式错误"
  }
}
```

### 7.3 模板下载接口

**请求**：
```
GET /system/user/importTemplate
```

**响应**：
```
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename=user_template.xlsx

[Excel 模板二进制数据]
```

## 九、常见问题与解决

### 问题1：导出文件乱码

**原因**：响应编码问题

**解决**：后端设置正确的 Content-Type 和编码

```java
response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
response.setCharacterEncoding("utf-8");
```

### 问题2：导出时 Token 过期

**原因**：下载请求未携带 Token

**解决**：使用 `download` 方法会自动携带 Token

```javascript
// 错误方式（不会携带 Token）
window.open('/system/user/export')

// 正确方式
proxy.download('/system/user/export', params, 'user.xlsx')
```

### 问题3：导出大数据量超时

**原因**：数据量过大，请求超时

**解决**：增加请求超时时间

```javascript
proxy.download('/system/user/export', params, 'user.xlsx', {
  timeout: 60000  // 60秒
})
```

### 问题4：导出文件名中文乱码

**原因**：文件名编码问题

**解决**：后端对文件名进行 URL 编码

```java
String filename = URLEncoder.encode("用户数据.xlsx", "UTF-8");
response.setHeader("Content-Disposition", "attachment;filename=" + filename);
```

## 十一、file-saver 库说明

项目使用 [file-saver](https://github.com/eligrey/FileSaver.js) 库处理文件保存。

### 基本用法

```javascript
import { saveAs } from 'file-saver'

// 保存文本文件
const blob = new Blob(['Hello World'], { type: 'text/plain;charset=utf-8' })
saveAs(blob, 'hello.txt')

// 保存 Blob
const blob = new Blob([data], { type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' })
saveAs(blob, 'data.xlsx')

// 保存 URL
saveAs('https://example.com/file.pdf', 'file.pdf')
```
