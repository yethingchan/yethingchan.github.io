## 二、核心目录详解

### 2.1 API 接口目录 (`src/api/`)

存放所有后端 API 接口定义，按模块组织：

```
src/api/
├── login.js                   # 登录相关接口
├── menu.js                    # 菜单接口
├── monitor/                   # 监控模块接口
│   ├── cache.js              # 缓存监控
│   ├── job.js                # 定时任务
│   ├── jobLog.js             # 任务日志
│   ├── logininfor.js         # 登录日志
│   ├── online.js             # 在线用户
│   ├── operlog.js            # 操作日志
│   └── server.js             # 服务器监控
├── system/                    # 系统模块接口
│   ├── config.js             # 参数配置
│   ├── dept.js               # 部门管理
│   ├── menu.js               # 菜单管理
│   ├── notice.js             # 通知公告
│   ├── post.js               # 岗位管理
│   ├── role.js               # 角色管理
│   ├── user.js               # 用户管理
│   └── dict/                 # 字典管理
│       ├── data.js           # 字典数据
│       └── type.js           # 字典类型
└── tool/                      # 工具模块接口
    └── gen.js                # 代码生成
```

**接口定义示例**：
```javascript
// src/api/system/user.js
import request from '@/utils/request'

// 查询用户列表
export function listUser(query) {
  return request({
    url: '/system/user/list',
    method: 'get',
    params: query
  })
}

// 新增用户
export function addUser(data) {
  return request({
    url: '/system/user',
    method: 'post',
    data: data
  })
}
```

### 2.4 自定义指令目录 (`src/directive/`)

```
src/directive/
├── common/                    # 通用指令
│   └── copyText.js           # 复制文本指令
├── permission/                # 权限指令
│   ├── hasPermi.js           # 权限字符指令
│   └── hasRole.js            # 角色权限指令
└── index.js                   # 指令注册入口
```

**权限指令使用**：
```vue
<!-- 权限字符控制 -->
<el-button v-hasPermi="['system:user:add']">新增</el-button>

<!-- 角色控制 -->
<el-button v-hasRole="['admin']">管理员按钮</el-button>
```
