# RuoYi-Vue3 技术细节汇总表

## 一、核心技术细节一览表

| 技术点 | 实现方式 | 文件位置 | 说明 |
|--------|----------|----------|------|
| **自动导入** | unplugin-auto-import | `vite/plugins/auto-import.js` | 无需手动导入 Vue API |

## 十四、项目亮点总结

| 亮点 | 描述 |
|------|------|
| **Vue 3 Composition API** | 全面采用最新的组合式 API，代码更简洁 |
| **Pinia 状态管理** | 替代 Vuex，更轻量、更易用 |
| **Vite 构建** | 极速的开发体验，秒级热更新 |
| **Element Plus** | 完整的 UI 组件库，开发效率高 |
| **动态路由** | 根据权限动态加载路由，安全性高 |
| **多层权限控制** | 路由级、菜单级、按钮级权限 |
| **完善的工具函数** | 封装常用操作，提高开发效率 |
| **响应式设计** | 适配桌面端和移动端 |
| **暗黑模式** | 支持明暗主题切换 |
| **代码生成** | 自动生成 CRUD 代码 |

---

## 十五、技术选型理由

| 技术 | 选型理由 |
|------|----------|
| **Vue 3** | 性能更好、体积更小、Composition API 更灵活 |
| **Pinia** | Vue 3 官方推荐，比 Vuex 更简单 |
| **Vite** | 开发启动快、热更新快、构建配置简单 |
| **Element Plus** | Vue 3 生态最成熟的 UI 库 |
| **Axios** | 功能强大、拦截器机制完善 |
| **js-cookie** | 简单易用的 Cookie 操作库 |
| **file-saver** | 跨浏览器文件保存方案 |
| **nprogress** | 轻量级进度条组件 |
