## 一、最快解决方法

### 1. 先启动模拟器

1. 点击 Android Studio 右上角 **手机图标 📱**（Device Manager）
2. 选择你创建好的模拟器 → 点 **Launch** 启动
3. 等模拟器完全开机、显示桌面后，再点运行 ▶️

### 2. 或者连接真实安卓手机

用数据线把手机插电脑，**必须开启：**

- 设置 → 开发者选项 → **USB 调试**
- 弹出授权 → 点 **允许**

## 二、如果已经开了设备，但还是报错

按下面 4 个步骤排查，**一定能解决**：

### 步骤 1：检查 AS 是否识别到设备

看 Android Studio 底部工具栏：

- 显示 **设备名称**（如 Pixel 7）= 识别成功
- 显示 **No Devices** = 没识别到

### 步骤 2：重启 ADB（最有效）

1. 打开底部 **Build** 旁边的 **Terminal** 终端
2. 输入命令：

bash

运行

```
adb kill-server
adb start-server
```

然后再运行项目。

### 步骤 3：检查运行配置

1. 点击运行按钮 ▶️ 左边的 **app** 下拉
2. 选择 **Edit Configurations**
3. 找到 **Deployment Target Options**
4. 选择：**USB Device or Emulator**（不要选无设备）

### 步骤 4：模拟器无法启动？

- 打开 Device Manager → 点模拟器右边 ▼ → **Wipe Data**
- 再重新启动
 
### 总结

1. 报错原因：**没有可用的安卓设备（模拟器 / 真机）**
2. 解决核心：**先启动设备，再运行项目**
3. 无效就用：`adb kill-server` + `adb start-server`
