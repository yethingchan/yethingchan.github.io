## 响应式与多端适配

在工业物联网场景中，上位机的使用终端越来越多样化——工程师可能在控制室用大屏显示器操作，在巡检时用手机查看数据，在办公室用笔记本配置参数。IoTGateway基于LayUI的栅格系统和响应式工具类，实现了基本的多端适配能力。本章介绍这些响应式特性的具体用法和工业场景下的适配策略。

## LayUI响应式基础

### 栅格断点

LayUI的栅格系统支持四种屏幕尺寸断点：

| 断点前缀 | 最小宽度 | 典型设备 | 工控场景 |
|----------|---------|---------|---------|
| `xs` | 0px | 手机（<768px） | 现场巡检用手机 |
| `sm` | 768px | 平板 | 车间平板终端 |
| `md` | 992px | 小屏笔记本 | 工程师笔记本 |
| `lg` | 1200px | 桌面显示器 | 控制室大屏 |

### 响应式列宽

在IoTGateway的首页仪表盘中，图表在不同屏幕下的布局会自动调整：

```html
<!-- 在中等及以上屏幕：左侧3列 + 右侧9列 -->
<!-- 在小屏幕：自动堆叠为上下排列 -->
<div class="layui-row layui-col-space15">
    <div class="layui-col-md3">
        <div class="layui-card">
            <div class="layui-card-header">设备状态</div>
            <div class="layui-card-body">
                <wt:chart type="Pie" height="200" ... />
            </div>
        </div>
    </div>
    <div class="layui-col-md9">
        <div class="layui-card">
            <div class="layui-card-header">设备变量状态</div>
            <div class="layui-card-body">
                <wt:chart type="Bar" height="200" ... />
            </div>
        </div>
    </div>
</div>
```

**行为说明：**
- 屏幕 >= 992px：饼图占25%宽度，柱状图占75%
- 屏幕 < 992px：两个图表各占100%宽度，上下堆叠

### 多断点组合

可以为不同屏幕尺寸分别指定列宽：

```html
<!-- 手机占满，平板占一半，桌面占1/3 -->
<div class="layui-col-xs12 layui-col-sm6 layui-col-md4">
    <div class="layui-card">
        <div class="layui-card-header">传感器A</div>
        <div class="layui-card-body">温度: 25.6℃</div>
    </div>
</div>
```

## 响应式工具类

LayUI提供了一系列响应式显示/隐藏工具类：

| 类名 | 说明 |
|------|------|
| `layui-hide-xs` | 在手机尺寸隐藏 |
| `layui-hide-sm` | 在平板尺寸隐藏 |
| `layui-hide-md` | 在中等尺寸隐藏 |
| `layui-hide-lg` | 在大屏尺寸隐藏 |
| `layui-show-xs-block` | 仅手机尺寸显示 |
| `layui-show-sm-block` | 仅平板尺寸显示 |

在IoTGateway的布局头部（`Layout.cshtml`），多处使用了响应式隐藏：

```html
<!-- 官网链接：手机上隐藏，避免空间不足 -->
<li class="layui-nav-item layui-hide-xs" lay-unselect>
    <a href="http://iotgateway.net" target="_blank">
        <i class="layui-icon layui-icon-website"></i>
    </a>
</li>

<!-- 主题切换：手机上隐藏 -->
<li class="layui-nav-item layui-hide-xs" lay-unselect>
    <a href="javascript:;" layadmin-event="theme">
        <i class="layui-icon layui-icon-theme"></i>
    </a>
</li>

<!-- 全屏按钮：手机上隐藏（手机无此需求） -->
<li class="layui-nav-item layui-hide-xs" lay-unselect>
    <a href="javascript:;" layadmin-event="fullscreen">
        <i class="layui-icon layui-icon-screen-full"></i>
    </a>
</li>
```

## 移动端适配

### 侧边栏处理

在移动设备上，侧边栏默认隐藏，通过头部左侧的汉堡菜单按钮触发显示：

```html
<!-- 移动端遮罩层 -->
<div class="layadmin-body-shade" layadmin-event="shade"></div>
```

当侧边栏展开时：
1. 侧边栏以浮动层形式覆盖在内容区之上
2. 半透明遮罩层出现在内容区域
3. 点击遮罩或菜单项后侧边栏自动收起

### 视口设置

IoTGateway的登录页面设置了标准的视口meta标签：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta http-equiv="X-UA-Compatible" content="ie=edge">
```

这确保了页面在移动浏览器中正确缩放，不会出现在IE兼容模式下的布局异常。

### 触摸交互优化

LayUI的部分组件针对触摸设备做了优化：

```javascript
// 轮播组件根据设备类型选择触发方式
carousel.render({
    elem: this,
    trigger: (device.ios || device.android) ? 'click' : 'hover',
    // 移动设备用点击触发，桌面设备用悬停触发
});
```

## 表格的响应式处理

数据表格是管理后台的核心组件，在移动端的适配策略如下：

### 水平滚动

LayUI表格在窄屏下自动启用水平滚动：

```javascript
table.render({
    elem: '#deviceTable',
    cols: [[
        {field: 'DeviceName', title: '设备名称', width: 150},
        {field: 'DriverName', title: '驱动', width: 120},
        {field: 'AutoStart', title: '自动启动', width: 100},
        {field: 'Description', title: '描述', minWidth: 200}
    ]],
    // 列总宽度超过容器宽度时自动出现水平滚动条
});
```

### 固定列

关键操作列可以固定在右侧，不随水平滚动：

```javascript
table.render({
    cols: [[
        {type: 'checkbox'},
        {field: 'DeviceName', title: '设备名称', width: 150},
        // ... 其他列 ...
        {fixed: 'right', title: '操作', width: 150, toolbar: '#barTpl'}
    ]]
});
```

### 隐藏次要列

在移动端，可以通过媒体查询隐藏非关键列，只保留核心信息：

```css
@media screen and (max-width: 768px) {
    /* 隐藏描述列 */
    td[data-field="Description"] { display: none; }
    /* 隐藏索引列 */
    td[data-field="Index"] { display: none; }
}
```

## 图表的响应式

ECharts图表天然支持容器自适应。在IoTGateway中，图表的`resize`处理需要注意以下几点：

```javascript
// 监听窗口resize事件
window.addEventListener('resize', function() {
    // 重新计算所有图表尺寸
    if (typeof trendChart !== 'undefined') {
        trendChart.resize();
    }
    if (typeof gaugeChart !== 'undefined') {
        gaugeChart.resize();
    }
});

// LayUI侧边栏展开/收起时也需要resize
layui.use('element', function(){
    var element = layui.element;
    element.on('nav(layadmin-system-side-menu)', function(){
        setTimeout(function(){
            // 侧边栏动画结束后resize图表
            window.dispatchEvent(new Event('resize'));
        }, 300);
    });
});
```

## 工业场景适配建议

### 控制室大屏

控制室通常使用40寸以上的工业显示器，分辨率可能达到4K：

```css
/* 大屏优化 */
@media screen and (min-width: 1920px) {
    .layui-card-body {
        font-size: 16px;  /* 加大字号 */
    }
    .layui-table td {
        padding: 12px 15px;  /* 增大间距 */
    }
}
```

### 现场平板

车间环境中常用的工业平板通常为10寸左右，横屏使用：

```css
/* 平板横屏优化 */
@media screen and (min-width: 768px) and (max-width: 1024px) and (orientation: landscape) {
    .layui-side {
        width: 160px;  /* 缩小侧边栏宽度，留更多空间给内容 */
    }
}
```

### 手套操作

工业现场操作人员可能戴手套，需要增大点击区域：

```css
/* 大按钮模式 */
.touch-friendly .layui-btn {
    min-height: 44px;     /* 最小触摸目标44px */
    min-width: 44px;
    padding: 10px 20px;
}

.touch-friendly .layui-form-switch {
    width: 60px;          /* 增大开关尺寸 */
    height: 34px;
}
```

## PWA潜力

虽然IoTGateway目前未实现PWA（Progressive Web App），但基于其Web架构，添加PWA支持可以带来以下好处：

1. **添加到主屏幕** - 手机/平板上像APP一样使用
2. **离线缓存** - 网络中断时仍可访问基本界面
3. **推送通知** - 设备告警推送到手机

添加PWA支持只需增加`manifest.json`和Service Worker：

```json
{
    "name": "IoTGateway",
    "short_name": "IoT",
    "start_url": "/",
    "display": "standalone",
    "background_color": "#ffffff",
    "theme_color": "#20222A",
    "icons": [
        { "src": "/images/logo-192.png", "sizes": "192x192", "type": "image/png" }
    ]
}
```

## 打印支持

IoTGateway在`appsettings.json`中配置了表格打印功能：

```json
{
  "UIOptions": {
    "DataTable": {
      "ShowPrint": true
    }
  }
}
```

通过打印样式表优化打印输出：

```css
@media print {
    .layui-header,
    .layui-side,
    .layadmin-pagetabs,
    .layadmin-body-shade {
        display: none !important;  /* 打印时隐藏导航元素 */
    }
    .layui-body {
        position: static !important;
        margin: 0 !important;
    }
}
```

## 小结

IoTGateway基于LayUI的栅格系统和响应式工具类，实现了对PC、平板、手机等多种终端的基本适配。在实际工业部署中，建议根据具体的使用终端类型（控制室大屏、车间平板、巡检手机）进一步优化布局和交互细节。对于需要频繁移动操作的场景，可以考虑添加PWA支持以获得更好的用户体验。
