## 管理后台设计

IoTGateway的管理后台是运维人员和工程师的主要操作界面，涵盖了设备管理、用户权限、系统配置、日志查看等功能。后台基于LayUI Admin模板和WTM框架共同构建，具备完整的侧边栏导航、标签页管理、RBAC权限控制和主题切换能力。本章深入分析管理后台的整体设计思路和实现细节。

## 整体布局结构

IoTGateway采用LayUI的经典后台管理布局（`Layout.cshtml`）：

```html
<div class="layui-layout layui-layout-admin">
    <!-- 1. 头部区域 -->
    <div class="layui-header">...</div>
    
    <!-- 2. 侧边菜单 -->
    <div class="layui-side layui-side-menu">...</div>
    
    <!-- 3. 标签页导航 -->
    <div class="layadmin-pagetabs">...</div>
    
    <!-- 4. 主体内容区域 -->
    <div class="layui-body" id="LAY_app_body">...</div>
    
    <!-- 5. 移动端遮罩 -->
    <div class="layadmin-body-shade" layadmin-event="shade"></div>
</div>
```

布局采用**固定头部 + 固定侧边栏 + 弹性内容区**的经典模式，适合长时间操作的管理后台。

## 侧边栏导航

### 动态菜单加载

侧边栏菜单通过WTM框架的菜单API动态加载，支持多级嵌套：

```html
<script type="text/html" template 
        lay-url="/_Framework/Menu?t=@DateTime.Now.Ticks"
        lay-done="layui.element.render('nav', 'layadmin-system-side-menu');">
    
    <div class="layui-logo" lay-href="">
        <span>
            <img src="~/layuiadmin/style/res/logo.png" />
            {{ layui.setter.name || 'layuiAdmin' }}
        </span>
    </div>

    <ul class="layui-nav layui-nav-tree" lay-shrink="all" 
        id="LAY-system-side-menu" 
        lay-filter="layadmin-system-side-menu">
      {{#
          var path = layui.router().path;
          layui.each(d.data, function(index, item){
              var hasChildren = typeof item.list === 'object' && item.list.length > 0;
              var url = item.jump || item.name;
      }}
      <li data-name="{{ item.name }}" class="layui-nav-item">
        <a href="javascript:;" 
           {{ hasChildren ? '' : 'lay-href="'+ url +'"' }} 
           lay-tips="{{ item.title }}">
          <i class="{{ item.icon }}"></i>
          <cite>{{ item.title }}</cite>
        </a>
        {{# if(hasChildren){ }}
        <dl class="layui-nav-child">
          {{# layui.each(item.list, function(index2, item2){ }}
          <dd>
            <a href="javascript:;" lay-href="{{ item2.jump || item2.name }}">
              <i class="{{ item2.icon }}"></i>
              <cite>{{ item2.title }}</cite>
            </a>
          </dd>
          {{# }); }}
        </dl>
        {{# } }}
      </li>
      {{# }); }}
    </ul>
</script>
```

**设计要点：**
- 菜单数据通过`/_Framework/Menu`接口获取，由WTM框架根据当前用户的角色和权限动态生成
- 使用LayUI的模板引擎（`{{ }}`语法）渲染菜单HTML
- 支持三级菜单嵌套
- `lay-shrink="all"`使同级菜单互斥展开（手风琴模式）

### 菜单配置

IoTGateway的菜单通过WTM的`_Admin`区域管理，支持以下操作：
- 新增/编辑/删除菜单项
- 设置菜单图标（LayUI图标字体）
- 配置菜单跳转URL
- 设置菜单可见权限

## 标签页管理

IoTGateway配置为标签页模式（Tab Mode），用户可以同时打开多个页面：

```json
{
  "PageMode": "Tab",    // 标签页模式
  "TabMode": "Simple"   // 简洁标签样式
}
```

### 标签页结构

```html
<div class="layadmin-pagetabs" id="LAY_app_tabs">
    <!-- 左右滚动控制 -->
    <div class="layui-icon layadmin-tabs-control layui-icon-prev" 
         layadmin-event="leftPage"></div>
    <div class="layui-icon layadmin-tabs-control layui-icon-next" 
         layadmin-event="rightPage"></div>
    
    <!-- 下拉菜单（关闭标签操作） -->
    <div class="layui-icon layadmin-tabs-control layui-icon-down">
        <ul class="layui-nav layadmin-tabs-select" 
            lay-filter="layadmin-pagetabs-nav">
            <li class="layui-nav-item">
                <a href="javascript:;"></a>
                <dl class="layui-nav-child">
                    <dd layadmin-event="closeThisTabs">
                        <a>关闭当前标签</a>
                    </dd>
                    <dd layadmin-event="closeOtherTabs">
                        <a>关闭其他标签</a>
                    </dd>
                    <dd layadmin-event="closeAllTabs">
                        <a>关闭所有标签</a>
                    </dd>
                </dl>
            </li>
        </ul>
    </div>
    
    <!-- 标签列表 -->
    <div class="layui-tab" lay-unauto lay-allowClose="true" 
         lay-filter="layadmin-layout-tabs">
        <ul class="layui-tab-title" id="LAY_app_tabsheader">
            <li lay-id="/"><i class="layui-icon layui-icon-home"></i></li>
        </ul>
    </div>
</div>
```

### 标签页操作

- **点击标签** - 切换到对应页面
- **关闭标签** - 点击标签上的关闭按钮
- **右键菜单** - 关闭当前/关闭其他/关闭所有
- **左右滚动** - 标签过多时可以滚动浏览

## RBAC权限控制

### 认证方式

IoTGateway支持两种认证方式：

**Cookie认证（页面访问）：**
```json
{
  "CookieOptions": {
    "Issuer": "http://localhost",
    "Audience": "http://localhost",
    "Expires": 3600,
    "SlidingExpiration": true,
    "SecurityKey": "superSecretKey@345",
    "LoginPath": "/Login/Login"
  }
}
```

**JWT认证（API访问）：**
```json
{
  "JwtOptions": {
    "Issuer": "http://localhost",
    "Audience": "http://localhost",
    "Expires": 3600,
    "SecurityKey": "superSecretKey@345",
    "RefreshTokenExpires": 86400,
    "LoginPath": "/_Framework/Redirect401"
  }
}
```

### 权限模型

WTM框架提供了完整的RBAC权限模型：

```
用户（FrameworkUser）
  ├── 角色（FrameworkRole）  ── 多对多
  │     └── 页面权限（PageFunction）
  ├── 用户组（FrameworkGroup）── 多对多
  └── 数据权限（DataPrivilege）
菜单（FrameworkMenu）
  └── 角色权限（哪些角色可以访问哪些菜单）
```

### 管理界面

IoTGateway的`_Admin`区域提供了完整的权限管理页面：

| 页面 | 路径 | 功能 |
|------|------|------|
| 用户管理 | `/_Admin/FrameworkUser/Index` | 增删改查用户，分配角色 |
| 角色管理 | `/_Admin/FrameworkRole/Index` | 管理角色，配置页面权限 |
| 菜单管理 | `/_Admin/FrameworkMenu/Index` | 配置菜单树和图标 |
| 用户组管理 | `/_Admin/FrameworkGroup/Index` | 管理用户组和数据权限 |
| 数据权限 | `/_Admin/DataPrivilege/Index` | 配置行级数据权限 |
| 操作日志 | `/_Admin/ActionLog/Index` | 查看用户操作记录 |

### 角色权限配置

角色管理页面支持细粒度的权限配置（`FrameworkRole/PageFunction.cshtml`）：

```cshtml
<!-- 角色列表页 -->
<wt:searchpanel vm="@Model" reset-btn="true">
    <wt:row items-per-row="ItemsPerRowEnum.Three">
        <wt:textbox field="Searcher.RoleCode" />
        <wt:textbox field="Searcher.RoleName" />
    </wt:row>
</wt:searchpanel>
<wt:grid vm="@Model" url="/_Admin/FrameworkRole/Search" />
```

## 登录页面

IoTGateway的登录页面（`Login.cshtml`）采用了独立的全屏设计，不使用管理后台布局：

```cshtml
@model IoTGateway.ViewModel.HomeVMs.LoginVM
@{
    Layout = null;
    int bgnumber = new Random().Next(1, 6);
}

<body>
    <div class="loginBody app-login-back-@bgnumber">
        <header class="login-header">
            <img src="/images/logo.png" alt="" height="48">
        </header>
        <div class="login-content">
            <div class="login-form">
                <h1>IoTGateway</h1>
                <form action="/Login/Login" method="post">
                    <input type="hidden" name="Redirect" value="@Model.Redirect">
                    <ul class="loginForm">
                        <li>
                            <input type="text" name="ITCode" 
                                   placeholder="@Model.Localizer["Login.InputUserName"]" 
                                   class="login-input" value="@Model.ITCode">
                        </li>
                        <li>
                            <input type="password" name="Password" 
                                   placeholder="@Model.Localizer["Login.InputPassword"]" 
                                   class="login-input" value="@Model.Password">
                        </li>
                        <li>
                            <input type="checkbox" name="RememberLogin" value="true" 
                                   @(Model.RememberLogin ? "checked" : "")>
                            <span>@Model.Localizer["Login.RememberMe"]</span>
                        </li>
                        <li>
                            <button type="submit" class="login-button">
                                @Model.Localizer["Login.Login"]
                            </button>
                        </li>
                    </ul>
                </form>
            </div>
        </div>
    </div>
</body>
```

**特点：**
- 随机背景图（`app-login-back-1` ~ `app-login-back-5`）
- Cookie前缀为`IoTGateway`（在`appsettings.json`中配置）
- 支持"记住我"功能
- 多语言国际化

## 多租户支持

IoTGateway通过WTM框架支持多租户模式：

```json
{
  "EnableTenant": false  // 是否启用多租户
}
```

启用后，布局头部会出现租户切换菜单：

```cshtml
@if (tenants.Count() > 0)
{
    <li class="layui-nav-item" lay-unselect>
        <a href="javascript:;">
            <cite>@current</cite>
        </a>
        <dl class="layui-nav-child">
            <dd>
                <wt:linkbutton url="/_Framework/SetTenant?tenant=@Model?.Wtm?.LoginUserInfo?.TenantCode" 
                               target="ButtonTargetEnum.self" 
                               text="主租户" is-link="true" />
            </dd>
            @foreach (var item in tenants)
            {
                <dd>
                    <wt:linkbutton url="/_Framework/SetTenant?tenant=@item.Value" 
                                   target="ButtonTargetEnum.self" 
                                   text="@item.Text" is-link="true" />
                </dd>
            }
        </dl>
    </li>
}
```

## 主题切换

LayUI Admin支持动态主题切换，用户可以自定义：
- 头部颜色
- 侧边栏颜色
- Logo区域样式
- 整体配色方案

通过点击头部右侧的主题图标（`layadmin-event="theme"`）打开主题面板，选择后主题设置会保存到`localStorage`中。

## 页面显示模式

IoTGateway支持两种页面显示模式：

| 模式 | 配置值 | 说明 |
|------|--------|------|
| Tab模式 | `"PageMode": "Tab"` | 多标签页，适合同时操作多个功能 |
| Single模式 | `"PageMode": "Single"` | 单页面，每次导航替换整个内容区 |

Tab模式还支持两种标签样式：
- `"TabMode": "Default"` - 默认样式
- `"TabMode": "Simple"` - 简洁样式（IoTGateway默认）

## 小结

IoTGateway的管理后台是LayUI Admin模板和WTM框架的有机结合。LayUI提供了成熟的布局、导航和组件体系，WTM则负责菜单权限、用户管理和数据绑定。两者结合使得IoTGateway能够快速构建功能完备的工业物联网管理后台，同时保持高度的可定制性。
