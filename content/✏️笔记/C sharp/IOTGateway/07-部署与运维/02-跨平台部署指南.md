## 跨平台部署指南

.NET 8.0的一个核心优势是跨平台支持，IoTGateway可以运行在Windows、Linux和macOS上。这意味着同一个代码库可以部署在工控机（Windows）、边缘网关（Linux ARM）和开发工作站（macOS）上。本章详细讲解各平台的部署步骤和注意事项。

## Kestrel服务器配置

IoTGateway使用Kestrel作为内置Web服务器，在`Program.cs`中配置了监听端口：

```csharp
public static IHostBuilder CreateWebHostBuilder(string[] args)
{
    return Host.CreateDefaultBuilder(args)
        .ConfigureWebHostDefaults(webBuilder =>
        {
            webBuilder.UseStartup<Startup>();
            webBuilder.UseKestrel(option =>
            {
                option.ListenAnyIP(1888, l => l.UseMqtt());  // MQTT端口
                option.ListenAnyIP(518);                      // HTTP端口
            });
        })
        .UseNLog();
}
```

**关键配置说明：**
- `ListenAnyIP(518)` - HTTP服务监听所有网卡的518端口
- `ListenAnyIP(1888, l => l.UseMqtt())` - MQTT服务监听1888端口（MQTTnet扩展）
- Kestrel是一个高性能的跨平台Web服务器，生产环境中可直接使用或配合反向代理

## Windows部署

### 前置条件

- Windows 10/11 或 Windows Server 2016+
- .NET 8.0 Runtime（或使用自包含发布）

### 步骤一：发布应用

```powershell
# 在开发机器上发布
dotnet publish IoTGateway/IoTGateway.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -o ./publish/win-x64
```

### 步骤二：部署到目标机器

```powershell
# 将发布文件拷贝到目标机器
xcopy /E /I .\publish\win-x64 \\TargetPC\C$\IoTGateway

# 或通过压缩包传输
Compress-Archive -Path .\publish\win-x64\* -DestinationPath .\iotgateway-win.zip
```

### 步骤三：注册为Windows服务

**方式A：使用sc.exe**

```powershell
# 以管理员身份运行
sc.exe create IoTGateway `
  binPath= "C:\IoTGateway\IoTGateway.exe" `
  start= auto `
  DisplayName= "IoTGateway Service"

# 启动服务
sc.exe start IoTGateway

# 查看状态
sc.exe query IoTGateway

# 停止服务
sc.exe stop IoTGateway
```

**方式B：使用NSSM（推荐，更灵活）**

```powershell
# 下载NSSM: https://nssm.cc/download
nssm install IoTGateway "C:\IoTGateway\IoTGateway.exe"
nssm set IoTGateway AppDirectory "C:\IoTGateway"
nssm set IoTGateway AppStdout "C:\IoTGateway\logs\stdout.log"
nssm set IoTGateway AppStderr "C:\IoTGateway\logs\stderr.log"
nssm set IoTGateway AppRotateFiles 1
nssm set IoTGateway AppRotateBytes 10485760
nssm start IoTGateway
```

### 步骤四：配置防火墙

```powershell
# 开放HTTP端口
netsh advfirewall firewall add rule name="IoTGateway HTTP" `
  dir=in action=allow protocol=TCP localport=518

# 开放MQTT端口
netsh advfirewall firewall add rule name="IoTGateway MQTT" `
  dir=in action=allow protocol=TCP localport=1888
```

### Windows服务管理

```powershell
# 查看服务状态
Get-Service IoTGateway

# 重启服务
Restart-Service IoTGateway

# 查看服务日志
Get-EventLog -LogName Application -Source IoTGateway -Newest 20
```

## Linux部署

### 前置条件

- Ubuntu 20.04+ / CentOS 7+ / Debian 11+
- .NET 8.0 Runtime（或使用自包含发布）

### 步骤一：安装.NET运行时（如果使用依赖框架发布）

```bash
# Ubuntu
wget https://packages.microsoft.com/config/ubuntu/22.04/packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
sudo apt-get update
sudo apt-get install -y aspnetcore-runtime-8.0

# CentOS
sudo dnf install dotnet-runtime-8.0
```

### 步骤二：发布应用

```bash
# 发布为Linux x64
dotnet publish IoTGateway/IoTGateway.csproj \
  -c Release \
  -r linux-x64 \
  --self-contained true \
  -o ./publish/linux-x64

# 或使用单文件发布（推荐）
dotnet publish IoTGateway/IoTGateway.csproj \
  -c Release \
  -r linux-x64 \
  --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -o ./publish/linux-x64
```

### 步骤三：部署到目标机器

```bash
# 创建部署目录
sudo mkdir -p /opt/iotgateway
sudo chown $USER:$USER /opt/iotgateway

# 拷贝发布文件
scp -r ./publish/linux-x64/* user@target:/opt/iotgateway/

# 设置执行权限
chmod +x /opt/iotgateway/IoTGateway

# 创建数据和日志目录
mkdir -p /opt/iotgateway/data
mkdir -p /opt/iotgateway/logs
```

### 步骤四：创建systemd服务

```bash
sudo nano /etc/systemd/system/iotgateway.service
```

写入以下内容：

```ini
[Unit]
Description=IoTGateway Industrial IoT Service
Documentation=https://iotgateway.net
After=network.target network-online.target
Wants=network-online.target

[Service]
Type=notify
WorkingDirectory=/opt/iotgateway
ExecStart=/opt/iotgateway/IoTGateway
Restart=always
RestartSec=10
KillSignal=SIGINT
SyslogIdentifier=iotgateway
User=iotgateway
Group=iotgateway

# 环境变量
Environment=ASPNETCORE_ENVIRONMENT=Production
Environment=DOTNET_PRINT_TELEMETRY_MESSAGE=false
Environment=TZ=Asia/Shanghai

# 安全加固
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/iotgateway/data /opt/iotgateway/logs /opt/iotgateway/files
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

### 步骤五：启动和管理服务

```bash
# 创建运行用户
sudo useradd -r -s /bin/false iotgateway
sudo chown -R iotgateway:iotgateway /opt/iotgateway

# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start iotgateway

# 设置开机自启
sudo systemctl enable iotgateway

# 查看状态
sudo systemctl status iotgateway

# 查看日志
sudo journalctl -u iotgateway -f

# 重启服务
sudo systemctl restart iotgateway
```

### 步骤六：配置防火墙

```bash
# Ubuntu (ufw)
sudo ufw allow 518/tcp comment "IoTGateway HTTP"
sudo ufw allow 1888/tcp comment "IoTGateway MQTT"
sudo ufw reload

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-port=518/tcp
sudo firewall-cmd --permanent --add-port=1888/tcp
sudo firewall-cmd --reload
```

## ARM平台部署（树莓派/工控机）

许多边缘网关设备基于ARM架构，IoTGateway可以在这些设备上运行。

### 发布ARM版本

```bash
# ARM64（树莓派4、RK3568等）
dotnet publish IoTGateway/IoTGateway.csproj \
  -c Release \
  -r linux-arm64 \
  --self-contained true \
  -p:PublishSingleFile=true \
  -o ./publish/linux-arm64

# ARM32（较老的树莓派）
dotnet publish IoTGateway/IoTGateway.csproj \
  -c Release \
  -r linux-arm \
  --self-contained true \
  -o ./publish/linux-arm
```

### 部署到树莓派

```bash
# 拷贝到树莓派
scp -r ./publish/linux-arm64/* pi@192.168.1.100:/home/pi/iotgateway/

# SSH到树莓派，创建systemd服务（同Linux步骤）
ssh pi@192.168.1.100
sudo systemctl enable iotgateway
sudo systemctl start iotgateway
```

### ARM部署注意事项

1. **内存限制** - 树莓派4通常4-8GB内存，SQLite足够用，不建议使用大型数据库
2. **存储介质** - SD卡写入寿命有限，建议将数据库和日志挂载到USB硬盘
3. **散热** - 长时间运行需要注意散热，避免CPU降频
4. **时间同步** - ARM设备可能没有RTC电池，需要配置NTP

```bash
# 配置NTP时间同步
sudo timedatectl set-ntp true
sudo timedatectl set-timezone Asia/Shanghai
```

## Nginx反向代理配置

在生产环境中，建议在Kestrel前面放置Nginx作为反向代理：

```nginx
# /etc/nginx/sites-available/iotgateway

server {
    listen 80;
    server_name iot.example.com;

    # HTTP请求代理
    location / {
        proxy_pass http://127.0.0.1:518;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket支持（MQTT over WS）
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_read_timeout 300s;
    }
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/iotgateway /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## HTTPS配置

```nginx
server {
    listen 443 ssl http2;
    server_name iot.example.com;

    ssl_certificate /etc/ssl/certs/iot.example.com.crt;
    ssl_certificate_key /etc/ssl/private/iot.example.com.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    location / {
        proxy_pass http://127.0.0.1:518;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name iot.example.com;
    return 301 https://$host$request_uri;
}
```

## 常见问题

### Q: 端口被占用怎么办？

```bash
# 查看端口占用
sudo lsof -i :518
sudo lsof -i :1888

# 或者
sudo netstat -tlnp | grep 518
```

### Q: 权限不足？

```bash
# 检查文件权限
ls -la /opt/iotgateway/

# 修复权限
sudo chown -R iotgateway:iotgateway /opt/iotgateway/
```

### Q: 数据库文件锁定？

SQLite在写入时会锁定数据库文件。如果多个进程同时访问，可能出现锁定问题。确保只有一个IoTGateway实例访问同一个数据库文件。

## 小结

IoTGateway基于.NET 8.0和Kestrel服务器，天然支持跨平台部署。Windows环境推荐使用NSSM注册为服务，Linux环境推荐使用systemd管理，ARM边缘设备通过自包含发布实现免运行时安装。配合Nginx反向代理可以实现HTTPS和域名访问，满足工业环境的安全和可访问性要求。
