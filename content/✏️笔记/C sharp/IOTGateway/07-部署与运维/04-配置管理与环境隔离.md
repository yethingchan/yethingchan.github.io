## 配置管理与环境隔离

IoTGateway使用ASP.NET Core的标准配置体系，以`appsettings.json`为核心配置文件。在工业物联网项目中，开发环境、测试环境和生产环境通常需要不同的配置（数据库连接、MQTT参数、安全密钥等）。本章详细解析IoTGateway的配置体系和环境隔离策略。

## appsettings.json结构总览

IoTGateway的`appsettings.json`包含以下主要配置节：

```json
{
  "Logging": { },           // 日志配置
  "Connections": [ ],       // 数据库连接
  "CookiePre": "IoTGateway", // Cookie前缀
  "IsQuickDebug": false,    // 调试模式
  "EnableTenant": false,    // 多租户
  "CorsOptions": { },       // 跨域配置
  "Languages": "zh,en",     // 多语言
  "BlazorMode": "server",   // Blazor模式（预留）
  "UIOptions": { },         // UI配置
  "PageMode": "Tab",        // 页面模式
  "TabMode": "Simple",      // 标签模式
  "JwtOptions": { },        // JWT认证
  "CookieOptions": { },     // Cookie认证
  "Domains": { },           // 外部域名
  "FileUploadOptions": { }, // 文件上传
  "AppSettings": { }        // 自定义配置
}
```

## 数据库连接配置

### SQLite（默认）

```json
{
  "Connections": [
    {
      "Key": "default",
      "Value": "Data Source = ./data/iotgateway.db",
      "DbContext": "DataContext",
      "DBType": "SQLite"
    }
  ]
}
```

SQLite是IoTGateway的默认数据库，适合单机部署和边缘网关场景：
- 零配置，无需安装数据库服务器
- 数据库文件位于`./data/iotgateway.db`
- 适合中小规模数据量（数万设备变量以内）

### MySQL

```json
{
  "Connections": [
    {
      "Key": "default",
      "Value": "Server=localhost;Database=iotgateway;Uid=root;Pwd=your_password;",
      "DbContext": "DataContext",
      "DBType": "MySQL"
    }
  ]
}
```

### PostgreSQL

```json
{
  "Connections": [
    {
      "Key": "default",
      "Value": "Host=localhost;Database=iotgateway;Username=postgres;Password=your_password;",
      "DbContext": "DataContext",
      "DBType": "PostgreSQL"
    }
  ]
}
```

### SQL Server

```json
{
  "Connections": [
    {
      "Key": "default",
      "Value": "Server=localhost;Database=iotgateway;User Id=sa;Password=your_password;TrustServerCertificate=true;",
      "DbContext": "DataContext",
      "DBType": "SqlServer"
    }
  ]
}
```

### 多连接字符串

WTM框架支持配置多个数据库连接，IoTGateway通过`CSSelector`方法动态选择：

```json
{
  "Connections": [
    {
      "Key": "default",
      "Value": "Data Source = ./data/iotgateway.db",
      "DbContext": "DataContext",
      "DBType": "SQLite"
    },
    {
      "Key": "history",
      "Value": "Server=localhost;Database=iot_history;Uid=root;Pwd=password;",
      "DbContext": "HistoryContext",
      "DBType": "MySQL"
    }
  ]
}
```

在`Startup.cs`中的动态选择逻辑：

```csharp
public string CSSelector(ActionExecutingContext context)
{
    // 根据请求路径或租户信息返回不同的连接字符串Key
    if (context.HttpContext.Request.Path.StartsWithSegments("/api/history"))
    {
        return "history";
    }
    return null; // null表示使用default
}
```

## 认证配置

### Cookie认证（Web页面）

```json
{
  "CookieOptions": {
    "Issuer": "http://localhost",
    "Audience": "http://localhost",
    "Domain": "",
    "Expires": 3600,
    "SlidingExpiration": true,
    "SecurityKey": "superSecretKey@345",
    "RefreshTokenExpires": 86400,
    "LoginPath": "/Login/Login"
  }
}
```

| 配置项 | 说明 | 生产建议 |
|--------|------|---------|
| `Issuer` | 签发者 | 修改为实际域名 |
| `Audience` | 受众 | 修改为实际域名 |
| `Expires` | 过期时间（秒） | 3600（1小时） |
| `SlidingExpiration` | 滑动过期 | true，活跃用户不会过期 |
| `SecurityKey` | 签名密钥 | **必须修改为强随机字符串** |
| `LoginPath` | 登录页路径 | 默认即可 |

### JWT认证（API接口）

```json
{
  "JwtOptions": {
    "Issuer": "http://localhost",
    "Audience": "http://localhost",
    "Expires": 3600,
    "SecurityKey": "superSecretKey@345",
    "RefreshTokenExpires": 86400,
    "LoginPath": "/_Framework/Redirect401"
  }
}
```

JWT用于API接口的无状态认证，适用于：
- 外部系统调用IoTGateway API
- 移动端APP访问
- Swagger API调试

**安全注意：** 生产环境中必须修改`SecurityKey`为强密码，否则存在安全风险。

## 跨域配置（CORS）

```json
{
  "CorsOptions": {
    "EnableAll": true,
    "Policy": [
      {
        "Name": "Default",
        "Domain": "http://localhost,https://localhost"
      }
    ]
  }
}
```

- `EnableAll: true` - 允许所有来源（开发环境适用）
- 生产环境建议设置`EnableAll: false`并配置允许的域名

## UI配置

```json
{
  "UIOptions": {
    "DataTable": {
      "RPP": 20,           // 每页记录数（Records Per Page）
      "ShowPrint": true,    // 显示打印按钮
      "ShowFilter": true    // 显示筛选按钮
    },
    "ComboBox": {
      "DefaultEnableSearch": true  // 下拉框启用搜索
    },
    "DateTime": {
      "DefaultReadonly": true      // 日期选择器只读
    },
    "SearchPanel": {
      "DefaultExpand": false       // 搜索面板默认折叠
    }
  }
}
```

这些配置影响所有WTM TagHelper生成的页面，无需逐个视图修改。

## 文件上传配置

```json
{
  "IsFilePublic": false,
  "FileUploadOptions": {
    "UploadLimit": 2097152000,
    "SaveFileMode": "Local",
    "Settings": {
      "local": [
        {
          "GroupName": "default",
          "GroupLocation": "./files"
        }
      ],
      "oss": [
        {
          "GroupName": "default",
          "GroupLocation": "wtmimg",
          "ServerUrl": "",
          "Key": "",
          "Secret": ""
        }
      ]
    }
  }
}
```

| 配置项 | 说明 |
|--------|------|
| `IsFilePublic` | 是否需要登录才能下载文件 |
| `UploadLimit` | 上传大小限制（字节），当前约2GB |
| `SaveFileMode` | 存储方式：`Local`/`Database`/`oss` |
| `local.GroupLocation` | 本地存储路径 |
| `oss.*` | 对象存储（阿里云OSS等）配置 |

## 环境隔离

### ASP.NET Core环境变量

ASP.NET Core通过`ASPNETCORE_ENVIRONMENT`环境变量区分部署环境：

| 环境值 | 说明 | 配置文件 |
|--------|------|---------|
| `Development` | 开发环境 | `appsettings.Development.json` |
| `Staging` | 测试/预发布环境 | `appsettings.Staging.json` |
| `Production` | 生产环境 | `appsettings.Production.json` |

### 环境特定配置文件

配置文件的加载优先级为：
1. `appsettings.json` - 基础配置（始终加载）
2. `appsettings.{Environment}.json` - 环境特定配置（覆盖基础配置）
3. 环境变量 - 最高优先级
4. 命令行参数 - 最高优先级

**示例：`appsettings.Development.json`**

```json
{
  "Logging": {
    "Console": {
      "LogLevel": {
        "Default": "Debug"
      }
    }
  },
  "Connections": [
    {
      "Key": "default",
      "Value": "Data Source = ./data/iotgateway_dev.db",
      "DbContext": "DataContext",
      "DBType": "SQLite"
    }
  ],
  "IsQuickDebug": true,
  "JwtOptions": {
    "SecurityKey": "devKey123"
  }
}
```

**示例：`appsettings.Production.json`**

```json
{
  "Logging": {
    "Console": {
      "LogLevel": {
        "Default": "Warning"
      }
    }
  },
  "Connections": [
    {
      "Key": "default",
      "Value": "Server=db-server;Database=iotgateway;Uid=app;Pwd=strong_password;",
      "DbContext": "DataContext",
      "DBType": "MySQL"
    }
  ],
  "IsQuickDebug": false,
  "EnableTenant": false,
  "JwtOptions": {
    "Issuer": "https://iot.company.com",
    "Audience": "https://iot.company.com",
    "SecurityKey": "ProductionVeryLongAndRandomSecurityKey@2024!"
  },
  "CorsOptions": {
    "EnableAll": false,
    "Policy": [
      {
        "Name": "Default",
        "Domain": "https://iot.company.com,https://admin.company.com"
      }
    ]
  }
}
```

### 通过环境变量覆盖配置

在Docker或systemd中，可以使用环境变量覆盖配置，避免将敏感信息写入配置文件：

```bash
# Docker方式
docker run -d \
  -e ASPNETCORE_ENVIRONMENT=Production \
  -e Connections__0__Value="Server=db;Database=iot;Uid=app;Pwd=secret;" \
  -e JwtOptions__SecurityKey="MyProductionKey" \
  iotgateway:latest
```

```ini
# systemd方式
[Service]
Environment=ASPNETCORE_ENVIRONMENT=Production
Environment=Connections__0__Value=Server=db;Database=iot;Uid=app;Pwd=secret;
Environment=JwtOptions__SecurityKey=MyProductionKey
```

**环境变量命名规则：**
- 使用双下划线`__`表示JSON层级分隔
- 数组索引用数字表示
- 例如`Connections__0__Value`对应`Connections[0].Value`

## 多语言配置

IoTGateway支持中英文双语：

```json
{
  "Languages": "zh,en"
}
```

语言资源文件通过`IStringLocalizer`使用，资源文件存放在`Resources/`目录下。在Startup中注册多语言服务：

```csharp
services.AddWtmMultiLanguages(ConfigRoot);

// 在请求管道中启用
app.UseWtmMultiLanguages();
```

语言切换通过`/_Framework/SetLanguage`接口实现，用户可以在右上角的语言菜单中切换。

{

## 配置安全建议

### 生产环境必须修改的配置

| 配置项 | 默认值 | 建议 |
|--------|--------|------|
| `JwtOptions.SecurityKey` | `superSecretKey@345` | 修改为32位以上随机字符串 |
| `CookieOptions.SecurityKey` | `superSecretKey@345` | 同上 |
| `CorsOptions.EnableAll` | `true` | 改为`false`，配置允许的域名 |
| `IsQuickDebug` | `false` | 确保生产环境为`false` |
| `IsFilePublic` | `false` | 保持`false`，防止未授权下载 |
| 数据库连接字符串 | SQLite本地 | 生产环境使用强密码 |

### 敏感信息管理

不建议将密码和密钥直接写入配置文件。推荐方案：

1. **环境变量** - 最简单，适合Docker部署
2. **Secret Manager** - 开发环境使用
3. **Azure Key Vault** / **HashiCorp Vault** - 企业级密钥管理
4. **Docker Secrets** - Swarm/K8s环境

```bash
# .NET Secret Manager（开发环境）
dotnet user-secrets init
dotnet user-secrets set "JwtOptions:SecurityKey" "MyDevKey123"
```

## 小结

IoTGateway的配置体系以`appsettings.json`为核心，涵盖了数据库连接、认证授权、UI行为、文件管理等方面。通过环境特定的配置文件和环境变量覆盖机制，可以实现开发、测试、生产环境的完全隔离。在生产部署时，务必修改默认密钥、收紧CORS策略、确保调试模式关闭，以保障系统安全。
