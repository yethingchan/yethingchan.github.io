## 自定义驱动开发指南

IoTGateway采用插件化架构，添加新协议支持只需创建一个实现 `IDriver` 接口的DLL文件。本文将手把手教你从零开发一个自定义驱动插件。

---

## 开发前准备

### 环境要求

```
开发工具:
  - Visual Studio 2022 或 VS Code + C# Dev Kit
  - .NET 8 SDK
  - IoTGateway源码（用于参考和测试）

NuGet依赖:
  - PluginInterface 项目引用（IDriver接口和Attribute定义）
  - Microsoft.Extensions.Logging（日志）
  - 协议相关的第三方库
```

### 项目结构

创建一个新的Class Library项目：

```bash
# 创建驱动项目
dotnet new classlib -n PLC.MyProtocol -f net8.0
cd PLC.MyProtocol

# 添加PluginInterface引用
dotnet add reference ../PluginInterface/PluginInterface.csproj

# 添加日志库
dotnet add package Microsoft.Extensions.Logging.Abstractions
```

项目文件示例：

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
  </PropertyGroup>

  <ItemGroup>
    <ProjectReference Include="../../PluginInterface/PluginInterface.csproj" />
  </ItemGroup>

  <ItemGroup>
    <PackageReference Include="Microsoft.Extensions.Logging.Abstractions" Version="8.0.0" />
    <!-- 添加你需要的协议库 -->
    <PackageReference Include="YourProtocolLibrary" Version="1.0.0" />
  </ItemGroup>
</Project>
```

## 理解IDriver接口

### 接口定义

```csharp
// PluginInterface/IDriver.cs
public interface IDriver : IDisposable
{
    // 设备唯一标识（系统自动填充）
    public string DeviceId { get; }
    
    // 连接是否存活
    public bool IsConnected { get; }
    
    // 通信超时时间（毫秒）
    public int Timeout { get; }
    
    // 最小通信周期（毫秒）
    public uint MinPeriod { get; }

    // 日志记录器（系统注入）
    public ILogger _logger { get; set; }

    // 建立连接
    public bool Connect();

    // 关闭连接
    public bool Close();

    // 标准读取方法（必须实现）
    public DriverReturnValueModel Read(DriverAddressIoArgModel ioArg);

    // 异步写入方法（RPC远程调用）
    public Task<RpcResponse> WriteAsync(string RequestId, string Method,
        DriverAddressIoArgModel ioArg);
}
```

### 关键数据模型

```csharp
// 读写参数模型
public class DriverAddressIoArgModel
{
    public Guid ID { get; set; }           // 变量ID
    public string Address { get; set; }    // 地址字符串
    public object Value { get; set; }      // 写入值
    public DataTypeEnum ValueType { get; set; }  // 数据类型
    public EndianEnum EndianType { get; set; }   // 字节序
}

// 读取返回值模型
public class DriverReturnValueModel
{
    public VaribaleStatusTypeEnum StatusType { get; set; }  // 状态
    public object? Value { get; set; }                       // 值
    public object? CookedValue { get; set; }                 // 加工后的值
    public string? Message { get; set; }                     // 错误信息
}

// RPC响应模型
public class RpcResponse
{
    public bool IsSuccess { get; set; }       // 是否成功
    public string? Description { get; set; }  // 描述
}
```

## Attribute系统

IoTGateway使用自定义Attribute来实现驱动的自动发现和配置UI生成：

### 四种Attribute

```csharp
// 1. [DriverSupported] - 类级别，声明支持的设备类型（可多个）
[DriverSupported("DeviceTypeA")]
[DriverSupported("DeviceTypeB")]
// → 在Web UI中显示为设备类型下拉选项

// 2. [DriverInfo] - 类级别，驱动元信息
[DriverInfo("MyDriver", "V1.0.0", "Copyright MyCompany 2024")]
// → 在Web UI的驱动管理页面显示

// 3. [ConfigParameter] - 属性级别，配置参数
[ConfigParameter("IP地址")]
public string IpAddress { get; set; } = "127.0.0.1";
// → 在Web UI中自动生成为配置输入框
// → 属性的默认值会作为UI的默认值

// 4. [Method] - 方法级别，暴露读取方法
[Method("读数据", description: "读取设备数据")]
public DriverReturnValueModel ReadData(DriverAddressIoArgModel ioArg)
// → 在变量配置时可选择此读取方法
```

### Attribute源码

```csharp
// ConfigParameterAttribute.cs
[AttributeUsage(AttributeTargets.Property, Inherited = true, AllowMultiple = false)]
public class ConfigParameterAttribute : Attribute
{
    public string Description { get; }
    public ConfigParameterAttribute(string description)
    {
        Description = description;
    }
}

// MethodAttribute.cs
[AttributeUsage(AttributeTargets.Method, Inherited = false, AllowMultiple = false)]
public class MethodAttribute : Attribute
{
    public string Name { get; }
    public ProtectTypeEnum Protect_Type { get; }
    public string Description { get; }
    
    public MethodAttribute(string name, 
        ProtectTypeEnum protect_Type = ProtectTypeEnum.ReadOnly, 
        string description = "")
    {
        Name = name;
        Protect_Type = protect_Type;
        Description = description;
    }
}

// DriverSupportedAttribute.cs
[AttributeUsage(AttributeTargets.Class, Inherited = false, AllowMultiple = true)]
public class DriverSupportedAttribute : Attribute
{
    public string DAPName { get; }
    public DriverSupportedAttribute(string dAPName) { DAPName = dAPName; }
}

// DriverInfoAttribute.cs
[AttributeUsage(AttributeTargets.Class, Inherited = false, AllowMultiple = false)]
public class DriverInfoAttribute : Attribute
{
    public string Name { get; }
    public string Copyright { get; }
    public string Version { get; }
    
    public DriverInfoAttribute(string name, string version, string copyRight)
    {
        Name = name; Version = version; Copyright = copyRight;
    }
}
```

## 完整驱动开发示例

下面以开发一个**自定义TCP协议**驱动为例，演示完整的开发流程。

### 步骤1: 创建驱动类

```csharp
using Microsoft.Extensions.Logging;
using PluginInterface;
using System.Net.Sockets;
using System.Text;

namespace PLC.MyProtocol
{
    [DriverSupported("MyDevice")]
    [DriverInfo("MyProtocol", "V1.0.0", "Copyright MyCompany 2024")]
    public class DeviceMyProtocol : IDriver
    {
        private TcpClient? _tcpClient;
        private NetworkStream? _stream;

        public ILogger _logger { get; set; }
        private readonly string _device;

        #region 配置参数

        [ConfigParameter("设备Id")] 
        public string DeviceId { get; set; }

        [ConfigParameter("IP地址")] 
        public string IpAddress { get; set; } = "192.168.1.100";

        [ConfigParameter("端口号")] 
        public int Port { get; set; } = 5000;

        [ConfigParameter("超时时间ms")] 
        public int Timeout { get; set; } = 3000;

        [ConfigParameter("最小通讯周期ms")] 
        public uint MinPeriod { get; set; } = 1000;

        [ConfigParameter("通信协议头")] 
        public string ProtocolHeader { get; set; } = "ST";

        #endregion

        #region 构造函数（反射调用，签名必须匹配）

        /// <summary>
        /// 构造函数 - 必须接受(string, ILogger)两个参数
        /// DriverService通过反射调用此构造函数
        /// </summary>
        public DeviceMyProtocol(string device, ILogger logger)
        {
            _device = device;
            _logger = logger;
            _logger.LogInformation($"Device:[{_device}],Create()");
        }

        #endregion

        #region 连接管理

        public bool IsConnected => _tcpClient != null && _tcpClient.Connected;

        public bool Connect()
        {
            try
            {
                _logger.LogInformation($"Device:[{_device}],Connect()");
                
                _tcpClient = new TcpClient();
                _tcpClient.ReceiveTimeout = Timeout;
                _tcpClient.SendTimeout = Timeout;
                
                // 异步连接，同步等待
                var connectTask = _tcpClient.ConnectAsync(IpAddress, Port);
                if (!connectTask.Wait(Timeout))
                {
                    _logger.LogWarning($"Device:[{_device}],Connect timeout");
                    return false;
                }
                
                _stream = _tcpClient.GetStream();
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, $"Device:[{_device}],Connect(),Error");
                return false;
            }

            return IsConnected;
        }

        public bool Close()
        {
            try
            {
                _stream?.Close();
                _tcpClient?.Close();
                _logger.LogInformation($"Device:[{_device}],Close()");
                return !IsConnected;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, $"Device:[{_device}],Close(),Error");
                return false;
            }
        }

        public void Dispose()
        {
            try
            {
                _stream?.Dispose();
                _tcpClient?.Dispose();
                GC.SuppressFinalize(this);
                _logger.LogInformation($"Device:[{_device}],Dispose()");
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, $"Device:[{_device}],Dispose(),Error");
            }
        }

        #endregion

        #region 读写方法

        [Method("读取温度", description: "读取设备温度值")]
        public DriverReturnValueModel Read(DriverAddressIoArgModel ioArg)
        {
            var ret = new DriverReturnValueModel 
            { 
                StatusType = VaribaleStatusTypeEnum.Good 
            };

            if (!IsConnected)
            {
                ret.StatusType = VaribaleStatusTypeEnum.Bad;
                ret.Message = "设备未连接";
                return ret;
            }

            try
            {
                // 构建请求帧: ST + 地址 + 校验 + ET
                string request = $"{ProtocolHeader}|RD|{ioArg.Address}";
                byte[] sendBytes = Encoding.ASCII.GetBytes(request);
                
                _stream!.Write(sendBytes, 0, sendBytes.Length);
                
                // 读取响应
                byte[] buffer = new byte[1024];
                int bytesRead = _stream.Read(buffer, 0, buffer.Length);
                string response = Encoding.ASCII.GetString(buffer, 0, bytesRead);
                
                // 解析响应: ST|OK|值|ET
                var parts = response.Split('|');
                if (parts.Length >= 3 && parts[1] == "OK")
                {
                    ret.Value = ParseValue(parts[2], ioArg.ValueType);
                }
                else
                {
                    ret.StatusType = VaribaleStatusTypeEnum.Bad;
                    ret.Message = $"设备返回错误: {response}";
                }
            }
            catch (Exception ex)
            {
                ret.StatusType = VaribaleStatusTypeEnum.Bad;
                ret.Message = ex.Message;
                _logger.LogError(ex, $"Device:[{_device}],Read(),Error");
            }

            return ret;
        }

        [Method("读取状态", description: "读取设备运行状态")]
        public DriverReturnValueModel ReadStatus(DriverAddressIoArgModel ioArg)
        {
            var ret = new DriverReturnValueModel 
            { 
                StatusType = VaribaleStatusTypeEnum.Good 
            };

            if (!IsConnected)
            {
                ret.StatusType = VaribaleStatusTypeEnum.Bad;
                ret.Message = "设备未连接";
                return ret;
            }

            try
            {
                string request = $"{ProtocolHeader}|ST";
                byte[] sendBytes = Encoding.ASCII.GetBytes(request);
                _stream!.Write(sendBytes, 0, sendBytes.Length);

                byte[] buffer = new byte[256];
                int bytesRead = _stream.Read(buffer, 0, buffer.Length);
                string response = Encoding.ASCII.GetString(buffer, 0, bytesRead);

                ret.Value = response.Split('|')[2]; // 返回状态字符串
            }
            catch (Exception ex)
            {
                ret.StatusType = VaribaleStatusTypeEnum.Bad;
                ret.Message = ex.Message;
            }

            return ret;
        }

        #endregion

        #region 写入方法

        public async Task<RpcResponse> WriteAsync(string requestId, string method,
            DriverAddressIoArgModel ioArg)
        {
            var rpcResponse = new RpcResponse { IsSuccess = false };

            try
            {
                if (!IsConnected)
                {
                    rpcResponse.Description = "设备未连接";
                    return rpcResponse;
                }

                // 构建写入命令: ST|WR|地址|值|ET
                string command = $"{ProtocolHeader}|WR|{ioArg.Address}|{ioArg.Value}";
                byte[] sendBytes = Encoding.ASCII.GetBytes(command);
                
                await _stream!.WriteAsync(sendBytes, 0, sendBytes.Length);

                byte[] buffer = new byte[256];
                int bytesRead = await _stream.ReadAsync(buffer, 0, buffer.Length);
                string response = Encoding.ASCII.GetString(buffer, 0, bytesRead);

                if (response.Contains("OK"))
                    rpcResponse.IsSuccess = true;
                else
                    rpcResponse.Description = $"写入失败: {response}";
            }
            catch (Exception ex)
            {
                rpcResponse.Description = ex.Message;
                _logger.LogError(ex, $"Device:[{_device}],WriteAsync(),Error");
            }

            return rpcResponse;
        }

        #endregion

        #region 私有方法

        private object ParseValue(string rawValue, DataTypeEnum valueType)
        {
            return valueType switch
            {
                DataTypeEnum.Float => float.Parse(rawValue),
                DataTypeEnum.Int16 => short.Parse(rawValue),
                DataTypeEnum.Int32 => int.Parse(rawValue),
                DataTypeEnum.Uint16 => ushort.Parse(rawValue),
                DataTypeEnum.Uint32 => uint.Parse(rawValue),
                DataTypeEnum.Double => double.Parse(rawValue),
                DataTypeEnum.Bool => rawValue == "1" || rawValue.ToLower() == "true",
                _ => rawValue
            };
        }

        #endregion
    }
}
```

### 步骤2: 编译驱动DLL

```bash
cd PLC.MyProtocol
dotnet build -c Release

# 输出: bin/Release/net8.0/PLC.MyProtocol.dll
```

### 步骤3: 部署驱动

将编译好的DLL复制到IoTGateway的驱动目录：

```bash
# 复制到驱动目录
copy bin\Release\net8.0\PLC.MyProtocol.dll ^
     D:\path\to\iotgateway\IoTGateway\bin\Debug\net8.0\drivers\net8.0\

# 或者在发布时使用
dotnet publish -c Release -o ./publish
```

> **重要**：驱动DLL必须放在 `drivers/net8.0/` 目录下，DriverService启动时会扫描此目录加载所有实现了IDriver接口的DLL。

重启后，在Web管理界面中可以看到新驱动：

```
Web管理界面 → 驱动管理 → 查看驱动列表

应该可以看到:
  - PLC.MyProtocol.dll
  - 驱动名称: MyProtocol
  - 版本: V1.0.0
  - 支持设备: MyDevice
```

## 驱动开发最佳实践

### 1. 构造函数签名

```csharp
// 必须严格匹配: (string device, ILogger logger)
public DeviceMyProtocol(string device, ILogger logger)
{
    _device = device;
    _logger = logger;
}
```

DriverService通过反射查找此构造函数，签名不匹配将导致驱动加载失败。

### 2. 日志记录

每个关键操作都应该记录日志：

```csharp
// 生命周期日志
_logger.LogInformation($"Device:[{_device}],Create()");
_logger.LogInformation($"Device:[{_device}],Connect()");
_logger.LogInformation($"Device:[{_device}],Close()");
_logger.LogInformation($"Device:[{_device}],Dispose()");

// 错误日志
_logger.LogError(ex, $"Device:[{_device}],Read(),Error");

// 调试日志
_logger.LogDebug($"Device:[{_device}],Request:{hexString}");
```

### 3. 异常处理

所有通信操作必须包裹在try-catch中：

```csharp
public DriverReturnValueModel Read(DriverAddressIoArgModel ioArg)
{
    var ret = new DriverReturnValueModel 
    { 
        StatusType = VaribaleStatusTypeEnum.Good 
    };

    // 先检查连接状态
    if (!IsConnected)
    {
        ret.StatusType = VaribaleStatusTypeEnum.Bad;
        ret.Message = "设备未连接";
        return ret;
    }

    try
    {
        // 通信操作...
    }
    catch (TimeoutException)
    {
        ret.StatusType = VaribaleStatusTypeEnum.Bad;
        ret.Message = "通信超时";
    }
    catch (Exception ex)
    {
        ret.StatusType = VaribaleStatusTypeEnum.Bad;
        ret.Message = ex.Message;
        _logger.LogError(ex, "...");
    }

    return ret;
}
```

### 4. 资源管理

```csharp
public void Dispose()
{
    try
    {
        // 按顺序释放资源
        _stream?.Dispose();
        _tcpClient?.Dispose();
        
        // 抑制终结器（防止二次释放）
        GC.SuppressFinalize(this);
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "Dispose error");
    }
}
```

### 5. 连接状态检测

IsConnected应该真实检测连接状态，而不是简单返回一个布尔变量：

```csharp
// 好: 真实检测
public bool IsConnected => _tcpClient != null && _tcpClient.Connected;

// 差: 只在Connect时设置
private bool _connected;
public bool IsConnected => _connected;  // TCP断开后不会自动变false

// 最佳: 主动探测（如Fanuc驱动）
public bool IsConnected
{
    get
    {
        try
        {
            // 尝试读取一个轻量级数据来判断连接是否存活
            var result = _client.Ping();
            return result.IsSuccess;
        }
        catch { return false; }
    }
}
```

### 6. 数据类型支持

确保支持常用的数据类型：

```csharp
// 必须支持的类型
DataTypeEnum.Bool        // 布尔
DataTypeEnum.Int16       // 16位有符号整数
DataTypeEnum.Uint16      // 16位无符号整数
DataTypeEnum.Int32       // 32位有符号整数
DataTypeEnum.Uint32      // 32位无符号整数
DataTypeEnum.Float       // 32位浮点数
DataTypeEnum.AsciiString // ASCII字符串

// 可选支持的类型
DataTypeEnum.Double      // 64位浮点数
DataTypeEnum.Int64       // 64位有符号整数
DataTypeEnum.Uint64      // 64位无符号整数
DataTypeEnum.Utf8String  // UTF-8字符串
```

## 调试与测试

### 本地测试方法

```csharp
// 创建一个测试控制台项目
class Program
{
    static void Main()
    {
        var logger = LoggerFactory.Create(b => b.AddConsole()).CreateLogger<DeviceMyProtocol>();
        
        // 创建驱动实例
        var driver = new DeviceMyProtocol("TestDevice", logger);
        
        // 设置配置参数（模拟Web UI的配置输入）
        driver.IpAddress = "192.168.1.100";
        driver.Port = 5000;
        driver.Timeout = 3000;
        
        // 测试连接
        Console.WriteLine($"连接: {driver.Connect()}");
        Console.WriteLine($"状态: {driver.IsConnected}");
        
        // 测试读取
        var ioArg = new DriverAddressIoArgModel
        {
            Address = "TEMP_01",
            ValueType = DataTypeEnum.Float
        };
        var result = driver.Read(ioArg);
        Console.WriteLine($"读取结果: {result.Value}, 状态: {result.StatusType}");
        
        // 测试写入
        var writeArg = new DriverAddressIoArgModel
        {
            Address = "SET_POINT",
            Value = "25.5",
            ValueType = DataTypeEnum.Float
        };
        var writeResult = driver.WriteAsync("req1", "Read", writeArg).Result;
        Console.WriteLine($"写入结果: {writeResult.IsSuccess}");
        
        // 清理
        driver.Close();
        driver.Dispose();
    }
}
```
