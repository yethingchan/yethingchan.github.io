## 插件化架构

### 为什么需要插件化

在工业现场，你可能需要对接十几种不同品牌的PLC和仪表：西门子的S7协议、三菱的MC协议、欧姆龙的Fins协议、Modbus TCP/RTU、OPC UA等等。如果把所有协议代码都写在主程序中，每次新增一个协议就需要重新编译整个系统，这在生产环境中是不可接受的。

IoTGateway 通过插件化架构解决了这个问题：**新协议只需实现一个接口、编译一个DLL，放入指定目录即可自动发现**。

### 插件架构三层结构

```
┌─────────────────────────────────────────────────────┐
│           PluginInterface (契约层)                    │
│  IDriver / ConfigParameterAttribute / MethodAttribute │
│  DriverAddressIoArgModel / DriverReturnValueModel     │
│         (驱动开发者唯一需要引用的程序集)                 │
├─────────────────────────────────────────────────────┤
│           Plugin (运行时引擎)                         │
│  DriverService   → 驱动发现、加载、配置生成            │
│  DeviceService   → 驱动实例化、线程管理               │
│  DeviceThread    → 采集循环、RPC处理                  │
│  MessageService  → 数据上报、指令接收                 │
│         (主程序内部，驱动开发者无需了解)                 │
├─────────────────────────────────────────────────────┤
│           Drivers (协议驱动实现)                       │
│  PLC.ModBusMaster / PLC.SiemensS7 / OPC.UaClient      │
│  CNC.Fanuc / PLC.MelsecMc / PLC.OmronFins             │
│         (各自编译为独立DLL，运行时动态加载)              │
└─────────────────────────────────────────────────────┘
```

### IDriver 接口：驱动契约

`IDriver` 是所有驱动必须实现的接口，它定义了驱动的最小能力集：

```csharp
public interface IDriver : IDisposable
{
    // 基本信息
    public string DeviceId { get; }
    public bool IsConnected { get; }
    public int Timeout { get; }
    public uint MinPeriod { get; }
    public ILogger _logger { get; set; }

    // 连接管理
    public bool Connect();
    public bool Close();

    // 标准数据读取
    public DriverReturnValueModel Read(DriverAddressIoArgModel ioArg);

    // RPC写入（远程命令）
    public Task<RpcResponse> WriteAsync(string RequestId, string Method,
                                         DriverAddressIoArgModel ioArg);
}
```

#### 接口设计解析

| 成员 | 职责 | 上位机场景 |
|------|------|-----------|
| `IsConnected` | 报告连接状态 | DeviceThread根据此属性决定是读取还是重连 |
| `Connect()` | 建立物理连接 | 打开TCP Socket、串口等 |
| `Close()` | 关闭连接 | 释放Socket、串口资源 |
| `Read()` | 同步读取一个地址 | 轮询采集中逐变量读取 |
| `WriteAsync()` | 异步写入（RPC） | 远程控制设备参数 |
| `MinPeriod` | 最小轮询周期 | 限制采集频率，保护设备 |
| `IDisposable` | 资源释放 | 确保非托管资源被释放 |

### 自定义特性：驱动的元数据标注

IoTGateway 使用自定义 Attribute 来描述驱动的元数据，这些信息在运行时通过反射读取：

#### ConfigParameterAttribute - 配置参数标注

```csharp
[AttributeUsage(AttributeTargets.Property, Inherited = true)]
public class ConfigParameterAttribute : Attribute
{
    public string Description { get; }
    public ConfigParameterAttribute(string description)
    {
        Description = description;
    }
}
```

驱动开发者在自己的驱动类中这样使用：

```csharp
// 示例：Modbus驱动的配置参数
public class ModbusDriver : IDriver
{
    [ConfigParameter("IP地址")]
    public string IpAddress { get; set; }

    [ConfigParameter("端口号")]
    public int Port { get; set; } = 502;

    [ConfigParameter("站号")]
    public byte SlaveId { get; set; } = 1;

    // ... IDriver 实现
}
```

当用户添加设备并选择驱动时，`DriverService.AddConfigs()` 会通过反射扫描这些属性，自动生成 `DeviceConfig` 记录，填充到配置界面中。

#### MethodAttribute - 方法标注

```csharp
[AttributeUsage(AttributeTargets.Method, Inherited = false)]
public class MethodAttribute : Attribute
{
    public string Name { get; }
    public ProtectTypeEnum Protect_Type { get; }
    public string Description { get; }
}
```

驱动中的每个读取方法都需要标注 `MethodAttribute`，这样 `DeviceThread` 才能发现并创建委托：

```csharp
// 示例：Modbus驱动中的读取方法
[Method("ReadHoldingRegister", ProtectTypeEnum.ReadOnly, "读取保持寄存器")]
public DriverReturnValueModel ReadHoldingRegister(DriverAddressIoArgModel ioArg)
{
    // 实现 Modbus 03 功能码读取
}

[Method("WriteSingleRegister", ProtectTypeEnum.WriteOnly, "写入单个寄存器")]
public DriverReturnValueModel WriteSingleRegister(DriverAddressIoArgModel ioArg)
{
    // 实现 Modbus 06 功能码写入
}
```

#### DriverSupportedAttribute - 设备支持标注

```csharp
[AttributeUsage(AttributeTargets.Class, Inherited = false, AllowMultiple = true)]
public class DriverSupportedAttribute : Attribute
{
    public string DAPName { get; }
}
```

用于标注驱动支持的设备类型，便于前端进行分类展示。

### DriverService：驱动发现与加载

`DriverService` 是驱动管理的核心服务，负责在启动时扫描驱动目录，通过反射发现所有实现了 `IDriver` 接口的类。

```csharp
public class DriverService
{
    private readonly string _driverPath;
    private readonly string[] _driverFiles;
    private readonly List<DriverInfo> _driverInfos = new();

    public DriverService(IConfiguration configRoot, ILogger<DriverService> logger)
    {
        // 驱动DLL存放目录
        _driverPath = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "drivers/net8.0");
        _driverFiles = Directory.GetFiles(_driverPath, "*.dll");

        // 加载所有驱动
        LoadAllDrivers();
    }

    private void LoadAllDrivers()
    {
        foreach (var file in _driverFiles)
        {
            var dll = Assembly.LoadFrom(file);
            foreach (var type in dll.GetTypes()
                .Where(x => typeof(IDriver).IsAssignableFrom(x) && x.IsClass))
            {
                _driverInfos.Add(new DriverInfo
                {
                    FileName = Path.GetFileName(file),
                    Type = type
                });
            }
        }
    }
}
```

#### 反射加载流程

```
启动时扫描 drivers/net8.0/ 目录
    │
    ├── Assembly.LoadFrom("PLC.ModBusMaster.dll")
    │   └── 发现 ModbusTcpDriver : IDriver → 记录到 _driverInfos
    │
    ├── Assembly.LoadFrom("PLC.SiemensS7.dll")
    │   └── 发现 S7Driver : IDriver → 记录到 _driverInfos
    │
    ├── Assembly.LoadFrom("OPC.UaClient.dll")
    │   └── 发现 OpcUaDriver : IDriver → 记录到 _driverInfos
    │
    └── ... 其他驱动DLL
```

#### 配置参数自动生成

当用户创建新设备并选择驱动后，`AddConfigs` 方法会自动生成该驱动所需的所有配置项：

```csharp
public void AddConfigs(Guid? deviceId, Guid? driverId)
{
    // 通过反射获取驱动类型的 (string, ILogger) 构造函数
    var constructor = driverInfo.Type.GetConstructor(
        new[] { typeof(string), typeof(ILogger) });
    var instance = constructor.Invoke(
        new object[] { device?.DeviceName, _logger }) as IDriver;

    // 扫描所有带 ConfigParameterAttribute 的属性
    foreach (var property in driverInfo.Type.GetProperties())
    {
        var configAttribute = property.GetCustomAttribute<ConfigParameterAttribute>();
        if (configAttribute != null)
        {
            var deviceConfig = new DeviceConfig
            {
                DeviceId = deviceId,
                DeviceConfigName = property.Name,
                Description = configAttribute.Description,
                Value = property.GetValue(instance)?.ToString()
            };
            dc.Set<DeviceConfig>().Add(deviceConfig);
        }
    }
    dc.SaveChanges();
}
```

### DeviceService：驱动实例化与管理

`DeviceService` 在 `DriverService` 的基础上，负责为每个设备创建具体的驱动实例和采集线程：

```csharp
public void CreateDeviceThread(Device device)
{
    // 1. 从 DriverInfos 中找到对应的驱动类型
    var driverInfo = DriverManager.DriverInfos
        .SingleOrDefault(x => x.Type.FullName == device.Driver?.AssembleName);

    // 2. 通过反射创建驱动实例
    var constructor = driverInfo.Type.GetConstructor(
        new Type[] { typeof(string), typeof(ILogger) });
    var driverInstance = constructor?.Invoke(
        new object[] { device.DeviceName, _logger }) as IDriver;

    // 3. 通过反射为配置属性赋值
    foreach (var property in driverInfo.Type.GetProperties())
    {
        if (property.GetCustomAttribute<ConfigParameterAttribute>() is null)
            continue;
        var setting = settings.FirstOrDefault(x => x.DeviceConfigName == property.Name);
        var convertedValue = ConvertSettingValue(property.PropertyType, setting.Value);
        property.SetValue(driverInstance, convertedValue);
    }

    // 4. 创建 DeviceThread 并启动采集
    var deviceThread = new DeviceThread(device, driverInstance, ...);
    DeviceThreads.Add(deviceThread);
}
```

#### 配置值类型转换

由于 `DeviceConfig` 中所有配置值都以字符串形式存储，`ConvertSettingValue` 方法负责将字符串转换为驱动属性所需的目标类型：

```csharp
private object ConvertSettingValue(Type targetType, string value)
{
    if (targetType == typeof(int)) return int.Parse(value);
    if (targetType == typeof(bool)) return value != "0";
    if (targetType == typeof(IPAddress)) return IPAddress.Parse(value);
    if (targetType.IsEnum) return Enum.Parse(targetType, value);
    // ... 其他类型
}
```


### 驱动开发规范总结

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 创建类库项目 | 目标框架 net8.0，仅引用 PluginInterface |
| 2 | 实现 IDriver | 实现 Connect/Close/Read/WriteAsync |
| 3 | 标注 ConfigParameter | 在配置属性上添加 `[ConfigParameter("描述")]` |
| 4 | 标注 Method | 在读取方法上添加 `[Method("方法名")]` |
| 5 | 标注 DriverSupported | 在类上添加 `[DriverSupported("设备类型")]` |
| 6 | 编译为DLL | 输出到 `drivers/net8.0/` 目录 |
| 7 | 在管理界面添加驱动 | 系统自动发现并提供选择 |

### 安全性考量

1. **构造函数约定**：驱动必须提供 `(string, ILogger)` 签名的构造函数
2. **类型安全**：`ConvertSettingValue` 对不支持的类型抛出 `NotSupportedException`
3. **异常隔离**：每个 `DeviceThread` 独立运行，一个驱动崩溃不影响其他设备
4. **超时保护**：`IDriver.Timeout` 属性限制单次读写操作的最大耗时
