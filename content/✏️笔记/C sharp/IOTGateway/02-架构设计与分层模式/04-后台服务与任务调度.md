## 后台服务与任务调度

### 后台服务在工业上位机中的角色

工业上位机与普通Web应用的最大区别在于：**它不仅要处理HTTP请求，还需要在后台持续运行设备数据采集循环**。IoTGateway 使用了 ASP.NET Core 的 `BackgroundService` 机制来管理这些长时间运行的后台任务。

### 后台服务总览


### IoTBackgroundService：启动入口

`IoTBackgroundService` 继承自 `BackgroundService`，是整个后台服务体系的启动入口。

```csharp
public class IoTBackgroundService : BackgroundService
{
    public static DBTypeEnum DbType;
    public static string connnectSetting;
    private readonly IHostApplicationLifetime _appLifeTime;
    private readonly IServiceProvider _serviceProvider;

    public IoTBackgroundService(IConfiguration configRoot,
        IHostApplicationLifetime appLifeTime,
        IServiceProvider serviceProvider)
    {
        // 1. 解析数据库连接配置
        var connnectSettings = new List<ConnnectSettingsModel>();
        configRoot.Bind("Connections", connnectSettings);
        connnectSetting = connnectSettings[0].Value;

        // 2. 根据配置确定数据库类型
        switch (connnectSettings[0].DbType?.Trim().ToLower())
        {
            case "oracle": DbType = DBTypeEnum.Oracle; break;
            case "mysql":  DbType = DBTypeEnum.MySql;  break;
            case "pgsql":  DbType = DBTypeEnum.PgSql;  break;
            case "sqlite": DbType = DBTypeEnum.SQLite;  break;
            case "dameng": DbType = DBTypeEnum.DaMeng;  break;
        }

        // 3. SQLite模式下自动执行迁移
        if (DbType == DBTypeEnum.SQLite)
        {
            using var dc = new DataContext(connnectSetting, DbType);
            if (dc.Database.GetPendingMigrations().Any())
                dc.Database.Migrate();
        }
    }

    public override Task StartAsync(CancellationToken cancellationToken)
    {
        // 注册应用启动完成回调
        _appLifeTime.ApplicationStarted.Register(OnStarted);
        return Task.CompletedTask;
    }

    protected override Task ExecuteAsync(CancellationToken stoppingToken)
    {
        return Task.CompletedTask; // 不使用ExecuteAsync
    }

    private void OnStarted()
    {
        // 应用启动完成后，触发核心服务初始化
        _ = _serviceProvider.GetRequiredService<DeviceService>();
        _ = _serviceProvider.GetRequiredService<ModbusSlaveService>();
    }
}
```

#### 启动顺序解析

```
1. 构造函数执行（服务注册阶段）
   ├── 读取 appsettings.json 中的 Connections 配置
   ├── 解析数据库类型
   └── SQLite: 检查并执行Pending Migrations
       │
2. StartAsync() 被调用
   └── 注册 ApplicationStarted 回调
       │
3. 应用完全启动后 OnStarted() 被调用
   ├── GetRequiredService<DeviceService>() → 触发设备加载
   └── GetRequiredService<ModbusSlaveService>() → 启动Modbus从站
```

> **为什么不用 `ExecuteAsync`？** 因为 `IoTBackgroundService` 的核心工作是**初始化**，而不是运行一个长循环。真正的采集循环在各个 `DeviceThread` 中运行。

### DeviceService：设备线程管理器

`DeviceService` 是设备采集的管理中心，负责创建、更新和销毁 `DeviceThread`。

```csharp
public class DeviceService : IDisposable
{
    public List<DeviceThread> DeviceThreads { get; } = new();
    public DriverService DriverManager;
    private readonly MessageService _messageService;

    public DeviceService(IConfiguration configRoot,
        DriverService driverManager,
        MessageService messageService,
        MqttServer mqttServer,
        ILogger<DeviceService> logger)
    {
        DriverManager = driverManager;
        _messageService = messageService;
        CreateDeviceThreads(); // 构造时立即加载所有设备
    }

    public void CreateDeviceThreads()
    {
        using var dc = new DataContext(_connectSetting, _dbType);
        var devices = dc.Set<Device>()
            .Where(x => x.DeviceTypeEnum == DeviceTypeEnum.Device)
            .Include(x => x.Driver)
            .Include(x => x.DeviceConfigs)
            .Include(x => x.DeviceVariables)
            .AsNoTracking()
            .ToList();

        foreach (var device in devices)
            CreateDeviceThread(device);
    }
}
```

#### 设备热更新

当用户通过Web界面修改设备配置后，`DeviceService` 提供了热更新能力，无需重启应用：

```csharp
public void UpdateDevice(Device device)
{
    RemoveDeviceThread(device);  // 1. 停止旧线程
    CreateDeviceThread(device);  // 2. 创建新线程
}

public void RemoveDeviceThread(Device device)
{
    var deviceThread = DeviceThreads.FirstOrDefault(x => x.Device.ID == device.ID);
    if (deviceThread != null)
    {
        deviceThread.StopThread();  // 取消Token + 关闭驱动
        deviceThread.Dispose();      // 释放资源
        DeviceThreads.Remove(deviceThread);
    }
}
```

### DeviceThread：核心采集循环

`DeviceThread` 是整个系统中最核心的类，每个设备实例对应一个 `DeviceThread`，它运行着一个独立的异步采集循环。

```csharp
public class DeviceThread : IDisposable
{
    public readonly Device Device;
    public readonly IDriver Driver;
    private readonly CancellationTokenSource _tokenSource = new();
    private readonly ManualResetEventSlim _resetEvent = new(true);
    private Task _task;

    // 方法委托缓存
    public readonly Dictionary<string,
        Func<DriverAddressIoArgModel, DriverReturnValueModel>> MethodDelegates;

    public DeviceThread(Device device, IDriver driver, ...)
    {
        // 1. 订阅RPC事件
        _messageService.OnExcRpc += MyMqttClient_OnExcRpc;

        // 2. 缓存驱动方法的委托（避免运行时反射）
        MethodDelegates = new Dictionary<string,
            Func<DriverAddressIoArgModel, DriverReturnValueModel>>();
        foreach (var methodInfo in Driver.GetType().GetMethods()
            .Where(x => x.GetCustomAttribute(typeof(MethodAttribute)) != null))
        {
            var del = (Func<DriverAddressIoArgModel, DriverReturnValueModel>)
                Delegate.CreateDelegate(
                    typeof(Func<DriverAddressIoArgModel, DriverReturnValueModel>),
                    Driver, methodInfo);
            MethodDelegates[methodInfo.Name] = del;
        }

        // 3. 如果设备设置为自启动，启动采集循环
        if (Device.AutoStart)
            _task = CreateThreadAsync(_tokenSource.Token);
    }
}
```

#### 采集循环详解

```csharp
private async Task CreateThreadAsync(CancellationToken token)
{
    await Task.Delay(5000, token); // 启动延迟5秒

    // 上传客户端属性（设备配置信息）
    foreach (var group in Device.DeviceVariables.GroupBy(x => x.Alias))
    {
        var configDict = Device.DeviceConfigs
            .Where(x => x.DataSide == DataSide.ClientSide || x.DataSide == DataSide.AnySide)
            .ToDictionary(x => x.DeviceConfigName, x => x.Value);
        await _messageService.UploadAttributeAsync(deviceName, configDict);
    }

    // 主采集循环
    while (!token.IsCancellationRequested)
    {
        _resetEvent.Wait(token); // 等待RPC操作完成

        if (Driver.IsConnected)
        {
            // 按Alias分组，逐组读取变量
            foreach (var group in Device.DeviceVariables
                .Where(x => x.ProtectType != ProtectTypeEnum.WriteOnly)
                .GroupBy(x => x.Alias))
            {
                // 读取触发变量
                var triggerVars = group.Where(x => x.IsTrigger).ToList();
                await ReadVariablesAsync(triggerVars, ...);

                // 触发条件满足时读取非触发变量
                if (triggerValues.Values.Any(x => x is true) || !triggerVars.Any())
                {
                    var nonTriggerVars = group.Where(x => !triggerVars...).ToList();
                    await ReadVariablesAsync(nonTriggerVars, ...);
                    canPub = true;
                }

                // 发布遥测数据
                if (canPub)
                    await _messageService.PublishTelemetryAsync(...);
            }

            // 死连接检测：连续60秒无成功读取则断开重连
            if (all variables Bad && DateTime.UtcNow - _lastGoodTime > 60s)
            {
                Driver.Close();
                Driver.Dispose();
            }
        }
        else
        {
            // 尝试重连
            if (Driver.Connect())
                _messageService.DeviceConnected(deviceName, Device);
        }

        await Task.Delay(Device.DeviceVariables.Any() ? (int)Driver.MinPeriod : 10000, token);
    }
}
```

#### 采集循环流程图

```
启动延迟5秒
    │
    ├── 上传客户端属性
    │
    ▼
┌──→ 等待 _resetEvent（RPC暂停点）
│       │
│       ├── Driver.IsConnected == true ?
│       │   ├── YES: 逐组读取变量
│       │   │       ├── 读取触发变量
│       │   │       ├── 触发条件满足 → 读取普通变量
│       │   │       ├── 表达式计算
│       │   │       ├── 发布遥测数据
│       │   │       └── 死连接检测
│       │   │
│       │   └── NO:  通知断线 → Driver.Connect() → 重连
│       │
│       ▼
│   await Task.Delay(MinPeriod)
│       │
└───────┘ (循环直到 CancellationToken 触发)
```

### 变量读取与表达式计算

```csharp
private async Task ReadVariablesAsync(List<DeviceVariable> variables, ...)
{
    foreach (var item in variables.OrderBy(x => x.Index))
    {
        // 1. 通过委托缓存调用驱动方法（无反射开销）
        if (MethodDelegates.TryGetValue(item.Method, out var methodDelegate))
            ret = methodDelegate(ioarg);

        // 2. 环形缓冲区记录最近三次值
        item.EnqueueVariable(ret.Value);

        // 3. 表达式计算（如：温度 = 原值 * 0.1）
        if (ret.StatusType == VaribaleStatusTypeEnum.Good
            && !string.IsNullOrWhiteSpace(item.Expressions?.Trim()))
        {
            expressionText = item.Expressions.GetExpressionText(item.Values, ...);
            ret.CookedValue = _interpreter.Eval(expressionText);
        }

        item.EnqueueCookedVariable(ret.CookedValue);

        // 4. 变化检测：值变化时通过内置MQTT推送前端
        if (ValueChanged(item))
        {
            var msg = new InjectedMqttApplicationMessage(
                new MqttApplicationMessage()
                {
                    Topic = $"internal/v1/gateway/telemetry/{Device.DeviceName}/{item.Name}",
                    PayloadSegment = Encoding.UTF8.GetBytes(JsonConvert.SerializeObject(ret))
                });
            mqttServer.InjectApplicationMessage(msg);
        }

        // 5. 指令间隔延迟
        await Task.Delay((int)Device.CmdPeriod, token);
    }
}
```

### RPC指令处理

当云平台下发写入指令时，`DeviceThread` 通过事件机制接收并处理：

```csharp
public async void MyMqttClient_OnExcRpc(object sender, RpcRequest e)
{
    // 仅处理属于当前设备的RPC请求
    if (e.DeviceName != Device.DeviceName && ...)
        return;

    if (e.Method.ToLower() == "write")
    {
        _resetEvent.Reset(); // 暂停采集循环

        if (!Driver.IsConnected)
            Driver.Connect();

        foreach (var para in e.Params)
        {
            var variable = Device.DeviceVariables
                .FirstOrDefault(x => x.Name == para.Key);
            if (variable != null && variable.ProtectType != ProtectTypeEnum.ReadOnly)
            {
                var writeResponse = await Driver.WriteAsync(e.RequestId, variable.Method, ioArgModel);
                rpcResponse.IsSuccess = writeResponse.IsSuccess;
            }
        }

        _resetEvent.Set(); // 恢复采集循环
    }

    await _messageService.ResponseRpcAsync(rpcResponse);

    // 记录RPC日志
    await using var dc = new DataContext(...);
    dc.Set<RpcLog>().Add(rpcLog);
    await dc.SaveChangesAsync();
}
```

### 后台服务注册

在 `Startup.cs` 中，后台服务的注册方式各不相同：

```csharp
// BackgroundService 方式（框架自动管理生命周期）
services.AddHostedService<IoTBackgroundService>();

// Singleton 方式（手动管理，通过ServiceProvider获取）
services.AddSingleton<DeviceService>();
services.AddSingleton<DriverService>();
services.AddSingleton<MessageService>();
services.AddSingleton<ModbusSlaveService>();
```

> **为什么 DeviceService 不用 AddHostedService？** 因为 `DeviceService` 需要被 ViewModel 层通过 `ServiceProvider` 访问（用于热更新设备），而 `BackgroundService` 注册的服务不在常规DI容器中暴露。

### CancellationToken 与优雅停机

```
应用关闭信号
    │
    ├── BackgroundService.StoppingToken 触发
    │
    ├── DeviceThread._tokenSource.Cancel()
    │   ├── while循环退出
    │   ├── Driver.Close()
    │   └── _messageService.OnExcRpc -= handler（取消事件订阅）
    │
    └── DeviceService.Dispose()
        ├── 遍历所有DeviceThread
        ├── thread.StopThread()
        └── thread.Dispose()
```
