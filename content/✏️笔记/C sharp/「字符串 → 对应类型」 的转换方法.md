好！我给你整理**最常用、最实用、和 `int.Parse` 同一类的 C# 格式转换方法**，全部列表给你，一看就懂、直接能用！

它们全部都是 **「字符串 → 对应类型」** 的转换方法，和 `int.Parse` 用法**完全一样**！

---

# 一、和 int.Parse 同类的 **Parse 方法大全**
## 1. `int.Parse(字符串)`
转 **整数**
```csharp
int a = int.Parse("100");
```

## 2. `double.Parse(字符串)`
转 **小数/双精度浮点数**
```csharp
double d = double.Parse("3.14");
```

## 3. `float.Parse(字符串)`
转 **单精度浮点数**
```csharp
float f = float.Parse("2.5");
```

## 4. `decimal.Parse(字符串)`
转 **高精度小数（钱、金额专用）**
```csharp
decimal money = decimal.Parse("99.5");
```

## 5. `bool.Parse(字符串)`
转 **布尔值（true/false）**
```csharp
bool b = bool.Parse("true");
```

## 6. `long.Parse(字符串)`
转 **长整数（很大的整数）**
```csharp
long l = long.Parse("1234567890123");
```

## 7. `byte.Parse(字符串)`
转 **字节（0~255）**
```csharp
byte b = byte.Parse("255");
```

## 8. `short.Parse(字符串)`
转 **短整数**
```csharp
short s = short.Parse("100");
```

## 9. `DateTime.Parse(字符串)`
转 **日期时间**（超级常用）
```csharp
DateTime time = DateTime.Parse("2025-05-24");
```

## 10. `TimeSpan.Parse(字符串)`
转 **时间间隔（小时:分钟:秒）**
```csharp
TimeSpan ts = TimeSpan.Parse("2:30:00");
```

# 二、更安全的版本：**TryParse（不会报错！）**
所有 Parse 都有对应的 **TryParse**，推荐优先用！

## 例子：
```csharp
int a;
bool success = int.TryParse("123", out a);
```

## 全部对应：
- `int.TryParse`
- `double.TryParse`
- `decimal.TryParse`
- `bool.TryParse`
- `long.TryParse`
- `DateTime.TryParse`
- `byte.TryParse`
- ...所有类型都有

# 三、最简单记忆法
### **所有 C# 基本类型，几乎都自带：**
**类型.Parse(字符串)**  
**类型.TryParse(字符串, out 变量)**
