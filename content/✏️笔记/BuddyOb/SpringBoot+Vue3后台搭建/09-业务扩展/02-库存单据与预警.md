# 09-2 库存单据（入库 / 出库 / 盘点）与库存预警

> 上接：[[SpringBoot+Vue3后台搭建/09-业务扩展/01-物料与库位管理(Locations)]]
> 单据（订单/凭证）是企业系统的"业务动作载体"：任何库存变化都必须有**单据**留痕，不能裸改库存表。本文件讲清"单据 → 库存联动 → 预警"的完整链路。

## 2.1 单据表设计

一张主表 + 一张明细表（标准做法：一张单有多行物料）：

```sql
-- 库存单据主表
CREATE TABLE wms_stock_bill (
  bill_id     BIGINT PRIMARY KEY AUTO_INCREMENT,
  bill_no     VARCHAR(64) NOT NULL COMMENT '单号(系统生成)',
  bill_type   CHAR(1)     NOT NULL COMMENT '1入库 2出库 3盘点',
  status      CHAR(1)     DEFAULT '0' COMMENT '0草稿 1已提交 2已完成',
  remark      VARCHAR(255) DEFAULT '',
  create_by   VARCHAR(64),
  create_time DATETIME    DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_bill_no (bill_no)
) COMMENT='库存单据';

-- 单据明细（一行一个物料+数量+库位）
CREATE TABLE wms_stock_bill_item (
  item_id  BIGINT PRIMARY KEY AUTO_INCREMENT,
  bill_id  BIGINT NOT NULL,
  mat_id   BIGINT NOT NULL,
  loc_id   BIGINT NOT NULL,
  qty      INT    NOT NULL COMMENT '数量',
  del_flag CHAR(1) DEFAULT '0'
) COMMENT='单据明细';
```

## 2.2 单据提交 → 库存联动（核心事务）

关键点：**单据"完成"时才改库存**，且必须用 `@Transactional` 保证"明细循环改库存"要么全成、要么全回滚。

```java
@Service
public class StockBillServiceImpl extends ServiceImpl<StockBillMapper, WmsStockBill>
        implements IStockBillService {

    @Resource private IStockBillItemService itemService;
    @Resource private IInventoryService invService;

    /** 提交单据：草稿→完成，并联动库存 */
    @Transactional(rollbackFor = Exception.class)
    public void submit(Long billId) {
        WmsStockBill bill = this.getById(billId);
        if (bill == null || !"0".equals(bill.getStatus()))
            throw new BusinessException("单据不存在或已处理");

        List<WmsStockBillItem> items = itemService.list(
            Wrappers.lambdaQuery(WmsStockBillItem.class).eq(WmsStockBillItem::getBillId, billId));

        for (WmsStockBillItem it : items) {
            if ("1".equals(bill.getBillType()))      // 入库：+
                invService.changeQty(it.getMatId(), it.getLocId(), it.getQty());
            else if ("2".equals(bill.getBillType())) // 出库：-
                invService.changeQty(it.getMatId(), it.getLocId(), -it.getQty());
            // 盘点(type=3)：直接计算差额并 set，略
        }
        bill.setStatus("2");
        this.updateById(bill);
    }
}
```

```java
@Service
public class InventoryServiceImpl extends ServiceImpl<InventoryMapper, WmsInventory>
        implements IInventoryService {

    /** 库存增减：没有记录就插入，有就更新（乐观锁可加 version 字段防并发超卖） */
    @Transactional(rollbackFor = Exception.class)
    public void changeQty(Long matId, Long locId, int delta) {
        WmsInventory inv = this.getOne(Wrappers.lambdaQuery(WmsInventory.class)
            .eq(WmsInventory::getMatId, matId).eq(WmsInventory::getLocId, locId));
        if (inv == null) {
            if (delta < 0) throw new BusinessException("库存不足");
            inv = new WmsInventory(); inv.setMatId(matId); inv.setLocId(locId);
            inv.setQty(delta); this.save(inv);
        } else {
            int after = inv.getQty() + delta;
            if (after < 0) throw new BusinessException("库存不足，出库失败");
            inv.setQty(after); this.updateById(inv);
        }
        // 改完立刻检查预警（见 2.4）
        checkAlert(matId);
    }
}
```

**讲解**
- `@Transactional(rollbackFor=Exception.class)`：循环里任意一行失败（如库存不足抛异常），前面已改的库存**整体回滚**——这是财务级数据正确性的底线。
- 库存用"有则更、无则插"+ 负数校验，避免出库成负数。工业场景再加 `version` 乐观锁或 `UPDATE ... SET qty=qty+? WHERE qty+?>=0` 防并发超卖。

## 2.3 单据 Controller（提交接口）

```java
@RestController
@RequestMapping("/wms/bill")
public class StockBillController {
    @Resource private IStockBillService billService;

    @PreAuthorize("hasPermi('wms:bill:list')")
    @GetMapping("/list")
    public R<WmsStockBill> list(WmsStockBill q, PageQuery pq) {
        return R.ok(billService.page(new Page<>(pq.getPageNum(), pq.getPageSize()),
            Wrappers.lambdaQuery(q).orderByDesc(WmsStockBill::getCreateTime)));
    }

    @PreAuthorize("hasPermi('wms:bill:submit')")
    @PutMapping("/submit/{billId}")
    public AjaxResult submit(@PathVariable Long billId) {
        billService.submit(billId);
        return AjaxResult.success("单据已提交，库存已更新");
    }

    @PreAuthorize("hasPermi('wms:bill:add')")
    @PostMapping
    public AjaxResult add(@RequestBody WmsStockBill bill) {
        bill.setBillNo("B" + System.currentTimeMillis()); // 简单单号生成
        bill.setStatus("0");
        billService.save(bill);
        return AjaxResult.success();
    }
}
```

## 2.4 库存预警（低于安全库存自动提醒）

两种触发：① 每次库存变动后即时查（上面 `checkAlert`）；② 定时全量扫（用 [[../06-系统工具/03-Swagger接口文档与Quartz定时任务]] 的 Quartz 每天跑）。这里给即时查 + 写预警表：

```java
@Resource private WmsMaterialMapper materialMapper;
@Resource private RedisCache redisCache;

/** 库存低于物料 safe_qty → 写预警 + 推 Redis 通道（前端可订阅弹窗） */
public void checkAlert(Long matId) {
    WmsMaterial m = materialMapper.selectById(matId);
    int totalQty = this.list(Wrappers.lambdaQuery(WmsInventory.class)
        .eq(WmsInventory::getMatId, matId))
        .stream().mapToInt(WmsInventory::getQty).sum();
    if (m != null && totalQty < m.getSafeQty()) {
        String key = "wms:alert:" + matId;
        // 用 Redis 去重：同一物料 1 小时内只报一次，避免刷屏
        if (!redisCache.hasKey(key)) {
            redisCache.setCacheObject(key, true, 1, TimeUnit.HOURS);
            // 写操作日志（[[../07-日志与监控/01-操作日志与登录日志]] 的 LogAspect 会记录）
            log.warn("库存预警：物料{} 当前{} 低于安全库存{}", m.getMatName(), totalQty, m.getSafeQty());
            // 这里也可插入 wms_alert 表 / 发站内信 / 调企业微信机器人
        }
    }
}
```

> 预警"落地方式"任选：① 写 `wms_alert` 表供后台"预警列表"页查；② 进操作日志；③ 发消息（站内信/邮件/钉钉/企微）。企业项目一般用消息中心，本教程先用 Redis 去重 + 日志，够用且清晰。
