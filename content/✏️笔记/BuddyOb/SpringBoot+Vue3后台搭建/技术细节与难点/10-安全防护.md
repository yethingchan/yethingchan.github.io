# 10 安全防护 · 技术细节与难点

> 配套原教程：[[../10-安全防护/00-索引]]（密码加密/防暴破/IP 黑名单 / XSS+SQL 注入 / Token 强化+防重复提交 / 上传拦截+限流）
> 本篇是**工程的"护城河"**——讲**BCrypt 盐怎么管、分布式锁怎么原子、XSS 和富文本怎么两全、限流精度怎么选**。

## 一、技术细节

### 10.1 密码加密
**BCrypt / Argon2**：加盐哈希，不存明文。BCrypt **自带盐**（hash 里就含盐），`matches(raw, hash)` 验证，你不用自己拼盐。

### 10.2 防暴破 + IP 黑名单
`Redis` 计数：`INCR key(username|ip)` + `EXPIRE`（如 5 分钟），超阈值（如 5 次）→ 锁账号/IP。IP 黑名单直接拒。

### 10.3 XSS + SQL 注入
- **XSS**：`HttpServletRequestWrapper` 装饰器重写 `getParameter/getHeader`，用 **OWASP Encoder** 按上下文（HTML/JS/URL）编码；`HttpOnly` Cookie；富文本用 **Jsoup 白名单** 过滤。
- **SQL 注入**：MyBatis **`#{}` 预编译（? 占位符）**，输入永远当"数据"不当"代码"；`QueryWrapper` 同理参数化。关键字拦截器作辅助。

### 10.4 Token 强化 + 防重复提交
- **绑定 IP/UA**：token `claims` 里塞 `ip/ua`，校验时比对，防盗用。
- **单点登录**：同账号新登录覆盖 Redis 里旧 token → 旧端下次 401。
- **防重放**：`nonce` / 时间戳窗口（5–15s）。
- **防重复提交**：分布式锁（`SET NX EX` / Redisson）或重放 token（提交前发、提交后销毁）。

### 10.5 上传拦截 + 限流
- **上传**：后缀白名单 + MIME + 大小 + **UUID 随机名** + 存根目录**外** + 禁执行。
- **限流**：令牌桶/漏桶；注解 + 拦截器 + Redis 计数（滑动/固定窗口）。

## 二、技术难点

1. **BCrypt 盐**：千万别自己生成盐拼进去——`BCryptPasswordEncoder` **自动盐**，`matches` 会从 hash 里解出盐比对。自己拼只会验证失败。
2. **分布式锁原子性（最易错）**：`SET key value NX EX` 是**原子**的（设值+过期一步），用对命令才防死锁；**释放要用 Lua 校验 value 再删**（防误删别人的锁）。Redisson 封装得更好。
3. **XSS 与富文本冲突**：公告/论坛要存 HTML，全转义会丢格式。**解法**：Jsoup **白名单**（只允许 `b/p/img/br` 等安全标签）而非裸转义。
4. **SQL 注入拦截误杀**：拦截器扫 `or/union/select` 易误杀正常业务（如搜商品名 `"xxx or yyy"`）。**解法**：以 `#{}` 预编译为主（根上免疫），关键字拦截只作辅助、且只在出现危险组合（`' or '1'='1'`）时才拦。
5. **Token 单点体验**：同账号多端，新登录覆盖旧 token → 旧端下次请求 401。前端需感知"被踢"重登（联动 [[技术细节与难点/04-权限管理]] 的踢人）。
6. **防重放时间窗**：窗口太严（延迟误杀）/太松（失效）要权衡，取 **5–15s**。
7. **限流精度**：固定窗口临界点突刺（00:01 和 00:59 各 100 次算 2 窗口=200 超限，但实际跨 2 分钟）——**滑动窗口更准但更耗存储**。

## 三、本项目的解法

| 难点 | 本项目做法 |
|------|--------------|
| BCrypt 盐 | `BCryptPasswordEncoder` 自动盐，`matches(raw,hash)` 验证 |
| 分布式锁 | `SET key value NX EX` 原子 + Lua 校验 value 释放；或 Redisson |
| XSS 富文本 | Jsoup 白名单（允许安全标签）而非全转义 |
| SQL 注入 | `#{}` 预编译为主，关键字拦截为辅 |
| Token 单点 | 新登录覆盖 Redis 旧 token，旧端下次 401 |
| 防重放 | `nonce` + 时间戳窗口 5–15s |
| 上传 | 后缀/MIME/大小白名单 + UUID 名 + 存根外 + 禁执行 |
| 限流 | 令牌桶 + Redis 计数（滑动窗口优先） |

> 一句话：**安全的难点是"平衡"——XSS 要放富文本、注入拦截别误杀、限流别误伤正常流量；本项目用"预编译为主+白名单+原子锁+令牌桶"在安全和体验间取平衡。**
