# 06 系统工具 · 技术细节与难点

> 配套原教程：[[../06-系统工具/00-索引]]（代码生成器 / 上传与验证码 / Swagger + Quartz）
> 本篇讲**代码生成器的模板变量怎么映射、Quartz 集群怎么不重复跑、验证码并发怎么不串**。

## 一、技术细节

### 6.1 代码生成器（最有技术含量）
- 数据源：MySQL 的 `information_schema.tables` / `columns` 读表名、列名、类型、注释、是否主键。
- 模板引擎：**Velocity**（本项目用 `${tableName}` / `$columns`；注意 `$c.primary` 决定加不加 `@TableId`）。
- 渲染产物：`Entity` / `Mapper` / `IService+ServiceImpl` / `Controller` / Vue 页面。
- 数据模型：把查到的元数据灌进 `GenTable` 对象，模板里 `$tableName` / `$columns` 就是它。

### 6.2 文件上传
`MultipartFile`；本地存（路径可配）或 OSS（阿里云/七牛）。**文件名 UUID 随机化**防覆盖 + 防 `../../etc/passwd` 路径穿越。返回可访问 URL（Nginx 反代或 OSS 外链）。

### 6.3 验证码
算术/图形验证码；**Redis 存 `code + uuid`**（60s TTL）。校验时比对 `uuid + code`。防刷：同 uuid 频繁换、同 IP 限频。

### 6.4 Swagger → Spring Doc
Boot 3 **用 `springdoc-openapi`**（不是老 `springfox`，老的那个还是 `javax` 会炸）。`@Operation` / `@Parameter` 注解生成 OpenAPI；需放行 `/v3/api-docs` / `/swagger-ui`。

### 6.5 Quartz 定时任务
`Job`（实现 `executeInternal`）/ `Trigger`（cron）/ `Scheduler`；动态增删用 `scheduler.scheduleJob/deleteJob`。**`@DisallowConcurrentExecution`** 防同一 job 并发重入。

## 二、技术难点

1. **模板变量映射（最易错）**：表名/列名 → Java 命名（下划线转驼峰）；类型映射（MySQL `varchar`→`String`、`int`→`Integer`、`datetime`→`LocalDateTime`、`tinyint`→`Boolean/Integer` 有歧义）；包路径拼接。**生成放错包路径 → Maven 不编译**。
2. **生成后编译器认不认**：生成文件必须落在 `src/main/java/<正确包>` 下，且包声明 `package com.example.admin.xxx` 要对；否则 `mvn compile` 看不到或报包错。本项目约定**生成路径 = 配置的系统包前缀**。
3. **验证码并发串号**：多端同时拉验证码，必须 **uuid 关联**（每个验证码绑定一个 uuid，前端提交时带 uuid 回来比），否则 A 端的码被 B 端校验。TTL 过期自动失效。
4. **Quartz 集群重复执行**：多节点部署时，同一 job 每个节点调度器都触发 → 跑 N 遍。解法：**`@DisallowConcurrentExecution` + JDBC JobStore（数据库锁）** 或分布式锁；单机开发可忽略。
5. **Swagger 与 Security 冲突**：`/v3/api-docs` 被 Security 拦截 → 需 `permitAll` 放行；且 Spring Doc 在 Security 6 下要配 `HttpSecurity` 放行（呼应 [[技术细节与难点/03-后端基础框架]] 的链路放行）。
6. **上传路径穿越**：用户传 `../../etc/passwd` 当文件名，若直接拼路径就写入系统文件。本项目**只用 UUID 随机名 + 固定基目录**，原文件名绝不进路径。

## 三、本项目的解法

| 难点 | 本项目做法 |
|------|--------------|
| 模板映射 | Velocity `${tableName}`/`$columns` + `GenTable` 数据模型；类型映射表集中处理 |
| 生成编译 | 生成路径按系统包前缀，包声明一致 |
| 验证码并发 | Redis 存 `code+uuid`，提交带 uuid 比对，TTL 过期 |
| Quartz 集群 | `@DisallowConcurrentExecution` + JDBC JobStore |
| Swagger 冲突 | `springdoc-openapi` + `HttpSecurity` 放行 `/v3/api-docs` |
| 路径穿越 | UUID 随机名 + 固定基目录，原文件名不进路径 |

> 一句话：**系统工具的难点集中在"代码生成器"和"定时任务集群"——前者考模板与类型映射，后者考并发去重；本项目用 Velocity+包前缀、Quartz 注解+JDBC 锁化解。**
