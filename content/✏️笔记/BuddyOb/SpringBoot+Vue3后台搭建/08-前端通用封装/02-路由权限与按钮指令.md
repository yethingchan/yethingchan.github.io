# 08-2 路由权限守卫 + 按钮权限指令

> 上接：[[SpringBoot+Vue3后台搭建/08-前端通用封装/01-表格与表单通用组件]]

## 2.1 路由守卫（permission.js）：登录后拉权限

`src/permission.js` 在 `main.js` 里 `import './permission'`（见 [[../01-工程初始化/02-前端Vue3初始化]] 2.5），它注册 `router.beforeEach`：

```js
import router from './router'
import { getToken } from '@/utils/auth'
import { useUserStore } from '@/store/modules/user'
import { useDictStore } from '@/store/modules/dict'

const whiteList = ['/login', '/auth-redirect']   // 免登录白名单

router.beforeEach(async (to, from, next) => {
  const token = getToken()
  if (!token) {                       // ① 无 token
    if (whiteList.includes(to.path)) return next()
    return next(`/login?redirect=${to.path}`)   // 跳登录并记住目标
  }
  const userStore = useUserStore()
  if (userStore.roles.length === 0) {  // ② 有 token 但还没拉过用户信息
    try {
      await userStore.getInfo()             // 拉 角色/权限/菜单树
      await userStore.generateRoutes()         // 根据权限动态加路由
      useDictStore().loadAll()              // 顺手拉字典（[[../05-字典与基础数据/01-字典管理]]）
      next({ ...to, replace: true })          // 重进一次，路由已就绪
    } catch (e) {
      userStore.logout(); next('/login')
    }
  } else {
    next()                              // ③ 信息已就位，直接放行
  }
})
```

**逐行解释**
- **① 无 token**：拦截到登录页，`?redirect=` 记下想去的地址，登录成功后跳回去——这是"未登录访问 `/user` 自动跳登录"的实现。
- **② 首访拉信息**：`getInfo()` 调 `/getInfo` 后端返回 `{roles, permissions, user}`（见下方 2.3）。`generateRoutes()` 把"后端菜单树"转成 Vue 路由动态 `addRoute`（见 2.4）。
- **`next({...to, replace:true})`**：路由是动态加的，首访时还没注册，重进一次让新路由生效。新手常漏这步导致"刷新白屏/首次进不去"。

## 2.2 user store（存角色/权限/菜单）

```js
export const useUserStore = defineStore('user', {
  state: () => ({ token: getToken(), roles: [], permissions: [], menuTree: [], userId: '' }),
  actions: {
    async getInfo() {
      const res = await getInfo()              // 后端 /getInfo
      this.roles = res.roles                 // ['admin']
      this.permissions = res.permissions        // ['system:user:add', ...]
      this.userId = res.user.userId
      this.menuTree = res.menus                // 后端菜单树（前端路由用）
      return res
    },
    async generateRoutes() {
      const routes = filterAsyncRoutes(baseRoutes, this.permissions)
      routes.forEach(r => router.addRoute(r))   // 动态注册
    },
    logout() { this.token=''; this.roles=[]; clearAuth() }
  }
})
```
> `permissions` 就是后端 `selectPermsByUserId` 的那串（[[../04-权限管理模块/02-角色与菜单权限分配]] 2.3），**前端按钮/菜单隐藏都靠它**。

## 2.3 后端 /getInfo 返回什么

```java
@GetMapping("/getInfo")
public AjaxResult getInfo() {
    LoginUser u = SecurityUtils.getLoginUser();
    return AjaxResult.success()
        .put("user", u.getSysUser())
        .put("roles", u.getRoleKeys())         // ['admin']
        .put("permissions", u.getPermissions()); // ['system:user:list', ...]
}
```
菜单树另由 `/system/menu/treeselect` 返回（[[../04-权限管理模块/03-菜单树管理]]），前端据此渲染侧边栏。

## 2.4 v-hasPermi 指令（按钮级隐藏）

`src/directive/index.js`：
```js
import { useUserStore } from '@/store/modules/user'
export const hasPermi = {
  mounted(el, binding) {
    const { permissions } = useUserStore()
    const need = binding.value                 // ['system:user:add']
    const ok = need?.some(p => permissions.includes(p))
    if (!ok) el.parentNode?.removeChild(el)        // 无权限 → 从 DOM 删掉按钮
  }
}
```
`main.js` 里 `app.directive('hasPermi', hasPermi)` 注册后，模板里 `<el-button v-hasPermi="['system:user:add']">新增</el-button>` 就能**无权限自动消失**。

**前后端双保险**：前端 `v-hasPermi` 提升体验（看不到），后端 `@PreAuthorize("hasPermi('system:user:add')")` 兜底（硬拦，见 [[../03-后端基础框架/03-SpringSecurity与JWT鉴权]] 3.6）。**只做前端隐藏 = 形同虚设**（开发者工具手动调接口仍能调）。

## 2.5 动态路由 vs 静态路由
- **静态**（`router/index.js`）：登录、404 等公共页，任何人都可进。
- **动态**（`generateRoutes`）：菜单对应的业务页，**按权限 addRoute**，无权限的人连路由都没有，直接 404。

## 验证清单
- [ ] 未登录访问 `/system/user` → 自动跳 `/login?redirect=/system/user`，登录后回原页。
- [ ] 某角色无 `system:user:add`，其前端"新增"按钮 DOM 里不存在（审查元素找不到）。
- [ ] 直接调 `POST /system/user`（无权限）→ 后端 403（前端隐藏只是第一道）。
- [ ] 刷新页面不白屏（`next({...to, replace:true})` 生效）。
