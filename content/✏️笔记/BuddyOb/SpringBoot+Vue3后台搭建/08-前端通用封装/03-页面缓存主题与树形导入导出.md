# 08-3 页面缓存 / 主题 / 树形 / 导入导出

> 上接：[[SpringBoot+Vue3后台搭建/08-前端通用封装/02-路由权限与按钮指令]]

## 3.1 keep-alive（切页不丢查询条件）

**需求**：在"用户管理"筛了条件、翻到第 3 页，点进"角色"再回来——希望用户页**还是第 3 页、条件还在**，而不是重置。

```vue
<!-- layout 的 <router-view>，用 v-slot 包 keep-alive -->
<template>
  <router-view v-slot="{ Component }">
    <keep-alive :include="cachedViews">
      <component :is="Component" />
    </keep-alive>
  </router-view>
</template>

<script setup>
import { useTagsViewStore } from '@/store/modules/tagsView'
const cachedViews = computed(() => useTagsViewStore().cachedViews)  // ['system/user/index', ...]
</script>
```
**配合路由 meta**：
```js
{ path: 'user', component: () => import('@/views/system/user/index.vue'),
  meta: { title: '用户管理', cache: true } }   // cache=true 才进 include
```
**后端呼应**：菜单表 `is_cache` 字段（[[../04-权限管理模块/03-菜单树管理]] 3.4）就是控制这个——`cache=true` 的菜单，前端才把它组件名加进 `cachedViews`。`v-hasPermi` 隐藏的菜单即便 `cache=true` 也不会缓存未授权页。

> 关掉 `keep-alive` 的页（如表单页）每次进都**重新挂载**、`onMounted` 重新查——适合不含查询状态的页。

## 3.2 主题切换（深 / 浅 + 布局）

```js
// store/modules/settings.js
export const useSettingsStore = defineStore('settings', {
  state: () => ({ theme: 'light', sideTheme: 'dark', tagsView: true }),
  actions: {
    toggleTheme() {
      this.theme = this.theme === 'light' ? 'dark' : 'light'
      document.documentElement.classList.toggle('dark', this.theme === 'dark')
      localStorage.setItem('theme', this.theme)
    }
  }
})
```
**Element Plus 暗色**：额外引入暗色样式 `element-plus/theme-chalk/dark/css-vars.css`，加 `html.dark` class 即生效。布局（侧栏深浅、顶栏固定）同理切 class。

## 3.3 树形组件（部门 / 菜单 / 分类）

前端三件套（见 [[../04-权限管理模块/03-菜单树管理]]、[[../04-权限管理模块/04-部门与岗位管理]]）：
- `el-tree`：角色授权勾选（`:default-checked-keys` 回显）。
- `el-table` + `:tree-props="{children:'children'}"`：菜单/部门**树形表格**（后端给 `children` 嵌套，见 [[../04-权限管理模块/03-菜单树管理]] 3.2）。

拖拽排序：`el-tree` 的 `draggable` + `allow-drop`，松手调后端 `changeOrder`/`changeParent` 更新 `order_num`/`parent_id`（[[../04-权限管理模块/04-部门与岗位管理]] 4.1）。

## 3.4 导入导出（Excel）

**导出**：后端 blog 流（[[../04-权限管理模块/01-用户管理]] 1.4 前端 + 2.3 后端 EasyExcel）或前端 xlsx（[[../08-前端通用封装/01-表格与表单通用组件]] 1.4）。

**导入**：
```vue
<el-upload :auto-upload="false" :on-change="handleFile" accept=".xlsx">
  <el-button>选择 Excel</el-button>
</el-upload>
<script setup>
import * as XLSX from 'xlsx'
function handleFile(file) {
  const reader = new FileReader()
  reader.onload = e => {
    const wb = XLSX.read(e.target.result, { type:'array' })
    const rows = XLSX.utils.sheet_to_json(wb.Sheets[wb.SheetNames[0]])
    // rows: [{用户ID,登录账号,...}] → 转成后端 DTO 批量 POST
    importUser(rows)
  }
  reader.readAsArrayBuffer(file.raw)
}
</script>
```
**后端导入**：`importUser(List<SysUserExcelVO>)` 校验（账号重复、格式）→ 批量 `saveBatch`（BCrypt 密码）。模板下载 = 先导一份空表给用户填（[[../04-权限管理模块/01-用户管理]]）。
