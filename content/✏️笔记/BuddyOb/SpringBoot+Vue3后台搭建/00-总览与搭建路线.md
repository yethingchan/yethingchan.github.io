# Spring Boot + Vue3 后台管理系统 · 从 0 到 1 全栈教程

> 目标：照着本教程的代码，你能独立搭出一个**企业级后台管理系统**（类似若依 RuoYi-Vue3，但自己从零写出来，懂每一行）。
> 本教程用 Obsidian `[[双链]]` 串联。建议从本页按编号顺序读。

## 一、技术栈（务必统一，代码才能跑）

| 层 | 选型 | 版本 | 作用 |
|----|------|------|------|
| 后端 | **JDK** | 17 | 语言运行时 |
| | **Spring Boot** | 3.2.5 | 容器/自动装配 |
| | **Spring Security** | 6.2.4 | 认证授权 |
| | **JWT（jjwt）** | 0.12.5 | 无状态令牌 |
| | **MyBatis-Plus** | 3.5.7 | ORM（比原生 MyBatis 少写 80% SQL） |
| | **MySQL** | 8.0 | 主库 |
| | **Redis** | 7 | 缓存/会话/限流 |
| | **Druid** | 1.2.23 | 连接池+监控 |
| | **springdoc-openapi** | 2.5.0 | Swagger 接口文档 |
| | **Quartz** | 2.3.2 | 定时任务 |
| | **EasyExcel** | 3.3.4 | Excel 导入导出 |
| | **Hutool** | 5.8.27 | 工具集 |
| 前端 | **Vue** | 3.4 | 框架 |
| | **Vite** | 5 | 构建 |
| | **Vue Router** | 4.3 | 路由 |
| | **Pinia** | 2.1 | 状态 |
| | **Element Plus** | 2.7 | UI 组件库 |
| | **axios** | 1.7 | HTTP |
| | **ECharts** | 5.5 | 图表 |
| | **xlsx(SheetJS)** | 0.18 | 前端导出 |
| | **js-cookie** | 3.0 | 存 token |

> 为什么用 MyBatis-Plus 而不是原生 MyBatis？教程核心是**讲清 RBAC 与架构**，用 MP 的 `QueryWrapper`/`BaseMapper` 能让你专注业务逻辑，不被 XML 淹没。理解后你随时能切回原生 MyBatis。

## 二、最终项目结构（你跟着搭出来的样子）

```
springboot-vue3-admin/                # 根（前后端可放一起，也可用两个仓库）
├─ admin/                           # 后端（Maven 单模块即可，用 package 分层）
│  ├─ pom.xml
│  └─ src/main/
│     ├─ java/com/example/admin/
│     │  ├─ AdminApplication.java        # 启动类
│     │  ├─ config/                    # 配置（安全/MP/Redis/Cors/Swagger/Quartz）
│     │  ├─ common/                   # 公共层
│     │  │  ├─ result/AjaxResult.java # 统一返回
│     │  │  ├─ exception/             # 全局异常+枚举
│     │  │  ├─ annotation/           # @DataScope @RateLimit 等
│     │  │  ├─ utils/                # 令牌/字典/Redis/Servlet 工具
│     │  │  └─ constant/             # 常量
│     │  ├─ security/                 # 认证授权（JwtFilter/JWT 工具/UserDetails）
│     │  ├─ modules/
│     │  │  ├─ system/               # 系统模块（用户/角色/菜单/部门/岗位/字典/参数/公告/日志）
│     │  │  ├─ monitor/              # 监控模块（在线用户/服务/缓存）
│     │  │  └─ quartz/              # 定时任务
│     │  ├─ generator/               # 代码生成器
│     │  └─ aspect/                  # 操作日志切面/数据权限切面
│     └─ resources/
│        ├─ application.yml            # 主配置
│        ├─ application-druid.yml     # 数据源
│        └─ mapper/                   # *Mapper.xml（MP 大多不用写）
└─ admin-ui/                        # 前端（Vite）
   ├─ package.json  vite.config.js  index.html
   └─ src/
      ├─ main.js  App.vue  permission.js   # 权限路由守卫
      ├─ api/        # 各模块请求函数
      ├─ router/      # 路由（动态+静态）
      ├─ store/       # pinia：user/dict/app/tagsView
      ├─ utils/       # request.js(axios) / auth.js / ruoyi.js
      ├─ directive/    # v-hasPermi / v-hasRole 指令
      ├─ layout/      # 整体框架（侧栏/顶栏/内容区/标签栏）
      ├─ components/   # 通用组件（表格/Pagination/右击菜单/上传/树）
      └─ views/       # 各业务页面（system/monitor/tool/...）
```

> 这个结构是**从若依提炼的"最小可用骨架"**，你照着建，每一层在后续章节都会填充真实代码。

## 三、阅读顺序（= 搭建顺序）

```
① 工程初始化（01）→ 能起一个空前后端并能跨域联调
② 数据库与 RBAC 表设计（02）→ 把库表建出来
③ 后端基础框架（03）→ 返回值/异常/MP/Redis/Security+JWT/防护 全通
④ 权限管理模块（04）★核心 → 用户/角色/菜单/部门/岗位/数据权限/在线用户
⑤ 字典与基础数据（05）→ 字典/参数/公告
⑥ 系统工具（06）→ 代码生成/上传/验证码/Swagger/Quartz
⑦ 日志与监控（07）→ 操作/登录日志/服务器/Redis/缓存/备份
⑧ 前端通用封装（08）→ 表格/表单/权限指令/缓存/主题/树/导入导出
⑨ 业务扩展（09）→ 物料库位/单据/预警/报表/审批/对接（接你 Locations 项目）
⑩ 安全防护（10）→ 密码/防暴破/注入/Token/文件拦截
```

## 四、学习清单（照着打勾，由易到难）

- [ ] 用 Spring Initializr / Maven 起一个空 Boot 工程，能 `http://localhost:8080/hello` 返回
- [ ] 用 Vite 起一个 Vue3 空工程，Element Plus + Router + Pinia 装好
- [ ] 配好跨域，前端 axios 能打到后端 hello
- [ ] 按 02 章 SQL 建出 RBAC 全套表并有 init 数据
- [ ] 封装 `AjaxResult` + 全局异常，所有接口统一返回
- [ ] 配好 MyBatis-Plus + Druid + Redis，能 CRUD 一张表
- [ ] 跑通 Security + JWT 登录，拿到 token 才能访问受保护接口
- [ ] 用户管理：分页/筛选/导出/重置密码/启停
- [ ] 角色管理 + 菜单权限分配（勾选菜单与按钮）
- [ ] 菜单管理：三级树（菜单/页面/按钮），自动生成菜单 SQL
- [ ] 部门/岗位树形 + 用户绑定
- [ ] 数据权限：角色控制"全部/本部门/仅本人"数据范围
- [ ] 在线用户：查看会话、强制下线
- [ ] 字典管理：前后端读字典，下拉不硬编码
- [ ] 参数配置 + 通知公告（首页弹窗）
- [ ] 代码生成器：导表→一键出前后端全套代码
- [ ] 文件上传（本地+OSS）+ 图形/滑块/短信验证码
- [ ] Swagger 在线接口文档 + Quartz 定时任务
- [ ] 操作/登录日志 + 服务器/Redis/数据库监控 + 缓存管理 + 备份
- [ ] 前端表格/表单通用组件、v-hasPermi 按钮权限、keep-alive、主题切换、树形、导入导出
- [ ] 业务模块：物料/库位(Locations)/单据/预警/报表
- [ ] 安全防护：密码加密/防暴破/IP 名单/注入过滤/Token/文件拦截
- [ ] 能对着 [[SpringBoot+Vue3后台搭建/11-极简分层总结]] 复述整个系统骨架
