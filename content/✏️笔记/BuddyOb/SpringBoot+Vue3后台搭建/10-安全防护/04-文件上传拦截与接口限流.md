# 10-4 文件上传安全拦截 + 接口限流

> 上接：[[SpringBoot+Vue3后台搭建/10-安全防护/03-Token鉴权强化与防重复提交]]
> 上传是**高危入口**（传个 `.jsp`/`.exe` 就能getshell）；限流是**保命阀**（防 CC/脚本狂刷打挂服务）。两个都得上。

## 4.1 上传前置：全局大小限制

`application.yml`（超过直接 413，连 Controller 都进不去）：
```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB        # 单文件
      max-request-size: 50MB      # 单次请求总大小
```

## 4.2 上传四重校验（扩展名 / MIME / 大小 / 随机名）

基础上传见 [[../06-系统工具/02-文件上传与验证码]]。安全版在保存前加校验：

```java
@Component
public class UploadSecurity {
    // ① 扩展名白名单（只放业务真需要的）
    private static final Set<String> ALLOW = Set.of("jpg","jpeg","png","gif","pdf","xlsx","docx");
    // ② 危险扩展（绝不放行）
    private static final Set<String> DENY = Set.of("jsp","jspx","exe","sh","bat","php","asp","jar","class");

    public String checkAndSave(MultipartFile file, String baseDir) throws IOException {
        String orig = file.getOriginalFilename();
        String ext = orig.substring(orig.lastIndexOf('.') + 1).toLowerCase();

        if (DENY.contains(ext)) throw new BusinessException("禁止上传该类型文件");
        if (!ALLOW.contains(ext)) throw new BusinessException("不支持的文件类型：" + ext);
        if (file.getSize() > 10 * 1024 * 1024) throw new BusinessException("文件超过 10MB");

        // ③ MIME 校验：用 JDK 探实际内容类型，而非信客户端报的 ContentType
        String mime = Files.probeContentType(
            Paths.get(file.getOriginalFilename()));  // 或用 ImageIO 读图片头
        if (mime == null || (!mime.startsWith("image/") && !mime.startsWith("application/")))
            throw new BusinessException("文件内容非法");

        // ④ 随机文件名 + 存 Web 根之外（不能让用户直接访问到上传目录执行）
        String newName = UUID.randomUUID() + "." + ext;
        Path dir = Paths.get(baseDir);            // baseDir 配在应用外部，如 /data/uploads
        Files.createDirectories(dir);
        file.transferTo(dir.resolve(newName));

        // ⑤（可选）病毒扫描：调 ClamAV（本地 clamscan 或 clamd REST）
        // if (virusScan(dir.resolve(newName))) { Files.delete(...); throw ... }

        return newName;
    }
}
```

**要点**
- **扩展名白名单 + 危险扩展黑名单双保险**：黑客常改扩展名（`evil.jpg.jsp`）绕过，所以 MIME/内容校验才是主力。
- **存 Web 根之外**：若上传到 `static/uploads/` 且服务器把 `.jsp` 当脚本执行，传个 webshell 就完蛋。存到应用读不到、Nginx 不解析的目录，靠后端接口按需回传。
- **随机文件名**：杜绝"覆盖已有文件"和"路径穿越"（`../../etc/passwd`）。
- **图片额外验**：用 `ImageIO.read(file)` 不为 null 才说明真能解析成图，挡掉伪图马。

## 4.3 接口限流（防刷 / 防 CC）

固定窗口计数：每 IP 每接口每 N 秒最多 M 次，超了返回 429。

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RateLimit {
    int count() default 10;        // 窗口内允许次数
    int seconds() default 1;       // 窗口大小
}
```

```java
@Component
public class RateLimitInterceptor implements HandlerInterceptor {
    @Resource private RedisTemplate<String,String> redisTemplate;  // 或 RedisCache 包一层
    @Override
    public boolean preHandle(HttpServletRequest req, HttpServletResponse res, Object handler) {
        if (handler instanceof HandlerMethod hm) {
            RateLimit rl = hm.getMethodAnnotation(RateLimit.class);
            if (rl != null) {
                String ip = getClientIp(req);
                String key = "ratelimit:" + ip + ":" + req.getRequestURI();
                // INCR + 首设过期，原子窗口计数
                Long n = redisTemplate.opsForValue().increment(key);
                if (n == 1) redisTemplate.expire(key, Duration.ofSeconds(rl.seconds()));
                if (n > rl.count()) {
                    res.setStatus(429); res.setHeader("Retry-After", String.valueOf(rl.seconds()));
                    return false;
                }
            }
        }
        return true;
    }
}
```

用法（在敏感/高耗接口上）：
```java
@RateLimit(count = 5, seconds = 60)   // 同一 IP 60 秒内最多调 5 次
@PostMapping("/sendSms")
public AjaxResult sendSms(@RequestBody SmsBody body) { ... }
```
> 更高阶用 **Bucket4j**（令牌桶，支持突发流量平滑）；多节点必须共用 Redis（如上面），否则各节点独立计数形同虚设。
