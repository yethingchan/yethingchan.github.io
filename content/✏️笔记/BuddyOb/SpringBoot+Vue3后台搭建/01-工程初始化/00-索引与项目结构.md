## 关键决策
- **后端用 Maven 单模块 + package 分层**（不是多模块）。从 0 到 1 先把一条线走通，多模块是后期拆分的事（你 RuoYi 项目是多模块，可对照 halcon 视觉知识库（本仓库同级目录，需另开）的后端结构）。
- **前端用 Vite**（不是 vue-cli/webpack）。Vite 启动秒级，是 2024+ 的标配。
- **前后端分两个目录**（`admin/` + `admin-ui/`），通过 HTTP + 跨域联调，符合真实部署（Nginx 反代）。

## 读完后你应该能
- [ ] 启动 Boot，访问 `http://localhost:8080/hello` 返回 JSON
- [ ] 启动 Vite，`npm run dev` 打开页面
- [ ] 浏览器 Network 里能看到前端打到 8080 的请求成功（无 CORS 红字）
