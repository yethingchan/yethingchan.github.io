**解释**
- `vue` 3.4 + `vue-router` 4 + `pinia` 2：Vue3 全家桶。
- `element-plus`：UI 库（表单/表格/弹窗全是它）。
- `axios`：HTTP 客户端；`js-cookie`：存 token。
- `xlsx`：前端也能导出 Excel（后端导出见 [[../06-系统工具/01-代码生成器]] 之外的上传章节）。
- `unplugin-auto-import` + `unplugin-vue-components`：Element Plus **按需自动引入**，不用每个文件 `import` 组件（省事、体积小）。

## 2.3 vite.config.js

```js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import AutoImport from 'unplugin-auto-import/vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'
import path from 'path'

export default defineConfig({
  plugins: [
    vue(),
    // 自动引入 Element Plus 组件 + API（如 ElMessage, ref）
    AutoImport({ resolvers: [ElementPlusResolver()] }),
    Components({ resolvers: [ElementPlusResolver()] })
  ],
  resolve: {
    alias: { '@': path.resolve(__dirname, 'src') }   // @ 指向 src，import 不再写 ../../../ 
  },
  server: {
    port: 80,
    proxy: {
      // 开发期把 /dev-api 代理到后端 8080，规避跨域
      '/dev-api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: p => p.replace(/^\/dev-api/, '')   // 去掉前缀
      }
    }
  }
})
```

**解释**
- `alias '@' → src`：此后 `import { } from '@/api/user'` 即可。
- `proxy['/dev-api']`：**开发期跨域的解决方案**。前端请求 `/dev-api/login` → Vite 转发到 `localhost:8080/login`。生产用 Nginx 反代，逻辑相同。
- `rewrite`：把 `/dev-api` 前缀去掉，后端收到干净路径。

## 2.5 src/main.js（装配）

```js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import pinia from './store'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
import './permission'          // 路由守卫（权限控制，见 [[../08-前端通用封装/02-路由权限与按钮指令]]）

const app = createApp(App)

// 全量注册所有 Element Plus 图标（也可按需，这里为省事全量）
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

app.use(ElementPlus)
app.use(pinia)
app.use(router)
app.mount('#app')
```

**解释**
- `app.use(ElementPlus)`：全量注册组件（若用 2.3 的 auto-import 可去掉全量，二选一）。
- `import './permission'`：路由守卫**必须在 `app.use(router)` 之后、挂载之前注册**，否则首次跳转不触发。
- 图标全量注册简单但打包大，生产可用 `unplugin-icons` 按需。

## 2.7 src/router/index.js（基础路由）

```js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/login', component: () => import('@/views/login/index.vue') },
  { path: '/', component: () => import('@/layout/index.vue'), redirect: '/dashboard' },
  { path: '/dashboard', component: () => import('@/views/dashboard/index.vue') }
]

const router = createRouter({
  history: createWebHistory(),   // HTML5 模式（URL 无 #）
  routes
})

export default router
```
