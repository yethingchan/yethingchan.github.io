## 三类日志职责
```
操作日志：谁、何时、改了哪条数据 → 追责/审计
登录日志：谁、何地、成功/失败 → 暴力破解预警
业务日志：代码里 log.info → 排错（不在库，落文件/ELK）
```

## 验证清单
- [ ] 任意增删改后 `sys_oper_log` 多一条（含参数/结果）。
- [ ] 登录成功/失败都进 `sys_login_log`，失败 N 次触发预警。
- [ ] 监控页能看到 CPU/内存/JVM/Redis 命中率。
- [ ] 菜单/字典改后"清缓存"立即生效；误删缓存可"刷回"。
- [ ] 一键 mysqldump 出 .sql，能下载、能恢复。
