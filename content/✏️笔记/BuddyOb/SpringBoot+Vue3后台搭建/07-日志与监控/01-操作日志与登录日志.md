# 07-1 操作日志 + 登录日志

> 上接：[[SpringBoot+Vue3后台搭建/07-日志与监控/00-索引]]

## 1.1 操作日志：AOP 环绕所有写操作

**注解驱动**：在要记录的方法上写 `@Log(title="用户管理", businessType=BUSINESS_ADD)`。

```java
@Target(ElementType.METHOD) @Retention(RetentionPolicy.RUNTIME)
public @interface Log {
    String title() default "";                // 操作模块
    BusinessType businessType() default BusinessType.OTHER;
}
public enum BusinessType { OTHER, INSERT, UPDATE, DELETE, GRANT, EXPORT, IMPORT, FORCE, CLEAN }
```

**切面**（环绕，成功失败都记）：
```java
@Aspect @Component
public class LogAspect {
    @Resource private ISysOperLogService operLogService;

    @Around("@annotation(log)")
    public Object around(ProceedingJoinPoint jp, Log log) throws Throwable {
        long start = System.currentTimeMillis();
        Object result = null; String error = "";
        int status = 0;
        try { result = jp.proceed(); }
        catch (Throwable e) { status = 1; error = e.getMessage(); throw e; } // 异常照抛，但先记
        finally {
            long cost = System.currentTimeMillis() - start;
            SysOperLog o = build(jp, log, status, error, result, cost);
            operLogService.save(o);   // 异步更好（见 1.4）
        }
        return result;
    }

    private SysOperLog build(ProceedingJoinPoint jp, Log log, int status,
                                  String error, Object result, long cost) {
        SysOperLog o = new SysOperLog();
        o.setTitle(log.title());
        o.setBusinessType(log.businessType().ordinal());
        o.setOperName(SecurityUtils.getUsername());   // 当前人
        o.setOperIp(ServletUtils.getClientIP());      // 请求 IP
        o.setOperParam(JSON.toJSONString(jp.getArgs()));  // 入参（截断防爆库）
        o.setJsonResult(status == 0 ? JSON.toJSONString(result) : "");
        o.setStatus(status); o.setErrorMsg(error);
        o.setOperTime(LocalDateTime.now());
        return o;
    }
}
```
**逐行解释**
- `@Around("@annotation(log)")`：匹配"所有带 `@Log` 的方法"，并把注解实例注入。
- `try/proceed/finally`：**先让业务跑**，成功失败都进 `finally` 留痕，但异常继续上抛（不能因为记日志把异常吞了）。
- `getArgs()` 入参序列化存 `oper_param`——事后追责"他当时传了啥"。超过 2000 字符要 `substring`（[[../02-数据库与RBAC/03-日志任务监控表]] 表里 `oper_param VARCHAR(2000)`）。
- 切面要能拿到 `SecurityUtils.getUsername()`（从 SecurityContext 取，见 [[../03-后端基础框架/03-SpringSecurity与JWT鉴权]]）。

## 1.2 用法（Controller 上加注解）
```java
@Log(title = "操作日志", businessType = BusinessType.INSERT)
@PreAuthorize("hasPermi('monitor:operlog:list')")
@PostMapping
public AjaxResult add(@RequestBody SysUser user) { ... }
```
**没加 `@Log` 的接口就不记**——精准控制哪些操作要审计。

## 1.3 登录日志
登录成功/失败都记。用 Spring 的 `ApplicationEvent` 或直接在 `LoginController` 里写：
```java
// 登录成功
SysLoginLog log = new SysLoginLog(username, ip, "PC", "Chrome", "Win11", 0, "登录成功");
loginLogService.save(log);
// 登录失败（密码错/验证码错）
loginLogService.save(new SysLoginLog(username, ip, ..., 1, "密码错误"));
```
**暴力破解预警**：定时查 `sys_login_log WHERE status=1 AND user_name=? AND login_time > 5分钟前`，若 >5 次 → 锁账号（[[../10-安全防护/01-密码加密与防暴破IP名单]]）。

## 1.4 异步写日志（避免拖慢主流程）
`operLogService.save` 改成 `@Async`：
```java
@Async
@Transactional(propagation = Propagation.REQUIRES_NEW)  // 独立事务，主事务回滚也不影响
public void save(SysOperLog o) { baseMapper.insert(o); }
```
> 别忘了启动类加 `@EnableAsync`。否则 `@Async` 不生效。

## 1.5 前端：日志列表 + 导出
和 [[../04-权限管理模块/01-用户管理]] 的表格一模一样：`el-table` + 分页 + 导出按钮（`v-hasPermi="['monitor:operlog:export']"`）。
