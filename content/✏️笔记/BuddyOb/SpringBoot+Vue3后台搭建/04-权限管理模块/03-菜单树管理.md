# 04-3 菜单管理（三级树 / 拖拽 / 自动生成 SQL）

> 上接：[[SpringBoot+Vue3后台搭建/04-权限管理模块/02-角色与菜单权限分配]]

## 3.1 菜单树：后端把扁平列表拼成树

```java
@RestController
@RequestMapping("/system/menu")
public class SysMenuController {
    @Resource private ISysMenuService menuService;

    /** 返回树（前端 el-tree 直接吃） */
    @GetMapping("/list")
    public AjaxResult list(SysMenu menu) {
        List<SysMenu> menus = menuService.selectMenuList(menu);
        return AjaxResult.success(menuService.buildMenuTree(menus)); // 拼树
    }

    /** 新增：parent_id 决定挂哪一级 */
    @PreAuthorize("hasPermi('system:menu:add')")
    @PostMapping public AjaxResult add(@Valid @RequestBody SysMenu menu) {
        menuService.save(menu); return AjaxResult.success();
    }
    @PreAuthorize("hasPermi('system:menu:edit')")
    @PutMapping  public AjaxResult edit(@RequestBody SysMenu menu) { ... }
    /** 级联删除：删父连带删子（见 3.4） */
    @PreAuthorize("hasPermi('system:menu:remove')")
    @DeleteMapping("/{menuId}") public AjaxResult remove(@PathVariable Long menuId) {
        menuService.deleteMenuById(menuId); return AjaxResult.success();
    }

    /** 角色授权页：返回树 + 该角色已勾 keys（[[../04-权限管理模块/02-角色与菜单权限分配]] 用） */
    @GetMapping("/treeselect") public AjaxResult treeselect() {
        return AjaxResult.success(menuService.buildMenuTree(menuService.list()));
    }
    @GetMapping("/role/{roleId}") public AjaxResult roleMenu(@PathVariable Long roleId) {
        return AjaxResult.success(roleMenuMapper.selectMenuIdsByRole(roleId));
    }
}
```

## 3.2 拼树工具（递归）

```java
@Service
public class SysMenuServiceImpl extends ServiceImpl<SysMenuMapper, SysMenu>
        implements ISysMenuService {

    @Override
    public List<SysMenu> buildMenuTree(List<SysMenu> all) {
        List<SysMenu> roots = all.stream()
                .filter(m -> m.getParentId() == 0).collect(Collectors.toList());
        for (SysMenu root : roots) recurse(root, all);
        return roots;
    }
    private void recurse(SysMenu parent, List<SysMenu> all) {
        List<SysMenu> children = all.stream()
                .filter(m -> m.getParentId().equals(parent.getMenuId()))
                .sorted(Comparator.comparing(SysMenu::getOrderNum))
                .collect(Collectors.toList());
        parent.setChildren(children);     // 前端 el-table 树形 / el-tree 都吃 children
        for (SysMenu c : children) recurse(c, all);
    }

    /** 级联删除：找所有子孙 id（含自己）一起删 */
    @Override @Transactional
    public void deleteMenuById(Long menuId) {
        List<Long> ids = new ArrayList<>();
        collectChildren(menuId, list(), ids);
        ids.add(menuId);
        removeBatchByIds(ids);              // 物理删（菜单不是业务数据，可真删）
        roleMenuMapper.delete(Wrappers.<SysRoleMenu>query().in("menu_id", ids)); // 清角色授权
    }
    private void collectChildren(Long pid, List<SysMenu> all, List<Long> acc) {
        for (SysMenu m : all)
            if (m.getParentId().equals(pid)) { acc.add(m.getMenuId()); collectChildren(m.getMenuId(), all, acc); }
    }
}
```

**讲解**
- `buildMenuTree` 是**经典树形算法**：先找 `parent_id=0` 的顶级，递归把子挂到 `children`。
- 前端 `el-table` 有 `row-key="menuId"` + `:tree-props="{children:'children'}"` 即可渲染成可展开的树表格（[[../08-前端通用封装/03-页面缓存主题与树形导入导出]]）。
- **级联删除**必须用递归收集所有子孙，否则留孤儿菜单。

## 3.3 自动生成菜单 SQL（一键入库）

运维常要把"配好的菜单"导成 SQL 给别的環境执行。后端拼 INSERT：

```java
@GetMapping("/exportSql")
public void exportSql(HttpServletResponse resp) throws IOException {
    List<SysMenu> all = menuService.list();
    StringBuilder sb = new StringBuilder();
    sb.append("-- 菜单初始化 SQL，自动生成，请勿手改\n");
    for (SysMenu m : all) {
        sb.append(String.format(
            "INSERT INTO sys_menu(menu_id,menu_name,parent_id,menu_type,perms,component,status) " +
            "VALUES (%d,'%s',%d,'%s','%s','%s','%s');\n",
            m.getMenuId(), m.getMenuName(), m.getParentId(),
            m.getMenuType(), m.getPerms(), m.getComponent(), m.getStatus()));
    }
    resp.setContentType("application/sql");
    resp.setHeader("Content-Disposition", "attachment;filename=menu.sql");
    resp.getWriter().write(sb.toString());
}
```
**讲解**：`menu_type` 决定前端怎么渲染——`M` 目录（只分组不点）、`C` 菜单（有 `component` 路由页）、`F` 按钮（只有 `perms` 串，用于 `v-hasPermi`）。**三级就是靠这三者 + `parent_id` 嵌套**。

## 3.4 菜单配置字段一览（对应你截图的表单）

| 字段 | 含义 | 备注 |
|------|------|------|
| menuName | 菜单名称 | 显示文字 |
| parentId | 上级 | 0=顶级 |
| orderNum | 显示排序 | 数字小在上 |
| path | 路由地址 | 如 `user` |
| component | 组件路径 | 如 `system/user/index` |
| isFrame | 是否外链 | 1是 0否 |
| isCache | 缓存开关 | 配 `keep-alive`（[[../08-前端通用封装/03-页面缓存主题与树形导入导出]]） |
| visible | 显示/隐藏 | 0显示 1隐藏 |
| status | 启用/停用 | 1 停用的菜单不渲染 |
| perms | 权限标识 | `system:user:list` |
| icon | 图标 | Element 图标名 |

> 注：缓存主题在 [[../08-前端通用封装/03-页面缓存主题与树形导入导出]] 讲 keep-alive。
