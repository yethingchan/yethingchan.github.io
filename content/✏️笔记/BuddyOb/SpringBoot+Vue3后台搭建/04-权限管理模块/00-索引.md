## 全套接口清单（最终你要实现的）
```
用户：GET  /system/user/list   POST /system/user  PUT /system/user
      DELETE /system/user/{ids}   PUT /system/user/resetPwd
      PUT /system/user/changeStatus   POST /system/user/import   GET /system/user/export
角色：GET  /system/role/list   POST/PUT/DELETE ...   PUT /system/role/dataScope
      GET /system/role/menuTreeselect/{roleId}   PUT /system/role/auth
菜单：GET  /system/menu/list(树)   POST/PUT/DELETE   GET /system/menu/{id}
      GET /system/menu/treeselect   GET /system/menu/role/{roleId}
部门：GET  /system/dept/list(树)   POST/PUT/DELETE/status
岗位：GET  /system/post/list   POST/PUT/DELETE
在线：GET  /monitor/online/list   DELETE /monitor/online/{token}
```

## 验证清单（整章学完应达成）
- [ ] 登录 admin 后能增删改查用户，并看到分页/筛选/导出按钮（无权限按钮自动隐藏）。
- [ ] 新建"仓库员"角色，勾选几个菜单与按钮，分配给某用户，该用户登录后只看到这些菜单。
- [ ] 菜单管理里增一个"报表"菜单（带权限串），自动生成 insert SQL。
- [ ] 部门树下新增子部门，用户绑定部门后数据权限生效（只能看本部门数据）。
- [ ] 在线用户列表能看到自己，点"强退"后该 token 失效。
