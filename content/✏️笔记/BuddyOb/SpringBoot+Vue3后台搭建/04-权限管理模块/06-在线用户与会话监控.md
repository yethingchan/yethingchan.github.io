# 04-6 在线用户 / 会话监控

> 上接：[[SpringBoot+Vue3后台搭建/04-权限管理模块/05-数据权限实现]]

## 6.1 原理
登录时我们把 `LoginUser` 存进 Redis（`login:{token}`），并设了 2 小时过期（[[../03-后端基础框架/03-SpringSecurity与JWT鉴权]] 3.3）。**所有在线会话 = Redis 里 `login:*` 这批 key**。在线用户列表、强制下线，本质都是操作这些 key。

## 6.2 后端：列表 + 强退

```java
@RestController
@RequestMapping("/monitor/online")
public class SysUserOnlineController {
    @Resource private RedisCache redisCache;

    /** 当前在线会话列表 */
    @PreAuthorize("hasPermi('monitor:online:list')")
    @GetMapping("/list")
    public R<OnlineUser> list(@RequestParam(required=false) String ipAddr) {
        List<OnlineUser> list = new ArrayList<>();
        for (String key : redisCache.keys("login:*")) {       // 扫所有 login:* key
            LoginUser u = redisCache.getCacheObject(key);
            if (u == null) continue;
            OnlineUser o = new OnlineUser();
            o.setToken(key.replace("login:", ""));
            o.setUserName(u.getUsername());
            o.setIpAddr(u.getIpAddr());
            o.setLoginTime(u.getLoginTime());
            if (ipAddr == null || o.getIpAddr().contains(ipAddr)) list.add(o);
        }
        return R.ok(new Page<>(1, 10, list.size(), list)); // 小数据直接内存分页
    }

    /** 强制下线：删 token 对应 key */
    @PreAuthorize("hasPermi('monitor:online:forceLogout')")
    @DeleteMapping("/{token}")
    public AjaxResult forceLogout(@PathVariable String token) {
        redisCache.deleteObject("login:" + token);
        return AjaxResult.success("已强制下线");
    }
}
```

**逐行解释**
- `redisCache.keys("login:*")`：用通配扫 key。**注意**：生产 Redis 数据量大时 `KEYS` 会阻塞，应改用 `SCAN` 游标（[[../07-日志与监控/02-监控与缓存备份]] 会提）。
- 强制下线 = `deleteObject("login:"+token)`。下次该用户带这个 token 访问，**JwtFilter 从 Redis 取不到 LoginUser → 不塞 Context → 401**，等于被踢。这就是"无状态 token + Redis 存会话"的强退机制。
- 要踢人前最好校验"不能踢自己/管理员"，避免误删。

## 6.4 会话时长 / 超时预警（扩展）
- `loginTime` 存进 `LoginUser`，页面算 `now - loginTime` 显示"已在线 1h23m"。
- 想做"半小时无操作自动过期"：Redis 的 token key 设 `expire` + 每次请求 `expire` 续期（滑动窗口），或后端 `checkLogin` 接口续期。
- 多端登录互踢：登录时按 `username` 找旧 token key 删掉（一个用户只允许一个会话）。
