# 04-1 用户管理（分页 / 多条件筛选 / 导出 / 重置密码 / 启停 / 导入）

> 上接：[[SpringBoot+Vue3后台搭建/04-权限管理模块/00-索引]]

## 1.1 后端：Controller（完整能力）

```java
@RestController
@RequestMapping("/system/user")
public class SysUserController {
    @Resource private ISysUserService userService;

    /** 列表：分页 + 多条件筛选（@PreAuthorize 校验本接口权限串） */
    @PreAuthorize("hasPermi('system:user:list')")
    @GetMapping("/list")
    public R<SysUser> list(SysUser user, PageQuery pq,
                                @RequestParam(required=false) Long[] deptIds) {
        Page<SysUser> page = userService.selectUserPage(
                new Page<>(pq.getPageNum(), pq.getPageSize()), user, deptIds);
        return R.ok(page);
    }

    @PreAuthorize("hasPermi('system:user:query')")
    @GetMapping("/{id}")
    public AjaxResult get(@PathVariable Long id) {
        return AjaxResult.success(userService.getById(id));
    }

    /** 新增：密码用 BCrypt 加密（[[../03-后端基础框架/03-SpringSecurity与JWT鉴权]] 的 passwordEncoder） */
    @PreAuthorize("hasPermi('system:user:add')")
    @PostMapping
    public AjaxResult add(@Valid @RequestBody SysUser user) {
        if (userService.checkUserNameUnique(user))
            throw new BusinessException("账号已存在");
        user.setPassword(passwordEncoder.encode(defaultPwd));  // 默认密码取参数表
        userService.save(user);
        return AjaxResult.success();
    }

    @PreAuthorize("hasPermi('system:user:edit')")
    @PutMapping
    public AjaxResult edit(@Valid @RequestBody SysUser user) {
        userService.updateById(user);
        return AjaxResult.success();
    }

    /** 删除（逻辑删，del_flag=2，见 [[../03-后端基础框架/02-MyBatisPlus与Redis配置]]） */
    @PreAuthorize("hasPermi('system:user:remove')")
    @DeleteMapping("/{ids}")
    public AjaxResult remove(@PathVariable Long[] ids) {
        userService.removeBatchByIds(Arrays.asList(ids));
        return AjaxResult.success();
    }

    /** 重置密码：管理员重置为默认密码 */
    @PreAuthorize("hasPermi('system:user:resetPwd')")
    @PutMapping("/resetPwd")
    public AjaxResult resetPwd(@RequestBody SysUser user) {
        userService.resetPwd(user.getUserId(), defaultPwd);
        return AjaxResult.success();
    }

    /** 启用/禁用账号 */
    @PreAuthorize("hasPermi('system:user:edit')")
    @PutMapping("/changeStatus")
    public AjaxResult changeStatus(@RequestBody SysUser user) {
        userService.updateById(user);   // 只 set 了 status
        return AjaxResult.success();
    }

    /** 导出 Excel（EasyExcel） */
    @PreAuthorize("hasPermi('system:user:export')")
    @PostMapping("/export")
    public void export(SysUser user, HttpServletResponse response) throws IOException {
        List<SysUser> list = userService.list(Wrappers.query(user));
        response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
        response.setHeader("Content-Disposition", "attachment;filename=user.xlsx");
        EasyExcel.write(response.getOutputStream(), SysUserExcelVO.class)
                 .sheet("用户数据").doWrite(list);
    }

    @Resource private PasswordEncoder passwordEncoder;
    @Value("${sys.user.initPassword:123456}") private String defaultPwd;
}
```

**逐接口解释**
- `@PreAuthorize("hasPermi('system:user:list')")`：方法级权限。**前提**是 `SecurityConfig` 开启 `@EnableMethodSecurity`（Security 6 写法），且 `JwtFilter` 把用户权限塞进了 `Authentication.authorities`（[[../03-后端基础框架/03-SpringSecurity与JWT鉴权]] 3.4）。没有对应权限的角色，访问直接 403，**前端按钮也会按这个串隐藏**（见下文 `v-hasPermi`）。
- `selectUserPage(...)`：多条件（用户名模糊、状态、部门 in）由 Service 用 `QueryWrapper` 拼（见 1.3）。
- **导出**用 `EasyExcel`：`SysUserExcelVO` 是**导出专用 VO**（字段上加 `@ExcelProperty("用户ID")`），与数据库实体解耦——敏感字段（password）绝不进导出 VO。
- **重置密码**永远走 BCrypt 重新 encode，绝不存明文。

## 1.3 Service：多条件分页

```java
@Service
public class SysUserServiceImpl extends ServiceImpl<SysUserMapper, SysUser>
        implements ISysUserService {

    @Override
    public Page<SysUser> selectUserPage(Page<SysUser> page, SysUser q, Long[] deptIds) {
        QueryWrapper<SysUser> w = new QueryWrapper<>();
        if (q.getUserName() != null)
            w.like("user_name", q.getUserName());        // 模糊
        if (q.getStatus() != null)
            w.eq("status", q.getStatus());                // 精确
        if (q.getPhonenumber() != null)
            w.like("phonenumber", q.getPhonenumber());
        if (deptIds != null && deptIds.length > 0)
            w.in("dept_id", Arrays.asList(deptIds));   // 部门批量
        w.eq("del_flag", "0");                            // 逻辑未删
        w.orderByDesc("create_time");
        return baseMapper.selectPage(page, w);
    }

    @Override
    public void resetPwd(Long userId, String defaultPwd) {
        SysUser u = new SysUser();
        u.setUserId(userId);
        u.setPassword(passwordEncoder.encode(defaultPwd));
        baseMapper.updateById(u);
    }
}
```
**讲解**：`QueryWrapper` 是 MP 的**条件构造器**——`like/eq/in/orderByDesc` 直接拼 WHERE，零 SQL。分页交给 `selectPage`（配合 [[../03-后端基础框架/02-MyBatisPlus与Redis配置]] 的 `PaginationInnerInterceptor`）。

`src/views/system/user/index.vue`（核心片段，完整布局见 [[../08-前端通用封装/01-表格与表单通用组件]]）
```vue
<template>
  <div>
    <!-- 搜索表单：多条件 -->
    <el-form :inline="true" :model="query">
      <el-form-item label="账号"><el-input v-model="query.userName" placeholder="账号" /></el-form-item>
      <el-form-item label="状态">
        <el-select v-model="query.status" clearable>
          <el-option label="正常" value="0" /><el-option label="停用" value="1" />
        </el-select>
      </el-form-item>
      <el-form-item>
        <el-button type="primary" @click="getList">查询</el-button>
        <!-- v-hasPermi：无权限按钮自动隐藏（[[../08-前端通用封装/02-路由权限与按钮指令]]） -->
        <el-button v-hasPermi="['system:user:add']" type="success" @click="openAdd">新增</el-button>
        <el-button v-hasPermi="['system:user:export']" @click="handleExport">导出</el-button>
      </el-form-item>
    </el-form>

    <!-- 表格：:data 直接吃后端 R.ok 的 rows -->
    <el-table :data="tableData.rows" v-loading="loading">
      <el-table-column type="selection" /><el-table-column prop="userName" label="账号" />
      <el-table-column prop="nickName" label="昵称" />
      <el-table-column prop="status" label="状态">
        <template #default="{row}">
          <el-switch v-model="row.status" active-value="0" inactive-value="1"
            @change="(v)=>handleStatus(row)" />
        </template>
      </el-table-column>
      <el-table-column label="操作">
        <template #default="{row}">
          <el-button v-hasPermi="['system:user:edit']" link @click="openEdit(row)">编辑</el-button>
          <el-button v-hasPermi="['system:user:resetPwd']" link @click="handleReset(row)">重置密码</el-button>
          <el-button v-hasPermi="['system:user:remove']" link type="danger" @click="handleDel(row)">删除</el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- 分页 -->
    <el-pagination v-model:current-page="query.pageNum" v-model:page-size="query.pageSize"
      :total="tableData.total" @current-change="getList" layout="total,prev,pager,next" />
  </div>
</template>

<script setup>
import { ref, reactive } from 'vue'
import { listUser, addUser, updateUser, delUser, resetPwd, changeStatus, exportUser } from '@/api/system/user'
import { ElMessage, ElMessageBox } from 'element-plus'

const query = reactive({ pageNum: 1, pageSize: 10, userName: '', status: '' })
const tableData = ref({ rows: [], total: 0 })
const loading = ref(false)

async function getList() {
  loading.value = true
  const res = await listUser(query)
  tableData.value = res          // 后端返回 {code:200, rows:[], total:100}
  loading.value = false
}
getList()

// 导出（blob 下载）
async function handleExport() {
  const blob = await exportUser()
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a'); a.href = url; a.download = 'user.xlsx'; a.click()
}

// 启停
async function handleStatus(row) {
  await changeStatus({ userId: row.userId, status: row.status })
  ElMessage.success('状态已更新')
}

// 删除
function handleDel(row) {
  ElMessageBox.confirm('确认删除？').then(async () => {
    await delUser(row.userId); ElMessage.success('已删除'); getList()
  })
}
</script>
```
**讲解**
- 后端返回 `R.ok(page)` → `{rows,total}`，前端 `:data="tableData.rows"` 直接绑定。
- `v-hasPermi` 是自定义指令，从 `store/user` 拿当前用户权限串列表，对不上就 `v-if=false` 把按钮删掉——**前后端双保险**：后端 `@PreAuthorize` 兜底，前端隐藏提升体验。
- 导出拿 `blob`，用 `URL.createObjectURL` + `<a download>` 触发浏览器下载。
