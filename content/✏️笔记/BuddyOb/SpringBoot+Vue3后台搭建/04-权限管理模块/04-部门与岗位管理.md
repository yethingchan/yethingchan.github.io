# 04-4 部门管理（树形）+ 岗位管理

> 上接：[[SpringBoot+Vue3后台搭建/04-权限管理模块/03-菜单树管理]]

## 4.1 部门树（与公司/分公司/车间/班组多级）
部门表 `sys_dept` 用 `parent_id` 表达层级。树形拼法和菜单一模一样（见 [[../04-权限管理模块/03-菜单树管理]] 3.2）。

```java
@RestController
@RequestMapping("/system/dept")
public class SysDeptController {
    @Resource private ISysDeptService deptService;

    @GetMapping("/list")
    public AjaxResult list(SysDept dept) {
        return AjaxResult.success(deptService.buildDeptTree(deptService.list()));
    }
    @PreAuthorize("hasPermi('system:dept:add')")
    @PostMapping public AjaxResult add(@RequestBody SysDept dept) {
        deptService.save(dept); return AjaxResult.success();
    }
    @PutMapping  public AjaxResult edit(@RequestBody SysDept dept) { ... }
    /** 调整上级：改 parent_id（要防止"自己挂自己子孙下"的环） */
    @PutMapping("/{deptId}/parent/{newParentId}")
    public AjaxResult changeParent(@PathVariable Long deptId, @PathVariable Long newParentId) {
        if (deptService.isDescendant(newParentId, deptId))
            throw new BusinessException("不能挂到自己的子部门下");
        deptService.updateById(new SysDept(deptId, newParentId));
        return AjaxResult.success();
    }
}
```
**讲解**：`buildDeptTree` 同菜单递归。`changeParent` 必须校验**不能把部门挂到它的子孙下**，否则树出现环、前端无限递归爆栈。

## 4.2 部门关联用户 → 数据权限的输入
用户表有 `dept_id`。一个用户在"本部门"数据权限下，能看的其实是 **自己 dept_id 及其所有子部门**。所以部门树还能"向下展开"：

```java
// 取某部门的所有后代 id（含自己），供数据权限用（[[../04-权限管理模块/05-数据权限实现]] 调用）
public List<Long> getDeptAndChildren(Long deptId) {
    List<Long> acc = new ArrayList<>(); acc.add(deptId);
    collectChildren(deptId, list(), acc);   // 同菜单的递归
    return acc;
}
```

## 4.3 岗位管理（用户绑定，用于筛选/审批）
岗位是"职务"维度，和部门正交。一张 `sys_post` + 关系表 `sys_user_post`。

```java
@RestController
@RequestMapping("/system/post")
public class SysPostController {
    @Resource private ISysPostService postService;

    @GetMapping("/list")
    public R<SysPost> list(SysPost post, PageQuery pq) {
        return R.ok(postService.selectPage(new Page<>(pq.getPageNum(), pq.getPageSize()), post));
    }
    @PostMapping public AjaxResult add(@Valid @RequestBody SysPost post) { ... }
    @PutMapping  public AjaxResult edit(@RequestBody SysPost post) { ... }
    @DeleteMapping("/{ids}") public AjaxResult remove(@PathVariable Long[] ids) { ... }
}
```
用户绑定岗位：编辑用户时传 `postIds` → 重建 `sys_user_post`。岗位在**审批流**（[[../09-业务扩展/03-报表与第三方对接]]）里常作"审批人候选"维度。

## 4.4 前端：部门树选择器
用户表单里"所属部门"用树形弹窗选：
```vue
<el-tree-select v-model="form.deptId" :data="deptTree"
  :props="{label:'deptName',value:'deptId'}" check-strictly />
```
`el-tree-select` 是 Element Plus 的树形下拉，直接吃 `buildDeptTree` 的结果。
