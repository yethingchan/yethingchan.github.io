# 02-3 日志 / 定时任务 / 监控表

> 上接：[[SpringBoot+Vue3后台搭建/02-数据库与RBAC/02-辅助表(字典参数公告)]]

## 1) 操作日志表（留痕所有写操作）

```sql
CREATE TABLE `sys_oper_log` (
  `oper_id`        BIGINT NOT NULL AUTO_INCREMENT COMMENT '日志主键',
  `title`          VARCHAR(50)  DEFAULT '' COMMENT '操作模块（如"用户管理"）',
  `business_type`   INT          DEFAULT 0  COMMENT '类型(0其它1新增2修改3删除4授权5导出6导入7强退8清空)',
  `method`         VARCHAR(100) DEFAULT '' COMMENT '方法名',
  `request_method` VARCHAR(10)  DEFAULT '' COMMENT '请求方式(GET/POST)',
  `operator_type`   VARCHAR(20)  DEFAULT 'PC' COMMENT '操作类别',
  `oper_name`      VARCHAR(50)  DEFAULT '' COMMENT '操作人',
  `dept_name`      VARCHAR(50)  DEFAULT '' COMMENT '部门名',
  `oper_url`        VARCHAR(255) DEFAULT '' COMMENT '请求URL',
  `oper_ip`         VARCHAR(128) DEFAULT '' COMMENT '操作IP',
  `oper_location`   VARCHAR(255) DEFAULT '' COMMENT '操作地点',
  `oper_param`      VARCHAR(2000) DEFAULT '' COMMENT '请求参数',
  `json_result`     VARCHAR(2000) DEFAULT '' COMMENT '返回参数',
  `status`          INT          DEFAULT 0  COMMENT '状态(0正常1异常)',
  `error_msg`       VARCHAR(2000) DEFAULT '' COMMENT '错误消息',
  `oper_time`       DATETIME    DEFAULT NULL COMMENT '操作时间',
  PRIMARY KEY (`oper_id`),
  KEY `idx_oper_name` (`oper_name`),
  KEY `idx_oper_time` (`oper_time`)
) ENGINE=InnoDB COMMENT='操作日志记录';
```
**讲解**：通过 AOP 切面在 Controller 执行后自动写入（[[../07-日志与监控/01-操作日志与登录日志]]）。`oper_param`/`json_result` 存请求与响应，方便事后追查；超过 2000 字符要截断，防爆库。

## 2) 登录日志表（安全审计）

```sql
CREATE TABLE `sys_login_log` (
  `info_id`    BIGINT NOT NULL AUTO_INCREMENT COMMENT '访问ID',
  `user_name`  VARCHAR(50)  DEFAULT '' COMMENT '用户账号',
  `ipaddr`     VARCHAR(128) DEFAULT '' COMMENT '登录IP',
  `login_location` VARCHAR(255) DEFAULT '' COMMENT '登录地点',
  `browser`    VARCHAR(50)  DEFAULT '' COMMENT '浏览器',
  `os`         VARCHAR(50)  DEFAULT '' COMMENT '操作系统',
  `status`     CHAR(1)     DEFAULT '0' COMMENT '状态(0成功1失败)',
  `msg`        VARCHAR(255) DEFAULT '' COMMENT '提示消息',
  `login_time` DATETIME    DEFAULT NULL COMMENT '访问时间',
  PRIMARY KEY (`info_id`)
) ENGINE=InnoDB COMMENT='系统访问记录';
```
**讲解**：登录成功/失败都记。`status=1` 失败次数多 → 触发暴力破解预警（[[../10-安全防护/01-密码加密与防暴破IP名单]]）。IP 地点用纯真库/IP 库解析。

## 3) Quartz 定时任务表（两套：任务定义 + 执行日志）

```sql
-- 任务定义（与 Quartz 自带表可共存；这里用业务表驱动更易管理）
CREATE TABLE `sys_job` (
  `job_id`        BIGINT NOT NULL AUTO_INCREMENT COMMENT '任务ID',
  `job_name`      VARCHAR(64)  DEFAULT '' COMMENT '任务名称',
  `job_group`     VARCHAR(64)  DEFAULT 'DEFAULT' COMMENT '任务组名',
  `invoke_target` VARCHAR(500) DEFAULT '' COMMENT '调用目标(如 jobDemo.syncStock())',
  `cron_expression` VARCHAR(255) DEFAULT '' COMMENT 'cron表达式',
  `misfire_policy` VARCHAR(20) DEFAULT '3' COMMENT '计划策略(1立即2执行一次3放弃)',
  `concurrent`    CHAR(1)     DEFAULT '1' COMMENT '是否并发(0禁止1允许)',
  `status`         CHAR(1)     DEFAULT '0' COMMENT '状态(0正常1暂停)',
  `create_time`    DATETIME    DEFAULT NULL,
  PRIMARY KEY (`job_id`)
) ENGINE=InnoDB COMMENT='定时任务调度表';

CREATE TABLE `sys_job_log` (
  `job_log_id`  BIGINT NOT NULL AUTO_INCREMENT COMMENT '日志ID',
  `job_name`    VARCHAR(64)  DEFAULT '' COMMENT '任务名',
  `job_group`   VARCHAR(64)  DEFAULT '' COMMENT '任务组',
  `invoke_target` VARCHAR(500) DEFAULT '' COMMENT '调用方法',
  `job_message` VARCHAR(500) DEFAULT '' COMMENT '日志信息',
  `status`       CHAR(1)     DEFAULT '0' COMMENT '执行状态(0成功1失败)',
  `exception_info` VARCHAR(2000) DEFAULT '' COMMENT '异常信息',
  `create_time`  DATETIME    DEFAULT NULL,
  PRIMARY KEY (`job_log_id`)
) ENGINE=InnoDB COMMENT='定时任务调度日志表';
```
**讲解**：`cron_expression` 如 `0 0 2 * * ?`（每天 2 点）。`invoke_target` 是字符串，运行时反射调 Bean 方法（[[../06-系统工具/03-Swagger接口文档与Quartz定时任务]]）。禁止并发(`concurrent=0`)时上一次没跑完不下新任务。

## 4) 监控相关说明
- **服务器/Redis/数据库监控不建表**：实时读 `OperatingSystemMXBean` / `RedisTemplate.info()` / Druid 监控端点（[[../07-日志与监控/02-监控与缓存备份]]）。
- **缓存管理**：直接操作 Redis，无需表。
- **数据库备份**：备份文件落磁盘，可用一张 `sys_backup` 记录元信息（文件名/大小/时间），非必须。
