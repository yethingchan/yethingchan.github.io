# 02 · 数据库与 RBAC 模型设计

> 上接：[[SpringBoot+Vue3后台搭建/01-工程初始化/03-前后端联调与跨域]]
> 本章目标：用 SQL 把"用户-角色-菜单-部门-岗位"的 RBAC 五元组 + 字典/参数/公告 + 日志/任务 全部建出来。

## RBAC 是什么（先懂模型再建表）
**RBAC（Role-Based Access Control）= 用户不直接挂权限，而是挂"角色"，角色挂"权限（菜单+按钮）"**。

```
       分配            拥有
用户 ───────► 角色 ───────► 权限(菜单/按钮)
 │                                    ▲
 └──── 属于 ──► 部门/岗位 ──────┘ (数据权限范围)
```
好处：加一个"仓库员"角色，一次性勾好权限，以后来 100 个仓库员都挂这个角色即可，不用每人配一遍。

## 五张核心表关系
| 表 | 作用 | 关键外键 |
|----|------|---------|
| `sys_user` | 用户 | `dept_id`→部门, `post_ids`(冗余或关系表) |
| `sys_role` | 角色(权限载体) | — |
| `sys_user_role` | 用户↔角色(多对多) | user_id, role_id |
| `sys_menu` | 菜单/按钮(权限项) | `parent_id`(树), `perms`(权限串) |
| `sys_role_menu` | 角色↔菜单(多对多) | role_id, menu_id |
| `sys_dept` | 部门(树) | `parent_id` |
| `sys_post` | 岗位 | — |
| `sys_user_post` | 用户↔岗位 | user_id, post_id |

> `sys_menu` 一张表装下"菜单+页面+按钮"三级：靠 `menu_type`（`M`菜单/`C`页面/`F`按钮）+ `parent_id` 树。
