# 03 · 后端基础框架（让一切"自动运转"的地基）

> 上接：[[SpringBoot+Vue3后台搭建/02-数据库与RBAC/03-日志任务监控表]]
> 目标：搭好四类"横切基础设施"，之后写业务只需专注 CRUD，不用重复造轮子。

## 四类基础设施
1. **统一返回 + 全局异常**：所有接口返回 `{code,msg,data}`；任何异常被兜底成统一格式。
2. **MyBatis-Plus + Redis**：分页/自动填充/通用 CRUD；Redis 序列化与缓存工具。
3. **Spring Security + JWT**：登录发 token，过滤器校验，受保护接口无 token 即 401。
4. **跨域 CORS + XSS 防护 + 防重复提交**：安全与清洁输入。

## 验证清单
- [ ] 任意 Controller 返回 `AjaxResult` 结构；故意抛异常返回统一错误。
- [ ] `userMapper.selectPage(...)` 能拿到分页（total/records）。
- [ ] `RedisTemplate.opsForValue().set(...)` 能存，且 Redis 里是 JSON 而非乱码。
- [ ] 不带 token 访问 `/system/user/list` 返回 401；带 token 正常。
- [ ] XSS 过滤器把 `<script>` 参数转义；重复提交被拦。
