# 03-1 统一返回与全局异常

> 上接：[[SpringBoot+Vue3后台搭建/03-后端基础框架/00-索引]]

## 1.1 为什么需要统一返回
前端希望**所有接口长一个样**：`{code:200, msg:'success', data:{...}}`。否则每个接口返回格式不同，前端要写一堆 if。约定：**200=成功，非 200=失败（含 msg）**。

## 1.2 AjaxResult（统一返回体）

```java
package com.example.admin.common.result;

import java.util.HashMap;

/** 统一返回：前端 axios 拦截器就靠 code 判断成败（见 [[../08-前端通用封装/01-表格与表单通用组件]]） */
public class AjaxResult extends HashMap<String, Object> {
    public static final int SUCCESS = 200;
    public static final int ERROR   = 500;

    public AjaxResult() { put("code", SUCCESS); put("msg", "success"); }

    // 成功（带数据）
    public static AjaxResult success(Object data) {
        AjaxResult r = new AjaxResult();
        r.put("data", data);
        return r;
    }
    // 成功（自定义消息）
    public static AjaxResult success(String msg, Object data) {
        AjaxResult r = new AjaxResult();
        r.put("msg", msg); r.put("data", data);
        return r;
    }
    // 失败
    public static AjaxResult error(String msg) {
        AjaxResult r = new AjaxResult();
        r.put("code", ERROR); r.put("msg", msg);
        return r;
    }
    public static AjaxResult error(int code, String msg) {
        AjaxResult r = new AjaxResult();
        r.put("code", code); r.put("msg", msg);
        return r;
    }
}
```
**讲解**：继承 `HashMap` 是为了前端直接 `res.data`/`res.code` 取字段，当然也可写成普通 POJO。关键是**所有 Controller 只返回 AjaxResult**。

## 1.3 R（表格分页返回，仿若依）

```java
package com.example.admin.common.result;

import com.baomidou.mybatisplus.core.metadata.IPage;
import java.io.Serializable;
import java.util.List;

/** 列表接口专用：前端 el-table 要 {total, rows} */
public class R<T> implements Serializable {
    private int code = 200;
    private String msg = "success";
    private long total;     // 总条数
    private List<T> rows; // 当前页数据

    public static <T> R<T> ok(IPage<T> page) {
        R<T> r = new R<>();
        r.total = page.getTotal();
        r.rows  = page.getRecords();
        return r;
    }
    // getter/setter 省略（Lombok @Data 即可）
}
```
**讲解**：MP 的 `IPage` 自带 `total`/`records`，包一层给前端。`rows` 对应 `el-table :data`。

## 1.4 业务异常 + 错误码枚举

```java
package com.example.admin.common.exception;

/** 主动抛的业务异常：如"用户名已存在" */
public class BusinessException extends RuntimeException {
    private final int code;
    public BusinessException(String msg) { super(msg); this.code = 500; }
    public BusinessException(int code, String msg) { super(msg); this.code = code; }
    public int getCode() { return code; }
}

// 常用错误码（集中管理，避免散落魔法数字）
public enum ErrorCode {
    USER_NOT_FOUND(1001, "用户不存在"),
    PASSWORD_ERROR(1002, "密码错误"),
    CAPTCHA_ERROR(1003, "验证码错误"),
    TOKEN_EXPIRED(1004, "令牌已过期");
    // ...
    public final int code; public final String msg;
    ErrorCode(int code, String msg) { this.code = code; this.msg = msg; }
}
```

## 1.5 全局异常处理器（兜底）

```java
package com.example.admin.common.exception;

import com.example.admin.common.result.AjaxResult;
import jakarta.validation.ConstraintViolationException;
import org.springframework.validation.BindException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice   // = @ControllerAdvice + @ResponseBody：拦截所有 @RestController 异常
public class GlobalExceptionHandler {

    /** 业务异常 → 用它的 code+msg */
    @ExceptionHandler(BusinessException.class)
    public AjaxResult handleBusiness(BusinessException e) {
        return AjaxResult.error(e.getCode(), e.getMessage());
    }

    /** @Valid 校验失败（@RequestBody 参数） */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public AjaxResult handleValid(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldError().getDefaultMessage();
        return AjaxResult.error(400, msg);   // 前端直接弹这个 msg
    }

    /** 参数校验失败（@RequestParam / 表单） */
    @ExceptionHandler(BindException.class)
    public AjaxResult handleBind(BindException e) {
        return AjaxResult.error(400, e.getFieldError().getDefaultMessage());
    }

    /** 兜底：未知异常 */
    @ExceptionHandler(Exception.class)
    public AjaxResult handleOther(Exception e) {
        e.printStackTrace();
        return AjaxResult.error("服务器内部错误：" + e.getMessage());
    }
}
```
**逐行解释**
- `@RestControllerAdvice`：是 Spring 全局异常拦截器，**所有 Controller 抛的异常都先到这里**，保证返回格式统一。
- `MethodArgumentNotValidException`：前端传 JSON（`@RequestBody`）但 `@Valid` 校验不过时抛。我们取 `FieldError.defaultMessage`——也就是 DTO 上 `@NotBlank(message="用户名不能为空")` 写的提示，直接返给前端弹窗。
- `BindException`：表单/`@RequestParam` 校验失败的另一形态，都得接住。
- 兜底 `Exception` 必须打日志（生产上送日志系统），别把堆栈直接返前端（泄漏信息）。

## 1.6 Controller 里怎么用

```java
@GetMapping("/user/{id}")
public AjaxResult getOne(@PathVariable Long id) {
    SysUser u = userService.getById(id);
    if (u == null) throw new BusinessException(ErrorCode.USER_NOT_FOUND);
    return AjaxResult.success(u);
}
```
前端收到 `{code:1001, msg:"用户不存在", data:null}`，弹窗即可。

- [ ] 故意 `throw new BusinessException(...)`，返回统一错误而非 500 白页。
