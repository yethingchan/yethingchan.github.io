## 1.2 字典缓存（Redis，避免每次查库）

```java
@Service
public class SysDictDataServiceImpl extends ServiceImpl<SysDictDataMapper, SysDictData>
        implements ISysDictDataService {

    @Resource private RedisCache redisCache;
    private static final String KEY = "dict:";

    /** 取某类型下所有 {label,value}，供前端下拉 */
    public List<DictDataVo> getDictByType(String dictType) {
        List<DictDataVo> cached = redisCache.getCacheObject(KEY + dictType);
        if (cached != null) return cached;                 // 命中缓存直接返
        List<SysDictData> list = list(Wrappers.<SysDictData>query()
                .eq("dict_type", dictType).orderByAsc("dict_sort"));
        cached = list.stream().map(d -> new DictDataVo(d.getDictLabel(), d.getDictValue())).toList();
        redisCache.setCacheObject(KEY + dictType, cached);   // 写缓存
        return cached;
    }

    /** 任何字典变更后清缓存（宁可少存，勿脏读） */
    @Override @Transactional
    public boolean save(SysDictData entity) { clear(entity.getDictType()); return super.save(entity); }
    private void clear(String type) { redisCache.deleteObject(KEY + type); }
}
```

**讲解**：`dict:{type}` 是每类一个 key。前端下拉走缓存，毫秒级。改字典后**必须清缓存**否则读到旧值——这正是 [[../03-后端基础框架/02-MyBatisPlus与Redis配置]] 2.5 缓存工具类的用武之地。

## 1.3 前端：下拉/标签自动读字典

`src/store/modules/dict.js`（Pinia，登录后一次性拉全量字典）
```js
import { defineStore } from 'pinia'
import { getDicts } from '@/api/system/dict'
export const useDictStore = defineStore('dict', {
  state: () => ({ dictMap: {} }),
  actions: {
    async loadAll() {
      const types = ['sys_user_sex','sys_normal_disable', 'wms_stock_status']
      for (const t of types) this.dictMap[t] = await getDicts(t)
    }
  }
})
```

`src/utils/dict.js`（公共方法，组件里直接调）
```js
import { useDictStore } from '@/store/modules/dict'
export function getDict(type) {
  return useDictStore().dictMap[type] || []
}
```

组件里用：
```vue
<el-select v-model="form.sex">
  <el-option v-for="d in getDict('sys_user_sex')" :key="d.value"
    :label="d.label" :value="d.value" />
</el-select>

<!-- 表格标签：用 listClass 直接上色 -->
<el-table-column label="状态">
  <template #default="{row}">
    <dict-tag :type="'sys_normal_disable'" :value="row.status" />
  </template>
</el-table-column>
```

**讲解**：`getDict('sys_user_sex')` 返回 `[{label:'男',value:'0'},...]` 直接喂 `el-select`。**新增"未知=2"只需后台加一条字典数据，前端零改动**——这就是字典化的价值。
