## 2.1 参数配置（系统开关 + 业务参数）

后端配置表 `sys_config`（见 [[../02-数据库与RBAC/02-辅助表(字典参数公告)]]）。读取两路：

```java
@Service
public class SysConfigServiceImpl extends ServiceImpl<SysConfigMapper, SysConfig>
        implements ISysConfigService {
    @Resource private RedisCache redisCache;
    private static final String KEY = "config:";

    /** 取参数值（先缓存后 DB） */
    public String getConfigValue(String configKey, String defaultVal) {
        String cached = redisCache.getCacheObject(KEY + configKey);
        if (cached != null) return cached;
        SysConfig c = getOne(Wrappers.<SysConfig>query().eq("config_key", configKey));
        String v = c == null ? defaultVal : c.getConfigValue();
        redisCache.setCacheObject(KEY + configKey, v);
        return v;
    }
    /** 改动后清缓存 */
    @Override @Transactional
    public boolean updateById(SysConfig entity) {
        redisCache.deleteObject(KEY + entity.getConfigKey());
        return super.updateById(entity);
    }
}
```
业务里调：
```java
String warn = configService.getConfigValue("wms.stock.warn", "10"); // 库存预警阈值
int threshold = Integer.parseInt(warn);
```

## 2.2 公告：发布 + 首页弹窗

```java
@RestController
@RequestMapping("/system/notice")
public class SysNoticeController {
    @Resource private ISysNoticeService noticeService;

    @PreAuthorize("hasPermi('system:notice:add')")
    @PostMapping public AjaxResult add(@Valid @RequestBody SysNotice n) {
        noticeService.save(n); return AjaxResult.success();
    }
    // list/edit/remove 略

    /** 登录后拉"生效中 + 本人角色可见 + 未读"的公告 */
    @GetMapping("/unread")
    public AjaxResult unread() {
        LoginUser u = SecurityUtils.getLoginUser();
        List<SysNotice> list = noticeService.listUnread(u.getUserId(), u.getRoleKeys());
        return AjaxResult.success(list);
    }
}
```
`listUnread` 逻辑：
```java
query().eq("status","0").le("effect_time", now())   // 生效中且已到生效时间
      .and(w -> w.eq("receive_scope","ALL")
                    .or().in("receive_scope", roleKeys));  // 全部 或 角色匹配
// 再排除已读（已读表/缓存，略）
```

## 2.3 前端：首页弹窗

```vue
<script setup>
import { onMounted } from 'vue'
import { getUnreadNotice } from '@/api/system/notice'
import { useUserStore } from '@/store/modules/user'
onMounted(async () => {
  const list = await getUnreadNotice()
  list.forEach(n => {
    ElNotification({ title: n.noticeTitle, message: n.noticeContent,
                  type: 'warning', duration: 0, position: 'top-right' })
  })
})
</script>
```
**讲解**：`duration:0` 不自动关，需用户手动关。置顶（`top='Y'`）的排前面。`receive_scope` 用 `roleKey` 逗号串匹配，前端只显本人角色范围内的。
