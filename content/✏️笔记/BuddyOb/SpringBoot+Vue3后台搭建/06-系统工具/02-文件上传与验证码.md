# 06-2 文件上传（本地 + OSS）+ 验证码

> 上接：[[SpringBoot+Vue3后台搭建/06-系统工具/01-代码生成器]]

## 2.1 本地上传（最常用）

```java
@RestController
@RequestMapping("/common/upload")
public class FileUploadController {
    @Value("${file.local-path:D:/upload}")  private String localPath;
    @Value("${file.allowed:jpg,png,jpeg,gif,pdf}") private String allowed;
    @Value("${file.max-size:10}") private long maxMb;   // 单位 MB

    @PostMapping
    public AjaxResult upload(@RequestParam("file") MultipartFile file) {
        // 1) 后缀白名单（防 exe/脚本 上传，[[../10-安全防护/04-文件上传拦截与接口限流]] 细讲）
        String ext = FilenameUtils.getExtension(file.getOriginalFilename()).toLowerCase();
        if (!Arrays.asList(allowed.split(",")).contains(ext))
            throw new BusinessException("不允许的文件类型");
        if (file.getSize() > maxMb * 1024 * 1024)
            throw new BusinessException("文件超过 " + maxMb + "MB");

        // 2) 重命名为 UUID，避免覆盖/路径穿越
        String name = UUID.randomUUID() + "." + ext;
        File dest = new File(localPath, name);
        file.transferTo(dest);

        // 3) 返回可访问 URL（Nginx 反代到 localPath，或存 OSS 返回外链）
        String url = "/profile/" + name;
        Map<String,String> m = new HashMap<>(); m.put("url", url); m.put("name", name);
        return AjaxResult.success(m);
    }
}
```
**讲解**
- **后缀白名单**是文件安全底线：只允许 `jpg/png/pdf` 等，`.exe/.sh/.jsp` 一律拒（详见 [[../10-安全防护/04-文件上传拦截与接口限流]]）。
- **UUID 重命名**：防两件事——① 同名覆盖；② 用户传 `../../etc/passwd` 这种**路径穿越**（原文件名绝不能直接拼路径）。
- `transferTo` 落盘；返回 URL 前端 `<img :src="url">` 回显。

## 2.2 OSS 上传（阿里云，生产推荐）

```xml
<dependency>
  <groupId>com.aliyun.oss</groupId>
  <artifactId>aliyun-sdk-oss</artifactId>
  <version>3.17.4</version>
</dependency>
```
```java
@Service
public class OssService {
    @Value("${oss.endpoint}") private String endpoint;
    @Value("${oss.key-id}")  private String keyId;
    @Value("${oss.key-secret}") private String keySecret;
    @Value("${oss.bucket}") private String bucket;

    public String upload(MultipartFile file) throws Exception {
        OSS oss = new OSSClientBuilder().build(endpoint, keyId, keySecret);
        String name = UUID.randomUUID() + "." + FilenameUtils.getExtension(file.getOriginalFilename());
        oss.putObject(bucket, name, file.getInputStream());   // 直传云端
        oss.shutdown();
        return "https://" + bucket + "." + endpoint + "/" + name;  // 外链
    }
}
```
**讲解**：对象存储省去自己管磁盘/扩容，返回的是**公网 URL**，前端直接 `<img>`。配置放 `application.yml` 的 `oss.*`，别硬编码。

## 2.4 图形验证码（登录用）

**思路**：后端画一张带随机码的图 → 码存 Redis（`captcha:{uuid}` 2 分钟过期）→ 前端登录时带 `code+uuid` 提交校验。

```java
@GetMapping("/captchaImage")
public AjaxResult captcha() throws IOException {
    // 1) 随机 4 位码
    String code = RandomUtil.randomString(4);
    String uuid = UUID.randomUUID().toString();
    // 2) 存 Redis（2 分钟）
    redisCache.setCacheObject("captcha:" + uuid, code, 2, TimeUnit.MINUTES);
    // 3) 画到 BufferedImage（简化：真实用 EasyCaptcha 库更抗机器）
    BufferedImage img = new BufferedImage(100, 40, BufferedImage.TYPE_INT_RGB);
    Graphics g = img.getGraphics(); g.setColor(Color.WHITE); g.fillRect(0,0,100,40);
    g.setColor(Color.BLUE); g.setFont(new Font("Arial", Font.BOLD, 28)); g.drawString(code, 15, 30);
    ByteArrayOutputStream os = new ByteArrayOutputStream();
    ImageIO.write(img, "png", os);
    String base64 = Base64.getEncoder().encodeToString(os.toByteArray());
    Map<String,String> m = Map.of("uuid", uuid, "img", "data:image/png;base64," + base64);
    return AjaxResult.success(m);
}
```
登录校验：
```java
String cached = redisCache.getCacheObject("captcha:" + body.getUuid());
if (cached == null) throw new BusinessException(ErrorCode.CAPTCHA_EXPIRED);
if (!cached.equalsIgnoreCase(body.getCode())) throw new BusinessException(ErrorCode.CAPTCHA_ERROR);
redisCache.deleteObject("captcha:" + body.getUuid());  // 一次性
```
> 生产用 **EasyCaptcha**（`com.github.whvcse:EasyCaptcha`）一行出图+算数码，比手画强。前端 `<img :src="img">` + 隐藏 `uuid` 随登录提交。

## 2.5 滑块 / 短信验证码（可选）

- **滑块**：前端拖动拼图，后端校验"拖动轨迹是否人类"（简单版只校验最终 X 坐标正确）。纯前端也能做，后端主要防脚本刷登录。
- **短信**：调阿里云/腾讯云 SMS SDK 发 6 位码，码存 Redis（`sms:{phone}`），登录/改密时校验。**关键**：发码接口要**限流**（同手机号 60 秒内只能发一次），否则被刷爆资费。

## 2.6 验证清单
- [ ] 传 `.exe` 被拒；传 `a/../../b.png` 不会穿越目录。
- [ ] 头像上传后返回 URL，前端 `<img>` 能显示。
- [ ] 登录时图形码错误/过期分别报对应错误；正确后该 uuid 立即可用一次。
- [ ] 切 OSS 后返回的是 `https://bucket.endpoint/...` 外链。
