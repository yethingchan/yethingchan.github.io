# 06-1 代码生成器（导表 → 一键出全套）

> 上接：[[SpringBoot+Vue3后台搭建/06-系统工具/00-索引]]

## 1.0 它解决什么
你正在用的"代码生成"功能，本质就这一节。**一张表 → 自动产出前后端 10 个文件**，省掉 80% 的样板 CRUD 代码。

## 1.1 整体流水线

```
① 读库元数据：INFORMATION_SCHEMA.COLUMNS
       拿到字段名/类型/注释/是否主键/是否必填
        ↓
② 建 TableInfo 模型（表名→类名、字段→属性、Java 类型映射）
        ↓
③ 套模板（Velocity/Freemarker）渲染每个文件
        ↓
④ 三选一：预览(返回字符串) / 下载(zip) / 写盘(项目目录)
```

## 1.3 读库元数据

```java
@Service
public class GenTableServiceImpl {
    @Resource private JdbcTemplate jdbc;   // 直接用 JDBC 读 information_schema

    /** 列出库里所有未被生成的业务表 */
    public List<GenTable> listTables() {
        return jdbc.query(
            "SELECT table_name, table_comment FROM information_schema.tables " +
            "WHERE table_schema = (SELECT DATABASE()) AND table_name NOT LIKE 'sys_%'",
            (rs, i) -> new GenTable(rs.getString(1), rs.getString(2)));
    }

    /** 读某表字段，拼成 GenTableColumn 列表 */
    public List<GenTableColumn> listColumns(String tableName) {
        return jdbc.query(
            "SELECT column_name, data_type, column_comment, " +
            "column_key, is_nullable FROM information_schema.columns " +
            "WHERE table_schema=(SELECT DATABASE()) AND table_name=?",
            (rs, i) -> {
                GenTableColumn c = new GenTableColumn();
                c.setColumnName(rs.getString("column_name"));
                c.setDataType(rs.getString("data_type"));       // varchar/bigint...
                c.setColumnComment(rs.getString("column_comment"));
                c.setPrimary("PRI".equals(rs.getString("column_key")));
                c.setRequired("NO".equals(rs.getString("is_nullable")));
                c.setJavaType(mapJavaType(c.getDataType())); // 类型映射
                c.setJavaField(toCamel(c.getColumnName()));        // 下划线→驼峰
                return c;
            }, tableName);
    }

    /** DB 类型 → Java 类型 */
    private String mapJavaType(String db) {
        return switch (db.toLowerCase()) {
            case "bigint" -> "Long";
            case "int","integer","tinyint" -> "Integer";
            case "varchar","char","text","longtext" -> "String";
            case "datetime","timestamp" -> "LocalDateTime";
            case "decimal" -> "BigDecimal";
            default -> "String";
        };
    }
}
```
**讲解**：`information_schema` 是 MySQL 自带的"元数据库"，字段信息全在这。生成器**不连业务表，而是查这张系统表**。`mapJavaType` 把 `varchar→String`/`bigint→Long`，这就是"自动识别字段类型"的背后。

## 1.4 模板示例（Entity.vm）

```velocity
package ${packageName}.modules.${moduleName}.domain;

import com.baomidou.mybatisplus.annotation.*;
import lombok.Data;

@Data
@TableName("${tableName}")
public class ${ClassName} {
#foreach($c in $columns)
    /** ${c.columnComment} */
    @TableField("${c.columnName}")
    private ${c.javaType} ${c.javaField};
#end
}
```
> 模板用 `${tableName}`/`$columns` 占位，引擎把 1.3 的 `GenTable` 当数据模型灌进去渲染。`$c.primary` 可决定是否加 `@TableId`。

## 1.5 生成控制器（一键产出全套的入口）

```java
@RestController
@RequestMapping("/tool/gen")
public class GenController {
    @Resource private GenTableService genService;

    /** ① 预览：返回每个文件的内容（前端分 tab 展示） */
    @GetMapping("/preview/{tableName}")
    public AjaxResult preview(@PathVariable String tableName) {
        return AjaxResult.success(genService.preview(tableName)); // Map<文件名,代码字符串>
    }

    /** ② 下载：打成 zip 流 */
    @GetMapping("/download/{tableName}")
    public void download(@PathVariable String tableName, HttpServletResponse resp) throws IOException {
        byte[] zip = genService.downloadZip(tableName);
        resp.setHeader("Content-Disposition", "attachment;filename=ruoyi.zip");
        resp.getOutputStream().write(zip);
    }

    /** ③ 直接写入项目目录（需配 genPath，谨慎使用） */
    @GetMapping("/genCode/{tableName}")
    public AjaxResult genCode(@PathVariable String tableName) {
        genService.writeToProject(tableName);
        return AjaxResult.success("生成成功，请刷新项目");
    }
}
```
`writeToProject` 落盘示例（注意路径权限）：
```java
void writeToProject(String table) {
    Map<String,String> files = renderAll(table);   // 渲染全部
    String base = genConfig.getGenPath();           // 如 D:/project/admin
    for (var e : files.entrySet()) {
        Path p = Paths.get(base, e.getKey());  // key 含相对路径
        Files.createDirectories(p.getParent());
        Files.writeString(p, e.getValue(), StandardCharsets.UTF_8);
    }
}
```
