# 02 实体注解与表映射

> 上接：[[MyBatis-Plus/01-核心概念与快速集成]]
> 注解是 MP "零 XML" 的基石：靠注解把 Java 字段和表列自动对上。

## 2.1 注解全景

| 注解 | 作用 | 常用属性 |
|------|------|-----------|
| `@TableName` | 实体 ↔ 表名 | `value`（表名）、`schema` |
| `@TableId` | 标记主键 | `type`（[[MyBatis-Plus/10-主键策略与雪花算法]]） |
| `@TableField` | 字段 ↔ 列 | `value`（列名）、`fill`、`exist=false`（非表字段） |
| `@TableLogic` | 逻辑删除 | 字段（值看全局配置） |
| `@Version` | 乐观锁 | 字段（[[MyBatis-Plus/12-逻辑删除与乐观锁]]） |
| `@EnumValue` | 枚举存库 | 标记枚举里映射数据库的值 |
| `@TableField(typeHandler=...)` | 复杂类型 | JSON 等（[[MyBatis-Plus/14-多租户与JSON类型处理器]]） |

## 2.2 @TableName

```java
@TableName("sys_user")          // 表名
// @TableName(value="sys_user", schema="ruoyi")  // 跨 schema
public class SysUser { ... }
```
> 全局可配 `table-prefix: sys_` 省得每个实体写前缀。`yml` 见 [[MyBatis-Plus/01-核心概念与快速集成]] 1.3。

## 2.3 @TableId 主键

```java
@TableId(type = IdType.AUTO)        // 数据库自增（MySQL AUTO_INCREMENT）
// @TableId(type = IdType.ASSIGN_ID) // 雪花（默认，3.5 全局默认就是这个）
private Long userId;
```
> 不写 `@TableId` 也能跑，但 MP 不知道哪列是主键会告警。详见 [[MyBatis-Plus/10-主键策略与雪花算法]]。

## 2.4 @TableField（最常用）

```java
public class SysUser {
    @TableId private Long userId;

    @TableField("user_name")        // 列名和字段名不一致时显式指定
    private String userName;

    @TableField(fill = FieldFill.INSERT)       // 插入时自动填（见 [[MyBatis-Plus/11-自动填充MetaObjectHandler]]）
    private LocalDateTime createTime;

    @TableField(fill = FieldFill.INSERT_UPDATE) // 插入+更新都填
    private LocalDateTime updateTime;

    @TableField(exist = false)        // 不是表字段！只是前端传参/临时计算用
    private String deptName;          // 联表查出来的，库里没这列

    @TableLogic                    // 逻辑删除字段
    private String delFlag;
}
```
**要点**
- `exist=false` 极常用：DTO 里常带"确认密码""部门名"等库里不存在的字段，**不加 `exist=false` 会报"找不到列"**。
- `fill` 配合 `MetaObjectHandler` 才能自动填，单独写无效（见 11 章）。
- 列名和字段名符合 `下划线↔驼峰` 规则时（`user_name`↔`userName`），**可省略 `@TableField("user_name")`**——但显式写更稳、可读。

## 2.5 @EnumValue（枚举优雅落库）

```java
public enum StatusEnum {
    NORMAL(0, "正常"), DISABLED(1, "停用");
    @EnumValue                 // 存库的是 code（0/1），不是枚举名
    private final int code;
    private final String desc;
    // getter...
}
// 实体里直接用：private StatusEnum status;  MP 自动按 @EnumValue 映射
```

## 2.6 全局配置里的映射项

```yaml
mybatis-plus:
  global-config:
    db-config:
      table-prefix: sys_        # 实体 User → 表 sys_user（免 @TableName）
      id-type: ASSIGN_ID        # 默认主键策略
      logic-delete-field: delFlag
      logic-delete-value: "2"
      logic-not-delete-value: "0"
  configuration:
    map-underscore-to-camel-case: true   # 下划线自动转驼峰
```

## 验证清单

- [ ] 实体字段名和列名不一致时，靠 `@TableField("列名")` 对上，查询不报错。
- [ ] `exist=false` 的字段参与查询/新增时，SQL 不含该列。
- [ ] 枚举字段入库的是 `@EnumValue` 的值，不是 `NORMAL` 这种名字。
- [ ] 配了 `table-prefix` 后，`User` 实体自动找 `sys_user` 表。
