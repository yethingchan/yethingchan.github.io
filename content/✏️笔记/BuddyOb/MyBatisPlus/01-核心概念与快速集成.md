# 01 核心概念与快速集成

> 上接：[[MyBatisPlus/00-总览与学习路线]]

## 1.1 三个核心抽象

| 概念 | 是什么 | 你写在哪 |
|------|--------|-----------|
| **Model/Entity** | 数据库表对应的 Java 对象 | `domain/User.java`，加 `@TableName` |
| **BaseMapper<T>** | 通用 CRUD 接口（MP 已实现的） | `mapper/UserMapper extends BaseMapper<User>` |
| **IService<T> + ServiceImpl<M,T>** | 比 Mapper 再高一层，带批量/链式 | `service/IUserService` + `UserServiceImpl` |

> MP 的思路：**你只写接口继承，MP 把实现塞进来**。所以 `UserMapper` 啥方法都不用写，就有 `insert/selectById/selectList/updateById/deleteById...`。

## 1.2 Maven 依赖（Spring Boot 3）

```xml
<dependency>
  <groupId>com.baomidou</groupId>
  <artifactId>mybatis-plus-boot-starter</artifactId>
  <version>3.5.7</version>
</dependency>
<!-- 注意：不要再引原生 mybatis-spring-boot-starter，会冲突 -->
```

## 1.3 application.yml 配置

```yaml
mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml   # 你手写 XML 的位置（MP 通用 CRUD 不需要）
  type-aliases-package: com.example.admin.**.domain   # 实体包（类型别名，XML 里写 resultType 不用全限定名）
  configuration:
    map-underscore-to-camel-case: true           # 下划线→驼峰（db:user_name → Java:userName）
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl  # 开发期打印 SQL
  global-config:
    db-config:
      id-type: ASSIGN_ID          # 全局默认主键策略（雪花，见 [[MyBatisPlus/10-主键策略与雪花算法]]）
      logic-delete-field: delFlag  # 逻辑删除字段名（见 [[MyBatisPlus/12-逻辑删除与乐观锁]]）
      logic-delete-value: "2"      # 删除标记
      logic-not-delete-value: "0"  # 未删标记
```

> ⚠️ **和你 test-module 的坑呼应**：这里 `type-aliases-package` 必须覆盖你实体所在包。你之前 `Locations` 报 `Could not resolve type alias`，就是 `cn.yething.**.domain` 没被包进来。

## 1.4 启动类扫描

```java
@SpringBootApplication
@MapperScan("com.example.admin.**.mapper")   // 扫 Mapper 接口（也可在每个 Mapper 上 @Mapper）
public class AdminApplication { public static void main(String[] a){ SpringApplication.run(AdminApplication.class,a);} }
```

## 1.5 第一个能跑的 insert

```java
// domain/User.java
@Data
@TableName("sys_user")
public class User {
    @TableId(type = IdType.AUTO)   // 自增主键
    private Long userId;
    private String userName;
    private Integer age;
    private String status;
}

// mapper/UserMapper.java
public interface UserMapper extends BaseMapper<User> {}  // 空接口，MP 注入实现

// 任意地方
@Resource UserMapper userMapper;
User u = new User(); u.setUserName("张三"); u.setAge(20);
userMapper.insert(u);     // 自增主键回写 u.getUserId()
System.out.println(u.getUserId());  // 数据库生成的值已回填
```

**讲解**
- `insert` 后，自增/`ASSIGN_ID` 生成的主键**自动回填**到实体对象（`u.getUserId()` 立即可用）。
- 不用写任何 XML、不用建 `UserMapper.xml`——这就是 MP 省下的 80% 体力活。
