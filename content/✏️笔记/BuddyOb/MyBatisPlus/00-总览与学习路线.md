# MyBatis-Plus 知识体系（从入门到企业级）

> 目的：系统讲清 MyBatis-Plus（简称 MP）的全部能力，**重中之重是各种 Wrapper（条件构造器）**——它让你几乎不用写 SQL 就能完成 90% 查询。
> 本库用 Obsidian `[[双链]]` 串联，建议按编号顺序读。
> 前置：[[../MyBatis Mapper XML/00-总览与目录]]（原生 MyBatis 语法）——MP 是 MyBatis 的增强，先懂原生再看增强更顺。
> 实战关联：本教程的 Spring 后台全程用 MP，见 [[../SpringBoot+Vue3后台搭建/03-后端基础框架/02-MyBatisPlus与Redis配置]]。

## 一、MP 是什么

| 维度 | 原生 MyBatis | MyBatis-Plus |
|------|---------------|----------------|
| SQL 写法 | 全手写 XML / 注解 | **通用 CRUD 零 SQL**，复杂 SQL 仍可手写 |
| 条件拼接 | 在 XML 里写 `<if>` `<foreach>` | **Wrapper 链式拼 WHERE**（类型安全可选） |
| 分页 | 自己写 `limit` + count | **分页插件自动**拦截 `selectPage` |
| 主键 | 手写 `selectKey` | **雪花/自增/UUID 策略一行配** |
| 逻辑删/乐观锁 | 手写 | **注解 + 拦截器自动** |

> 一句话：**MP = MyBatis + 通用 Mapper/Service + Wrapper + 一堆拦截器**。复杂多表关联你仍写 XML，简单单表 CRUD 全交给 MP。

## 二、技术栈（版本固定，代码才跑得起来）

| 组件 | 版本 | 作用 |

## 三、学习路线（四阶，由易到难）

```
L1 入门（会用）
  01 核心概念与快速集成  → pom + yml + 扫描，能跑通第一个 insert
  02 实体注解与表映射     → @TableName/@TableId/@TableField/@TableLogic/@Version
  03 BaseMapper 的 CRUD  → insert/delete/update/selectById/selectList...

L2 CRUD 与 Wrapper ★重点
  04 IServer / ServiceImpl → 比 BaseMapper 更好用的上层 API（get/save/remove/list/page）
  05 QueryWrapper 详解    → 所有查询条件 eq/like/between/in/orderBy/apply...（最常用）
  06 UpdateWrapper 详解   → set/setSql，更新不带实体
  07 LambdaWrapper 与列安全 → LambdaQuery/UpdateWrapper，用方法引用防字段名写错
  08 动态条件与自定义 SQL  → condition 参数、nested/or/and、@Select("${ew}") 结合手写 SQL

L3 高级特性
  09 分页插件            → PaginationInnerInterceptor + Page/IPage
  10 主键策略            → IdType.ASSIGN_ID 雪花算法
  11 自动填充            → MetaObjectHandler + FieldFill
  12 逻辑删除与乐观锁    → @TableLogic / @Version + 拦截器

L4 企业级
  13 代码生成器          → FastAutoGenerator 一键出 Entity/Mapper/Service/Controller
  14 多租户与 JSON 处理器 → TenantLineInnerInterceptor / JacksonTypeHandler
  15 企业级实战与避坑     → 防全表更新、性能、联表、常见错误
```

## 四、学习清单（照着打勾）

- [ ] `pom` 引入 `mybatis-plus-boot-starter`，`yml` 配好 `mapper-locations`/`type-aliases-package`
- [ ] `User` 实体加 `@TableName`/`@TableId`，`UserMapper extends BaseMapper<User>` 能 `insert`
- [ ] 用 `QueryWrapper` 写出"年龄>18 且 姓名含 '张' 且 状态=1"的查询
- [ ] 用 `LambdaQueryWrapper` 重写上面的查询（用 `User::getAge` 而非字符串列名）
- [ ] 用 `UpdateWrapper` 把"所有停用用户"的 `remark` 置为某个值（不带实体对象）
- [ ] 动态条件：查询参数有值时才拼 `like`，为空时跳过（用 `condition` 参数）
- [ ] `selectPage(new Page<>(1,10), wrapper)` 拿到 `rows` + `total`
- [ ] 配好 `MetaObjectHandler`，`createTime`/`updateTime` 自动填充
- [ ] `del_flag` 逻辑删除：`removeById` 自动变成 `UPDATE ... SET del_flag=1`
- [ ] `@Version` 乐观锁：并发改同一条不丢更新
- [ ] `FastAutoGenerator` 连库一键生成全套代码
- [ ] 能对着 [[MyBatisPlus/05-QueryWrapper详解]] 的"速查表"默写所有条件方法
