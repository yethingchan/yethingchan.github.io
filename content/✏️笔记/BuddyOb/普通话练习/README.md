## 核心训练理念（先读这段）

发音这件事，本质是**肌肉记忆**。就像健身，看再多不练没用，每天练一点点、坚持下来才有效。

**三个关键原则：**

1. **慢比快重要。** 初期一定要慢、要夸张。把每个字的口型、舌位做到位，宁可像播音腔一样"过分标准"。速度是后期自然形成的，一开始追求快只会带着错误加速。

2. **听 + 说 + 录。** 光说不听等于闭眼练字。每次练完用手机录下来回放，你会立刻发现哪里含糊、哪里吞音。对比标准发音（可用系统朗读、新闻联播）找差距。

3. **量的积累。** 每天 15–20 分钟，比周末突击 3 小时有效得多。发音肌肉需要**高频、短时**的反复刺激。

## 每天怎么练（推荐 15–20 分钟固定流程）

```
① 热身 3 分钟   →  口腔操 + 气息练习（见 01 篇）
② 正音 5 分钟   →  当天的专项（前后鼻音 / 平翘舌，见 02、03 篇）
③ 绕口令 3 分钟 →  嘴皮子灵活度（见 04 篇）
④ 朗读 5 分钟   →  一段材料，追求清晰有感情（见 06 篇）
⑤ 复盘 2 分钟   →  录音回放，记下今天最含糊的 3 个字
```

坚持这个循环，配合 [07-30天练习计划.md](./07-30天练习计划.md) 的节奏，一个月能听出明显变化。

## 三个立刻能用的小技巧

1. **说话前先"立起来"**：站直、肩膀放松、下巴微收，气从小腹发出，声音自然更稳更亮。含糊往往是因为气不够、含着说。

2. **句尾别掉气**：很多人前半句清楚、后半句吞掉。刻意练习"把最后一个字送出去"，句子完整度立刻提升。

3. **给逻辑词重音**：说话有逻辑，一半靠内容，一半靠"首先/但是/所以/更重要的是"这些词说清楚。给它们一点停顿和重音，听众就能跟上你的思路。
