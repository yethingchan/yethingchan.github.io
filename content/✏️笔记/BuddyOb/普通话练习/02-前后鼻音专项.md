# 02 · 前后鼻音专项（an/en ↔ ang/eng；in ↔ ing）

> 前后鼻音不分，是南方朋友最普遍的发音问题。
> 本篇给你**原理 + 判别方法 + 大量对比词 + 练习句段**，每天练一组。

---

## 一、原理：区别到底在哪

**前鼻音（-n）**和**后鼻音（-ng）**的唯一区别在**收音时舌头的位置**：

| 类型 | 韵尾 | 收音动作 | 感觉 |
| --- | --- | --- | --- |
| **前鼻音** | -n | 舌尖**顶住上齿龈**（上门牙后面那道肉埂） | 声音靠前，鼻腔轻 |
| **后鼻音** | -ng | 舌根**抬起顶住软腭**（喉咙上方），舌尖不动 | 声音靠后，鼻腔共鸣重 |

**一句话记忆：**
- 前鼻音 = 舌尖往前顶（**n**，像"恩"字收尾）。
- 后鼻音 = 舌根往后缩（**ng**，像"嗯"字带喉音、或英文 sing 的收尾）。

---

## 二、自测判别方法

**方法 1：捏鼻子**
念一个字，捏住鼻子——
- 如果声音明显受阻、发闷 → 你发的是**后鼻音**（鼻腔共鸣强）。
- 如果影响较小 → 偏**前鼻音**。

**方法 2：看舌尖**
念完字，停在收尾口型上，感觉舌尖：
- 顶在上门牙后面 → 前鼻音 -n ✅
- 悬空、舌根发紧 → 后鼻音 -ng ✅

**方法 3：拖长音**
把韵尾拖长："安——n" vs "昂——ng"，反复切换，体会舌头前后移动。

## 三、an ↔ ang 对比词（重点练）

先各念 5 遍，再左右交替念，做出区别：

| 前鼻 an | 后鼻 ang |
| --- | --- |
| 安（ān） | 肮（āng） |
| 班（bān） | 帮（bāng） |
| 三（sān） | 桑（sāng） |
| 谈（tán） | 唐（táng） |
| 干（gān） | 刚（gāng） |
| 山（shān） | 商（shāng） |
| 蓝（lán） | 狼（láng） |
| 反（fǎn） | 访（fǎng） |
| 站（zhàn） | 丈（zhàng） |
| 万（wàn） | 忘（wàng） |

**易错词组（生活高频）：**
- 帮忙（bāng máng）——注意两个都是后鼻。
- 参观（cān guān）——两个都是前鼻。
- 单位（dān wèi）／ 当心（dāng xīn）
- 商店（shāng diàn）／ 山顶（shān dǐng）

## 四、en ↔ eng 对比词

| 前鼻 en | 后鼻 eng |
| --- | --- |
| 奔（bēn） | 崩（bēng） |
| 门（mén） | 蒙（méng） |
| 分（fēn） | 风（fēng） |
| 根（gēn） | 更（gēng） |
| 神（shén） | 生（shēng） |
| 陈（chén） | 成（chéng） |
| 人（rén） | 仍（réng） |
| 真（zhēn） | 争（zhēng） |

**易错词组：**
- 成分（chéng fèn）——前一个后鼻、后一个前鼻，最考验区分。
- 身份（shēn fèn）／ 生根（shēng gēn）
- 风分（fēng fēn）对比：风（后鼻）、分（前鼻）。

---

## 五、in ↔ ing 对比词（南方尤其易混）

| 前鼻 in | 后鼻 ing |
| --- | --- |
| 因（yīn） | 英（yīng） |
| 心（xīn） | 星（xīng） |
| today 民（mín） | 明（míng） |
| 拼（pīn） | 平（píng）※对比 pin/ping |
| 林（lín） | 灵（líng） |
| 信（xìn） | 姓（xìng） |
| 金（jīn） | 京（jīng） |
| 亲（qīn） | 青（qīng） |

**易错词组：**
- 心情（xīn qíng）——心是前鼻、情是后鼻。
- 明星（míng xīng）／ 亲近（qīn jìn，都前鼻）／ 清晰（qīng xī）
- 人民（rén mín，都前鼻）对比 人名（rén míng，名是后鼻）。

## 六、专项练习句（把对比词放进句子）

放慢速度，把每个鼻韵尾都收清楚，读三遍并录音：

1. 老**王**（后）在**田**（前）里**帮**（后）**忙**（后）种**棉**（前）花。
2. **今**（前）天**天**（前）气**晴**（后）朗，**心**（前）**情**（后）特别好。
3. 这家**商**（后）**店**（前）的**生**（后）**意**很**兴**（后）**隆**（后）。
4. **人**（前）**民**（前）广**场**（后）上**灯**（后）光**明**（后）亮。
5. **陈**（前）**成**（后）**分**（前）不清**成**（后）**分**（前），被老师**批**评。
6. **风**（后）一**吹**，**门**（前）就**砰**（后）地**关**（前）上了。
7. **青**（后）**山**（前）**绿**水**间**（前），**清**（后）**风**（后）拂**面**（前）来。

## 七、绕口令（前后鼻音专攻）

**绕口令 1：分不清 vs 是最灵**
> 天上一群**鹅**，湖里一群**鹅**，
> 鹅飞湖水**动**（后），鹅落水生**波**。

**绕口令 2：藏 vs 长**
> 墙上画只**红**（后）凤**凰**（后），
> 红凤凰、粉凤凰、红粉凤凰花凤凰。

**绕口令 3：清 vs 亲**
> **清**（后）**清**（后）河边一根**藤**（后），
> **青**（后）藤**顶**（后）上挂铜**铃**（后），
> **风**（后）吹藤动铜铃动，风停藤定铜铃**静**（后）。

**绕口令 4：新 vs 星**
> 门前有四**棵**树，树上结满**新**（前）果，
> **星**（后）**星**（后）眨眼**心**（前）欢喜，**心**（前）想**明**（后）天**摘**满笼。

---

## 八、今日打卡建议

```
1. an/ang 对比词 一轮        （3分钟）
2. en/eng + in/ing 各挑一半   （3分钟）
3. 专项练习句 读3遍          （2分钟）
4. 绕口令 挑1条 慢→快         （2分钟）
5. 录音回放，标出仍然分不清的字
```

**判断进步的标准**：能在句子里"不假思索"地把前后鼻音发对，而不是刻意想才对——那说明已经形成肌肉记忆了。
