# 03 · 平翘舌音专项（z/c/s ↔ zh/ch/sh）+ n/l + h/f

> 平翘舌不分（把"是"读成"四"、"知道"读成"资道"）是另一个高频问题。
> 本篇顺带覆盖 n/l 不分、h/f 不分。给你判别方法和大量对比材料。

---

## 一、平舌 vs 翘舌：原理

| 类型 | 声母 | 舌头位置 | 感觉 |
| --- | --- | --- | --- |
| **平舌音** | z、c、s | 舌尖平抵**上门牙背面** | 声音"扁"、靠前 |
| **翘舌音** | zh、ch、sh、r | 舌尖**翘起**抵**硬腭前部**（上齿龈往后一点） | 声音"卷"、靠后 |

**关键动作**：翘舌音发音时，舌尖要**卷起来往上翘**，抵住上颚。平舌音舌尖是平的、贴在门牙后。

**自测**：念"知"（zhī），舌尖应该是翘起来顶住上颚的；如果舌尖平平贴在门牙后，就发成了平舌"资"（zī）。

---

## 二、对应关系（一一对照记）

```
平舌  →  翘舌
 z   →   zh    （资 → 知）
 c   →   ch    （疵 → 吃）
 s   →   sh    （思 → 师）
```

## 五、s ↔ sh 对比词（最高频）

| 平舌 s | 翘舌 sh |
| --- | --- |
| 思（sī） | 师（shī） |
| 四（sì） | 是（shì） |
| 塞（sāi） | 筛（shāi） |
| 桑（sāng） | 商（shāng） |
| 松（sōng） | 舂（chōng）… 对比取 送 sòng / 中 |
| 苏（sū） | 书（shū） |
| 三（sān） | 山（shān） |
| 岁（suì） | 睡（shuì） |

**超高频易错词（务必练熟）：**
- 是不是（shì bu shì）——别读成"四不四"。
- 四十四（sì shí sì）——平翘交替，经典难点。
- 老师（lǎo shī）／ 思考（sī kǎo）
- 知识（zhī shí）／ 主持（zhǔ chí）／ 城市（chéng shì）

## 六、经典对比句：四是四，十是十

慢速念，把每个 s / sh 分清楚，这是检验平翘舌的黄金标准：

> 四（sì）是（shì）四（sì），
> 十（shí）是（shì）十（shí），
> 十四（shí sì）是（shì）十四（shí sì），
> 四十（sì shí）是（shì）四十（sì shí），
> 谁（shéi）把（bǎ）十四（shí sì）说（shuō）四十（sì shí），
> 就（jiù）打（dǎ）他（tā）的（de）嘴（zuǐ）。

## 七、附加难点：n ↔ l 不分

**原理：**
- **n（鼻音）**：舌尖抵上齿龈，气流从**鼻腔**出来（捏鼻子会受阻）。
- **l（边音）**：舌尖抵上齿龈，气流从舌头**两侧**出来（捏鼻子不受阻）。

**对比词：**

| n | l |
| --- | --- |
| 那（nà） | 辣（là） |
| 奶（nǎi） | 来（lái） |
| 男（nán） | 蓝（lán） |
| 牛（niú） | 流（liú） |
| 你（nǐ） | 里（lǐ） |
| 怒（nù） | 路（lù） |
| 娘（niáng） | 良（liáng） |

**练习句：**
> 牛（niú）郎（láng）恋（liàn）刘（liú）娘（niáng），刘（liú）娘（niáng）念（niàn）牛（niú）郎（láng）。

---

## 八、附加难点：h ↔ f 不分

部分方言把"飞机"说成"灰机"、"福"说成"胡"。

**原理：**
- **h**：舌根靠近软腭，气流摩擦（喉部音）。
- **f**：上齿咬下唇，气流从唇齿间摩擦。

**对比词：**

| h | f |
| --- | --- |
| 花（huā） | 发（fā） |
| 湖（hú） | 福（fú） |
| 灰（huī） | 飞（fēi） |
| 换（huàn） | 饭（fàn） |
| 红（hóng） | 缝（féng） |

**练习句：**
> 会（huì）计（jì）小（xiǎo）方（fāng），飞（fēi）到（dào）湖（hú）南（nán）分（fēn）红（hóng）花（huā）。

## 九、平翘舌综合绕口令

**绕口令 1：石狮子**
> 施（shī）氏（shì）食（shí）狮（shī），十（shí）时（shí）拾（shí）狮（shī）尸（shī）。

**绕口令 2：造纸**
> 制（zhì）造（zào）**纸**，用（yòng）**桑**（sāng）**枝**（zhī），
> **桑**（sāng）**枝**（zhī）**造**（zào）**纸**（zhǐ）**质**（zhì）**最**（zuì）**佳**（jiā）。

**绕口令 3：知与吃**
> 老（lǎo）**师**（shī）**知**（zhī）道（dào）**吃**（chī）**柿**（shì）子（zi），
> **柿**（shì）子（zi）**是**（shì）不（bú）**是**（shì）**四**（sì）毛（máo）**四**（sì）？

## 十、今日打卡建议

```
1. z/zh、c/ch、s/sh 对比词 各挑一半   （3分钟）
2. "四是四，十是十" 慢速3遍           （2分钟）
3. n/l 或 h/f 对比（按你的弱项）       （2分钟）
4. 综合绕口令 挑1条 慢→快             （2分钟）
5. 录音回放，找出仍混的字对
```

**进步标志**：在自然语速下，"是/四""知/资""老师/思考"不再需要刻意想就能发对。
