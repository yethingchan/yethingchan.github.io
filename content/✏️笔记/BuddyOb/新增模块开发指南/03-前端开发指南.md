# 03 · 前端开发指南

> 前端新增一个管理页面，**只需两个文件**：`views` 里的页面组件 + `api` 里的接口封装。
> 路由、菜单、权限全部由后端动态下发，`router` / `store` / `main.js` 都不用改。

---

## 只需新建两个文件

```
frontend/src/
├── views/business/goods/index.vue   ← 新增：页面组件
└── api/business/goods.js            ← 新增：接口封装
```

> **命名对齐规则（重要）**：
> `views` 下的路径要和后端菜单表的 `component` 字段对应。
> `src/views/business/goods/index.vue` → 后端菜单 `component` 填 `business/goods/index`。

## 文件 1：API 接口封装

**路径**：`api/business/goods.js`

```js
import request from '@/utils/request'

/** 列表（分页+条件） */
export function listGoods(params) {
  return request({ url: '/business/goods/list', method: 'get', params })
}

/** 单条（编辑回显） */
export function getGoods(id) {
  return request({ url: '/business/goods/' + id, method: 'get' })
}

/** 新增 */
export function addGoods(data) {
  return request({ url: '/business/goods', method: 'post', data })
}

/** 修改 */
export function editGoods(data) {
  return request({ url: '/business/goods', method: 'put', data })
}

/** 批量删除（ids 是数组，自动序列化成 ids=1&ids=2） */
export function removeGoods(ids) {
  return request({ url: '/business/goods', method: 'delete', params: { ids } })
}
```

**范式（所有模块一致）：**

| 函数 | method | 参数 | 对应后端 |
| --- | --- | --- | --- |
| `listXxx(params)` | get | `params`（分页+条件） | `GET /xxx/list` |
| `getXxx(id)` | get | 拼在 url 上 | `GET /xxx/{id}` |
| `addXxx(data)` | post | `data`（JSON body） | `POST /xxx` |
| `editXxx(data)` | put | `data`（JSON body） | `PUT /xxx` |
| `removeXxx(ids)` | delete | `params:{ ids }`（数组） | `DELETE /xxx?ids=` |

> `request` 门面已处理：`/api` 前缀、`Bearer token`、`code!==200` 弹错、`401/403` 跳登录、数组参数序列化。你**不用管这些**。

## 文件 2：页面组件

**路径**：`views/business/goods/index.vue`

这是一个标准 CRUD 页，包含：搜索表单 + 工具条 + 表格 + 分页 + 新增/编辑弹窗 + 删除确认。直接照抄改字段即可。

```vue
<template>
  <div>
    <!-- ① 搜索表单 -->
    <el-form :inline="true" :model="query" class="search-form">
      <el-form-item label="名称">
        <el-input v-model="query.goodsName" placeholder="商品名称" clearable />
      </el-form-item>
      <el-form-item label="状态">
        <el-select v-model="query.status" clearable style="width:120px">
          <el-option label="正常" value="0" />
          <el-option label="停用" value="1" />
        </el-select>
      </el-form-item>
      <el-form-item>
        <el-button type="primary" :icon="Search" @click="load">查询</el-button>
        <el-button :icon="Refresh" @click="reset">重置</el-button>
      </el-form-item>
    </el-form>

    <!-- ② 工具条：新增 -->
    <div class="page-tool-bar">
      <el-button type="primary" :icon="Plus" v-hasPermi="'business:goods:add'" @click="openAdd">新增</el-button>
    </div>

    <!-- ③ 表格 -->
    <el-table :data="rows" border stripe>
      <el-table-column prop="goodsId" label="编号" width="80" />
      <el-table-column prop="goodsName" label="名称" />
      <el-table-column prop="goodsCode" label="编码" />
      <el-table-column prop="stock" label="库存" width="100" />
      <el-table-column label="状态" width="90">
        <template #default="{ row }">
          <el-tag :type="row.status === '0' ? 'success' : 'danger'">
            {{ row.status === '0' ? '正常' : '停用' }}
          </el-tag>
        </template>
      </el-table-column>
      <el-table-column prop="createTime" label="创建时间" />
      <el-table-column label="操作" width="160" fixed="right">
        <template #default="{ row }">
          <el-button link type="primary" :icon="Edit" v-hasPermi="'business:goods:edit'" @click="openEdit(row)">修改</el-button>
          <el-button link type="danger" :icon="Delete" v-hasPermi="'business:goods:remove'" @click="remove(row)">删除</el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- ④ 分页 -->
    <div class="pagination-wrap">
      <el-pagination
        v-model:current-page="page.pageNum"
        v-model:page-size="page.pageSize"
        :total="total"
        :page-sizes="[10, 20, 50]"
        layout="total, sizes, prev, pager, next"
        @current-change="load"
        @size-change="load" />
    </div>

    <!-- ⑤ 新增/编辑弹窗 -->
    <el-dialog v-model="dialogVisible" :title="dialogTitle" width="520px">
      <el-form ref="formRef" :model="form" :rules="rules" label-width="90px">
        <el-form-item label="名称" prop="goodsName">
          <el-input v-model="form.goodsName" />
        </el-form-item>
        <el-form-item label="编码" prop="goodsCode">
          <el-input v-model="form.goodsCode" />
        </el-form-item>
        <el-form-item label="库存" prop="stock">
          <el-input-number v-model="form.stock" :min="0" />
        </el-form-item>
        <el-form-item label="状态">
          <el-radio-group v-model="form.status">
            <el-radio value="0">正常</el-radio>
            <el-radio value="1">停用</el-radio>
          </el-radio-group>
        </el-form-item>
        <el-form-item label="备注">
          <el-input v-model="form.remark" type="textarea" :rows="3" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" :loading="submitting" @click="submit">确定</el-button>
      </template>
    </el-dialog>
  </div>
</template>

<script setup>
import { ref, reactive, onMounted } from 'vue'
import { Search, Refresh, Plus, Edit, Delete } from '@element-plus/icons-vue'
import { listGoods, addGoods, editGoods, removeGoods } from '@/api/business/goods'
import { ElMessage, ElMessageBox } from 'element-plus'

// —— 列表状态 ——
const rows = ref([])
const total = ref(0)
const page = reactive({ pageNum: 1, pageSize: 10 })
const query = reactive({ goodsName: '', status: '' })

// —— 弹窗状态 ——
const dialogVisible = ref(false)
const dialogTitle = ref('')
const submitting = ref(false)
const formRef = ref()
const form = reactive({
  goodsId: undefined, goodsName: '', goodsCode: '', stock: 0, status: '0', remark: ''
})
const rules = {
  goodsName: [{ required: true, message: '请输入名称', trigger: 'blur' }],
  goodsCode: [{ required: true, message: '请输入编码', trigger: 'blur' }]
}

// —— 加载列表 ——
function load() {
  listGoods({ ...page, ...query }).then(res => {
    rows.value = res.rows || []
    total.value = res.total || 0
  })
}

function reset() {
  query.goodsName = ''
  query.status = ''
  page.pageNum = 1
  load()
}

// —— 打开新增 ——
function openAdd() {
  dialogTitle.value = '新增商品'
  Object.assign(form, { goodsId: undefined, goodsName: '', goodsCode: '', stock: 0, status: '0', remark: '' })
  dialogVisible.value = true
}

// —— 打开编辑 ——
function openEdit(row) {
  dialogTitle.value = '修改商品'
  Object.assign(form, row)
  dialogVisible.value = true
}

// —— 提交 ——
function submit() {
  formRef.value.validate(valid => {
    if (!valid) return
    submitting.value = true
    const req = form.goodsId ? editGoods(form) : addGoods(form)
    req.then(() => {
      ElMessage.success('操作成功')
      dialogVisible.value = false
      load()
    }).finally(() => { submitting.value = false })
  })
}

// —— 删除 ——
function remove(row) {
  ElMessageBox.confirm('确认删除商品「' + row.goodsName + '」？', '提示', { type: 'warning' })
    .then(() => removeGoods([row.goodsId]).then(() => {
      ElMessage.success('删除成功')
      load()
    }))
    .catch(() => {})
}

onMounted(load)
</script>
```

## Element Plus 组件标准用法速查

| 需求 | 组件 & 写法 |
| --- | --- |
| 搜索表单 | `<el-form :inline="true" :model="query" class="search-form">` |
| 输入框 | `<el-input v-model="query.xxx" clearable />` |
| 下拉 | `<el-select v-model="query.xxx" clearable>` + `<el-option label value>` |
| 按钮+图标 | `<el-button type="primary" :icon="Search" @click="load">` |
| 表格 | `<el-table :data="rows" border stripe>` |
| 普通列 | `<el-table-column prop="xxx" label="xx" width="80" />` |
| 自定义列 | `<el-table-column><template #default="{ row }">...</template></el-table-column>` |
| 状态标签 | `<el-tag :type="row.status==='0'?'success':'danger'">` |
| 操作列 | `fixed="right"` + `link` 类型按钮 |
| 分页 | `<el-pagination v-model:current-page v-model:page-size :total :page-sizes @current-change @size-change>` |
| 弹窗 | `<el-dialog v-model="dialogVisible" :title width>` + `<template #footer>` |
| 表单校验 | `<el-form ref="formRef" :model :rules>` + `<el-form-item prop>`，提交前 `formRef.value.validate()` |
| 数字输入 | `<el-input-number v-model :min :max />` |
| 单选 | `<el-radio-group v-model>` + `<el-radio value="0">` |
| 消息提示 | `ElMessage.success(...)` |
| 确认框 | `ElMessageBox.confirm(...).then(...)` |

图标从 `@element-plus/icons-vue` 按需导入：`import { Search, Plus, Edit, Delete } from '@element-plus/icons-vue'`（已全局注册，`:icon="Search"` 直接用）。

## 按钮权限：v-hasPermi

```html
<el-button v-hasPermi="'business:goods:add'">新增</el-button>
```

- 注意**引号嵌套**：外层双引号是 Vue 指令，内层单引号是权限字符串。
- 无该权限时，按钮的 DOM 会在挂载时被直接移除。
- 权限串必须和后端 `@PreAuthorize` / 数据库 `perms` 一致。

## 如果弹窗/搜索需要"字典下拉"

比如状态、类型这类固定选项，本项目有字典机制。用法：

```js
import { dictDataByType } from '@/api/system/dict'

const typeOptions = ref([])
onMounted(() => {
  load()
  dictDataByType('sys_goods_status').then(res => {
    typeOptions.value = res.data || []
  })
})
```

```html
<el-select v-model="form.status">
  <el-option v-for="t in typeOptions" :key="t.dictValue" :label="t.dictLabel" :value="t.dictValue" />
</el-select>
```

字典数据需在"字典管理"里先配好（`sys_dict_type` + `sys_dict_data`）。简单的固定两三项也可以直接写死 `<el-option>`，不一定要走字典。

## 为什么不用改路由？

再次强调本项目的动态路由机制（详见 01 文档第四节）：

- 你新增的 `views/business/goods/index.vue` 会被 `import.meta.glob('../views/**/*.vue')` 在编译期自动收集。
- 后端菜单表里配一条 `component = business/goods/index` 的菜单记录。
- 用户登录 → `/getRouters` 下发菜单 → `utils/route.js` 把 `component` 映射到你的 `.vue` → `router.addRoute` 挂载 → 侧边栏出现菜单。

**所以你只管写 `.vue` 和 `.js`，菜单交给数据库配置（见 04 文档）。**
