# 02 · 后端开发指南

> 后端新增一个模块的"四件套"：**Entity → Mapper → Service → Controller**。
> 本项目约定极简：**没有 Service 接口 + Impl 之分，没有 XML Mapper**。照本文模板逐层写即可。

---

## 目录与命名约定

```
backend/src/main/java/com/example/admin/
├── domain/          ← 实体类（放这里）
├── mapper/          ← Mapper 接口（放这里）
├── service/         ← Service 类（放这里，注意：没有 service/impl 子包）
├── controller/
│   ├── system/      ← 系统管理类接口（用户/角色/菜单/字典/参数）
│   ├── monitor/     ← 监控类接口（日志/公告演示）
│   └── business/    ← 业务模块接口（你的新模块建议放这里）
├── common/          ← 公共类（AjaxResult / 工具 / 常量）→ 复用，不用改
├── security/        ← 安全相关（权限校验/登录用户）→ 复用，不用改
├── annotation/      ← @Log 注解 → 复用
└── aspect/          ← 日志切面 → 复用
```

**命名建议**（以"商品 goods"为例）：
- 表名：`biz_goods`（或沿用 `sys_` 前缀看团队习惯，业务表建议 `biz_`）
- 实体：`Goods`（`@TableName("biz_goods")`）
- Mapper：`GoodsMapper`
- Service：`GoodsService`
- Controller：`GoodsController`，路径 `/business/goods`
- 权限串：`business:goods:list` / `:query` / `:add` / `:edit` / `:remove`

## 第 1 层：实体类 Entity

**路径**：`domain/Goods.java`

```java
package com.example.admin.domain;

import com.baomidou.mybatisplus.annotation.IdType;
import com.baomidou.mybatisplus.annotation.TableId;
import com.baomidou.mybatisplus.annotation.TableName;
import lombok.Data;

import java.io.Serializable;
import java.util.Date;

/**
 * 商品实体
 */
@Data
@TableName("biz_goods")
public class Goods implements Serializable {

    /** 主键，MySQL 自增 */
    @TableId(type = IdType.AUTO)
    private Long goodsId;

    private String goodsName;    // 商品名称
    private String goodsCode;    // 商品编码
    private Integer stock;       // 库存
    private String status;       // 状态 0正常 1停用
    private String createBy;     // 创建人
    private Date createTime;     // 创建时间
    private String remark;       // 备注
}
```

**要点：**
- `@Data`（Lombok）自动生成 getter/setter/toString，**不用手写**。
- `@TableName("biz_goods")` 绑定表名。不写的话默认按类名驼峰转下划线（`Goods` → `goods`）。
- `@TableId(type = IdType.AUTO)` 主键自增，对应 MySQL `AUTO_INCREMENT`。
- 字段名用驼峰（`goodsName`），数据库列名用下划线（`goods_name`），MyBatis-Plus 默认自动映射（已在 `application.yml` 配 `map-underscore-to-camel-case: true`）。

## 第 2 层：Mapper 接口

**路径**：`mapper/GoodsMapper.java`

```java
package com.example.admin.mapper;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.example.admin.domain.Goods;
import org.apache.ibatis.annotations.Mapper;

@Mapper
public interface GoodsMapper extends BaseMapper<Goods> {
    // 空接口即可！继承 BaseMapper 后自动拥有：
    // insert / updateById / deleteById / deleteBatchIds /
    // selectById / selectList / selectPage 等全套 CRUD
}
```

**要点：**
- **空接口**继承 `BaseMapper<实体>` 就获得全套 CRUD，**不需要写任何 SQL，不需要 XML**。
- `AdminApplication` 上有 `@MapperScan("com.example.admin.mapper")`，所以 `@Mapper` 注解可写可不写（写上是双保险）。
- **什么时候需要自定义 SQL？** 只有联表查询、复杂统计等 `BaseMapper` 满足不了的场景，才在接口里用 `@Select` 注解写（仿 `SysMenuMapper`），或新建 XML。普通 CRUD 完全不需要。

## 第 3 层：Service 类

**路径**：`service/GoodsService.java`

```java
package com.example.admin.service;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.metadata.IPage;
import com.example.admin.common.utils.StringUtils;
import com.example.admin.domain.Goods;
import com.example.admin.mapper.GoodsMapper;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.List;

/**
 * 商品 Service
 */
@Service
@RequiredArgsConstructor
public class GoodsService {

    private final GoodsMapper goodsMapper;

    /** 分页列表 + 动态条件查询 */
    public IPage<Goods> list(IPage<Goods> page, String goodsName, String status) {
        LambdaQueryWrapper<Goods> q = new LambdaQueryWrapper<>();
        // 第一个参数为 true 时该条件才生效，实现"条件为空就忽略"
        q.like(StringUtils.isNotBlank(goodsName), Goods::getGoodsName, goodsName);
        q.eq(StringUtils.isNotBlank(status), Goods::getStatus, status);
        q.orderByDesc(Goods::getGoodsId);
        return goodsMapper.selectPage(page, q);
    }

    /** 查单条 */
    public Goods get(Long id) {
        return goodsMapper.selectById(id);
    }

    /** 新增 */
    public void add(Goods goods) {
        goodsMapper.insert(goods);
    }

    /** 修改 */
    public void update(Goods goods) {
        goodsMapper.updateById(goods);
    }

    /** 批量删除 */
    public void delete(List<Long> ids) {
        goodsMapper.deleteBatchIds(ids);
    }
}
```

**要点：**
- **`@Service` 普通类，没有接口，没有 Impl。** 这是本项目的强约定，别去建 `GoodsServiceImpl`。
- **`@RequiredArgsConstructor` + `final` 字段** 做构造器注入（Lombok），不用 `@Autowired`。
- **动态查询用 `LambdaQueryWrapper`**：`q.like(条件, 字段方法引用, 值)`，第一个 boolean 参数为 `false` 时该条件被忽略——这就是"搜索框没填就不加这个条件"的实现方式。
- 分页调 `selectPage(page, wrapper)`，分页拦截器（`MybatisPlusConfig`）已全局配好，自动拼 `LIMIT` 和 `COUNT`。

**常用 Wrapper 方法速查：**

| 方法 | 含义 | 例子 |
| --- | --- | --- |
| `eq` | 等于 | `q.eq(cond, Goods::getStatus, "0")` |
| `like` | 模糊匹配 | `q.like(cond, Goods::getGoodsName, name)` |
| `ge` / `le` | 大于等于 / 小于等于 | `q.ge(cond, Goods::getCreateTime, start)` |
| `in` | 在集合内 | `q.in(cond, Goods::getGoodsId, ids)` |
| `orderByDesc` / `orderByAsc` | 排序 | `q.orderByDesc(Goods::getGoodsId)` |

## 第 4 层：Controller

**路径**：`controller/business/GoodsController.java`

```java
package com.example.admin.controller.business;

import com.baomidou.mybatisplus.core.metadata.IPage;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.example.admin.annotation.Log;
import com.example.admin.common.AjaxResult;
import com.example.admin.domain.Goods;
import com.example.admin.service.GoodsService;
import lombok.RequiredArgsConstructor;
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.web.bind.annotation.*;

import java.util.List;

/**
 * 商品管理
 */
@RestController
@RequestMapping("/business/goods")
@RequiredArgsConstructor
public class GoodsController {

    private final GoodsService goodsService;

    /** 列表（分页 + 条件） */
    @PreAuthorize("@ps.hasPermi('business:goods:list')")
    @GetMapping("/list")
    public AjaxResult list(@RequestParam(defaultValue = "1") int pageNum,
                           @RequestParam(defaultValue = "10") int pageSize,
                           String goodsName, String status) {
        IPage<Goods> page = goodsService.list(new Page<>(pageNum, pageSize), goodsName, status);
        return AjaxResult.success(page.getRecords(), page.getTotal());
    }

    /** 查单条（编辑回显） */
    @PreAuthorize("@ps.hasPermi('business:goods:query')")
    @GetMapping("/{id}")
    public AjaxResult get(@PathVariable Long id) {
        return AjaxResult.success(goodsService.get(id));
    }

    /** 新增 */
    @PreAuthorize("@ps.hasPermi('business:goods:add')")
    @Log(title = "商品管理", businessType = 1)
    @PostMapping
    public AjaxResult add(@RequestBody Goods goods) {
        goodsService.add(goods);
        return AjaxResult.success();
    }

    /** 修改 */
    @PreAuthorize("@ps.hasPermi('business:goods:edit')")
    @Log(title = "商品管理", businessType = 2)
    @PutMapping
    public AjaxResult edit(@RequestBody Goods goods) {
        goodsService.update(goods);
        return AjaxResult.success();
    }

    /** 批量删除：ids=1&ids=2 */
    @PreAuthorize("@ps.hasPermi('business:goods:remove')")
    @Log(title = "商品管理", businessType = 3)
    @DeleteMapping
    public AjaxResult remove(@RequestParam List<Long> ids) {
        goodsService.delete(ids);
        return AjaxResult.success();
    }
}
```

**要点：**
- **类上** `@RestController` + `@RequestMapping("/business/goods")` 定义模块基础路径。
- **每个方法** 加 `@PreAuthorize("@ps.hasPermi('权限串')")`，权限串规则见下。
- **写操作（add/edit/remove）** 加 `@Log(title="模块名", businessType=X)`，自动落操作日志。`businessType`：1=新增，2=修改，3=删除，0=其它。
- **返回值**：
  - 列表 → `AjaxResult.success(rows, total)`
  - 单条 → `AjaxResult.success(data)`
  - 增删改成功 → `AjaxResult.success()`
- **删除接口** 用 `@RequestParam List<Long> ids` 接收数组，前端传 `?ids=1&ids=2`。

## RESTful 接口规范（本项目约定）

| 操作 | HTTP 方法 | 路径 | 参数位置 |
| --- | --- | --- | --- |
| 列表 | GET | `/business/goods/list` | query（分页+条件） |
| 详情 | GET | `/business/goods/{id}` | 路径变量 |
| 新增 | POST | `/business/goods` | body（JSON） |
| 修改 | PUT | `/business/goods` | body（JSON） |
| 删除 | DELETE | `/business/goods?ids=1&ids=2` | query（数组） |

> 注意：`role/menu` 模块的删除用的是路径变量 `/{id}`，但**新模块统一推荐用 `?ids=` 数组风格**（和 user/config/notice/dict 一致），前端 `request.js` 已内置数组序列化。

## 权限字符串命名规则

格式：**`业务域:模块:动作`**，全小写，冒号分隔。

```
business:goods:list      查询列表
business:goods:query     查看详情
business:goods:add       新增
business:goods:edit      修改
business:goods:remove    删除
```

- 业务域：`system`（系统管理）、`monitor`（监控）、`business`（业务）等。
- 这些串要**原样**写进：
  1. Controller 的 `@PreAuthorize`
  2. 数据库 `sys_menu.perms`（见 04 文档）
  3. 前端 `v-hasPermi`（见 03 文档）
- **三处必须一字不差。**

```
GoodsController.list()          @PreAuthorize 校验权限
      │
      ▼
GoodsService.list()             LambdaQueryWrapper 拼条件
      │
      ▼
GoodsMapper.selectPage()        继承 BaseMapper，分页拦截器生效
      │
      ▼
biz_goods 表                    结果映射回 Goods 对象
```
