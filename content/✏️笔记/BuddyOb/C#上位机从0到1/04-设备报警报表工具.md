## 一、设备实时状态监控（三色可视化）

`FrmDeviceMonitor` 按寄存器映射表定时读取 PLC：用 `RegisterMap.ReadAll()` 拉全部点位，绑定到 `DataGridView`；故障码 >0 的行标红。

```csharp
// FrmDeviceMonitor
var driver = PlcDriverFactory.Create(ParamService.Get("plc_type"));
_map = new RegisterMap(driver);
_timer = new Timer { Interval = 2000 };
_timer.Tick += (s, e) => Refresh();   // 定时刷新，不阻塞通信线程
```
- 运行/待机/故障三色：靠"故障码"列值判定（>0 红），数据源来自 `plc_point` 映射。
- 实时读取 PLC 运行参数/速度/故障代码：点位配置即可，无需改界面。
- 后台 `Timer` 刷新，UI 通过 `SafeUi.Invoke` 回写，通信线程不被卡。

## 二、报警管理

`AlarmService` 负责产生/查询/标记/清理；`FrmAlarm` 列表展示。

- **自动巡检**：`AlarmService.ScanAndRaise()` 定时扫三类库存异常：
  - 库存不足：`SUM(qty) <= stock_warn_qty` 参数阈值
  - 库存超期：`expiry_date <= date('now','+N day')`（N = `expiry_warn_days`）
  - 库位禁用：`mat_location.disabled=1`
- **主窗体滚动栏 + 声音**：`MainForm.AlarmTick()` 每 5s 调巡检，未读条数写状态栏；新增未读且 `alarm_sound≠0` 时 `SystemSounds.Beep.Play()`。
- **详情持久**：报警落 `sys_alarm`（type/level/message/source/time/is_read）；已读标记、导出 Excel、清空都在 `FrmAlarm`。
- **库位禁用/设备故障实时弹窗报警**：巡检产生的 error 级报警会触发上面声音+滚动栏；如需"弹窗"，可在 `AlarmTick` 里对新增 error 调 `MessageBox.Show`（本工程默认用滚动栏+声音，避免打断操作）。

## 三、报表与统计分析

`ReportService` 返回 `DataTable`，`GdiChart` 零依赖自绘：

```csharp
// FrmReports
var dt = ReportService.InOutSummary(dim, from, to);   // day/month/year
var io = new DataTable();
io.Columns.Add("label"); io.Columns.Add("value");
foreach (DataRow r in dt.Rows)
    io.Rows.Add(r["period"], (double)r["in_qty"] + (double)r["out_qty"]);
_inOut.SetData(io, "label", "value");   // GdiChart 柱状
```
- **出入库日报/月报/年报**：`InOutSummary` 用 `strftime` 按维度聚合（`UNION ALL` 入/出），算总量、物料收发排行。
- **库位利用率**：`LocationUtilization()` 按库区统计 total/used/free → 饼图。
- **物料周转/呆滞**：`MaterialTurnover(since)` 按出入频次排序，频次最低=呆滞。
- **可视化 + 导出**：柱状/折线/饼图（`Charts.cs`），导出 Excel（`ExcelHelper.ExportDataTable` 真 .xls）、打印（`PrintDocument`）。
- **定时自动生成**：`FrmReports` 的"导出"写到 `sys_param.report_path`；要定时，可在 `MainForm` 加一个 `Timer` 周期调 `ReportService`+写文件（本工程提供能力，定时开关按需在 UI 加）。

## 四、通用工具辅助

`FrmTools` 聚合常用工具，按钮各自调服务：
- **本地备份/恢复**：`BackupService.Backup()` 用 `SQLiteConnection.BackupDatabase`（在线热备，生成 `host_yyyyMMddHHmmss.db`）；`Restore()` 覆盖当前库文件。
- **自动定时备份**：`MainForm` 加 `Timer` 周期调 `Backup()` 即可（能力已具备）。
- **清理过期日志/作废单据**：`CleanLogs()`（按 `log_keep_days`）、`CleanCanceledDocs()`。
- **Excel 导入导出**：`ExcelHelper` 导出 HTML 表格 .xls、CSV 导入导出；物料批量导入在 [[C#上位机从0到1/03-库存与单据业务]]。
- **PLC 模拟调试**：`FrmPlcSim` 手动读写寄存器（用 `PlcSimulator`，无需真机），见 [[C#上位机从0到1/02-硬件通信核心]]。
- **报文调试工具**：`FrmMsgDebug` 手输十六进制发帧，验证头尾/长度域解析（可"模拟回包"测粘包分包）。
