# C# 上位机系统 · 从 0 到 1 搭建总览

> 一份**可直接在 Visual Studio 打开编译运行**的 C# WinForms 上位机（SCADA 风格）完整工程。
> 仓库真实代码位于 `D:\A_Work\Vue\RuoYi-Vue\CSharpHost\`（不在本笔记目录，便于 VS 打开）。
> 本笔记是"教程"：讲清**项目目录、架构、技术栈、九大模块如何映射到代码、部署与排错**。跟着做即可搭出可运行项目。

## 一、技术栈与运行前提

| 项 | 选择 | 说明 |
|----|------|------|
| 语言/框架 | **C# + .NET Framework 4.8 + WinForms** | 上位机最主流组合，国产工控环境兼容性最好 |
| 项目形态 | **单项目 SDK-style（`<UseWindowsForms>true</UseWindowsForms>`）** | `.csproj` 自动收纳全部 `.cs`，无需手工列文件 |
| 数据库 | **SQLite（`System.Data.SQLite` NuGet）** | 本地文件库，零服务依赖，首次运行自动建表 |
| 图表 | **自绘 GDI（`Graphics`/`Bitmap`）** | 柱状/折线/饼图零依赖，随窗口自适应 |
| 硬件 | 串口 `System.IO.Ports`、TCP `TcpClient` | PLC 用抽象驱动 + **内置模拟器**，无真实设备也能跑通全流程 |
| 部署 | 发布为 Windows 程序 + 开机自启 + 托盘 | 见 [[C#上位机从0到1/06-部署与排错]] |

> ⚠️ 本机需安装 **Visual Studio 2022 + ".NET 桌面开发" 工作负载**（含 .NET Framework 4.8 目标包）。
> 打开 `CSharpHost.sln` → 右击 Host 项目"还原 NuGet" → `F5` 调试。默认账号 `admin / 123456`。

## 二、项目目录（真实结构）

```
CSharpHost/
├─ CSharpHost.sln
└─ Host/
   ├─ Host.csproj                 # SDK 风格，单项目，引用 System.Data.SQLite
   ├─ Program.cs                # 入口：全局异常/单实例/自启/初始化
   ├─ Common/                  # 横切关注点
   │  ├─ PasswordHelper.cs     # SHA256+盐 密码
   │  ├─ Logger.cs            # 通信日志(按日分文件)+应用日志+事件
   │  ├─ Session.cs           # 会话：当前用户/权限/数据权限
   │  └─ SafeUi.cs           # 跨线程安全更新控件
   ├─ Data/
   │  ├─ DbHelper.cs         # SQLite 参数化访问+事务
   │  └─ Schema.cs           # 全库建表脚本（幂等）
   ├─ BLL/                    # 业务逻辑层（每模块一个 Service）
   │  ├─ AuthService.cs      # 登录/用户/角色/权限/菜单构建
   │  ├─ DictService / ParamService
   │  ├─ MaterialService / LocationService / StockService
   │  ├─ DocService.cs       # 入/出(FIFO)/调拨/盘点 + 事务
   │  ├─ AlarmService / ReportService / LogService
   │  ├─ BackupService / PlcPointService
   │  └─ ...
   ├─ Hardware/               # 二、硬件通信核心
   │  ├─ SerialManager.cs    # 串口/模拟通道/自动重连/十六进制日志
   │  ├─ TcpManager.cs      # TCP：自定义帧协议/粘包分包/心跳/重连/队列
   │  ├─ PlcDriver.cs       # IPlcDriver + 汇川/西门子/三菱 + 模拟器 + 寄存器映射
   │  └─ DeviceCapture.cs    # 扫码枪/称重 串口服捕
   └─ UI/                     # 窗体 + 通用控件
      ├─ LoginForm.cs / MainForm.cs / FrmLock.cs
      ├─ GridPager.cs          # DataGridView 封装(分页/列隐藏/行标红/双击)
      ├─ Charts.cs             # GdiChart(柱/折/饼) + LocationPanel(GDI库位图)
      ├─ CommonUi.cs          # 校验/加载框/InputBox
      ├─ ExcelHelper.cs        # Excel(HTML)/CSV 导入导出
      └─ Frm*.cs              # 各业务窗体（见下）
```

## 三、九大模块 → 代码映射

| 模块 | 核心代码 | 关键设计 |
|------|----------|----------|
| 一、基础系统权限 | `AuthService` + `FrmUsers/FrmRoles/FrmDict/FrmParams` | 权限 code（菜单+按钮），按钮 `Visible` 受 `Session.HasPerm` 控制；数据权限 `location_code LIKE 'WHxx%'` |
| 二、硬件通信核心 | `Hardware/*` | 串口自动扫描/重连；TCP 自定义帧(0xAA+长度+负载+0x55)与粘包分包；PLC 抽象驱动 + 模拟器；扫码/称重串口服捕 |
| 三、库存主数据 | `Material/Location/Stock Service` + `FrmMaterials/FrmLocations/FrmStock` | 物料 CRUD+条码；库位三级树(库区/库位/料斗)+GDI 绿/红/黄；库存台账多条件筛选+汇总饼图 |
| 四、出入库单据 | `DocService` + `FrmInbound/Outbound/Transfer/DocQuery` | 入/出/调拨/盘点；**出库 FIFO**；**库存不足弹窗拦截**；单据状态机 draft→submitted→done/cancel；全部在 `DbHelper.Tx` 事务内 |
| 五、设备监控与报警 | `AlarmService` + `FrmDeviceMonitor/FrmAlarm` | 定时器扫描库存超期/不足/库位禁用自动报警；主窗体滚动栏+声音；设备状态三色 |
| 六、报表统计 | `ReportService` + `FrmReports` | 出入库日/月/年报、库位利用率、物料周转/呆滞；GDI 图表 + 导出/打印 |
| 七、通用工具 | `BackupService/PlcPointService/ExcelHelper` + `FrmTools/FrmPlcSim/FrmMsgDebug` | 备份/恢复/清理；PLC 模拟调试；报文调试工具 |
| 八、UI 通用基础 | `GridPager/Charts/CommonUi` | 分页/列隐藏/行标红/双击弹窗；多标签页；加载动画；输入校验；右键/自适应；日志滚动不阻塞 |
| 九、安全与运维 | `Program/Logger/Session/DbHelper.Tx` | 全局异常捕获不闪退；单据事务回滚；断线缓存补发(队列)；开机自启+托盘；多线程隔离 |

## 四、学习清单（由易到难，与代码顺序一致）

- [ ] 跑通：打开 sln、还原 NuGet、F5 用 admin 登录
- [ ] 看懂 `Program.cs` 的全局异常处理与单实例
- [ ] 看懂 `Schema.cs` 全库表结构（九大模块如何落地）
- [ ] 权限：新增用户/角色、给角色勾选按钮权限、观察按钮显隐
- [ ] 数据权限：给用户分配库区，验证库存查询被过滤
- [ ] 硬件：用 `FrmPlcSim` 读写寄存器；用 `FrmMsgDebug` 发十六进制帧看粘包分包
- [ ] 串口：接扫码枪/称重，体验"扫码自动填充"
- [ ] 库存：建物料/库位树，看 GDI 库位图（绿/红/黄）
- [ ] 单据：做一张入库单→提交（看库存+）；做出库单→故意超领看拦截
- [ ] 盘点：账面 vs 扫码，看盈亏自动校正库存
- [ ] 报警：制造一条超期库存，看主窗体滚动栏+声音
- [ ] 报表：出一张出入库柱状图 + 导出 Excel
- [ ] 工具：备份数据库、清理日志；PLC 模拟调试
- [ ] 运维：开机自启 + 托盘后台；故意抛异常看不闪退
