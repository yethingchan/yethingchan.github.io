## 一、权限模型：菜单 + 按钮，全部用 code 控制

权限点统一存 `sys_permission(code, type, parent_code, form)`。`type='menu'` 是菜单（点开 `form` 指向的窗体），`type='button'` 是按钮操作（如 `material:add`）。

```
SeedPerms 示例（AuthService.cs 内）：
("user","用户管理","menu","setting","Host.UI.FrmUsers",1),
    ("user:add","新增","button","user","",1),
    ("user:enable","启停","button","user","",3),
```
- 角色→权限：`sys_role_perm(role_id, perm_code)`。
- 用户→角色：`sys_user_role`。
- 取用户全部权限：`AuthService.GetUserPerms(userId)` 合并其所有角色 → `HashSet<string>` 存入 `Session.Permissions`。

## 二、菜单按权限构建（主窗体左侧树）

`MainForm.BuildNav()` 调 `AuthService.BuildMenu(perms)`，只返回该用户拥有的菜单节点；双击叶子节点用反射打开窗体：

```csharp
// MainForm.cs
private void OpenForm(string formType, string title)
{
    var t = Type.GetType(formType);            // 如 "Host.UI.FrmMaterials"
    if (t == null || !typeof(Form).IsAssignableFrom(t)) { /* 提示 */ return; }
    var f = (Form)Activator.CreateInstance(t);   // 反射实例化
    f.TopLevel = false; f.FormBorderStyle = FormBorderStyle.None; f.Dock = DockStyle.Fill;
    var page = new TabPage(title) { Tag = t };
    page.Controls.Add(f); f.Show();
    _tabs.TabPages.Add(page); _tabs.SelectedTab = page;
}
```

## 三、按钮权限：Visible 受 HasPerm 控制

每个业务窗体构造函数里根据 `Session.HasPerm("xxx:add")` 控制按钮显隐，做到"不同角色功能按钮权限控制（Visiable 隐藏按钮）"：

```csharp
// FrmUsers.cs
bAdd.Visible = Session.HasPerm("user:add");
bEdit.Visible = Session.HasPerm("user:edit");
bEn.Visible   = Session.HasPerm("user:enable");
```

## 四、数据权限隔离（不同操作员只看自己库区）

`sys_user.warehouse_id`：0=全部，>0=仅该库区。`Session.DataScopeFilter()` 返回 SQL 片段：
- 管理员（warehouse_id=0）→ `1=1`（不过滤）
- 普通操作员 → `location_code LIKE 'WH01%'`（库位/料斗编码约定以库区 `WHxx` 开头）

库存查询 `StockService.Query` 把这个片段拼进 WHERE，普通用户只能看自己负责库区数据。

## 五、登录 / 记住登录 / 自动登录 / 锁屏

- 登录：`AuthService.Login` 用 `PasswordHelper.Verify`（SHA256+盐）比对，写登录日志（`sys_log_login`）。
- 记住登录：凭据经轻量 XOR+Base64 存本地 `login.dat`，下次回填。
- 自动登录：程序带 `/auto` 参数启动时（`Program.Main`）调 `LoginForm.TryAutoLogin` 直接进主窗体。
- 锁屏：`FrmLock` 需重输密码解锁；`MainForm` 空闲 5 分钟自动锁（`_idleTimer`）。

## 六、字典：下拉框统一读取，不硬编码

`sys_dict(type,label,value)` 管理物料类型/库位状态/出入库类型/设备状态。窗体下拉框一律来自 `DictService.ToCombo(type)`，新增字典项在 `FrmDict` 统一维护，代码里**绝不写死** `"正常"/"禁用"` 这类字面量。

## 七、系统参数

`sys_param(param_key, param_value)` 落地：数据库连接路径、PLC IP/端口/类型、串口/波特率、库存预警阈值、报表导出路径、日志保存天数、扫码枪前缀、界面主题/字体/报警声音/刷新频率。`FrmParams` 直接编辑并 `ParamService.Set` 落库。
