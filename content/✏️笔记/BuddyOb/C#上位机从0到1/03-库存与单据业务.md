## 一、物料档案管理（WCS 库存业务）

`MaterialService`：CRUD、`GenBarcode()` 生成条码（编码+校验位）、`ImportBatch()` 从 CSV 批量导入、`SetEnabled` 禁用启用。
`FrmMaterials`：GridPager 列表 + 新增/编辑/禁用/Excel导入/导出/打印标签。条码打印用 `PrintDocument` 自绘：

```csharp
// FrmMaterials.PrintLabels()

    ev.Graphics.DrawString("条码：" + MaterialService.GenBarcode(m.Code), new Font("Consolas",10), Brushes.Black, 50, y+24);
```

## 二、库位/料格管理（三级树 + GDI 可视化）

库区→库位→料斗 三级树，`mat_location` 用 `parent_code` 自关联。`FrmLocations` 左树右 `LocationPanel`（GDI 自绘）：

- **绿色空闲 / 红色占用 / 黄色异常(禁用)** 见 `LocationService.CellsForView()`：按占用率 + `disabled` 算 `CellState`。
- GDI 绘制在 `Charts.cs` 的 `LocationPanel.OnPaint`：随窗口 `ClientSize` 自适应布局。
- 库位可**绑定 PLC 点位**（`plc_point`），点位配置 CSV 一键导入/导出。

## 三、库存台账查询

`StockService.Query(material, location, status, expiryWarn)`：
- 多条件筛选：物料编码/库位/状态（不足 low、超期 expiry）/有效期预警。
- 汇总：`Summary()` 返回总数量、空闲格、占用格 → **饼图**。
- **异常行标红**：`GridPager.MarkRows(r => 有效期临近30天 || 数量≤10, Color.LightPink)`。
- 导出 Excel（`ExcelHelper`）、打印清单（`PrintDocument`）。

## 四、入库管理（手动/扫码/WCS）

`DocService.CreateInboundDraft / SubmitInbound / ScanInbound / CancelInbound`：
- 保存=草稿（`status='draft'`，不动库存）；提交=真正加库存（`status='done'`）。
- **扫码入库自动填充**：`ScanInbound` 用 `LocationService.AllocateFreeHopper(warehouseCode)` **自动分配空闲料斗**，无需手填库位。
- WCS 推送 = `type='wcs'` 的 `ScanInbound`。
- 单据保存/提交/撤销全在 `DbHelper.Tx` 事务内，失败自动回滚（见 [[C#上位机从0到1/05-UI通用与安全运维]]）。

## 五、出库管理（FIFO 先进先出 + 防超领）

```csharp
// DocService.SubmitOutbound（事务内）
var stocks = DbHelper.QueryOn(c,
    "SELECT ... FROM mat_stock s ... WHERE material_code=@m AND qty>0 " +
    "ORDER BY produce_date ASC, batch ASC", ("@m", need.MaterialCode)); // FIFO
double total = stocks.Sum(r => (double)r["qty"]);
if (total < need.Qty) throw new Exception($"物料 {m} 库存不足：需{need}，可用{total}（禁止超领）");
foreach (var r in stocks) { var take = Math.Min(q, remain); SubStock(...); remain -= take; } // 按 FIFO 逐批扣
```
- **按先进先出自动分配批次**（生产日期早、批次小优先）。
- **库存不足弹窗报警、禁止超领**：不足直接抛异常 → `FrmOutbound.Submit` `catch` 后 `MessageBox.Show` 拦截，库存不动。

## 六、调拨 / 盘点

- **调拨**（`DocService.CreateTransfer`）：源库位减、目标库位加，事务内完成；源不足抛错拦截。
- **盘点**（`DocService.CreateCount`）：
  - 盘点单记录 `book_qty`（账面）vs `actual_qty`（实际扫码），`diff` 自动算。
  - 提交时 `AdjustStock` **把账面直接校正为实际数**（`doc_count_item.diff` 留痕）。

## 七、单据查询

`FrmDocQuery`：入/出/调拨/盘点按类型+状态（`draft/submitted/done/cancel`）分页查询；双击看明细；打印/导出。`DocService.QueryDocs` 用 `SELECT *` + 状态过滤，注意 transfer/count 表无 `type` 列（已用查询参数处理，避免空引用）。
