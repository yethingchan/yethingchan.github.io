## 2. 编译运行（5 步跑通）
```text
1) 双击打开  D:\A_Work\Vue\RuoYi-Vue\CSharpHost\CSharpHost.sln
2) 在"解决方案资源管理器"右键 Host 项目 → "还原 NuGet 程序包"
       （联网拉取 System.Data.SQLite，约几秒到一分钟）
3) 确认目标框架：Host 项目属性 → 目标框架 = .NET Framework 4.8
4) 按 F5（或"调试 → 开始调试"）启动
5) 登录框出现 → 账号 admin / 密码 123456 → 进入主界面
```
首跑会自动在 `%LocalAppData%\CSharpHost\host.db` 建库建表，并种入 admin 账号，**无需任何手工建库**。

## 3. 首次运行会发生什么
- `Program.Main` → `DbHelper.EnsureDb()`：
  - 目录 `%LocalAppData%\CSharpHost\` 不存在则创建；
  - 库文件不存在则 `SQLiteConnection.CreateFile` 并跑 `Schema.CreateAll`（全部 `CREATE TABLE IF NOT EXISTS`，**幂等**，二次运行不会报错）；
  - 已存在则仍跑一遍 `CreateAll` 以补齐升级时新增的表。
- `AuthService.EnsureAdmin()`：若 `sys_user` 里没有 admin，则插入 admin + 一个 operator 角色 + 默认权限种子。
- 之后打开 `LoginForm`；勾"记住登录"会把账号密码以 `XOR+Base64` 存到 `login.dat`（仅防明文，非高强度加密，勿用于公网）。
- 日志落到 `%LocalAppData%\CSharpHost\logs\comm_yyyyMMdd.log` 与 `app_yyyyMMdd.log`。

## 4. 发布成可分发程序
目标：生成一堆文件，拷到工控机直接双击 `Host.exe` 就能跑（**目标机不必装 VS**）。

1. 解决方案资源管理器 → 右键 Host → **"发布..."**（或"发布 Host"）。
2. 选 **"文件夹"** 目标，路径随便（如 `CSharpHost\Publish\`）。
3. 设置：
   - 部署模式：**独立 (self-contained)** 或 **依赖框架**（工控机若已装 .NET 4.8 运行库选依赖即可，包更小）；
   - 目标运行时：**win-x64**（多数工控机）或 **win-x86**（老 32 位机注意选 x86，否则 PLC 串口 DLL 可能不匹配）；
   - 配置：**Release**。
4. 点"发布"，去输出文件夹拿 `Host.exe` + 一堆依赖 dll + `System.Data.SQLite.dll`（含它的 native `SQLite.Interop.dll`）。
5. 整目录压缩拷到目标机解压即可。**不要只拷 exe**，缺 `SQLite.Interop.dll` 会报 `DllNotFoundException`。

> 若需"一键安装 + 自动装运行库"，可改用 **ClickOnce**（发布向导里选"ClickOnce"），它会在目标机自动检查并安装 .NET 4.8 运行库。

## 5. 开机自启 + 托盘部署
程序已内置支持，只差"把他放进启动项"：

**方式 A —— 启动文件夹（最简单）**
- 把 `Host.exe` 的快捷方式放进：`%AppData%\Microsoft\Windows\Start Menu\Programs\Startup\`
- 快捷方式"目标"末尾加空格 `/auto`，例如：
  `"D:\Deploy\Host\Host.exe" /auto`
- 系统登录后自动启动，程序读 `login.dat` 自动登入（需先手动登录一次并勾"记住登录"）。

**方式 B —— 注册表（适合域控批量）**
- `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` 或 `HKCU\...\Run`
- 新建字符串值：`CSharpHost` = `"D:\Deploy\Host\Host.exe" /auto`

**托盘后台**
- 运行后最小化 → 程序 `Hide()` 进后台，右下角托盘出现图标；
- 双击托盘图标恢复窗口；右键托盘 → 显示 / 锁屏 / 退出。
- 5 分钟无键鼠操作自动锁屏（弹 `FrmLock` 须重输密码）。

## 6. 常见坑与排查表
| 现象 | 原因 | 解决 |
|------|------|------|
| 打开 sln 报"找不到 .NET Framework 4.8" | VS 没装桌面工作负载 | VS 安装器补".NET 桌面开发" |
| 编译报 `DllNotFoundException: SQLite.Interop.dll` | 发布时没带上 native dll | 整目录发布，确认 `SQLite.Interop.dll`(x64/x86 匹配) 在场 |
| 运行提示"数据库初始化失败" | `%LocalAppData%` 被重定向/无写权限 | 确认当前用户对 `C:\Users\<你>\AppData\Local\` 可写 |
| 串口打不开 / 提示"端口不存在" | 串口名错（应是 `COM3` 不是 `3`）、被别的程序占用、USB 转串口驱动没装 | 设备管理器确认 COM 号；关掉占用的串口调试助手 |
| TCP 连不上 PLC / WCS | IP、端口错、防火墙挡、对端未起 | 先用 `FrmMsgDebug` 发测试帧；`ping`/`telnet ip port` 验证 |
| 收报看起来"粘"在一起 | 对端连发，多个帧灌进一个 buffer | 已是按 `0xAA…0x55` 拆帧（`ExtractFrames`），确认对端帧格式一致；可用 `FrmMsgDebug` 模拟验证 |
| 半截报文迟迟不解析 | 这是**分包**，在等后续字节 | 代码 `frameEnd > _bufLen` 时 `break` 等更多数据，正常；若对端不发了会卡，属协议层问题 |
| 出库提示"库存不足（禁止超领）" | 库存确实不够或条码/批次不匹配 | 先入库；或查 `mat_stock` 是否该物料有正库存 |
| 单据提交后库存没变 | 异常被 `DbHelper.Tx` 回滚了 | 看弹窗信息与 `logs\app_*.log` 的"全局未处理异常" |
| 改了代码重新发布仍跑旧逻辑 | 拷错目录 / 没重新发布 | 确认发布输出目录与拷贝的是同一份 |
| 多开导致抢串口 | 没限制单实例 | 已用 `Mutex "Global\\CSharpHostUpperComputer"` 防重复，若仍多开说明是不同用户会话 |
| 无真实硬件也想跑通 | — | 全工程内置 `PlcSimulator` + `SimSerialChannel`；用 `FrmPlcSim` 读写寄存器、用 `FrmMsgDebug` 收发十六进制帧即可全程演示 |
