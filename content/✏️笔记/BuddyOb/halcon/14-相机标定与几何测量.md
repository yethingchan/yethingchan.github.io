# L4-4 相机标定与几何测量

> 前置：[[halcon/13-分类与MLP_SVM]]
> 下接：[[halcon/15-三维视觉基础]]

## 1. 为什么要标定

- 像素 → **真实世界毫米**，必须知道内参（焦距、主点、畸变）。
- 未标定的尺寸只是"像素数"，不可比。

## 2. 标定板

- HALCON 提供 `caltab_*` 描述文件（圆点阵板），需打印已知间距板子。
- 也可用 `create_calib_data` 自定标定数据。

## 3. 标定流程

```halcon
* 1) 建标定数据
create_calib_data ('calibration_object', 1, 1, CalibDataID)
* 2) 设置相机参数初始值（面阵相机）
set_calib_data_cam_param (CalibDataID, 0, 'area_scan_division', \
    [0.016, 0, 0, 0, 0, 0, 0.0000074, 0.0000074, 2592, 1944])
* 3) 逐张找标定板
find_calib_object (Image, CalibDataID, 0, 0, 0, [], [])
* 4) 执行标定
calibrate_cameras (CalibDataID, Error)
* 5) 取内外参
get_calib_data (CalibDataID, 'camera', 0, 'params', CamParam)
```

## 4. 像素→世界坐标（测量）

```halcon
* 用相机位姿把像素映射到世界平面
image_points_to_world_plane (CamParam, Pose, Row, Col, 'mm', X, Y)
* 距离（世界单位）
distance_pp (X1, Y1, X2, Y2, DistMM)
```

## 5. 手眼标定（Eye-in-Hand / Eye-to-Hand）

- 配合机械臂：用 `hand_eye` 相关算子求相机与机器人基座变换。
- 是**企业级自动化**标配（引导机器人抓取）。
