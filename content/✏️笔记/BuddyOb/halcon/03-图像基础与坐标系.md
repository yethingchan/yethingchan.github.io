# L1-3 图像基础与坐标系

> 前置：[[halcon/02-HDevelop环境与HALCON语法]]
> 下接：[[halcon/04-图像采集与相机配置]]

## 1. 图像的基本属性

- **分辨率**：宽 × 高（像素数），如 2592×1944。
- **位深/通道**：
  - 灰度图：单通道 `byte`（0~255）。
  - 彩色图：`byte` 三通道（RGB / YUV / Bayer）。
- **像素值类型**：`byte`（0-255）、`uint2`、`real`（浮点，亚像素/标定后常用）、`int1/2/4`、`complex`、`direction`。

## 2. HALCON 坐标系（重要！）

- 原点在**左上角**。
- **行 Row 在前（y），列 Column 在后（x）**。
- 与数学 `(x,y)` 相反，初学者极易搞反：`(Row, Column)` = `(y, x)`。

```halcon
* 访问像素：get_grayval(Image, Row, Column, Grayval)
* 画点：gen_region_points
```

## 3. 通道操作

```halcon
* 读取为 RGB
read_image (ImageRGB, 'clip')
* 拆通道
decompose3 (ImageRGB, R, G, B)
* 灰度化
rgb1_to_gray (ImageRGB, GrayImage)
* 合并
compose3 (R, G, B, ImageRGB2)
```

## 4. 图像类型转换

```halcon
* byte -> real（做标定/浮点运算前常用）
convert_image_type (GrayImage, ImageReal, 'real')
* 缩放像素值范围
scale_image (ImageReal, ImageScaled, 1.0, 0.0)
```

## 5. 感兴趣区域 ROI

```halcon
* 画矩形 ROI
draw_rectangle1 (WindowHandle, Row1, Column1, Row2, Column2)
gen_rectangle1 (Rectangle, Row1, Column1, Row2, Column2)
* 减少定义域（只处理 ROI 内）
reduce_domain (Image, Rectangle, ImageReduced)
```
