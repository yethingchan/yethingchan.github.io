# HALCON 系统学习路线（循序渐进 → 企业级）

> 本目录系统讲解 MVTec HALCON 机器视觉库的全部核心知识点。
> 路线设计为 **5 个阶段**，从零基础到企业级工程落地，每阶段标注「📚要看的书」「🎯达标水平」「⚠️难度」。
> 建议在 Obsidian 中从本页点 `[[ ]]` 双链逐篇往下学。

## 五阶段路线图

| 阶段 | 主题 | 核心能力 | 难度 |
|------|------|----------|------|
| **L1 基础** | 概述 / HDevelop / 图像基础 | 会装环境、能跑通第一个例程、理解图像与坐标系 | ⭐ |
| **L2 图像处理** | 采集 / 滤波 / 阈值 / 形态学 / Blob | 能独立完成"找目标→分割→计数"基础视觉任务 | ⭐⭐ |
| **L3 几何与匹配** | 边缘 / 轮廓 / 形状匹配 / 1D·2D 测量 | 能做定位、尺寸测量、缺陷检测 | ⭐⭐⭐ |
| **L4 高级应用** | OCR / 条码二维码 / 分类 / 标定 / 3D / 深度学习 | 能解决字符、识别、标定、AI 检测类工业需求 | ⭐⭐⭐⭐ |
| **L5 企业级** | C#/.NET 集成 / 性能优化 / 并行 / 部署规范 | 能把算法封装成稳定可维护的工业软件 | ⭐⭐⭐⭐⭐ |

## 📚 核心书单（贯穿全程）

1. **《Machine Vision Algorithms and Applications》** — Carsten Steger / Markus Ulrich / Christian Wiedemann（**必读圣经**，HALCON 核心作者写的理论+实践）
2. **HALCON 官方文档**：`%HALCONROOT%/doc`（Quick Guide、HDevelop User's Guide、Programming Guide、Solution Guides I~III）
3. **《数字图像处理》** — Gonzalez & Woods（补充经典理论，选读）
4. **参考中文**：《HALCON 机器视觉算法原理与编程实战》《机器视觉技术》（辅助理解）
5. **深度学习**：MVTec Deep Learning Tool 官方文档 + 例程（`%HALCONROOT%/examples`)

## 🎯 各阶段达标水平（自检清单）

- **L1 达标**：能在 HDevelop 跑例程、读懂 `.hdev` 结构、解释 image/region/xld 三者区别。
- **L2 达标**：拿到一张工业图，能选对预处理+分割方法，输出目标的 region 和数量。
- **L3 达标**：能实现模板匹配定位 + 亚像素边缘 + 尺寸测量，误差理解到像素/亚像素级。
- **L4 达标**：能独立交付 OCR、条码、分类、标定、DL 检测中的一类完整方案。
- **L5 达标**：能把 HALCON 算法封装进 C# 工业软件，处理异常、性能达标、可部署维护。
