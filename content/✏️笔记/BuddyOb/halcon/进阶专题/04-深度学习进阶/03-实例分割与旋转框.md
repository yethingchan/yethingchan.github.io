# 04-3 实例分割与旋转框（旋转/密集目标）

> 上接：[[halcon/进阶专题/04-深度学习进阶/00-索引]]

## 原理一句话
标准目标检测输出**水平矩形框（axis-aligned）**。但工业零件常**密集排列、互相重叠、且本身是斜的**——水平框会把多个零件框在一起、或框里塞满背景。两把钥匙：
- **实例分割（Instance Segmentation）**：输出每个目标的**像素级掩膜**，天然解决重叠/密集。
- **旋转框（Oriented/Rotated Box）**：输出带角度的框，贴合斜放零件。

## 路线 A：实例分割

```halcon
* 1) 建实例分割模型（注意 type 不同）
create_dl_model (DLModelSeg, 'instance_segmentation', \
                 [Width, Height, 3], [], [], [])
* 2) 标注格式：每张图给"逐像素的实例 id 图"
* 3) 训练同 04-2，推理得每个实例的 mask + 类别 + 置信
apply_dl_model (DLModelSeg, DLSample, 'segmentation', \
                DLResult)
*    DLResult 里每个实例：mask（区域）、class_id、score
```

## 路线 B：旋转框检测

```halcon
* HALCON 检测模型支持 'rotated_rectangle' 输出
* 标注时直接画带角度的矩形；推理返回 phi（角度）
* 用 smallest_rectangle2 把结果转成 (row,col,phi,len1,len2)
smallest_rectangle2 (Region, Row, Column, Phi, Len1, Len2)
*    Phi 是零件主轴方向 → 可直接用于引导旋转台/吸嘴对位
```

**逐行解释**：
- 实例分割的标注比检测重（要描轮廓/填像素），但换来**重叠目标个数精确、边界精确**——例如一盒药板里数清楚每粒药是否缺失。
- `smallest_rectangle2` 是 HALCON 经典算子，从任意区域求**最小外接旋转矩形**（含 `Phi` 角度）。旋转框检测本质是让 DL 直接预测这个 (Row,Col,Phi,Len1,Len2)。
- `Phi` 角度可直接驱动机械机构做**对位**（纠偏），这是旋转框在工业里比水平框更实用的原因。

## 选型
| 场景 | 推荐 |
|------|------|
| 零件不重叠、只需定位 | 水平框检测（最快） |
| 零件重叠/密集/要数个数 | **实例分割** |
| 零件斜放、要对位纠偏 | **旋转框** |
| 缺陷无定形 | 语义分割 / AD（见 [[halcon/进阶专题/01-缺陷检测专题/04-异常检测DeepAnomaly]]） |

## 关键坑
1. **旋转框角度歧义**：`Phi` 有 ±π 周期性，训练标注要统一约定（如 Len1≥Len2），否则网络学乱。
2. **分割边缘精度**：下采样倍率决定掩膜粗细，零件小要降下采样。
3. **标注成本**：实例分割标注最贵，能用旋转框解决就别上分割。
