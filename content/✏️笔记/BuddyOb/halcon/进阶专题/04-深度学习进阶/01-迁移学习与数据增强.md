# 04-1 迁移学习与数据增强（小样本救星）

> 上接：[[halcon/进阶专题/04-深度学习进阶/00-索引]]、[[halcon/16-深度学习Deep Learning]]

## 原理一句话
工业数据集动辄只有几十上百张——从零训一个深度学习网络必过拟合。**迁移学习**用 HALCON 预训练好的 backbone（在百万级自然图像上训过，已学会"边缘/纹理/部件"等通用特征），只**微调最后几层**适配你的任务。**数据增强**则在训练时实时对图片做几何/光度变换，人为"造"出更多样本、提升泛化。

## 算子链

```halcon
* 1) 创建模型时指定"预训练权重"（迁移的入口）
*    'pretrained_dl_classifier_compact.hdl' 是 HALCON 自带 backbone
read_dl_model (DLModel, 'pretrained_dl_classifier_compact.hdl')
*    或 create_dl_model 时传 'type'='classification' + 权重文件

* 2) 设置增强（训练时自动应用）
*    augmentation 参数：旋转/缩放/亮度/镜像...
set_dl_model_param (DLModel, 'augmentation', \
                    ['rotation','scale','brightness'], \
                    ['true','true','true'])
set_dl_model_param (DLModel, 'augmentation_rotation', \
                    rad(-15), rad(15))      * 旋转 ±15°
set_dl_model_param (DLModel, 'augmentation_brightness', \
                    'blit_range', [-20, 20]) * 亮度 ±20

* 3) 冻结浅层、只训深层（经典迁移策略）
*    HALCON 用 'learning_rate' 分块，或 set 不同块的 trainable
set_dl_model_param (DLModel, 'frozen_layers', ['conv1','conv2'])
```

**逐行解释**：
- `read_dl_model(..'.hdl')`：`.hdl` 是 HALCON 编译好的预训练模型。读进来后它已带通用视觉特征，你只在其上加分类头/检测头。
- `augmentation` 系列：训练时每张图**随机**施加这些变换，等于把 1 张图变成无限张不同版本，直接对抗小样本过拟合。
- `frozen_layers`：把前面卷积层"冻住"不更新，只训后面——既省算力，又防止小数据集把通用特征冲坏。**这是迁移学习的核心动作**。

## 关键技巧
1. **增强要"贴合真实变化"**：零件只会旋转不会上下镜像？那就别开镜像，否则教错分布。
2. **增强别过度**：亮度抖动 ±50 会把好件变坏件，过犹不及。
3. **小样本优先 AD**（见 [[halcon/进阶专题/01-缺陷检测专题/04-异常检测DeepAnomaly]]）：连标注都缺时，AD 比分类更合适。
4. **领域自适应**：若现场光照与训练差极大，增强里重点加"亮度+噪声+模糊"逼近现场。
