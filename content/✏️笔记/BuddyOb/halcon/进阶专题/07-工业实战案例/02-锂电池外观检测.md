# 07-2 锂电池外观检测（壳体/极片/焊点）

> 上接：[[halcon/进阶专题/07-工业实战案例/00-索引]]

## 需求
锂电（圆柱/方壳/软包）外观要检：① 金属壳表面划痕/凹坑/脏污；② 极片涂布均匀性（条纹/漏箔）；③ 极耳/焊点有无虚焊、偏移；④ 二维码追溯。难点：**壳体是高反光金属**，普通光直接过曝；极片是大面幅、低对比纹理。

## 方案分解
```
① 壳体表面缺陷（反光杀手）
   ├─ 光学：同轴光先压反光 [[05-光学成像专题/01-打光方案设计]]
   └─ 算法：光度立体提表面法线 [[01-缺陷检测专题/01-光度立体法PhotometricStereo]]
            划痕在法线图里极明显

② 极片涂布缺陷（大面低对比）
   └─ 频域带通/陷波，滤掉规则涂布纹理、留异常 [[01-缺陷检测专题/02-频域带通滤波]]
      或更稳：深度学习异常检测（OK 样本训）[[01-缺陷检测专题/04-异常检测DeepAnomaly]]

③ 焊点/极耳
   └─ 定位：形状匹配（刚性件）[[09-形状匹配与模板匹配]]
      判定：Blob 面积/灰度 + 几何测量 [[10-一维测量与二维计量]]

④ 追溯码
   └─ 二维码读取 [[12-条形码与二维码识别]]
```

## HALCON 流程骨架（以壳体光度立体为例）
```halcon
* 三光源图（同轴光，硬件打光先行）
read_image (Imgs, ['l0','l1','l2'])
* 光度立体：得到法线 + 高度场
PhotometricStereo (Imgs, Height, Grad, Albedo, [0,0,0],[-45,0,45], \
                   'gb','least_squares',[],[ ])
* 法线梯度突变 = 划痕
* 转成可检图后阈值
decompose3 (Grad, Nx, Ny, Nz)
* 例：算 Nz 的局部方差，高方差区域=划痕候选
* 再用 [[01-缺陷检测专题/04-异常检测DeepAnomaly]] 兜底微小缺陷
```

## 工程要点
- **深度学习兜底**：光度立体对"大面积不光顺"敏感但参数多；微小缺陷（针孔）用 AD 互补，双模型投票。
- **节拍**：极片是卷材→线阵相机 [[05-光学成像专题/03-线阵相机与高速成像]] + 分块处理。
- **GPU**：AD + 频域都重，上 GPU（[[06-性能与工程化专题/02-GPU与算子加速]]）。
- **安全**：电池检测漏检有起火风险，阈值保守 + 复检。

## 🎯 检查点
- [ ] 能说清"为何锂电壳体首选光度立体"
- [ ] 知道极片大面低对比该走频域还是 AD
- [ ] 理解双模型（光度立体+AD）投票的价值
