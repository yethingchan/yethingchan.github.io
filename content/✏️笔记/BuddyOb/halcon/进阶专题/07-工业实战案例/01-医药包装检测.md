# 07-1 医药包装检测（瓶签/铝箔/缺粒）

> 上接：[[halcon/进阶专题/07-工业实战案例/00-索引]]

## 需求
制药线要检：① 瓶身标签有没有、贴正没；② 生产批号/有效期 OCR 对不对；③ 泡罩板里**每粒药是否都在**（防漏装）；④ 胶囊颜色/有无破损。要求 100% 在线、节拍 ~300ms。

## 方案分解（对应专题）
```
① 标签定位
   └─ 瓶身+标签是"多部件相对转动" → 组件匹配 [[02-高级匹配专题/02-基于组件匹配]]
      标签角度 → 纠偏后裁 ROI 给 OCR

② 批号 OCR
   └─ 先阈值/极性归一 → 字符分割 → OCR [[11-OCR与字符识别]]
      字体用医药专用 .omc 训练（数字+字母）

③ 缺粒计数（泡罩板）
   └─ 泡罩孔是"密集、可能重叠" → 实例分割 [[04-深度学习进阶/03-实例分割与旋转框]]
      数 mask 个数 = 药粒数，少了=漏装报警
      （轻量替代：Blob+模板孔数对比，但重叠时分割更稳）

④ 颜色/破损
   └─ 颜色用多通道阈值；破损用 Blob 面积/圆度筛选 [[06-阈值分割与Blob分析]]
```

## HALCON 流程骨架
```halcon
* ① 组件匹配定位标签
find_component_model (Img, CompModel, .., Row, Col, Ang, Score, ..)
*   用 Ang 把图仿射校正到"标签水平"
hom_mat2d_rotate (HomMat, -Ang, Row, Col, HomMatR)
affine_trans_image (Img, ImgR, HomMatR, 'constant', 'false')

* ② 标签区域裁出 → OCR
reduce_domain (ImgR, LabelRegion, ImgLabel)
*    OCR 见 [[11-OCR与字符识别]]
* ③ 泡罩板实例分割数粒
apply_dl_model (DLSeg, DLSample, 'segmentation', DLRes)
*    统计实例数
* ④ 颜色判定
trans_from_rgb (Img, H, S, V, 'hsv')
threshold (S, ColorRegion, ..)   * 颜色异常
```

## 工程要点
- **节拍**：OCR + 分割都重，用 [[06-性能与工程化专题/03-并行与多线程节拍]] 把"取图"与"算法"流水化；分割上 GPU。
- **合规**：医药属 GMP 强监管，算法要**可审计**——结果图留档、参数版本化（见 [[halcon/19-企业级部署与最佳实践]]）。
- **误检代价极高**：宁可"报警复核"也不漏，阈值偏保守 + 人工复检工位。
