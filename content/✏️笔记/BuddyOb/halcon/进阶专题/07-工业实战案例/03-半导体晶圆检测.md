# 07-3 半导体晶圆检测（尺寸/缺陷/分类）

> 上接：[[halcon/进阶专题/07-工业实战案例/00-索引]]

## 需求
晶圆/芯片制造要检：① 关键尺寸（CD，线宽/间距）**亚微米精度**；② 表面颗粒/划伤/桥接/断线缺陷；③ 缺陷**分类归因**（光刻/刻蚀/颗粒）以改进工艺。环境是洁净室、工件小、精度要求极高。

## 方案分解
```
① 高精度尺寸测量（亚像素）
   └─ 先精密标定（远心镜头+标定板）[[14-相机标定与几何测量]]
      再亚像素边缘 + 计量模型 [[10-一维测量与二维计量]]
      → 线宽误差 < 1px，换算到微米

② 表面缺陷
   ├─ 高对比（颗粒/桥接）：Blob + 形态学 [[06-阈值分割与Blob分析]][[07-形态学运算]]
   └─ 低对比/微小：频域 [[01-缺陷检测专题/02-频域带通滤波]]
                    或 AD [[01-缺陷检测专题/04-异常检测DeepAnomaly]]

③ 缺陷分类归因
   └─ 提特征（面积/形态/灰度/位置分布）
      → MLP/SVM 分类 [[13-分类与MLP_SVM]]
      输出"颗粒/划伤/桥接"类别辅助工艺改进
```

## HALCON 流程骨架（尺寸测量）
```halcon
* ① 标定（洁净室用远心，畸变小）
*    见 [[14-相机标定与几何测量]]，得到 CamParam
* ② 亚像素边缘 + 计量
*    建 Metrology 模型测线宽
create_metrology_model (Metro)
add_metrology_object_line_measure (Metro, Row1, Col1, Row2, Col2, \
                                  Width, Height, 1, [], [], \
                                  MeasureHandle)
apply_metrology_model (Img, Metro)
get_metrology_object_result (Metro, 'all', 'result_type', 'all_param', R)
*    R 里含 measured 线对 → 算间距 = 真实尺寸（已含标定）
```

## 工程要点
- **远心镜头**：普通镜头有透视，边缘测不准；晶圆用远心消除视角误差。
- **温漂**：洁净室温控，但镜头/工件热胀，需定期重标定（[[halcon/19-企业级部署与最佳实践]] 的"模型版本与回滚"思路）。
- **分类闭环**：缺陷分类结果回灌工艺（哪台设备、哪道工序），是半导体 AOI 的核心价值——不止"检出来"，更要"告诉工程师为什么"。
- **节拍与精度权衡**：全图亚像素慢，先 Blob 粗定位候选区，再只对候选区做精密测量。
