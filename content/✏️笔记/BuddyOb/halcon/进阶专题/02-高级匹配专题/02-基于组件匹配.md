# 02-2 基于组件的匹配（Component-Based Matching）

> 上接：[[halcon/进阶专题/02-高级匹配专题/00-索引]]

## 原理一句话
有些物体**由多个部件组成、且部件间相对位姿会变化**（例如：带标签的瓶子——瓶身和标签各自会转；或一组齿轮的相对角度不固定）。把每个部件单独建模型，再学"部件之间的相对位姿关系"作为软约束，整体匹配既快又抗局部错位。

## 算子链

```halcon
* 1) 建各个组件的模型（先像普通 shape model 那样准备）
*    ComponentModel 需要：每个组件的 ModelID + 训练图
*    先准备单组件模板 contours（例如瓶身、标签）
create_component_model (TemplateImage, \
                        ['model_body','model_label'], \
                        [ModelBodyID, ModelLabelID], \
                        Rad(-15), Rad(30), 'auto', \
                        'auto', 'none', 'use_polarity', \
                        'auto', 'auto', ComponentModelID)

* 2) 训练组件间相对位姿（给一组含变化的训练图）
train_component_model (ComponentModelID, TrainingImages, \
                       -1, -1, 'true', 0, 0.8, 'training')

* 3) 查找（一次返回所有组件位姿）
find_component_model (SearchImage, ComponentModelID, \
                      Rad(-15), Rad(30), 0.7, \
                      0, 0.5, 'least_squares', \
                      0, 0.8, ModelIndex, RowComp, ColComp, \
                      AngleComp, ScoreComp, ModelComp)

* 4) 取组件轮廓并叠加
get_component_model_contours (Contours, ComponentModelID, 'all', 1)
```

**逐行解释**：
- `create_component_model` 第二个参数是**组件名列表**，第三个是**各自预建的 shape model ID**。`train_component_model` 用多张含变化的训练图**学习组件相对位姿分布**——这是它抗错位的核心。
- `find_component_model` 一次性返回所有组件的 Row/Col/Angle，你就能分别用每个部件的姿态做后续测量。
- 相对位姿约束是**软的**（概率分布），所以即使某部件被遮挡，其余部件仍能定位整体。

## 适用 vs 不适用
- ✅ 多部件、部件相对位置会变、又要整体定位 → 首选。
- ❌ 单一刚性物体 → 直接用 `create_shape_model` 更快。
- ❌ 部件形变（非刚性）→ 用 [[halcon/进阶专题/02-高级匹配专题/01-可形变模板匹配]]。

## 关键坑
1. **训练图要覆盖位姿变化范围**：变化没训到，推理就失配。
2. **组件别切太碎**：切太细匹配慢且噪声大，按"功能/可见性"切。
3. **极性一致**：训练与现场光照差异大时，用 `'ignore_local_polarity'`。
