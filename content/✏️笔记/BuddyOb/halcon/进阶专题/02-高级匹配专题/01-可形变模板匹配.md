# 02-1 可形变模板匹配（Deformable Matching）

> 上接：[[halcon/进阶专题/02-高级匹配专题/00-索引]]

## 原理一句话
标准形状匹配把模板当**刚性**找。可形变匹配允许模板在**局部发生弹性变形**（拉伸、弯曲），用"形变能量"约束不让它乱变形。适合**橡胶、软包装、布料、皮革**这类天生会变形的物体。

## 算子链

```halcon
* 1) 从参考图提取模板（不再是 create_shape_model）
*    Variant 指定变形模型：'rigid'（仅平移旋转）/ 'aniso'（各向异性缩放）
*    'planar'（平面透视变形）
create_deformable_model (Template, 'auto', \
                         rad(-10), rad(20), 'auto', \
                         rad(-10), rad(20), 'auto', \
                         'auto', 'none', 'use_polarity', \
                         'auto', 'auto', \
                         ['min_contrast','model_type'], ['auto','aniso'], \
                         ModelID)

* 2) 查找（允许最大变形量）
find_deformable_model (SearchImage, ModelID, \
                       rad(-10), rad(20), \
                       0.7, 0, 0, 'least_squares', \
                       [3,1], 0.7, \
                       Row, Column, Angle, Score, \
                       HomMat2D)

* 3) 取回变形后的轮廓（可见它"弯"成什么样）
get_deformable_model_contours (Contours, ModelID, 1)
*   用 HomMat2D 把模板轮廓映射到匹配位置
affine_trans_contour_xld (Contours, ModelAtPos, HomMat2D)
```

**逐行解释**：
- `create_deformable_model` 参数分两段角度：先模板本身的角度范围，再允许的**搜索旋转范围**；`'aniso'` 表示允许 x/y 方向不同比例缩放（布料被拉偏常见）。
- `find_deformable_model` 倒数第二组 `[3,1]` 是**平滑/网格分辨率**：`3` 是变形网格大小，`1` 是亚像素插值。值越小越精细但越慢。
- `HomMat2D` 是**把模板逐点变形映射到现场的变换矩阵**——这就是"变形结果"本身，可直接叠加显示。

## 关键坑
1. **变形量不能开太大**：`find` 里 `0.7` 是相对变形幅度上界，过大易误匹配且巨慢。先小后调。
2. **对比度与极性**：变形件常光照不均，`'use_polarity'` 若不稳，试 `'ignore_global_polarity'` 或 `'ignore_local_polarity'`。
3. **模板质量**：变形匹配的模板要从**最"标准"的一张**提取，别用已经变形的当模板。
4. **性能**：比刚性匹配慢数倍，必要时降分辨率（`find_deformable_model` 内部会自动金字塔，但输入图别太大）。
