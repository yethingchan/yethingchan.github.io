# 03-1 点云处理与分割（ObjectModel3D）

> 上接：[[halcon/进阶专题/03-三维视觉进阶/00-索引]]、[[halcon/15-三维视觉基础]]

## 原理一句话
3D 数据在 HALCON 里统一用 **`ObjectModel3D`** 表示（点云 / 网格 / 体素都包这一种结构）。高级操作围绕它：去噪、下采样、分割（按平面/法线/曲率）、拟合几何基元、计算形貌特征。

## 核心算子

```halcon
* 1) 从深度图/XYZ 图像构造点云
*    XYZ 三张图（每张是 HxW 的 float，记录每个像素的 x/y/z 真实坐标）
xyz_to_object_model_3d (X, Y, Z, ObjectModel3D)

* 2) 去噪 + 下采样（体素化，提速且均匀）
smooth_object_model_3d (ObjectModel3D, 'mls', [], \
                        [['neighbor_type','mls_order'],['xyz','2']], \
                        OM3DSmooth)
sample_object_model_3d (OM3DSmooth, 'fast', 0.01, OM3DSampled)
*    0.01 = 体素边长（米），越大点越稀

* 3) 分割：按平面将场景拆成"地平面 + 物体"
*    return_upper_threshold 控制保留上半部分
segment_object_model_3d (OM3DSampled, 'planarity', 0.05, 0.5, \
                         ObjectModel3DSegmented)
*    0.05 = 平面度阈值；0.5 = 保留平面以上 50% 高度带

* 4) 拟合一个平面并求平面度（缺陷：表面是否平整）
fit_primitives_object_model_3d (ObjectModel3DSegmented, \
                                ['primitive_type','fitting_algorithm'], \
                                ['plane','least_squares_tukey'], \
                                OM3DPlane, \
                                ['outlier_percentage','ground'],[5.0,'true'])
*    返回平面参数 + 残差，残差标准差即"平面度"
```

**逐行解释**：
- `xyz_to_object_model_3d`：这是把**深度相机/结构光/双目**输出的 XYZ 图转成点云的标准入口。
- `smooth_object_model_3d(..'mls'..)`：移动最小二乘（MLS）曲面平滑，同时可补洞。`'mls_order'='2'` 拟合二次多项式，能修表面噪声。
- `segment_object_model_3d(..'planarity'..)`：基于**平面度**分割，把"像平面的"和"不太平的"分开——提取桌面/载具平面、保留上方物体。
- `fit_primitives_object_model_3d`：把点云拟合成平面/球/圆柱等基元；`'least_squares_tukey'` 是抗离群点的稳健拟合（5% 离群容忍）。

## 关键坑
1. **坐标单位**：XYZ 图单位通常是米，别和毫米的机器人坐标混（手眼标定时要统一，见 [[halcon/进阶专题/03-三维视觉进阶/03-手眼标定实战]]）。
2. **噪声来自深度相机**：先平滑再分割，否则平面度虚高。
3. **下采样粒度**：体素太大丢细节，太小算得慢。按缺陷最小尺寸反推。
