# 03-2 三维匹配与配准（Registration）

> 上接：[[halcon/进阶专题/03-三维视觉进阶/00-索引]]、[[halcon/15-三维视觉基础]]

## 原理一句话
把**扫描得到的工件点云**和**标准 CAD/模板点云**对齐到同一坐标系——对齐后，模板上的"理论位置"直接映射到现场，就能做**偏差检测、引导、比对**。两类方法：

- **ICP（迭代最近点）**：无模型、纯几何对齐，靠反复找最近点+求刚性变换迭代收敛。
- **表面匹配（surface-based）**：先用 CAD 建 3D 形状模型，现场直接 `find_surface_model` 一步定位（更像 3D 版形状匹配）。

## 路线 A：ICP 配准

```halcon
* 1) 准备：Scene（现场点云）与 Model（标准点云）
*    先做粗配准（如用上面 03-1 的分割/姿态初值）
* 2) 精配准 ICP
registration_3d_object_model (Scene, Model, 'icp', \
                               ['max_iterations','point_distance'], \
                               [200, 0.005], \
                               Pose, Covariance)
*    Pose：把 Model 对齐到 Scene 的 3D 位姿（7 元：3平移+4四元数）
*    0.005 = 收敛距离阈值（米）
```

## 路线 B：表面匹配（有 CAD 模型时更强）

```halcon
* 1) 从 CAD/标准点云建表面模型
prepare_object_model_3d (ModelOM3D, 'reduce_resolution', 0.005, \
                         ModelReduced)
create_surface_model (ModelReduced, 'auto', [], [], SurfaceModelID)

* 2) 现场查找（一步出位姿，带姿态抽样）
find_surface_model (SceneOM3D, SurfaceModelID, \
                   0.03, 0.3, 0.5, 'false', \
                   'num_matches', 1, \
                   Pose, Score, SurfaceMatchingResultID)
*    0.03/0.3 = 采样点距范围；0.5 = 最小得分
```

**逐行解释**：
- ICP 的 `Pose` 是 7 维位姿（HALCON 约定：3 平移 + 4 四元数），可用 `pose_to_hom_mat3d` 转 4×4 矩阵做坐标变换。
- 表面匹配 `create_surface_model` 内部基于 **3D 特征（如 FPFH 类）** 建立可快速检索的结构；`find_surface_model` 用 RANSAC + 姿态投票，对部分遮挡、噪声都更鲁棒，且**速度通常优于纯 ICP**。
- 实战常**组合**：ICP 精修表面匹配的初值。

## 关键坑
1. **粗配准先行**：ICP 是局部收敛，初值差会陷入错误局部最优。用分割/重心/表面匹配结果给初值。
2. **点云密度匹配**：Model 与 Scene 密度差太多，最近点对应错。先 `sample_object_model_3d` 统一分辨率。
3. **离群点**：`registration_3d_object_model` 的 `'point_distance'` 要合理，过大把噪声当对应。
