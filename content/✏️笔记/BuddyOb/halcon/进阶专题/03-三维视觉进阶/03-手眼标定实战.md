# 03-3 手眼标定实战（Hand-Eye Calibration）

> 上接：[[halcon/进阶专题/03-三维视觉进阶/00-索引]]、[[halcon/14-相机标定与几何测量]]

## 原理一句话
视觉给了"物体在**相机坐标系**下的位姿"，机器人要的是"物体在**机器人基坐标系**下的位姿"。中间差一个固定变换：**手眼矩阵（Hand-Eye）**。标定就是求出它，让视觉结果能直接喂给机器人去抓取。

两种安装：
- **Eye-in-Hand（眼在手上）**：相机装在机械臂末端。求 `base_M_cam`（相机相对机器人基坐标系）。
- **Eye-to-Hand（眼在手外）**：相机固定看工作台。也求固定变换。

## 算子链（Eye-in-Hand 为例）

```halcon
* 1) 先做相机内参标定（见 14 章），得到 CamParam
* 2) 准备手眼标定数据：对 N 个姿态，记录
*     - 机器人末端位姿 ToolInBasePose（机器人给的）
*     - 相机看到的标定板位姿 CalObjInCamPose（用 find_calib_plate 求）
* 3) 执行手眼标定
hand_eye_calibration (CalibDataID, Errors)
*    CalibDataID 里已塞入每组的 ToolInBasePose + CalObjInCamPose
*    输出：机器人基坐标 → 相机坐标 的变换（存进 CalibDataID）
* 4) 取结果
get_calib_data (CalibDataID, 'camera', 0, 'base_in_cam_pose', \
                BaseInCamPose)
*    之后：物体位姿_cam → 乘这个变换 → 物体位姿_base，直接发给机器人
```

**逐行解释**：
- 每组数据必须**同时**有"机器人末端位姿"和"相机看板位姿"，且两者对应同一时刻——这就是手眼标定的输入对。
- `hand_eye_calibration` 内部解的是 `Base_M_Tool * Tool_M_Cam = Base_M_Cam` 这类方程（AX=XB 问题），用多组姿态超定求解。
- 输出 `BaseInCamPose` 即"相机在机器人基坐标系中的位姿"，是后续所有坐标转换的钥匙。

## 实战要点（决定成败）
1. **标定板要进相机视野且清晰**：每个姿态板都要被完整看到，否则该组作废。
2. **姿态要有足够旋转多样性**：只平移不旋转，手眼矩阵解不准（退化）。建议覆盖多方向转动。
3. **单位统一**：HALCON 用米，机器人常用毫米——`set_origin_pose` 或换算时务必一致，否则抓取差 1000 倍。
4. **验证**：标定后用 `Errors` 看重投影误差，>1~2 像素说明数据采集有问题。
5. **固定后别动**：手眼矩阵只在"相机-机器人相对位置不变"时有效，重装要重标。
