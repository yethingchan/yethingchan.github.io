# 05-1 打光方案设计

> 上接：[[halcon/进阶专题/05-光学成像专题/00-索引]]

## 四种基础光及适用

| 打光 | 怎么打 | 适合 | 避坑 |
|------|--------|------|------|
| **明场（正面/前向）** | 光从相机侧打向物体 | 一般外形、字符、颜色 | 反光件会过曝 |
| **暗场（低角度掠射）** | 光几乎平行表面、极低角度 | **划痕/边缘/透明件轮廓**（划痕把光散射进镜头） | 背景要暗，否则没对比 |
| **同轴光（On-Axis）** | 半透镜让光沿光轴打、垂直照物体 | **镜面/金属反光件**、平整表面 | 结构占空间，贵 |
| **漫射（穹顶/Dome）** | 光从四面八方均匀包住 | 曲面、消除阴影、纹理均匀 | 细节对比低，不适合找划痕 |

## 选型决策树
```
物体是镜面/金属反光？
  ├─ 是 → 同轴光（先压反光），再考虑光度立体（见 01-1）
  └─ 否 → 找什么特征？
        ├─ 划痕/边缘 → 暗场（低角度掠射）
        ├─ 字符/色差 → 明场（配滤光片提对比）
        └─ 曲面/怕阴影 → 穹顶漫射
```

## 实战要点
1. **颜色滤光片是穷人版"算法"**：红物体在红光下变亮、在蓝光下变黑——用互补滤光片直接把背景压没，比后期阈值省事得多。
2. **光角度微调 = 特征开关**：同一划痕，光角度差 5° 可能从"看不见"变"极其明显"，务必在样件上实测。
3. **避免过曝**：曝光/增益别拉满，留出灰度动态范围给缺陷。
4. **稳定性 > 一时的好图**：产线要的是 7×24 一致，选光方案时考虑温漂、灰尘、振动。

## 与算法联动
- 反光件：光（同轴）+ 算法（光度立体 [[halcon/进阶专题/01-缺陷检测专题/01-光度立体法PhotometricStereo]]）双保险。
- 低对比：光（暗场/滤光）+ 算法（频域 [[halcon/进阶专题/01-缺陷检测专题/02-频域带通滤波]]）。
