# 05-2 偏振与多光谱成像

> 上接：[[halcon/进阶专题/05-光学成像专题/00-索引]]

## 偏振（Polarization）：专治反光
### 原理
光有"振动方向"。光滑表面（金属、塑料、水面）的**镜面反射是部分偏振的**，而漫反射（物体本来的样子）基本不偏振。在镜头前加**偏振片**，旋转到合适角度，能把讨厌的镜面高光"滤掉"，只留漫反射细节。

### 应用
- **消除金属/玻璃反光**：看清楚反光件表面的真实纹理与缺陷。
- **应力检测**：透明塑料/玻璃受力会产生双折射，偏振下呈现彩色应力纹（工业上检注塑应力、玻璃良率）。
- **HALCON 配合**：偏振只是成像手段，得到"去反光图"后照常用 Blob/光度立体处理。

## 多光谱（Multispectral）：区分"肉眼同色"的材质
### 原理
普通相机看 RGB 三通道。多光谱相机在**多个窄波段**（如 405/45/590/730/850nm）成像。很多材质在**特定波段**才有差异——人眼看一样的，相机在特定光下立判。

### 应用
- **分拣**：同色不同材质（塑料种类、果蔬成熟度、药品真伪）。
- **缺陷**：某些缺陷只在近红外(NIR)显现（如农产品内部腐坏、印刷底纹）。
- **HALCON 配合**：多光谱图像是 N 通道图，`compose` 后可用**通道差/比值/分类（见 [[halcon/13-分类与MLP_SVM]]）** 区分。

## 关键坑
1. **偏振要转角度找最佳**：偏振片角度不是固定的，现场旋转到反光最小。
2. **多光谱需配对应光源**：波段要和照明匹配，否则没信号。
3. **成本与速度**：多光谱相机+分光器贵、帧率通常低，需评估产线节拍（见 [[halcon/进阶专题/06-性能与工程化专题/02-GPU与算子加速]]）。
4. **两种可叠加**：偏振去反光 + 多光谱分材质，是高端检测组合拳。
