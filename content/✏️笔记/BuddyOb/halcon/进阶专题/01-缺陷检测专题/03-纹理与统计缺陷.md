# 01-3 纹理与统计缺陷（皮革/织物/木材）

> 上接：[[halcon/进阶专题/01-缺陷检测专题/00-索引]]、[[halcon/06-阈值分割与Blob分析]]

## 原理一句话
自然纹理（皮纹、布纹）**没有规则周期**，FFT 法失效。改用**纹理特征**（局部对比度、熵、响应能量）逐块统计，偏离"正常纹理模型"的区域就是缺陷。

## 路线 A：局部阈值 + 纹理滤波
```halcon
* 用局部标准差/均值做"动态阈值"，适合纹理缓慢变化
* 思想：每个像素和"周边邻域均值"比，偏离太大=异常
var_threshold (Image, Region, 15, 15, 0.2, 2, 'dark')
* 解释：15x15 邻域；0.2 是标准差系数；2 是偏移；'dark' 找偏暗缺陷
connection (Region, Conn)
select_shape (Conn, Defects, ['area','ra'], 'and', [30,5], [99999,99999])
```

## 路线 B：纹理滤波器（ Laws / 高斯导数）
```halcon
* texture_laws：用 Laws 掩膜组（L5E5 等）提取纹理能量图
texture_laws (Image, Textures, 'el', 5, 5)
* 取某一响应通道，正常纹理能量均匀，缺陷处突兀
select_obj (Textures, EnergyMap, 3)
threshold (EnergyMap, Bad, 120, 255)   * 能量异常区
```

## 路线 C：高斯混合建模（无监督"正常"）
适合**你只有大量 OK 图、几乎没有 NG 图**的纹理场景：
```halcon
* 用 OK 样本训练一个"正常纹理模型"（GMM / 字典）
* 推理时，重构误差大的 = 缺陷
* 例：train_background_illum / create_text_model 系列
```
HALCON 在 `textury` 与 `class_2dim_sup` 之外，更现代的做法是**深度学习异常检测**（见 [[halcon/进阶专题/01-缺陷检测专题/04-异常检测DeepAnomaly]]），纹理统计法作为轻量兜底。

## 关键坑
1. **纹理阈值不能全局**：`var_threshold`/`dyn_threshold` 才是正解，全局 `threshold` 在纹理上必漏。
2. **邻域大小决定能检多小的缺陷**：邻域太小噪声多，太大漏小缺陷，需按缺陷尺寸反推。
3. **光照不均会伪缺陷**：先 `illuminate` 或同态滤波做光照归一。
