# 01-2 频域带通滤波（低对比度缺陷）

> 上接：[[halcon/进阶专题/01-缺陷检测专题/00-索引]]、[[halcon/05-图像预处理与滤波]]

## 原理一句话
把图转到**傅里叶域**，规则纹理（周期性）会聚成**离散的亮点（频谱尖峰）**。设计一个**带通/陷波滤波器**把"背景纹理的频率"滤掉、保留"破损/脏污"这类非周期低频或异常频率，再逆变换回空间域，缺陷就被"放大"出来了。

适用：**规则背景上的细微异常**——液晶玻璃、PCB 走线、纺织网孔、瓶盖螺纹。

## 典型流程

```halcon
* 1) 转灰度并做 FFT
rgb1_to_gray (Image, Gray)
fft_generic (Gray, ImageFFT, 'to_freq', -1, 'sqrt', 'dc_center', 'complex')

* 2) 构造带通/陷波掩膜：保留缺陷频带、抑制背景周期
*    gen_bandpass 生成一个带通（保留中间频带）
gen_bandpass (Bandpass, 0.4, 'none', 'rft', Width, Height)
*    或更常用：用 gen_circle_sector / gen_ellipse 在频谱上手动画"通带"，
*    把规则纹理的尖峰挖掉（陷波 notching）

* 3) 频域乘掩膜 → 逆变换
multiply_image (ImageFFT, Bandpass, ImageFFTf, 1, 0)
fft_generic (ImageFFTf, ImageFiltered, 'from_freq', 1, 'sqrt', \
            'dc_center', 'byte')

* 4) 此时缺陷对比度高了，普通阈值即可
threshold (ImageFiltered, RegionDef, 10, 255)
connection (RegionDef, Conn)
select_shape (Conn, Defects, 'area', 'and', 50, 999999)
```

**逐行解释**：
- `fft_generic` 的 `'dc_center'` 表示把零频（直流/平均亮度）移到频谱中心，方便我们"看中心、挖尖峰"。
- `gen_bandpass(.., 0.4, ..)` 的 `0.4` 是归一化频率（0~1，1=奈奎斯特），控制保留多宽的频带。值越小保留越低频。
- 实际工业里**更常用陷波（notch）**：先 `fft` 看频谱，找到规则纹理对应的亮尖峰，用 `gen_circle` 画小圆把这些尖峰"置 0"，其余频率保留——这样背景被压下去、缺陷凸显。

## 关键技巧
1. **先看频谱再设计滤波器**：`dev_display` FFT 结果，肉眼找尖峰位置，别盲调参数。
2. **窗口函数**：大图 FFT 边缘效应明显，先用 `crop_part` 取 ROI 或加窗。
3. **频域 + 空间域组合**：FFT 找候选区 → 原图局部再用 Blob/测量精修，精度更高。
4. 性能：FFT 单次 O(N log N)，但 HALCON 的 `rft_generic` 比 `fft_generic` 快（仅实数输入时用）。
