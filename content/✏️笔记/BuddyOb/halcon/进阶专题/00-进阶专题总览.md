## 学习顺序建议

```
光学成像(05)  → 决定你能"拍到什么"
   ↓
缺陷检测(01)  → 决定你能"看出来什么"
   ↓
高级匹配(02)  → 决定你能"定位到什么"
   ↓
三维视觉(03)  → 决定你能"量准什么"
   ↓
深度学习(04)  → 决定你能"识别到什么"
   ↓
性能工程化(06)→ 决定你能"跑多快、落不落得了地"
   ↓
实战案例(07)  → 综合打通
```

## 📚 进阶核心书单（高难度部分）

1. **Steger, Ulrich, Wiedemann《Machine Vision Algorithms in HALCON》** —— 算法原理圣经，光度立体、亚像素、三维的数学推导全在附录。
2. **《Halcon 算例集合 / Solution Guide III-B (3D)》《Solution Guide II-B (Matching)》** —— MVTec 官方专题手册，每个高难算子都配完整示例。
3. **Zhang, Z. "A flexible new technique for camera calibration" (2000)** —— 标定本质论文。
4. **Goodfellow《Deep Learning》** —— 理解 DL 章节的 backbone、loss、数据增强。
5. **补充：Ian 之外的实践书《Deep Learning for Vision Systems》(Manning)** —— 工业缺陷/分割实战友好。

## 🎯 学完本专题你的水平

- 能独立设计一个从**打光 → 成像 → 算法 → 标定 → 部署**的完整工业视觉方案，而不是只会调现成例程。
- 面对"这个缺陷 HALCON 例程里没有"的需求，能判断该走**光度立体 / 频域 / 深度学习异常检测**哪条路。
- 能在 C#/C++ 工程里把 HALCON 算法以**毫秒级节拍**稳定跑在产线上，并做版本管理与回滚。

## 进阶学习清单（与讲解顺序一致，由易到难）

- [ ] 理解"成像决定上限、算法只是逼近上限"——先学光学成像专题
- [ ] 掌握光度立体法（多光源）提取表面法线与反照率
- [ ] 掌握频域带通滤波检测低对比度缺陷
- [ ] 掌握基于纹理/高斯混合的复杂背景缺陷
- [ ] 掌握深度学习异常检测（无缺陷样本也能训）
- [ ] 掌握可形变模板匹配（deformable matching）
- [ ] 掌握基于组件的匹配（component-based）与描述符匹配
- [ ] 掌握点云处理与三维配准（ICP/表面匹配）
- [ ] 掌握手眼标定（eye-in-hand / eye-to-hand）实战
- [ ] 掌握深度学习迁移学习与数据增强策略
- [ ] 掌握实例分割、旋转框、自定义训练调优
- [ ] 掌握打光方案设计（明场/暗场/同轴/漫射）
- [ ] 掌握偏振与多光谱成像原理与应用
- [ ] 掌握 HDevEngine 把 .hdev 嵌入 C# 工程
- [ ] 掌握 GPU 加速与算子并行/多线程节拍优化
- [ ] 能综合完成医药/锂电/半导体类实战案例
