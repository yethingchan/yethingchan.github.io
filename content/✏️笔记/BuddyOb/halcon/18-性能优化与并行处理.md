# L5-2 性能优化与并行处理

> 前置：[[halcon/17-与C#_NET_VS集成]]
> 下接：[[halcon/19-企业级部署与最佳实践]]

## 1. 提速的层次

```
① 算法层：少算子、降分辨率、ROI 限定
② 算子层：选对算子（如 median vs mean）
③ 并行层：并行算子 / 多进程 / GPU
④ 架构层：异步、流水线、缓存模型
```

## 2. 算法与算子优化

- **reduce_domain 到 ROI**：只处理目标区，省大量计算。
- **降采样再处理**：金字塔思路，先小图粗定位。
- 形状匹配用**金字塔**（create_shape_model 自动）。
- 避免循环中 `threshold` 整个大图。

## 3. HALCON 并行算子

```halcon
* 自动并行（同一算子多 ROI）
* 用 tuple 输入，HALCON 内部并行
count_occurrences (...)
* 多线程：用 parallel_* 或 HDevEngine 多线程
```

- HALCON 多数算子**自动多线程**（受 `set_system('thread_num', N)` 控制）。
- 设 `set_system('parallelize_operators', 'true')`。

## 4. 模型复用（关键）

```halcon
* 模板/分类/计量模型只创建一次，循环里反复用
create_shape_model (...)        * 初始化时建
for i := 0 to N by 1
    find_shape_model (...)     * 循环内复用
endfor
clear_shape_model (ModelID)    * 结束时释放
```
> 企业级最容易犯的错：**每次循环都 create/clear 模型**，极慢。模型应全局持有。

## 5. GPU 与深度学习加速

- 安装 **CUDA 版 HALCON**（halconxl / 对应 GPU 库）。
- DL 推理默认走 GPU；传统算子 GPU 加速有限。

## 6. 性能评估

- `count_seconds (Start)` ... `count_seconds (End)` 测耗时。
- `profile`：HDevelop 自带性能分析（菜单→执行→性能分析）。
