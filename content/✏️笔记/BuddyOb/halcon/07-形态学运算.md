# L2-4 形态学运算

> 前置：[[halcon/06-阈值分割与Blob分析]]
> 下接：[[halcon/08-边缘检测与轮廓XLD]]

## 1. 作用在 Region 上的形态学

```halcon
* 膨胀（变大/填洞）
dilation_circle (Region, RegionDilation, 3.5)
* 腐蚀（变小/去噪点）
erosion_circle (Region, RegionErosion, 3.5)
* 开运算 = 先腐蚀后膨胀（去小噪点，保主体）
opening_circle (Region, RegionOpening, 3.5)
* 闭运算 = 先膨胀后腐蚀（填小洞，保主体）
closing_circle (Region, RegionClosing, 3.5)
* 形态学梯度 = 膨胀 - 腐蚀（轮廓）
difference (RegionDilation, RegionErosion, RegionBorder)
* 填充孔洞
fill_up (Region, RegionFilled)
* 去除小于 N 像素的小块
opening (Region, RegionOpen, 3)
```

## 2. 结构元素（SE）

- 圆形 `circle`、矩形 `rectangle1/2`、菱形 `diamond`、八角 `octagon`。
- 半径越大，作用越强。

## 3. 骨架与细化

```halcon
* 骨架提取（用于字符、裂纹）
skeleton (Region, Skeleton)
* 细化
thin (Region, ThinRegion)
```

## 4. 典型用途口诀

- 去小白点 → **开运算**
- 填空小洞 → **闭运算 / fill_up**
- 断线连接 → **闭运算 / dilation**
- 裂痕/字符骨架 → **skeleton**

## 5. XLD 上的形态学（亚像素）

`sort_contours_xld`、`union_adjacent_contours_xld`、`shape_trans_xld`（也可对 XLD 做变换）。
