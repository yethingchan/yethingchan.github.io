## 1. 一维测量（1D Measuring）— 卡尺法

用于：**边缘对之间的距离**（宽度、间隙、壁厚）。

### 流程

```halcon
* 1) 创建测量矩形（沿待测方向的"卡尺"）
gen_measure_rectangle2 (Row, Column, Phi, Length1, Length2, \
                        Width, Height, 'nearest_neighbor', MeasureHandle)
* 2) 测边缘对
measure_pairs (Image, MeasureHandle, 1.0, 30, 'all', 'all', \
               RowEdgeFirst, ColumnEdgeFirst, AmplitudeFirst, \
               RowEdgeSecond, ColumnEdgeSecond, AmplitudeSecond)
* 3) 距离 = 两对边缘间距
* 4) 释放
close_measure (MeasureHandle)
```

- `Length1`：测量方向半长；`Length2`：垂直方向半宽（越大越抗噪）。
- `Sigma=1.0` 高斯平滑；`Threshold=30` 边缘幅度阈值。

## 2. 单边缘测量

```halcon
measure_pos (Image, MeasureHandle, 1.0, 30, 'all', 'all', \
             RowEdge, ColumnEdge, Amplitude, Distance)
```

## 3. 二维计量（Metrology）★更现代、更强

把"测量对象"抽象成**计量模型**，可同时测圆/椭圆/线/矩形，自动拟合。

```halcon
* 1) 建计量模型
create_metrology_model (MetrologyHandle)
set_metrology_model_image_size (MetrologyHandle, Width, Height)
* 2) 加一个圆对象
add_metrology_object_generic (MetrologyHandle, 'circle', \
    [Row, Column, Radius], 20, 5, 1, 30, [], [], CircleIndices)
* 3) （可选）用形状匹配结果作为初始位姿
* 4) 执行测量
apply_metrology_model (Image, MetrologyHandle)
* 5) 取结果
get_metrology_object_result (MetrologyHandle, CircleIndices, 'all', \
    'result_type', 'all_param', Parameter)
* 6) 释放
clear_metrology_model (MetrologyHandle)
```

### 计量对象类型

`circle`（圆）、`ellipse`（椭圆）、`line`（直线）、`rectangle2`（矩形）。

## 4. 1D vs 2D 计量选择

| 需求 | 选 |
|------|----|
| 简单宽度/间隙、速度快 | 1D measure_pairs |
| 多个圆/矩形/线混合、需鲁棒拟合 | 2D Metrology ★ |
