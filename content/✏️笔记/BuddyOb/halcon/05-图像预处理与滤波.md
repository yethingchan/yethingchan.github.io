# L2-2 图像预处理与滤波

> 前置：[[halcon/04-图像采集与相机配置]]
> 下接：[[halcon/06-阈值分割与Blob分析]]

## 1. 为什么预处理

原始图常有噪声、光照不均、对比度低。预处理目标：**突出目标、抑制干扰**，为分割打基础。

## 2. 灰度变换（点运算）

```halcon
* 线性拉伸对比度
scale_image (Image, ImageScaled, 1.5, -50)
* 直方图均衡
equ_histo_image (Image, ImageEqu)
* 反相
invert_image (Image, ImageInvert)
```

## 3. 平滑滤波（去噪，会模糊边缘）

| 算子 | 特点 |
|------|------|
| `mean_image` | 均值，简单快，模糊明显 |
| `gauss_filter` | 高斯，保边较好 |
| `median_image` | 中值，**去椒盐噪声**最强，保边 |
| `binomial_filter` | 近似高斯，整数核快 |

```halcon
gauss_filter (Image, ImageGauss, 3)
median_image (Image, ImageMedian, 'circle', 3, 'mirrored')
```

## 4. 锐化 / 边缘增强

```halcon
* 拉普拉斯锐化
laplace (Image, ImageLaplace, 'absolute', 3, 'n_4')
* 高提升滤波
emphasize (Image, ImageEmph, 7, 7, 1.5)
```

## 5. 频域滤波（周期性噪声/纹理）

```halcon
* 傅里叶变换
fft_generic (Image, ImageFFT, 'to_freq', -1, 'sqrt', 'dc_center', 'complex')
* 在频域用 circular_binary 等掩膜滤波后再反变换
fft_generic (ImageFFT, ImageBack, 'from_freq', 1, 'sqrt', 'dc_center', 'byte')
```

## 6. 选择滤波的口诀

- 椒盐噪点 → **中值**
- 高斯噪声 → **高斯/均值**
- 整体光照不均 → **均衡化 / 同态 / 除法校正**
- 纹理/摩尔纹 → **频域**
