# L4-2 条形码与二维码识别

> 前置：[[halcon/11-OCR与字符识别]]
> 下接：[[halcon/13-分类与MLP_SVM]]

## 1. 一维条形码

```halcon
* 创建解码器（可指定码制，或 'auto'）
create_bar_code_model ([], [], BarCodeHandle)
set_bar_code_param (BarCodeHandle, 'element_size_min', 1.5)
* 解码
find_bar_code (Image, SymbolRegions, BarCodeHandle, 'auto', DecodedDataStrings)
* DecodedDataStrings 即条码内容
clear_bar_code_model (BarCodeHandle)
```

- 常见码制：`EAN-13`、`Code 128`、`Code 39`、`UPC-A`、`Interleaved 2 of 5`。
- 问题：对比度低/模糊 → 调 `element_size_min`、`min_identical_scanlines`。

## 2. 二维码（Data Matrix / QR）

```halcon
* 创建 2D 数据码模型
create_data_code_2d_model ('Data Matrix ECC 200', [], [], DataCodeHandle)
* 解码（可找多个）
find_data_code_2d (Image, SymbolXLDs, DataCodeHandle, 'stop_after_result_num', 1, \
                    ResultHandles, DecodedDataStrings)
clear_data_code_2d_model (DataCodeHandle)
```

- 类型：`Data Matrix ECC 200`、`QR Code`、`PDF417`、`Aztec`。
- 难点：镜面反光、小尺寸、弯曲表面 → 调 `minimum_module_size`、`contrast_min`、`mirrored`。

## 3. 通用调优

- 预处理增强对比度（equ_histo / emphasize）。
- 用 `get_bar_code_result` / `get_data_code_2d_results` 取调试信息（如候选位置）。
- 模块尺寸过小 → 提高图像分辨率或拉近镜头。
