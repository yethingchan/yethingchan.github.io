# L2-1 图像采集与相机配置

> 前置：[[halcon/03-图像基础与坐标系]]
> 下接：[[halcon/05-图像预处理与滤波]]

## 1. 采集接口

- **Image Acquisition Interface**：HALCON 通过 `open_framegrabber` 统一接入不同相机。
- 支持：GigE Vision、USB3 Vision、GenICam、DirectShow、File（读图）、以及其他厂商 SDK。

## 2. 从文件读图（最常用调试方式）

```halcon
read_image (Image, 'C:/data/part_001.png')
* 批量读目录
list_files ('C:/data', ['files','follow_links'], ImageFiles)
tuple_regexp_select (ImageFiles, ['\\.(png|jpg)$','ignore_case'], Selected)
for Index := 0 to |Selected|-1 by 1
    read_image (Image, Selected[Index])
endfor
```

## 3. 接真实相机

```halcon
* 打开 GigE 相机
open_framegrabber ('GigEVision2', 0, 0, 0, 0, 0, 0, 'default', -1, 'default', \
                    -1, 'false', 'default', 'default', 0, -1, AcqHandle)
* 设置参数
set_framegrabber_param (AcqHandle, 'ExposureTime', 20000.0)
set_framegrabber_param (AcqHandle, 'Gain', 1.0)
* 抓一帧
grab_image_start (AcqHandle, -1)
grab_image_async (Image, AcqHandle, -1)
* 关闭
close_framegrabber (AcqHandle)
```

## 4. 关键采集参数（影响成像质量）

| 参数 | 说明 | 调参方向 |
|------|------|----------|
| ExposureTime 曝光 | 进光量 | 太暗↑、运动模糊↓ |
| Gain 增益 | 放大信号 | 噪声随之↑ |
| PixelFormat | Mono8 / RGB8 / Bayer | 决定通道 |
| TriggerMode | 软触发/硬触发 | 产线用硬触发保证同步 |

## 5. 采集成像常见问题

- **过曝/欠曝**→ 调曝光增益。
- **运动模糊**→ 缩短曝光或加频闪光源。
- **拖影/不同步**→ 用硬件触发（encoder/PLC 信号）。
