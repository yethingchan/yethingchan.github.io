# L3-2 形状匹配与模板匹配

> 前置：[[halcon/08-边缘检测与轮廓XLD]]
> 下接：[[halcon/10-一维测量与二维计量]]

## 1. 形状匹配（Shape-Based Matching）★工业定位核心

适合：**有稳定形状、允许旋转缩放、有遮挡**的零件定位。

### 创建模板

```halcon
* 1) 用 ROI 圈出要匹配的零件
reduce_domain (Image, ROI, ImageReduced)
* 2) 提取边缘 XLD（金字塔）
* 3) 创建形状模型（自动从边缘轮廓学习）
create_shape_model (ImageReduced, 'auto', rad(-30), rad(60), 'auto', \
                     'auto', 'use_polarity', 'auto', 'auto', ModelID)
* 参数：图像, 金字塔层级, 起始角, 角度范围, 角度步长,
*        优化方式, 极性(明暗), 对比度, 最小对比度
get_shape_model_contours (ModelContours, ModelID, 1)
```

### 搜索匹配

```halcon
find_shape_model (SearchImage, ModelID, rad(-30), rad(60), 0.7, 0, 0.5, \
                 'least_squares', 0, 0.9, Row, Column, Angle, Score)
* 0.7 = 最小得分阈值；Score 越高越准
* 可视化
dev_display_shape_matching_results (Row, Column, Angle, ModelID, 1, 0)
```

## 2. 关键参数与调优

| 参数 | 作用 | 建议 |
|------|------|------|
| 角度范围 | 允许的旋转 | 实测零件最大转角 |
| 金字塔层级 | 由粗到精加速 | `auto` 通常够 |
| MinScore | 最低匹配分 | 0.7~0.9，过低误匹配 |
| 极性 | `use_polarity` 明暗一致 / `ignore_global_polarity` | 光照变化大用 ignore |
| NumMatches | 期望匹配个数 | 多目标设大 |

## 3. 优化要点

- 模板要有**足够边缘细节**，纯色块匹配不了。
- 光照变化大 → `ignore_global_polarity` 或 `ignore_local_polarity`。
- 多目标 → `NumMatches` 设上限，避免慢。
- 用 `set_shape_model_param` 动态调整。

## 4. 其他匹配方式对比

| 方法 | 适用 |
|------|------|
| 形状匹配 create_shape_model | 旋转缩放、遮挡的零件 ★ |
| 灰度匹配 create_ncc_model | 纹理丰富、无清晰边缘 |
| 形变匹配 create_local_deformable_model | 柔性/易变形物体 |
| 组件匹配 create_component_model | 多部件组合目标 |
