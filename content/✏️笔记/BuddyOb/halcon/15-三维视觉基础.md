# L4-5 三维视觉基础

> 前置：[[halcon/14-相机标定与几何测量]]
> 下接：[[halcon/16-深度学习Deep Learning]]

## 1. 三维数据来源

| 方式 | 说明 |
|------|------|
| 双目/多目立体 | 视差求深度 |
| 结构光 / 激光轮廓 | 三角测量 |
| ToF / 深度相机 | 直接深度图 |
| 点云文件 | XYZ 数组 |

HALCON 用 **ObjectModel3D** 统一表示 3D 数据。

## 2. 点云读取与显示

```halcon
* 读 PLY/OBJ/XYZ 等
read_object_model_3d ('part.ply', 'm', [], [], ObjectModel3D, Status)
* 采样/降噪
sample_object_model_3d (ObjectModel3D, 'fast', 0.01, [], [], Sampled)
* 显示（需 3D 窗口）
* visualize_object_model_3d(...)
```

## 3. 平面拟合与高度测量

```halcon
* 从深度图转点云
xyz_to_object_model_3d (X, Y, Z, ObjectModel3D)
* 拟合平面（找基准面）
fit_primitives_object_model_3d (ObjectModel3D, 'plane', [], [], PlaneModel)
* 求点到面距离（平面度/高度差）
```

## 4. 典型 3D 应用

- **平面度**：拟合平面 + 偏差。
- **体积/段差**：高度图统计。
- **3D 匹配**：`create_surface_model` 点云配准。
- **抓取位姿**：3D 位姿估计引导机器人。
