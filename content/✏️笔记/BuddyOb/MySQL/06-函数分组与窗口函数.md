# 06 · 函数、分组与窗口函数

## 1. 聚合函数（配合 GROUP BY）

| 函数 | 含义 |
|------|------|
| `COUNT(*)` | 行数（含 NULL 行） |
| `COUNT(col)` | 该列非 NULL 数 |
| `SUM/AVG/MAX/MIN` | 求和/平均/最大/最小 |

```sql
SELECT dept_id, COUNT(*) AS cnt, AVG(sal) AS avg_sal
FROM sys_user
GROUP BY dept_id;
```

> `COUNT(*)` vs `COUNT(1)` vs `COUNT(col)`：InnoDB 下 `COUNT(*)` 和 `COUNT(1)` 等价且最优；`COUNT(col)` 忽略 NULL。

## 2. GROUP BY / HAVING（回顾执行顺序）

- `GROUP BY` 分组；`SELECT` 里非聚合列必须出现在 GROUP BY 中。
- `HAVING` 过滤分组结果（可用聚合函数），在 GROUP BY 之后执行。

```sql
SELECT dept_id, COUNT(*) c
FROM sys_user
GROUP BY dept_id
HAVING c > 5;          -- 人数大于5的部门
```

## 3. 常用单行函数

| 类别 | 函数示例 |
|------|----------|
| 字符串 | `CONCAT(a,b)`, `SUBSTRING(s,1,3)`, `TRIM(s)`, `LENGTH(s)`, `REPLACE` |
| 数值 | `ROUND(x,2)`, `CEIL`, `FLOOR`, `MOD` |
| 日期 | `NOW()`, `DATE_FORMAT(d,'%Y-%m')`, `DATEDIFF(a,b)`, `DATE_ADD` |
| 流程 | `IF(cond,a,b)`, `CASE WHEN ... THEN ... ELSE ... END` |

```sql
SELECT
  user_name,
  CASE WHEN status=0 THEN '正常' ELSE '禁用' END AS st,
  DATE_FORMAT(create_time,'%Y-%m') AS month
FROM sys_user;
```

## 4. 窗口函数（MySQL 8.0 神器 ⭐）

**不改变行数**，在「窗口」内做计算，常用于排名/同比/累计。

```sql
SELECT
  dept_id, user_name, sal,
  ROW_NUMBER() OVER (PARTITION BY dept_id ORDER BY sal DESC) AS rn,       -- 不并列序号
  RANK()       OVER (PARTITION BY dept_id ORDER BY sal DESC) AS rk,       -- 并列跳号
  DENSE_RANK() OVER (PARTITION BY dept_id ORDER BY sal DESC) AS drk,     -- 并列不跳
  SUM(sal)     OVER (PARTITION BY dept_id ORDER BY user_id) AS running,   -- 累计和
  LAG(sal)     OVER (PARTITION BY dept_id ORDER BY user_id) AS prev_sal -- 上一行
FROM sys_user;
```

| 函数 | 用途 |
|------|------|
| `ROW_NUMBER()` | 行号（去重/分页常用） |
| `RANK()` / `DENSE_RANK()` | 排名（并列处理不同） |
| `LEAD()` / `LAG()` | 取后/前 N 行 |
| `SUM()/AVG() OVER` | 累计/移动平均 |
| `NTILE(n)` | 按序分桶 |

> 语法：`函数() OVER (PARTITION BY 分组 ORDER BY 排序 [窗口帧])`。
> 典型场景：**取每个部门工资前 3 名**、**按时间取上一条记录**——用 GROUP BY 做不到，必须窗口函数。

## 5. 行转列 / 列转行

- 行转列：`SUM(CASE WHEN ... THEN ... END)` 透视。
- 列转行：`UNION ALL` 多列拼成多行。
