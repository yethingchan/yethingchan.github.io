# 07 企业级 SQL 与架构实战 · 索引

> 前置：[[MySQL/进阶专题/00-进阶专题总览]]
> 基础入口：[[MySQL/00-总览与学习路线]]
> 本专题是进阶七部曲的"收口篇"——把前六个专题的原理，落到真实业务的 SQL 与架构上。

基础篇 06 已经讲过窗口函数、分库分表、备份容灾的"是什么"。本专题聚焦"怎么用对、怎么不出事"：

| 编号 | 主题 | 解决什么 | 链接 |
|------|------|----------|------|
| 01 | 窗口函数与递归 CTE 深度 | 排名/同比环比/树形递归，替代复杂子查询 | [[MySQL/进阶专题/07-企业级SQL与架构实战/01-窗口函数与递归CTE深度]] |
| 02 | 高并发扣减防超卖（WMS） | 库存"原子扣减"，杜绝超卖与脏写 | [[MySQL/进阶专题/07-企业级SQL与架构实战/02-高并发扣减防超卖(WMS)]] |
| 03 | 缓存与数据库一致性（Canal） | 缓存双写一致性、binlog 订阅兜底 | [[MySQL/进阶专题/07-企业级SQL与架构实战/03-缓存与数据库一致性(Canal)]] |
| 04 | 冷热分离归档与读写分离一致性 | 大表瘦身、从库延迟下的读一致性 | [[MySQL/进阶专题/07-企业级SQL与架构实战/04-冷热分离归档与读写分离一致性]] |
| 05 | 线上事故复盘（深分页/大事务/索引错配） | 三类最高频线上坑的成因与救法 | [[MySQL/进阶专题/07-企业级SQL与架构实战/05-线上事故复盘(深分页大事务索引错配)]] |

## 本专题贯穿主线

```
窗口函数/CTE(写对分析 SQL)
      ↓
高并发扣减(写对交易 SQL，不超卖)
      ↓
缓存一致性(读多写少场景的兜底)
      ↓
冷热分离 + 读写分离一致性(海量数据下的稳定)
      ↓
事故复盘(把前面踩过的坑统一归档)
```
