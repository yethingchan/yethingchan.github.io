## 学习顺序建议

```
事务锁(01) → 数据怎么"一致、不打架"
   ↓
索引优化器(02) → 查询怎么"快"、为什么慢
   ↓
分库分表(03) → 单库撑不住怎么办
   ↓
高可用复制(04) → 挂了怎么办
   ↓
备份容灾(05) → 删了/坏了怎么救
   ↓
调优运维(06) → 日常怎么"养"
   ↓
企业SQL实战(07)→ 综合打通 + 救火
```

## 📚 进阶核心书单

1. **《MySQL 技术内幕：InnoDB 存储引擎》—— 姜承尧** —— 中文里把 InnoDB 讲最透的，MVCC/锁/B+树/redo/undo 必读。
2. **《高性能 MySQL（High Performance MySQL）》—— Baron Schwartz 等** —— 调优、复制、分库分表、监控的圣经。
3. **《数据库索引设计与优化》—— Tapio Lahdenmaki** —— 从"响应时间"角度讲索引，颠覆直觉。
4. **MySQL 官方手册 "InnoDB Architecture"、"Optimization"、"Replication" 三章** —— 一切以 8.0 手册为准。
5. **《Designing Data-Intensive Applications》—— Martin Kleppmann** —— 理解复制/分片/一致性的本质（超越 MySQL）。

## 🎯 学完本专题你的水平

- 能对着 `EXPLAIN FORMAT=JSON` 和 `optimizer_trace` 说出"为什么走这个索引、cost 多少"。
- 能分析死锁（`show engine innodb status`）、定位长事务、解释 MVCC 读不阻塞写。
- 能设计分片键、选全局 ID 方案、用 ShardingSphere 落地分库分表。
- 能搭建 GTID + 半同步 + MGR 的高可用，配 ProxySQL 读写分离。
- 能独立完成 PITR 时间点恢复、误删库表应急、xtrabackup 物理备份。
- 能调 Buffer Pool、无痛做超大表 DDL（gh-ost），并用 Prometheus 监控告警。
- 能写出防超卖的库存 SQL、理解缓存与 DB 一致性、复盘深分页等线上事故。
