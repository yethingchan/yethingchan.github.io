# 15 · 备份恢复、容灾与安全规范

> 进阶路线：[[00-总览与学习路线]] → L4 企业级（收官） ｜ 前置：[[13-主从复制与读写分离]] ｜ [[03-数据类型与字符集]]

数据不丢、不被拖库、代码不埋雷 —— 这是「企业级」的底线。

## 1. 备份的两种思路

| 类型 | 工具 | 原理 | 恢复速度 | 影响 |
|------|------|------|---------|------|
| **逻辑备份** | `mysqldump` / `mysqlpump` / `mydumper` | 导出 SQL 文本 | 慢（逐条插） | 小，在线 |
| **物理备份** | `xtrabackup`(Percona) | 拷贝数据文件 | 快（直接拷回） | 大，近在线 |

```bash
# 逻辑：单库
mysqldump -u root -p --single-transaction db > db.sql
# 逻辑：全库(含存储过程/事件)
mysqldump -u root -p --single-transaction --routines --events --all-databases > full.sql
# 物理：热备
xtrabackup --backup --target-dir=/backup/full
```

> `--single-transaction`：InnoDB 一致性快照备份，**不锁表**（必须是 InnoDB）。

## 2. binlog 增量备份与 PITR

- 全量 + binlog = **时间点恢复（PITR）**：能恢复到「误删前一秒」。
- 必须 `log_bin = ON`、格式 `ROW`（见 [[13-主从复制与读写分离]]）。

```bash
# 从全备 + binlog 恢复到指定时间
mysqlbinlog --start-datetime="2026-07-19 10:00:00" \
           --stop-datetime="2026-07-19 14:00:00" \
           binlog.000123 | mysql -u root -p
```

> 误删表救命流程：恢复最近全备 → 重放全备后到误删前的 binlog → 数据回位。**所以 binlog 绝不能和主库放同一块盘**。

## 3. 容灾（DR）

- **异地备份**：备份副本跨机房/云（3-2-1 原则：3 份、2 种介质、1 份异地）。
- **主从/集群**：见 [[13-主从复制与读写分离]]、[[14-分库分表与高可用架构]]。
- **演练恢复**：备份不等于能恢复，**定期演练恢复**才是真容灾。

## 4. 安全：账号与权限

- **最小权限**：应用账号只给 `SELECT/INSERT/UPDATE/DELETE` 对应库，**绝不给 `GRANT`/`DROP`/`FILE`**。
- **禁 root 远程**：root 仅本地；应用用独立账号。
- **密码 + SSL**：`REQUIRE SSL`，密文传输。
- 角色（8.0）：`CREATE ROLE dev_ro;` 再赋给用户，便于批量管权限。

```sql
CREATE USER 'app'@'10.0.%' IDENTIFIED BY '强密码' REQUIRE SSL;
GRANT SELECT, INSERT, UPDATE, DELETE ON shop.* TO 'app'@'10.0.%';
```

## 5. SQL 注入防护（开发规范）

- **永远用预编译/参数化**（`#{}` / `PreparedStatement`），禁拼接。
- 回顾 MyBatis：`#{}` 预编译 vs `${}` 拼接风险，见 `MyBatis Mapper XML/04-sql片段与include`。
- 关掉不必要的 `FILE` 权限、限制 `secure_file_priv`。

## 6. 企业开发规范（阿里 MySQL 军规要点）

1. 表必有**自增/雪花主键**、`utf8mb4`、InnoDB。
2. **表达是否用 `TINYINT`（0/1）**，禁 `NULL` 布尔语义混乱。
3. **金额 `DECIMAL`**，禁 `FLOAT/DOUBLE`。
4. 索引：**高选择性、组合最左前缀、避免失效写法**（[[09-索引设计与优化实战]]）。
5. **禁用 `SELECT *`、禁用大事务、禁用 `DELETE/UPDATE` 不带 WHERE**。
6. 严禁在 MySQL 做复杂运算/大批量循环（交给应用/数仓）。
7. 分页**深分页用游标**（[[12-慢查询分析与调优]]）。
