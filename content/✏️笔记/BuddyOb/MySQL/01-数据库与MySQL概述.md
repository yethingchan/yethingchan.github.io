# 01 · 数据库与 MySQL 概述

> 进阶路线：[[00-总览与学习路线]] → L1 基础

## 1. 什么是数据库与关系型数据库

- **数据库（DB）**：按数据结构组织、存储、管理数据的仓库。
- **关系型数据库（RDBMS）**：数据以「二维表（行/列）」表示，表间通过「键」建立关系。核心理论是**关系代数**与**范式**。
- 主流 RDBMS：MySQL、PostgreSQL、Oracle、SQL Server。
- 对比 NoSQL（Redis/MongoDB）：关系型强一致、支持事务 SQL；NoSQL 弱一致、水平扩展好、适合非结构化/高并发 KV。

## 2. MySQL 简介

- 最流行的开源关系型数据库，2008 被 Sun 收购，后随 Sun 入 Oracle。
- **版本选择（企业现状）**：
  - 5.7：老牌稳定，但已停止维护（EOL）。
  - **8.0（推荐）**：默认引擎 InnoDB、支持 CTE、窗口函数、不可见索引、原子 DDL、角色权限、JSON 增强。
- 常见分支：Percona Server、MariaDB（社区分支）。

## 3. MySQL 逻辑架构（四层）

```
客户端 (mysql / Navicat / 应用 JDBC)
        ↓
① 连接层    : 连接管理、授权认证、线程池
        ↓
② 服务层    : 解析器、优化器(生成执行计划)、查询缓存(8.0已移除)、
                跨存储引擎功能(存储过程/触发器/视图)
        ↓
③ 存储引擎层: 插件式，InnoDB(默认) / MyISAM / Memory ...
        ↓
④ 文件系统层 : 数据文件(.ibd)、redo/undo log、binlog
```

> 关键点：**Server 层与存储引擎层分离**。SQL 优化、缓存是 Server 层；数据怎么存、事务怎么实现是引擎层（InnoDB）的事。

## 4. 核心逻辑概念

| 概念 | 说明 |
|------|------|
| 实例（instance） | 后台进程 + 内存结构，一个 mysqld 一个实例 |
| 数据库/模式（schema） | 一组表的容器（`CREATE DATABASE`） |
| 表（table） | 行（记录）+ 列（字段） |
| 索引（index） | 加速查询的数据结构，详见 [[07-索引原理B+Tree]] |

## 5. 安装与连接（速查）

```bash
# 客户端连接
mysql -h 127.0.0.1 -P 3306 -u root -p

# 看版本
SELECT VERSION();

# 看存储引擎
SHOW ENGINES;

# 看当前库
SELECT DATABASE();
```

## 6. 一条 SQL 的整体生命周期（预告）

`客户端 → 连接 → 解析 → 优化器生成计划 → 执行引擎调 InnoDB → 返回`
其中**优化器怎么选索引、InnoDB 怎么保证事务**，是后面 L3 的重点（[[08-执行计划EXPLAIN]]、[[10-事务ACID与隔离级别]]、[[11-锁机制与并发控制]]）。
