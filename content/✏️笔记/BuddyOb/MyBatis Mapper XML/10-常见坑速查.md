# 10 · 常见坑速查

> 上接：[[00-总览与目录]]
> 各主题详见对应模块。

## 1. `Could not resolve type alias 'Xxx'`
**原因**：实体 `Xxx` 所在包没被 `mybatis.typeAliasesPackage` 扫描到，别名未注册。
**解决**：把包加进该配置（可用 `**` 通配）。
- 本仓库：`ruoyi-admin/src/main/resources/application.yml`
  `typeAliasesPackage: com.ruoyi.**.domain,cn.yething.**.domain`
- 详见：[[02-parameterType与resultType]]

## 2. `parameterType="Long[]"` 报找不到别名
**原因**：MyBatis 默认别名**没有 `Long[]`**（只有 `long[]` 这种基本类型数组）。
**解决**：数组参数**直接省略 `parameterType`**，用 `collection="array"` 遍历。
- 详见：[[06-foreach的collection规则]]

## 3. `<foreach>` 报 `Parameter 'array' not found`
**原因**：`collection` 名字和实际参数形态不匹配。
**解决**：数组→`array`、List→`list`、有 `@Param("x")`→`x`。
- 详见：[[06-foreach的collection规则]]

## 4. `resultType` 列名对不上属性
**原因**：列名 `user_name` 对不上 `userName`，又没写 `resultMap`。
**解决**：开启下划线转驼峰，或改用 `resultMap` 显式映射。
- 详见：[[03-resultMap详细]]

## 5. `#{}` 与 `${}` 混用
**规则**：
- `#{}` 预编译防注入（**值**用这个）。
- `${}` 字符串拼接（表名/列名/`order by` 字段用这个，且值必须是写死的常量）。
- **用户输入禁止用 `${}`**，否则 SQL 注入。
- 详见：[[04-sql片段与include]]

## 6. XML 改了不生效
**检查**：
- `mapperLocations`（`classpath*:mapper/**/*Mapper.xml`）能扫到该文件；
- `target/classes` 下已重新拷贝（Maven/IDE 重新编译）；
- 多模块项目确认该模块已被主模块依赖、在 classpath 上。
- 详见：[[01-文件结构与四大标签]]
