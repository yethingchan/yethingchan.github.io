## 核心认知

动态 SQL 的本质是 **MyBatis 把 XML 里的 `<if>` 等标签编译成一个 `SqlNode` 树，运行时由 `OgnlCache` 求值后拼接出最终 SQL 字符串**。所以：
- 标签里能写 OGNL 表达式（`list.size`、`param.userName != null`）。
- `#{}` 会在拼接阶段先变成 `?`，最后由 JDBC 设参——所以占位符永远安全。
- `${}` 是**直接字符串替换**，永远做拼接用，**绝不拼用户输入**。
