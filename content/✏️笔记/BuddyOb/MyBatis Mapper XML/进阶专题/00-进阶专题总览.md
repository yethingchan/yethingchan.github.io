## 学习顺序建议

```
动态SQL高级(01)  → 先把"条件拼出来"
   ↓
高级结果映射(02) → 把"对象关系映射对"
   ↓
缓存机制深度(03) → 把"查过的别再查"
   ↓
批量与性能优化(04)→ 把"一次干一堆、别慢"
   ↓
插件与拦截器(05)→ 把"框架能力织进去"
   ↓
企业实战与排查(06)→ 综合打通 + 救火
```

## 📚 进阶核心书单

1. **《MyBatis 技术内幕》—— 徐郡明** —— 唯一把 `SqlSession`/`Executor`/`StatementHandler` 源码讲透的中文书，插件与缓存章节必读。
2. **MyBatis 官方文档 "Dynamic SQL" / "Mappers" / "Configuration" 三章** —— 所有标签与属性以官方为准（`trim`/`bind`/`@SelectProvider`）。
3. **《Java Persistence with MyBatis 3》—— K. S. K. Prasad** —— 进阶映射与缓存示例清晰。
4. **MyBatis-Spring 官方文档** —— `SqlSessionTemplate` 如何与 Spring 事务同步（对应 06-04）。

## 🎯 学完本专题你的水平

- 能写出任意复杂的动态 SQL（多级分支、嵌套集合、跨库方言），不再靠字符串拼接。
- 能正确设计一对一/一对多/多对多映射并理解延迟加载的触发条件与坑。
- 能基于 Redis 自实现二级缓存，并说清缓存三大问题与事务脏读。
- 能用 BATCH 执行器与流式查询把批量/大结果集性能拉满。
- 能读懂甚至自写 MyBatis 插件，理解 RuoYi 数据权限（`DataScopeAspect`）底层就是 SQL 注入。
- 遇到 `#{}` vs `${}`、类型别名找不到（`Locations` 那种）等诡异 Bug，能秒级定位根因。
