# 02-高级结果映射 · 构造器映射与列前缀继承复用

> 前置：[[MyBatis Mapper XML/进阶专题/02-高级结果映射/00-索引]]

## `constructor` 映射不可变对象

若 `SysUser` 没 setter、只有全参构造，用 `<constructor>`：

```xml
<resultMap id="userCtor" type="SysUser">
  <constructor>
    <idArg column="user_id" javaType="int"/>
    <arg column="user_name" javaType="string"/>
    <arg column="email" javaType="string"/>
  </constructor>
</resultMap>
```
- `<idArg>` 标记主键列（用于去重/缓存）。
- `<arg>` 按顺序对应构造器参数。
- 适合**不可变值对象（DTO/VO）**，比反射 setter 更稳。

## `columnPrefix`：同一行映射多个同级集合

当一次 JOIN 同时带出"角色列表"和"部门列表"两列集合，且列名前缀不同：

```xml
<resultMap id="userFull" type="SysUser">
  <id property="userId" column="user_id"/>
  <!-- 部门列用 d_ 前缀 -->
  <association property="dept" javaType="SysDept" columnPrefix="d_">
    <id property="deptId" column="id"/>
    <result property="deptName" column="name"/>
  </association>
  <!-- 角色列用 r_ 前缀 -->
  <collection property="roles" ofType="SysRole" columnPrefix="r_">
    <id property="roleId" column="id"/>
    <result property="roleName" column="name"/>
  </collection>
</resultMap>
```
SQL 里要起别名：`d_id, d_name, r_id, r_name`。`columnPrefix="d_"` 会自动把子映射的 `column="id"` 解析成 `d_id`。

## `extends`：resultMap 复用

```xml
<resultMap id="baseUser" type="SysUser">
  <id property="userId" column="user_id"/>
  <result property="userName" column="user_name"/>
</resultMap>

<resultMap id="userWithDept" type="SysUser" extends="baseUser">
  <association property="dept" javaType="SysDept" .../>
</resultMap>
```
- `extends` 把父 `resultMap` 的字段**继承**下来，子只加自己的。
- 配合 `discriminator`（见 03）或 `association` 复用，避免重复写基础字段。

## `autoMapping="true"` 与显式映射混用

```xml
<resultMap id="userAuto" type="SysUser" autoMapping="true">
  <id property="userId" column="user_id"/>
  <association property="dept" .../>   <!-- 显式处理关联，其余列自动映射 -->
</resultMap>
```
- `autoMapping` 下，列名按 `mapUnderscoreToCamelCase` 规则自动匹配同名属性。
- 显式写的（如 `association`）优先；其余自动。

## 整体复用建议

```
公共字段 → 抽成 baseUser（extends 复用）
关联对象 → 抽成独立 resultMap + <association resultMap="...">
多集合同表 → columnPrefix 区分
不可变对象 → constructor
多态行 → discriminator + extends
```
