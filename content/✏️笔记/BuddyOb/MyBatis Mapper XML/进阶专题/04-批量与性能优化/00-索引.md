## 核心认知

批量性能 = **减少网络往返 + 减少 SQL 解析 + 减少事务提交次数**。两个层面：
- **SQL 层面**：一条 `INSERT ... VALUES (...),(...)`（foreach）。
- **JDBC 层面**：`addBatch()` + `executeBatch()`（`ExecutorType.BATCH`）。
