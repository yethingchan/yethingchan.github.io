# 01 · 文件结构与四大语句标签

> 上接：[[00-总览与目录]]

## 1. 文件基本结构

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
"http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.ruoyi.system.mapper.SysUserMapper">

    <!-- 这里写 SQL 语句 -->

</mapper>
```

- `<mapper>` 根标签只能有一个。
- `namespace` 必须指向对应的 **Mapper 接口全限定名**（包名 + 接口名）。
- 每个 `<select>/<insert>/<update>/<delete>` 的 `id` 必须和接口里的方法名一致。

## 2. 四大语句标签

| 标签 | 用途 | 是否返回结果集 |
|------|------|----------------|
| `<select>` | 查询 | 是 |
| `<insert>` | 新增 | 否（返回影响行数） |
| `<update>` | 修改 | 否 |
| `<delete>` | 删除 | 否 |

### 通用属性

```xml
<select id="selectUserById"
        parameterType="Long"
        resultType="com.ruoyi.system.domain.SysUser"
        resultMap="SysUserResult"
        flushCache="false"
        useCache="true"
        timeout="10"
        fetchSize="256"
        statementType="PREPARED"
        databaseId="mysql"
        lang="xml">
    select ...
</select>
```

| 属性 | 说明 |
|------|------|
| `id` | **必填**，对应接口方法名，同一 namespace 内唯一。 |
| `parameterType` | 入参类型。**可省略**，MyBatis 运行时自动推断（详见 [[02-parameterType与resultType]]）。 |
| `resultType` | 返回结果类型（单条/集合的元素类型），用全限定类名或类型别名。 |
| `resultMap` | 自定义结果映射的 id（详见 [[03-resultMap详细]]）。`resultType` 与 `resultMap` 二选一。 |
| `useCache` | 该语句结果是否进二级缓存，默认 `true`（select）。详见 [[08-二级缓存cache]]。 |
| `flushCache` | 执行前是否清空缓存，默认 `false`（select）。 |
| `timeout` | 超时秒数。 |
| `fetchSize` | JDBC 抓取批量大小。 |
| `statementType` | `STATEMENT` / `PREPARED`（默认）/ `CALLABLE`。 |
| `databaseId` | 多数据库时按 `databaseIdProvider` 匹配。 |

> 关于 `resultType` 与 `resultMap` 的取舍，见 [[02-parameterType与resultType]]。
> 关于动态条件、批量遍历，见 [[05-动态SQL]] 与 [[06-foreach的collection规则]]。
