# MyBatis Mapper XML 语法 · 总览与目录

> 适用：MyBatis 3.x（本仓库 mybatis-3.5.x）。
> 一份 Mapper XML 对应一个 Mapper 接口：`namespace` = 接口全限定名，各语句 `id` = 接口方法名。
> 本目录为系统化拆分笔记，按主题分模块，用双链互相引用。

## 核心心智模型

```
一个 Mapper 接口  ──对应──>  一个 Mapper XML
  方法名 selectXxx   ──对应──>  <select id="selectXxx">
  方法参数            ──映射──>  parameterType / 动态SQL 的 test
  方法返回类型       ──映射──>  resultType / resultMap
```

- **入参怎么来**：`parameterType`（可省略）声明整体类型；动态 SQL 里用属性名取。
- **结果怎么去**：简单对象用 `resultType`（自动映射），列名对不上或有关联用 `resultMap`。
- **逻辑怎么写**：条件用动态 SQL（`if`/`choose`/`where`/`set`/`trim`/`foreach`/`bind`）。
- **批量怎么写**：`<foreach>`，关键是 `collection` 取值（见 [[06-foreach的collection规则]]）。

## 本仓库相关约定

- 类型别名由 `ruoyi-admin/src/main/resources/application.yml` 的
  `mybatis.typeAliasesPackage: com.ruoyi.**.domain,cn.yething.**.domain` 自动扫描 `*.domain` 包注册（简单类名即别名）。
- Mapper XML 扫描路径：`classpath*:mapper/**/*Mapper.xml`。
- Mapper 接口扫描：`@MapperScan`（本仓库已含 `cn.yething.test.mapper` 等）。
