# 01 · 部署架构总览

## 三种部署规模

### 1. 开发/演示（单机能跑就行）
```
你电脑：npm run dev（3000）  +  mvn spring-boot:run（8080）  + 本地 MySQL
```
最省事，仅本地自测。

### 2. Windows 服务器（小团队内部用）
```
Windows Server：
  Nginx（80）→ 托管 dist/ + 反代 /api → 后端 jar（8080）
  MySQL（3306）
```
前端静态资源走 Nginx，后端 jar 直接 `java -jar`，可选注册成 Windows 服务。

### 3. Linux 生产（推荐）
```
Linux（CentOS/Ubuntu）：
  Nginx（80/443）→ dist/ + 反代 /api → 后端（systemd 托管 jar，8080）
  MySQL（3306，或独立机）
```
生产标准做法：Nginx 反代 + systemd 守护 + 可选 Docker。

## 数据流（生产）

```
用户浏览器
   │  https://域名/         （Nginx 80/443）
   ▼
Nginx
   ├─ 静态资源 /  →  读 dist/index.html + assets/*
   └─ /api/*      →  proxy_pass http://127.0.0.1:8080/   （剥离 /api）
                       ▼
                   Spring Boot jar（8080）
                       ▼
                   MySQL（3306）
```

## 端口规划

| 服务 | 端口 | 对外 | 说明 |
|------|------|------|------|
| Nginx | 80 / 443 | ✅ | 用户访问入口 |
| Spring Boot | 8080 | ❌（仅内网） | 由 Nginx 反代，不直接暴露 |
| MySQL | 3306 | ❌（仅内网） | 只允许本机/内网连 |

> 安全原则：**只暴露 Nginx**，后端和数据库不对外网开放。

## 小结

生产 = Nginx 入口（静态+反代）+ 后端 jar（systemd/Docker）+ MySQL。只暴露 80/443，后端与数据库藏内网。
