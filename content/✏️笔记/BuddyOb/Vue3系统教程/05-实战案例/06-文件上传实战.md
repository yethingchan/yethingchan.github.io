# 06 · 文件上传实战

## 前端（el-upload）

```vue
<template>
  <el-upload
    action="/api/common/upload"
    :headers="{ Authorization: 'Bearer ' + getToken() }"
    :on-success="onSuccess"
    :before-upload="beforeUpload"
    list-type="text"
  >
    <el-button type="primary">上传文件</el-button>
  </el-upload>
</template>

<script setup>
import { getToken } from '@/utils/auth'
function beforeUpload(file) {
  const ok = file.size / 1024 / 1024 < 10
  if (!ok) ElMessage.error('文件不能超过 10MB')
  return ok
}
function onSuccess(res) {
  if (res.code === 200) {
    form.fileUrl = res.data.url
    ElMessage.success('上传成功')
  } else {
    ElMessage.error(res.msg)
  }
}
</script>
```

> ⚠️ `el-upload` 不走 `request.js`，所以 `action` 必须带 `/api` 前缀，且手动加 `Authorization`（从 `getToken()` 取）。

## 后端

```java
@PostMapping("/common/upload")
public AjaxResult upload(@RequestParam("file") MultipartFile file) {
    // 存本地磁盘或对象存储，返回可访问 URL
    String url = save(file);
    return AjaxResult.success(Map.of("url", url, "fileName", file.getOriginalFilename()));
}
```

`application.yml` 调大限制：
```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB
```

## 生产建议

- 文件存对象存储（OSS/COS）或 Nginx 静态目录，别塞进 jar。
- 上传接口至少过 JWT（本项目已带 token）。
- 校验文件类型（白名单），防上传可执行文件。

## 小结

上传 = `el-upload` 的 `action="/api/..."` + 手动 token；后端 `MultipartFile`；注意大小限制与存储位置。
