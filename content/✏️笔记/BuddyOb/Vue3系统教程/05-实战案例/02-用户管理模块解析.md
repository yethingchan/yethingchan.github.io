# 02 · 用户管理模块解析

用户管理是后台最核心的模块，串起"用户-角色-权限"整个体系。

## 后端结构（约定）

| 层 | 文件 |
|----|------|
| Controller | `controller/SysUserController`（`/system/user`） |
| Service | `SysUserService` |
| Mapper | `SysUserMapper` |
| Entity | `SysUser` |
| 接口 | `list / get / add / update / delete / 分配角色` |

## 关键接口契约

| 接口 | 权限 | 说明 |
|------|------|------|
| `GET /system/user/list` | `system:user:list` | 分页列表 |
| `POST /system/user` | `system:user:add` | 新增 |
| `PUT /system/user` | `system:user:edit` | 编辑 |
| `DELETE /system/user/{ids}` | `system:user:del` | 删除 |
| `GET /system/role/optionselect` | — | 下拉选角色 |

## 前端结构

- `views/system/user/index.vue`：表格 + 查询 + 新增/编辑弹窗（含角色多选）+ 删除。
- `api/system/user.js`：对应请求函数。

## 用户-角色关系

- `sys_user` 与 `sys_role` 是多对多，通过 `sys_user_role` 中间表关联。
- 新增用户时选角色 → 写入中间表。
- 登录时后端据用户角色汇总 `permissions`。

## 前端取数要点

```js
const res = await listUser(queryParams.value)
tableData.value = res.data.rows
total.value = res.data.total
```

## 权限按钮

```vue
<el-button v-hasPermi="'system:user:add'">新增</el-button>
<el-button v-hasPermi="'system:user:edit'">编辑</el-button>
<el-button v-hasPermi="'system:user:del'" type="danger">删除</el-button>
```

## 小结

用户模块 = 用户 CRUD + 角色分配 + 权限汇总。理解它，就理解了整个权限体系的基础。
