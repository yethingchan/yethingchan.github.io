# 04 · 菜单管理模块解析

菜单管理是"动态路由"的数据源，理解它才懂前端菜单怎么来的。

## sys_menu 关键字段

| 字段 | 含义 |
|------|------|
| `menu_id` | 菜单 ID |
| `parent_id` | 父 ID（0=顶级） |
| `menu_name` | 显示名 |
| `path` | 路由 path（如 `user`、`system`） |
| `component` | 视图组件（目录=`Layout`，菜单=`system/user/index`） |
| `perms` | 权限串（按钮用，如 `system:user:add`） |
| `menu_type` | M=目录 / C=菜单 / F=按钮 |
| `icon` | 图标（Element Plus 图标名） |
| `order_num` | 排序 |
| `status` | 0=显示 1=隐藏 |

## 三种类型

- **M（目录）**：只做分组，如"系统管理"。`component='Layout'`，有子菜单。
- **C（菜单）**：可点击进页面。`component='system/user/index'`，对应 `views/system/user/index.vue`。
- **F（按钮）**：不可见，只存 `perms`，用于后端 `@PreAuthorize` 和前端 `v-hasPermi`。

## 前端如何消费

`/getRouters` 返回菜单树 → `generateRoutes` 转换：
- `component='Layout'` → 套布局壳。
- `component='system/user/index'` → 懒加载 `views/system/user/index.vue`。
- `meta.title/icon` → 侧边栏文字与图标。

## 加一个新菜单（实战）

见 01 篇第 4 步。要点：父用 `M`+`Layout`，子用 `C`+`views` 路径，按钮用 `F`+`perms`。

## ⚠️ 常见错误

- `component` 路径与实际 `views/` 文件不符 → 点击菜单 404。
- 忘了给角色授权该菜单 → 登录后看不到。
- `icon` 填了不存在的图标名 → 图标空白。

## 小结

菜单 = 动态路由的数据源。M/C/F 三类，component 字段是前后端约定的关键。
