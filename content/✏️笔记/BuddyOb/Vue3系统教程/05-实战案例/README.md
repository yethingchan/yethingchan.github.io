## 实战口诀（记住这 8 句）

1. 后端四件套：Entity / Mapper / Service / Controller。
2. 前端两文件：`views/模块/index.vue` + `api/模块.js`。
3. 数据库两 SQL：`schema-mysql.sql` 加表 + `data.sql`(或菜单管理)加菜单/权限。
4. 权限串三处一致：注解 / 库 perms / v-hasPermi。
5. 数据取 `res.data`，列表用 `res.data.rows`/`total`。
6. 动态路由靠 `sys_menu`，后端 `component` 字段是约定核心。
7. 生产靠 Nginx 反代 `/api`，`proxy_pass` 末尾要带 `/`。
8. 刷新子路由 404 → 补 `try_files`。
