# 01 · 新增一个管理模块全流程

以"商品管理"为例，从零加一个完整 CRUD 模块。后端四件套 + 前端两文件 + 数据库两 SQL + 菜单权限。

## 步骤总览

```
1. 数据库：schema-mysql.sql 加商品表
2. 后端：Entity → Mapper → Service → Controller
3. 前端：api/goods.js + views/business/goods/index.vue
4. 菜单：在 sys_menu 插入父菜单+按钮权限（或写进 data.sql）
5. 启动验证
```

## 1. 数据库建表

`backend/src/main/resources/schema-mysql.sql` 追加：

```sql
CREATE TABLE sys_goods (
  goods_id    BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '商品ID',
  goods_name  VARCHAR(100) NOT NULL COMMENT '商品名称',
  price       DECIMAL(10,2) DEFAULT 0 COMMENT '价格',
  stock       INT DEFAULT 0 COMMENT '库存',
  status      CHAR(1) DEFAULT '0' COMMENT '状态（0正常 1停用）',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品表';
```

然后重新 `source schema-mysql.sql`（或单独执行这段）。

## 2. 后端四件套

**Entity** `domain/SysGoods.java`：
```java
@TableName("sys_goods")
public class SysGoods {
    @TableId(type = IdType.AUTO)
    private Long goodsId;
    private String goodsName;
    private BigDecimal price;
    private Integer stock;
    private String status;
    private Date createTime;
    // getter/setter
}
```

**Mapper** `mapper/SysGoodsMapper.java`：
```java
@Mapper
public interface SysysGoodsMapper extends BaseMapper<SysGoods> {}
```

**Service** `service/SysGoodsService.java`（本项目无接口+Impl，直接类）：
```java
@Service
public class SysGoodsService {
    @Autowired private SysGoodsMapper mapper;
    public List<SysGoods> list(SysGoods q) {
        return mapper.selectList(new QueryWrapper<>(q));
    }
    public int add(SysGoods g) { return mapper.insert(g); }
    public int update(SysGoods g) { return mapper.updateById(g); }
    public int delete(Long id) { return mapper.deleteById(id); }
}
```

**Controller** `controller/SysGoodsController.java`：
```java
@RestController
@RequestMapping("/business/goods")
public class SysGoodsController {
    @Autowired private SysGoodsService service;

    @PreAuthorize("hasAuthority('business:goods:list')")
    @GetMapping("/list")
    public TableDataInfo list(SysGoods q) {
        // 分页见 03 分册 10 篇
        return getDataTable(service.list(q));
    }
    @PreAuthorize("hasAuthority('business:goods:add')")
    @PostMapping
    public AjaxResult add(@RequestBody SysGoods g) { return toAjax(service.add(g)); }

    @PreAuthorize("hasAuthority('business:goods:edit')")
    @PutMapping
    public AjaxResult edit(@RequestBody SysGoods g) { return toAjax(service.update(g)); }

    @PreAuthorize("hasAuthority('business:goods:del')")
    @DeleteMapping("/{ids}")
    public AjaxResult del(@PathVariable List<Long> ids) { /* 批量删 */ }
}
```

## 3. 前端两文件

**api/business/goods.js**：
```js
import request from '@/utils/request'
export function listGoods(q) { return request({ url: '/business/goods/list', method: 'get', params: q }) }
export function addGoods(d) { return request({ url: '/business/goods', method: 'post', data: d }) }
export function updateGoods(d) { return request({ url: '/business/goods', method: 'put', data: d }) }
export function delGoods(ids) { return request({ url: '/business/goods/' + ids.join(','), method: 'delete' }) }
```

**views/business/goods/index.vue**：按 02 分册 15~17 篇的表格/表单/分页范式写（查询表单 + 表格 + 弹窗 + 分页 + 按钮带 `v-hasPermi`）。

## 4. 菜单与权限（关键）

在 `sys_menu` 插入（或通过菜单管理页加）：
```sql
INSERT INTO sys_menu(parent_id, menu_name, path, component, perms, menu_type, icon, order_num)
VALUES (0, '商品管理', 'goods', 'business/goods/index', '', 'M', 'Goods', 1);
INSERT INTO sys_menu(parent_id, menu_name, path, component, perms, menu_type)
VALUES (上条ID, '商品新增', '', '', 'business:goods:add', 'F');
INSERT INTO sys_menu(parent_id, menu_name, path, component, perms, menu_type)
VALUES (上条ID, '商品编辑', '', '', 'business:goods:edit', 'F');
INSERT INTO sys_menu(parent_id, menu_name, path, component, perms, menu_type)
VALUES (上条ID, '商品删除', '', '', 'business:goods:del', 'F');
```

- 父菜单 `menu_type='M'`，`component='business/goods/index'`（对应 `views/business/goods/index.vue`）。
- 按钮 `menu_type='F'`，`perms='business:goods:add'`（与后端注解、前端 `v-hasPermi` 一致）。
- 给 admin 角色授权这些菜单（菜单管理页勾选）。

## 5. 验证

1. 重启后端（entity 已扫描）。
2. 重新登录（菜单从 `/getRouters` 下发，左侧出现"商品管理"）。
3. 增删改查走通，按钮按权限显示。

## 小结

新增模块 = 建表 + 后端四件套 + 前端两文件 + 菜单权限 INSERT。权限串三处一致，组件路径对应 `views/`。
