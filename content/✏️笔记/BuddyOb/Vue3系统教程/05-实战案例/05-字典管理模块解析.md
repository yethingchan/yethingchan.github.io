# 05 · 字典管理模块解析

字典把"状态码↔中文"集中维护，避免硬编码。

## 表结构

- `sys_dict_type`：`dict_id`, `dict_name`(显示), `dict_type`(编码,如 `sys_normal_disable`)
- `sys_dict_data`：`dict_code`, `dict_type`(外键编码), `dict_label`(中文), `dict_value`(值), `dict_sort`

## 用法

前端下拉取字典：
```js
import { getDicts } from '@/api/system/dict'
const statusOptions = ref([])
getDicts('sys_normal_disable').then(res => { statusOptions.value = res.data })
```

表格里翻译：
```vue
<el-table-column label="状态">
  <template #default="scope">
    {{ statusOptions.find(d => d.dictValue === scope.row.status)?.dictLabel || scope.row.status }}
  </template>
</el-table-column>
```

## 后端接口

```
GET /system/dict/data/type/{dictType}  → 该类型字典项列表
GET /system/dict/type/list             → 类型列表
```

## 新增字典

1. 字典管理 → 新增类型（`sys_normal_disable` / 系统开关）。
2. 点类型 → 新增数据项（`0`=正常, `1`=停用）。
3. 前端用 `getDicts('sys_normal_disable')` 取。

## 小结

字典 = 类型表 + 数据表；前端 `getDicts(type)` 取列表用于下拉与翻译，避免在代码里硬编码中文。
