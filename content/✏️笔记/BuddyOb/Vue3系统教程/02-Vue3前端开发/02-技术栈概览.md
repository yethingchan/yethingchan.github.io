# 02 · 技术栈概览

本项目前端技术栈（已核对 `package.json`）：

| 技术 | 版本 | 作用 |
|------|------|------|
| Vue | ^3.5.10 | 视图框架（组合式 API） |
| Vite | ^5.4.8 | 构建/开发服务器 |
| Element Plus | ^2.8.4 | UI 组件库 |
| @element-plus/icons-vue | ^2.3.1 | Element Plus 图标 |
| Pinia | ^2.2.4 | 状态管理 |
| vue-router | ^4.4.5 | 路由 |
| axios | ^1.7.7 | HTTP 客户端 |

构建工具链：
- `@vitejs/plugin-vue`：让 Vite 识别 `.vue`。
- `vite`：开发服务器 + 打包（Rollup）。

## 为什么是这个组合

- **Vue 3 + Vite**：启动快、热更新秒级、组合式 API 好组织。
- **Element Plus**：后台管理系统最成熟的 Vue 3 组件库，表格/表单/弹窗开箱即用。
- **Pinia**：Vue 官方推荐的状态库，比 Vuex 简洁，TypeScript 友好。
- **vue-router 4**：Vue 3 配套的路由，支持 history 模式与动态 `addRoute`。
- **axios**：业界标准 HTTP 库，拦截器机制正好做 token 注入与统一错误。

## 语言

**纯 JavaScript（ESM）**，`package.json` 有 `"type": "module"`。没有 TypeScript、没有 Babel、没有 `jsconfig.json`（这些都可后加，非必需）。

## 与服务端的关系

```
Vue 前端 ──HTTP /api──▶ Spring Boot 后端 ──▶ MySQL
```

前端只负责界面与交互，后端只返回 JSON。

## 小结

技术栈 = Vue3 + Vite5 + Element Plus2.8 + Pinia2.2 + vue-router4 + axios，纯 JS。这套是当下后台管理系统的主流选择。
