# 20 · 侧边栏菜单渲染

侧边栏由 `src/views/layout/sidebarItem.vue` **递归**渲染后端下发的菜单树。

## 核心逻辑

```vue
<script setup>
import { computed } from 'vue'
import SidebarItem from './sidebarItem.vue'   // 自己引用自己（递归）
const props = defineProps({ item: { type: Object, required: true } })

// 解析完整路径（处理父/子 path 拼接）
function resolvePath(childPath) {
  if (/^https?:\/\//.test(childPath)) return childPath   // 外链直接用
  if (childPath.startsWith('/')) return childPath        // 绝对路径
  return props.item.path + '/' + childPath               // 相对路径拼接
}
</script>

<template>
  <!-- 有子节点 → 子菜单 -->
  <el-sub-menu v-if="item.children && item.children.length" :index="resolvePath(item.path)">
    <template #title>
      <el-icon v-if="item.meta?.icon"><component :is="item.meta.icon" /></el-icon>
      <span>{{ item.meta?.title }}</span>
    </template>
    <sidebar-item
      v-for="child in item.children"
      :key="child.path"
      :item="child"
    />
  </el-sub-menu>

  <!-- 无子节点 → 菜单项 -->
  <el-menu-item v-else :index="resolvePath(item.path)">
    <el-icon v-if="item.meta?.icon"><component :is="item.meta.icon" /></el-icon>
    <template #title>{{ item.meta?.title }}</template>
  </el-menu-item>
</template>
```

## 关键点

- **递归组件**：`sidebarItem` 自己 `import` 自己，遍历 `item.children`。
- 图标用 `<component :is="item.meta.icon" />`——图标名来自后端菜单的 `icon` 字段（如 `User`），已在 main.js 全局注册。
- `resolvePath`：处理外链（`http`）、绝对路径（`/xxx`）、相对路径拼接。
- 数据来自 `userStore.menus`（后端 `/getRouters` 下发的路由树）。

## 菜单项怎么点进去

`el-menu` 的 `router` 模式会把 `index` 当作路由跳转；本项目通过 `resolvePath` 拼出的路径正好是动态路由的 `path`，点击即跳转对应业务页。

## 小结

侧边栏 = 递归 `sidebarItem` 渲染 `userStore.menus`；图标取 `meta.icon`，路径由 `resolvePath` 拼接。
