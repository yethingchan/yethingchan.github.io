# 16 · 表单与弹窗标准用法

新增/编辑页面 = `el-dialog` + `el-form` + `v-model` 双向绑定。本项目标准范式：

```vue
<template>
  <el-dialog :title="title" v-model="open" width="500px" @closed="reset">
    <el-form ref="formRef" :model="form" :rules="rules" label-width="80px">
      <el-form-item label="用户名" prop="userName">
        <el-input v-model="form.userName" placeholder="请输入" />
      </el-form-item>
      <el-form-item label="状态" prop="status">
        <el-radio-group v-model="form.status">
          <el-radio value="0">正常</el-radio>
          <el-radio value="1">停用</el-radio>
        </el-radio-group>
      </el-form-item>
    </el-form>
    <template #footer>
      <el-button @click="open = false">取消</el-button>
      <el-button type="primary" @click="submit">确定</el-button>
    </template>
  </el-dialog>
</template>

<script setup>
import { ref, reactive } from 'vue'
import { addUser, updateUser } from '@/api/system/user'

const open = ref(false)
const title = ref('')
const formRef = ref()
const form = reactive({ userId: undefined, userName: '', status: '0' })
const rules = {
  userName: [{ required: true, message: '用户名不能为空', trigger: 'blur' }]
}

function openAdd() {
  reset(); title.value = '新增用户'; open.value = true
}
function submit() {
  formRef.value.validate((valid) => {
    if (!valid) return
    const api = form.userId ? updateUser(form) : addUser(form)
    api.then(() => { /* 刷新列表、关弹窗 */ })
  })
}
function reset() {
  formRef.value?.resetFields()
  Object.assign(form, { userId: undefined, userName: '', status: '0' })
}
</script>
```

## 关键点

- `v-model="open"`：`el-dialog` 的开关（子组件 `update:modelValue` 原理）。
- `:model="form"`：绑定表单对象；`:rules` 校验规则。
- `formRef.validate(cb)`：提交前校验，通过才发请求。
- 新增/编辑共用一个弹窗：靠 `form.userId` 是否存在判断调 `add` 还是 `update`。

## 小结

弹窗表单范式：弹窗 `v-model` 控制、`el-form` 绑定 `form` 与 `rules`、提交先 `validate`、按 `id` 选 add/update。
