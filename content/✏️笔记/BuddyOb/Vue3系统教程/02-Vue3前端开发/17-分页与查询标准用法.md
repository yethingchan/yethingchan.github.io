# 17 · 分页与查询标准用法

## 分页组件

```vue
<el-pagination
  v-model:current-page="queryParams.pageNum"
  v-model:page-size="queryParams.pageSize"
  :total="total"
  :page-sizes="[10, 20, 50]"
  layout="total, sizes, prev, pager, next, jumper"
  @current-change="getList"
  @size-change="getList"
/>
```

- `v-model:current-page` / `v-model:page-size`：双向绑定翻页参数。
- `:total`：总条数（来自后端 `res.data.total`）。
- 翻页/改每页大小触发 `getList` 重新拉数据。

## 查询表单

```vue
<el-form :model="queryParams" inline>
  <el-form-item label="用户名">
    <el-input v-model="queryParams.userName" placeholder="请输入" @keyup.enter="handleQuery" />
  </el-form-item>
  <el-button type="primary" @click="handleQuery">搜索</el-button>
  <el-button @click="resetQuery">重置</el-button>
</el-form>
```

```js
function handleQuery() {
  queryParams.value.pageNum = 1   // 查询回到第一页
  getList()
}
function resetQuery() {
  Object.assign(queryParams.value, { userName: '', pageNum: 1, pageSize: 10 })
  getList()
}
```

## 与后端契约

| 前端参数 | 后端接收 |
|----------|----------|
| `pageNum` / `pageSize` | `PageQuery` 的 `pageNum` / `pageSize` |
| `userName` 等筛选 | `@RequestParam` 或实体字段 |
| 返回 `res.data.rows` / `res.data.total` | `TableDataInfo` 的 `rows` / `total` |

## 小结

分页 = `el-pagination` 绑定 `pageNum/pageSize/total`；查询 = 表单 `v-model` 绑定 `queryParams`，搜索回第一页。
