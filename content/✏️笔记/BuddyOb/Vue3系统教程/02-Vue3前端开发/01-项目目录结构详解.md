# 01 · 项目目录结构详解

本项目的 `frontend/` 目录结构（已核对真实磁盘）：

```
frontend/
├── dist/                       # 构建产物（npm run build 生成）
├── index.html                  # 入口 HTML，挂载 #app
├── package.json                # 依赖与脚本
├── package-lock.json           # 依赖锁
├── vite.config.js              # Vite 配置（代理、别名）
├── node_modules/               # 依赖（npm install 生成）
└── src/
    ├── api/                    # 接口层（每个模块一个 js）
    │   ├── login.js
    │   ├── business/notice.js
    │   ├── monitor/operlog.js
    │   └── system/{config,dict,menu,role,user}.js
    ├── directive/              # 自定义指令
    │   ├── index.js            # 注册 v-hasPermi
    │   └── hasPermi.js
    ├── router/
    │   └── index.js            # 路由 + 路由守卫
    ├── store/
    │   ├── index.js
    │   └── modules/user.js     # 全局用户状态（唯一 store）
    ├── styles/
    │   └── index.css
    ├── utils/
    │   ├── auth.js             # token 存/取
    │   ├── permission.js       # hasPermi 权限判断
    │   ├── request.js          # axios 封装（核心）
    │   └── route.js            # 后端路由 → vue-router
    ├── views/                  # 页面（按模块分目录）
    │   ├── dashboard/index.vue
    │   ├── error/404.vue
    │   ├── layout/{index.vue, sidebarItem.vue}
    │   ├── login/index.vue
    │   ├── business/notice/index.vue
    │   ├── monitor/operlog/index.vue
    │   └── system/{config,dict,menu,role,user}/index.vue
    ├── App.vue                 # 根组件
    └── main.js                 # 入口
```

## 关键约定

| 目录/文件 | 职责 |
|-----------|------|
| `src/api/*` | 只放请求函数，不写业务逻辑 |
| `src/views/*` | 页面组件，按 `模块/index.vue` 组织 |
| `src/store/modules/user.js` | 全局登录态/菜单/权限（唯一 store） |
| `src/utils/request.js` | 所有 HTTP 请求的唯一出口 |
| `@` 别名 | 指向 `src/`，如 `@/api/login` |

## ⚠️ 项目没有的东西（别按 RuoYi 官方去找）

- 没有 `src/settings.js`（全局设置内联在各组件）。
- 没有 `src/store/modules/app.js`（只有 user，无布局/主题 store）。
- 没有 `public/` 目录（静态资源走 `index.html` 与 `styles`）。
- 没有 `.env*` 环境变量文件。
- 没有 `Dockerfile` / `nginx.conf` / 部署脚本（部署分册会补）。

## 小结

记住这张图：`api` 管请求、`views` 管页面、`store/user` 管全局态、`utils/request` 管 HTTP、`router` 管跳转。改功能基本就在这几个目录里转。
