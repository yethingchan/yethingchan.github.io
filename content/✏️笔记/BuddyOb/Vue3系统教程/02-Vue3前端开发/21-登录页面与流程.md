# 21 · 登录页面与流程

登录是前后端对接的第一道关。本项目登录流程：

```
用户输入账号密码
  → POST /api/login
  → 后端返回 { code:200, data:{ token } }
  → 前端存 token 到 localStorage
  → 跳转首页 /
  → 路由守卫触发 getInfo + getRouters
  → 挂载动态路由，进入首页
```

## 登录页核心

```vue
<script setup>
import { ref, reactive } from 'vue'
import { useUserStore } from '@/store/modules/user'
import { useRouter } from 'vue-router'

const userStore = useUserStore()
const router = useRouter()
const loginForm = reactive({ username: 'admin', password: '123456' })

function handleLogin() {
  userStore.login(loginForm).then(() => {
    router.push('/')           // 成功后进首页，守卫会自动拉信息/挂路由
  })
}
</script>

<template>
  <el-form :model="loginForm" @submit.prevent="handleLogin">
    <el-input v-model="loginForm.username" placeholder="用户名" />
    <el-input v-model="loginForm.password" type="password" @keyup.enter="handleLogin" />
    <el-button type="primary" @click="handleLogin">登录</el-button>
  </el-form>
</template>
```

## 关键点

- `userStore.login(form)` 内部调 `/login`，成功后 `setToken` 写 `localStorage`。
- 登录成功后 `router.push('/')`，**真正的用户信息/菜单拉取在路由守卫里做**（见 09 篇）。
- 默认账号 `admin / 123456`（后端 `data.sql` 注入角色/菜单，密码 BCrypt 运行时种入）。

## 退出登录

```js
await userStore.logout()   // 调 /logout + 清 localStorage + 清 state
router.push('/login')
```

## 小结

登录 = 调 `/login` 拿 token → 存 localStorage → 跳首页 → 守卫拉信息挂路由。默认 `admin/123456`。
