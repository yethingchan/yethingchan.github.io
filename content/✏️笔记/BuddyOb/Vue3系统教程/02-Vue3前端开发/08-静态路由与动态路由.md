# 08 · 静态路由与动态路由

本项目的路由分两层：**静态路由（写死在代码）+ 动态路由（后端下发）**。

## 静态路由（constantRoutes）

写在 `src/router/index.js`，所有人都能访问，与权限无关：

```js
export const constantRoutes = [
  { path: '/login', component: () => import('@/views/login/index.vue'), hidden: true },
  { path: '/404', component: () => import('@/views/error/404.vue'), hidden: true },
  {
    path: '/',
    component: () => import('@/views/layout/index.vue'),
    redirect: '/index',
    children: [
      { path: 'index', name: 'Index', component: () => import('@/views/dashboard/index.vue'),
        meta: { title: '首页', icon: 'HomeFilled', affix: true } }
    ]
  },
  { path: '/:pathMatch(.*)*', redirect: '/404', hidden: true }
]
```

- 登录页、404、布局壳、首页仪表盘是静态的。
- `meta` 存标题、图标、是否固定标签。

## 动态路由（后端菜单）

登录后，前端调 `/getRouters` 拿到后端菜单树，转成路由再 `addRoute`：

```js
const rawRouters = await userStore.getRouters()
const asyncRoutes = generateRoutes(rawRouters)
asyncRoutes.forEach((r) => router.addRoute(r))
```

后端返回的每个菜单节点形如：

```json
{
  "path": "system",
  "component": "Layout",
  "name": "System",
  "meta": { "title": "系统管理", "icon": "Setting" },
  "children": [
    {
      "path": "user",
      "component": "system/user/index",
      "name": "User",
      "meta": { "title": "用户管理", "icon": "User" }
    }
  ]
}
```

`generateRoutes`（`src/utils/route.js`）把 `component: 'Layout'` → 布局壳组件，`component: 'system/user/index'` → 懒加载 `views/system/user/index.vue`。

## 为什么要动态路由

- **菜单/权限由后端 `sys_menu` 表控制**：改数据库就能加菜单，前端不用改代码、重新打包。
- **按角色展示**：不同角色拿到不同菜单树，天然实现"看不到没权限的菜单"。

## 小结

- 静态路由：登录/404/布局/首页，写死。
- 动态路由：后端 `/getRouters` 下发，前端 `addRoute` 挂载。
- 这正是后台系统"菜单可配、权限可控"的关键。
