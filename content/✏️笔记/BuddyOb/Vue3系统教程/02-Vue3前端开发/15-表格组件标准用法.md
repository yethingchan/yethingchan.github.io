# 15 · 表格组件标准用法

后台系统的"列表页"几乎都是表格。本项目用 `el-table` 的标准范式：

```vue
<template>
  <el-table :data="tableData" v-loading="loading" border style="width:100%">
    <el-table-column type="selection" width="55" />
    <el-table-column type="index" label="#" width="55" />
    <el-table-column prop="userName" label="用户名" />
    <el-table-column prop="status" label="状态">
      <template #default="scope">
        <el-tag :type="scope.row.status === '0' ? 'success' : 'info'">
          {{ scope.row.status === '0' ? '正常' : '停用' }}
        </el-tag>
      </template>
    </el-table-column>
    <el-table-column label="操作" width="180">
      <template #default="scope">
        <el-button size="small" @click="handleEdit(scope.row)" v-hasPermi="'system:user:edit'">编辑</el-button>
        <el-button size="small" type="danger" @click="handleDelete(scope.row)" v-hasPermi="'system:user:del'">删除</el-button>
      </template>
    </el-table-column>
  </el-table>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { listUser } from '@/api/system/user'

const tableData = ref([])
const loading = ref(false)
const queryParams = ref({ pageNum: 1, pageSize: 10 })

function getList() {
  loading.value = true
  listUser(queryParams.value).then(res => {
    tableData.value = res.data.rows
    loading.value = false
  })
}
onMounted(getList)
</script>
```

## 关键用法

- `:data` 绑定数组；`v-loading` 显示加载动画。
- `prop` 直接映射字段；需要格式化用 `#default="scope"` 插槽，`scope.row` 是当前行。
- `type="selection"` 多选；`type="index"` 序号。
- 操作列用作用域插槽 + `v-hasPermi` 控制按钮显隐。

## 数据契约

后端列表接口返回 `{ data: { rows: [...], total: N } }`。前端取 `res.data.rows`，分页总数取 `res.data.total`（见下篇分页）。

## 小结

表格 = `el-table` + `el-table-column`，数据走 `:data`，自定义列用作用域插槽。操作列配合 `v-hasPermi`。
