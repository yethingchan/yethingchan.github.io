# 24 · 代码规范与目录约定

本项目沉淀的约定（照着写就不会乱）。

## 目录约定

```
src/
├── api/模块名.js          # 接口层，只写请求函数
├── views/模块/index.vue   # 页面，按模块分目录
├── store/modules/*.js     # 全局状态
├── utils/*.js             # 工具（request/auth/permission/route）
├── directive/*.js         # 自定义指令
└── router/index.js        # 路由
```

## 命名约定

| 对象 | 规范 | 示例 |
|------|------|------|
| 页面组件 | `PascalCase` + `index.vue` | `views/system/user/index.vue` |
| api 文件 | `模块名.js` | `user.js`、`notice.js` |
| 请求函数 | `listXxx/getXxx/addXxx/updateXxx/delXxx` | `listUser` |
| 变量 | `camelCase` | `tableData`、`queryParams` |
| 权限串 | `业务:模块:动作` | `system:user:add` |

## 页面范式（标准 CRUD 页）

每个列表页基本一致：

```vue
<template>
  <!-- 1. 查询表单 -->
  <!-- 2. 操作按钮（带 v-hasPermi） -->
  <!-- 3. el-table -->
  <!-- 4. el-pagination -->
  <!-- 5. el-dialog（新增/编辑表单） -->
</template>
<script setup>
  // 1. 引入 api
  // 2. ref/reactive 状态
  // 3. getList / handleQuery / resetQuery
  // 4. handleAdd / handleEdit / submit / handleDelete
  // 5. onMounted(getList)
</script>
```

## 请求数据取法

统一：`const res = await api()` → 数据在 `res.data`。

## import 顺序（建议）

```js
import { ref } from 'vue'                 // 1. 框架
import { useXxxStore } from '@/store/...' // 2. 状态
import { useRouter } from 'vue-router'    // 3. 路由
import { listXxx } from '@/api/...'       // 4. api
import { ElMessage } from 'element-plus'  // 5. 组件库
```

## `.gitignore` 注意

`node_modules/`、`dist/` 应忽略，不入库。

## 小结

记住：api 只管请求、views 按模块、命名 `camelCase`、权限串 `业务:模块:动作`、数据取 `res.data`。
