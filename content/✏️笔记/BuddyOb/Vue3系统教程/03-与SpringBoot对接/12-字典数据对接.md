# 12 · 字典数据对接

字典 = 把"状态码 → 中文含义"集中管理（如 `status: 0→正常, 1→停用`）。

## 数据库结构（约定）

- `sys_dict_type`：字典类型（`dict_type='sys_normal_disable'`, `dict_name='系统开关'`）
- `sys_dict_data`：字典数据（`dict_type`, `dict_value='0'`, `dict_label='正常'`, `dict_sort`）

## 后端接口

```
GET /system/dict/data/type/{dictType}  → 返回该类型的字典项列表
```

## 前端使用

### 方式一：下拉从字典取

```vue
<el-select v-model="form.status">
  <el-option
    v-for="dict in statusOptions"
    :key="dict.dictValue"
    :label="dict.dictLabel"
    :value="dict.dictValue"
  />
</el-select>
```

```js
import { getDicts } from '@/api/system/dict'
getDicts('sys_normal_disable').then(res => {
  statusOptions.value = res.data
})
```

### 方式二：表格里翻译

```vue
<el-table-column label="状态">
  <template #default="scope">
    {{ statusFormat(scope.row.status) }}
  </template>
</el-table-column>
```

```js
function statusFormat(val) {
  const item = statusOptions.value.find(d => d.dictValue === val)
  return item ? item.dictLabel : val
}
```

## 本项目约定

- 字典数据来自后端 `sys_dict_data`，前端按需调 `getDicts(dictType)` 拉取。
- 字典可缓存到 Pinia 或 localStorage，避免重复请求（本项目目前每次拉）。

## 小结

字典 = 后端 `sys_dict_*` 表 + `/dict/data/type/{type}` 接口；前端 `getDicts` 取列表，用于下拉项与表格翻译。
