# 11 · 文件上传下载对接

## 上传（前端）

Element Plus `el-upload`：

```vue
<el-upload
  class="upload-demo"
  action="/api/common/upload"
  :headers="{ Authorization: 'Bearer ' + getToken() }"
  :on-success="handleSuccess"
  :show-file-list="true"
>
  <el-button type="primary">点击上传</el-button>
</el-upload>
```

```js
function handleSuccess(res) {
  if (res.code === 200) {
    form.fileUrl = res.data.url   // 后端返回可访问的文件地址
  } else {
    ElMessage.error(res.msg)
  }
}
```

> ⚠️ `el-upload` 的 `action` 是**完整前缀路径**，本项目要写 `/api/common/upload`（带 `/api`），否则开发态代理不生效。它不走 `request.js`，所以要手动加 `Authorization` 头（从 `getToken()` 取）。

## 上传（后端）

```java
@PostMapping("/common/upload")
public AjaxResult upload(MultipartFile file) {
    String url = fileService.upload(file);   // 存磁盘/云，返回访问 URL
    return AjaxResult.success(Map.of("url", url, "fileName", file.getOriginalFilename()));
}
```

- `MultipartFile` 接收；Spring Boot 默认最大 1MB，需在 `application.yml` 调大：
  ```yaml
  spring:
    servlet:
      multipart:
        max-file-size: 10MB
        max-request-size: 10MB
  ```

## 下载

```js
// 直接 window 打开（后端返回文件流，Content-Disposition 触发下载）
window.open(`/api/common/download?fileName=${encodeURIComponent(name)}`)
```

后端用 `HttpServletResponse` 写流，设 `Content-Disposition: attachment`。

## 注意

- 上传接口一般**不校验细粒度权限**（或仅登录），但必须过 JWT。
- 生产环境文件建议存对象存储（OSS/COS）或 Nginx 静态目录，别塞进 jar。

## 小结

上传 = `el-upload` 的 `action="/api/..."` + 手动带 token，后端 `MultipartFile` 接收；下载 = 直接 `window.open` 后端文件流。
