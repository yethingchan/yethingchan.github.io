# 07 · 动态路由从后端获取

菜单不是写死在前端，而是**后端 `sys_menu` 表下发**，前端转成路由挂载。改数据库即可加菜单，不用改前端代码。

## 数据流

```
sys_menu 表（parent_id 树）
  → 后端 /getRouters 拼成菜单树
  → 前端 userStore.getRouters() 拿到树
  → generateRoutes() 转成 vue-router 记录
  → router.addRoute() 挂载
  → 侧边栏读 userStore.menus 渲染
```

## 后端菜单节点结构（约定）

```json
{
  "path": "system",
  "component": "Layout",
  "name": "System",
  "meta": { "title": "系统管理", "icon": "Setting" },
  "children": [
    {
      "path": "user",
      "component": "system/user/index",
      "name": "User",
      "meta": { "title": "用户管理", "icon": "User" }
    }
  ]
}
```

## 前端转换（src/utils/route.js）

```js
const modules = import.meta.glob('../views/**/*.vue')
function loadView(component) {
  const key = `../views/${component}.vue`
  return modules[key] || (() => import('@/views/error/404.vue'))
}
function toRoute(vo, isRoot) {
  const route = { path: isRoot ? '/' + vo.path : vo.path, name: vo.name, meta: vo.meta || {} }
  if (vo.component === 'Layout') route.component = Layout        // 目录用布局壳
  else if (vo.component) route.component = loadView(vo.component) // 菜单用对应视图
  if (vo.children?.length) route.children = vo.children.map(c => toRoute(c, false))
  return route
}
```

## ⚠️ 约定要点（后端必须遵守）

1. **目录节点** `component: 'Layout'`（大写 L），前端用它套布局壳。
2. **菜单节点** `component: 'system/user/index'`（对应 `views/system/user/index.vue`，**不带 `.vue`**）。
3. `meta.title` / `meta.icon` 必须有，否则菜单显示异常。
4. 后端 `component` 字符串必须与前端 `views/` 下真实路径一致，否则懒加载失败跳 404。

## 小结

动态路由 = 后端菜单树 → `generateRoutes` 转路由 → `addRoute` 挂载。后端 `component` 字段是约定核心。
