# 05 · 登录接口对接流程

## 接口契约

**POST** `/api/login`

请求体：
```json
{ "username": "admin", "password": "123456" }
```

响应：
```json
{ "code": 200, "msg": "success", "data": { "token": "eyJhbGciOi..." } }
```

## 前端调用链

```
login/index.vue
  → userStore.login(form)
      → api/login.js: loginApi(form)
          → request({ url:'/login', method:'post', data:form })
              → 响应拦截：code===200，返回 res
      → setToken(res.data.token)   // 写 localStorage
      → this.token = res.data.token
  → router.push('/')               // 跳首页
      → 路由守卫 beforeEach
          → userStore.getInfo()    // 拉 {user, roles, permissions}
          → userStore.getRouters() // 拉菜单树
          → generateRoutes + addRoute
          → next({...to, replace:true})
```

## 后端需要返回什么

| 接口 | 返回 | 前端用途 |
|------|------|----------|
| `/login` | `{ data: { token } }` | 存 token |
| `/getInfo` | `{ data: { user, roles, permissions } }` | 用户信息、角色、按钮权限 |
| `/getRouters` | `{ data: [菜单树] }` | 动态路由/侧边栏 |

> 三者缺一不可，否则登录后白屏或菜单/权限失效。

## 默认账号

后端 `data.sql` 注入角色/菜单，密码由 `DataInitRunner` 用 BCrypt 运行时种入：
- `admin / 123456`（管理员）
- `operator / 123456`（操作员）

## 小结

登录 = 调 `/login` 拿 token → 跳首页 → 守卫拉 `getInfo`+`getRouters` → 挂动态路由。后端三类接口返回字段必须对齐。
