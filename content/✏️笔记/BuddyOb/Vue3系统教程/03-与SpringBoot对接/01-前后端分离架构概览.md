# 01 · 前后端分离架构概览

## 什么是前后端分离

- **前端**：Vue 应用，跑在浏览器，负责界面、交互、路由（SPA）。
- **后端**：Spring Boot，只提供 **JSON 数据接口**，不渲染页面。
- 两者通过 **HTTP + JSON** 通信，独立开发、独立部署。

## 本项目的部署拓扑

```
浏览器 (Vue SPA)
   │  HTTP 请求 /api/xxx
   ▼
[Nginx]  ← 生产环境：托管 dist + 反代 /api
   │
   ▼
Spring Boot 后端 ( :8080 )
   │
   ▼
MySQL ( :3306 )
```

- 开发态：Nginx 不存在，Vite 代理把 `/api` 转给 8080。
- 生产态：Nginx 托管静态 `dist/` 并把 `/api` 反代到 8080。

## 前后端各自职责

| 职责 | 前端 | 后端 |
|------|------|------|
| 页面/路由 | ✅ | ❌ |
| 表单校验（基础） | ✅ | ✅（最终校验） |
| 业务规则 | ❌ | ✅ |
| 数据持久化 | ❌ | ✅ |
| 权限（菜单/按钮可见性） | ✅（UI 层） | ✅（接口层，最终防线） |
| 鉴权（token） | 存 token、带请求 | 签发/校验 token |

## 关键认识

> **权限有两道防线**：前端 `v-hasPermi` 只是"看不见"，真正的安全靠后端 `@PreAuthorize`。前端被绕过（如直接调接口）时，后端照样拦截。

## 小结

前后端分离 = 浏览器 Vue + Nginx + Spring Boot + MySQL。前端管界面，后端管数据与规则，JSON 通信。
