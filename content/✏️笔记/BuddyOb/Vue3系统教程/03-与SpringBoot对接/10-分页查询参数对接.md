# 10 · 分页查询参数对接

## 前端入参

`el-pagination` 绑定：

```js
const queryParams = ref({ pageNum: 1, pageSize: 10, userName: '' })
```

发 GET 请求：`/system/user/list?pageNum=1&pageSize=10&userName=`

## 后端接收

```java
@GetMapping("/list")
public TableDataInfo list(UserQuery query) {
    // query 含 pageNum, pageSize, 以及 userName 等筛选字段
    startPage(query);                 // 设置分页
    List<SysUser> list = userService.selectList(query);
    return getDataTable(list);        // 包成 { rows, total }
}
```

`UserQuery` 继承分页基类（含 `pageNum`/`pageSize`）。MyBatis-Plus 分页拦截器据此加 `LIMIT`。

## 后端返回

```json
{
  "code": 200,
  "msg": "success",
  "data": { "rows": [ ...10条... ], "total": 57 }
}
```

## 前端消费

```js
function getList() {
  listUser(queryParams.value).then(res => {
    tableData.value = res.data.rows
    total.value = res.data.total
  })
}
```

## 翻页联动

```vue
<el-pagination
  v-model:current-page="queryParams.pageNum"
  v-model:page-size="queryParams.pageSize"
  :total="total"
  @current-change="getList"
  @size-change="getList"
/>
```

## 数组参数

批量删除 `ids=[1,2,3]`，`request.js` 的 `paramsSerializer` 序列化为 `ids=1&ids=2&ids=3`，后端：

```java
@DeleteMapping("/{ids}")
public AjaxResult remove(@PathVariable List<Long> ids) { ... }
// 或 @RequestParam List<Long> ids
```

## 小结

分页 = 前端 `pageNum/pageSize` 入参，后端 `startPage` + `getDataTable` 返回 `rows/total`，前端取 `res.data.rows/total`。
