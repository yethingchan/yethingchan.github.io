# 03 · 与 Spring Boot 对接

本分册讲**前后端之间的契约**：接口格式、鉴权、动态菜单、权限、跨域、分页、文件、字典。这部分决定系统能不能跑起来。

> 后端事实（已核对）：Spring Boot 3 + MyBatis-Plus + **纯 MySQL**（已移除 H2/Redis）；默认 profile 即 MySQL；统一返回 `AjaxResult{code,msg,data}`；JWT 放在 `Authorization: Bearer`；菜单/权限走 `sys_menu` 表动态下发。

## 对接的总原则

| 维度 | 约定 |
|------|------|
| 数据格式 | JSON（`Content-Type: application/json`） |
| 统一返回 | `{ code, msg, data }`，`code===200` 成功 |
| 鉴权 | `Authorization: Bearer <jwt>` |
| 前端前缀 | 所有请求 `/api`，开发态 Vite 代理、生产态 Nginx 反代 |
| 权限串 | `业务:模块:动作`，前端/后端/数据库三处一致 |
| 分页 | `pageNum`/`pageSize` 入参，`rows`/`total` 出参 |
