# 08 · 生命周期钩子

组件从"创建"到"销毁"会经历一系列阶段，Vue 提供钩子函数让你在关键时刻插代码。

## 生命周期流程

```
创建阶段： setup → beforeCreate → created
挂载阶段： beforeMount → mounted
更新阶段： beforeUpdate → updated
卸载阶段： beforeUnmount → unmounted
```

> 组合式 API 里 `beforeCreate`/`created` 已被 `setup`（即 `<script setup>` 本身）取代，直接用 `setup` 里的同步代码即可。

## 常用钩子（组合式写法）

```vue
<script setup>
import { onMounted, onUpdated, onUnmounted } from 'vue'

onMounted(() => {
  console.log('DOM 已挂载，可操作 ref、发初始请求')
})
onUpdated(() => {
  console.log('数据变化导致重新渲染后')
})
onUnmounted(() => {
  console.log('组件销毁，清理定时器/事件监听')
})
</script>
```

## 各钩子典型用途

| 钩子 | 适合做什么 |
|------|-----------|
| `onMounted` | 发首屏请求、初始化图表、绑定全局事件 |
| `onUpdated` | 依赖 DOM 更新后的操作（少用） |
| `onUnmounted` | 清除 `setInterval`、移除 `window` 监听、断开 WebSocket |
| `onBeforeUnmount` | 卸载前保存草稿 |

## 本项目中的例子

登录后进入首页，在 `onMounted` 拉取用户信息（实际由路由守卫 `beforeEach` 触发 `userStore.getInfo()`，属于更上层的"应用启动"逻辑）。普通页面在 `onMounted` 里加载表格数据：

```vue
<script setup>
import { ref, onMounted } from 'vue'
import { listNotice } from '@/api/business/notice'
const list = ref([])
onMounted(() => { loadData() })
function loadData() {
  listNotice(queryParams).then(res => { list.value = res.data.rows })
}
</script>
```

## 小结

- 最常用的就是 `onMounted`（初始化）和 `onUnmounted`（清理）。
- 组合式 API 用 `onXxx` 函数注册钩子。
- 发请求、初始化一般放 `onMounted`。
