# 13 · 组件基础

组件是 Vue 的"积木"。一个 `.vue` 文件就是一个组件，可复用、可组合。

## 注册与使用

### 局部注册（本项目主流）

```vue
<!-- Parent.vue -->
<script setup>
import Child from '@/components/Child.vue'
</script>
<template>
  <Child />
</template>
```

`<script setup>` 中导入的组件可直接在模板使用，无需 `components` 选项。

### 全局注册（本项目在 main.js）

```js
// main.js
import ElementPlus from 'element-plus'
app.use(ElementPlus)               // 全部 Element Plus 组件全局可用
// 全局注册所有图标
for (const [key, c] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, c)
}
```

## 组件命名

- 文件名用 `PascalCase`（如 `UserTable.vue`）。
- 模板里可用 `<UserTable />` 或 `<user-table />`。

## Props 与 Emit（父子通信两大通道）

```vue
<!-- Child.vue -->
<script setup>
const props = defineProps({ title: String, count: { type: Number, required: true } })
const emit = defineEmits(['change'])
function onClick() { emit('change', props.count + 1) }
</script>
```

```vue
<!-- Parent.vue -->
<Child :title="t" :count="n" @change="n = $event" />
```

> 详细见 [14-Props](./14-Props父子组件通信.md) 与 [15-自定义事件 emit](./15-自定义事件emit.md)。

## 单文件组件的好处

- 模板、逻辑、样式**聚合在一个文件**，易维护。
- `<style scoped>` 样式隔离。
- 可独立复用（如本项目 `sidebarItem.vue` 在菜单里递归调用自己）。

## 本项目中的组件层级

```
App.vue
 └─ router-view
     └─ Layout (views/layout/index.vue)
         ├─ Sidebar (sidebarItem.vue 递归)
         ├─ 顶栏（用户信息、退出）
         └─ router-view → 业务页面（如 system/user/index.vue）
```

## 小结

- 组件 = 可复用的 `.vue` 文件。
- `<script setup>` 导入即局部注册。
- 父子通信：\(父→子\) 用 `props`，\(子→父\) 用 `emit`。
