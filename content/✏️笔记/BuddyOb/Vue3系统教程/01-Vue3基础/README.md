# 01 · Vue 3 基础

本分册只讲 **Vue 3 框架本身**，不依赖任何具体业务。读完你会对"Vue 是怎么工作的"建立起完整心智模型，为后面理解本项目的工程代码打基础。

> 本项目的 Vue 版本是 **3.5**，使用的是**组合式 API（Composition API）**风格，但本分册会同时介绍选项式 API 以便对照。

## 学习建议

- 1~8 篇是**核心原理**，务必吃透响应式与组合式 API。
- 9~12 篇是**模板常用指令**，写页面天天用。
- 13~20 篇是**组件化进阶**，做后台管理系统必会。

读完本分册后，进入 [02-Vue3前端开发](./../02-Vue3前端开发/README.md) 看本项目如何把这些能力组织成一个真实工程。
