# 18 · 动态组件与异步组件

## 动态组件 `<component :is>`

同一个位置切换不同组件：

```vue
<script setup>
import Home from './Home.vue'
import About from './About.vue'
import { ref, shallowRef } from 'vue'
const current = shallowRef(Home)
</script>
<template>
  <button @click="current = About">切到关于</button>
  <component :is="current" />
</template>
```

- `:is` 可以是组件对象，或全局注册的组件名字符串。
- 用 `shallowRef` 存组件对象（避免深层响应式开销）。

## 异步组件 `defineAsyncComponent`

代码分割、按需加载（提升首屏速度）：

```js
import { defineAsyncComponent } from 'vue'
const UserTable = defineAsyncComponent(() => import('@/views/system/user/index.vue'))
```

> 本项目动态路由（`generateRoutes`）正是用 `import.meta.glob` 懒加载所有 `views/**/*.vue`，等价于异步组件——让每个菜单页按需加载，不进首包。

## 配合 `<KeepAlive>` 缓存

```vue
<KeepAlive>
  <component :is="current" />
</KeepAlive>
```

缓存被切走的组件状态（表单不丢）。

## 本项目中的例子

动态路由：`generateRoutes` 把后端返回的 `component: 'system/user/index'` 转成懒加载：

```js
const modules = import.meta.glob('../views/**/*.vue')
function loadView(component) {
  const key = `../views/${component}.vue`
  return modules[key] || (() => import('@/views/error/404.vue'))
}
```

## 小结

- `<component :is>` 动态切换组件。
- `defineAsyncComponent` / `import()` 做代码分割，按需加载。
- 本项目动态路由 = 后端下发菜单 → 前端懒加载对应 `.vue`。
