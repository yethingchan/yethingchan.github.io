# 01 · 什么是 Vue 3

## 一句话定义

**Vue 是一个用于构建用户界面的渐进式 JavaScript 框架。** "渐进式"意味着你可以只用它做一小块交互，也可以用它搭建整个单页应用（SPA）。

## 为什么选 Vue 3（对比 Vue 2）

| 维度 | Vue 2 | Vue 3 |
|------|-------|-------|
| 响应式原理 | `Object.defineProperty` | `Proxy`（能监听新增属性/数组索引） |
| 代码组织 | 选项式 API 为主 | 组合式 API（`<script setup>`） |
| 性能 | 基准 | 更快、包更小（Tree-shaking） |
| TypeScript | 支持一般 | 一等公民 |
| 碎片 | 模板需单一根节点 | 支持多根节点（Fragment） |

> 本项目使用 **Vue 3.5**，并采用组合式 API。

## 三个核心概念

1. **声明式渲染**：你描述"界面应该长什么样"（基于数据），Vue 负责把它变成 DOM 并随数据更新。
   ```vue
   <template><p>{{ message }}</p></template>
   <script setup>const message = 'Hello Vue3'</script>
   ```
2. **响应式（Reactivity）**：数据变化时，用到它的视图自动更新，无需手动操作 DOM。
3. **组件化（Components）**：把界面拆成独立、可复用的 `.vue` 文件，像搭积木一样组合。

## Vue 在"前后端分离后台"中的角色

```
浏览器
 └─ Vue 前端（SPA）  ←─ 你写的 .vue 页面、Element Plus 组件
       │  HTTP(S) /api
       ▼
   Spring Boot 后端  ←─ 只返回 JSON 数据（不渲染页面）
       │
       ▼
   MySQL 数据库
```

Vue 负责**所有界面与交互**，后端只提供**数据接口**。这就是"前后端分离"。

## 小结

- Vue = 渐进式前端框架，本教程配套版本是 Vue 3。
- 三件套：**声明式渲染 + 响应式 + 组件化**。
- 在后台系统里，Vue 是"界面层"，后端是"数据层"。
