# 11 · 事件处理

交互靠事件。Vue 用 `v-on`（简写 `@`）监听 DOM 事件。

## 基本用法

```vue
<button @click="sayHello">点我</button>
<button @click="count++">+1</button>
```

```js
function sayHello() { alert('Hello') }
```

## 传递参数

```vue
<button @click="greet('张三')">问候</button>
```

```js
function greet(name) { console.log('你好', name) }
```

## 访问原生事件对象

```vue
<!-- 不传参时，默认第一个参数就是 event -->
<button @click="onClick">按钮</button>

<!-- 既要参数又要 event，用 $event -->
<button @click="onClick('hi', $event)">按钮</button>
```

```js
function onClick(msg, e) { console.log(msg, e.target) }
```

## 事件修饰符

常用修饰符，省去手写 `event.preventDefault()` 等：

| 修饰符 | 作用 |
|--------|------|
| `.stop` | 阻止冒泡 `e.stopPropagation()` |
| `.prevent` | 阻止默认行为 `e.preventDefault()` |
| `.once` | 只触发一次 |
| `.enter` / `.space` | 按键修饰（表单回车提交） |
| `.self` | 只有点自身才触发 |

```vue
<form @submit.prevent="onSubmit">       <!-- 阻止表单默认刷新 -->
<a @click.stop="doSomething">链接</a>   <!-- 阻止冒泡 -->
<input @keyup.enter="search" />         <!-- 回车触发搜索 -->
```

## 本项目中的例子

登录表单回车提交：

```vue
<el-form @submit.prevent="handleLogin">
  <el-input v-model="loginForm.password" @keyup.enter="handleLogin" />
</el-form>
```

表格操作按钮：

```vue
<el-button @click="handleEdit(row)" v-hasPermi="'system:user:edit'">编辑</el-button>
<el-button @click="handleDelete(row)" v-hasPermi="'system:user:del'">删除</el-button>
```

## 小结

- `@事件="处理函数"`，可带参、可用 `$event`。
- 修饰符 `.stop/.prevent/.enter/.once` 很常用。
- 后台里按钮点击、表单提交、回车搜索全靠它。
