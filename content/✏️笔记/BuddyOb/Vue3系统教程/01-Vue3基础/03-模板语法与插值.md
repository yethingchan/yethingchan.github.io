# 03 · 模板语法与插值

模板（template）是 Vue 的"HTML + 少量指令"层。本篇讲最常用的语法。

## 1. 文本插值 `{{ }}`

```vue
<p>{{ message }}</p>
<p>{{ count + 1 }}</p>
<p>{{ ok ? '是' : '否' }}</p>
```

`{{ }}` 里可以放**变量、表达式**，但不能放语句（`if / for` 不行）。

## 2. 原始 HTML：`v-html`

```vue
<p v-html="rawHtml"></p>
```

> 注意：动态插入 HTML 有 XSS 风险，只用于可信内容。

## 3. 属性绑定：`v-bind`（简写 `:`）

```vue
<img :src="imageUrl" />
<button :disabled="isDisabled">按钮</button>
<div :class="{ active: isActive }"></div>
```

## 4. 事件绑定：`v-on`（简写 `@`）

```vue
<button @click="onClick">点击</button>
<button @click="count++">+1</button>
```

## 5. 双向绑定：`v-model`

```vue
<input v-model="name" />
```

（详见 [12-表单输入绑定](./12-表单输入绑定v-model.md)）

## 6. 指令（Directives）

带 `v-` 前缀的特殊属性，负责响应式行为：

| 指令 | 作用 |
|------|------|
| `v-if` / `v-else` | 条件渲染（销毁/重建 DOM） |
| `v-show` | 条件显示（切 `display`） |
| `v-for` | 列表渲染 |
| `v-bind` (`:`) | 属性绑定 |
| `v-on` (`@`) | 事件绑定 |
| `v-model` | 双向绑定 |
| `v-slot` (`#`) | 插槽 |

## 7. 动态参数

```vue
<a :[attrName]="url">链接</a>
<button @[eventName]="handler">按钮</button>
```

## 本项目中的例子

菜单渲染（`sidebarItem.vue`）就用到了 `:class`、`:is`、`@click`：

```vue
<el-menu-item :index="resolvePath(item.path)" @click="handleClick">
  <component :is="item.meta.icon" />
  <span>{{ item.meta.title }}</span>
</el-menu-item>
```

## 小结

- `{{ }}` 插文本；`:` 绑属性；`@` 绑事件；`v-model` 双向绑。
- 指令是 Vue 模板的灵魂。
