# 01 · 后端总览与分层架构

> 对应清单：入门第 1～4 条。本文讲"后端长什么样、一次调用如何层层穿透"。

## 一、后端的分层（记住这条调用链）

RuoYi 后端严格的分层是**经典四层 + 两块横切**：

```
Controller（接口层，com.ruoyi.web.controller）
      ↓ 调
Service 接口（ISysUserService）+ Impl 实现（业务层，com.ruoyi.system.service）
      ↓ 调
Mapper 接口（数据访问层，com.ruoyi.system.mapper）
      ↓ 映射
Mapper.xml（SQL，resources/mapper/**）
      ↓
MySQL
```

横切的两块（不归某一层，而是"织入"各层）：
- **安全 / 过滤**：`JwtAuthenticationTokenFilter`、`SecurityConfig`
- **AOP**：`DataScopeAspect`（数据权限）、`LogAspect`（操作日志）、`RateLimiterAspect`（限流）

## 三、用"查询用户列表"串一遍分层

```java
// ① Controller 层 —— 只做"收参数、调服务、包返回"
@PreAuthorize("@ss.hasPermi('system:user:list')")
@GetMapping("/list")
public TableDataInfo list(SysUser user) {
    startPage();                          // 从 request 取 pageNum/pageSize 塞进 PageHelper
    List<SysUser> list = userService.selectUserList(user);
    return getDataTable(list);            // 把 list 包成 {total, rows}
}

// ② Service 接口
public interface ISysUserService {
    List<SysUser> selectUserList(SysUser user);
}

// ③ Service 实现 —— 真正的业务在这里
@Service
public class SysUserServiceImpl implements ISysUserService {
    public List<SysUser> selectUserList(SysUser user) {
        return userMapper.selectUserList(user);   // 委托给 Mapper
    }
}

// ④ Mapper 接口（MyBatis 代理，无需写实现）
public interface SysUserMapper {
    List<SysUser> selectUserList(SysUser user);
}

// ⑤ Mapper.xml 里的 SQL
<select id="selectUserList" resultType="SysUser">
  select u.* from sys_user u
  left join sys_dept d on u.dept_id = d.dept_id
  <where>
    <if test="userName != null and userName != ''">
      and u.user_name like concat('%', #{userName}, '%')
    </if>
    ${params.dataScope}   <!-- 数据权限 SQL 片段，由 AOP 注入 -->
  </where>
</select>
```

**逐行解释：**
- `startPage()` / `getDataTable()` 来自 `BaseController`（见 [[08-后端-控制层与统一异常]]），配合 **PageHelper** 做物理分页。
- `@PreAuthorize("@ss.hasPermi('system:user:list')")` 是**方法级权限**：字符串 `system:user:list` 与前端 `v-hasPermi` 用的是**同一套编码**，后端 `@ss` 指向 `PermissionService.hasPermi()`（见 [[05-后端-安全与鉴权]]）。
- `${params.dataScope}` 是**数据权限**的注入点：AOP 在方法执行前算好 `AND (dept_id IN (...))` 拼进来（见 [[06-后端-AOP与拦截器]]）。
- `#{userName}` 用预编译参数，**天然防 SQL 注入**；`${...}` 是直接拼接，只用于可信片段（如数据权限，且已做过清空防注入）。

## 四、控制反转：谁创建谁？

- `@SpringBootApplication` 启动后，`@ComponentScan` 扫描所有带 `@Component`/`@Service`/`@Controller`/`@Configuration` 的类并实例化进 IoC 容器。
- `Controller` 里 `@Autowired private ISysUserService userService;` 是**依赖注入**——Spring 把容器里的 `SysUserServiceImpl` 实例自动塞进来。
- `userMapper` 没有实现类，是 **MyBatis 运行时生成代理**，`sqlSessionFactory` 把接口和 XML 绑定（见 [[03-后端-配置层]]）。
