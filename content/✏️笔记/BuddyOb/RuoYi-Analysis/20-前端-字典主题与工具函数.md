## 一、字典机制（高级第 23 条，前后端合看）

**后端**：`sys_dict_type`（类型，如 `sys_normal_disable`）+ `sys_dict_data`（数据，如 `0=正常,1=停用`）。
- `SysDictTypeServiceImpl` / `SysDictDataServiceImpl` 提供查接口；
- `DictUtils` 把字典缓存进 Redis，避免每次查库。

**前端**：`DictData` 插件（`src/plugins/dict.js` + `src/components/DictData`）。
```js
// ① 页面 created 里拉字典（挂到 this.dict.type 下）
created() { this.getDicts('sys_normal_disable').then(() => {}) }
// ② 下拉直接用
<el-option v-for="dict in dict.type.sys_normal_disable" :key="dict.value"
  :label="dict.label" :value="dict.value"/>
// ③ 表格里用 <dict-tag> 把值翻成带色标签
<dict-tag :options="dict.type.sys_normal_disable" :value="scope.row.status"/>
```
- `getDicts('xxx')`（挂在 `Vue.prototype`，见 [[13-前端-入口与全局挂载]]）会：先查 `store/dict` 缓存 → 没有就调 `api/system/dict/data` → 存入 `dict.type.xxx` 并缓存。
- **一次拉取，全应用共享**，切到别的页不重复请求。

> 为什么不用硬编码下拉？**字典可后台改**（如加个"冻结"状态），改完前端不发包就生效。这是"配置驱动 UI"的典范。

## 二、主题与布局设置（进阶第 18 条）

- `settings.js`（见 [[12-前端总览与工程结构]]）是布局配置的"默认值"：`sideTheme:'theme-dark'`、`tagsView:true`、`navType:1` 等。
- 这些值在 `main.js` 被 `Vue.use(plugins)` 时塞进 `store/settings`。
- `Layout` 的 `Settings` 抽屉（齿轮触发，见 [[18-前端-布局Layout]]）改的就是 `store/settings` → 整个外壳实时变。
- **主题色**是 CSS 变量（`--current-color` 等，`layout/index.vue` 的 `:style` 注入）。`ThemePicker` 改这个变量，所有引用它的组件瞬间换色。
- 顶栏还有"尺寸"切换（`size` 存 cookie，`Element` 启动时读，见 [[13-前端-入口与全局挂载]]）。

## 三、全局 $ 方法（入门第 9 条，回顾）

`main.js` 挂在 `Vue.prototype` 上的这些，任意组件 `this.xxx` 即用（见 [[13-前端-入口与全局挂载]] / [[16-前端-请求封装与权限工具]]）：
- `this.parseTime(date)` —— 日期格式化（表格时间列）
- `this.addDateRange(params, range, 'createTime')` —— 时间范围拼到查询参数
- `this.selectDictLabel(dicts, val)` —— 值翻 label
- `this.handleTree(list, 'deptId', 'parentId', 'children')` —— 扁平数组转树
- `this.download(url, params, name)` —— 调 `request.download` 导出文件
- `this.getDicts('xxx')` / `this.getConfigKey('xxx')` —— 拉字典 / 系统参数

> 这些是 RuoYi 的"标准库"。**自己写新页面时，先想"这几个有没有现成"**，别重复造轮子。

## 四、★ 全局串联图（把 21 章收成一张网）

```
┌─ 后端 ────────────────────────────────────────────────────────┐
│ pom/启动(RuoYiApplication:扫 cn.yething+com.ruoyi)  [[02]]      │
│   ↓                                                            │
│ SecurityConfig(无态/CSRF关/CORS)  [[03]][[05]]                 │
│   ↓ 每次请求                                                   │
│ JwtAuthenticationTokenFilter → Redis 取 LoginUser → SecurityContext │
│   ↓                                                            │
│ @PreAuthorize("@ss.hasPermi('x:y:z')") → PermissionService    │
│   ↓ 业务前                                                    │
│ DataScopeAspect → 拼 SQL 注入 BaseEntity.params.dataScope   [[06]]│
│   ↓                                                            │
│ Controller → Service → Mapper(XML ${params.dataScope}) → MySQL │
│   ↓ 返回                                                       │
│ AjaxResult/R<T> / TableDataInfo  [[04]][[08]]                    │
│   （@Log 切面异步写 sys_oper_log [[06]]）                       │
│ 菜单：SysMenuServiceImpl.buildMenus → RouterVo(component字符串)[[07]]│
└───────────────────────────┬──────────────────────────────────┘
                             │  ① HTTP（/dev-api 经 vue.config.js 代理）
┌───────────────────────────▼──────────────────────────────────┐
│ 前端（Vue 2 + Element UI）[[12]]                              │
│ main.js 挂全局/组件/指令  [[13]]                                │
│   ↓                                                            │
│ 守卫 permission.js：白名单→GetInfo 拉权限→GenerateRoutes  [[14]]│
│   ↓ 把后端 RouterVo 的 component 字符串换成 import        │
│ router.addRoutes → Layout 渲染菜单  [[18]]                       │
│   ↓ 页面操作                                                   │
│ 视图调 api/*.js → request.js（加 token/防重提/401 处理）[[16]] │
│   ↓                                                            │
│ 按钮 v-hasPermi 按 permissions 显隐  [[17]]                     │
│ 表格/分页/树/字典 用通用组件  [[17]][[19]][[20]]                │
└───────────────────────────────────────────────────────────────┘
```
**一句话记忆**：后端"认人（JWT）→ 放权（@PreAuthorize）→ 裁数据（DataScope）→ 出菜单（buildMenus）"；前端"带票进门（request）→ 按票显菜单/按钮（permissions）→ 调接口拿数据（api）→ 拼页面（组件）"。

## 五、给你的学习路径建议（配合 00 的 `- [ ]` 清单）

1. **先跑起来**：`ruoyi-ui` 里 `npm install` + `npm run dev`，后端启 `RuoYiApplication`。看登录→首页的全过程（对照 [[14]] 守卫）。
2. **改一个小功能**：在 `sys_menu` 加个菜单 → 看前端自动出页（验证 [[14]] 动态路由）。
3. **读一个完整链路**：`/system/user/list` 从前端 `listUser` 一路追到后端 `SysUserController` → `SysUserServiceImpl` → `SysUserMapper.xml`（对照 [[01]] 分层 + [[19]] 视图）。
4. **碰一个权限坑**：把某个按钮的 `v-hasPermi` 字符串改错 → 看按钮消失但接口还能调（理解前后端权限要**双写一致**，[[05]] + [[17]]）。
5. **玩一次代码生成**：建张表 → 代码生成器导出 → 看生成的 `Xxx.vue` 就是 [[19]] 那种骨架（[[09]]）。
