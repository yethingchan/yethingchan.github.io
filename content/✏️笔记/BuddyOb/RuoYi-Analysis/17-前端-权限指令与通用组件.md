# 17 · 前端-权限指令与通用组件

> 对应清单：进阶第 16 条（v-hasPermi / v-hasRole）、进阶第 17 条（通用组件）。
> 业务页面 80% 由"指令 + 通用组件"拼成。本文精讲 `v-hasPermi` 指令，并速览高频组件。

## 一、v-hasPermi —— 按钮级权限（真实）

```js
import store from '@/store'
export default {
  inserted(el, binding, vnode) {
    const { value } = binding
    const all_permission = "*:*:*"            // ① 超级管理员通配
    const permissions = store.getters && store.getters.permissions
    if (value && value instanceof Array && value.length > 0) {
      const permissionFlag = value
      const hasPermissions = permissions.some(permission =>
        all_permission === permission || permissionFlag.includes(permission))
      if (!hasPermissions) {
        el.parentNode && el.parentNode.removeChild(el)   // ② 没权限就删掉 DOM
      }
    } else { throw new Error(`请设置操作权限标签值`) }
  }
}
```

**逐行解释（前端权限的最后一环）：**
1. **`all_permission = "*:*:*"`**：`permissions` 里含这个通配串的就是超管，所有按钮都显示。
2. **`store.getters.permissions`**：就是 [[15-前端-Vuex状态管理]] 里 `GetInfo` 存进来的那个数组（来自后端 `LoginUser.permissions`）。
3. **比对逻辑**：`permissionFlag.includes(permission)`——按钮写的 `['system:user:add']` 只要命中用户权限集合里任意一个就显示。
4. ② **没权限 → `removeChild(el)`**：直接从 DOM 移除按钮，**不是隐藏**（更安全，F12 也看不到）。
5. 用法：`<el-button v-hasPermi="['system:user:add']">新增</el-button>`。字符串 `system:user:add` 与后端 `@PreAuthorize("@ss.hasPermi('system:user:add')")` **同一套**——前后端必须一致，否则"按钮在但点了 403"或"按钮没了但接口能调"。

> 同目录还有 `v-hasRole`（按 `store.getters.roles` 显隐，用于按角色控制）、`dialog`/`module` 等指令，注册方式同（见 [[13-前端-入口与全局挂载]] 的 `import './directive'`）。

## 三、Pagination 怎么和后端分页对接

```html
<pagination v-show="total > 0"
  :total="total"
  :page.sync="queryParams.pageNum"
  :limit.sync="queryParams.pageSize"
  @pagination="getList" />
```
- `queryParams.pageNum/pageSize` 双向绑：组件翻页改它 → 触发 `@pagination="getList"`。
- `getList` 里 `listUser(queryParams)` → 后端 `startPage()` 用这两个值（`PageHelper.startPage`）→ `res.total`/`res.rows` 回填 `total`/`userList`。
- 形成闭环：**组件翻页 → 改 query → 调 api → 后端分页 → 回填**。无需手写分页逻辑。

> 学完本章，你掌握了"按钮显隐靠 `v-hasPermi`、表格分页靠 `<pagination/>`、树下拉靠 `<treeselect/>`、字典靠 `<dict-tag/>`"——业务页几乎全由这些拼出。下一章看这些组件被"布局 Layout"怎么摆出来。
