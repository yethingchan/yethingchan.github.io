**解释（和后端对齐看）：**
- **Vue 2.6 + vue-router 3 + vuex 3**：这是 Vue2 全家桶，语法是 `new Vue({...})`、`options API`。和咱们另一个教程里的 Vue3 `<script setup>` 写法**不是一回事**，别混。
- **element-ui 2.15**：组件库（`el-table`/`el-button`/`el-form`…）。注意是 `element-ui`（Vue2 版），不是 `element-plus`（Vue3 版）。
- **axios 0.30**：HTTP 客户端，所有请求经 `utils/request.js` 统一封装。
- **jsencrypt**：登录密码 **RSA 加密**再传（前端用公钥加密，后端私钥解密——防明文被嗅探）。
- **echarts**：监控页图表。**nprogress**：路由切换顶部进度条。**js-cookie**：存 token。

## 三、vue.config.js —— 构建与代理（进阶第 19 条）

```js
const baseUrl = 'http://localhost:8080'   // 后端地址
module.exports = {
  publicPath: process.env.NODE_ENV === "production" ? "/" : "/",
  outputDir: 'dist', assetsDir: 'static',
  devServer: {
    host: '0.0.0.0', port: process.env.port || 80, open: true,
    proxy: {
      [process.env.VUE_APP_BASE_API]: {        // ① '/dev-api' → 后端
        target: baseUrl, changeOrigin: true,
        pathRewrite: { ['^' + process.env.VUE_APP_BASE_API]: '' }
      },
      '^/v3/api-docs/(.*)': { target: baseUrl, changeOrigin: true } // swagger 代理
    }
  },
  configureWebpack: {
    plugins: [ new CompressionPlugin({            // ② 生产 gzip
      test: /\.(js|css|html|jpe?g|png|gif|svg)?$/i, algorithm: 'gzip' }) ]
  },
  chainWebpack(config) {
    // ③ svg-sprite：src/assets/icons 走 svg-sprite-loader
    config.module.rule('svg').exclude.add(resolve('src/assets/icons'))
    config.module.rule('icons').test(/\.svg$/).use('svg-sprite-loader')...
    config.when(process.env.NODE_ENV !== 'development', config => {
      config.optimization.splitChunks({           // ④ 分包
        cacheGroups: {
          libs:    { name: 'chunk-libs', test: /[\\/]node_modules[\\/]/, priority: 10 },
          elementUI:{ name: 'chunk-elementUI', test: /_?element-ui/, priority: 20 },
          commons: { name: 'chunk-commons', test: resolve('src/components'), minChunks: 3 }
        }})
    })
  }
}
```

**解释：**
- ① **dev 代理是前后端联调的关键**：前端跑在 `:80`（或你配的端口），请求 `/dev-api/system/user/list`，代理把它转到 `http://localhost:8080/system/user/list`。**所以开发时不跨域、不写死后端地址**。`pathRewrite` 把前缀 `/dev-api` 去掉，后端收到干净的路径。
- ② **gzip**：打包时把静态资源压成 `.gz`，Nginx 开启 `gzip_static` 后直接发，省流量。
- ③ **svg-sprite**：`src/assets/icons/*.svg` 被合成一张雪碧图，组件里 `<svg-icon icon-class="user"/>` 直接用，不打包成图片请求。
- ④ **分包**：`element-ui`/`node_modules`/公共组件各自成 chunk，**首屏只加载必要的**，其余懒加载。

## 四、.env.* —— 环境开关（真实）

```bash
# .env.development
VUE_APP_TITLE = 若依管理系统
ENV = 'development'
VUE_APP_BASE_API = '/dev-api'     # ← 和 vue.config.js 的 proxy key 对应
VUE_CLI_BABEL_TRANSPILE_MODULES = true
```
- `VUE_APP_BASE_API` 在前端**任何地方**都能 `process.env.VUE_APP_BASE_API` 取到，它是 axios 的 `baseURL`（见 [[16-前端-请求封装与权限工具]]）。
- 还有 `.env.production`（生产，通常 `VUE_APP_BASE_API = '/prod-api'`，由 Nginx 反代）、`.env.staging`。

## 五、前端视角的"一次请求"

```
1. 视图里 this.$getList() → 调 api/system/user.js 的 listUser(query)
2. listUser → request({ url:'/system/user/list', method:'get', params:query })
3. request.js 请求拦截器：加 Authorization: Bearer <token>
4. 经 vue.config.js 代理 → 后端 :8080
5. 响应拦截器：code=200 返回 res.data；401 弹重新登录；500 报错
6. 视图把 res.rows / res.total 喂给 el-table / Pagination
```
