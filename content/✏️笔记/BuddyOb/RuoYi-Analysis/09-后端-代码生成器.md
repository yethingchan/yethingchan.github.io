# 09 · 后端-代码生成器（ruoyi-generator）

> 对应清单：高级第 18 条。
> 模块 `com.ruoyi.generator`：读数据库元数据 → 用 Velocity 模板 → 吐出 Controller/Service/Mapper/domain/Vue 全套代码。
> 说明：本模块是标准 RuoYi 生成器，下列方法/模板为其通用实现，本仓库同名类逻辑一致。

## 一、它能生成什么

在 `系统工具 / 代码生成` 页面：
1. 导入库里任意表 → 自动读字段、类型、注释；
2. 在线配置（哪些字段做查询条件、哪些必填、前端用输入框还是下拉）；
3. 一键 **预览 / 下载 zip / 自定义（直接写进工程）**。

产出物：`XxxController.java` + `IXxxService`/`XxxServiceImpl` + `XxxMapper.java` + `XxxMapper.xml` + `Xxx.java`(domain) + `Xxx.vue`(前端列表) + `xxx.js`(api) + `sql`（菜单）。

## 二、核心领域对象（GenTable / GenTableColumn）

```java
// 一张"待生成表"的元信息（对应 sys_gen_table）
public class GenTable extends BaseEntity {
    private Long    tableId;
    private String   tableName;       // 物理表名
    private String   tableComment;    // 表注释 → 用作页面标题
    private String   className;        // 生成类名（去前缀、转驼峰）
    private String   tplCategory;      // 模板：crud / tree / 主子表
    private String   packageName;      // 生成到哪个包
    private String   moduleName;       // 前端模块名（system/tool...）
    private String   businessName;     // 业务名（user/dept...）
    private String   functionName;     // 功能名
    private List<GenTableColumn> columns;  // ① 字段集合
}
// 单个字段元信息（对应 sys_gen_table_column）
public class GenTableColumn {
    private String columnName;        // user_name
    private String columnComment;    // 用户名称
    private String javaType;          // String / Long / Date
    private String jdbcType;         // VARCHAR / BIGINT
    private String isPk;              // 是否主键
    private String isRequired;        // 是否必填
    private String isInsert;          // 是否进 insert
    private String isEdit;            // 是否进 edit
    private String isList;            // 是否列表展示
    private String isQuery;           // 是否作查询条件
    private String queryType;         // EQ / LIKE / BETWEEN
    private String htmlType;          // input / select / datetime / ...
}
```

**解释：** 这两张表把"你想怎么生成"全部持久化。改一次配置下次还能接着用。

## 三、GenTableServiceImpl —— 读库 + 渲染（核心）

```java
@Service
public class GenTableServiceImpl implements IGenTableService {
    // ① 从 information_schema 拉库里所有表
    public List<GenTable> selectDbTableList(GenTable genTable) {
        return genTableMapper.selectDbTableList(genTable);   // SQL: select * from information_schema.TABLES where TABLE_SCHEMA = 当前库
    }
    // ② 导入表时，读字段 + 初始化列
    public void importGenTable(List<GenTable> tableList) {
        for (GenTable table : tableList) {
            List<GenTableColumn> columns =
                genTableMapper.selectDbTableColumnsByName(table.getTableName()); // information_schema.COLUMNS
            GenUtils.initTable(table, "作者");    // 算 className/package/module...
            GenUtils.initColumnField(columns, table);  // 算 javaType/htmlType/是否必填...
            genTableMapper.insertGenTable(table);
            genTableColumnMapper.insertGenTableColumn(columns);
        }
    }
    // ③ 预览：把数据塞进 Velocity，渲染出每个文件的字符串
    public Map<String, String> previewCode(Long tableId) {
        GenTable table = genTableMapper.selectGenTableById(tableId);
        List<GenTableColumn> columns = table.getColumns();
        VelocityInitializer.init();                       // 初始化 Velocity 引擎
        VelocityContext context = VelocityUtils.prepareContext(table, columns); // ④ 组装模板变量
        Map<String, String> dataMap = new LinkedHashMap<>();
        for (String template : VelocityUtils.getTemplateList(table)) {  // *.vm 列表
            StringWriter sw = new StringWriter();
            Template tpl = Velocity.getTemplate(template);
            tpl.merge(context, sw);
            dataMap.put(template, sw.toString());        // 每个 .vm 渲染成一段代码字符串
        }
        return dataMap;
    }
}
```

**逐行解释：**
- ① `information_schema.TABLES` / `COLUMNS`：MySQL 自带的"元数据表"，**不需要你建**，RuoYi 直接查它拿到全库表结构。
- ② `GenUtils.initColumnField`：按字段名/类型**推断前端控件**——`name` 含 `Time` → datetime；含 `status/type` → select；含 `sex` → radio 等（这套启发式规则是生成器"聪明"的地方）。
- ③ `VelocityInitializer` + `VelocityUtils.prepareContext`：把 `GenTable`+`columns` 打包成模板上下文（变量如 `${table.className}`、`${columns}`）。
- ④ 遍历 `resources/templates/vm/` 下所有 `*.vm`（Java 的 controller.vm/service.vm/domain.vm/mapper.vm/mapper.xml.vm，以及 Vue 的 vue.vm/index-tree.vue.vm/api.js.vm/sql.vm），逐个 `merge` 渲染成代码字符串，预览页直接展示。

## 四、Velocity 模板长什么样（节选 domain.vm）

```
package ${packageName}.domain;

import com.ruoyi.common.core.domain.BaseEntity;
import org.apache.commons.lang3.builder.ToStringBuilder;
import org.apache.ibatis.type.Alias;

@Alias("${ClassName}")
public class ${ClassName} extends BaseEntity {
#foreach($column in $columns)
#if($column.javaField)
    /** $column.columnComment */
    private $column.javaType $column.javaField;
#end
#end
    // getter / setter 由模板循环生成 ...
}
```

**解释：** `${table.className}` 等是 Velocity 变量，渲染时替换成真实值。`#foreach` 遍历字段生成属性。这就是"一份模板 → 任意表代码"。

## 五、三种输出方式

| 方式 | 实现 | 用途 |
|---|---|---|
| 预览 | `previewCode` 返回 Map<文件名,代码串> | 页面高亮展示，先看看对不对 |
| 下载 | 把 Map 打成 zip 用 `FileUtils` 写出 | 你手动丢进工程 |
| 自定义（写盘） | `GenUtils.generatorCode` 直接 `Writer` 写文件到 `${moduleName}/...` | 一键落盘，刷新工程即用（最常用） |

> 生成器是"用框架写框架"。理解它后，你新开一张业务表，5 分钟就能拿到全套 CRUD 前后端代码，再在骨头上填肉。下一章看定时任务——另一种"无人值守"的能力。
