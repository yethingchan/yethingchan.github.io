# 13 · 前端-入口与全局挂载

> 对应清单：入门第 9 条（main.js 全局挂载）。
> `main.js` 是应用启动的总装配间：把 Element UI、全局方法、全局组件、指令、路由、store 全挂上。

## 一、main.js 全文精讲（真实）

```js
import Vue from 'vue'
import Cookies from 'js-cookie'
import Element from 'element-ui'
import './assets/styles/element-variables.scss'
import '@/assets/styles/index.scss'
import App from './App'
import store from './store'
import router from './router'
import directive from './directive'        // ① 全局指令（含 v-hasPermi）
import plugins from './plugins'
import { download } from '@/utils/request'

import './assets/icons'                 // ② SVG 雪碧图注册
import './permission'                   // ③ 路由守卫（注册到 router）
import { getDicts } from "@/api/system/dict/data"
import { getConfigKey } from "@/api/system/config"
import { parseTime, resetForm, addDateRange, selectDictLabel, handleTree } from "@/utils/ruoyi"

// ④ 把常用方法挂到 Vue.prototype，全组件 this.xxx 直接调
Vue.prototype.getDicts = getDicts
Vue.prototype.getConfigKey = getConfigKey
Vue.prototype.parseTime = parseTime
Vue.prototype.resetForm = resetForm
Vue.prototype.addDateRange = addDateRange
Vue.prototype.selectDictLabel = selectDictLabel
Vue.prototype.selectDictLabels = selectDictLabels
Vue.prototype.download = download
Vue.prototype.handleTree = handleTree

// ⑤ 把通用组件注册成全局组件
Vue.component('DictTag', DictTag)
Vue.component('Pagination', Pagination)
Vue.component('RightToolbar', RightToolbar)
Vue.component('Editor', Editor)
Vue.component('FileUpload', FileUpload)
Vue.component('ImageUpload', ImageUpload)
Vue.component('ImagePreview', ImagePreview)

Vue.use(directive)        // ⑥ 装指令
Vue.use(plugins)           // ⑦ 装插件（cache/auth/dict）
DictData.install()           // ⑧ 字典插件（全局可用 $dict）

Vue.use(Element, { size: Cookies.get('size') || 'medium' })  // ⑨ Element UI
Vue.config.productionTip = false
new Vue({ el: '#app', router, store, render: h => h(App) })  // ⑩ 启动！
```

**逐段解释（记住这几类"全局挂载"，后面到处受益）：**
1. **`import './directive'`**：把 `v-hasPermi` / `v-hasRole` 等指令注册进 Vue（见 [[17-前端-权限指令与通用组件]]）。
2. **`import './assets/icons'`**：把 `src/assets/icons` 下所有 svg 注册成图标组件，`<svg-icon icon-class="user"/>` 能直接用。
3. **`import './permission'`**：执行 `permission.js` 里 `router.beforeEach(...)`，把**路由守卫**绑到 router 上（见 [[14-前端-路由与权限守卫]]）。
4. **`Vue.prototype.xxx = ...`**：这是 RuoYi 的"全局工具"套路。挂上去后，任意 `.vue` 里 `this.parseTime(row.createTime)`、`this.download(url, params, name)` 即可，**不用每个组件都 import**。这是 Vue2 的典型做法（Vue3 改用 `app.config.globalProperties`）。
5. **`Vue.component('Pagination', ...)`**：`Pagination`/`DictTag`/`FileUpload` 等变成**全局组件**，模板里直接 `<pagination v-show=.../>`、`<dict-tag/>`，免 import。
6. ⑦ **`plugins`**（`src/plugins/index.js`）：聚合 `cache`（本地/会话存储封装，基于 `js-cookie`/`localStorage`）、`auth`（token 读写）、`dict`（字典缓存）等。
7. ⑧ **`DictData.install()`**：字典插件，提供 `this.getDicts('sys_normal_disable')` 拉字典并缓存，配合 `<dict-tag :options="..."/>` 和 `dict.type` 用（见 [[20-前端-字典主题与工具函数]]）。
8. ⑨ Element UI 全局装，**默认尺寸**从 cookie `size` 读（顶部"尺寸"切换就改这个 cookie）。

## 二、App.vue —— 极简根组件

```vue
<template>
  <div id="app">
    <router-view />          <!-- ① 路由出口：当前路由对应的页面渲染在这 -->
    <theme-picker />           <!-- ② 主题选择器（默认隐藏，布局设置里出现） -->
  </div>
</template>
<script>
import ThemePicker from "@/components/ThemePicker"
export default { name: "App", components: { ThemePicker } }
</script>
<style scoped>
#app .theme-picker { display: none; }   /* 默认藏起来 */
</style>
```

**解释：** 整个应用就是"一个 `<router-view/>` + 一只主题选择器"。所有页面都是 `router-view` 里切换显示的视图。`theme-picker` 默认 `display:none`，只在"布局设置"抽屉打开时才现身（见 [[18-前端-布局Layout]] / [[20-前端-字典主题与工具函数]]）。

## 三、plugins / directive / assets（知道干什么）

| 目录 | 职责 |
|---|---|
| `src/plugins/index.js` | 聚合 `cache`(存储)、`auth`(token)、`dict`(字典) 插件，`Vue.use(plugins)` 时一并装 |
| `src/plugins/cache.js` | `storage`(localStorage) / `session`(sessionStorage) 封装：`cache.session.getJSON('sessionObj')` |
| `src/plugins/auth.js` | 包装 `js-cookie`：`getToken/setToken/removeToken`（token 存 cookie） |
| `src/directive/index.js` | 注册 `v-hasPermi`/`v-hasRole`（permission）、`dialog`、`module` 等指令 |
| `src/assets/styles/*` | 全局样式：`index.scss`(基础)、`ruoyi.scss`(定制)、`variables.scss`(主题变量)、`element-variables.scss`(Element 主题) |
| `src/assets/icons/*` | 全部 svg 图标（被 svg-sprite 合成雪碧图） |

> 学完本章，你理解了"为什么组件里能直接 `this.parseTime`、能直接写 `<pagination/>`、能直接 `v-hasPermi`"——都是 `main.js` 在启动时挂的全局能力。下一章是前端最绕也最重要的一环：**路由与权限守卫**。
