# 16 · 前端-请求封装与权限工具

> 对应清单：进阶第 11 条（request.js 拦截器）、入门第 10 条（api/*.js）。
> 所有 HTTP 都走 `utils/request.js` 这一个 axios 实例。本文精讲它，并讲 `auth`/`ruoyi` 工具与 `api/*.js` 套路。

## 一、utils/request.js —— 全前端唯一出口（真实）

```js
import axios from 'axios'
import store from '@/store'
import { getToken } from '@/utils/auth'
import { isRelogin } from '@/utils/request'   // 本文件导出 isRelogin

axios.defaults.headers['Content-Type'] = 'application/json;charset=utf-8'
const service = axios.create({
  baseURL: process.env.VUE_APP_BASE_API,   // ① '/dev-api'（见 [[12-前端总览与工程结构]]）
  timeout: 10000
})

// ② 请求拦截器
service.interceptors.request.use(config => {
  const isToken = (config.headers || {}).isToken === false     // ③ 该请求是否免 token
  const isRepeatSubmit = (config.headers || {}).repeatSubmit === false
  if (getToken() && !isToken) {
    config.headers['Authorization'] = 'Bearer ' + getToken()   // ④ 加 token
  }
  if (config.method === 'get' && config.params) {           // ⑤ get 参数拼到 URL
    let url = config.url + '?' + tansParams(config.params)
    config.params = {}; config.url = url.slice(0,-1)
  }
  if (!isRepeatSubmit && (config.method==='post'||config.method==='put')) {
    const requestObj = { url: config.url, data: JSON.stringify(config.data), time: Date.now() }
    const sessionObj = cache.session.getJSON('sessionObj')
    if (!sessionObj) cache.session.setJSON('sessionObj', requestObj)
    else if (requestObj.data === sessionObj.data && Date.now()-sessionObj.time < 1000) {
      return Promise.reject(new Error('数据正在处理，请勿重复提交'))  // ⑥ 防重提
    } else cache.session.setJSON('sessionObj', requestObj)
  }
  return config
}, error => Promise.reject(error))

// ⑦ 响应拦截器
service.interceptors.response.use(res => {
  const code = res.data.code || 200
  const msg = errorCode[code] || res.data.msg || errorCode['default']
  if (res.request.responseType === 'blob' || res.request.responseType === 'arraybuffer')
    return res.data                         // ⑧ 文件流直接返
  if (code === 401) {                          // ⑨ token 过期
    if (!isRelogin.show) {
      isRelogin.show = true
      MessageBox.confirm('登录状态已过期...').then(() => {
        isRelogin.show = false
        store.dispatch('LogOut').then(() => location.href = '/index')
      })
    }
    return Promise.reject('无效的会话，或者会话已过期，请重新登录。')
  } else if (code === 500) { Message({ message: msg, type: 'error' }); return Promise.reject(new Error(msg)) }
  else if (code === 601) { Message({ message: msg, type: 'warning' }); return Promise.reject('error') }
  else if (code !== 200) { Notification.error({ title: msg }); return Promise.reject('error') }
  else return res.data                         // ⑩ 正常：返回 res.data
}, error => { /* 网络异常/超时 友好提示 */ })

// ⑪ 通用下载
export function download(url, params, filename, config) {
  return service.post(url, params, { responseType: 'blob', ...config })
    .then(data => { /* blob 用 file-saver 存盘，否则解析错误 JSON */ })
}
export default service
```

**逐行解释（这是前后端"契约"的执行处）：**
1. **`baseURL = '/dev-api'`**：所有请求都带这个前缀 → 被 `vue.config.js` 代理到后端 `:8080`（见 [[12-前端总览与工程结构]]）。
2. **请求拦截器**：每个请求发出前统一加工。
3. ③ **`isToken === false`**：个别请求（如登录、验证码）不需要带 token——在 api 里 `headers: { isToken: false }` 即可跳过 ④。
4. ④ **`Authorization: Bearer <token>`**：和后端 `SecurityConfig` 的 `token.header=Authorization` + `TokenService.getToken` 去 `Bearer ` 前缀**严丝合缝对应**。前端加、后端去、Redis 取 `LoginUser`。
5. ⑤ **get 参数拼 URL**：axios 的 `params` 会被自动序列化，RuoYi 这里手动拼成 `?a=1&b=2` 并清空 `params`，是它自己的风格（也方便日志）。
6. ⑥ **前端防重提**：同 URL+同 data+1 秒内再次发，直接 reject。这是**前端一层**；后端还有 `RepeatSubmitInterceptor`（见 [[06-后端-AOP与拦截器]]）兜底。
7. **响应拦截器**：统一处理后端 `AjaxResult` 的 `code`。
8. ⑧ **blob 直返**：导出文件时 `responseType:'blob'`，不走 code 判断，直接给二进制。
9. ⑨ **`code === 401`**：后端 `AuthenticationEntryPointImpl` 返回 401 → 这里弹"登录过期"确认框 → 调 `LogOut` 清状态跳首页。这是"无感续期失败"时的兜底。
10. ⑩ **`return res.data`**：业务代码 `listUser().then(res => ...)` 里 `res` 已是 `{code,msg,data/rows/total}`，**不是 axios 原 response**——少一层 `.data`。
11. ⑪ **`download`**：导出按钮统一走它，用 `file-saver` 存盘（见 [[19-前端-视图与API分层]] 的导出）。

## 二、utils/auth.js —— token 的存与取

```js
import Cookies from 'js-cookie'
const TokenKey = 'Admin-Token'
export function getToken() { return Cookies.get(TokenKey) }
export function setToken(token) { return Cookies.set(TokenKey, token) }
export function removeToken() { return Cookies.remove(TokenKey) }
```
- 就是 `js-cookie` 的薄封装，`request.js` 和 `store/user.js` 都靠它。**token 存 cookie 而非 localStorage**，便于后端设 `HttpOnly`/`SameSite` 时更安全（也可配成 localStorage）。

## 三、utils/ruoyi.js —— 全局工具（挂在 Vue.prototype）

`src/utils/ruoyi.js` 导出这些，在 `main.js` 被挂成 `this.parseTime` 等（见 [[13-前端-入口与全局挂载]]）：
- `parseTime(date, fmt)`：Date → 字符串（表格里 `{{ parseTime(scope.row.createTime) }}`）。
- `addDateRange(params, dateRange, propName)`：把时间范围拼成 `params.params.beginTime/endTime`，后端 XML 用 `#{params.beginTime}` 查（列表页的时间筛选就这么传）。
- `handleTree(data, id, parentId, children)`：扁平数组 → 树（部门/菜单选择树）。和后端 `getChildPerms` 是镜像。
- `selectDictLabel(dicts, value)` / `selectDictLabels`：按 value 从字典取 label（表格里把 `0/1` 翻成"正常/停用"）。
- `tansParams(params)`：对象 → `a=1&b=2`（请求拦截器用）。

## 四、api/*.js —— 每个微服务一个文件（入门第 10 条）

```js
// src/api/system/user.js
import request from '@/utils/request'
export function listUser(query) {           // ① 一个函数 = 一次 request
  return request({ url: '/system/user/list', method: 'get', params: query })
}
export function addUser(data) {
  return request({ url: '/system/user', method: 'post', data: data })
}
export function resetUserPwd(userId, password) {
  return request({ url: '/system/user/resetPwd', method: 'put',
    data: { userId, password } })
}
// ② 免 token 的请求（如验证码）
export function getCodeImg() {
  return request({ url: '/captchaImage', method: 'get', headers: { isToken: false } })
}
```

**解释：** 每个 `api/*.js` 只做"封装 REST 函数"，**不含业务逻辑**。视图里 `import { listUser } from '@/api/system/user'`，调它拿到 `res.data`。这种"视图→api→request→后端"的三层，让**换接口地址/加拦截只动一处**。

## 五、utils/errorCode.js —— 错误码字典

```js
export default {
  '401': '认证失败，无法访问系统资源',
  '403': '当前操作没有权限',
  '404': '访问资源不存在',
  '500': '系统未知错误，请反馈给管理员',
  '601': '系统警告，请联系管理员',
  'default': '系统未知错误，请反馈给管理员'
}
```
- 响应拦截器里 `errorCode[code] || res.data.msg`：**优先用后端 `msg`，没有再用前端字典**——所以后端 `ServiceException("xxx")` 的文案能直接显示给用户。
