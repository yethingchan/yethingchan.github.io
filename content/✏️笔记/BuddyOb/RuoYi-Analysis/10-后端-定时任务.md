# 10 · 后端-定时任务（ruoyi-quartz）

> 对应清单：高级第 19 条（定时任务）。
> 模块 `com.ruoyi.quartz`：基于 Quartz 调度，让你在后台配 Cron 表达式 → 周期性跑一段 Java 方法（发报表、清缓存、对账…）。
> 本模块是标准 RuoYi 定时任务，下列类为其通用实现，本仓库同名类逻辑一致。

## 一、核心领域（SysJob / SysJobLog）

```java
// 一条"定时任务"的配置（对应 sys_job）
public class SysJob extends BaseEntity {
    private Long     jobId;
    private String   jobName;        // 任务名
    private String   jobGroup;       // 任务组
    private String   invokeTarget;    // ① 要调谁："ryTask.ryParams('ruoyi')" 或 "com.x.A.b()"
    private String   cronExpression;  // ② Cron：0 0 2 * * ? = 每天凌晨2点
    private String   misfirePolicy;  // 错过执行的策略
    private String   concurrent;     // ③ 是否允许并发（0=允许/1=禁止）
    private String   status;          // ④ 0=运行 1=暂停
}
// 每次执行的日志（对应 sys_job_log）
public class SysJobLog {
    private Long   jobLogId;
    private String jobName;
    private String jobGroup;
    private String invokeTarget;
    private String jobMessage;
    private String status;          // 0 成功 1 失败
    private String exceptionInfo;     // 失败堆栈
}
```

**解释：**
- ① `invokeTarget` 是"任务指向"：填 `ryTask.ryParams('ruoyi')` 就周期性调 `RyTask.ryParams("ruoyi")`；或填全限定 `com.x.Service.method()`。
- ② `cronExpression` 标准 Quartz Cron（秒 分 时 日 月 周）。
- ④ `status=0` 才真正调度；暂停就是停掉触发器。

## 二、ScheduleUtils —— 把"配置"变成"Quartz 作业"

```java
public class ScheduleUtils {
    // ① Quartz 的 JobKey / TriggerKey 约定前缀
    public static final String JOB_KEY = "TASK_";

    // ② 把一个 SysJob 创建成 Quartz 的 JobDetail + Trigger
    public static void createScheduleJob(Scheduler scheduler, SysJob job) {
        Class<? extends Job> jobClass = getQuartzJobClass(job);  // ③ 并发控制决定用哪个类
        JobDetail jobDetail = JobBuilder.newJob(jobClass)
                .withIdentity(getJobKey(job.getJobId())).build();
        CronTrigger trigger = TriggerBuilder.newTrigger()
                .withIdentity(getTriggerKey(job.getJobId()))
                .withSchedule(CronScheduleBuilder.cronSchedule(job.getCronExpression()))
                .build();
        jobDetail.getJobDataMap().put(SysJob.JOB_PARAM_KEY, job); // ④ 把 SysJob 本身塞进上下文
        scheduler.scheduleJob(jobDetail, trigger);
    }
    // 根据 concurrent 选类：禁止并发 → 用 QuartzDisallowConcurrentExecution
    private static Class<? extends Job> getQuartzJobClass(SysJob job) {
        return "1".equals(job.getConcurrent())
            ? QuartzDisallowConcurrentExecution.class  // @DisallowConcurrentExecution
            : QuartzJobExecution.class;
    }
}
```

**逐行解释：**
- ② `JobDetail` + `CronTrigger` 是 Quartz 的两大件：作业（干什么）+ 触发器（何时干）。
- ③ `QuartzDisallowConcurrentExecution` 带了 `@DisallowConcurrentExecution` 注解——上一次还没跑完，这次**不并发**开新线程（防止慢任务堆叠）。允许并发就用普通 `QuartzJobExecution`。
- ④ `JobDataMap` 把 `SysJob` 传进作业，运行时能拿到 `invokeTarget` 等。

## 三、AbstractQuartzJob —— 真正执行的那一下

```java
public abstract class AbstractQuartzJob implements Job {
    @Override
    public void execute(JobExecutionContext context) {
        SysJob job = (SysJob) context.getMergedJobDataMap().get(SysJob.JOB_PARAM_KEY);
        SysJobLog jobLog = new SysJobLog();
        jobLog.setJobName(job.getJobName());
        try {
            JobInvokeUtil.invokeMethod(job);   // ① 反射调目标方法
            jobLog.setStatus("0");
        } catch (Exception e) {
            jobLog.setStatus("1");
            jobLog.setExceptionInfo(...);
        } finally {
            AsyncManager.me().execute(AsyncFactory.recordJobLog(jobLog)); // ② 异步写 sys_job_log
        }
    }
}
```

**解释：**
- ① `JobInvokeUtil.invokeMethod(job)`：拆 `invokeTarget` 字符串，用**反射** `method.invoke(bean, args)`。若写 `ryTask.ryParams('ruoyi')`，它从 Spring 容器取 `RyTask` 这个 Bean，调其 `ryParams("ruoyi")`。
- ② 执行结果（成败+堆栈）异步写 `sys_job_log`，后台"调度日志"页可查——**任务在后台跑，出了问题有据可查**。

## 四、RyTask —— 你写任务逻辑的地方

```java
@Component("ryTask")                 // ① 名字就是 invokeTarget 里的前缀
public class RyTask {
    public void ryMultipleParams(String s, Boolean b, Long l, Double d, Integer i) {
        System.out.println(String.format("执行多参方法：%s,%s,%s,%s,%s", s, b, l, d, i));
    }
    public void ryParams(String params) {   // ② 被 "ryTask.ryParams('ruoyi')" 调
        System.out.println("参数：" + params);
    }
    public void ryNoParams() { System.out.println("无参任务"); }
}
```

**解释：** 加 `@Component("ryTask")` 让 Spring 管理它；`invokeTarget` 填 `ryTask.ryParams('xxx')` 就能周期性执行。业务任务你照这个样子加方法即可。

## 五、其它件

| 类 | 职责 |
|---|---|
| `ScheduleConfig` | 配 `SchedulerFactoryBean` + `ThreadPoolTaskExecutor`（任务线程池），工程启动时把 `sys_job` 里 `status=0` 的 Job 全 `scheduleJob` 注册进去 |
| `CronUtils` | Cron 校验 / 下次执行时间计算（前端录入时实时提示"下次运行：..."） |
| `SysJobServiceImpl` | 增删改任务时同步 `scheduler.rescheduleJob / deleteJob / pauseJob / resumeJob` |
| `SysJobController` / `SysJobLogController` | `/monitor/job`、`/monitor/job/log` 后台页面接口 |
