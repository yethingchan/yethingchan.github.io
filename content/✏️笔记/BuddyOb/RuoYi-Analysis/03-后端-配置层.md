# 03 · 后端-配置层（ruoyi-framework.config）

> 对应清单：进阶第 1 条（SecurityFilterChain）、入门第 7 条（RedisCache）、高级第 4 条（MyBatis 扫描）、高级第 22 条（文件上传/验证码）。
> 配置层集中在 `com.ruoyi.framework.config` + `properties`、`ruoyi-admin` 的 `application.yml`。本文挑**最关键的两个配置类全文精讲**，其余列出职责。

## 一、SecurityConfig —— 整个安全的总开关（节选核心）

```java
@EnableMethodSecurity(prePostEnabled = true, securedEnabled = true)
@Configuration
public class SecurityConfig {
    @Autowired private JwtAuthenticationTokenFilter authenticationTokenFilter;
    @Autowired private CorsFilter corsFilter;
    @Autowired private PermitAllUrlProperties permitAllUrl;

    @Bean
    protected SecurityFilterChain filterChain(HttpSecurity httpSecurity) throws Exception {
        return httpSecurity
            .csrf(csrf -> csrf.disable())                       // ① 关 CSRF
            .headers(h -> h.cacheControl(c->c.disable())
                           .frameOptions(o->o.sameOrigin()))     // 允许同源 iframe（Druid 监控用）
            .exceptionHandling(e -> e.authenticationEntryPoint(unauthorizedHandler)) // ② 未登录统一返回
            .sessionManagement(s -> s.sessionCreationPolicy(STATELESS)) // ③ 无状态，不用 session
            .authorizeHttpRequests(r -> {
                permitAllUrl.getUrls().forEach(url -> r.requestMatchers(url).permitAll());
                r.requestMatchers("/login","/register","/captchaImage").permitAll() // ④ 登录/注册/验证码匿名
                 .requestMatchers(GET, "/","/*.html","/**.css","/**.js","/profile/**").permitAll()
                 .requestMatchers("/swagger-ui.html","/v3/api-docs/**","/druid/**").permitAll()
                 .anyRequest().authenticated();                         // ⑤ 其余全部要登录
            })
            .logout(l -> l.logoutUrl("/logout").logoutSuccessHandler(logoutSuccessHandler))
            .addFilterBefore(authenticationTokenFilter, UsernamePasswordAuthenticationFilter.class) // ⑥ JWT 过滤器在最前
            .addFilterBefore(corsFilter, JwtAuthenticationTokenFilter.class)                    // ⑦ CORS 在 JWT 前
            .build();
    }

    @Bean
    public BCryptPasswordEncoder bCryptPasswordEncoder() {
        return new BCryptPasswordEncoder();   // ⑧ 密码加密器（全局复用）
    }
}
```

**逐条解释（这是 Spring Security 6 的 lambda DSL 写法，不是旧版 `WebSecurityConfigurerAdapter`）：**
1. **关 CSRF**：因为本项目用 token 鉴权、不用 cookie session，CSRF token 机制没意义，关掉避免误伤。
2. **`authenticationEntryPoint`**：未携带有效 token 访问受保护资源时，401 从这里统一返回（配合前端 `request.js` 的 401 弹窗重新登录）。
3. **`STATELESS`**：<u>每个请求都自带 token，服务器不存 session</u>。这是无状态 REST 的核心。
4. **`permitAll` 白名单**：登录、注册、验证码必须匿名可访问，否则永远登不进去（死循环）。`permitAllUrl` 还支持 `@Anonymous` 注解动态放行（见 [[05-后端-安全与鉴权]]）。
5. **`anyRequest().authenticated()`**：兜底——没被上面放行的，都要登录。
6. **JWT 过滤器位置**：`addFilterBefore(... UsernamePasswordAuthenticationFilter)` 表示 JWT 校验在用户名密码过滤器**之前**，保证后续 `@PreAuthorize` 能拿到 `SecurityContext` 里的用户。
7. **CORS 最前**：跨域预检 `OPTIONS` 要先被 `CorsFilter` 放行，否则浏览器直接拦。
8. **`BCryptPasswordEncoder`**：注入成 Bean 后，登录校验、改密码都 `@Autowired` 它来 `encode/matches`（见 [[05-后端-安全与鉴权]] 的 `SysPasswordService`）。

## 二、MyBatisConfig —— 让 MyBatis 认识你的包（节选核心）

```java
@Configuration
public class MyBatisConfig {
    @Bean
    public SqlSessionFactory sqlSessionFactory(DataSource dataSource) throws Exception {
        String typeAliasesPackage = env.getProperty("mybatis.typeAliasesPackage"); // "com.ruoyi.**.domain,cn.yething.**.domain"
        typeAliasesPackage = setTypeAliasesPackage(typeAliasesPackage); // 把 ** 展开成真实包路径
        VFS.addImplClass(SpringBootVFS.class);
        SqlSessionFactoryBean sessionFactory = new SqlSessionFactoryBean();
        sessionFactory.setDataSource(dataSource);
        sessionFactory.setTypeAliasesPackage(typeAliasesPackage);
        sessionFactory.setMapperLocations(resolveMapperLocations(
            StringUtils.split(env.getProperty("mybatis.mapperLocations"), ","))); // classpath*:mapper/**/*Mapper.xml
        sessionFactory.setConfigLocation(new DefaultResourceLoader().getResource(
            env.getProperty("mybatis.configLocation"))); // mybatis/mybatis-config.xml
        return sessionFactory.getObject();
    }
}
```

**解释：**
- `typeAliasesPackage` 来自 `application.yml` 的 `mybatis.typeAliasesPackage`。`**` 是通配，但 MyBatis 原生不认 `**`，所以 `setTypeAliasesPackage()` 用 Spring 的 `PathMatchingResourcePatternResolver` 把 `com.ruoyi.**.domain` 扫描成真实包名列表，这样 XML 里 `resultType="SysUser"` 才找得到类。
- **这就是你那个 `Locations` 报错的关键配置**：必须包含 `cn.yething.**.domain`，否则 XML 写 `resultType="Locations"` 时 MyBatis 不知道 `Locations` 是哪个类 → `Could not resolve type alias`。
- `mapperLocations = classpath*:mapper/**/*Mapper.xml`：扫描所有 jar/模块下的 Mapper XML（所以 test-module 的 XML 也能被加载）。
- `setConfigLocation` 指向全局 `mybatis-config.xml`（里面通常配 `mapUnderscoreToCamelCase=true` 等）。

## 三、其余配置类一览（知道干什么即可）

| 配置类 | 职责 | 关联清单 |
|---|---|---|
| `RedisConfig` | 配 `RedisTemplate` + JSON 序列化（`FastJson2JsonRedisSerializer`），让 Redis 里 `LoginUser` 能正确存/取 | 入门第 7 条 |
| `DruidConfig` + `properties/DruidProperties` | 阿里 Druid 连接池 + 监控页 `/druid/**`；读 `spring.datasource.druid.*` | — |
| `CaptchaConfig` + `KaptchaTextCreator` | 验证码生成器（math 数字计算 / char 字符），`captchaType` 在 yml 配 | 高级第 22 条 |
| `ResourcesConfig` | 静态资源映射（`/profile/**` → 上传目录）、`InterceptorRegistry` 注册 `RepeatSubmitInterceptor` | [[06-后端-AOP与拦截器]] |
| `ServerConfig` | 读取服务器 IP/端口，供"系统监控"展示 | — |
| `ThreadPoolConfig` | 自定义线程池 `ThreadPoolExecutor`，供 `AsyncManager` 异步记日志用 | [[06-后端-AOP与拦截器]] |
| `I18nConfig` | 加载 `i18n/messages*.properties`（中英文案，如 `user.password.not.match`） | — |
| `ApplicationConfig` | 普通 `@Configuration`，装配一些 Bean | — |
| `SwaggerConfig`（在 ruoyi-admin） | springdoc-openapi 配置，`/v3/api-docs`、`/swagger-ui.html` | 高级第 22 条 |

## 四、application.yml 关键片段（ruoyi-admin 的 resources）

```yaml
mybatis:
  typeAliasesPackage: com.ruoyi.**.domain,cn.yething.**.domain   # ← 你的包在这
  mapperLocations: classpath*:mapper/**/*Mapper.xml
  configLocation: classpath:mybatis/mybatis-config.xml
pagehelper:
  helperDialect: mysql
  supportMethodsArguments: true
token:
  header: Authorization
  secret: abcdefghijklmnopqrstuvwxyz
  expireTime: 30
xss:
  enabled: true
  excludes: /system/notice
  urlPatterns: /system/*,/monitor/*,/tool/*
```

**解释：**
- `token.secret` 是 JWT 签名密钥（**生产必须改长、改随机**）；`header: Authorization` 对应前端 `request.js` 里 `config.headers['Authorization'] = 'Bearer ' + getToken()`。
- `pagehelper` 是**物理分页插件**：Controller 里 `startPage()` 设了 `pageNum/pageSize`，PageHelper 自动在紧随其后的第一条 SQL 上加 `LIMIT`。
- `xss.enabled: true` 打开 XSS 过滤（见 [[04-后端-通用核心层]]）。

> 配置层是"地基"。读完这章，你应理解：安全的总闸门在 `SecurityConfig`，MyBatis 认类靠 `typeAliasesPackage`，Redis/连接池/验证码都在各自信配置类里用 `@Bean` 交付给 Spring。下一章看 `common` 里那些"到处被调用"的基础件。
