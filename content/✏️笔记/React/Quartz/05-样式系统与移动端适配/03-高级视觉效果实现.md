本章选取本项目中七个最具代表性的高级视觉效果，逐一分析其实现原理。每个效果都涉及 CSS、JavaScript 和组件架构的综合运用。

## 1. 星空背景（StarryBackground.tsx）

星空背景使用 tsParticles 引擎，通过 CDN 运行时加载，不打包到项目构建产物中。

### CDN 加载方式

```tsx
// quartz/components/StarryBackground.tsx
<script
  type="module"
  dangerouslySetInnerHTML={{
    __html: `
      import { tsParticles } from "https://cdn.jsdelivr.net/npm/tsparticles-engine@2/+esm";
      import { loadSlim } from "https://cdn.jsdelivr.net/npm/tsparticles-slim@2/+esm";
    `,
  }}
/>
```

使用 ES Module CDN 而非 npm 包，有三个好处：减小构建体积、避免版本冲突、方便独立更新。代价是依赖用户网络环境，因此代码中有 `try/catch` 降级处理。

### 粒子配置

```typescript
await tsParticles.load({
  id: "starry-background",
  options: {
    fullScreen: { enable: false },   // 不占全屏，限定在容器内
    background: { color: "transparent" },
    fpsLimit: 60,
    particles: {
      number: { value: 90, density: { enable: true, area: 1000 } },
      color: { value: ["#ffffff", "#c4b5fd", "#93c5fd", "#67e8f9"] },
      // 白色、紫色、蓝色、青色 -- 四种颜色的粒子
      shape: { type: "circle" },
      opacity: {
        value: { min: 0.1, max: 0.8 },
        animation: { enable: true, speed: 0.8, minimumValue: 0.1 }
      },
      size: { value: { min: 1, max: 3 } },
      move: {
        enable: true, speed: 0.25, direction: "none",
        random: true, straight: false,
        outModes: { default: "out" }
      },
      links: { enable: false }  // 不连线，保持"星星"感
    },
    interactivity: {
      events: {
        onHover: { enable: true, mode: "grab" },
        resize: true
      },
      modes: { grab: { distance: 120, links: { opacity: 0.18 } } }
    },
    detectRetina: true
  }
});
```

设计考量：90 个粒子在性能和视觉效果之间取得平衡。`direction: "none"` + `random: true` 让粒子以随机方向缓慢飘动，模拟星空的宁静感。`grab` 交互让鼠标悬停时附近粒子被"吸引"，增加趣味性。

### SPA 防重复初始化

Quartz 是 SPA 应用，页面切换不会刷新浏览器，因此需要防止粒子引擎被重复初始化：

```typescript
async function initParticles() {
  const container = document.getElementById("starry-background");
  if (!container) return;
  // 关键：检查是否已初始化
  if (container.dataset.loaded === "true") return;
  container.dataset.loaded = "true";

  try {
    await loadSlim(tsParticles);
    await tsParticles.load({ id: "starry-background", options: { ... } });
  } catch (e) {
    console.warn("StarryBackground: CDN 加载失败，粒子效果已禁用", e);
  }
}

initParticles();
// SPA 导航后也尝试初始化（仅未初始化时生效）
document.addEventListener("nav", () => {
  setTimeout(initParticles, 50);
});
```

`custom.scss` 中还通过主题控制星空的可见度：

```scss
:root[saved-theme="dark"] #starry-background { opacity: 1; }
:root[saved-theme="light"] #starry-background { opacity: 0.35; }
```

暗色模式全亮度、亮色模式降至 35%，确保两种主题下都不影响正文阅读。

## 2. 扇形阅读进度按钮（BackToTop.tsx 中的 #scroll-toggle）

### conic-gradient 实现环形进度

核心 CSS 使用 `conic-gradient`（圆锥渐变）实现环形进度指示器：

```scss
#scroll-toggle {
  width: 64px;
  height: 64px;
  border-radius: 999px;
  // 核心：扇形进度条
  background: conic-gradient(
    #111827 calc(var(--progress, 0) * 360deg),
    transparent calc(var(--progress, 0) * 360deg)
  );
}

// 内层白色圆，让渐变只显示为环形
#scroll-toggle::before {
  content: '';
  position: absolute;
  width: 52px;
  height: 52px;
  border-radius: 999px;
  background: linear-gradient(180deg, rgba(255,255,255,0.96), rgba(248,250,252,0.94));
  z-index: 0;
}
```

原理：外层 64px 圆使用 `conic-gradient`，从 0 度到 `--progress * 360` 度填充深色，其余部分透明。内层 52px 的白色伪元素叠加在上面，只露出 6px 宽的"进度环"。`isolation: isolate` 确保伪元素正确参与层叠上下文。

### CSS 自定义属性驱动进度

JavaScript 在滚动时更新 `--progress` 的值（0 到 1）：

```typescript
function updateScroll() {
  const scrollTop = getScrollTop();
  const scrollHeight = getScrollHeight() - getClientHeight();
  const progress = Math.min(scrollTop / Math.max(scrollHeight, 1), 1);

  // 更新环形进度
  scrollBtn.style.setProperty("--progress", progress.toString());

  // 更新箭头方向
  scrollIcon.innerHTML = scrollTop < 200 ? "▼" : "▲";

  // 更新顶部进度条
  progressBar.style.transform = `scaleX(${progress})`;
}
```

### 桌面端与移动端的滚动容器差异

由于桌面端使用 `#quartz-body` 作为滚动容器（`overflow-y: auto; height: 100dvh`），而移动端由 `window` 滚动，进度计算需要动态适配：

```typescript
function getScrollContainer() {
  const quartzBody = document.querySelector('.page > #quartz-body');
  if (quartzBody && getComputedStyle(quartzBody).overflowY === 'auto') {
    return quartzBody;   // 桌面端
  }
  return window;          // 移动端
}
```

这种动态检测避免了硬编码滚动容器，确保 SPA 导航后在不同布局下都能正确计算进度。

### 时间更新逻辑

```typescript
const updateClock = () => {
  const now = new Date();
  const hh = String(now.getHours()).padStart(2, "0");
  const mm = String(now.getMinutes()).padStart(2, "0");
  clockBtn.innerText = hh + ":" + mm;
};

updateClock();
clockTimer = setInterval(updateClock, 60000);  // 每分钟更新
```

使用 `setInterval` 而非 `requestAnimationFrame`，因为时钟只需每分钟更新一次，无需 60fps 的渲染开销。`padStart(2, "0")` 确保个位数前面补零。

## 4. Hero Banner 视差效果

### 固定背景与前景视差

Hero Banner 由文章前置的 `.article-cover` 元素实现，图片在滚动时产生视差位移：

```scss
.article-cover {
  position: relative;
  width: 100%;
  height: 360px;
  overflow: hidden;
  border-radius: 28px;
  isolation: isolate;     // 创建隔离的层叠上下文
}

.article-cover img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  transform: scale(1.04);  // 略微放大，避免视差时露出空白
  will-change: transform;   // 提示浏览器优化
}
```

JavaScript 在滚动时动态更新图片的 `translateY`：

```typescript
// BackToTop.tsx 中的 updateScroll 函数
const banner = document.querySelector(".article-cover img");
if (banner) {
  const offset = getScrollTop() * 0.12;  // 视差系数 0.12
  banner.style.transform = `scale(1.06) translateY(${offset}px)`;
}
```

`0.12` 的系数意味着页面每滚动 100px，图片只移动 12px，产生微妙的纵深差。`scale(1.06)` 配合 `translateY` 确保视差移动时不会露出图片边缘空白。

### 毛玻璃遮罩层

```scss
.article-cover::before {
  content: "";
  position: absolute;
  inset: 0;
  backdrop-filter: blur(2px);
  background: linear-gradient(to bottom,
    rgba(0,0,0,0.08),
    rgba(0,0,0,0.14));
  z-index: 1;
  border-top: 1px solid rgba(255,255,255,0.18);  // 顶部高光线
}
```

### 底部渐变过渡

```scss
.article-cover::after {
  content: "";
  position: absolute;
  inset: 0;
  background: linear-gradient(to top,
    rgba(0,0,0,0.48) 0%,     // 底部最浓
    rgba(0,0,0,0.18) 24%,
    rgba(0,0,0,0.04) 50%,
    transparent 100%);         // 顶部透明

}
```

底部渐变让 Banner 图片自然过渡到下方的文章卡片区域，避免图片与白色卡片之间的硬切边。

## 5. 阅读进度条（彩虹渐变）

顶部固定进度条使用多色线性渐变，在暗色和亮色模式下有不同的配色：

```scss
#reading-progress {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 5px;
  transform-origin: left;
  transform: scaleX(0);      // 初始宽度为 0
  z-index: 9999999;

  // 亮色模式：暖色渐变
  background: linear-gradient(90deg, #f472b6, #fb923c, #facc15);
  box-shadow: 0 0 12px rgba(129,140,248,0.6);
  transition: transform 0.12s linear;
}

// 暗色模式：冷色渐变
:root[saved-theme="dark"] #reading-progress {
  background: linear-gradient(90deg, #818cf8, #6366f1, #a78bfa);
  box-shadow: 0 0 12px rgba(129,140,248,0.4);
}
```

使用 `transform: scaleX()` 而非 `width` 来控制进度条宽度，因为 `transform` 不触发重排（reflow），只触发重绘（repaint），性能更优。`transform-origin: left` 确保从左到右展开。

JavaScript 端的实现：

```typescript
if (progressBar) {
  progressBar.style.transform = `scaleX(${progress})`;
}
```

`0.12s linear` 的过渡时间使进度条跟随滚动时几乎无延迟，但又在快速跳转时不会"闪烁"。

## 7. 页面切换过渡动画

### SPA 导航触发

Quartz 的 SPA 路由在每次页面切换时触发 `nav` 事件。`BackToTop.tsx` 监听此事件并添加过渡动画：

```typescript
function triggerPageTransition() {
  document.body.classList.remove("page-transition");
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      document.body.classList.add("page-transition");
    });
  });
}

// 首次加载
triggerPageTransition();

// SPA 导航
document.addEventListener("nav", () => {
  triggerPageTransition();
  setTimeout(() => { init(); updateScroll(); }, 80);
});
```

双重 `requestAnimationFrame` 确保浏览器在移除类和重新添加类之间完成一次渲染帧，使动画能够重新触发。

### CSS 动画定义

```scss
.page-transition article {
  animation: quartzArticleFade 0.42s ease;
}

@keyframes quartzArticleFade {
  from {
    opacity: 0;
    transform: translateY(10px);
    filter: blur(4px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
    filter: blur(0);
  }
}
```

三个属性的组合产生了丰富的过渡感：
- `opacity: 0 -> 1`：淡入
- `translateY(10px) -> 0`：从下方微微上滑
- `blur(4px) -> 0`：从模糊到清晰

`blur(4px)` 是一个高级的过渡技巧，模拟了人眼"对焦"的视觉感受，使页面切换的过渡更加自然。0.42 秒的动画时长经过调试，既不过快（让用户感到"跳闪"），也不过慢（让用户等待）。

总结：本项目的七个高级视觉效果展示了从纯 CSS（彩虹进度条、彩色文件夹）到 CSS + JS 结合（星空背景、视差 Banner、扇形进度）再到组件级架构（页面切换动画）的多种实现模式。每个效果都兼顾了性能（`will-change`、`transform` 替代 `width`、`passive` 事件监听器）和降级（CDN 加载失败的 `try/catch`、移动端隐藏不必要的动效），是工程思维与视觉设计的良好结合。
