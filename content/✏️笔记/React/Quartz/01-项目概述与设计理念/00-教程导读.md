这份教程是为"Odyssey"项目编写的完整中文技术指南。Odyssey 是一个基于 Quartz v4.5.2 构建的个人技术博客，拥有星空粒子背景、光标发光、毛玻璃卡片、浮动时钟、扇形阅读进度按钮等一系列自定义视觉效果。本教程不仅教你"怎么做"，更要让你理解"为什么这样做"。

## 目标读者

这份教程面向有一定前端基础、但没有 Quartz 使用经验的开发者。如果你满足以下条件，这份教程就是为你准备的：

- 能读懂 HTML/CSS/JavaScript 代码，写过简单的网页
- 了解 Node.js 的基本使用，知道 `npm install` 和 `package.json` 是什么
- 对 TypeScript 有基本认知（不要求精通，但需要知道类型注解和接口的写法）
- 平时用 Markdown 写笔记或文档
- 想拥有一个功能丰富、视觉效果出众的个人博客，并且希望完全掌控每一个技术细节

如果你是纯前端新手，建议先花一周时间学习 HTML/CSS/JS 基础；如果你已经是 Quartz 老手，可以直接跳到第三部分"核心架构"寻找感兴趣的主题。

## 教程整体结构

整个教程分为六大部分，由浅入深、由面到点地展开：

**第一部分：项目概述与设计理念**（你正在阅读的部分）
从宏观视角理解 Quartz 框架的定位、技术栈选型理由，以及本项目的设计哲学。读完这部分，你会知道 Quartz 是什么、为什么选它、以及 Odyssey 项目做了哪些定制。

**第二部分：环境搭建与项目初始化**
手把手引导你克隆项目、安装依赖、理解两个核心配置文件 `quartz.config.ts` 和 `quartz.layout.ts` 的结构，并跑起本地开发服务器。

**第三部分：核心架构深度解析**
这是教程的"硬核"部分。我们将拆解 Quartz 的内容管道（Markdown -> Parse -> Transform -> Filter -> Emit）、插件化架构（transformers/filters/emitters 三层）、以及 SPA 路由的 DOM morphing 原理。配合真实源码逐行讲解。

**第四部分：自定义组件开发**
以本项目中的实际组件为案例，讲解如何开发 Quartz 组件：星空粒子背景 `StarryBackground.tsx`、光标发光效果 `CursorGlow.tsx`、浮动时钟、扇形进度按钮、毛玻璃文章卡片等。每个组件都会从需求分析讲到代码实现。

**第五部分：样式体系与多端适配**
讲解 Quartz 的 SCSS 样式架构、CSS 变量体系、暗色模式实现、以及如何通过 `custom.scss` 和 `variables.scss` 进行全局样式定制。同时覆盖移动端适配的关键策略。

**第六部分：部署上线与进阶话题**
涵盖 GitHub Pages 部署、自定义域名配置、构建性能优化、i18n 国际化、以及增量构建的调试技巧。

## 建议的学习路径

根据你的经验和目标，有三条推荐路径：

**路径 A：快速上手型** -- 如果你只是想尽快把自己的博客跑起来，建议先读完第一部分的概述，然后跳到第二部分搭建环境，再浏览第四部分的组件代码直接复制使用。遇到不懂的地方再回头查阅第三部分。

**路径 B：深度学习型** -- 如果你想彻底理解 Quartz 的每一行代码，建议按顺序从第一部分读到第六部分。这是一个系统性的学习过程，每一步都建立在前一步的基础之上。

**路径 C：按需查阅型** -- 如果你已经在使用 Quartz，只是想了解某个具体功能（比如 SPA 路由的 morphing 是怎么做的，或者 Explorer 组件的 Trie 树是怎么构建的），可以直接跳到对应章节。每篇文章都尽量做到自包含，提供足够的上下文。

## 前置知识要求

在开始之前，确保你对以下内容有基本了解：

- **HTML/CSS/JavaScript 基础** -- 理解 DOM 结构、CSS 盒模型、事件监听等概念
- **Node.js 使用** -- 会使用 `npm` 安装包、运行脚本，理解 `node_modules` 的作用
- **TypeScript 基础** -- 知道什么是类型注解、接口（interface）、泛型的基本概念
- **Markdown 写作** -- 会用 Markdown 写文档，了解 frontmatter（YAML 头部信息）的格式

不需要掌握的：React 开发经验、构建工具（Vite/Webpack）的深度知识、后端开发经验。这些在教程中都会涉及并解释。

## 这份教程要教什么

一份好的教程不只是告诉你步骤，更要让你理解每个步骤背后的原因。这份教程的核心目标有三：

**第一，从零构建一个功能丰富的 Quartz 博客。** 你将学会如何从一个空白项目出发，逐步添加自定义组件、修改样式体系、调整配置，最终得到一个视觉效果出众、功能完备的个人博客。

**第二，理解每一个设计决策背后的理由。** 为什么 Quartz 选了 Preact 而不是 React？为什么用 remark/rehype 而不是手写解析器？为什么 SPA 导航要用 DOM morphing 而不是简单的 `innerHTML` 替换？每一个"为什么"都会得到回答。

**第三，获得独立扩展和维护项目的能力。** 读完这份教程，你应该有能力独立开发新的 Quartz 组件、调试构建管道问题、以及根据自身需求定制博客的任何部分。

准备好了吗？让我们从了解 Quartz 框架本身开始。
