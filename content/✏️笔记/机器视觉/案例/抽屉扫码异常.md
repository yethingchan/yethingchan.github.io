# 完整落地方案（Halcon，你的场景：浅灰抽屉+浅灰包装袋+小块黄色标签）
## 核心痛点拆解
1. 主体包装袋和底板灰度几乎重合，**全局二值化直接失效**，单纯靠灰度分不出整包；
2. 黄色标签只占1/16面积，很小，但**色彩和灰色底板完全不冲突**，是整个图像里唯一高区分特征；
3. 光照轻微波动，灰度差直接抹平，导致框选区域也识别不到。

## 最优思路：不走「分割整个包装袋」，先抓黄色标签，再反向定位整个包装
黄色标签是稳定特征，不受灰度接近影响，分两步走：
1. 彩色通道/HSV分割，精准提取黄色小标签（不受浅灰背景干扰）；
2. 以标签位置、尺寸为基准，向外扩充矩形区域，得到完整包装袋；
3. 最后再做校验、尺寸判断，确认是目标包装。

## 分步实操流程（Halcon完整逻辑）
### 第一步：硬件微调（低成本，大幅提升稳定性）
不用大改设备，只调3点：
1. 光源：用**低角度环形光**，斜打光，包装袋纸质会轻微漫反射，抽屉平面反光均匀，人为拉出细微灰度差；禁止垂直同轴光（会抹平灰度差异）；
2. 背景：能换就换深灰/黑色垫板，一次性解决灰度相近；不能换就强化色彩通道；
3. 相机：务必开彩色模式，灰度相机直接丢失黄色信息，这个场景彩色是刚需。

### 第二步：提取黄色标签（核心，百分百能分开灰色背景）
灰度图分不清，但HSV色彩空间里黄色和灰色完全隔离：
1. 图像转HSV通道
```hdevelop
decompose3 (Image, ImageR, ImageG, ImageB)
trans_from_rgb (ImageR, ImageG, ImageB, ImageH, ImageS, ImageV, 'hsv')
```
2. 阈值筛选黄色色相H
黄色H区间大致：20~40，饱和度S不能太低（灰色饱和度极低，会直接过滤掉抽屉+包装灰色本体）
```hdevelop
threshold (ImageH, RegionYellow, 20, 40)
threshold (ImageS, RegionSat, 30, 255)
intersection (RegionYellow, RegionSat, RegionTag)
```
- 灰色抽屉、灰色包装袋：饱和度S极低，直接被过滤；
- 只有黄色标签会保留下来，不受灰度干扰。

3. Blob筛选，过滤微小粉尘杂点
```hdevelop
connection (RegionTag, TagBlobs)
select_shape (TagBlobs, TargetTag, 'area', 'and', 50, 3000)
```
此时 `TargetTag` 就是包装袋上的黄色标签，稳定存在，光照轻微变化也不会消失。

### 第三步：由标签反向框出完整包装袋
已知标签在包装袋表面，基于标签向外扩张，得到包装整体区域：
1. 获取标签最小外接矩形
```hdevelop
smallest_rectangle2 (TargetTag, Row, Column, Phi, Length1, Length2)
```
2. 向外扩充区域（根据你的包装尺寸，上下左右放大倍数）
比如标签只占1/16，长宽放大4~6倍，刚好覆盖整个包装：
```hdevelop
expand_region (TargetTag, RegionExpanded, 120, 120, 'constant')
```
`RegionExpanded` 就是完整包装袋的感兴趣区域ROI。

### 第四步：在ROI内做灰度二次校验，确认是包装袋
现在只在放大后的区域内处理，不用整张图区分灰度：
1. 裁剪图像到包装ROI，排除外部抽屉背景干扰
```hdevelop
reduce_domain (Image, RegionExpanded, ImageROI)
```
2. ROI内使用**局部自适应二值化 dyn_threshold**
只对比包装内部和紧邻背景的细微灰度差，不受整张图灰度影响：
```hdevelop
mean_image (ImageROI, ImageMean, 15, 15)
dyn_threshold (ImageROI, ImageMean, RegionPack, 6, 'light')
```
3. 形态学闭运算，填补包装微小断裂，合并区域
```hdevelop
closing_circle (RegionPack, RegionPackClose, 3)
```
4. 形状筛选（长宽比、面积），过滤残留杂点，最终得到完整包装袋轮廓。

## 备用方案：如果只能用灰度相机（无彩色，抓不到黄色）
没有色彩只能靠灰度差，放弃全局二值化，全程用局部算法：
1. 预处理增强细微灰度差
```hdevelop
emphasize (Image, ImageEm, 7, 7, 1.2)
```
2. 局部动态阈值分割 dyn_threshold，替代binary_threshold全局阈值
3. 提取轮廓 edges_sub_pix，靠包装边缘线条定位，不靠灰度填充
4. 轮廓拟合矩形，匹配包装长方形特征

## 为什么你现在识别不到？根源
1. 直接整张图全局二值化：抽屉和包装灰度重叠，阈值无论怎么调，包装区域残缺、直接消失；
2. 没有利用黄色标签这个最强特征，硬靠微弱灰度区分，光照一变就失效；
3. 整张图噪点多，灰度差异被粉尘、反光抹平，框选ROI也无法弥补全局灰度重叠问题。

## 稳定识别关键总结
1. 优先彩色相机 + HSV提取黄色标签，这是最稳、最简单的路线；
2. 以标签为锚点，反向扩出包装区域，缩小图像处理范围，减少背景干扰；
3. 不要直接对整张图分割包装，细微灰度差扛不住光照波动；
4. 硬件辅助：低角度打光，拉大纸质包装与平板抽屉的反光灰度差。
