# C# 上位机开发技能树 / 知识图谱

> 本文档是C#上位机开发学习路线的全面知识图谱，帮助你有条理地掌握从入门到精通所需的全部技能。

---

## 一、技能标注说明

| 标注 | 含义 |
|------|------|
| **[必学]** | 上位机开发核心技能，必须掌握 |
| **[推荐]** | 推荐掌握，能显著提升开发效率和项目质量 |
| **[了解]** | 了解即可，遇到具体需求时再深入学习 |

| 标注 | 含义 |
|------|------|
| **初级** | 入门阶段（0-3个月） |
| **中级** | 进阶阶段（3-12个月） |
| **高级** | 精通阶段（1年以上） |

## 四、学习路线建议

### 第一阶段：C#语言基础（1-2个月）

```
学习目标：掌握C#编程基础，能编写简单的控制台程序

学习内容：
1. [必学] 基础语法 → 流程控制 → 面向对象编程
2. [必学] 集合与泛型 → 文件IO操作
3. [必学] 委托与事件 → 异常处理
4. [必学] 异步编程（async/await）

实践项目：
- 编写一个学生成绩管理系统（控制台版）
- 编写一个简单的文件复制/整理工具
```

### 第二阶段：WinForms开发（2-3个月）

```
学习目标：能独立开发功能完整的桌面应用

学习内容：
1. [必学] 常用控件 → DataGridView → Chart控件
2. [必学] 窗体生命周期 → 多窗体交互
3. [必学] 多线程UI更新（Invoke）
4. [推荐] 数据绑定 → 用户控件封装

实践项目：
- 编写一个个人记账软件
- 编写一个串口调试助手（含数据展示）
```

### 第三阶段：数据库与配置（1个月）

```
学习目标：掌握数据持久化与配置管理

学习内容：
1. [必学] SQL基础 → SQLite → ADO.NET
2. [推荐] Dapper → EF Core
3. [必学] 配置文件管理
4. [必学] Serilog日志系统

实践项目：
- 将串口调试助手升级，增加数据存储功能
- 实现配置参数的保存与加载
```

### 第四阶段：工业通信（2-3个月）

```
学习目标：掌握PLC等工业设备的通信技术

学习内容：
1. [必学] 串口通信 → TCP/IP通信
2. [必学] Modbus RTU → Modbus TCP
3. [必学] 汇川PLC通信协议
4. [推荐] 西门子/三菱PLC通信
5. [必学] 通信封装与异常处理

实践项目：
- 编写一个Modbus通信测试工具
- 实现汇川PLC数据读写功能
```

### 第五阶段：项目实战（2-3个月）

```
学习目标：能独立完成完整的上位机项目

学习内容：
1. [必学] 分层架构设计
2. [必学] 接口设计与设计模式
3. [必学] 报警系统实现
4. [必学] 数据备份与恢复
5. [推荐] 单元测试

实践项目：
- 完整的汇川PLC数据监控系统
```

### 第六阶段：进阶提升（持续学习）

```
学习目标：提升代码质量与项目工程化能力

学习内容：
1. [推荐] MVVM模式 → 依赖注入
2. [推荐] 性能优化
3. [推荐] 自动化测试
4. [必学] 安装包制作与部署
5. [了解] OPC UA → MQTT
```
