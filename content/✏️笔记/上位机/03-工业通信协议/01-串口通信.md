# 01 - 串口通信（Serial Port Communication）

---

## 一、知识讲解

### 1.1 串口通信基础

串口通信（Serial Communication）是工业自动化领域中最经典的通信方式之一，上位机通过串口与PLC、传感器、变频器等设备进行数据交换。尽管以太网通信日益普及，串口通信因其在恶劣电磁环境下的稳定性，至今仍在大量设备中使用。

#### RS232 vs RS485 对比

| 特性 | RS232 | RS485 |
|------|-------|-------|
| 通信方式 | 全双工（可同时收发） | 半双工（同一时刻只能收或发） |
| 传输距离 | 最长约15米 | 最长约1200米 |
| 通信速率 | 最高约115200bps | 最高约10Mbps |
| 节点数量 | 1对1（点对点） | 1对多（最多128个节点） |
| 电平标准 | +/-12V（非平衡） | +/-5V差分信号（平衡） |
| 抗干扰能力 | 较弱 | 强（差分信号抗干扰） |
| 典型接口 | DB9（9针） | DB9 / 端子接线（A/B两线） |
| 适用场景 | 短距离PC通信、调试 | 工业现场、多设备组网 |

#### 选型建议

- **RS232**：适合上位机与单一设备的短距离通信（如调试阶段、连接单台PLC）
- **RS485**：适合工业现场多设备组网（如一条485总线上挂接多台变频器/仪表）
- **现代上位机**：PC通常没有原生串口，需要使用USB转RS232/RS485转换器（如CH340、FT232、CP2102芯片）

### 1.2 SerialPort 类详解

`System.IO.Ports.SerialPort` 是 .NET 提供的串口操作类，支持 .NET Framework 和 .NET Core/.NET 5+。

#### 核心属性

```csharp
// === 端口名称 ===
serialPort.PortName = "COM3";          // 串口号，如 COM1, COM2, COM3 ...
// 获取可用串口列表：
string[] ports = SerialPort.GetPortNames();

// === 波特率（Baud Rate） ===
// 常见值：9600, 19200, 38400, 57600, 115200
// 波特率必须与设备一致，否则乱码
serialPort.BaudRate = 9600;

// === 数据位（Data Bits） ===
// 通常为 8 位，少数设备使用 7 位
serialPort.DataBits = 8;

// === 停止位（Stop Bits） ===
// StopBits.One   = 1个停止位（最常用）
// StopBits.OnePointFive = 1.5个停止位
// StopBits.Two   = 2个停止位
serialPort.StopBits = StopBits.One;

// === 校验位（Parity） ===
// Parity.None    = 无校验（最常用）
// Parity.Even    = 偶校验
// Parity.Odd     = 奇校验
// Parity.Mark    = 标记校验
// Parity.Space   = 空格校验
serialPort.Parity = Parity.None;

// === 流控制（Handshake） ===
// Handshake.None = 无流控
// Handshake.RequestToSend (RTS/CTS硬件流控)
// Handshake.XOnXOff (软件流控)
serialPort.Handshake = Handshake.None;

// === 缓冲区设置 ===
serialPort.ReadBufferSize = 4096;      // 接收缓冲区大小（字节）
serialPort.WriteBufferSize = 2048;     // 发送缓冲区大小（字节）

// === 超时设置 ===
serialPort.ReadTimeout = 500;          // 读超时（毫秒），-1为无限等待
serialPort.WriteTimeout = 500;         // 写超时（毫秒）
```

### 1.3 串口打开与关闭

```csharp
SerialPort serialPort = new SerialPort("COM3", 9600, Parity.None, 8, StopBits.One);

// 打开串口
if (!serialPort.IsOpen)
{
    try
    {
        serialPort.Open();
        Console.WriteLine("串口打开成功");
    }
    catch (UnauthorizedAccessException ex)
    {
        Console.WriteLine($"串口被占用：{ex.Message}");
    }
    catch (IOException ex)
    {
        Console.WriteLine($"串口不存在：{ex.Message}");
    }
}

// 关闭串口（非常重要！程序退出前必须关闭）
if (serialPort.IsOpen)
{
    serialPort.Close();
    serialPort.Dispose();
}
```

### 1.4 数据发送

串口发送数据有三种常见方式：发送字符串、发送字节数组、发送十六进制数据。

```csharp
// ===== 方式1：发送字符串 =====
serialPort.WriteLine("AT+RST");        // 发送字符串 + 换行符
serialPort.Write("Hello");              // 发送字符串（不追加换行符）

// ===== 方式2：发送字节数组 =====
byte[] sendData = new byte[] { 0x01, 0x03, 0x00, 0x00, 0x00, 0x0A, 0xC5, 0xCD };
serialPort.Write(sendData, 0, sendData.Length);

// ===== 方式3：发送十六进制字符串（工具方法） =====
/// <summary>
/// 将十六进制字符串转换为字节数组
/// 例如："01 03 00 00 00 0A C5 CD" => byte[8]
/// </summary>
public static byte[] HexStringToBytes(string hexString)
{
    hexString = hexString.Replace(" ", "").Replace("-", "");
    if (hexString.Length % 2 != 0)
        throw new ArgumentException("十六进制字符串长度必须为偶数");

    byte[] bytes = new byte[hexString.Length / 2];
    for (int i = 0; i < bytes.Length; i++)
    {
        bytes[i] = Convert.ToByte(hexString.Substring(i * 2, 2), 16);
    }
    return bytes;
}

// 使用示例：发送Modbus RTU请求帧
string hexCmd = "01 03 00 00 00 0A C5 CD";
byte[] modbusFrame = HexStringToBytes(hexCmd);
serialPort.Write(modbusFrame, 0, modbusFrame.Length);

// ===== 方式4：带延迟的发送（某些设备需要） =====
serialPort.Write(sendData, 0, sendData.Length);
Thread.Sleep(100);  // 等待设备处理
```

### 1.5 数据接收

串口数据接收推荐使用事件驱动方式（`DataReceived` 事件），而不是阻塞式读取。

```csharp
// ===== 注册数据接收事件 =====
serialPort.DataReceived += SerialPort_DataReceived;
// 设置触发阈值：当缓冲区收到 >= 1 字节时触发
serialPort.ReceivedBytesThreshold = 1;

// ===== 事件处理方法 =====
private void SerialPort_DataReceived(object sender, SerialDataReceivedEventArgs e)
{
    SerialPort sp = (SerialPort)sender;

    // 方式1：读取所有可用字节（推荐）
    int bytesToRead = sp.BytesToRead;
    byte[] buffer = new byte[bytesToRead];
    int actualRead = sp.Read(buffer, 0, bytesToRead);

    // 方式2：读取到行（适用于以换行符结尾的文本协议）
    // string line = sp.ReadExisting();

    // 处理接收到的数据
    ProcessReceivedData(buffer);
}

// ===== 数据缓冲与协议解析 =====
// 工业设备通信通常需要将数据先缓存，再按协议帧格式解析
private List<byte> receiveBuffer = new List<byte>();

private void ProcessReceivedData(byte[] data)
{
    // 将新数据追加到缓冲区
    receiveBuffer.AddRange(data);

    // 尝试解析完整帧（以Modbus RTU为例）
    while (receiveBuffer.Count >= 5)  // 最小帧长度
    {
        byte slaveAddr = receiveBuffer[0];
        byte functionCode = receiveBuffer[1];

        // 根据功能码判断帧长度
        int frameLength = GetExpectedFrameLength(functionCode, receiveBuffer);
        if (frameLength < 0 || receiveBuffer.Count < frameLength)
            break;  // 数据不够，等待下次接收

        // 提取完整帧
        byte[] completeFrame = receiveBuffer.GetRange(0, frameLength).ToArray();
        receiveBuffer.RemoveRange(0, frameLength);

        // 校验CRC
        if (ValidateCRC(completeFrame))
        {
            // 解析数据
            ParseModbusFrame(completeFrame);
        }
        else
        {
            Console.WriteLine("CRC校验失败，丢弃帧");
        }
    }
}

/// <summary>
/// 根据Modbus功能码计算期望的帧长度
/// </summary>
private int GetExpectedFrameLength(byte funcCode, List<byte> buffer)
{
    return funcCode switch
    {
        0x01 or 0x02 or 0x03 or 0x04 => 3 + buffer[2] + 2,  // 地址+功能码+字节数+数据+CRC
        0x05 or 0x06 => 8,    // 地址+功能码+地址(2)+值(2)+CRC(2)
        0x0F or 0x10 => 8,     // 地址+功能码+起始地址(2)+数量(2)+CRC(2)
        _ => -1
    };
}
```

### 1.6 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 端口占用 | 其他程序已打开该串口 | 关闭占用程序；使用`try-catch`捕获异常 |
| 数据丢失 | 接收缓冲区溢出 | 增大`ReadBufferSize`；及时读取数据 |
| 乱码 | 波特率/数据位/校验位不匹配 | 与设备参数保持完全一致 |
| 只发不收 | 接收线(RX/TX)接反或未接 | 检查接线：TX接RX，RX接TX |
| 接收不全 | 数据帧跨多次事件到达 | 使用缓冲区拼接，等待完整帧再解析 |
| 程序退出后串口无法打开 | 未正确关闭串口 | 使用`using`语句或`Dispose()` |

## 二、代码示例

### 2.1 完整的串口通信封装类

```csharp
using System;
using System.Collections.Generic;
using System.IO.Ports;
using System.Threading;

/// <summary>
/// 串口通信封装类
/// 封装了串口的基本操作：打开、关闭、发送、接收
/// 支持十六进制数据的发送和接收
/// 支持协议帧的缓冲与解析
/// </summary>
public class SerialCommService : IDisposable
{
    private SerialPort _serialPort;
    private readonly List<byte> _receiveBuffer = new List<byte>();
    private readonly object _bufferLock = new object();
    private bool _isRunning = false;

    // ========== 事件定义 ==========
    /// <summary>数据接收完成事件（已解析的完整帧）</summary>
    public event Action<byte[]> OnDataReceived;
    /// <summary>接收原始数据事件（每次触发时收到的原始字节）</summary>
    public event Action<byte[]> OnRawDataReceived;
    /// <summary>串口错误事件</summary>
    public event Action<string> OnError;

    // ========== 属性 ==========
    public string PortName { get; set; } = "COM1";
    public int BaudRate { get; set; } = 9600;
    public int DataBits { get; set; } = 8;
    public StopBits StopBits { get; set; } = StopBits.One;
    public Parity Parity { get; set; } = Parity.None;
    public int ReadTimeout { get; set; } = 500;
    public int WriteTimeout { get; set; } = 500;

    /// <summary>
    /// 初始化SerialPort对象并配置参数
    /// </summary>
    public SerialCommService()
    {
        _serialPort = new SerialPort();
        ConfigureSerialPort();
    }

    public SerialCommService(string portName, int baudRate)
    {
        PortName = portName;
        BaudRate = baudRate;
        _serialPort = new SerialPort();
        ConfigureSerialPort();
    }

    /// <summary>
    /// 根据属性配置SerialPort参数
    /// </summary>
    private void ConfigureSerialPort()
    {
        _serialPort.PortName = PortName;
        _serialPort.BaudRate = BaudRate;
        _serialPort.DataBits = DataBits;
        _serialPort.StopBits = StopBits;
        _serialPort.Parity = Parity;
        _serialPort.ReadTimeout = ReadTimeout;
        _serialPort.WriteTimeout = WriteTimeout;
        _serialPort.ReadBufferSize = 8192;   // 接收缓冲区设大一些
        _serialPort.WriteBufferSize = 4096;
        _serialPort.ReceivedBytesThreshold = 1;
        _serialPort.DtrEnable = true;        // 启用DTR信号
        _serialPort.RtsEnable = true;        // 启用RTS信号
    }

    /// <summary>
    /// 打开串口
    /// </summary>
    public bool Open()
    {
        if (_serialPort.IsOpen) return true;

        try
        {
            _serialPort.Open();
            _serialPort.DataReceived += DataReceivedHandler;
            _isRunning = true;
            Console.WriteLine($"[{PortName}] 串口打开成功 (波特率:{BaudRate})");
            return true;
        }
        catch (UnauthorizedAccessException ex)
        {
            OnError?.Invoke($"串口被占用: {ex.Message}");
            return false;
        }
        catch (IOException ex)
        {
            OnError?.Invoke($"串口不存在: {ex.Message}");
            return false;
        }
        catch (Exception ex)
        {
            OnError?.Invoke($"打开串口失败: {ex.Message}");
            return false;
        }
    }

    /// <summary>
    /// 关闭串口
    /// </summary>
    public void Close()
    {
        if (!_serialPort.IsOpen) return;

        _isRunning = false;
        try
        {
            _serialPort.DataReceived -= DataReceivedHandler;
            _serialPort.Close();
            Console.WriteLine($"[{PortName}] 串口已关闭");
        }
        catch (Exception ex)
        {
            OnError?.Invoke($"关闭串口失败: {ex.Message}");
        }
    }

    /// <summary>
    /// 发送字节数组
    /// </summary>
    public bool SendData(byte[] data)
    {
        if (!_serialPort.IsOpen)
        {
            OnError?.Invoke("串口未打开，无法发送");
            return false;
        }

        try
        {
            _serialPort.Write(data, 0, data.Length);
            Console.WriteLine($"[{PortName}] 发送: {BitConverter.ToString(data)}");
            return true;
        }
        catch (TimeoutException)
        {
            OnError?.Invoke("发送超时");
            return false;
        }
        catch (Exception ex)
        {
            OnError?.Invoke($"发送失败: {ex.Message}");
            return false;
        }
    }

    /// <summary>
    /// 发送十六进制字符串
    /// 例如: SendHexString("01 03 00 00 00 0A C5 CD")
    /// </summary>
    public bool SendHexString(string hexString)
    {
        byte[] data = HexStringToBytes(hexString);
        return SendData(data);
    }

    /// <summary>
    /// 发送字符串
    /// </summary>
    public bool SendString(string text)
    {
        if (!_serialPort.IsOpen)
        {
            OnError?.Invoke("串口未打开，无法发送");
            return false;
        }
        try
        {
            _serialPort.WriteLine(text);
            return true;
        }
        catch (Exception ex)
        {
            OnError?.Invoke($"发送字符串失败: {ex.Message}");
            return false;
        }
    }

    /// <summary>
    /// DataReceived事件处理
    /// 注意：此事件在辅助线程上触发，不可直接更新UI
    /// </summary>
    private void DataReceivedHandler(object sender, SerialDataReceivedEventArgs e)
    {
        try
        {
            int bytesToRead = _serialPort.BytesToRead;
            byte[] buffer = new byte[bytesToRead];
            int actualRead = _serialPort.Read(buffer, 0, bytesToRead);

            // 触发原始数据事件
            OnRawDataReceived?.Invoke(buffer);

            // 加入缓冲区（线程安全）
            lock (_bufferLock)
            {
                _receiveBuffer.AddRange(buffer);
            }

            // 触发数据接收事件
            OnDataReceived?.Invoke(buffer);
        }
        catch (Exception ex)
        {
            OnError?.Invoke($"接收数据异常: {ex.Message}");
        }
    }

    /// <summary>
    /// 从缓冲区获取并清空所有数据
    /// </summary>
    public byte[] GetBufferAndClear()
    {
        lock (_bufferLock)
        {
            byte[] data = _receiveBuffer.ToArray();
            _receiveBuffer.Clear();
            return data;
        }
    }

    /// <summary>
    /// 获取当前缓冲区中的数据（不清空）
    /// </summary>
    public byte[] PeekBuffer()
    {
        lock (_bufferLock)
        {
            return _receiveBuffer.ToArray();
        }
    }

    /// <summary>
    /// 获取可用串口列表
    /// </summary>
    public static string[] GetAvailablePorts()
    {
        return SerialPort.GetPortNames();
    }

    /// <summary>
    /// 十六进制字符串 -> 字节数组
    /// </summary>
    public static byte[] HexStringToBytes(string hexString)
    {
        hexString = hexString.Replace(" ", "").Replace("-", "").Replace("0x", "");
        if (hexString.Length % 2 != 0)
            throw new ArgumentException("十六进制字符串长度必须为偶数");

        byte[] bytes = new byte[hexString.Length / 2];
        for (int i = 0; i < bytes.Length; i++)
        {
            bytes[i] = Convert.ToByte(hexString.Substring(i * 2, 2), 16);
        }
        return bytes;
    }

    /// <summary>
    /// 字节数组 -> 十六进制字符串
    /// </summary>
    public static string BytesToHexString(byte[] bytes, string separator = " ")
    {
        return BitConverter.ToString(bytes).Replace("-", separator);
    }

    public void Dispose()
    {
        Close();
        _serialPort?.Dispose();
    }
}
```

### 2.2 上位机场景案例：通过串口与PLC Modbus RTU通信

```csharp
using System;
using System.Threading;

/// <summary>
/// 上位机串口通信案例：通过RS485串口读取PLC的Modbus RTU数据
/// 场景：上位机通过USB转RS485读取汇川/西门子PLC的保持寄存器数据
/// </summary>
public class ModbusRtuSerialExample
{
    private SerialCommService _serial;

    public void Run()
    {
        // ====== 第一步：创建并打开串口 ======
        _serial = new SerialCommService("COM3", 9600);
        _serial.OnDataReceived += OnDataReceived;
        _serial.OnError += (msg) => Console.WriteLine($"[错误] {msg}");

        if (!_serial.Open())
        {
            Console.WriteLine("串口打开失败，请检查连接");
            return;
        }

        // ====== 第二步：发送Modbus RTU读请求 ======
        // 读取从站地址01的保持寄存器，起始地址0x0000，读取10个寄存器
        // 功能码03 = 读保持寄存器
        byte slaveAddr = 0x01;
        byte funcCode = 0x03;
        ushort startAddr = 0x0000;
        ushort quantity = 0x000A;

        byte[] request = BuildReadHoldingRegistersRequest(
            slaveAddr, startAddr, quantity);

        Console.WriteLine("发送Modbus RTU请求...");
        _serial.SendData(request);

        // ====== 第三步：等待响应并解析 ======
        Thread.Sleep(1000);  // 等待设备响应

        // ====== 第四步：关闭串口 ======
        _serial.Close();
    }

    /// <summary>
    /// 构造Modbus RTU读保持寄存器请求帧
    /// 帧结构：[从站地址][功能码][起始地址高][起始地址低][数量高][数量低][CRC低][CRC高]
    /// </summary>
    private byte[] BuildReadHoldingRegistersRequest(
        byte slaveAddr, ushort startAddr, ushort quantity)
    {
        byte[] frame = new byte[8];
        frame[0] = slaveAddr;                          // 从站地址
        frame[1] = 0x03;                               // 功能码：读保持寄存器
        frame[2] = (byte)(startAddr >> 8);              // 起始地址高字节
        frame[3] = (byte)(startAddr & 0xFF);           // 起始地址低字节
        frame[4] = (byte)(quantity >> 8);               // 数量高字节
        frame[5] = (byte)(quantity & 0xFF);             // 数量低字节

        // 计算CRC16校验码
        ushort crc = CalculateCRC16(frame, 0, 6);
        frame[6] = (byte)(crc & 0xFF);                 // CRC低字节
        frame[7] = (byte)((crc >> 8) & 0xFF);          // CRC高字节

        return frame;
    }

    /// <summary>
    /// Modbus CRC16校验计算
    /// </summary>
    private ushort CalculateCRC16(byte[] data, int offset, int length)
    {
        ushort crc = 0xFFFF;
        for (int i = offset; i < offset + length; i++)
        {
            crc ^= data[i];
            for (int j = 0; j < 8; j++)
            {
                if ((crc & 0x0001) != 0)
                {
                    crc >>= 1;
                    crc ^= 0xA001;
                }
                else
                {
                    crc >>= 1;
                }
            }
        }
        return crc;
    }

    /// <summary>
    /// 数据接收回调：解析Modbus RTU响应帧
    /// 响应帧结构：[从站地址][功能码][字节数][数据...][CRC低][CRC高]
    /// </summary>
    private void OnDataReceived(byte[] data)
    {
        Console.WriteLine($"收到响应: {SerialCommService.BytesToHexString(data)}");

        if (data.Length < 5) return;

        byte slaveAddr = data[0];
        byte funcCode = data[1];

        // 检查异常响应（功能码最高位为1表示异常）
        if ((funcCode & 0x80) != 0)
        {
            byte exceptionCode = data[2];
            Console.WriteLine($"Modbus异常响应，异常码: 0x{exceptionCode:X2}");
            return;
        }

        byte byteCount = data[2];  // 返回的数据字节数

        // 解析寄存器值（每个寄存器2字节，高字节在前）
        Console.WriteLine($"从站{slaveAddr} 返回{byteCount / 2}个寄存器值:");
        for (int i = 0; i < byteCount; i += 2)
        {
            if (i + 3 < data.Length)
            {
                ushort value = (ushort)((data[3 + i] << 8) | data[4 + i]);
                ushort regAddr = (ushort)(0 + i / 2);
                Console.WriteLine($"  寄存器[{regAddr}] = {value} (0x{value:X4})");
            }
        }
    }
}
```

## 三、注意事项

1. **线程安全**：`DataReceived` 事件在非UI线程触发，如果需要更新WinForms/WPF界面，必须使用 `Invoke` 或 `Dispatcher.Invoke`。
2. **资源释放**：串口是独占资源，务必在程序退出前关闭。推荐使用 `using` 语句或实现 `IDisposable`。
3. **波特率匹配**：串口通信双方（上位机和设备）的波特率、数据位、停止位、校验位必须完全一致，否则会导致乱码。
4. **数据缓冲**：串口数据可能分多次到达（一帧数据被拆成多个`DataReceived`事件），必须使用缓冲区拼接完整帧后再解析。
5. **485收发切换**：使用RS485时，设备在发送和接收之间需要切换方向。有些USB转485模块可以自动切换，有些需要软件控制RTS信号。
6. **USB转串口延迟**：USB转串口设备可能存在毫秒级延迟，不适合超高频通信（如 >1000Hz）。
7. **COM口号变化**：USB转串口设备的COM口号可能在插拔后变化，建议通过设备描述（VID/PID）来识别，而非硬编码COM号。

## 五、常见错误

### 错误1：跨线程访问UI控件
```
错误信息：System.InvalidOperationException: 跨线程操作无效
```
**原因**：在 `DataReceived` 事件中直接操作UI控件。
**解决**：
```csharp
// WinForms:
this.Invoke((MethodInvoker)delegate {
    textBox1.AppendText(text);
});

// WPF:
Application.Current.Dispatcher.Invoke(() => {
    textBox1.AppendText(text);
});
```

### 错误2：串口被占用
```
错误信息：UnauthorizedAccessException: 对端口“COM3”的访问被拒绝
```
**原因**：其他程序已经打开了该串口，或上次程序未正确关闭。
**解决**：关闭占用程序；在`Dispose`/`FormClosing`中确保调用`serialPort.Close()`。

### 错误3：接收数据不完整
**现象**：收到的数据只有一部分，帧被截断。
**原因**：数据到达速度和程序处理速度不匹配，或一次`DataReceived`事件只包含了部分帧。
**解决**：使用接收缓冲区，等凑齐完整一帧再解析。

### 错误4：发送数据后立刻读取没有数据
**原因**：串口通信有传输延迟，设备需要处理时间。
**解决**：在发送后添加适当延迟，或使用事件方式接收而非同步读取。

### 错误5：.NET Core/.NET 5+ 中找不到 SerialPort
**原因**：需要安装 NuGet 包 `System.IO.Ports`。
**解决**：
```
dotnet add package System.IO.Ports
```

### 错误6：程序退出后COM口无法打开
**原因**：串口未正确释放资源，系统仍认为该端口被占用。
**解决**：确保在程序退出前调用`Close()`和`Dispose()`；必要时拔插USB设备。
