# 04 - 部署与打包

> 本文讲解上位机项目的发布、部署和打包技术，帮助你将开发好的程序可靠地交付给最终用户。

---

## 一、知识讲解

### 1.1 Release vs Debug 发布

| 对比项 | Debug模式 | Release模式 |
|--------|-----------|-------------|
| **编译优化** | 不优化，便于调试 | 启用优化（代码内联、常量折叠等） |
| **调试信息** | 包含完整的调试符号（PDB文件） | 不包含或精简调试信息 |
| **代码检查** | 不检查边界、溢出等 | 启用更严格的检查 |
| **运行速度** | 较慢 | 更快（通常提升20%-50%） |
| **文件大小** | 较大 | 较小 |
| **适用场景** | 开发和调试阶段 | **正式发布给用户** |

> **重要：正式发布必须使用Release模式！** Debug模式不仅运行慢，还可能包含敏感的调试信息。

### 1.2 .NET Framework版本选择

| 版本 | 发布年份 | 支持系统 | 推荐度 |
|------|----------|----------|--------|
| .NET Framework 4.0 | 2010 | Win7+ | 过时，不推荐 |
| .NET Framework 4.5 | 2012 | Win7 SP1+ | 可用 |
| .NET Framework 4.6 | 2015 | Win7 SP1+ | 可用 |
| .NET Framework 4.7 | 2017 | Win7 SP1+ | 推荐 |
| **.NET Framework 4.8** | **2019** | **Win7 SP1+/Win10/Win11** | **强烈推荐** |
| .NET 6/7/8 (Core) | 2021+ | 跨平台 | 新项目推荐 |

> **上位机推荐使用 .NET Framework 4.8**：工控电脑（Windows 7/10）兼容性最好，WinForms支持最完善。

### 1.3 部署方式对比

| 部署方式 | 说明 | 优点 | 缺点 | 推荐场景 |
|----------|------|------|------|----------|
| **安装包** | 用安装工具制作Setup.exe | 专业体验、可选安装路径、创建快捷方式 | 需要制作安装脚本 | **正式交付用户** |
| **ClickOnce** | 微软的部署技术 | 自动更新、一键安装 | 灵活性差、配置繁琐 | 内部使用的小工具 |
| **绿色版** | 解压即用的ZIP包 | 简单快速、便于U盘拷贝 | 无注册表、无卸载程序 | 现场临时部署 |
| **便携版** | 单个EXE文件（ILMerge） | 最简单，一个文件搞定 | 文件较大、启动稍慢 | 小型工具 |

### 2.2 发布前的检查清单

```csharp
// ============================================================
// 文件：PreReleaseCheck.cs
// 说明：发布前检查器 - 程序启动时自动检查发布环境
// ============================================================
namespace HwPlcMonitor.UI
{
    /// <summary>
    /// 发布前检查器
    /// 在程序启动时检查运行环境是否满足要求
    /// </summary>
    public static class PreReleaseChecker
    {
        public static List<string> CheckAll()
        {
            var issues = new List<string>();

            // 1. 检查.NET Framework版本
            issues.AddRange(CheckDotNetVersion());

            // 2. 检查管理员权限
            if (!CheckAdminPermission())
                issues.Add("建议以管理员权限运行（数据库写入可能需要权限）");

            // 3. 检查磁盘空间
            issues.AddRange(CheckDiskSpace());

            // 4. 检查配置文件
            issues.AddRange(CheckConfigFiles());

            // 5. 检查数据库文件
            issues.AddRange(CheckDatabase());

            return issues;
        }

        /// <summary>检查.NET Framework版本</summary>
        private static List<string> CheckDotNetVersion()
        {
            var issues = new List<string>();
            // 获取已安装的.NET Framework版本
            var version = Environment.Version;
            if (version.Major < 4 || (version.Major == 4 && version.Minor < 7))
            {
                issues.Add($"需要.NET Framework 4.7+，当前版本: {version}");
            }
            return issues;
        }

        /// <summary>检查是否有管理员权限</summary>
        private static bool CheckAdminPermission()
        {
            try
            {
                var identity = WindowsIdentity.GetCurrent();
                var principal = new WindowsPrincipal(identity);
                return principal.IsInRole(WindowsBuiltInRole.Administrator);
            }
            catch
            {
                return false;
            }
        }

        /// <summary>检查磁盘空间</summary>
        private static List<string> CheckDiskSpace()
        {
            var issues = new List<string>();
            var drive = new DriveInfo(AppDomain.CurrentDomain.BaseDirectory);
            if (drive.AvailableFreeSpace < 500 * 1024 * 1024) // 500MB
                issues.Add("磁盘可用空间不足500MB，数据库和日志可能导致磁盘写满");
            return issues;
        }

        // ... 其他检查方法省略
    }
}
```

### 2.3 Inno Setup 安装包制作

```pascal
; ============================================================
; 文件：HwPlcMonitorSetup.iss
; 说明：Inno Setup安装脚本
; 需要先安装 Inno Setup (https://jrsoftware.org/isinfo.php)
; ============================================================

#define MyAppName "汇川PLC监控系统"
#define MyAppVersion "1.0.0"
#define MyAppPublisher "XXX公司"
#define MyAppExeName "HwPlcMonitor.exe"

[Setup]
; 应用基本信息
AppId={{A1B2C3D4-E5F6-7890-ABCD-EF1234567890}
AppName={#MyAppName}
AppVersion={#MyAppVersion}
AppPublisher={#MyAppPublisher}

; 安装目录
DefaultDirName={autopf}\{#MyAppName}
DefaultGroupName={#MyAppName}
OutputDir=installer_output
OutputBaseFilename=HwPlcMonitor_Setup_{#MyAppVersion}
Compression=lzma2              ; 使用LZMA2压缩（更小）
SolidCompression=yes
WizardStyle=modern              ; 现代安装向导样式

; 权限要求
PrivilegesRequired=admin        ; 需要管理员权限

; 架构
ArchitecturesAllowed=x64compatible
ArchitecturesInstallIn64BitMode=x64compatible

[Languages]
Name="chinesesimplified"; MessagesFile="compiler:Languages\ChineseSimplified.isl"

[Tasks]
Name="desktopicon"; Description="创建桌面快捷方式"; Flags:checked

[Files]
; 主程序文件
Source: "..\src\HwPlcMonitor.UI\bin\Release\*"; DestDir: "{app}"; Flags: ignoreversion recursesubdirs createallsubdirs

; 配置文件（如果用户已有配置，不要覆盖）
Source: "..\src\HwPlcMonitor.UI\bin\Release\appsettings.json"; DestDir: "{app}"; Flags: onlyifdoesntexist

; 注意: 不打包Source文件和pdb文件

[Icons]
Name: "{group}\{#MyAppName}"; Filename: "{app}\{#MyAppExeName}"
Name: "{autodesktop}\{#MyAppName}"; Filename: "{app}\{#MyAppExeName}"; Tasks: desktopicon

[Run]
; 安装完成后运行程序（可选）
Filename: "{app}\{#MyAppExeName}"; Description: "安装完成后启动程序"; Flags: postinstall nowait skipifsilent

[UninstallDelete]
; 卸载时保留数据文件（不删除用户数据）
Type: filesandordirs; Name: "{app}\data"; Check: not IsTaskSelected('purge_data')
Type: filesandordirs; Name: "{app}\logs"; Check: not IsTaskSelected('purge_data')
Type: filesandordirs; Name: "{app}\backup"; Check: not IsTaskSelected('purge_data')

[Code]
// 自定义卸载页面：询问是否删除数据文件
procedure CurUninstallStepChanged(CurUninstallStep: TUninstallStep);
begin
  if CurUninstallStep = usPostUninstall then
  begin
    if MsgBox('是否同时删除数据文件和日志文件？' + #13#10 + '选择"是"将删除所有数据，不可恢复。',
      mbConfirmation, MB_YESNO) = IDYES then
    begin
      DelTree(ExpandConstant('{app}\data'), True, True, True);
      DelTree(ExpandConstant('{app}\logs'), True, True, True);
      DelTree(ExpandConstant('{app}\backup'), True, True, True);
    end;
  end;
end;
```

**制作安装包的步骤：**

```
1. 编译Release版本
   Visual Studio -> 生成 -> 配置管理器 -> Release -> 生成解决方案

2. 复制发布文件到临时目录
   将 bin\Release\ 下的所有文件复制到一个临时目录

3. 编写Inno Setup脚本
   根据上面的模板修改路径和名称

4. 编译安装包
   Inno Setup -> 打开脚本 -> 编译 -> 生成Setup.exe

5. 测试安装包
   在干净的Windows系统上测试安装、运行、卸载
```

### 2.4 NSIS 安装包制作（备选方案）

```nsi
; ============================================================
; 文件：HwPlcMonitor.nsi
; 说明：NSIS安装脚本（备选方案）
; 需要安装 NSIS (https://nsis.sourceforge.io/)
; ============================================================

!include "MUI2.nsh"

; 应用名称和版本
!define PRODUCT_NAME "汇川PLC监控系统"
!define PRODUCT_VERSION "1.0.0"
!define PRODUCT_PUBLISHER "XXX公司"
!define PRODUCT_EXE "HwPlcMonitor.exe"

; 输出配置
OutFile "HwPlcMonitor_Setup_${PRODUCT_VERSION}.exe"
InstallDir "$PROGRAMFILES64\${PRODUCT_NAME}"
InstallDirRegKey HKLM "Software\${PRODUCT_NAME}" "InstallDir"
RequestExecutionLevel admin

; 现代UI配置
!define MUI_ICON "app.ico"
!define MUI_UNICON "app.ico"
!define MUI_HEADERIMAGE
!define MUI_ABORTWARNING

; 安装页面
!insertmacro MUI_PAGE_DIRECTORY
!insertmacro MUI_PAGE_INSTFILES
!insertmacro MUI_UNPAGE_CONFIRM
!insertmacro MUI_UNPAGE_INSTFILES

; 语言
!insertmacro MUI_LANGUAGE "SimpChinese"

Section "主程序"
    SetOutPath "$INSTDIR"

    ; 复制所有发布文件
    File /r "bin\Release\*.*"

    ; 创建卸载程序
    WriteUninstaller "$INSTDIR\Uninstall.exe"

    ; 创建开始菜单快捷方式
    CreateDirectory "$SMPROGRAMS\${PRODUCT_NAME}"
    CreateShortCut "$SMPROGRAMS\${PRODUCT_NAME}\${PRODUCT_NAME}.lnk" "$INSTDIR\${PRODUCT_EXE}"
    CreateShortCut "$DESKTOP\${PRODUCT_NAME}.lnk" "$INSTDIR\${PRODUCT_EXE}"

    ; 写入注册表
    WriteRegStr HKLM "Software\${PRODUCT_NAME}" "InstallDir" "$INSTDIR"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "DisplayName" "${PRODUCT_NAME}"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "UninstallString" "$INSTDIR\Uninstall.exe"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "DisplayVersion" "${PRODUCT_VERSION}"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "Publisher" "${PRODUCT_PUBLISHER}"
SectionEnd

Section "Uninstall"
    ; 删除文件
    RMDir /r "$INSTDIR\data"
    RMDir /r "$INSTDIR\logs"
    RMDir /r "$INSTDIR\backup"
    Delete "$INSTDIR\*.*"
    RMDir "$INSTDIR"

    ; 删除快捷方式
    Delete "$SMPROGRAMS\${PRODUCT_NAME}\*.*"
    RMDir "$SMPROGRAMS\${PRODUCT_NAME}"
    Delete "$DESKTOP\${PRODUCT_NAME}.lnk"

    ; 删除注册表
    DeleteRegKey HKLM "Software\${PRODUCT_NAME}"
    DeleteRegKey HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}"
SectionEnd
```

## 三、注意事项

### 3.1 发布前必做检查

| 检查项 | 说明 | 方法 |
|--------|------|------|
| **切换到Release模式** | 确保使用Release编译 | Visual Studio顶部切换 |
| **更新版本号** | AssemblyVersion和FileVersion | AssemblyInfo.cs |
| **清理临时文件** | 删除bin/obj中的旧文件 | 清理解决方案 |
| **关闭调试代码** | 移除Console.WriteLine、断点 | 全局搜索 |
| **检查配置文件** | 确保默认配置适用于生产环境 | appsettings.json |
| **检查数据库初始化** | 首次运行能正确创建数据库 | 在干净环境测试 |
| **日志目录权限** | 确保有写入日志的权限 | 在目标机器测试 |
| **杀毒软件白名单** | 某些杀毒软件可能误报 | 提前测试 |

### 3.2 常见部署问题及解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 程序启动闪退 | 缺少.NET Framework | 安装对应版本的.NET Framework |
| 缺少DLL文件 | NuGet包没有正确复制 | 检查输出目录，手动复制缺失的DLL |
| 数据库访问报错 | 没有写入权限 | 给程序目录授予写入权限 |
| 串口打不开 | COM口被占用或权限不足 | 以管理员权限运行 |
| 配置读取失败 | 配置文件路径不对 | 使用绝对路径或AppDomain.BaseDirectory |
| 中文乱码 | 文件编码不是UTF-8 | 统一使用UTF-8编码 |
| 安装包过大 | 包含了不必要的文件 | 清理bin目录，排除pdb和xml |

## 四、实战案例

### 案例：上位机部署完整流程

**场景：将汇川PLC监控系统部署到工厂的工控电脑**

```
部署步骤：

第1步：发布准备
  ├── 切换到Release模式编译
  ├── 更新版本号为 1.0.0
  ├── 清理解决方案，重新生成
  └── 运行程序进行功能验证

第2步：制作安装包
  ├── 编写Inno Setup脚本
  ├── 编译生成 HwPlcMonitor_Setup_1.0.0.exe
  └── 在测试电脑上验证安装和卸载

第3步：现场部署
  ├── 检查工控电脑环境（Windows版本、.NET Framework）
  ├── 安装 .NET Framework 4.8（如果尚未安装）
  ├── 运行安装包
  ├── 修改配置文件（PLC的IP地址、采集周期等）
  └── 启动程序，测试PLC连接

第4步：部署验证
  ├── 检查PLC连接是否正常
  ├── 检查数据采集是否正常
  ├── 检查数据保存是否正常
  ├── 检查报警功能是否正常
  ├── 检查日志记录是否正常
  └── 检查数据库备份是否正常

第5步：交付文档
  ├── 使用说明文档
  ├── 故障排除指南
  └── 配置文件说明
```

> **提示**：部署是软件开发的最后一环，也是用户对软件的第一印象。一个好的安装包和规范的部署流程，能大大降低现场调试的工作量。建议在开发阶段就考虑部署问题，如使用相对路径、统一编码、不硬编码路径等。每次发布都要记录版本变更内容，方便后续追溯。
