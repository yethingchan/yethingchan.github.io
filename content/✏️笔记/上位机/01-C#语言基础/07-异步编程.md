## 1. 为什么需要异步

### 1.1 线程阻塞与界面卡顿

在上位机开发中，最常见的问题就是**通信阻塞导致界面卡顿**。当你在主线程（UI线程）上执行耗时的通信操作时，整个界面会冻结，用户无法进行任何操作。

```
同步调用的问题：

时间轴（主线程 = UI线程）:
  ┌────────────┬─────────────────────────┬──────────┐
  │ 点击按钮   │ 等待PLC响应(阻塞3秒)    │ 更新界面 │
  │ (50ms)    │                          │ (50ms)  │
  └────────────┴─────────────────────────┴──────────┘
  ↑              ↑                        ↑
  界面冻结开始   用户无法操作任何东西      界面才恢复
                鼠标点不动、按钮无响应
                看起来就像"死机"了


异步调用的好处：

时间轴（主线程 = UI线程）:
  ┌────────────┬────────────────────────────────────┐
  │ 点击按钮   │ 主线程继续响应用户操作               │
  │ (50ms)    │ 可以点击其他按钮、拖动窗口            │
  └────────────┼────────────────────────────────────┤
               │ （通信在后台线程完成）               │
  ┌────────────┼─────────────────────┐              │
  │ PLC通信线程│ 通信完成，通知UI更新  │              │
  │ (3000ms)  │ (回调/await)         │              │
  └────────────┴─────────────────────┘              │
  ↑                                                   ↑
  后台线程独立运行              通信完成后回到主线程更新UI
```

### 1.2 同步与异步的代码对比

```csharp
using System;
using System.Threading;

public class SyncVsAsyncDemo
{
    /// <summary>
    /// 同步方式：读取PLC数据（会阻塞UI线程）
    /// </summary>
    public double ReadPlcSync(string address)
    {
        // 模拟PLC通信耗时3秒
        Thread.Sleep(3000);  // ← 这里UI线程被阻塞，界面冻结3秒！

        double value = 25.5;
        return value;
    }

    /// <summary>
    /// 异步方式：读取PLC数据（不阻塞UI线程）
    /// </summary>
    public async Task<double> ReadPlcAsync(string address)
    {
        // await 会让当前方法"暂停"，控制权返回给调用者（UI线程恢复响应）
        // 后台线程执行实际的耗时操作
        await Task.Delay(3000);  // ← UI线程不阻塞，界面保持流畅！

        double value = 25.5;
        return value;
    }
}

/// <summary>
    /// 模拟WinForms界面
    /// </summary>
public class SimulatedForm
{
    public SimulatedForm()
    {
        _button.Click += OnButtonClicked;
    }

    private SimpleButton _button = new SimpleButton { Text = "读取PLC" };

    // ========================
    // 错误方式：同步调用
    // ========================
    private void OnButtonClicked_Wrong(object sender, EventArgs e)
    {
        Console.WriteLine("=== 同步方式（界面会卡顿）===");

        var demo = new SyncVsAsyncDemo();

        // 注意：这个方法运行在UI线程上
        // Thread.Sleep(3000) 会阻塞UI线程3秒
        // 界面在这3秒内完全无法操作！
        double value = demo.ReadPlcSync("D100");

        Console.WriteLine($"读取结果: {value}");
    }

    // ========================
    // 正确方式：异步调用
    // ========================
    private async void OnButtonClicked(object sender, EventArgs e)
    {
        Console.WriteLine("=== 异步方式（界面不卡顿）===");

        var demo = new SyncVsAsyncDemo();

        // await 将耗时操作放到后台线程
        // UI线程保持响应，用户可以继续操作
        double value = await demo.ReadPlcAsync("D100");

        // await 之后的代码自动回到UI线程执行
        Console.WriteLine($"读取结果: {value}");
    }
}

// 简化按钮
public class SimpleButton
{
    public string Text { get; set; }
    public event EventHandler Click;
    public void PerformClick() => Click?.Invoke(this, EventArgs.Empty);
}

public class WhyAsyncDemo
{
    public static void Main()
    {
        Console.WriteLine("=== 同步 vs 异步演示 ===\n");

        var form = new SimulatedForm();

        // 同步方式演示
        Console.WriteLine("[主线程] 开始同步读取...");
        var syncDemo = new SyncVsAsyncDemo();

        // 模拟：在主线程同步执行（界面冻结）
        DateTime start = DateTime.Now;
        double result = syncDemo.ReadPlcSync("D100");
        Console.WriteLine($"[主线程] 同步读取完成，耗时: {(DateTime.Now - start).TotalMilliseconds:F0}ms");
        Console.WriteLine($"[主线程] 结果: {result}\n");

        // 异步方式演示
        Console.WriteLine("[主线程] 开始异步读取...");
        var asyncDemo = new SyncVsAsyncDemo();
        Task.Run(async () =>
        {
            DateTime start2 = DateTime.Now;
            double result2 = await asyncDemo.ReadPlcAsync("D100");
            Console.WriteLine($"[后台] 异步读取完成，耗时: {(DateTime.Now - start2).TotalMilliseconds:F0}ms");
            Console.WriteLine($"[后台] 结果: {result2}");
        });

        Console.WriteLine("[主线程] 异步调用已发出，主线程继续执行其他任务...");
        Thread.Sleep(4000);  // 等待异步完成
    }
}
```

## 2. Task 基础

### 2.1 Task 是什么

`Task` 是 .NET 中表示异步操作的类，位于 `System.Threading.Tasks` 命名空间下。你可以把 Task 理解为一个"未来会完成的任务"。

```
Task 的核心概念：

Task                    → 表示一个没有返回值的异步操作
Task<TResult>          → 表示一个会返回 TResult 类型值的异步操作

Task 状态机：
  Created（已创建）
    → WaitingForActivation（等待启动）
    → Running（正在执行）
    → RanToCompletion（成功完成）或 Faulted（失败）或 Canceled（已取消）
```

### 2.2 Task 的创建和运行

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

public class TaskBasicDemo
{
    public void Run()
    {
        // ========================
        // 1. Task.Run — 最常用的创建方式
        // 将工作放到线程池线程上执行
        // ========================

        // Task.Run(Action) — 无返回值
        Task task1 = Task.Run(() =>
        {
            // 这个代码在线程池线程上执行
            Console.WriteLine($"  Task1 线程ID: {Thread.CurrentThread.ManagedThreadId}");
            Thread.Sleep(1000);
            Console.WriteLine("  Task1 完成: 模拟PLC通信");
        });

        // Task.Run(Func<TResult>) — 有返回值
        Task<double> task2 = Task.Run(() =>
        {
            Console.WriteLine($"  Task2 线程ID: {Thread.CurrentThread.ManagedThreadId}");
            Thread.Sleep(500);
            return 25.5;  // 返回值
        });

        // ========================
        // 2. Task.Wait — 等待任务完成
        // ========================

        Console.WriteLine("等待 Task1 完成...");
        task1.Wait();  // 阻塞当前线程直到 Task1 完成

        Console.WriteLine("等待 Task2 完成...");
        task2.Wait();  // 阻塞当前线程直到 Task2 完成

        // 获取 Task 的返回值（Result 属性会自动等待）
        double result = task2.Result;
        Console.WriteLine($"Task2 返回值: {result}\n");

        // ========================
        // 3. Task.WaitAll — 等待多个任务全部完成
        // ========================

        Console.WriteLine("--- Task.WaitAll ---");

        Task t1 = Task.Run(() =>
        {
            Thread.Sleep(1000);
            Console.WriteLine("  PLC-001 读取完成");
        });

        Task t2 = Task.Run(() =>
        {
            Thread.Sleep(2000);
            Console.WriteLine("  PLC-002 读取完成");
        });

        Task t3 = Task.Run(() =>
        {
            Thread.Sleep(1500);
            Console.WriteLine("  PLC-003 读取完成");
        });

        // 等待所有任务完成（总耗时约2秒，而不是1+2+1.5=4.5秒）
        Task.WaitAll(t1, t2, t3);
        Console.WriteLine("所有PLC读取完成\n");

        // ========================
        // 4. Task.WaitAny — 等待任意一个完成
        // ========================

        Console.WriteLine("--- Task.WaitAny ---");

        Task<string> fast = Task.Run(() =>
        {
            Thread.Sleep(1000);
            return "PLC-001";
        });

        Task<string> slow = Task.Run(() =>
        {
            Thread.Sleep(3000);
            return "PLC-002";
        });

        // 等待第一个完成的任务
        int index = Task.WaitAny(fast, slow);
        Console.WriteLine($"第一个完成的任务索引: {index}");
        Console.WriteLine($"第一个完成的PLC: {fast.Result}\n");

        // ========================
        // 5. Task.WhenAll — 异步等待所有任务（不阻塞线程）
        // ========================

        Console.WriteLine("--- Task.WhenAll ---");

        Task WhenAllDemo()
        {
            Task<double>[] readTasks = new[]
            {
                Task.Run(() => { Thread.Sleep(500); return 25.5; }),
                Task.Run(() => { Thread.Sleep(800); return 30.0; }),
                Task.Run(() => { Thread.Sleep(300); return 18.3; }),
            };

            // WhenAll 返回一个 Task，可以用 await 等待
            // 不会阻塞当前线程！
            return Task.WhenAll(readTasks);
        }

        Task allTask = WhenAllDemo();
        allTask.Wait();

        Console.WriteLine("所有异步读取完成\n");

        // ========================
        // 6. Task.WhenAny — 异步等待任意一个完成
        // ========================

        Console.WriteLine("--- Task.WhenAny ---");

        Task<Task<double>> anyTask = Task.WhenAny(
            Task.Run(() => { Thread.Sleep(200); return 100.0; }),
            Task.Run(() => { Thread.Sleep(500); return 200.0; })
        );

        var completedTask = anyTask.Result;
        Console.WriteLine($"最快完成的值: {completedTask.Result}\n");
    }
}
```

### 2.3 Task 的异常处理

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

public class TaskExceptionDemo
{
    public void Run()
    {
        // ========================
        // 1. Task 中的异常不会直接抛出
        // ========================

        Task faultedTask = Task.Run(() =>
        {
            throw new InvalidOperationException("PLC通信失败");
        });

        // 异常不会在这里抛出！Task内部记录了异常
        Thread.Sleep(100);

        // 异常只在以下情况下才会抛出：
        // a) 调用 .Wait()
        // b) 调用 .Result
        // c) 使用 await

        try
        {
            faultedTask.Wait();  // 这里才会抛出异常
        }
        catch (AggregateException ex)
        {
            // Task 的异常被包装在 AggregateException 中
            Console.WriteLine($"异常数量: {ex.InnerExceptions.Count}");
            Console.WriteLine($"内部异常: {ex.InnerExceptions[0].Message}");
        }

        // ========================
        // 2. 使用 await 获取异常（推荐）
        // ========================

        Task RunWithAwait()
        {
            return DoWorkAsync();
        }

        async Task DoWorkAsync()
        {
            try
            {
                await Task.Run(() =>
                {
                    throw new TimeoutException("PLC响应超时");
                });
            }
            catch (TimeoutException ex)
            {
                // 使用 await 时，异常不会被包装在 AggregateException 中
                // 直接捕获到原始异常类型
                Console.WriteLine($"await捕获异常: {ex.GetType().Name} - {ex.Message}");
            }
        }

        RunWithAwait().Wait();

        // ========================
        // 3. Task.WhenAll 中的多个异常
        // ========================

        Console.WriteLine("\n--- WhenAll 多个异常 ---");

        Task task1 = Task.Run(() => throw new TimeoutException("PLC-001超时"));
        Task task2 = Task.Run(() => throw new FormatException("PLC-002格式错误"));
        Task task3 = Task.Run(() => { Thread.Sleep(100); });  // 成功

        try
        {
            Task.WaitAll(task1, task2, task3);
        }
        catch (AggregateException ex)
        {
            // WhenAll 收集了所有任务的异常
            Console.WriteLine($"总异常数: {ex.InnerExceptions.Count}");
            foreach (var inner in ex.InnerExceptions)
            {
                Console.WriteLine($"  - {inner.GetType().Name}: {inner.Message}");
            }
        }
    }
}
```

## 3. async/await 语法详解

### 3.1 基本语法

`async` 和 `await` 是 C# 5.0 引入的语法糖，极大简化了异步编程的复杂度。

```
async/await 工作原理：

编译器将 async 方法转换为一个状态机：

  async Task<double> ReadPlcAsync()
  {
      // 阶段1
      double raw = await ReadRawDataAsync();
      // 阶段2（await之后）
      double result = ProcessData(raw);
      // 阶段3
      return result;
  }

编译器生成的状态机（简化）：
  ┌───────────────────┐
  │ 进入方法          │ → 执行阶段1代码
  │ 遇到 await       │ → 如果任务未完成，保存状态，返回Task给调用者
  └───────┬───────────┘
          │ 任务完成后回调
  ┌───────▼───────────┐
  │ 恢复状态          │ → 在原来的上下文中执行阶段2代码
  │ 遇到 return      │ → 设置Task的Result，标记完成
  └───────────────────┘
```

### 3.2 async 方法的各种返回值

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

public class AsyncReturnTypesDemo
{
    // ========================
    // 1. async Task — 无返回值的异步方法
    // 等价于同步方法中的 void
    // ========================

    /// <summary>
    /// 异步写入PLC数据（无返回值）
    /// </summary>
    public async Task WritePlcDataAsync(string address, double value)
    {
        // await 前的代码：在调用者线程执行
        Console.WriteLine($"准备写入 {address}...");

        // await：将后续代码放到后台执行或等待完成后回到原线程
        await Task.Delay(500);  // 模拟通信

        // await 后的代码：
        // 如果有同步上下文（如UI线程），会自动回到原线程执行
        Console.WriteLine($"写入完成 {address} = {value}");
    }

    // ========================
    // 2. async Task<TResult> — 有返回值的异步方法
    // 等价于同步方法中的 TResult
    // ========================

    /// <summary>
    /// 异步读取PLC数据（返回 double）
    /// </summary>
    public async Task<double> ReadPlcDataAsync(string address)
    {
        Console.WriteLine($"开始读取 {address}...");

        // 模拟耗时通信操作
        await Task.Delay(1000);

        // 返回读取到的值
        return 25.5;
    }

    // ========================
    // 3. async void — 事件处理器专用
    // 注意：async void 只能用于事件处理器！
    // 不能被 await 等待，异常会导致程序崩溃
    // ========================

    /// <summary>
    /// 按钮点击事件处理器（async void 是合法的）
    /// </summary>
    public async void OnReadButtonClicked(object sender, EventArgs e)
    {
        try
        {
            double value = await ReadPlcDataAsync("D100");
            Console.WriteLine($"读取到值: {value}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"读取失败: {ex.Message}");
        }
    }

    // ========================
    // 4. 同步上下文与 ConfigureAwait
    // ========================

    /// <summary>
    /// 使用 ConfigureAwait(false) 避免捕获同步上下文
    /// 在上位机库代码中推荐使用，避免死锁
    /// </summary>
    public async Task<double> ReadPlcNoContextAsync(string address)
    {
        Console.WriteLine($"读取 {address}（线程ID: {Thread.CurrentThread.ManagedThreadId}）");

        // ConfigureAwait(false) 表示不回到原始的同步上下文
        // 好处：
        // 1. 避免在库代码中捕获UI上下文导致死锁
        // 2. 性能稍好（不需要切换回原线程）
        // 坏处：
        // 1. await 之后的代码不保证在原线程执行
        //    如果要更新UI，需要手动 Invoke
        double value = await Task.Run(() =>
        {
            Thread.Sleep(1000);
            return 25.5;
        }).ConfigureAwait(false);

        Console.WriteLine($"读取完成（线程ID: {Thread.CurrentThread.ManagedThreadId}）");

        return value;
    }

    // ========================
    // 5. async 方法中的异常处理
    // ========================

    /// <summary>
    /// 异步方法的异常处理模式
    /// </summary>
    public async Task<(bool Success, double Value)> ReadPlcSafeAsync(string address)
    {
        try
        {
            // 参数检查（同步部分）
            if (string.IsNullOrEmpty(address))
            {
                throw new ArgumentNullException(nameof(address));
            }

            // 异步操作
            await Task.Delay(1000);

            // 模拟可能失败的操作
            Random rnd = new Random();
            if (rnd.Next(100) < 20)
            {
                throw new TimeoutException("PLC响应超时");
            }

            double value = 25.5;
            return (true, value);
        }
        catch (TimeoutException ex)
        {
            Console.WriteLine($"超时: {ex.Message}");
            return (false, 0);
        }
        catch (Exception ex)
        {
            Console.WriteLine($"错误: {ex.Message}");
            return (false, 0);
        }
    }
}

public class AsyncAwaitDemo
{
    public static void Main()
    {
        Console.WriteLine($"主线程ID: {Thread.CurrentThread.ManagedThreadId}\n");

        var demo = new AsyncReturnTypesDemo();

        // 调用 async Task 方法
        Task writeTask = demo.WritePlcDataAsync("D100", 30.0);
        writeTask.Wait();  // 等待完成

        Console.WriteLine();

        // 调用 async Task<TResult> 方法
        Task<double> readTask = demo.ReadPlcDataAsync("D102");
        readTask.Wait();
        Console.WriteLine($"读取结果: {readTask.Result}");

        Console.WriteLine();

        // ConfigureAwait 对比
        Console.WriteLine("--- ConfigureAwait 对比 ---");
        Task<double> noContextTask = demo.ReadPlcNoContextAsync("D104");
        noContextTask.Wait();

        Console.WriteLine();

        // 安全读取
        Console.WriteLine("--- 安全读取 ---");
        var safeResult = demo.ReadPlcSafeAsync("D106").Result;
        Console.WriteLine($"安全读取结果: 成功={safeResult.Success}, 值={safeResult.Value}");
    }
}
```

### 3.3 async/await 的执行流程详解

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

public class AsyncFlowDemo
{
    /// <summary>
    /// 演示 async/await 的完整执行流程
    /// 在每个关键点打印线程ID，帮助理解线程切换
    /// </summary>
    public async Task DemonstrateAsyncFlow()
    {
        Console.WriteLine($"[步骤1] 方法开始 (线程ID: {Thread.CurrentThread.ManagedThreadId})");

        // 阶段1：同步执行（在调用者线程）
        string address = "D100";
        Console.WriteLine($"[步骤2] 准备读取 {address} (线程ID: {Thread.CurrentThread.ManagedThreadId})");

        // 阶段2：await —— 异步等待
        // Task.Run 将工作放到线程池
        Console.WriteLine($"[步骤3] await 之前 (线程ID: {Thread.CurrentThread.ManagedThreadId})");

        double value = await Task.Run(() =>
        {
            Console.WriteLine($"  [后台工作] 开始通信 (线程ID: {Thread.CurrentThread.ManagedThreadId})");
            Thread.Sleep(1000);
            Console.WriteLine($"  [后台工作] 通信完成 (线程ID: {Thread.CurrentThread.ManagedThreadId})");
            return 25.5;
        });

        // 阶段3：await 之后 —— 自动回到原始同步上下文（如果有）
        Console.WriteLine($"[步骤4] await 之后 (线程ID: {Thread.CurrentThread.ManagedThreadId})");
        Console.WriteLine($"[步骤5] 处理数据: {value} (线程ID: {Thread.CurrentThread.ManagedThreadId})");

        // 多个 await 的串联
        Console.WriteLine($"[步骤6] 开始保存数据...");
        await Task.Run(() =>
        {
            Thread.Sleep(500);
            Console.WriteLine($"  [后台工作] 数据已保存到数据库");
        });

        Console.WriteLine($"[步骤7] 全部完成 (线程ID: {Thread.CurrentThread.ManagedThreadId})");
    }

    /// <summary>
    /// 多个 await 顺序执行
    /// </summary>
    public async Task MultipleAwaitDemo()
    {
        Console.WriteLine("\n=== 多个 await 顺序执行 ===");

        // 三个操作顺序执行（总耗时 = 1000 + 800 + 500 = 2300ms）
        DateTime start = DateTime.Now;

        double temp = await ReadSensorAsync("温度传感器", 1000);
        Console.WriteLine($"  温度: {temp}");

        double pressure = await ReadSensorAsync("压力传感器", 800);
        Console.WriteLine($"  压力: {pressure}");

        double flow = await ReadSensorAsync("流量传感器", 500);
        Console.WriteLine($"  流量: {flow}");

        Console.WriteLine($"  总耗时: {(DateTime.Now - start).TotalMilliseconds:F0}ms");
    }

    /// <summary>
    /// 模拟读取传感器
    /// </summary>
    private async Task<double> ReadSensorAsync(string name, int delayMs)
    {
        await Task.Delay(delayMs);
        Random rnd = new Random();
        return 20 + rnd.NextDouble() * 10;
    }
}

public class AsyncFlowDemoMain
{
    public static void Main()
    {
        Console.WriteLine($"主线程ID: {Thread.CurrentThread.ManagedThreadId}\n");

        var demo = new AsyncFlowDemo();

        Console.WriteLine("=== async/await 执行流程 ===");
        demo.DemonstrateAsyncFlow().Wait();
```

## 4. CancellationToken 取消令牌

### 4.1 什么是 CancellationToken

`CancellationToken` 是 .NET 中用于**协作式取消**的机制。它允许你将一个取消信号传递给正在运行的任务，让任务能够在合适的位置主动停止，而不是被强制中止。

```
CancellationToken 工作机制：

CancellationTokenSource (令牌源)
    │
    │ .Token → 获取 CancellationToken
    │ .Cancel() → 发出取消信号
    │
    ▼
CancellationToken (令牌)
    │
    │ .IsCancellationRequested → 检查是否被取消
    │ .ThrowIfCancellationRequested() → 如果被取消则抛异常
    │
    ▼
传入各个异步方法，方法内部检查令牌状态决定是否停止
```

### 4.2 CancellationToken 基本使用

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

public class CancellationDemo
{
    public void Run()
    {
        // ========================
        // 1. 基本使用流程
        // ========================

        Console.WriteLine("=== CancellationToken 基本使用 ===\n");

        // 创建令牌源
        using var cts = new CancellationTokenSource();

        // 获取令牌
        CancellationToken token = cts.Token;

        // 注册取消回调（取消时自动执行）
        token.Register(() =>
        {
            Console.WriteLine("[取消回调] 收到取消信号，正在清理资源...");
        });

        // 启动任务，传入令牌
        Task task = Task.Run(() =>
        {
            for (int i = 0; i < 100; i++)
            {
                // 检查是否被取消
                if (token.IsCancellationRequested)
                {
                    Console.WriteLine($"  任务在 {i} 时被取消");
                    return;  // 主动退出
                }

                Console.WriteLine($"  工作中... {i}");
                Thread.Sleep(100);
            }
        }, token);  // 将令牌传入 Task.Run

        // 500ms 后取消
        Thread.Sleep(500);
        Console.WriteLine("\n[主线程] 发出取消信号...");
        cts.Cancel();  // 取消任务

        task.Wait();  // 等待任务结束

        Console.WriteLine();

        // ========================
        // 2. ThrowIfCancellationRequested（推荐方式）
        // ========================

        Console.WriteLine("=== ThrowIfCancellationRequested ===\n");

        using var cts2 = new CancellationTokenSource();

        try
        {
            Task.Run(() =>
            {
                for (int i = 0; i < 100; i++)
                {
                    // 如果被取消，抛出 OperationCanceledException
                    cts2.Token.ThrowIfCancellationRequested();

                    Console.WriteLine($"  工作中... {i}");
                    Thread.Sleep(100);
                }
            }, cts2.Token).Wait();
        }
        catch (AggregateException ex)
        {
            if (ex.InnerExceptions[0] is OperationCanceledException)
            {
                Console.WriteLine("任务被正常取消（OperationCanceledException）");
            }
        }

        // ========================
        // 3. 带超时的取消
        // ========================

        Console.WriteLine("\n=== 超时取消 ===\n");

        // 创建带超时的令牌源（5秒后自动取消）
        using var timeoutCts = new CancellationTokenSource(TimeSpan.FromSeconds(5));

        try
        {
            Console.WriteLine("开始任务（5秒超时）...");
            Task.Run(() =>
            {
                for (int i = 0; i < 100; i++)
                {
                    timeoutCts.Token.ThrowIfCancellationRequested();

                    Console.WriteLine($"  工作中... {i}");
                    Thread.Sleep(1000);  // 每步1秒，肯定超时
                }
            }, timeoutCts.Token).Wait();
        }
        catch (AggregateException ex) when (ex.InnerExceptions[0] is OperationCanceledException)
        {
            Console.WriteLine("任务因超时被取消");
        }

        // ========================
        // 4. 链接多个令牌源
        // ========================

        Console.WriteLine("\n=== 链接令牌源 ===\n");

        using var ctsA = new CancellationTokenSource();
        using var ctsB = new CancellationTokenSource();

        // 创建链接令牌：任一源被取消，链接令牌都会被取消
        using var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(
            ctsA.Token, ctsB.Token
        );

        Task.Run(() =>
        {
            for (int i = 0; i < 20; i++)
            {
                linkedCts.Token.ThrowIfCancellationRequested();
                Console.WriteLine($"  工作中... {i}");
                Thread.Sleep(200);
            }
        }, linkedCts.Token);

        // 取消令牌A（令牌B没取消，但链接令牌会取消）
        Thread.Sleep(300);
        Console.WriteLine("取消令牌A...");
        ctsA.Cancel();

        Thread.Sleep(500);
        Console.WriteLine("链接令牌也跟着取消了");
    }
}
```

## 5. 并行编程基础

### 5.1 Parallel.For 和 Parallel.ForEach

`Parallel` 类提供了数据并行（对集合或索引范围执行相同的操作），适合CPU密集型的批量操作。

```
串行 vs 并行：

串行（for循环）：
  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
  │ D100 │ │ D102 │ │ D104 │ │ D106 │  依次执行
  │ 1秒  │ │ 1秒  │ │ 1秒  │ │ 1秒  │  总计4秒
  └──────┘ └──────┘ └──────┘ └──────┘

并行（Parallel.For）：
  ┌──────┐
  │ D100 │ ┐
  │ 1秒  │ │
  └──────┘ │
  ┌──────┐ │   同时执行
  │ D102 │ │   总计约1秒（假设4核CPU）
  │ 1秒  │ │
  └──────┘ │
  ┌──────┐ │
  │ D104 │ │
  │ 1秒  │ │
  └──────┘ │
  ┌──────┐ │
  │ D106 │ │
  │ 1秒  │ │
  └──────┘ ┘
```

### 5.2 并行编程代码示例

```csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

public class ParallelDemo
{
    public void Run()
    {
        // ========================
        // 1. Parallel.For — 并行for循环
        // ========================

        Console.WriteLine("=== Parallel.For ===\n");

        // 模拟PLC寄存器地址列表
        string[] addresses = { "D100", "D102", "D104", "D106", "D108", "D110" };

        // 串行读取
        var sw = Stopwatch.StartNew();
        var serialResults = new Dictionary<string, double>();

        foreach (var addr in addresses)
        {
            serialResults[addr] = SimulatePlcRead(addr, 500);
        }
        sw.Stop();
        Console.WriteLine($"串行读取耗时: {sw.ElapsedMilliseconds}ms (6 x 500ms = 3000ms)");

        // 并行读取
        sw.Restart();
        var parallelResults = new Dictionary<string, double>();

        // 使用并行锁保护共享字典
        object lockObj = new object();

        Parallel.For(0, addresses.Length, (i) =>
        {
            string addr = addresses[i];
            double value = SimulatePlcRead(addr, 500);

            // 对共享资源的访问需要加锁
            lock (lockObj)
            {
                parallelResults[addr] = value;
            }
        });
        sw.Stop();
        Console.WriteLine($"并行读取耗时: {sw.ElapsedMilliseconds}ms (约500ms)\n");

        // ========================
        // 2. Parallel.ForEach — 并行遍历集合
        // ========================

        Console.WriteLine("=== Parallel.ForEach ===\n");

        // 模拟一批需要处理的传感器数据
        var sensorDataList = Enumerable.Range(0, 10)
            .Select(i => new { Address = $"D{i * 2}", RawValue = i * 10.5 })
            .ToList();

        var processedData = new List<(string Address, double ScaledValue)>();
        object listLock = new object();

        Parallel.ForEach(sensorDataList, (data) =>
        {
            // 模拟数据处理（换算工程值）
            double scaled = data.RawValue * 0.1;
            string result = $"[{data.Address}] {data.RawValue} → {scaled:F2}";
            Console.WriteLine($"  {result} (线程: {Thread.CurrentThread.ManagedThreadId})");

            lock (listLock)
            {
                processedData.Add((data.Address, scaled));
            }
        });

        Console.WriteLine($"\n处理完成: {processedData.Count} 条数据");

        // ========================
        // 3. Parallel.ForEach 的重载版本（支持取消、分区等）
        // ========================

        Console.WriteLine("\n=== Parallel.ForEach 带取消令牌 ===\n");

        using var cts = new CancellationTokenSource();
        int processedCount = 0;

        try
        {
            Parallel.ForEach(
                addresses,                           // 数据源
                new ParallelOptions                  // 并行选项
                {
                    CancellationToken = cts.Token,   // 取消令牌
                    MaxDegreeOfParallelism = 2       // 最大并行度（限制同时执行的线程数）
                },
                (addr, state, index) =>
                {
                    processedCount++;
                    Console.WriteLine($"  处理 {addr} (序号: {index})");

                    // 模拟耗时
                    Thread.Sleep(300);

                    // 第3个处理完后停止
                    if (processedCount >= 3)
                    {
                        state.Stop();  // 停止后续迭代
                    }
                }
            );
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("并行操作被取消");
        }

        Console.WriteLine($"实际处理了 {processedCount} 个地址");

        // ========================
        // 4. Parallel.Invoke — 并行执行多个不相关的操作
        // ========================

        Console.WriteLine("\n=== Parallel.Invoke ===\n");

        Parallel.Invoke(
            () => Console.WriteLine("  操作1: 读取PLC-001"),
            () => Console.WriteLine("  操作2: 读取PLC-002"),
            () => Console.WriteLine("  操作3: 读取PLC-003")
        );
        Console.WriteLine("所有操作完成");
    }

    /// <summary>
    /// 模拟PLC读取（带延迟）
    /// </summary>
    private double SimulatePlcRead(string address, int delayMs)
    {
        Thread.Sleep(delayMs);
        Random rnd = new Random();
        return 20 + rnd.NextDouble() * 10;
    }
}

public class ParallelMain
{
    public static void Main()
    {
        Console.WriteLine("=== 并行编程演示 ===\n");
        Console.WriteLine($"CPU核心数: {Environment.ProcessorCount}\n");

        var demo = new ParallelDemo();
        demo.Run();
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;
using System.Threading.Tasks;

/// <summary>
/// 上位机异步PLC通信服务
/// 核心目标：所有通信操作不阻塞UI线程
/// </summary>
public class AsyncPlcService
{
    private string _ipAddress;
    private int _port;
    private Random _rnd = new Random();

    /// <summary>数据接收事件</summary>
    public event EventHandler<(string Address, double Value)> DataReceived;

    /// <summary>通信错误事件</summary>
    public event EventHandler<string> ErrorOccurred;

    public AsyncPlcService(string ip, int port)
    {
        _ipAddress = ip;
        _port = port;
    }

    /// <summary>
    /// 异步连接PLC（不阻塞UI）
    /// </summary>
    public async Task<bool> ConnectAsync()
    {
        try
        {
            Console.WriteLine($"[{_ipAddress}] 异步连接中...");

            // 使用 Task.Run 执行耗时的连接操作
            await Task.Run(() =>
            {
                Thread.Sleep(2000);  // 模拟连接耗时
            }).ConfigureAwait(false);

            Console.WriteLine($"[{_ipAddress}] 连接成功");
            return true;
        }
        catch (Exception ex)
        {
            ErrorOccurred?.Invoke(this, $"连接失败: {ex.Message}");
            return false;
        }
    }

    /// <summary>
    /// 异步读取单个寄存器（不阻塞UI）
    /// </summary>
    public async Task<double> ReadAsync(string address)
    {
        try
        {
            // 将通信操作放到后台线程
            double value = await Task.Run(() =>
            {
                // 模拟通信耗时
                Thread.Sleep(100);

                // 模拟10%概率失败
                if (_rnd.Next(100) < 10)
                {
                    throw new TimeoutException("PLC响应超时");
                }

                return 20 + _rnd.NextDouble() * 10;
            }).ConfigureAwait(false);

            // 触发数据接收事件
            DataReceived?.Invoke(this, (address, value));

            return value;
        }
        catch (TimeoutException ex)
        {
            ErrorOccurred?.Invoke(this, $"读取超时 {address}: {ex.Message}");
            return double.NaN;  // 返回NaN表示读取失败
        }
    }

    /// <summary>
    /// 异步写入寄存器（不阻塞UI）
    /// </summary>
    public async Task<bool> WriteAsync(string address, double value)
    {
        try
        {
            await Task.Run(() =>
            {
                Thread.Sleep(50);  // 模拟写入耗时
            }).ConfigureAwait(false);

            Console.WriteLine($"[{_ipAddress}] 写入成功: {address} = {value}");
            return true;
        }
        catch (Exception ex)
        {
            ErrorOccurred?.Invoke(this, $"写入失败 {address}: {ex.Message}");
            return false;
        }
    }

    /// <summary>
    /// 异步批量读取多个寄存器
    /// 使用 Task.WhenAll 并行读取
    /// </summary>
    public async Task<Dictionary<string, double>> ReadBatchAsync(
        string[] addresses)
    {
        var results = new Dictionary<string, double>();
        var tasks = new List<Task<(string Address, double Value)>>();

        // 为每个地址创建一个读取任务
        foreach (var address in addresses)
        {
            var task = ReadSingleAsync(address);
            tasks.Add(task);
        }

        // 并行等待所有读取完成
        var completedResults = await Task.WhenAll(tasks).ConfigureAwait(false);

        // 汇总结果
        foreach (var (address, value) in completedResults)
        {
            if (!double.IsNaN(value))
            {
                results[address] = value;
            }
        }

        return results;
    }

    /// <summary>
    /// 异步读取单个地址（返回元组）
    /// </summary>
    private async Task<(string Address, double Value)> ReadSingleAsync(string address)
    {
        try
        {
            double value = await Task.Run(() =>
            {
                Thread.Sleep(100 + _rnd.Next(100));  // 随机延迟
                return 20 + _rnd.NextDouble() * 10;
            }).ConfigureAwait(false);

            return (address, value);
        }
        catch (Exception ex)
        {
            ErrorOccurred?.Invoke(this, $"读取失败 {address}: {ex.Message}");
            return (address, double.NaN);
        }
    }
}
```

```csharp
    public void AddDevice(string name, string ip, int port, string[] addresses)
    {
        _devices.Add(new PlcDevice(name, ip, port, addresses));
    }

    /// <summary>
    /// 启动所有PLC的轮询
    /// </summary>
    public void Start()
    {
        if (_isRunning) return;

        _cts = new CancellationTokenSource();
        _isRunning = true;
        _pollingTask = PollingLoopAsync(_cts.Token);
        Console.WriteLine($"轮询管理器已启动（{PollInterval}ms间隔，{_devices.Count}个设备）");
    }

    /// <summary>
    /// 停止轮询
    /// </summary>
    public void Stop()
    {
        if (!_isRunning) return;

        _cts?.Cancel();
        try
        {
            _pollingTask?.Wait(TimeSpan.FromSeconds(5));
        }
        catch (AggregateException) { }

        _isRunning = false;
        Console.WriteLine("轮询管理器已停止");
    }

    /// <summary>
    /// 轮询循环（核心方法）
    /// </summary>
    private async Task PollingLoopAsync(CancellationToken cancellationToken)
    {
        while (!cancellationToken.IsCancellationRequested)
        {
            try
            {
                // 为每个设备创建一个读取任务
                var readTasks = _devices.Select(device =>
                    PollSingleDeviceAsync(device, cancellationToken)
                ).ToArray();

                // 并行等待所有设备读取完成
                await Task.WhenAll(readTasks).ConfigureAwait(false);
            }
            catch (OperationCanceledException)
            {
                Console.WriteLine("轮询被取消");
                break;
            }
            catch (Exception ex)
            {
                Console.WriteLine($"轮询异常: {ex.Message}");
            }

            // 等待下一次轮询（可被取消）
            try
            {
                await Task.Delay(PollInterval, cancellationToken)
                    .ConfigureAwait(false);
            }
            catch (OperationCanceledException)
            {
                break;
            }
        }
    }

    /// <summary>
    /// 轮询单个PLC设备的所有地址
    /// </summary>
    private async Task PollSingleDeviceAsync(
        PlcDevice device,
        CancellationToken cancellationToken)
    {
        var sw = Stopwatch.StartNew();

        try
        {
            // 对单个设备的多个地址，也使用并行读取
            var addressTasks = device.Addresses.Select(async addr =>
            {
                // 模拟PLC读取（带延迟和取消支持）
                double value = await Task.Run(() =>
                {
                    cancellationToken.ThrowIfCancellationRequested();
                    Thread.Sleep(50 + new Random().Next(50));  // 50-100ms
                    return 20 + new Random().NextDouble() * 10;
                }, cancellationToken).ConfigureAwait(false);

                return (Address: addr, Value: value);
            }).ToArray();

            var results = await Task.WhenAll(addressTasks).ConfigureAwait(false);

            sw.Stop();

            // 触发数据更新事件
            foreach (var (addr, val) in results)
            {
                DataUpdated?.Invoke(this, new PlcDataUpdateEventArgs(
                    device.Name, addr, val, sw.ElapsedMilliseconds
                ));
            }
        }
        catch (OperationCanceledException)
        {
            // 正常取消，不处理
        }
        catch (Exception ex)
        {
            Console.WriteLine($"[{device.Name}] 轮询错误: {ex.Message}");
        }
    }

    public void Dispose()
    {
        Stop();
        _cts?.Dispose();
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;
using System.Threading.Tasks;

/// <summary>
/// 定时数据采集器
/// 使用 async/await 实现精确的定时采集，不阻塞UI线程
/// </summary>
public class TimedDataCollector : IDisposable
{
    private CancellationTokenSource _cts;
    private bool _isRunning;

    /// <summary>采集到的数据历史</summary>
    private List<(DateTime Time, string Tag, double Value)> _history
        = new List<(DateTime, string, double)>();

    /// <summary>最大保留历史条数</summary>
    public int MaxHistorySize { get; set; } = 1000;

    /// <summary>数据采集完成事件</summary>
    public event EventHandler<(DateTime Time, string Tag, double Value)> DataCollected;

    /// <summary>采集开始事件</summary>
    public event EventHandler<string> CollectionStarted;

    /// <summary>采集停止事件</summary>
    public event EventHandler<string> CollectionStopped;

    /// <summary>
    /// 启动定时采集
    /// </summary>
    /// <param name="intervalMs">采集间隔（毫秒）</param>
    /// <param name="tags">要采集的标签列表</param>
    public void Start(int intervalMs, string[] tags)
    {
        if (_isRunning) return;

        _cts = new CancellationTokenSource();
        _isRunning = true;

        string tagList = string.Join(", ", tags);
        CollectionStarted?.Invoke(this, $"开始采集 [{tagList}] 间隔: {intervalMs}ms");

        // 启动采集任务
        _ = CollectionLoopAsync(intervalMs, tags, _cts.Token);
    }

    /// <summary>
    /// 采集循环
    /// 使用精准计时：每次采集后计算剩余等待时间
    /// </summary>
    private async Task CollectionLoopAsync(
        int intervalMs,
        string[] tags,
        CancellationToken cancellationToken)
    {
        var sw = System.Diagnostics.Stopwatch.StartNew();

        while (!cancellationToken.IsCancellationRequested)
        {
            DateTime cycleStart = DateTime.Now;

            try
            {
                // 对所有标签并行采集
                var tasks = new List<Task<(string Tag, double Value)>>();

                foreach (var tag in tags)
                {
                    tasks.Add(ReadTagAsync(tag, cancellationToken));
                }

                // 等待所有采集完成
                var results = await Task.WhenAll(tasks).ConfigureAwait(false);

                sw.Stop();

                // 记录和触发事件
                foreach (var (tag, value) in results)
                {
                    var record = (DateTime.Now, tag, value);
                    _history.Add(record);

                    DataCollected?.Invoke(this, record);
                }

                // 限制历史大小
                if (_history.Count > MaxHistorySize)
                {
                    _history.RemoveAt(0);
                }
            }
            catch (OperationCanceledException)
            {
                break;
            }
            catch (Exception ex)
            {
                Console.WriteLine($"采集异常: {ex.Message}");
            }

            // 精确等待：计算本次采集耗费的时间，减去后得到剩余等待时间
            TimeSpan elapsed = DateTime.Now - cycleStart;
            int remainingMs = intervalMs - (int)elapsed.TotalMilliseconds;

            if (remainingMs > 0)
            {
                try
                {
                    await Task.Delay(remainingMs, cancellationToken)
                        .ConfigureAwait(false);
                }
                catch (OperationCanceledException)
                {
                    break;
                }
            }
        }

        CollectionStopped?.Invoke(this, "采集已停止");
    }

    /// <summary>
    /// 异步读取单个标签
    /// </summary>
    private async Task<(string Tag, double Value)> ReadTagAsync(
        string tag,
        CancellationToken cancellationToken)
    {
        return await Task.Run(() =>
        {
            cancellationToken.ThrowIfCancellationRequested();

            // 模拟传感器读取
            Thread.Sleep(10);

            Random rnd = new Random(tag.GetHashCode());
            double baseValue = tag switch
            {
                "温度" => 25.0,
                "压力" => 1.0,
                "流量" => 50.0,
                "液位" => 75.0,
                _ => 0.0
            };

            // 加随机波动
            double noise = (rnd.NextDouble() - 0.5) * 2;
            return (tag, baseValue + noise);
        }, cancellationToken).ConfigureAwait(false);
    }

    /// <summary>
    /// 获取历史数据
    /// </summary>
    public List<(DateTime Time, string Tag, double Value)> GetHistory()
    {
        return new List<(DateTime, string, double)>(_history);
    }

    /// <summary>
    /// 停止采集
    /// </summary>
    public void Stop()
    {
        if (!_isRunning) return;
        _cts?.Cancel();
        _isRunning = false;
    }

    public void Dispose()
    {
        Stop();
        _cts?.Dispose();
    }
}
```

### 6.4 案例四：通信超时取消

```csharp
using System;
using System.Collections.Generic;
using System.Threading;
using System.Threading.Tasks;

/// <summary>
/// 带超时和取消功能的PLC通信管理器
/// 上位机中通信超时是最常见的需求之一
/// </summary>
public class TimeoutPlcManager
{
    private Dictionary<string, CancellationTokenSource> _pendingOperations
        = new Dictionary<string, CancellationTokenSource>();
    private object _lockObj = new object();

    /// <summary>通信超时事件</summary>
    public event EventHandler<(string Address, string Reason)> TimeoutOccurred;

    /// <summary>通信完成事件</summary>
    public event EventHandler<(string Address, double Value)> ReadCompleted;

    /// <summary>默认超时时间（毫秒）</summary>
    public int DefaultTimeoutMs { get; set; } = 3000;

    /// <summary>
    /// 异步读取PLC数据（带超时）
    /// </summary>
    public async Task<double> ReadWithTimeoutAsync(
        string address,
        int timeoutMs = -1)
    {
        int timeout = timeoutMs > 0 ? timeoutMs : DefaultTimeoutMs;

        // 创建超时令牌
        using var timeoutCts = new CancellationTokenSource(timeout);

        // 注册取消回调（用于通知）
        string operationId = $"{address}_{DateTime.Now.Ticks}";
        timeoutCts.Token.Register(() =>
        {
            TimeoutOccurred?.Invoke(this, (address, $"通信超时 ({timeout}ms)"));
        });

        lock (_lockObj)
        {
            _pendingOperations[operationId] = timeoutCts;
        }

        try
        {
            Console.WriteLine($"  开始读取 {address} (超时: {timeout}ms)...");

            // 使用 WhenAny 实现超时
            var readTask = Task.Run(() =>
            {
                // 模拟PLC通信（随机耗时：50ms ~ 5000ms）
                int delay = 50 + new Random(address.GetHashCode()).Next(4950);
                Thread.Sleep(delay);
                return 25.5;
            }, timeoutCts.Token);

            var delayTask = Task.Delay(timeout, timeoutCts.Token);

            // 等待第一个完成的任务
            Task completedTask = await Task.WhenAny(readTask, delayTask)
                .ConfigureAwait(false);

            if (completedTask == readTask)
            {
                // 通信在超时前完成
                timeoutCts.Cancel();  // 取消延迟任务
                double value = await readTask.ConfigureAwait(false);

                lock (_lockObj)
                {
                    _pendingOperations.Remove(operationId);
                }

                ReadCompleted?.Invoke(this, (address, value));
                Console.WriteLine($"  读取成功: {address} = {value:F2}");
                return value;
            }
            else
            {
                // 超时了
                timeoutCts.Cancel();  // 取消通信任务

                lock (_lockObj)
                {
                    _pendingOperations.Remove(operationId);
                }

                Console.WriteLine($"  读取超时: {address}");
                throw new TimeoutException($"读取 {address} 超时 ({timeout}ms)");
            }
        }
        catch (OperationCanceledException)
        {
            lock (_lockObj)
            {
                _pendingOperations.Remove(operationId);
            }

            Console.WriteLine($"  读取被取消: {address}");
            throw;
        }
    }

    /// <summary>
    /// 批量读取（部分超时不影响其他）
    /// </summary>
    public async Task<Dictionary<string, double>> ReadBatchWithTimeoutAsync(
        string[] addresses,
        int timeoutMs = -1)
    {
        var results = new Dictionary<string, double>();
        var tasks = new List<Task<(string Address, double Value, bool Success)>>();

        // 为每个地址创建独立的读取任务
        foreach (var address in addresses)
        {
            tasks.Add(ReadOneSafeAsync(address, timeoutMs));
        }

        // 并行等待所有任务
        var completedResults = await Task.WhenAll(tasks).ConfigureAwait(false);

        foreach (var (address, value, success) in completedResults)
        {
            if (success)
            {
                results[address] = value;
            }
        }

        return results;
    }

    private async Task<(string Address, double Value, bool Success)> ReadOneSafeAsync(
        string address,
        int timeoutMs)
    {
        try
        {
            double value = await ReadWithTimeoutAsync(address, timeoutMs)
                .ConfigureAwait(false);
            return (address, value, true);
        }
        catch (TimeoutException)
        {
            return (address, 0, false);
        }
    }

    /// <summary>
    /// 取消所有待处理的通信操作
    /// </summary>
    public void CancelAll()
    {
        lock (_lockObj)
        {
            foreach (var cts in _pendingOperations.Values)
            {
                cts.Cancel();
            }
            _pendingOperations.Clear();
        }
        Console.WriteLine("所有待处理操作已取消");
    }
}
```

### 7.1 async void 的陷阱

```csharp
// async void 只能用于事件处理器！
// 其他情况一律使用 async Task

// 错误：async void 作为普通方法
public async void BadMethod()  // 错误！
{
    await Task.Delay(1000);

    // 这个异常会直接导致程序崩溃！
    // 因为 async void 的异常无法被 await 捕获
}

// 正确：使用 async Task
public async Task GoodMethod()  // 正确
{
    await Task.Delay(1000);
    throw new Exception("出错了");
    // 调用者可以用 try-catch 捕获这个异常
}

// 唯一正确的 async void 用法：事件处理器
public async void OnButtonClicked(object sender, EventArgs e)  // 正确
{
    try
    {
        await DoWorkAsync();

    catch (Exception ex)
    {
        // 在事件处理器内部自行处理异常
        HandleError(ex);

}
```

### 7.2 死锁问题

```csharp
// 经典死锁场景：在同步方法中等待异步方法
public class DeadlockExample
{
    // 错误：在WinForms/WPF的UI线程上调用
    public void BadMethod()
    {
        // Task.Wait() 和 .Result 会阻塞当前线程
        // 同时 async 方法内部 await 之后要回到UI线程
        // UI线程被阻塞 → async方法无法回到UI线程 → 死锁！
        var result = GetDataAsync().Result;  // 死锁！
    }

    // 正确方式1：全程使用 async/await
    public async Task GoodMethod1()
    {
        var result = await GetDataAsync();  // 不会死锁
    }

    // 正确方式2：使用 ConfigureAwait(false)
    public void GoodMethod2()
    {
        var result = GetDataAsync().ConfigureAwait(false).GetAwaiter().GetResult();
        // ConfigureAwait(false) 告诉async方法不需要回到UI线程
        // 所以不会死锁（但不推荐在UI代码中这样做）
    }

    private async Task<string> GetDataAsync()
    {
        await Task.Delay(1000);
        return "data";
    }
}
```

### 7.3 ConfigureAwait(false) 使用建议

```csharp
// 规则：
// 1. UI层代码（事件处理器、ViewModel）→ 不需要 ConfigureAwait
// 2. 库代码（服务类、工具类）→ 推荐 ConfigureAwait(false)

// UI层代码
public async void OnReadClicked(object sender, EventArgs e)
{
    // 不需要 ConfigureAwait，因为要在UI线程更新控件
    var data = await _plcService.ReadAsync("D100");
    textBox.Text = data.ToString();  // 回到UI线程执行
}

// 库代码
public class PlcService
{
    public async Task<double> ReadAsync(string address)
    {
        // 使用 ConfigureAwait(false)，避免在库代码中捕获UI上下文

            .ConfigureAwait(false);
    }
}
```

### 7.4 不要在循环中不加限制地启动 Task

```csharp
// 错误：循环中无限制启动大量Task，耗尽线程池
foreach (var address in addresses)
{
    Task.Run(() => ReadPlc(address));  // 如果有10000个地址，就启动10000个Task！
}

// 正确：限制并行度
var semaphore = new SemaphoreSlim(maxConcurrency: 4);  // 最多4个并发

var tasks = addresses.Select(async address =>
{
    await semaphore.WaitAsync();
    try
    {
        return await ReadPlcAsync(address);
    }
    finally
    {
        semaphore.Release();
    }
});

await Task.WhenAll(tasks);
```

```csharp
}
```

### 错误3：忘记 await

```csharp
// 错误：调用了异步方法但没有 await
public async void Button_Click()
{
    SaveDataAsync();  // 没有 await！
    // 1. 异常不会被捕获
    // 2. 方法可能在数据保存完成前就返回
    // 3. 编译器会给出警告 CS4014
}

// 正确
public async void Button_Click()
{
    await SaveDataAsync();  // 等待完成后再继续
}
```

### 错误4：在 Parallel 中使用 async/await

```csharp
// 错误：Parallel.For 不支持 async lambda
Parallel.For(0, 10, async i =>
{
    await ReadAsync(i);  // 返回 Task，但 Parallel 期望 Action
    // 实际上并行循环会在 Task 创建后就进入下一步
    // 不会等待 Task 完成！
});

// 正确方式1：使用 Task.WhenAll
var tasks = Enumerable.Range(0, 10)
    .Select(i => ReadAsync(i));
await Task.WhenAll(tasks);  // 等待所有完成

// 正确方式2：使用 Parallel.ForEach + .Wait()
Parallel.ForEach(addresses, addr =>
{
    ReadAsync(addr).Wait();  // 阻塞等待（在非UI代码中可以）
});
```

### 错误5：CancellationToken 使用后继续使用

```csharp
// 错误：CancellationTokenSource 被 Dispose 后继续使用 Token
public async Task BadMethod()
{
    using var cts = new CancellationTokenSource();
    var token = cts.Token;

    cts.Cancel();
    cts.Dispose();  // CTS 被 Dispose

    await Task.Delay(1000, token);  // 错误！Token 的来源已被释放
}

// 正确：在 CTS 的生命周期内使用 Token
public async Task GoodMethod()
{
    using var cts = new CancellationTokenSource();
    var token = cts.Token;

    await Task.Delay(1000, token);  // 正确：CTS 还没被 Dispose
}  // 这里才 Dispose
```

---

> **总结**：异步编程是现代上位机开发的必备技能。`async/await` 让异步代码像同步代码一样简洁直观；`Task` 提供了强大的并行处理能力；`CancellationToken` 提供了优雅的取消机制。在上位机开发中，几乎所有通信操作都应该使用异步模式，以确保界面始终响应用户操作。记住核心原则：**UI线程不做耗时操作、库代码用 ConfigureAwait(false)、永远不用 async void（事件处理器除外）、不要同步等待异步方法**。
