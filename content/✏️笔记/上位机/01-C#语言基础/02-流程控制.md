## 1. if-else 条件判断

### 1.1 基本语法

`if-else` 是最基础的条件判断语句，根据条件表达式的结果（`true` 或 `false`）决定执行哪段代码。

```csharp
// ===== 基本形式 =====
if (条件表达式)
{
    // 条件为 true 时执行
}

// ===== 带else的形式 =====
if (条件表达式)
{
    // 条件为 true 时执行
}
else
{
    // 条件为 false 时执行
}

// ===== 多重if-else =====
if (条件1)
{
    // 条件1为 true
}
else if (条件2)
{
    // 条件1为 false 且 条件2为 true
}
else
{
    // 所有条件都不满足
}
```

### 1.2 上位机场景示例

#### 数据范围校验

```csharp
using System;

namespace IfElseDemo
{
    class Program
    {
        // 温度上下限常量
        public const double TEMP_HIGH_LIMIT = 120.0;   // 高温报警限
        public const double TEMP_LOW_LIMIT = -10.0;     // 低温报警限
        public const double TEMP_HIGH_WARNING = 100.0;  // 高温预警
        public const double TEMP_LOW_WARNING = 0.0;     // 低温预警

        static void Main(string[] args)
        {
            // 模拟从传感器读取的温度值
            double temperature = 105.5;

            // ===== 多重 if-else 判断温度状态 =====
            if (temperature > TEMP_HIGH_LIMIT)
            {
                // 高温报警 —— 最严重
                Console.WriteLine("[报警] 温度过高！启动紧急冷却系统！");
                // 触发报警输出
                // SendAlarm("温度过高", temperature);
            }
            else if (temperature > TEMP_HIGH_WARNING)
            {
                // 高温预警 —— 需要关注
                Console.WriteLine("[预警] 温度偏高，请关注温度趋势");
                // 记录预警日志
                // LogWarning($"温度偏高: {temperature}°C");
            }
            else if (temperature < TEMP_LOW_LIMIT)
            {
                // 低温报警
                Console.WriteLine("[报警] 温度过低！检查加热系统！");
            }
            else if (temperature < TEMP_LOW_WARNING)
            {
                // 低温预警
                Console.WriteLine("[预警] 温度偏低，请关注温度趋势");
            }
            else
            {
                // 温度正常
                Console.WriteLine("[正常] 温度在正常范围内");
            }
        }
    }
}
```

#### 设备连接状态判断

```csharp
using System;

namespace DeviceStatusCheck
{
    class Program
    {
        static void Main(string[] args)
        {
            bool isPlcOnline = true;
            bool isSensorOk = true;
            bool isAlarm = false;

            // 复合条件判断：所有条件都满足才能启动
            if (isPlcOnline && isSensorOk && !isAlarm)
            {
                Console.WriteLine("[系统] 所有设备正常，系统启动就绪");
            }
            else
            {
                Console.WriteLine("[系统] 存在异常，请检查以下设备状态:");

                // 逐项检查
                if (!isPlcOnline)
                    Console.WriteLine("  [故障] PLC 通信中断");

                if (!isSensorOk)
                    Console.WriteLine("  [故障] 传感器异常");

                if (isAlarm)
                    Console.WriteLine("  [报警] 存在未处理的报警");
            }
        }
    }
}
```

### 1.3 注意事项

- `if` 后面的条件表达式必须放在 `()` 中
- 即使 `if` 或 `else` 后面只有一行代码，也**强烈建议使用大括号 `{}`**，避免后续添加代码时出错
- `else if` 不是 `else if` 的缩写，而是 `else { if ... }` 的语法糖
- 条件表达式中，`&&`（与）和 `||`（或）是短路运算符，善用短路可以避免不必要的计算和异常

### 注意事项

```csharp
// ❌ 危险写法：没有大括号，后续添加代码时容易出错
if (temperature > 100)
    Console.WriteLine("高温");
    Console.WriteLine("报警！");  // 这行总是会执行，不受 if 控制！

// ✅ 推荐写法：始终使用大括号
if (temperature > 100)
{
    Console.WriteLine("高温");
    Console.WriteLine("报警！");
}

// ❌ 错误：C# 中不能用单个 = 做比较
// if (isConnected = true)  → 这是赋值！C# 编译器会报错（区别于 C/C++）

// ✅ 正确
if (isConnected == true)   // 显式比较
if (isConnected)           // 更简洁（推荐）
```

## 2. switch-case 多分支选择

### 2.1 基本语法

当需要对同一个变量进行多值判断时，`switch-case` 比 `if-else if` 更清晰。

```csharp
switch (表达式)
{
    case 值1:
        // 表达式等于值1时执行
        break;
    case 值2:
        // 表达式等于值2时执行
        break;
    default:
        // 所有case都不匹配时执行
        break;
}
```

### 2.2 上位机场景示例

#### 根据 PLC 返回码执行不同操作

```csharp
using System;

namespace SwitchCaseDemo
{
    // 定义 PLC 返回码枚举
    public enum PlcErrorCode
    {
        Success = 0,          // 成功
        Timeout = 1,          // 超时
        InvalidAddress = 2,   // 无效地址
        InvalidValue = 3,     // 无效数据
        Busy = 4,             // PLC忙
        DeviceFault = 5       // 设备故障
    }

    class Program
    {
        static void Main(string[] args)
        {
            // 模拟 PLC 返回的错误码
            PlcErrorCode errorCode = PlcErrorCode.InvalidAddress;

            Console.WriteLine($"PLC 返回码: {errorCode}");
            Console.WriteLine();

            // ===== 基本switch-case =====
            switch (errorCode)
            {
                case PlcErrorCode.Success:
                    Console.WriteLine("[成功] 操作执行成功");
                    // 更新界面显示
                    break;

                case PlcErrorCode.Timeout:
                    Console.WriteLine("[超时] 通信超时，请检查网络连接");
                    // 自动重试逻辑
                    break;

                case PlcErrorCode.InvalidAddress:
                    Console.WriteLine("[错误] 寄存器地址无效");
                    Console.WriteLine("  请检查地址是否超出 PLC 支持范围");
                    // 记录错误日志
                    break;

                case PlcErrorCode.InvalidValue:
                    Console.WriteLine("[错误] 写入数据值无效");
                    Console.WriteLine("  请检查数据范围是否符合要求");
                    break;

                case PlcErrorCode.Busy:
                    Console.WriteLine("[繁忙] PLC 正忙，请稍后重试");
                    break;

                case PlcErrorCode.DeviceFault:
                    Console.WriteLine("[故障] PLC 设备故障，请检查硬件");
                    // 切换到备用PLC
                    break;

                default:
                    Console.WriteLine($"[未知] 未处理的错误码: {errorCode}");
                    break;
            }
        }
    }
}
```

### 2.3 C# 8.0 模式匹配新语法

C# 8.0 引入了强大的模式匹配（Pattern Matching），让 `switch` 表达式更加简洁。

```csharp
using System;

namespace PatternMatchingDemo
{
    public enum AlarmLevel
    {
        Info,
        Warning,
        Error,
        Critical
    }

    class Program
    {
        static void Main(string[] args)
        {
            // ===== switch 表达式（C# 8.0+）=====
            // 用 => 箭头语法，更简洁
            AlarmLevel level = AlarmLevel.Error;

            // 传统写法
            string levelText1;
            switch (level)
            {
                case AlarmLevel.Info:
                    levelText1 = "信息"; break;
                case AlarmLevel.Warning:
                    levelText1 = "警告"; break;
                case AlarmLevel.Error:
                    levelText1 = "错误"; break;
                case AlarmLevel.Critical:
                    levelText1 = "严重"; break;
                default:
                    levelText1 = "未知"; break;
            }

            // 新写法：switch 表达式（推荐）
            string levelText2 = level switch
            {
                AlarmLevel.Info => "信息",
                AlarmLevel.Warning => "警告",
                AlarmLevel.Error => "错误",
                AlarmLevel.Critical => "严重",
                _ => "未知"           // _ 是弃元符（discard），表示 default
            };

            Console.WriteLine($"报警级别: {levelText2}");

            // ===== 关系模式（范围匹配）=====
            double temperature = 105.5;
            string tempStatus = temperature switch
            {
                > 120.0 => "严重报警",
                > 100.0 => "高温预警",
                < -10.0 => "严重低温",
                < 0.0 => "低温预警",
                _ => "正常"
            };
            Console.WriteLine($"温度状态: {tempStatus}");

            // ===== 组合模式（when 子句）=====
            int errorCode = 5;
            string errorMsg = errorCode switch
            {
                0 => "操作成功",
                1 or 2 => "通信异常",        // or 组合多个值
                >= 3 and <= 5 => "设备故障",   // and 表示范围
                _ => $"未知错误 (代码: {errorCode})"
            };
            Console.WriteLine($"错误信息: {errorMsg}");

            // ===== 对象模式 =====
            string input = "192.168.1.100";
            string result = input switch
            {
                null => "输入为空",
                "" => "输入为空字符串",
                string s when s.StartsWith("192.168") => "局域网地址",
                string s when s.StartsWith("10.") => "内网地址",
                _ => "其他地址"
            };
            Console.WriteLine($"地址类型: {result}");

            // ===== 嵌套 switch 表达式 =====
            string brand = "Siemens";
            string protocol = brand switch
            {
                "Siemens" => "S7",
                "Mitsubishi" => "MC",
                "Omron" => "FINS",
                _ => "Modbus"
            };

            int port = (brand, protocol) switch
            {
                ("Siemens", _) => 102,
                ("Mitsubishi", _) => 5000,
                ("Omron", _) => 9600,
                _ => 502
            };
            Console.WriteLine($"品牌: {brand}, 协议: {protocol}, 端口: {port}");
        }
    }
}
```

### 2.4 注意事项

- `switch` 的每个 `case` 分支必须以 `break`、`return`、`throw` 或 `goto` 结尾，不允许"贯穿"（与 C/C++ 不同）
- C# 7.0+ 支持在 `case` 中使用 `when` 子句添加额外条件
- C# 8.0 的 `switch` 表达式更简洁，适合简单的值映射场景
- 当分支很多（超过 5~7 个）且逻辑复杂时，考虑使用字典映射或策略模式替代

### 练习建议

1. 用 `switch` 实现 Modbus 功能码的中文描述映射
2. 用 C# 8.0 模式匹配重写温度区间判断逻辑
3. 实现一个命令解析器：用户输入 `read 40100` 或 `write 40100 100` 等命令进行解析

## 3. for 循环

### 3.1 基本语法

```csharp
// for 循环语法结构
for (初始化; 条件; 迭代)
{
    // 循环体
}

// 执行顺序：
// 1. 初始化（只执行一次）
// 2. 判断条件 → true 则执行循环体，false 则退出
// 3. 执行循环体
// 4. 执行迭代
// 5. 回到步骤 2
```

### 3.2 上位机场景示例

#### 批量读取多个寄存器

```csharp
using System;

namespace ForLoopDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 场景一：批量读取 10 个寄存器 =====
            int startAddress = 40100;   // 起始地址
            int registerCount = 10;     // 读取数量

            Console.WriteLine($"--- 批量读取 {startAddress} ~ {startAddress + registerCount - 1} ---");

            // for 循环：从 startAddress 开始，每次加 1，共读 registerCount 个
            for (int i = 0; i < registerCount; i++)
            {
                int address = startAddress + i;
                ushort rawValue = (ushort)(1000 + i * 100);  // 模拟读取值
                double actualValue = rawValue * 0.1;

                Console.WriteLine($"  地址 {address}: 原始值={rawValue}, 实际值={actualValue:F1}");
            }

            Console.WriteLine();

            // ===== 场景二：通信重试机制 =====
            int maxRetry = 3;
            bool connected = false;

            for (int retry = 1; retry <= maxRetry; retry++)
            {
                Console.Write($"第 {retry} 次尝试连接 PLC...");

                // 模拟连接操作（随机成功/失败）
                Random rand = new Random();
                bool success = rand.Next(1, 4) != 1;  // 2/3 概率成功

                if (success)
                {
                    Console.WriteLine("成功！");
                    connected = true;
                    break;  // 连接成功，跳出重试循环
                }
                else
                {
                    Console.WriteLine("失败！");
                    if (retry < maxRetry)
                    {
                        Console.WriteLine($"  等待 {(retry * 1000)}ms 后重试...");
                    }
                }
            }

            if (!connected)
            {
                Console.WriteLine($"[错误] 经过 {maxRetry} 次尝试仍无法连接 PLC");
            }
        }
    }
}
```

#### 嵌套 for 循环：遍历多设备多寄存器

```csharp
using System;

namespace NestedForLoop
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 场景：3 台 PLC，每台读取 5 个寄存器 =====
            string[] plcNames = { "PLC-001", "PLC-002", "PLC-003" };
            string[] ipAddresses = { "192.168.1.100", "192.168.1.101", "192.168.1.102" };
            int[] registers = { 40100, 40101, 40102, 40103, 40104 };

            Console.WriteLine("========== 批量采集所有 PLC 数据 ==========\n");

            // 外层循环：遍历每台 PLC
            for (int p = 0; p < plcNames.Length; p++)
            {
                Console.WriteLine($"[{plcNames[p]}] ({ipAddresses[p]})");

                // 内层循环：遍历每台 PLC 的寄存器
                for (int r = 0; r < registers.Length; r++)
                {
                    ushort rawValue = (ushort)(1000 + p * 100 + r * 10);
                    double value = rawValue * 0.1;

                    Console.WriteLine($"  寄存器 {registers[r]}: {value:F1}");
                }

                Console.WriteLine();  // 设备之间空一行
            }
        }
    }
}
```

### 3.3 注意事项

- `for` 循环的三个部分（初始化、条件、迭代）都可以省略，但分号不能省略
- 在循环体内修改循环变量的值要谨慎，可能导致意外行为
- 嵌套循环注意：内层循环每次外层循环都会完整执行一次
- 上位机中循环最常用于：批量读写寄存器、多设备轮询、重试逻辑

## 4. while / do-while 循环

### 4.1 while 循环

`while` 循环在执行前先判断条件，可能一次都不执行。

```csharp
while (条件表达式)
{
    // 条件为 true 时重复执行
}
```

#### 上位机场景：持续监听串口数据

```csharp
using System;
using System.Threading;  // 引入多线程命名空间

namespace WhileLoopDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 场景一：持续监听串口数据（模拟） =====
            bool isRunning = true;
            int dataCount = 0;

            Console.WriteLine("[串口监听] 开始监听 COM3...");
            Console.WriteLine("输入 'quit' 停止监听\n");

            while (isRunning)
            {
                // 模拟串口接收数据
                dataCount++;
                double temperature = 25.0 + (new Random().NextDouble() * 5);
                double pressure = 100.0 + (new Random().NextDouble() * 5);

                Console.WriteLine($"[{DateTime.Now:HH:mm:ss}] " +
                    $"温度={temperature:F1}°C, " +
                    $"压力={pressure:F1}kPa, " +
                    $"序号={dataCount}");

                // 模拟检查退出条件
                if (dataCount >= 5)
                {
                    Console.WriteLine("\n[系统] 达到最大演示次数，停止监听");
                    isRunning = false;
                }

                // 模拟采集间隔（真实程序中用 Thread.Sleep 或 Timer）
                Thread.Sleep(1000);  // 暂停 1000 毫秒（1秒）
            }

            Console.WriteLine($"[串口监听] 已停止，共接收 {dataCount} 条数据");
        }
    }
}
```

### 4.2 do-while 循环

`do-while` 循环先执行一次循环体，再判断条件。**至少执行一次**。

```csharp
do
{
    // 循环体
}
while (条件表达式);   // 注意末尾有分号！
```

#### 上位机场景：用户配置输入验证

```csharp
using System;

namespace DoWhileDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 场景：用户输入 Modbus 站号，必须验证通过 =====
            byte stationId = 0;

            do
            {
                Console.Write("请输入 Modbus 站号 (1~247): ");
                string input = Console.ReadLine();

                // 安全解析用户输入
                if (byte.TryParse(input, out stationId))
                {
                    if (stationId >= 1 && stationId <= 247)
                    {
                        Console.WriteLine($"站号设置成功: {stationId}");
                        break;  // 输入合法，退出循环
                    }
                    else
                    {
                        Console.WriteLine($"错误: 站号 {stationId} 超出范围 (1~247)，请重新输入");
                    }
                }
                else
                {
                    Console.WriteLine("错误: 请输入有效的数字 (1~247)");
                }
            }
            while (true);  // 无限循环，通过 break 退出

            // ===== 场景二：PLC 连接重试（先尝试再判断）=====
            int retryCount = 0;
            const int maxRetry = 3;
            bool connected = false;

            do
            {
                retryCount++;
                Console.Write($"第 {retryCount}/{maxRetry} 次尝试连接 PLC...");

                // 模拟连接（50% 概率成功）
                connected = new Random().Next(2) == 0;

                if (connected)
                {
                    Console.WriteLine("成功！");
                }
                else
                {
                    Console.WriteLine("失败");
                    if (retryCount < maxRetry)
                        Thread.Sleep(1000);
                }
            }
            while (!connected && retryCount < maxRetry);

            // 循环结束后判断最终结果
            if (connected)
            {
                Console.WriteLine("PLC 连接成功，开始数据采集...");
            }
            else
            {
                Console.WriteLine($"PLC 连接失败（已重试 {maxRetry} 次），请检查网络和设备");
            }
        }
    }
}
```

### 4.3 while vs do-while 对比

| 特性 | while | do-while |
|------|-------|----------|
| 判断时机 | 先判断后执行 | 先执行后判断 |
| 最少执行次数 | 0 次 | 1 次 |
| 适用场景 | 未知是否需要执行 | 至少执行一次（如输入验证） |
| 上位机应用 | 持续采集、监听 | 配置输入、首次连接 |

### 4.4 注意事项

- `do-while` 末尾的 `while` 后面有分号 `;`，不要忘记
- `while(true)` 可以创建无限循环，必须确保有 `break` 或 `return` 出口
- 长时间运行的循环要考虑性能（如加入 `Thread.Sleep` 释放 CPU）
- 避免死循环：确保循环条件最终会变为 `false`

### 5.3 foreach vs for 对比

| 特性 | foreach | for |
|------|---------|-----|
| 语法 | 简洁 | 较复杂 |
| 索引访问 | 无直接索引（需手动计数） | 直接通过索引访问 |
| 修改元素 | 不能修改集合本身 | 可以修改 |
| 适用场景 | 只读遍历 | 需要索引或修改 |

```csharp
// 需要索引时，用 for
for (int i = 0; i < devices.Length; i++)
{
    if (devices[i] == targetDevice)
    {
        Console.WriteLine($"找到目标设备，索引: {i}");
        break;
    }
}

// 只需要遍历值时，用 foreach（更简洁）
foreach (string device in devices)
{
    Console.WriteLine(device);
}

// ⚠️ foreach 中不能修改遍历的集合
// foreach (var item in list)
// {
//     list.Remove(item);  // ❌ 运行时抛异常！
// }
```

### 注意事项

- `foreach` 中不能修改正在遍历的集合（如不能添加/删除元素）
- 如果需要在遍历中修改集合，使用 `for` 倒序遍历
- 遍历大量数据时，`foreach` 可能有轻微的性能开销（取决于集合类型）

```csharp
using System;

namespace ReturnDemo
{
    class Program
    {
        static void Main(string[] args)
        {

        /// 验证 Modbus 寄存器地址是否有效

        /// <param name="address">寄存器地址</param>

        static bool ValidateRegisterAddress(int address)
        {
            // 提前返回：地址不能为负
            if (address < 0)
            {
                Console.WriteLine("  错误: 地址不能为负数");
                return false;
            }

            // 提前返回：地址不能超过 49999
            if (address > 49999)
            {
                Console.WriteLine("  错误: 地址超出范围 (最大 49999)");
                return false;
            }

            // 提前返回：地址不能在 20000~29999 之间（保留区域）
            if (address >= 20000 && address <= 29999)
            {
                Console.WriteLine("  错误: 地址在保留范围内 (20000~29999)");
                return false;
            }

            // 所有检查通过
            return true;
        }

        /// <summary>
        /// 安全除法（避免除零异常）
        /// </summary>
        static double SafeDivide(double dividend, double divisor)
        {
            if (divisor == 0)
            {
                Console.WriteLine("  警告: 除数为零，返回 0");
                return 0;
            }

            return dividend / divisor;
        }
```

### 6.4 break / continue / return 对比

| 关键字 | 作用 | 影响范围 | 典型场景 |
|--------|------|----------|----------|
| `break` | 跳出当前循环 | 只影响当前循环 | 重试成功后停止、找到目标后停止搜索 |
| `continue` | 跳过本次循环，进入下一次 | 只影响当前循环的本次迭代 | 跳过无效数据、跳过离线设备 |
| `return` | 退出整个方法 | 退出整个方法，不只是循环 | 校验失败时提前退出、返回结果 |

### 注意事项

- `break` 只跳出**最内层**的循环，嵌套循环中要跳出外层循环需要用标志变量或 `goto`
- `continue` 只是跳过当前迭代，不影响循环的继续执行
- `return` 会退出整个方法，不仅是循环
- 善用 `return` 的"提前返回"模式，减少嵌套层级，提高可读性

```csharp
// ❌ 不推荐：深层嵌套

{
    bool valid = true;
    if (value >= 0)
    {
        if (value <= 100)
        {
            if (value % 2 == 0)
            {
                // 有效
            }
            else
            {
                valid = false;
            }
        }
        else
        {
            valid = false;
        }
    }
    else
    {
        valid = false;
    }
    return valid;
}

// ✅ 推荐：提前返回

{
    if (value < 0) return false;
    if (value > 100) return false;
    if (value % 2 != 0) return false;
    return true;
}
```

### 7.1 通信重试与数据校验完整示例

```csharp
using System;
using System.Threading;

namespace ScadaCommDemo
{
    class Program
    {
        // 系统常量
        public const int MAX_RETRY = 3;
        public const int RETRY_DELAY_MS = 1000;
        public const double TEMP_HIGH = 100.0;
        public const double TEMP_LOW = 0.0;
        public const double INVALID_VALUE = -999.0;

        static void Main(string[] args)
        {
            Console.WriteLine("===========================================");
            Console.WriteLine("   上位机通信与数据处理演示");
            Console.WriteLine("===========================================\n");

            // ===== 第一部分：通信重试 =====
            Console.WriteLine("--- 第一部分：PLC 通信重试 ---");
            bool connected = ConnectWithRetry("192.168.1.100", 502);
            Console.WriteLine($"连接结果: {(connected ? "成功" : "失败")}\n");

            // ===== 第二部分：数据采集与校验 =====
            if (connected)
            {
                Console.WriteLine("--- 第二部分：数据采集与校验 ---");

                // 模拟采集 8 个温度值
                double[] temps = CollectData(8);
                ProcessData(temps);
            }

            // ===== 第三部分：命令解析 =====
            Console.WriteLine("\n--- 第三部分：命令解析 ---");
            ProcessCommand("READ 40100");
            ProcessCommand("WRITE 40100 1234");
            ProcessCommand("STATUS");
            ProcessCommand("QUIT");
        }

        /// <summary>
        /// 带重试机制的 PLC 连接
        /// </summary>
        static bool ConnectWithRetry(string ip, int port)
        {
            for (int retry = 1; retry <= MAX_RETRY; retry++)
            {
                Console.Write($"  连接 {ip}:{port} (第{retry}/{MAX_RETRY}次)... ");

                // 模拟连接（第一次失败，第二次成功）
                bool success = retry >= 2;

                if (success)
                {
                    Console.WriteLine("成功");
                    return true;
                }

                Console.WriteLine("失败");

                if (retry < MAX_RETRY)
                {
                    Console.WriteLine($"  等待 {RETRY_DELAY_MS}ms 后重试...");
                    Thread.Sleep(RETRY_DELAY_MS);
                }
            }

            return false;
        }

        /// <summary>
        /// 模拟采集数据
        /// </summary>
        static double[] CollectData(int count)
        {
            double[] data = new double[count];
            Random rand = new Random(42);  // 固定种子，方便演示

            for (int i = 0; i < count; i++)
            {
                // 随机生成正常值或异常值
                if (rand.Next(10) < 2)  // 20% 概率异常
                {
                    data[i] = INVALID_VALUE;
                }
                else
                {
                    data[i] = 20.0 + rand.NextDouble() * 30.0;  // 20~50之间
                }
            }

            return data;
        }

        /// <summary>
        /// 数据处理：校验、统计、报警
        /// </summary>
        static void ProcessData(double[] data)
        {
            double sum = 0;
            double max = double.MinValue;
            double min = double.MaxValue;
            int validCount = 0;
            int alarmCount = 0;

            Console.WriteLine();

            for (int i = 0; i < data.Length; i++)
            {
                double value = data[i];
                int address = 40100 + i;

                // 跳过无效值
                if (value == INVALID_VALUE)
                {
                    Console.WriteLine($"  [{address}] 无效值 (-999.0)，跳过");
                    continue;
                }

                // 检查范围
                if (value < TEMP_LOW || value > TEMP_HIGH)
                {
                    Console.WriteLine($"  [{address}] 报警值: {value:F1}°C");
                    alarmCount++;
                }
                else
                {
                    Console.WriteLine($"  [{address}] 正常值: {value:F1}°C");
                }

                // 统计
                if (value > max) max = value;
                if (value < min) min = value;
                sum += value;
                validCount++;
            }

            // 输出统计结果
            Console.WriteLine();
            Console.WriteLine($"  有效数据: {validCount}/{data.Length}");
            Console.WriteLine($"  最高温度: {max:F1}°C");
            Console.WriteLine($"  最低温度: {min:F1}°C");

            if (validCount > 0)
            {
                Console.WriteLine($"  平均温度: {sum / validCount:F1}°C");
            }

            Console.WriteLine($"  报警次数: {alarmCount}");
        }

        /// <summary>
        /// 命令解析器
        /// </summary>
        static void ProcessCommand(string command)
        {
            Console.Write($"  命令: {command} → ");

            string[] parts = command.Split(' ');

            switch (parts[0])
            {
                case "READ":
                    if (parts.Length >= 2 && int.TryParse(parts[1], out int readAddr))
                        Console.WriteLine($"读取寄存器 {readAddr}");
                    else
                        Console.WriteLine("参数错误: READ <地址>");
                    break;

                case "WRITE":
                    if (parts.Length >= 3 && int.TryParse(parts[1], out int writeAddr)
                        && int.TryParse(parts[2], out int writeVal))
                        Console.WriteLine($"写入寄存器 {writeAddr} = {writeVal}");
                    else
                        Console.WriteLine("参数错误: WRITE <地址> <值>");
                    break;

                case "STATUS":
                    Console.WriteLine("查询设备状态");
                    break;

                case "QUIT":
                    Console.WriteLine("退出程序");
                    break;

                default:
                    Console.WriteLine($"未知命令: {parts[0]}");
                    break;
            }
        }
    }
}
```

## 9. 常见错误汇总

| 错误类型 | 错误示例 | 正确写法 | 说明 |
|---------|---------|---------|------|
| if 少了大括号 | `if(x>0) a++; b++;` | `if(x>0){a++; b++;}` | 没有 `{}` 时只有一行受控制 |
| switch 忘记 break | `case 1: Console.Write("1");` | `case 1: Console.Write("1"); break;` | C# 不允许贯穿，必须 break |
| for 死循环 | `for(int i=0; i<10; i--)` | `for(int i=0; i<10; i++)` | 确保循环变量向退出条件趋近 |
| 数组越界 | `arr[arr.Length]` | `arr[arr.Length - 1]` | 索引从 0 到 Length-1 |
| do-while 忘记分号 | `} while(x > 0)` | `} while(x > 0);` | 末尾必须有分号 |
| 在 foreach 中修改集合 | `foreach(var x in list) list.Remove(x)` | 使用 `for` 倒序遍历 | foreach 不能修改集合 |
| 比较用 = | `if (x = 5)` | `if (x == 5)` | C# 中 = 是赋值（但编译器会报错） |
| 条件写错 | `if (x > 0 && y > 0 \|\| z)` | `if (x > 0 && (y > 0 \|\| z > 0))` | 注意运算符优先级，用括号明确 |
| 循环变量作用域 | `for(int i=0;i<5;i++){}` 后用 `i` | for 外部声明或循环内使用 | 循环变量在循环外不可访问 |
| continue/break 用错层级 | break 误以为跳出嵌套 | 用标志变量或重构 | break 只跳出最内层循环 |
