## 1. 数组 Array

### 1.1 数组基础

数组是存储**固定数量**同类型元素的集合。数组创建后长度不能改变。

```csharp
// ===== 声明数组的几种方式 =====

// 方式一：指定长度，后赋值
int[] registers = new int[10];  // 创建长度为 10 的 int 数组（默认值为 0）

// 方式二：声明的同时初始化
int[] values = new int[] { 100, 200, 300, 400, 500 };

// 方式三：简写（编译器自动推断）
int[] data = { 100, 200, 300, 400, 500 };

// 方式四：字符串数组
string[] plcNames = { "PLC-001", "PLC-002", "PLC-003" };

// ===== 访问数组元素（索引从 0 开始）=====
Console.WriteLine(values[0]);    // 100（第一个元素）
Console.WriteLine(values[4]);    // 500（最后一个元素）
// Console.WriteLine(values[5]);  // ❌ IndexOutOfRangeException 越界！

// ===== 修改数组元素 =====
values[0] = 999;
Console.WriteLine(values[0]);    // 999

// ===== 获取数组长度 =====
Console.WriteLine(values.Length);  // 5
```

### 1.2 数组遍历

```csharp
using System;

namespace ArrayTraversal
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 上位机场景：遍历寄存器数据 =====
            ushort[] registerValues = { 1234, 5678, 9012, 3456, 7890, 2345, 6789, 0123 };
            int baseAddress = 40100;

            // 方式一：for 循环（需要索引时使用）
            Console.WriteLine("--- 方式一：for 循环 ---");
            for (int i = 0; i < registerValues.Length; i++)
            {
                int address = baseAddress + i;
                Console.WriteLine($"  地址 {address}: {registerValues[i]}");
            }

            // 方式二：foreach 循环（不需要索引时使用）
            Console.WriteLine("\n--- 方式二：foreach 循环 ---");
            int index = 0;
            foreach (ushort value in registerValues)
            {
                Console.WriteLine($"  [{index}] 值: {value}");
                index++;
            }
        }
    }
}
```

### 1.3 多维数组

```csharp
using System;

namespace MultiDimensionalArray
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 二维数组（矩阵）=====
            // 上位机场景：多个设备，每个设备多个寄存器
            // 行 = 设备，列 = 寄存器

            // 声明一个 3行5列 的二维数组
            int[,] deviceRegisters = new int[3, 5];

            // 赋值
            deviceRegisters[0, 0] = 1000;  // 第1台设备，第1个寄存器
            deviceRegisters[0, 1] = 1010;
            deviceRegisters[1, 0] = 2000;  // 第2台设备，第1个寄存器
            deviceRegisters[2, 4] = 3500;  // 第3台设备，第5个寄存器

            // 遍历二维数组
            Console.WriteLine("--- 设备寄存器数据矩阵 ---");
            for (int device = 0; device < deviceRegisters.GetLength(0); device++)
            {
                Console.Write($"设备{device + 1}: ");
                for (int reg = 0; reg < deviceRegisters.GetLength(1); reg++)
                {
                    Console.Write($"{deviceRegisters[device, reg],6}");
                }
                Console.WriteLine();
            }

            // ===== 交错数组（数组的数组）=====
            // 上位机场景：每个设备的寄存器数量不同
            int[][] sensorGroups = new int[3][];

            sensorGroups[0] = new int[] { 100, 200, 300 };       // 设备1有3个传感器
            sensorGroups[1] = new int[] { 400, 500 };           // 设备2有2个传感器
            sensorGroups[2] = new int[] { 600, 700, 800, 900 };  // 设备3有4个传感器

            Console.WriteLine("\n--- 交错数组（每个设备传感器数量不同）---");
            for (int i = 0; i < sensorGroups.Length; i++)
            {
                Console.Write($"设备{i + 1} ({sensorGroups[i].Length}个): ");
                foreach (int val in sensorGroups[i])
                {
                    Console.Write($"{val} ");
                }
                Console.WriteLine();
            }
        }
    }
}
```

### 1.4 数组的常用方法

```csharp
using System;

namespace ArrayMethods
{
    class Program
    {
        static void Main(string[] args)
        {
            int[] data = { 45, 12, 78, 33, 90, 56, 23, 67 };

            // ===== 排序 =====
            Array.Sort(data);                    // 升序排序
            Console.WriteLine($"最小值: {data[0]}");              // 12
            Console.WriteLine($"最大值: {data[data.Length - 1]}"); // 90

            Array.Reverse(data);               // 反转（降序）
            Console.WriteLine($"反转后第一个: {data[0]}");         // 90

            // ===== 查找 =====
            int index = Array.IndexOf(data, 45);  // 查找值 45 的索引
            Console.WriteLine($"45 的索引: {index}");

            bool exists = Array.Contains(data, 33); // 是否包含 33
            Console.WriteLine($"包含 33: {exists}");

            // ===== 复制 =====
            int[] copy = new int[4];
            Array.Copy(data, copy, 4);          // 从 data 复制前 4 个元素到 copy
            Console.WriteLine($"复制结果: {string.Join(", ", copy)}");

            // ===== 清空 =====
            Array.Clear(data, 0, 3);           // 将前 3 个元素设为 0
            Console.WriteLine($"清空后: {string.Join(", ", data)}");

            // ===== Resize（实际上是创建新数组）=====
            Array.Resize(ref data, 12);          // 将数组扩展为 12 个元素（新增元素为 0）
            Console.WriteLine($"新长度: {data.Length}");
        }
    }
}
```

### 1.5 注意事项

- 数组长度**固定不变**，创建后不能增减元素（如需动态大小，用 `List<T>`）
- 索引从 `0` 开始，最大有效索引是 `Length - 1`，越界会抛 `IndexOutOfRangeException`
- 二维数组 `[,]` 是真正的矩阵，交错数组 `[][]` 是"数组的数组"（每行长度可以不同）
- `Array.Sort()` 会修改原数组（原地排序），不是返回新数组
- 上位机中数组常用于：批量寄存器数据、传感器数据缓存、通信缓冲区等

## 2. List\<T\> 动态列表

### 2.1 什么是 List\<T\>

`List<T>` 是最常用的动态集合，可以随时添加、删除元素，大小自动调整。`T` 是泛型参数，表示列表中元素的类型。

```csharp
// ===== 创建 List =====
List<int> numbers = new List<int>();              // 空列表
List<string> names = new List<string>() { "PLC-001", "PLC-002" };  // 带初始值

// ===== 添加元素 =====
numbers.Add(10);          // 添加单个元素
numbers.Add(20);
numbers.Add(30);
numbers.AddRange(new int[] { 40, 50, 60 });  // 批量添加

// ===== 访问元素 =====
Console.WriteLine(numbers[0]);    // 10
Console.WriteLine(numbers.Count); // 6（元素个数，不是 Capacity）

// ===== 修改元素 =====
numbers[0] = 100;

// ===== 删除元素 =====
numbers.Remove(30);        // 删除第一个值为 30 的元素
numbers.RemoveAt(0);        // 删除索引为 0 的元素
numbers.RemoveAll(x => x > 40);  // 删除所有大于 40 的元素（使用 Lambda 表达式）
```

### 2.2 上位机场景：管理 PLC 设备列表

```csharp
using System;

namespace ListDeviceManager
{
    /// <summary>
    /// 设备信息类
    /// </summary>
    public class DeviceInfo
    {
        public string Name { get; set; }
        public string IpAddress { get; set; }
        public int Port { get; set; }
        public bool IsOnline { get; set; }

        public override string ToString()
        {
            return $"{Name} ({IpAddress}:{Port}) - {(IsOnline ? "在线" : "离线")}";
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            // ===== 创建设备列表 =====
            List<DeviceInfo> devices = new List<DeviceInfo>
            {
                new DeviceInfo { Name = "西门子PLC-01", IpAddress = "192.168.1.10", Port = 102, IsOnline = true },
                new DeviceInfo { Name = "ModbusPLC-01", IpAddress = "192.168.1.100", Port = 502, IsOnline = true },
                new DeviceInfo { Name = "ModbusPLC-02", IpAddress = "192.168.1.101", Port = 502, IsOnline = false },
                new DeviceInfo { Name = "ModbusPLC-03", IpAddress = "192.168.1.102", Port = 502, IsOnline = true },
                new DeviceInfo { Name = "变频器-01", IpAddress = "192.168.1.200", Port = 502, IsOnline = true },
            };

            Console.WriteLine("========== 设备管理 ==========\n");

            // ===== 1. 遍历所有设备 =====
            Console.WriteLine("--- 所有设备列表 ---");
            foreach (var device in devices)
            {
                Console.WriteLine($"  {device}");
            }
            Console.WriteLine($"共 {devices.Count} 台设备\n");

            // ===== 2. 添加新设备 =====
            Console.WriteLine("--- 添加新设备 ---");
            devices.Add(new DeviceInfo
            {
                Name = "ModbusPLC-04",
                IpAddress = "192.168.1.103",
                Port = 502,
                IsOnline = false
            });
            Console.WriteLine($"  已添加，当前共 {devices.Count} 台设备\n");

            // ===== 3. 查找设备 =====
            Console.WriteLine("--- 查找设备 ---");

            // Find：查找第一个符合条件的元素
            DeviceInfo found = devices.Find(d => d.Name == "西门子PLC-01");
            if (found != null)
                Console.WriteLine($"  Find: 找到 → {found.Name}");

            // FindAll：查找所有符合条件的元素
            List<DeviceInfo> offlineDevices = devices.FindAll(d => !d.IsOnline);
            Console.WriteLine($"  FindAll: 离线设备 {offlineDevices.Count} 台:");
            foreach (var d in offlineDevices)
                Console.WriteLine($"    {d.Name}");

            // Exists：判断是否存在
            bool exists = devices.Exists(d => d.IpAddress == "192.168.1.200");
            Console.WriteLine($"  Exists: IP 192.168.1.200 存在: {exists}");

            // IndexOf：查找索引
            int idx = devices.FindIndex(d => d.Name == "ModbusPLC-02");
            Console.WriteLine($"  FindIndex: ModbusPLC-02 索引: {idx}\n");

            // ===== 4. 删除设备 =====
            Console.WriteLine("--- 删除设备 ---");

            // 按条件删除所有离线设备
            int removedCount = devices.RemoveAll(d => !d.IsOnline);
            Console.WriteLine($"  已移除 {removedCount} 台离线设备");
            Console.WriteLine($"  剩余 {devices.Count} 台设备\n");

            // ===== 5. 排序 =====
            Console.WriteLine("--- 按 IP 地址排序 ---");
            devices.Sort((a, b) => string.Compare(a.IpAddress, b.IpAddress, StringComparison.Ordinal));
            foreach (var device in devices)
                Console.WriteLine($"  {device.Name}: {device.IpAddress}");

            // ===== 6. 插入设备 =====
            Console.WriteLine("\n--- 在指定位置插入 ---");
            devices.Insert(0, new DeviceInfo
            {
                Name = "主PLC",
                IpAddress = "192.168.1.1",
                Port = 502,
                IsOnline = true
            });
            Console.WriteLine($"  在索引0插入 '主PLC'，当前第一个: {devices[0].Name}");

            // ===== 7. Contains 判断包含 =====
            bool hasDevice = devices.Contains(found);
            Console.WriteLine($"\n  Contains: 是否包含西门子PLC-01: {hasDevice}");
        }
    }
}
```

### 2.3 List\<T\> 常用方法汇总

| 方法 | 用途 | 示例 |
|------|------|------|
| `Add(item)` | 添加元素 | `list.Add(10);` |
| `AddRange(collection)` | 批量添加 | `list.AddRange(new[]{1,2,3});` |
| `Insert(index, item)` | 在指定位置插入 | `list.Insert(0, item);` |
| `Remove(item)` | 删除第一个匹配项 | `list.Remove(10);` |
| `RemoveAt(index)` | 按索引删除 | `list.RemoveAt(0);` |
| `RemoveAll(predicate)` | 按条件删除所有匹配项 | `list.RemoveAll(x => x > 10);` |
| `RemoveRange(index, count)` | 删除指定范围的元素 | `list.RemoveRange(0, 3);` |
| `Find(predicate)` | 查找第一个匹配项 | `list.Find(x => x > 5);` |
| `FindAll(predicate)` | 查找所有匹配项 | `list.FindAll(x => x > 5);` |
| `FindIndex(predicate)` | 查找第一个匹配项的索引 | `list.FindIndex(x => x > 5);` |
| `Exists(predicate)` | 判断是否存在 | `list.Exists(x => x > 5);` |
| `Contains(item)` | 判断是否包含 | `list.Contains(10);` |
| `Count` | 获取元素数量 | `int n = list.Count;` |
| `Sort()` | 排序 | `list.Sort();` |
| `Reverse()` | 反转 | `list.Reverse();` |
| `Clear()` | 清空所有元素 | `list.Clear();` |
| `ForEach(action)` | 对每个元素执行操作 | `list.ForEach(x => Console.WriteLine(x));` |

### 2.4 注意事项

- `List<T>` 的索引和数组一样从 0 开始
- `Remove()` 删除的是第一个匹配的元素，不是所有匹配的
- `RemoveAll()` 使用 Lambda 表达式，如 `list.RemoveAll(x => x > 100)`
- `Sort()` 默认使用元素的自然排序，自定义排序需要传入比较器 `Comparison<T>`
- 在 `foreach` 中不能添加/删除元素，需要用 `for` 倒序遍历或先收集要删除的项
- 上位机中最常用的操作：`Add`（添加设备）、`Find`（查找设备）、`RemoveAll`（移除离线设备）

## 3. Dictionary\<TKey,TValue\> 键值对

### 3.1 什么是 Dictionary

`Dictionary<TKey, TValue>` 是键值对集合，通过键（Key）快速查找值（Value）。类似于现实生活中的字典（通过拼音查汉字）。

```csharp
// ===== 创建 Dictionary =====
Dictionary<string, int> ages = new Dictionary<string, int>();

// ===== 添加键值对 =====
ages["张三"] = 25;
ages["李四"] = 30;
ages.Add("王五", 28);  // 另一种添加方式

// ===== 通过键访问值 =====
Console.WriteLine(ages["张三"]);    // 25

// ===== 判断键是否存在 =====
if (ages.ContainsKey("张三"))
    Console.WriteLine("张三存在");

// ===== TryGetValue（推荐的安全访问方式）=====
if (ages.TryGetValue("赵六", out int age))
    Console.WriteLine($"赵六的年龄: {age}");
else
    Console.WriteLine("赵六不存在");

// ===== 遍历 =====
foreach (KeyValuePair<string, int> kv in ages)
{
    Console.WriteLine($"姓名: {kv.Key}, 年龄: {kv.Value}");
}

// 简写（使用 var）
foreach (var kv in ages)
{
    Console.WriteLine($"{kv.Key}: {kv.Value}");
}
```

### 3.2 上位机场景：寄存器地址映射表

```csharp
using System;

namespace DictionaryRegisterMap
{
    /// <summary>
    /// 寄存器定义
    /// </summary>
    public class RegisterDefinition
    {
        public string Name { get; set; }           // 寄存器名称
        public ushort Address { get; set; }        // 寄存器地址
        public string DataType { get; set; }      // 数据类型
        public double Scale { get; set; }          // 缩放系数
        public string Unit { get; set; }           // 单位
        public double HighLimit { get; set; }     // 上限
        public double LowLimit { get; set; }      // 下限

        public override string ToString()
        {
            return $"{Name} (地址:{Address}, 类型:{DataType}, 范围:{LowLimit}~{HighLimit}{Unit})";
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            // ===== 场景一：用地址作为键的寄存器映射表 =====
            Dictionary<ushort, RegisterDefinition> registerMap = new Dictionary<ushort, RegisterDefinition>();

            // 添加寄存器定义
            registerMap[40100] = new RegisterDefinition
            {
                Name = "主反应釜温度", Address = 40100,
                DataType = "Float", Scale = 0.1, Unit = "°C",
                HighLimit = 120.0, LowLimit = -10.0
            };
            registerMap[40101] = new RegisterDefinition
            {
                Name = "主反应釜压力", Address = 40101,
                DataType = "Float", Scale = 0.01, Unit = "kPa",
                HighLimit = 500.0, LowLimit = 0.0
            };
            registerMap[40102] = new RegisterDefinition
            {
                Name = "冷却水流量", Address = 40102,
                DataType = "UInt16", Scale = 1.0, Unit = "L/min",
                HighLimit = 1000.0, LowLimit = 0.0
            };
            registerMap[40103] = new RegisterDefinition
            {
                Name = "进料阀门开度", Address = 40103,
                DataType = "UInt16", Scale = 0.1, Unit = "%",
                HighLimit = 100.0, LowLimit = 0.0
            };
            registerMap[40104] = new RegisterDefinition
            {
                Name = "电机运行状态", Address = 40104,
                DataType = "Bool", Scale = 1.0, Unit = "",
                HighLimit = 1.0, LowLimit = 0.0
            };

            Console.WriteLine("========== 寄存器映射表 ==========\n");

            // 查找指定地址的寄存器
            ushort targetAddr = 40101;
            if (registerMap.TryGetValue(targetAddr, out RegisterDefinition reg))
            {
                Console.WriteLine($"查找地址 {targetAddr}:");
                Console.WriteLine($"  名称: {reg.Name}");
                Console.WriteLine($"  类型: {reg.DataType}");
                Console.WriteLine($"  单位: {reg.Unit}");
                Console.WriteLine($"  范围: {reg.LowLimit} ~ {reg.HighLimit}");
            }

            // 遍历所有寄存器
            Console.WriteLine("\n--- 所有寄存器定义 ---");
            foreach (var kv in registerMap)
            {
                Console.WriteLine($"  地址 {kv.Key}: {kv.Value}");
            }

            // 统计
            Console.WriteLine($"\n共定义 {registerMap.Count} 个寄存器");

            // ===== 场景二：用设备名作为键的设备管理 =====
            Console.WriteLine("\n========== 设备管理 ==========\n");

            Dictionary<string, string> deviceIpMap = new Dictionary<string, string>
            {
                ["PLC-001"] = "192.168.1.100",
                ["PLC-002"] = "192.168.1.101",
                ["PLC-003"] = "192.168.1.102",
                ["变频器-01"] = "192.168.1.200",
                ["变频器-02"] = "192.168.1.201"
            };

            // 查找设备 IP
            string deviceName = "PLC-002";
            if (deviceIpMap.TryGetValue(deviceName, out string ip))
            {
                Console.WriteLine($"{deviceName} 的 IP: {ip}");
            }

            // 修改设备 IP
            deviceIpMap["PLC-002"] = "192.168.2.101";
            Console.WriteLine($"PLC-002 新 IP: {deviceIpMap["PLC-002"]}");

            // 删除设备
            deviceIpMap.Remove("变频器-02");
            Console.WriteLine($"删除后设备数: {deviceIpMap.Count}");

            // ===== 场景三：枚举值与描述的映射 =====
            Console.WriteLine("\n========== Modbus 功能码映射 ==========\n");

            Dictionary<byte, string> funcCodeMap = new Dictionary<byte, string>
            {
                [0x01] = "读线圈 (Read Coils)",
                [0x02] = "读离散输入 (Read Discrete Inputs)",
                [0x03] = "读保持寄存器 (Read Holding Registers)",
                [0x04] = "读输入寄存器 (Read Input Registers)",
                [0x05] = "写单个线圈 (Write Single Coil)",
                [0x06] = "写单个寄存器 (Write Single Register)",
                [0x0F] = "写多个线圈 (Write Multiple Coils)",
                [0x10] = "写多个寄存器 (Write Multiple Registers)"
            };

            byte code = 0x03;
            if (funcCodeMap.TryGetValue(code, out string desc))
            {
                Console.WriteLine($"功能码 0x{code:X2}: {desc}");
            }

            Console.WriteLine("\n所有功能码:");
            foreach (var kv in funcCodeMap)
            {
                Console.WriteLine($"  0x{kv.Key:X2}: {kv.Value}");
            }
        }
    }
}
```

### 3.3 Dictionary 常用方法汇总

| 方法 | 用途 | 示例 |
|------|------|------|
| `[key] = value` | 添加或修改键值对 | `dict["key"] = "value";` |
| `Add(key, value)` | 添加键值对（键已存在则抛异常） | `dict.Add("k", "v");` |
| `Remove(key)` | 删除指定键 | `dict.Remove("key");` |
| `ContainsKey(key)` | 判断键是否存在 | `dict.ContainsKey("key")` |
| `ContainsValue(value)` | 判断值是否存在 | `dict.ContainsValue("v")` |
| `TryGetValue(key, out var)` | 安全获取值 | `dict.TryGetValue("k", out var v)` |
| `Clear()` | 清空所有 | `dict.Clear()` |
| `Count` | 获取键值对数量 | `int n = dict.Count;` |
| `Keys` | 获取所有键的集合 | `foreach(var k in dict.Keys)` |
| `Values` | 获取所有值的集合 | `foreach(var v in dict.Values)` |

### 3.4 注意事项

- Dictionary 的键必须是唯一的，重复添加相同键会抛异常（用 `[key] = value` 则是覆盖）
- 键不能为 `null`，值可以为 `null`
- `TryGetValue` 是最安全的访问方式，推荐使用
- 遍历 Dictionary 时不保证顺序（如需有序，使用 `SortedDictionary`）
- 上位机中 Dictionary 最常用于：寄存器地址映射、设备名查找、枚举描述映射、配置项管理等

### 练习建议

2. 实现一个设备名称到 IP 地址的查找器，支持模糊搜索（如输入 "PLC" 返回所有 PLC 设备）
3. 用 Dictionary 实现一个简单的缓存系统（键=寄存器地址，值=最新读取值）

## 4. 其他集合

### 4.1 Queue\<T\> 队列（先进先出 FIFO）

队列遵循 **先进先出（First In, First Out）** 原则。适合需要"排队处理"的场景。

```csharp
using System;
using System.Collections.Generic;

namespace QueueDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 上位机场景：命令队列 =====
            // 先进先出：先发送的命令先执行
            Queue<string> commandQueue = new Queue<string>();

            // 入队（Enqueue）
            commandQueue.Enqueue("READ 40100");        // 第一个入队
            commandQueue.Enqueue("WRITE 40100 1234");  // 第二个入队
            commandQueue.Enqueue("READ 40101");        // 第三个入队
            commandQueue.Enqueue("WRITE 40101 5678");  // 第四个入队

            Console.WriteLine($"待执行命令数: {commandQueue.Count}");

            // 查看队首（不删除）
            Console.WriteLine($"下一个命令: {commandQueue.Peek()}");

            // 出队（Dequeue）—— 按顺序执行
            Console.WriteLine("\n--- 执行命令 ---");
            while (commandQueue.Count > 0)
            {
                string command = commandQueue.Dequeue();  // 取出并移除队首
                Console.WriteLine($"  执行: {command}  (剩余: {commandQueue.Count})");
            }

            Console.WriteLine($"\n命令队列已清空: {commandQueue.Count == 0}");

            // ===== 上位机场景：报警消息队列 =====
            Console.WriteLine("\n--- 报警消息队列 ---");

            Queue<string> alarmQueue = new Queue<string>();

            // 模拟报警消息入队
            alarmQueue.Enqueue("[10:00:01] 高温报警: 反应釜温度 125°C");
            alarmQueue.Enqueue("[10:00:03] 通信超时: PLC-002 无响应");
            alarmQueue.Enqueue("[10:00:05] 低压报警: 压缩空气压力 0.3MPa");

            // 按顺序处理报警
            while (alarmQueue.Count > 0)
            {
                string alarm = alarmQueue.Dequeue();
                Console.WriteLine($"  处理报警: {alarm}");
                // 这里可以调用报警处理方法
            }
        }
    }
}
```

### 4.2 Stack\<T\> 栈（后进先出 LIFO）

栈遵循 **后进先出（Last In, First Out）** 原则。适合需要"撤销"或"回退"的场景。

```csharp
using System;
using System.Collections.Generic;

namespace StackDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 上位机场景：操作历史记录（撤销功能）=====
            Stack<string> operationHistory = new Stack<string>();

            // 入栈（Push）
            operationHistory.Push("连接 PLC-001");
            operationHistory.Push("读取寄存器 40100");
            operationHistory.Push("修改参数: 温度上限 = 120°C");
            operationHistory.Push("写入寄存器 40100 = 1200");

            Console.WriteLine($"操作记录数: {operationHistory.Count}");

            // 查看栈顶（不删除）
            Console.WriteLine($"最近操作: {operationHistory.Peek()}");

            // 出栈（Pop）—— 逆序回放操作
            Console.WriteLine("\n--- 撤销操作（后进先出）---");
            while (operationHistory.Count > 0)
            {
                string operation = operationHistory.Pop();  // 取出并移除栈顶
                Console.WriteLine($"  撤销: {operation}");
            }

            // ===== 上位机场景：Modbus 帧解析栈 =====
            Console.WriteLine("\n--- 数据帧解析 ---");

            Stack<byte> frameStack = new Stack<byte>();
            byte[] frame = { 0x01, 0x03, 0x04, 0x00, 0x48, 0xF7, 0xA0 };

            // 将数据帧压入栈（倒序）
            foreach (byte b in frame)
            {
                frameStack.Push(b);
            }

            // 弹出时是正序
            Console.Write("帧数据: ");
            while (frameStack.Count > 0)
            {
                byte b = frameStack.Pop();
                Console.Write($"{b:X2} ");
            }
            Console.WriteLine();
        }
    }
}
```

### 4.3 HashSet\<T\> 哈希集合

`HashSet<T>` 是不包含重复元素的无序集合。适合需要"去重"的场景。

```csharp
using System;
using System.Collections.Generic;

namespace HashSetDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 上位机场景：已报警地址集合（去重）=====
            HashSet<int> alarmedAddresses = new HashSet<int>();

            // 添加报警地址
            alarmedAddresses.Add(40100);
            alarmedAddresses.Add(40101);
            alarmedAddresses.Add(40100);  // 重复添加，自动忽略！
            alarmedAddresses.Add(40102);

            Console.WriteLine($"报警地址数: {alarmedAddresses.Count}");  // 3（不是4）
            Console.WriteLine($"40100 是否报警: {alarmedAddresses.Contains(40100)}");  // true

            // 遍历
            Console.WriteLine("\n所有报警地址:");
            foreach (int addr in alarmedAddresses)
            {
                Console.WriteLine($"  {addr}");
            }

            // 解除报警
            alarmedAddresses.Remove(40101);
            Console.WriteLine($"\n解除 40101 报警后: {alarmedAddresses.Count} 个");

            // ===== 上位机场景：设备名称去重 =====
            Console.WriteLine("\n--- 设备名称去重 ---");

            string[] rawNames = { "PLC-001", "PLC-002", "PLC-001", "PLC-003", "PLC-002", "PLC-001" };

            // 用 HashSet 去重
            HashSet<string> uniqueNames = new HashSet<string>(rawNames);

            Console.WriteLine($"原始: {rawNames.Length} 条");
            Console.WriteLine($"去重后: {uniqueNames.Count} 条");
            foreach (string name in uniqueNames)
            {
                Console.WriteLine($"  {name}");
            }

            // ===== 上位机场景：集合运算 =====
            Console.WriteLine("\n--- 集合运算 ---");

            HashSet<int> setA = new HashSet<int> { 40100, 40101, 40102, 40103 };
            HashSet<int> setB = new HashSet<int> { 40102, 40103, 40104, 40105 };

            // 并集（A + B 所有元素）
            setA.UnionWith(setB);
            Console.WriteLine($"并集: {string.Join(", ", setA)}");  // 40100~40105

            // 交集（A 和 B 共同的元素）
            setA.IntersectWith(setB);
            Console.WriteLine($"交集: {string.Join(", ", setA)}");  // 40102, 40103
        }
    }
}
```

### 4.4 集合对比表

| 集合类型 | 特点 | 上位机典型场景 |
|---------|------|---------------|
| `Array` | 固定长度，快速索引 | 通信缓冲区、寄存器数据块 |
| `List<T>` | 动态大小，有序 | 设备列表、传感器数据记录 |
| `Dictionary<TKey,TValue>` | 键值对，快速查找 | 寄存器映射表、设备IP查找 |
| `Queue<T>` | 先进先出 | 命令队列、报警消息队列 |
| `Stack<T>` | 后进先出 | 操作历史（撤销）、帧解析 |
| `HashSet<T>` | 不重复元素 | 报警去重、在线设备集合 |

### 4.5 注意事项

- `Queue` 和 `Stack` 不要通过索引访问元素（它们不支持 `[]`）
- `HashSet` 不支持重复元素，添加重复元素不会报错，只是静默忽略
- `HashSet` 是无序的，遍历顺序和添加顺序不一定一致
- 上位机中 `Queue` 常用于通信命令排队发送，避免并发冲突
- 上位机中 `HashSet` 常用于跟踪"哪些设备已报警"（避免重复报警通知）

### 练习建议

1. 实现一个命令队列：入队多条 Modbus 读写命令，按顺序逐条执行
2. 用 `HashSet` 实现报警管理：相同的报警只记录一次，解除后才能再次报警
3. 用 `Stack` 实现简单的操作撤销功能

## 5. LINQ 基础

### 5.1 什么是 LINQ

LINQ（Language Integrated Query，语言集成查询）是 C# 内置的强大查询语法，可以方便地对集合进行筛选、排序、分组、统计等操作。

LINQ 有两种写法：
- **查询语法**：类似 SQL 的写法（`from ... where ... select`）
- **方法语法**：链式调用方法（`.Where().Select().OrderBy()`）

两种写法可以混用，方法语法更常用。

### 5.2 Where - 筛选

```csharp
using System;
using System.Linq;

namespace LinqWhere
{
    class Program
    {
        static void Main(string[] args)
        {
            // 准备数据
            var devices = new[]
            {
                new { Name = "PLC-001", Ip = "192.168.1.100", Online = true, Port = 502 },
                new { Name = "PLC-002", Ip = "192.168.1.101", Online = false, Port = 502 },
                new { Name = "PLC-003", Ip = "192.168.1.102", Online = true, Port = 502 },
                new { Name = "变频器-01", Ip = "192.168.1.200", Online = true, Port = 502 },
                new { Name = "变频器-02", Ip = "192.168.1.201", Online = false, Port = 502 },
                new { Name = "温控仪-01", Ip = "192.168.1.150", Online = true, Port = 8899 },
            };

            // ===== Where: 筛选在线设备 =====
            var onlineDevices = devices.Where(d => d.Online);
            Console.WriteLine("--- 在线设备 ---");
            foreach (var d in onlineDevices)
                Console.WriteLine($"  {d.Name} ({d.Ip})");

            // ===== Where: 筛选 502 端口的设备 =====
            var modbusDevices = devices.Where(d => d.Port == 502);
            Console.WriteLine($"\n--- Modbus 设备 ({modbusDevices.Count()} 台) ---");
            foreach (var d in modbusDevices)
                Console.WriteLine($"  {d.Name}");

            // ===== Where: 多条件筛选 =====
            var onlineModbus = devices.Where(d => d.Online && d.Port == 502);
            Console.WriteLine($"\n--- 在线的 Modbus 设备 ({onlineModbus.Count()} 台) ---");
            foreach (var d in onlineModbus)
                Console.WriteLine($"  {d.Name} ({d.Ip})");

            // ===== 查询语法写法（与上面等价）=====
            var onlineQuery = from d in devices
                             where d.Online
                             select d;
        }
```

### 5.4 OrderBy - 排序

```csharp
using System;
using System.Linq;

namespace LinqOrderBy
{
    class Program
    {
        static void Main(string[] args)
        {
            var sensors = new[]
            {
                new { Name = "温度传感器", Value = 25.6, Unit = "°C" },

                new { Name = "流量传感器", Value = 50.2, Unit = "L/min" },

            // ===== OrderByDescending: 降序排序 =====
            var byValueDesc = sensors.OrderByDescending(s => s.Value);

            foreach (var s in byValueDesc)
                Console.WriteLine($"  {s.Name}: {s.Value} {s.Unit}");

            var devices = new[]
            {

            var sorted = devices.OrderBy(d => d.Area).ThenBy(d => d.Priority);
            Console.WriteLine("\n--- 按区域+优先级排序 ---");
            foreach (var d in sorted)
                Console.WriteLine($"  {d.Name}: {d.Area}, 优先级: {d.Priority}");
```

### 5.5 GroupBy - 分组

```csharp
using System;
using System.Linq;

namespace LinqGroupBy
{
    class Program
    {
        static void Main(string[] args)
        {
            var devices = new[]
            {
                new { Name = "PLC-001", Area = "车间A", Online = true },
                new { Name = "PLC-002", Area = "车间A", Online = false },
                new { Name = "PLC-003", Area = "车间B", Online = true },
                new { Name = "变频器-01", Area = "车间A", Online = true },
                new { Name = "变频器-02", Area = "车间B", Online = false },
                new { Name = "温控仪-01", Area = "车间A", Online = true },

            var groupedByArea = devices.GroupBy(d => d.Area);

            foreach (var group in groupedByArea)

                foreach (var d in group)
                    Console.WriteLine($"  {d.Name} ({(d.Online ? "在线" : "离线")})");
            }

            // ===== GroupBy: 按在线状态分组并统计 =====
            var groupedByStatus = devices.GroupBy(d => d.Online ? "在线" : "离线");

                Total = g.Count(),
                Online = g.Count(d => d.Online),
                Offline = g.Count(d => !d.Online)
            });

            Console.WriteLine("\n--- 区域统计 ---");
            foreach (var stat in areaStats)
            {
                Console.WriteLine($"{stat.Area}: 总计 {stat.Total} 台, " +
                    $"在线 {stat.Online} 台, 离线 {stat.Offline} 台");
```

### 5.6 First / FirstOrDefault / Single / SingleOrDefault

```csharp
using System;
using System.Linq;

namespace LinqFirstDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            var devices = new[]
            {
                new { Name = "PLC-001", Ip = "192.168.1.100" },
                new { Name = "PLC-002", Ip = "192.168.1.101" },
                new { Name = "PLC-003", Ip = "192.168.1.102" },
            };

            // ===== First: 第一个匹配项（没有则抛异常）=====
            var first = devices.First(d => d.Name.Contains("PLC"));
            Console.WriteLine($"First: {first.Name}");

            // ===== FirstOrDefault: 第一个匹配项（没有则返回默认值）=====
            var foundOrDefault = devices.FirstOrDefault(d => d.Name == "不存在的设备");
            Console.WriteLine($"FirstOrDefault: {(foundOrDefault != null ? foundOrDefault.Name : "null")}");

            // ===== Single: 唯一匹配项（多于一个则抛异常）=====
            var single = devices.Single(d => d.Name == "PLC-002");
            Console.WriteLine($"Single: {single.Name}");

            // ===== SingleOrDefault: 唯一匹配项（没有则返回默认值，多于一个则抛异常）=====
            var singleOrDefault = devices.SingleOrDefault(d => d.Name == "不存在的设备");
            Console.WriteLine($"SingleOrDefault: {(singleOrDefault != null ? singleOrDefault.Name : "null")}");

            // ===== 推荐使用 FirstOrDefault + null 检查 =====
            var target = devices.FirstOrDefault(d => d.Ip == "192.168.1.101");
            if (target != null)
            {
                Console.WriteLine($"\n找到设备: {target.Name} ({target.Ip})");
            }
            else
            {
                Console.WriteLine("\n未找到目标设备");
            }
        }
    }
}
```

### 5.7 常用 LINQ 方法汇总

| 方法 | 用途 | 返回类型 | 示例 |
|------|------|----------|------|
| `Where(predicate)` | 筛选 | `IEnumerable<T>` | `.Where(x => x > 10)` |
| `Select(func)` | 投影/转换 | `IEnumerable<R>` | `.Select(x => x.Name)` |
| `OrderBy(key)` | 升序排序 | `IOrderedEnumerable<T>` | `.OrderBy(x => x.Value)` |
| `OrderByDescending(key)` | 降序排序 | `IOrderedEnumerable<T>` | `.OrderByDescending(x => x.Value)` |
| `ThenBy(key)` | 二级升序 | `IOrderedEnumerable<T>` | `.OrderBy(x => x.Area).ThenBy(x => x.Id)` |
| `GroupBy(key)` | 分组 | `IEnumerable<IGrouping>` | `.GroupBy(x => x.Area)` |
| `First()` | 第一个（无则异常） | `T` | `.First(x => x.Id == 1)` |
| `FirstOrDefault()` | 第一个（无则默认） | `T` | `.FirstOrDefault(x => x.Id == 1)` |
| `Single()` | 唯一一个 | `T` | `.Single(x => x.Id == 1)` |
| `SingleOrDefault()` | 唯一个（无则默认） | `T` | `.SingleOrDefault(x => x.Id == 1)` |
| `Count()` | 计数 | `int` | `.Count(x => x > 10)` |
| `Sum()` | 求和 | 数值 | `.Sum(x => x.Value)` |
| `Average()` | 平均值 | `double` | `.Average(x => x.Value)` |
| `Min()` / `Max()` | 最小/最大 | `T` | `.Max(x => x.Value)` |
| `Any()` | 是否存在 | `bool` | `.Any(x => x > 10)` |
| `All()` | 是否全部满足 | `bool` | `.All(x => x > 0)` |
| `Distinct()` | 去重 | `IEnumerable<T>` | `.Distinct()` |
| `Skip(n)` | 跳过前 n 个 | `IEnumerable<T>` | `.Skip(10)` |
| `Take(n)` | 取前 n 个 | `IEnumerable<T>` | `.Take(10)` |
| `ToArray()` | 转为数组 | `T[]` | `.Where(...).ToArray()` |
| `ToList()` | 转为列表 | `List<T>` | `.Where(...).ToList()` |

### 5.8 注意事项

- LINQ 是**延迟执行**的，查询定义后不会立即执行，遍历时才真正执行
- 如果需要立即执行，调用 `.ToList()` 或 `.ToArray()`
- `First()` 找不到会抛异常，`FirstOrDefault()` 找不到返回默认值（引用类型为 null）
- `Single()` 找到多个也会抛异常，确保结果唯一时才用
- LINQ 方法语法更灵活，支持更多操作；查询语法更接近 SQL，适合简单的 select
- 上位机中最常用的 LINQ 操作：`Where`（筛选）、`Select`（投影）、`FirstOrDefault`（查找）、`OrderBy`（排序）

### 练习建议

1. 用 LINQ 从设备列表中筛选出所有在线的 Modbus 设备，按 IP 排序
2. 用 LINQ GroupBy 按区域分组统计在线/离线设备数量
3. 用 LINQ 计算一组传感器数据中的最大值、最小值、平均值和超限个数

```csharp
    /// <summary>
    /// 实时数据记录
    /// </summary>
    public class SensorRecord

        public string RegisterName { get; set; }
        public ushort Address { get; set; }

        static void Main(string[] args)

            // 按区域分组统计
            var areaStats = devices.GroupBy(d => d.Area).Select(g => new

                Total = g.Count(),

                Console.WriteLine($"  {s.Area}: 总计{s.Total}台, 在线{s.Online}台, 离线{s.Offline}台");

            var targetDevice = devices.FirstOrDefault(d => d.Name == "主PLC");
            if (targetDevice != null)
                Console.WriteLine($"\n找到主PLC: {targetDevice.IpAddress}");

            {
                [40100] = new RegisterDef { Name = "反应釜温度", Address = 40100, DataType = "Float", Scale = 0.1, Unit = "°C", HighLimit = 120, LowLimit = -10 },

            };

            Console.WriteLine("寄存器定义表:");
            foreach (var kv in regMap.OrderBy(kv => kv.Key))
            {
                var r = kv.Value;
                Console.WriteLine($"  {r.Address}: {r.Name} ({r.DataType}, {r.LowLimit}~{r.HighLimit} {r.Unit})");
            }

            // 查找寄存器信息
            ushort lookupAddr = 40101;
            if (regMap.TryGetValue(lookupAddr, out RegisterDef reg))
            {
                Console.WriteLine($"\n地址 {lookupAddr} -> {reg.Name}");
            }

                DateTime time = DateTime.Now.AddMinutes(-10 + t * 2);

                // 为每个寄存器生成数据
                foreach (var kv in regMap)
                {
                    var r = kv.Value;
                    ushort rawVal = (ushort)rand.Next(0, 10000);
                    double actual = rawVal * r.Scale;

                    // 判断是否报警
                    bool isAlarm = actual > r.HighLimit || actual < r.LowLimit;

                    records.Add(new SensorRecord
                    {
                        Time = time,
                        DeviceName = "1号温度模块",
                        RegisterName = r.Name,
                        Address = r.Address,
                        RawValue = rawVal,
                        ActualValue = actual,
                        IsAlarm = isAlarm
                    });
                }
            }

            Console.WriteLine($"共采集 {records.Count} 条数据记录");

            // 筛选报警记录
            var alarmRecords = records.Where(r => r.IsAlarm).ToList();
            Console.WriteLine($"报警记录: {alarmRecords.Count} 条");
            foreach (var r in alarmRecords)
            {
                Console.WriteLine($"  [{r.Time:HH:mm}] {r.RegisterName}: {r.ActualValue:F1}");
            }

            // 按寄存器分组统计
            var regStats = records.GroupBy(r => r.RegisterName).Select(g => new
            {
                Name = g.Key,
                Count = g.Count(),
                Max = g.Max(r => r.ActualValue),
                Min = g.Min(r => r.ActualValue),
                Avg = g.Average(r => r.ActualValue),
                Alarms = g.Count(r => r.IsAlarm)
            });

            Console.WriteLine("\n数据统计:");
            foreach (var s in regStats)
            {
                Console.WriteLine($"  {s.Name}: 平均={s.Avg:F1}, 最大={s.Max:F1}, " +
                    $"最小={s.Min:F1}, 报警={s.Alarms}次");
            }

            // ===== 4. 命令队列 =====
            Console.WriteLine("\n--- 第四部分：命令队列 ---\n");

            Queue<string> cmdQueue = new Queue<string>();
            cmdQueue.Enqueue($"READ {40100} {5}");     // 批量读取 40100~40104
            cmdQueue.Enqueue($"WRITE {40105} 1");       // 启动搅拌电机
            cmdQueue.Enqueue($"READ {40100} {5}");     // 再次读取确认

            Console.WriteLine("待执行命令:");
            while (cmdQueue.Count > 0)
            {
                string cmd = cmdQueue.Dequeue();
                Console.WriteLine($"  执行: {cmd}  (剩余: {cmdQueue.Count})");
            }
        }
    }
}
```

### 6.2 上位机数据采集缓冲区

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

namespace DataBufferDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 上位机场景：固定大小的数据缓冲区 =====
            // 保留最新的 100 条传感器数据（超出时自动丢弃最旧的）
            int bufferSize = 100;
            Queue<double> dataBuffer = new Queue<double>();

            Console.WriteLine("--- 数据缓冲区演示 ---\n");

            // 模拟写入 150 条数据
            Random rand = new Random();
            for (int i = 1; i <= 150; i++)
            {
                double value = 25.0 + rand.NextDouble() * 10;
                dataBuffer.Enqueue(value);

                // 超出缓冲区大小时，移除最旧的数据
                if (dataBuffer.Count > bufferSize)
                {
                    dataBuffer.Dequeue();
                }
            }

            Console.WriteLine($"缓冲区大小: {dataBuffer.Count}/{bufferSize}");
            Console.WriteLine($"最新值: {dataBuffer.Last():F2}");

            // 使用 LINQ 统计缓冲区数据
            var bufferList = dataBuffer.ToList();
            Console.WriteLine($"平均值: {bufferList.Average():F2}");
            Console.WriteLine($"最大值: {bufferList.Max():F2}");
            Console.WriteLine($"最小值: {bufferList.Min():F2}");

            // 统计超限次数
            int overLimit = bufferList.Count(v => v > 32.0);
            Console.WriteLine($"超限次数: {overLimit}");

            // ===== 报警去重集合 =====
            Console.WriteLine("\n--- 报警去重演示 ---\n");

            HashSet<string> activeAlarms = new HashSet<string>();

            // 模拟多次报警
            string[] alarmMessages = {
                "[高温] 反应釜温度超标",
                "[通信] PLC-002 超时",
                "[高压] 压缩空气超压",
                "[高温] 反应釜温度超标",  // 重复
                "[通信] PLC-002 超时",     // 重复
                "[低压] 仪表气源压力低",
            };

            foreach (var msg in alarmMessages)
            {
                if (activeAlarms.Add(msg))
                    Console.WriteLine($"  新报警: {msg}");
                else
                    Console.WriteLine($"  重复忽略: {msg}");
            }

            Console.WriteLine($"\n当前活跃报警: {activeAlarms.Count} 条");
        }
    }
}
```

## 8. 常见错误汇总

| 错误类型 | 错误示例 | 正确写法 | 说明 |
|---------|---------|---------|------|
| 数组越界 | `arr[arr.Length]` | `arr[arr.Length - 1]` | 索引最大为 Length-1 |
| 数组长度不变 | `arr.Add(10)` | 用 `List<T>` | 数组不能动态增减 |
| List 越界 | `list[list.Count]` | `list[list.Count - 1]` | 和数组一样，索引从 0 开始 |
| foreach 中删除 | `foreach(...){list.Remove(x)}` | 用 `for` 倒序或 `RemoveAll` | foreach 中不能修改集合 |
| Dictionary 重复键 | `dict.Add("k","v")` 后再 `dict.Add("k","v2")` | 用 `dict["k"] = "v2"` 覆盖 | Add 不允许重复键 |
| Dictionary 键为 null | `dict[null] = "v"` | 键不能为 null | Dictionary 键不允许 null |
| LINQ 未执行 | 定义查询后立即检查结果 | 用 `ToList()` 立即执行 | LINQ 延迟执行 |
| First 无结果 | `.First(x => x.Id == 999)` | `.FirstOrDefault(...)` | First 无匹配会抛异常 |
| Queue 无元素 | `queue.Dequeue()` 当队列为空 | 先检查 `Count > 0` | 空队列 Dequeue 会抛异常 |
| 类型不匹配 | `List<int> list = new List<string>()` | 泛型类型一致 | `<T>` 必须匹配 |
| LINQ 忘记 using | 使用 LINQ 方法报错 | 添加 `using System.Linq;` | LINQ 在 System.Linq 命名空间 |
