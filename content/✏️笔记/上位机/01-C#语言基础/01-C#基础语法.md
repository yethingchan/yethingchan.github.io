## 1. C# 语言概述与开发环境搭建

### 1.1 什么是 C#

C#（读作 "C Sharp"）是由微软开发的面向对象编程语言，运行在 .NET 平台上。它具有以下特点：

- **语法简洁**：继承自 C/C++ 家族，但去掉了许多复杂的特性（如指针、头文件）
- **类型安全**：编译器会在编译时检查类型错误，减少运行时 bug
- **面向对象**：支持封装、继承、多态等核心 OOP 概念
- **广泛应用**：桌面应用（WPF/WinForms）、Web 应用（ASP.NET）、游戏开发（Unity）、上位机开发等
- **工业领域首选**：上位机软件大量使用 C# 开发，得益于其丰富的串口通信库和 UI 框架

### 1.2 上位机开发为什么选择 C#

| 对比项 | C# | Python | C++ |
|--------|-----|--------|------|
| 开发效率 | 高 | 高 | 低 |
| UI 开发 | WinForms/WPF 非常成熟 | 一般 | 较复杂 |
| 串口通信 | System.IO.Ports 原生支持 | pyserial | 需第三方库 |
| PLC 通信库 | 丰富（S7.Net、Modbus等） | 较少 | 需自己封装 |
| 部署难度 | 需安装 .NET 运行时 | 需安装 Python | 需编译 |

## 2. 第一个 C# 程序（Hello World 详解）

### 2.1 控制台 Hello World

```csharp
// 引入命名空间 —— 类似于 C++ 的 #include 或 Java 的 import
using System;

// 命名空间 —— 用于组织代码，避免类名冲突
// 上位机项目通常命名为 公司名.项目名，如 HwTech.Scada
namespace MyFirstApp
{
    // 类 —— C# 中所有代码必须写在类里面
    class Program
    {
        // Main 方法 —— 程序的入口点
        // static: 静态方法，不需要创建对象就能调用
        // void: 无返回值
        // string[] args: 命令行参数
        static void Main(string[] args)
        {
            // Console.WriteLine() 在控制台输出一行文本，自动换行
            Console.WriteLine("Hello, World!");
            
            // Console.Write() 输出文本，不换行
            Console.Write("请输入串口号: ");
            
            // Console.ReadLine() 读取用户输入的一行文本
            string input = Console.ReadLine();
            
            // 字符串插值 —— 用 $ 前缀，在字符串中嵌入变量
            Console.WriteLine($"你输入的串口号是: {input}");
        }
    }
}
```

### 2.2 逐行解析

```
using System;                        → 引入 System 命名空间（包含 Console 等基础类）
namespace MyFirstApp { ... }        → 定义命名空间 MyFirstApp
class Program { ... }               → 定义类 Program
static void Main(string[] args)     → 程序入口方法
Console.WriteLine("...");           → 输出到控制台并换行
```

### 2.3 上位机场景的 Hello World

```csharp

        }

```

### 2.4 注释的三种写法

```csharp
// 单行注释 —— 用于解释一行代码

/*
 * 多行注释 —— 用于解释一段代码
 * 适合较长的说明
 */

/// <summary>
/// XML 文档注释 —— 用于给方法、类添加说明
/// 在 VS 中鼠标悬停在方法名上时会显示此注释
/// </summary>
/// <param name="portName">串口名称</param>
/// <returns>连接成功返回 true</returns>

    return true;

```

### 注意事项

- C# 语句以分号 `;` 结尾，忘记分号是最常见的编译错误
- C# 区分大小写，`Console` 和 `console` 是不同的
- `Main` 方法是程序的入口，每个项目只能有一个
- 新版 C#（C# 9+）支持"顶级语句"，可以省略 `namespace`、`class`、`Main` 的壳子，但初学者建议先写完整结构

## 3. 变量与常量

### 3.1 什么是变量

变量是程序中用于存储数据的"容器"。你可以把它想象成一个带标签的盒子，标签是变量名，盒子里放的是数据。

### 3.2 变量声明方式

```csharp
// 方式一：先声明类型，再赋值（最规范的方式）
string deviceName;
deviceName = "温度传感器01";

// 方式二：声明的同时赋值（推荐）
string deviceName2 = "压力传感器02";

// 方式三：使用 var 关键字，让编译器自动推断类型
// var 只能在声明时赋值，且编译器必须能推断出类型
var ipAddress = "192.168.1.100";   // 编译器推断为 string
var port = 502;                     // 编译器推断为 int
var isConnected = true;             // 编译器推断为 bool

// 方式四：一次声明多个同类型变量
int coilStart = 0, coilEnd = 100, coilCount = 101;
```

### 3.3 var 的使用规则

```csharp
// ✅ 正确用法 —— var 声明时必须初始化
var sensorValue = 36.5;  // 编译器推断为 double

// ❌ 错误用法 —— var 不能只声明不赋值
var sensorValue;         // 编译错误！无法推断类型

// ❌ 错误用法 —— var 不能用于方法参数
public void ReadData(var address) { }  // 编译错误！

// ✅ var 不能用于类字段（成员变量），只能用于局部变量
// （在 C# 9.0+ 的某些情况下可以，但初学阶段不建议使用）
```

### 3.4 常量 const

```csharp
// const —— 编译时常量，值在编译时确定，不能被修改
// 命名规范：全部大写，单词间用下划线分隔（SCREAMING_SNAKE_CASE）
const string PLC_IP = "192.168.1.100";
const int PLC_PORT = 502;
const int MAX_RETRY_COUNT = 3;
const double VOLTAGE_REFERENCE = 5.0;

// 上位机场景：通信协议相关的常量
const byte FUNCTION_CODE_READ = 0x03;      // Modbus 读保持寄存器
const byte FUNCTION_CODE_WRITE = 0x06;     // Modbus 写单个寄存器
const byte FUNCTION_CODE_WRITE_MULTI = 0x10; // Modbus 写多个寄存器

// const 变量会被编译器内联替换，性能最优
// 适用于永远不会变化的值

// 注意：const 只能用于基本类型和字符串，不能用于对象
// const List<int> items = new List<int>();  // ❌ 编译错误！

// 如果需要运行时常量，使用 readonly
readonly string _deviceVersion;  // 只能在声明时或构造函数中赋值
```

### 3.5 上位机场景示例

```csharp
using System;

namespace ScadaConfig
{
    class DeviceConfig
    {
        // ========== 常量定义 ==========
        // PLC 通信参数
        public const string DEFAULT_PLC_IP = "192.168.1.100";
        public const int DEFAULT_PLC_PORT = 502;
        public const int DEFAULT_TIMEOUT = 3000;      // 超时时间（毫秒）
        public const int MAX_RETRY_COUNT = 3;         // 最大重试次数

        // 串口通信参数
        public const string DEFAULT_COM_PORT = "COM3";
        public const int DEFAULT_BAUD_RATE = 9600;

        static void Main(string[] args)
        {
            // ========== 变量定义 ==========
            // 设备信息
            string deviceName = "1号温度采集器";
            var ipAddress = DEFAULT_PLC_IP;      // var 推断为 string
            var port = DEFAULT_PLC_PORT;         // var 推断为 int

            // 运行时状态
            bool isConnected = false;
            double currentTemp = 0.0;
            int retryCount = 0;

            Console.WriteLine($"设备名称: {deviceName}");
            Console.WriteLine($"PLC地址: {ipAddress}:{port}");
            Console.WriteLine($"连接状态: {(isConnected ? "已连接" : "未连接")}");
            Console.WriteLine($"最大重试次数: {MAX_RETRY_COUNT}");
        }
    }
}
```

### 注意事项

- `var` 虽然方便，但不要滥用。当类型不明显时（如 `var result = GetData();`），建议显式写出类型，提高可读性
- `const` 的值必须在声明时就确定，且只能是基本类型（int、double、bool、string 等）
- 如果需要在运行时确定不变的值（如从配置文件读取后不再改变），使用 `readonly`
- 变量在使用前必须赋值，否则编译器会报错 `Use of unassigned local variable`

### 练习建议

1. 定义一组上位机系统的常量（IP 地址、端口号、设备名称等）
2. 练习使用 `var` 声明变量，并用 `GetType()` 方法验证编译器推断的类型
3. 尝试修改一个 `const` 变量，观察编译错误信息

## 4. 数据类型详解

### 4.1 C# 类型总览

C# 的类型分为两大类：

```
C# 类型
├── 值类型（Value Types）—— 存储在栈上，直接存值
│   ├── 基本类型：int, double, float, bool, char, decimal
│   ├── 枚举：enum
│   └── 结构体：struct
│
└── 引用类型（Reference Types）—— 存储在堆上，存的是引用（地址）
    ├── 类：class
    ├── 字符串：string
    ├── 数组：array
    └── 接口：interface
```

### 4.2 值类型详解

#### 整数类型

```csharp
// ===== 整数类型 =====
// 上位机中最常用的就是 int 和 short

int sensorCount = 100;          // 32位整数，范围: -2,147,483,648 ~ 2,147,483,647
                                 // 上位机场景：传感器数量、寄存器地址、采集周期等

short registerAddress = 40001;   // 16位整数，范围: -32,768 ~ 32,767
                                 // 上位机场景：Modbus 寄存器地址（0~65535 用 ushort）

ushort modbusAddr = 40100;      // 无符号16位整数，范围: 0 ~ 65,535
                                 // 上位机场景：PLC 寄存器地址

long timestamp = 1719000000000;  // 64位整数，范围极大
                                  // 上位机场景：时间戳（毫秒级）

byte functionCode = 0x03;       // 8位无符号整数，范围: 0 ~ 255
                                 // 上位机场景：Modbus 功能码

sbyte signedValue = -10;        // 8位有符号整数，范围: -128 ~ 127
```

#### 浮点类型

```csharp
// ===== 浮点类型 =====
// 注意精度差异，上位机中对精度要求高的场景（如温度、压力）要用 decimal

float temperature = 36.5f;       // 32位浮点，7位有效数字，必须加 f 后缀
                                  // 精度：约 6~9 位有效数字

double pressure = 101.325;       // 64位浮点，15~16位有效数字
                                  // 默认的小数类型，不加后缀就是 double
                                  // 精度：约 15~17 位有效数字

decimal voltage = 3.14159265358979m; // 128位高精度小数，28~29位有效数字
                                      // 必须加 m 后缀
                                      // 上位机场景：电量计量、精确称重、金额计算

// ===== 浮点数精度陷阱演示 =====
float a = 0.1f + 0.2f;
Console.WriteLine($"0.1 + 0.2 (float) = {a}");    // 0.300000012（有误差！）

decimal b = 0.1m + 0.2m;
Console.WriteLine($"0.1 + 0.2 (decimal) = {b}");  // 0.3（精确！）
```

#### 布尔类型

```csharp
// ===== 布尔类型 =====
// bool 只有两个值：true 和 false
// 上位机场景：设备连接状态、报警标志、IO 信号状态

bool isConnected = true;         // PLC 连接状态
bool isAlarm = false;            // 报警状态
bool isRunning = true;           // 设备运行状态
bool[] digitalInputs = new bool[8];  // 8路数字量输入状态

// ⚠️ C# 中 bool 不能用 0/1 代替（不像 C/C++）
// if (1) { }         // ❌ 编译错误
// if (isConnected) { }  // ✅ 正确
```

#### 字符类型

```csharp
// ===== 字符类型 =====
// char 存储单个字符（16位 Unicode）

char unitSymbol = '°';           // 温度单位符号
char delimiter = ',';           // CSV 分隔符
char newline = '\n';             // 换行符

// 常用转义字符
// \n 换行   \r 回车   \t 制表符   \\ 反斜杠   \' 单引号   \" 双引号
```

### 4.3 引用类型：string

```csharp
// ===== string 字符串类型 =====
// string 是引用类型，但使用起来像值类型（不可变）

string deviceName = "温度传感器";
string ipAddress = "192.168.1.100";
string empty = "";               // 空字符串
string nullStr = null;           // null —— 表示"没有值"，与空字符串不同

// 字符串是不可变的 —— 每次"修改"都会创建新字符串
string str = "Hello";
str = str + " World";  // 并非修改原字符串，而是创建了新字符串 "Hello World"
                        // 在高频操作中（如拼接大量数据）应使用 StringBuilder

// 字符串的判空
if (string.IsNullOrEmpty(str))       // 判断 null 或空字符串
    Console.WriteLine("字符串为空");

if (string.IsNullOrWhiteSpace(str))   // 判断 null、空字符串或纯空白字符
    Console.WriteLine("字符串为空白");
```

### 4.4 枚举类型 enum

```csharp
// ===== 枚举类型 =====
// 枚举用于定义一组命名的常量集合，提高代码可读性
// 上位机场景：设备状态、通信协议类型、数据类型等

// 基本枚举定义
public enum DeviceStatus
{
    Offline = 0,      // 离线
    Online = 1,       // 在线
    Alarm = 2,        // 报警
    Maintenance = 3   // 维护中
}

// 上位机场景：Modbus 功能码
public enum ModbusFunctionCode : byte  // 可以指定底层类型
{
    ReadCoils = 0x01,                  // 读线圈
    ReadDiscreteInputs = 0x02,        // 读离散输入
    ReadHoldingRegisters = 0x03,      // 读保持寄存器
    ReadInputRegisters = 0x04,        // 读输入寄存器
    WriteSingleCoil = 0x05,           // 写单个线圈
    WriteSingleRegister = 0x06,       // 写单个寄存器
    WriteMultipleRegisters = 0x10     // 写多个寄存器
}

// 上位机场景：数据类型
public enum DataType
{
    Bool = 0,       // 开关量
    Int16 = 1,      // 16位有符号整数
    UInt16 = 2,     // 16位无符号整数
    Int32 = 3,      // 32位有符号整数
    Float = 4,      // 32位浮点
    Double = 5,     // 64位浮点
    String = 6      // 字符串
}

// 使用枚举
DeviceStatus status = DeviceStatus.Online;
Console.WriteLine($"设备状态: {status}");            // 输出: 设备状态: Online
Console.WriteLine($"状态码: {(int)status}");          // 输出: 状态码: 1 （枚举转int）

ModbusFunctionCode funcCode = ModbusFunctionCode.ReadHoldingRegisters;
Console.WriteLine($"功能码: 0x{funcCode:X2}");       // 输出: 功能码: 0x03

// 枚举解析 —— 字符串转枚举
string statusText = "Alarm";
DeviceStatus parsed = (DeviceStatus)Enum.Parse(typeof(DeviceStatus), statusText);

// 安全解析（推荐）—— 解析失败返回默认值而非抛异常
if (Enum.TryParse<DeviceStatus>(statusText, out DeviceStatus result))
    Console.WriteLine($"解析成功: {result}");
```

### 4.5 结构体类型 struct

```csharp
// ===== 结构体 =====
// struct 是值类型，适合表示轻量级数据对象
// 上位机场景：寄存器信息、数据点定义、通信帧结构等

// 定义一个寄存器信息结构体
public struct RegisterInfo
{
    public string Name;           // 寄存器名称
    public ushort Address;        // 寄存器地址
    public DataType Type;         // 数据类型
    public double Scale;          // 缩放系数
    public string Unit;           // 单位
    public string Description;    // 描述

    // 结构体可以定义构造函数
    public RegisterInfo(string name, ushort address, DataType type, 
                        double scale = 1.0, string unit = "", string desc = "")
    {
        Name = name;
        Address = address;
        Type = type;
        Scale = scale;
        Unit = unit;
        Description = desc;
    }
}

// 使用结构体
var tempReg = new RegisterInfo(
    name: "工艺温度",
    address: 40100,
    type: DataType.Float,
    scale: 0.1,
    unit: "°C",
    desc: "主反应釜温度"
);

Console.WriteLine($"寄存器: {tempReg.Name}, 地址: {tempReg.Address}, 单位: {tempReg.Unit}");

// ⚠️ struct 是值类型，赋值时会复制整个数据
RegisterInfo reg2 = tempReg;  // 复制了一份新数据
reg2.Address = 40200;        // 修改 reg2 不会影响 tempReg
```

### 4.6 类型对比表

| 类型 | 分类 | 大小 | 范围 | 上位机典型用途 |
|------|------|------|------|----------------|
| `byte` | 值类型 | 1字节 | 0~255 | Modbus 功能码 |
| `sbyte` | 值类型 | 1字节 | -128~127 | 有符号8位数据 |
| `short` | 值类型 | 2字节 | -32768~32767 | 有符号寄存器值 |
| `ushort` | 值类型 | 2字节 | 0~65535 | Modbus 寄存器地址 |
| `int` | 值类型 | 4字节 | 约+-21亿 | 通用计数、地址 |
| `uint` | 值类型 | 4字节 | 0~约42亿 | 无符号计数 |
| `long` | 值类型 | 8字节 | 极大范围 | 时间戳 |
| `float` | 值类型 | 4字节 | 7位精度 | 一般传感器数据 |
| `double` | 值类型 | 8字节 | 15位精度 | 高精度传感器数据 |
| `decimal` | 值类型 | 16字节 | 28位精度 | 电量计量、金额 |
| `bool` | 值类型 | 1字节 | true/false | 开关量、状态标志 |
| `char` | 值类型 | 2字节 | Unicode字符 | 单个字符 |
| `string` | 引用类型 | 可变 | -- | 设备名称、IP地址 |
| `enum` | 值类型 | 取决于底层 | 取决于底层 | 状态、协议类型 |

### 注意事项

- 浮点数存在精度问题，不要用 `==` 直接比较两个浮点数是否相等
- `float` 变量赋值时必须加 `f` 后缀，`decimal` 必须加 `m` 后缀
- `string` 是引用类型但具有不可变性，频繁拼接请用 `StringBuilder`
- `enum` 默认底层类型是 `int`，可以指定为 `byte`、`short` 等节省空间
- `struct` 是值类型，赋值和传参都是复制整个数据，注意性能影响
- 上位机中与 PLC 通信时，寄存器值常用 `ushort`（0~65535）

## 5. 类型转换

### 5.1 隐式转换（自动转换）

当目标类型的范围大于源类型时，编译器自动完成转换，不会丢失数据。

```csharp
// ===== 隐式转换规则 =====
// byte → short → int → long → float → double
// 小类型可以自动转为大类型

byte dataByte = 100;
short dataShort = dataByte;     // byte → short，自动转换 ✅
int dataInt = dataShort;         // short → int，自动转换 ✅
long dataLong = dataInt;        // int → long，自动转换 ✅
float dataFloat = dataLong;     // long → float，自动转换 ✅
double dataDouble = dataFloat;  // float → double，自动转换 ✅

// 上位机场景：读取到的寄存器值（ushort）自动转为 int 进行计算
ushort registerValue = 4095;    // 16位寄存器原始值
int calculatedValue = registerValue * 10;  // ushort → int，自动转换
Console.WriteLine($"计算值: {calculatedValue}");  // 输出: 40950

// ⚠️ 注意：以下情况不会有隐式转换
// double d = 100;    // int → double ✅
// int i = 100.0;     // double → int ❌ 编译错误！可能丢失精度
```

### 5.2 显式转换（强制转换）

当目标类型的范围小于源类型时，必须显式强制转换，但可能丢失数据。

```csharp
// ===== 显式转换（强制转换）=====
// 语法：(目标类型)源值

double voltage = 220.5;
int voltageInt = (int)voltage;          // 截断小数部分，结果: 220
                                          // ⚠️ 不会四舍五入，是直接截断！

int count = 300;
short countShort = (short)count;        // 300 在 short 范围内，结果: 300 ✅
short overflow = (short)50000;          // 50000 超出 short 范围，结果: 溢出！❌

// 上位机场景：将 double 传感器值转为 int 显示
double rawTemp = 25.7;
int displayTemp = (int)rawTemp;         // 显示: 25（截断）

// 如果需要四舍五入，用 Convert 或 Math.Round
int roundedTemp = (int)Math.Round(rawTemp);  // 显示: 26（四舍五入）
```

### 5.3 Convert 类

`Convert` 类提供了一系列类型转换方法，功能更全面。

```csharp
// ===== Convert 类 =====
// Convert.ToInt32()、Convert.ToDouble()、Convert.ToString() 等

string strValue = "123";
int num1 = Convert.ToInt32(strValue);       // 字符串 → int: 123
double num2 = Convert.ToDouble(strValue);    // 字符串 → double: 123.0
bool flag = Convert.ToBoolean("true");       // 字符串 → bool: true

// Convert 的特点：转换失败会抛出异常
// Convert.ToInt32("abc")  → 抛出 FormatException

// 上位机场景：从界面文本框获取配置参数
string portText = "502";
int port = Convert.ToInt32(portText);        // "502" → 502

string baudText = "9600";
int baudRate = Convert.ToInt32(baudText);    // "9600" → 9600

// Convert 与强制转换的区别
string str = "3.14";
// int a = (int)str;              // ❌ 编译错误！不能直接强制转换字符串
int b = Convert.ToInt32(str);    // ✅ Convert 可以转字符串

double d = 3.99;
int c = (int)d;                   // 3（截断）
int e = Convert.ToInt32(d);      // 4（四舍五入）⚠️ 注意区别！
```

### 5.4 Parse 与 TryParse

```csharp
// ===== Parse（解析） =====
// 各类型都有自己的 Parse 方法
// 解析成功返回值，解析失败抛出异常

int num = int.Parse("456");           // 456
double d = double.Parse("3.14159");   // 3.14159
bool b = bool.Parse("true");          // true

// Parse 带格式参数（处理千分位等）
string numberStr = "1,234,567";
int bigNum = int.Parse(numberStr, System.Globalization.NumberStyles.AllowThousands);
// 结果: 1234567

// ===== TryParse（安全解析，推荐）=====
// 解析成功返回 true 并通过 out 参数传出值
// 解析失败返回 false，不会抛出异常

string input = "100";

if (int.TryParse(input, out int result))
{
    Console.WriteLine($"解析成功: {result}");  // 解析成功: 100
}
else
{
    Console.WriteLine("输入的不是有效的整数");
}

// 上位机场景：安全解析用户在界面中输入的寄存器地址
string addressInput = "40100";

if (ushort.TryParse(addressInput, out ushort registerAddress))
{
    Console.WriteLine($"寄存器地址: {registerAddress}");
    // 继续读取操作...
}
else
{
    Console.WriteLine($"错误: '{addressInput}' 不是有效的寄存器地址（0~65535）");
}

// TryParse 的 out 变量可以内联声明（C# 7.0+）
if (double.TryParse(sensorText, out double sensorValue))
{
    Console.WriteLine($"传感器值: {sensorValue:F2}");
}
```

### 5.5 上位机场景综合示例

```csharp
using System;

namespace TypeConversionDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // 模拟从 PLC 读取到的原始寄存器值
            ushort rawTemp = 1234;      // 原始值
            ushort rawPressure = 5678;  // 原始值

            // 隐式转换：ushort → int → double
            double temperature = rawTemp * 0.1;       // 123.4 °C
            double pressure = rawPressure * 0.01;      // 56.78 kPa

            Console.WriteLine($"温度: {temperature:F1} °C");    // F1 表示保留1位小数
            Console.WriteLine($"压力: {pressure:F2} kPa");       // F2 表示保留2位小数

            // 显式转换：将 double 存入 ushort（需确认不溢出）
            ushort tempToWrite = (ushort)(temperature * 10);     // 1234（反向编码）
            Console.WriteLine($"写入温度寄存器值: {tempToWrite}");

            // TryParse：安全解析用户输入
            Console.Write("请输入 Modbus 站号 (1~247): ");
            string stationInput = Console.ReadLine();

            if (byte.TryParse(stationInput, out byte stationId))
            {
                if (stationId >= 1 && stationId <= 247)
                    Console.WriteLine($"站号设置成功: {stationId}");
                else
                    Console.WriteLine("站号超出范围 (1~247)");
            }
            else
            {
                Console.WriteLine("无效输入，请输入数字");
            }

            // 数值转字符串（用于界面显示或日志记录）
            string tempLog = Convert.ToString(temperature);
            Console.WriteLine($"日志记录: 温度={tempLog}");
        }
    }
}
```

### 注意事项

- 隐式转换只发生在"小类型 → 大类型"，不会丢失精度
- 强制转换 `(int)` 是截断小数，而 `Convert.ToInt32()` 是四舍五入
- 对用户输入的数据，**始终使用 TryParse**，不要用 Parse（避免异常导致程序崩溃）
- `Convert.ToInt32(null)` 返回 0，而 `int.Parse(null)` 会抛异常
- 上位机中 PLC 寄存器通常是 16 位无符号整数（`ushort`），注意与有符号类型的转换

### 练习建议

1. 编写程序：输入一个温度值（字符串），安全解析为 `double`，然后分别用截断和四舍五入方式转为 `int`
2. 实现 Modbus 寄存器值的编码/解码：传感器值 123.4，缩放因子 0.1，编码为 ushort 写入 PLC，再从 PLC 读取 ushort 解码回来
3. 测试各种边界值：最大值、最小值、0、null、空字符串、非法格式

### 6.3 逻辑运算符

```csharp

bool systemReady = sensorOk && plcOnline;     // true && true = true

}
```

### 6.5 位运算符

位运算在上位机开发中非常重要，常用于：解析 Modbus 报文、操作 PLC 内部寄存器位、解析状态字。

```csharp
// ===== 位运算符 =====
byte status = 0b10110100;  // 二进制字面量（C# 7.0+）

// & 按位与 —— 常用于提取某一位的状态
// | 按位或 —— 常用于设置某一位
// ^ 按位异或 —— 常用于翻转某一位
// ~ 按位取反 —— 所有权位翻转
// << 左移   —— 相当于乘以 2^n
// >> 右移   —— 相当于除以 2^n

// ===== 上位机场景：解析 PLC 状态字 =====
// 假设从 PLC 读取了一个字节的状态字
// Bit7: 运行状态  Bit6: 报警  Bit5: 自动模式  Bit4: 手动模式  Bit3~0: 保留
byte statusWord = 0b10100000;

// 提取第 7 位（运行状态）
bool isRunning = (statusWord & 0b10000000) != 0;     // true
// 提取第 6 位（报警状态）
bool isAlarm = (statusWord & 0b01000000) != 0;       // false
// 提取第 5 位（自动模式）
bool isAutoMode = (statusWord & 0b00100000) != 0;    // true

Console.WriteLine($"运行: {isRunning}, 报警: {isAlarm}, 自动: {isAutoMode}");

// ===== 上位机场景：Modbus CRC 校验中的位操作 =====
ushort crc = 0xFFFF;
byte data = 0x03;
crc ^= data;        // 异或：将 data 合并到 crc 中

// ===== 上位机场景：交换高低字节 =====
ushort registerValue = 0x1234;
byte highByte = (byte)(registerValue >> 8);    // 0x12（右移8位取高字节）
byte lowByte = (byte)(registerValue & 0xFF);    // 0x34（与0xFF按位与取低字节）
Console.WriteLine($"高字节: 0x{highByte:X2}, 低字节: 0x{lowByte:X2}");

// 组合高低字节
ushort combined = (ushort)((highByte << 8) | lowByte);  // 0x1234
Console.WriteLine($"组合值: 0x{combined:X4}");
```

### 6.6 三元运算符 ?:

### 6.7 null 合并运算符 ??

```csharp
// ?? 运算符：左侧为 null 时返回右侧的值，否则返回左侧的值
// 上位机场景：提供默认值

string deviceName = null;
string displayName = deviceName ?? "未命名设备";  // 结果: "未命名设备"

string ip = "192.168.1.1";
string displayIp = ip ?? "127.0.0.1";            // 结果: "192.168.1.1"

// ??= 运算符（C# 8.0+）：左侧为 null 时才赋值
string config = null;
config ??= "默认配置";    // config 为 null，赋值为 "默认配置"
config ??= "新默认值";    // config 已有值，不变
Console.WriteLine(config);  // "默认配置"

// 上位机场景：配置项提供默认值
int? baudRate = null;
int actualBaud = baudRate ?? 9600;   // null 时使用默认波特率 9600
Console.WriteLine($"波特率: {actualBaud}");
```

### 6.8 null 条件运算符 ?.

```csharp
// ?. 运算符：对象不为 null 时才访问成员，否则返回 null
// 上位机场景：安全地访问可能为 null 的对象

string deviceName = "温度传感器";
int length = deviceName?.Length ?? 0;   // deviceName 不为 null，length = 6

string nullDevice = null;
int nullLength = nullDevice?.Length ?? 0;  // nullDevice 为 null，nullLength = 0

// 上位机场景：安全访问设备对象
class PlcDevice
{
    public string Name { get; set; }
    public bool IsConnected { get; set; }
}

PlcDevice device = new PlcDevice { Name = "PLC-001", IsConnected = true };

// 安全调用：如果 device 不为 null，才访问 Name
string name = device?.Name ?? "未知设备";

PlcDevice nullDevice2 = null;
string safeName = nullDevice2?.Name ?? "未知设备";  // 不会抛 NullReferenceException
```

### 注意事项

- 整数除法陷阱：`int / int` 结果还是 `int`，需要浮点结果时确保有浮点数参与
- `&&` 和 `||` 是短路运算符，`&` 和 `|` 不是
- 位运算只适用于整数类型，不能用于 `double` 或 `float`
- 三元运算符不要嵌套太深（最多 1~2 层），否则影响可读性
- `??` 和 `?.` 是 C# 处理 null 值的最佳方式，减少大量的 null 检查代码

2. 实现高低字节交换函数（`ushort` 输入，输出交换后的 `ushort`）
3. 用 `??` 和 `?.` 重写一段包含大量 null 检查的代码

### 9.2 PLC 地址计算工具

```csharp
using System;

namespace PlcAddressCalculator
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("========== PLC 寄存器地址计算工具 ==========");
            Console.WriteLine();

            // ===== Modbus 地址规则 =====
            // 0xxxx - 线圈（可读写，位操作）
            // 1xxxx - 离散输入（只读，位操作）
            // 3xxxx - 输入寄存器（只读，字操作）
            // 4xxxx - 保持寄存器（可读写，字操作）

            Console.Write("请输入 Modbus 地址 (如 40100): ");
            string input = Console.ReadLine();

            if (ushort.TryParse(input, out ushort address))
            {
                string region = GetRegionName(address);
                int actualAddress = GetActualAddress(address);
                string rw = GetReadWrite(address);

                Console.WriteLine();
                Console.WriteLine($"地址类型: {region}");
                Console.WriteLine($"实际地址: {actualAddress}");
                Console.WriteLine($"读写权限: {rw}");
            }
            else
            {
                Console.WriteLine("无效的地址格式！");
            }

            Console.WriteLine();
            Console.WriteLine("按任意键退出...");
            Console.ReadKey();
        }

        /// <summary>
        /// 根据地址范围判断区域名称
        /// </summary>
        static string GetRegionName(ushort address)
        {
            if (address >= 0 && address <= 9999)
                return "线圈 (Coils) - 0x";
            else if (address >= 10000 && address <= 19999)
                return "离散输入 (Discrete Inputs) - 1x";
            else if (address >= 30000 && address <= 39999)
                return "输入寄存器 (Input Registers) - 3x";
            else if (address >= 40000 && address <= 49999)
                return "保持寄存器 (Holding Registers) - 4x";
            else
                return "未知区域";
        }

        /// <summary>
        /// 计算实际寄存器地址（去掉首位数字）
        /// </summary>
        static int GetActualAddress(ushort address)
        {
            if (address >= 10000)
                return address % 10000;
            return address;
        }

        /// <summary>
        /// 获取读写权限
        /// </summary>
        static string GetReadWrite(ushort address)
        {
            if (address >= 0 && address <= 9999)
                return "读写 (Read/Write)";
            else if (address >= 10000 && address <= 19999)
                return "只读 (Read Only)";
            else if (address >= 30000 && address <= 39999)
                return "只读 (Read Only)";
            else if (address >= 40000 && address <= 49999)
                return "读写 (Read/Write)";
            else
                return "未知";
        }
    }
}
```

## 11. 常见错误汇总

| 错误类型 | 错误示例 | 正确写法 | 说明 |
|---------|---------|---------|------|
| 忘记分号 | `int x = 10` | `int x = 10;` | 每条语句必须以分号结尾 |
| 大小写错误 | `console.WriteLine()` | `Console.WriteLine()` | C# 区分大小写 |
| 整数除法 | `double r = 5 / 2;` → 2 | `double r = 5.0 / 2;` → 2.5 | int/int 结果是 int |
| float 无后缀 | `float f = 3.14;` | `float f = 3.14f;` | 小数字面量默认是 double |
| decimal 无后缀 | `decimal d = 3.14;` | `decimal d = 3.14m;` | decimal 必须加 m |
| var 未初始化 | `var x;` | `var x = 10;` | var 必须同时初始化 |
| 字符串比较 | `str1 = str2` | `str1 == str2` | 字符串用 == 比较，不用 = |
| 数组越界 | `arr[5]` (长度为5) | `arr[4]` | 索引从 0 开始 |
| null 引用 | `obj.Method()` 当 obj 为 null | `obj?.Method()` | 使用 ?. 避免异常 |
| Parse 无保护 | `int.Parse(userInput)` | `int.TryParse(userInput, out int val)` | 用户输入必须用 TryParse |
| 强制转换溢出 | `(short)50000` | 先检查范围再转换 | 强制转换不检查范围 |
| 字符串拼接性能 | 循环中用 `+` 拼接 | 使用 `StringBuilder` | 避免大量创建临时字符串 |
