## 1. 类与对象

### 1.1 什么是类和对象

**类（Class）** 是一种自定义的数据类型，它描述了一类事物的共同特征和行为。

**对象（Object）** 是类的具体实例。

| 概念 | 类比 | 示例 |
|------|------|------|
| 类 | 汽车的设计图纸 | `PlcDevice` 类 |
| 对象 | 按照图纸造出的具体汽车 | `plc1`、`plc2` 两个 PLC 设备对象 |

### 1.2 类的定义

一个类由 **字段（Field）**、**属性（Property）**、**方法（Method）** 和 **构造函数（Constructor）** 组成。

```csharp
// ===== 类的基本结构 =====
public class PlcDevice
{
    // ----- 字段（Field）-----
    // 存储数据的变量，通常为 private
    private string _ipAddress;       // PLC 的 IP 地址
    private int _port;                // PLC 的端口号
    private bool _isConnected;        // 连接状态

    // ----- 属性（Property）-----
    // 对外暴露字段的"安全接口"，控制读写权限
    public string IpAddress
    {
        get { return _ipAddress; }          // 读取时返回字段值
        set { _ipAddress = value; }         // 设置时赋值给字段
    }

    public int Port
    {
        get { return _port; }
        set { _port = value; }
    }

    // 只读属性（只有 get，外部不能修改）
    public bool IsConnected
    {
        get { return _isConnected; }
    }

    // 自动属性（编译器自动生成私有字段）
    public string Name { get; set; }        // 可读写
    public string FirmwareVersion { get; private set; }  // 类内部可写，外部只读

    // ----- 构造函数（Constructor）-----
    // 创建对象时自动调用的方法，用于初始化
    public PlcDevice(string name, string ip, int port)
    {
        Name = name;
        _ipAddress = ip;
        _port = port;
        _isConnected = false;
        FirmwareVersion = "V1.0.0";
    }

    // ----- 方法（Method）-----
    // 定义对象的行为/功能
    public bool Connect()
    {
        // 连接逻辑...
        _isConnected = true;
        return true;
    }

    public void Disconnect()
    {
        _isConnected = false;
    }

    public short ReadRegister(int address)
    {
        // 读取寄存器逻辑...
        return 0;
    }

    public void WriteRegister(int address, short value)
    {
        // 写入寄存器逻辑...
    }
}
```

### 1.3 创建和使用对象

```csharp
using System;

namespace ClassDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // ===== 创建对象（实例化）=====
            // 使用 new 关键字调用构造函数
            PlcDevice plc1 = new PlcDevice("1号PLC", "192.168.1.100", 502);
            PlcDevice plc2 = new PlcDevice("2号PLC", "192.168.1.101", 502);

            // ===== 访问属性 =====
            Console.WriteLine($"设备名称: {plc1.Name}");
            Console.WriteLine($"IP地址: {plc1.IpAddress}");
            Console.WriteLine($"端口号: {plc1.Port}");
            Console.WriteLine($"连接状态: {plc1.IsConnected}");

            // ===== 调用方法 =====
            plc1.Connect();
            Console.WriteLine($"连接后状态: {plc1.IsConnected}");

            // 读写寄存器
            short value = plc1.ReadRegister(40100);
            Console.WriteLine($"读取寄存器 40100: {value}");

            plc1.WriteRegister(40100, 1234);
            Console.WriteLine("写入寄存器 40100: 1234");

            // ===== 修改属性 =====
            plc1.IpAddress = "192.168.1.200";  // 通过属性修改
            Console.WriteLine($"新IP: {plc1.IpAddress}");

            // plc1.IsConnected = false;  // ❌ 编译错误！只读属性不能外部修改

            // 断开连接
            plc1.Disconnect();
            Console.WriteLine($"断开后状态: {plc1.IsConnected}");

            // ===== 两个对象互不影响 =====
            Console.WriteLine($"\n{plc2.Name}: IP={plc2.IpAddress}, 状态={plc2.IsConnected}");
            // plc2 仍然未连接（plc1 的操作不影响 plc2）
        }
    }

    // ===== PlcDevice 类定义 =====
    public class PlcDevice
    {
        private string _ipAddress;
        private int _port;
        private bool _isConnected;

        public string Name { get; set; }
        public string IpAddress { get { return _ipAddress; } set { _ipAddress = value; } }
        public int Port { get { return _port; } set { _port = value; } }
        public bool IsConnected { get { return _isConnected; } }

        public PlcDevice(string name, string ip, int port)
        {
            Name = name;
            _ipAddress = ip;
            _port = port;
            _isConnected = false;
        }

        public bool Connect()
        {
            Console.WriteLine($"[{Name}] 正在连接 {_ipAddress}:{_port}...");
            _isConnected = true;
            Console.WriteLine($"[{Name}] 连接成功");
            return true;
        }

        public void Disconnect()
        {
            _isConnected = false;
            Console.WriteLine($"[{Name}] 已断开连接");
        }

        public short ReadRegister(int address)
        {
            if (!_isConnected)
            {
                Console.WriteLine($"[{Name}] 错误: 设备未连接，无法读取");
                return -1;
            }
            // 模拟读取
            short mockValue = (short)(1000 + address % 100);
            Console.WriteLine($"[{Name}] 读取寄存器 {address} = {mockValue}");
            return mockValue;
        }

        public void WriteRegister(int address, short value)
        {
            if (!_isConnected)
            {
                Console.WriteLine($"[{Name}] 错误: 设备未连接，无法写入");
                return;
            }
            Console.WriteLine($"[{Name}] 写入寄存器 {address} = {value}");
        }
    }
}
```

### 1.4 构造函数详解

```csharp
public class PlcDevice
{
    public string Name { get; set; }
    public string IpAddress { get; set; }
    public int Port { get; set; }
    public bool IsConnected { get; private set; }

    // ===== 无参构造函数 =====
    // 如果没有定义任何构造函数，编译器会自动生成一个默认的无参构造函数
    // 一旦定义了有参构造函数，无参构造函数不会自动生成（需要手动定义）
    public PlcDevice()
    {
        Name = "未命名设备";
        IpAddress = "127.0.0.1";
        Port = 502;
        IsConnected = false;
    }

    // ===== 有参构造函数 =====
    public PlcDevice(string name, string ip, int port)
    {
        Name = name;
        IpAddress = ip;
        Port = port;
        IsConnected = false;
    }

    // ===== 构造函数重载（多个构造函数）=====
    // 可以用 this(...) 调用另一个构造函数（构造函数链）
    public PlcDevice(string name, string ip) : this(name, ip, 502)
    {
        // 只传 name 和 ip，port 默认 502
    }

    public PlcDevice(string name) : this(name, "127.0.0.1", 502)
    {
        // 只传 name，ip 默认 127.0.0.1，port 默认 502
    }
}

// 使用不同的构造函数创建对象
var plc1 = new PlcDevice();                           // 无参构造
var plc2 = new PlcDevice("PLC-001", "192.168.1.100", 502);  // 全参构造
var plc3 = new PlcDevice("PLC-002", "192.168.1.101");      // 使用默认端口
var plc4 = new PlcDevice("PLC-003");                         // 使用默认 ip 和端口
```

### 1.5 字段与属性的区别

| 对比项 | 字段（Field） | 属性（Property） |
|--------|-------------|----------------|
| 声明 | `private string _name;` | `public string Name { get; set; }` |
| 访问级别 | 通常 private | 通常 public |
| 读写控制 | 无 | 可控制 get/set（只读、只写、条件验证） |
| 数据验证 | 不方便 | 可以在 set 中添加验证逻辑 |
| 序列化 | 可序列化 | 也可以序列化 |
| 推荐使用 | 存储内部数据 | 对外暴露数据 |

### 注意事项

- 一个 `.cs` 文件中可以定义多个类，但建议每个类一个文件（文件名与类名一致）
- 字段用 `_camelCase` 命名，属性用 `PascalCase` 命名
- 属性的本质是 `get_Xxx()` 和 `set_Xxx()` 方法（编译后）
- 构造函数名必须与类名相同，没有返回值类型（连 `void` 都不写）
- 对象是引用类型，赋值时传递的是引用（地址），不是复制数据

### 练习建议

1. 定义一个 `SerialDevice` 类（串口设备），包含端口名、波特率、数据位等属性和 Open/Close 方法
2. 为 `PlcDevice` 添加一个 `ToString()` 方法，返回设备的完整信息
3. 创建多个 `PlcDevice` 对象，验证不同对象之间的数据互不影响

## 2. 访问修饰符

### 2.1 四种访问修饰符

C# 提供了四种访问修饰符，控制类成员的访问范围。

| 修饰符 | 访问范围 | 类比 | 典型用途 |
|--------|---------|------|---------|
| `public` | 任何地方都能访问 | 公共区域 | 属性、公共方法 |
| `private` | 仅本类内部能访问 | 个人隐私 | 字段、内部辅助方法 |
| `protected` | 本类 + 子类能访问 | 家庭内部 | 供子类使用的成员 |
| `internal` | 同一程序集（项目）内能访问 | 公司内部 | 项目内部共享 |

### 2.2 示例代码

```csharp
using System;

namespace AccessModifierDemo
{
    public class PlcDevice
    {
        // ===== public：任何地方都可以访问 =====
        public string Name { get; set; }              // 外部可读写

        // ===== private：只有本类内部可以访问 =====
        private string _ipAddress;                    // 外部不能直接访问
        private int _port;
        private bool _isConnected;

        // ===== protected：本类和子类可以访问 =====
        protected int _retryCount;                    // 子类可以访问和修改
        protected byte _stationId;

        // ===== internal：同一程序集内可以访问 =====
        internal string InternalId { get; set; }      // 仅本项目内使用

        // 构造函数
        public PlcDevice(string name, string ip, int port, byte stationId)
        {
            Name = name;
            _ipAddress = ip;
            _port = port;
            _stationId = stationId;
            _retryCount = 0;
            _isConnected = false;
        }

        // 公共方法：外部可以调用
        public bool Connect()
        {
            _retryCount = 0;  // private 字段可以在类内部使用
            _isConnected = true;
            return true;
        }

        // 私有方法：仅类内部使用
        private void LogMessage(string message)
        {
            Console.WriteLine($"[{Name}] {message}");
        }

        // 受保护方法：供子类调用
        protected void ResetRetryCount()
        {
            _retryCount = 0;
        }

        // 公共属性，但 set 是 private（外部只读，内部可写）
        public bool IsConnected
        {
            get { return _isConnected; }
            private set { _isConnected = value; }  // 只有类内部能修改
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            var plc = new PlcDevice("PLC-001", "192.168.1.100", 502, 1);

            // public 成员可以访问
            Console.WriteLine(plc.Name);               // ✅ public
            plc.Connect();                              // ✅ public

            // private 成员不能访问
            // plc._ipAddress = "10.0.0.1";           // ❌ 编译错误：private
            // plc.LogMessage("test");                  // ❌ 编译错误：private

            // protected 成员不能在类外部访问
            // plc._retryCount = 5;                    // ❌ 编译错误：protected

            // 通过公共属性访问 private 字段
            Console.WriteLine($"连接状态: {plc.IsConnected}");  // ✅ 通过 public 属性

            // IsConnected 的 set 是 private
            // plc.IsConnected = true;                 // ❌ 编译错误：set 是 private
        }
    }
}
```

### 2.3 类级别的访问修饰符

```csharp
// ===== 类也可以有访问修饰符 =====

public class PublicClass { }          // 任何地方都能使用
internal class InternalClass { }      // 仅同一程序集内可用
// private class PrivateClass { }    // ❌ 类不能是 private（嵌套类除外）
// protected class ProtectedClass { } // ❌ 类不能是 protected（嵌套类除外）

// 嵌套类可以是 private
public class OuterClass
{
    private class InnerClass { }      // 仅 OuterClass 内部可用
    protected class ProtectedInner { } // OuterClass 和子类可用
}
```

### 2.4 上位机场景：访问修饰符最佳实践

```csharp
public class PlcDevice
{
    // ===== 字段：全部 private（不暴露给外部）=====
    private string _ipAddress;
    private int _port;
    private bool _isConnected;
    private byte _stationId;
    private int _timeout;

    // ===== 属性：需要外部访问的用 public =====
    // 只读属性（外部只看不能改）
    public string Name { get; }
    public bool IsConnected { get; private set; }
    public byte StationId { get; }

    // 可读写属性（但可以在 set 中验证）
    public int Timeout
    {
        get { return _timeout; }
        set
        {
            if (value < 100 || value > 60000)
                throw new ArgumentException("超时时间必须在 100~60000ms 之间");
            _timeout = value;
        }
    }

    // ===== 构造函数：public（允许外部创建实例）=====
    public PlcDevice(string name, string ip, int port, byte stationId)
    {
        Name = name;
        _ipAddress = ip;
        _port = port;
        _stationId = stationId;
        _timeout = 3000;  // 默认超时
    }

    // ===== 公共方法：外部可以调用的操作 =====
    public bool Connect() { }
    public void Disconnect() { }
    public short ReadRegister(int address) { }
    public void WriteRegister(int address, short value) { }

    // ===== 受保护方法：子类可以重写 =====
    protected virtual void OnConnected() { }
    protected virtual void OnDisconnected() { }

    // ===== 私有方法：内部辅助方法 =====
    private bool ValidateAddress(int address) { }
    private ushort CalculateCrc(byte[] data) { }
    private void Log(string message) { }
}
```

### 注意事项

- 默认访问修饰符：类的成员如果不写访问修饰符，默认是 `private`
- 字段几乎总是 `private`，通过属性对外暴露
- `protected` 用于需要被子类访问的成员
- `internal` 用于同一项目（程序集）内多个类共享但不想暴露给外部的成员
- 上位机开发中，推荐字段全部 `private`，属性根据需要设为 `public` 或 `private set`

### 练习建议

1. 编写一个 `Sensor` 类，用不同的访问修饰符定义字段和属性，然后在 Main 方法中尝试访问，感受编译错误
2. 将某个字段从 `private` 改为 `protected`，在子类中验证能否访问

## 3. 封装

### 3.1 什么是封装

封装（Encapsulation）是面向对象编程的核心原则之一。它的核心思想是：

- **隐藏内部实现细节**：外部不需要知道数据是怎么存储和计算的
- **通过公共接口（属性/方法）访问数据**：控制外部对内部数据的访问和修改
- **数据验证**：在属性 setter 中验证数据合法性

### 3.2 属性的 getter/setter 详解

```csharp
using System;

namespace EncapsulationDemo
{
    public class TemperatureSensor
    {
        // ===== 方式一：完整属性（手动实现）=====
        // 适合需要验证逻辑的场景
        private double _temperature;

        public double Temperature
        {
            get
            {
                return _temperature;    // 直接返回字段值
            }
            set
            {
                // 在 set 中添加验证逻辑
                if (value < -273.15)
                {
                    Console.WriteLine("警告: 温度不能低于绝对零度 (-273.15°C)");
                    _temperature = -273.15;  // 修正为最小值
                }
                else if (value > 1000)
                {
                    Console.WriteLine("警告: 温度超出传感器测量范围");
                    _temperature = 1000;      // 修正为最大值
                }
                else
                {
                    _temperature = value;    // 正常赋值
                }

                // value 是关键字，代表外部传入的值
                Console.WriteLine($"温度已更新: {_temperature:F2}°C");
            }
        }

        // ===== 方式二：只读属性（只有 get）=====
        public string Unit
        {
            get { return "°C"; }
        }

        // ===== 方式三：计算属性（没有后备字段）=====
        public string Status
        {
            get
            {
                if (_temperature > 100) return "高温";
                if (_temperature < 0) return "低温";
                return "正常";
            }
        }

        // ===== 方式四：自动属性（编译器自动生成字段）=====
        // 语法简洁，适合不需要验证逻辑的属性
        public string SensorName { get; set; }
        public int SensorId { get; init; }  // init：只能在初始化时赋值（C# 9.0+）
        public DateTime LastUpdateTime { get; private set; }  // 只有类内部能写

        // 构造函数
        public TemperatureSensor(string name, int id)
        {
            SensorName = name;
            SensorId = id;
            _temperature = 25.0;
            LastUpdateTime = DateTime.Now;
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            var sensor = new TemperatureSensor("反应釜温度", 1);

            // 设置温度（会触发 setter 中的验证逻辑）
            Console.WriteLine("设置温度为 -300°C:");
            sensor.Temperature = -300;    // 会显示警告并修正

            Console.WriteLine("\n设置温度为 2000°C:");
            sensor.Temperature = 2000;    // 会显示警告并修正

            Console.WriteLine("\n设置温度为 85.5°C:");
            sensor.Temperature = 85.5;    // 正常赋值

            // 读取属性
            Console.WriteLine($"\n--- 传感器信息 ---");
            Console.WriteLine($"名称: {sensor.SensorName}");
            Console.WriteLine($"温度: {sensor.Temperature:F2}{sensor.Unit}");
            Console.WriteLine($"状态: {sensor.Status}");
            Console.WriteLine($"最后更新: {sensor.LastUpdateTime}");

            // Unit 是只读属性，不能赋值
            // sensor.Unit = "K";  // ❌ 编译错误
        }
    }
}
```

### 3.3 上位机场景：封装设备连接参数

```csharp
using System;

namespace DeviceConfigDemo
{
    /// <summary>
    /// PLC 通信配置类
    /// 通过属性封装确保配置参数的合法性
    /// </summary>
    public class PlcConfig
    {
        private string _ipAddress;
        private int _port;
        private byte _stationId;
        private int _timeout;
        private int _retryCount;

        // IP 地址属性（带验证）
        public string IpAddress
        {
            get => _ipAddress;
            set
            {
                if (string.IsNullOrWhiteSpace(value))
                    throw new ArgumentException("IP地址不能为空");

                // 简单的 IP 格式验证
                var parts = value.Split('.');
                if (parts.Length != 4)
                    throw new ArgumentException("IP地址格式错误，应为 x.x.x.x 格式");

                _ipAddress = value;
            }
        }

        // 端口属性（带验证）
        public int Port
        {
            get => _port;
            set
            {
                if (value < 1 || value > 65535)
                    throw new ArgumentException("端口号必须在 1~65535 之间");
                _port = value;
            }
        }

        // 站号属性（带验证）
        public byte StationId
        {
            get => _stationId;
            set
            {
                if (value == 0 || value > 247)
                    throw new ArgumentException("Modbus站号必须在 1~247 之间");
                _stationId = value;
            }
        }

        // 超时属性（带验证，默认值）
        public int Timeout
        {
            get => _timeout;
            set
            {
                _timeout = value < 100 ? 100 : (value > 30000 ? 30000 : value);
            }
        }

        // 重试次数（带验证）
        public int RetryCount
        {
            get => _retryCount;
            set
            {
                _retryCount = value < 0 ? 0 : (value > 10 ? 10 : value);
            }
        }

        // 只读属性：完整配置信息
        public string FullAddress
        {
            get => $"{_ipAddress}:{_port} (站号:{_stationId})";
        }

        // 构造函数
        public PlcConfig(string ip, int port, byte stationId)
        {
            IpAddress = ip;     // 通过属性赋值（触发验证）
            Port = port;
            StationId = stationId;
            Timeout = 3000;      // 默认超时
```

### 3.4 注意事项

- 属性的 `value` 关键字是隐式参数，代表外部传入的值

- `init`（C# 9.0+）只能在对象初始化时赋值，之后不能修改

## 4. 继承

### 4.1 什么是继承

继承允许一个类（子类/派生类）继承另一个类（父类/基类）的字段、属性和方法，并可以扩展新的功能或修改已有行为。

```
基类（父类）
    ↓ 继承
派生类（子类）
```

### 4.2 基本继承示例

```csharp
using System;

namespace InheritanceDemo
{
    // ===== 基类：通用设备 =====
    public class DeviceBase
    {
        // 公共属性
        public string Name { get; set; }
        public bool IsConnected { get; protected set; }

        // 受保护字段：子类可以访问
        protected string _connectionString;

        // 构造函数
        public DeviceBase(string name)
        {
            Name = name;
            IsConnected = false;
        }

        // 公共方法
        public virtual void Connect()
        {
            Console.WriteLine($"[{Name}] 正在连接...");
            IsConnected = true;
            Console.WriteLine($"[{Name}] 已连接");
        }

        public virtual void Disconnect()
        {
            IsConnected = false;
            Console.WriteLine($"[{Name}] 已断开");
        }

        // 虚方法：子类可以重写
        public virtual string GetDeviceInfo()
        {
            return $"设备名: {Name}, 连接状态: {IsConnected}";
        }
    }

    // ===== 子类：Modbus TCP 设备 =====
    public class ModbusTcpDevice : DeviceBase
    {
        // 子类新增属性
        public string IpAddress { get; set; }
        public int Port { get; set; }

        // 构造函数：用 base 调用父类构造函数
        public ModbusTcpDevice(string name, string ip, int port)
            : base(name)  // 调用父类的构造函数
        {
            IpAddress = ip;
            Port = port;
            _connectionString = $"{ip}:{port}";
        }

        // 重写父类方法（override）
        public override void Connect()
        {
            Console.WriteLine($"[{Name}] 正在通过 Modbus TCP 连接 {IpAddress}:{Port}...");
            // Modbus TCP 特定的连接逻辑
            base.Connect();  // 调用父类的 Connect 方法
        }

        // 重写信息方法
        public override string GetDeviceInfo()
        {
            return $"[ModbusTCP] {Name}, IP={IpAddress}, 端口={Port}, 状态={IsConnected}";
        }

        // 子类特有的方法
        public short[] ReadHoldingRegisters(int startAddr, int count)
        {
            if (!IsConnected)
            {
                Console.WriteLine($"[{Name}] 错误: 设备未连接");
                return null;
            }
            Console.WriteLine($"[{Name}] 读取保持寄存器: 地址={startAddr}, 数量={count}");
            return new short[count];  // 模拟返回数据
        }
    }

    // ===== 子类：串口设备 =====
    public class SerialDevice : DeviceBase
    {
        public string PortName { get; set; }
        public int BaudRate { get; set; }

        public SerialDevice(string name, string portName, int baudRate)
            : base(name)
        {
            PortName = portName;
            BaudRate = baudRate;
        }

        public override void Connect()
        {
            Console.WriteLine($"[{Name}] 正在打开串口 {PortName} (波特率: {BaudRate})...");
            IsConnected = true;
            Console.WriteLine($"[{Name}] 串口已打开");
        }

        public override string GetDeviceInfo()
        {
            return $"[Serial] {Name}, 串口={PortName}, 波特率={BaudRate}, 状态={IsConnected}";
        }

        public void SendCommand(string command)
        {
            if (!IsConnected)
            {
                Console.WriteLine($"[{Name}] 错误: 串口未打开");
                return;
            }
            Console.WriteLine($"[{Name}] 发送命令: {command}");
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            // 创建不同类型的设备对象
            DeviceBase modbus = new ModbusTcpDevice("西门子PLC", "192.168.1.100", 502);
            DeviceBase serial = new SerialDevice("变频器", "COM3", 9600);

            // 父类引用指向子类对象（多态）
            DeviceBase[] devices = { modbus, serial };

            Console.WriteLine("========== 设备信息 ==========\n");
            foreach (var device in devices)
            {
                // 调用各自重写的方法（多态）
                Console.WriteLine(device.GetDeviceInfo());
                device.Connect();
                Console.WriteLine();
            }

            // 子类特有方法需要转型
            if (modbus is ModbusTcpDevice modbusTcp)
            {
                modbusTcp.ReadHoldingRegisters(40100, 10);
            }

            if (serial is SerialDevice serialDev)
            {
                serialDev.SendCommand("AT+READ");
            }
        }
    }
}
```

### 4.3 base 关键字

`base` 关键字用于在子类中访问父类的成员。

```csharp
public class ModbusTcpDevice : DeviceBase
{
    public override void Connect()
    {
        // 调用父类的 Connect 方法
        base.Connect();

        // 然后执行子类特有的逻辑
        Console.WriteLine($"[{Name}] Modbus TCP 握手完成");
    }

    public ModbusTcpDevice(string name, string ip, int port)
        : base(name)  // 调用父类的构造函数
    {
        IpAddress = ip;
        Port = port;
    }

    public override string GetDeviceInfo()
    {
        // 先获取父类信息，再补充子类信息
        string baseInfo = base.GetDeviceInfo();
        return $"{baseInfo}, IP={IpAddress}:{Port}";
    }
}
```

### 4.4 virtual / override

- `virtual`：标记方法可以在子类中被重写
- `override`：子类中重写父类的虚方法

```csharp
// 父类
public class DeviceBase
{
    public virtual void Connect() { }        // 虚方法，子类可以重写
    public virtual void Disconnect() { }    // 虚方法
    public void Log(string msg) { }         // 非虚方法，子类不能重写（但可以隐藏）
}

// 子类
public class ModbusTcpDevice : DeviceBase
{
    public override void Connect() { }       // 重写父类虚方法 ✅
    // public override void Log(string msg) { }  // ❌ 编译错误：Log 不是 virtual
    public new void Log(string msg) { }     // 隐藏父类方法（不推荐）
}
```

### 4.5 sealed 密封类/方法

`sealed` 关键字阻止类被继承或方法被重写。

```csharp
// ===== sealed 类：不能被继承 =====
public sealed class FinalConfig
{
    public string IpAddress { get; set; }

    public FinalConfig(string ip)
    {
        IpAddress = ip;
    }
}

// public class MyConfig : FinalConfig { }  // ❌ 编译错误：FinalConfig 是 sealed

// ===== sealed 方法：不能被子类重写 =====
public class DeviceBase
{
    public virtual void Connect() { }
    public virtual void Disconnect() { }
}

public class ModbusDevice : DeviceBase
{
    public sealed override void Connect()  // sealed override：子类不能再重写
    {
        base.Connect();
    }
}

public class AdvancedModbus : ModbusDevice
{
    // public override void Connect() { }  // ❌ 编译错误：已被 sealed
}
```

### 4.6 注意事项

- C# 只支持**单继承**（一个类只能继承一个父类），但可以**实现多个接口**
- 子类构造函数通过 `: base(...)` 调用父类构造函数
- `virtual` 方法用 `override` 重写，非虚方法用 `new` 隐藏（不推荐）
- `sealed` 用于防止进一步继承/重写，通常用于框架中的核心类
- 所有类都隐式继承自 `System.Object`（或 `object`）

## 5. 多态

### 5.1 什么是多态

多态（Polymorphism）是指同一个操作作用于不同的对象，产生不同的行为。在 C# 中主要通过 **抽象类** 和 **接口** 实现多态。

### 5.2 抽象类 abstract

抽象类是不能被实例化的类，它可以包含抽象方法（没有实现，子类必须实现）。

```csharp
using System;

namespace AbstractClassDemo
{
    // ===== 抽象类 =====
    // 用 abstract 关键字修饰
    // 不能直接 new 创建实例
    public abstract class PlcDeviceBase
    {
        // ===== 抽象属性（子类必须实现）=====
        public abstract string ProtocolName { get; }
        public abstract int DefaultPort { get; }

        // ===== 普通属性（子类继承）=====
        public string Name { get; set; }
        public bool IsConnected { get; protected set; }
        public int Timeout { get; set; } = 3000;

        // ===== 抽象方法（子类必须实现）=====
        // 没有方法体，只有声明
        public abstract bool Connect();
        public abstract void Disconnect();
        public abstract short ReadRegister(int address);
        public abstract void WriteRegister(int address, short value);

        // ===== 普通方法（子类继承）=====
        public void ReadMultipleRegisters(int startAddress, int count, short[] buffer)
        {
            if (!IsConnected)
            {
                Console.WriteLine($"[{Name}] 错误: 设备未连接");
                return;
            }

            for (int i = 0; i < count; i++)
            {
                buffer[i] = ReadRegister(startAddress + i);
            }

            Console.WriteLine($"[{Name}] 批量读取 {count} 个寄存器完成");
        }

        // ===== 虚方法（子类可以选择重写）=====
        public virtual void SelfTest()
        {
            Console.WriteLine($"[{Name}] 执行基本自检...");
        }
    }

    // ===== 具体子类：西门子 S7 设备 =====
    public class SiemensS7Device : PlcDeviceBase
    {
        public string IpAddress { get; set; }

        public SiemensS7Device(string name, string ip) : base()
        {
            Name = name;
            IpAddress = ip;
        }

        // 实现抽象属性
        public override string ProtocolName => "S7";
        public override int DefaultPort => 102;

        // 实现抽象方法
        public override bool Connect()
        {
            Console.WriteLine($"[{Name}] S7 协议连接 {IpAddress}:102...");
            IsConnected = true;
            Console.WriteLine($"[{Name}] S7 连接成功");
            return true;
        }

        public override void Disconnect()
        {
            IsConnected = false;
            Console.WriteLine($"[{Name}] S7 连接已断开");
        }

        public override short ReadRegister(int address)
        {
            Console.WriteLine($"[{Name}] S7读取 DB1.DBX{address}");
            return (short)(1000 + address % 100);
        }

        public override void WriteRegister(int address, short value)
        {
            Console.WriteLine($"[{Name}] S7写入 DB1.DBX{address} = {value}");
        }

        // 可选：重写虚方法
        public override void SelfTest()
        {
            base.SelfTest();  // 调用父类
            Console.WriteLine($"[{Name}] S7 特定自检: 检查 CPU 状态...通过");
        }
    }

    // ===== 具体子类：Modbus TCP 设备 =====
    public class ModbusTcpDevice : PlcDeviceBase
    {
        public string IpAddress { get; set; }
        public int Port { get; set; }
        public byte StationId { get; set; }

        public ModbusTcpDevice(string name, string ip, int port, byte station = 1)
        {
            Name = name;
            IpAddress = ip;
            Port = port;
            StationId = station;
        }

        public override string ProtocolName => "Modbus TCP";
        public override int DefaultPort => 502;

        public override bool Connect()
        {
            Console.WriteLine($"[{Name}] Modbus TCP 连接 {IpAddress}:{Port} (站号:{StationId})...");
            IsConnected = true;
            Console.WriteLine($"[{Name}] Modbus TCP 连接成功");
            return true;
        }

        public override void Disconnect()
        {
            IsConnected = false;
            Console.WriteLine($"[{Name}] Modbus TCP 连接已断开");
        }

        public override short ReadRegister(int address)
        {
            Console.WriteLine($"[{Name}] Modbus读取寄存器 {address} (站号:{StationId})");
            return (short)(2000 + address % 200);
        }

        public override void WriteRegister(int address, short value)
        {
            Console.WriteLine($"[{Name}] Modbus写入寄存器 {address} = {value} (站号:{StationId})");
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            // ===== 多态：用父类引用指向不同子类对象 =====
            PlcDeviceBase[] devices = new PlcDeviceBase[]
            {
                new SiemensS7Device("1号西门子PLC", "192.168.1.10"),
                new ModbusTcpDevice("1号ModbusPLC", "192.168.1.100", 502, 1),
                new ModbusTcpDevice("2号ModbusPLC", "192.168.1.101", 502, 2),
            };

            Console.WriteLine("========== 多设备管理 ==========\n");

            // 统一操作：对所有设备执行相同的操作，但实际行为不同（多态）
            foreach (var device in devices)
            {
                // 输出设备信息
                Console.WriteLine($"设备: {device.Name} | 协议: {device.ProtocolName} | 默认端口: {device.DefaultPort}");

                // 连接（多态：调用的是各自子类的实现）
                device.Connect();

                // 读取数据（多态：调用的是各自子类的实现）
                short value = device.ReadRegister(40100);
                Console.WriteLine($"  读取结果: {value}");

                // 批量读取（普通方法，继承自父类，但内部调用的是子类的 ReadRegister）
                short[] buffer = new short[3];
                device.ReadMultipleRegisters(40100, 3, buffer);

                Console.WriteLine();
            }

            // ===== is 模式匹配（类型检查）=====
            Console.WriteLine("--- 类型检查 ---");
            foreach (var device in devices)
            {
                // 使用 is 关键字判断实际类型
                if (device is SiemensS7Device s7)
                {
                    Console.WriteLine($"{device.Name} 是西门子S7设备, IP: {s7.IpAddress}");
                }
                else if (device is ModbusTcpDevice modbus)
                {
                    Console.WriteLine($"{device.Name} 是Modbus设备, 站号: {modbus.StationId}");
                }
            }

            // ===== 断开所有设备 =====
            Console.WriteLine("\n--- 断开所有设备 ---");
            foreach (var device in devices)
            {
                if (device.IsConnected)
                    device.Disconnect();
            }
        }
    }
}
```

### 5.3 接口 interface

接口定义了一组"契约"，实现接口的类必须提供接口中所有成员的实现。接口可以实现"多重继承"的效果。

```csharp
using System;

namespace InterfaceDemo
{
    // ===== 定义接口 =====
    // 接口只声明方法签名，不提供实现
    // 命名规范：I + 名称（以 I 开头）

    /// <summary>
    /// 可连接设备接口
    /// </summary>
    public interface IConnectable
    {
        bool Connect();          // 连接方法
        void Disconnect();       // 断开方法
        bool IsConnected { get; } // 连接状态（只读属性）
    }

    /// <summary>
    /// 可读写设备接口
    /// </summary>
    public interface IReadableWritable
    {
        short ReadRegister(int address);
        void WriteRegister(int address, short value);
        void ReadMultipleRegisters(int startAddress, int count, short[] buffer);
    }

    /// <summary>
    /// 可配置接口
    /// </summary>
    public interface IConfigurable
    {
        void LoadConfig(string configPath);
        void SaveConfig(string configPath);
        string GetConfigInfo();
    }

    // ===== 实现多个接口 =====
    public class ModbusTcpDevice : IConnectable, IReadableWritable, IConfigurable
    {
        public string Name { get; set; }
        public string IpAddress { get; set; }
        public int Port { get; set; }
        public byte StationId { get; set; }

        // 实现 IConnectable
        public bool IsConnected { get; private set; }

        public bool Connect()
        {
            Console.WriteLine($"[{Name}] Modbus TCP 连接 {IpAddress}:{Port}...");
            IsConnected = true;
            return true;
        }

        public void Disconnect()
        {
            IsConnected = false;
            Console.WriteLine($"[{Name}] 已断开");
        }

        // 实现 IReadableWritable
        public short ReadRegister(int address)
        {
            if (!IsConnected) return -1;
            return (short)(new Random().Next(1000));
        }

        public void WriteRegister(int address, short value)
        {
            if (!IsConnected) return;
            Console.WriteLine($"[{Name}] 写入 {address} = {value}");
        }

        public void ReadMultipleRegisters(int startAddress, int count, short[] buffer)
        {
            for (int i = 0; i < count; i++)
                buffer[i] = ReadRegister(startAddress + i);
        }

        // 实现 IConfigurable
        public void LoadConfig(string configPath)
        {
            Console.WriteLine($"[{Name}] 从 {configPath} 加载配置");
            // 实际会从文件读取 IP、端口等参数
        }

        public void SaveConfig(string configPath)
        {
            Console.WriteLine($"[{Name}] 配置保存到 {configPath}");
        }

        public string GetConfigInfo()
        {
            return $"{Name}: {IpAddress}:{Port} (站号:{StationId})";
        }

        public ModbusTcpDevice(string name, string ip, int port, byte station = 1)
        {
            Name = name;
            IpAddress = ip;
            Port = port;
            StationId = station;
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            var device = new ModbusTcpDevice("PLC-001", "192.168.1.100", 502, 1);

            // 用接口类型声明变量（更灵活）
            IConnectable connectable = device;
            IReadableWritable rw = device;
            IConfigurable config = device;

            // 通过不同接口调用同一对象的不同能力
            Console.WriteLine("通过 IConnectable 接口:");
            connectable.Connect();
            Console.WriteLine($"  连接状态: {connectable.IsConnected}");
            connectable.Disconnect();

            Console.WriteLine("\n通过 IReadableWritable 接口:");
            rw.Connect();
            short val = rw.ReadRegister(40100);
            Console.WriteLine($"  读取值: {val}");
            rw.WriteRegister(40100, 1234);

            Console.WriteLine("\n通过 IConfigurable 接口:");
            config.LoadConfig("plc_config.json");
            Console.WriteLine($"  配置信息: {config.GetConfigInfo()}");
            config.SaveConfig("plc_config.json");

            // ===== 接口作为方法参数（多态的强大之处）=====
            Console.WriteLine("\n--- 批量连接所有可连接设备 ---");
            var devices = new IConnectable[]
            {
                new ModbusTcpDevice("PLC-001", "192.168.1.100", 502),
                new ModbusTcpDevice("PLC-002", "192.168.1.101", 502),
                new ModbusTcpDevice("PLC-003", "192.168.1.102", 502),
            };

            ConnectAll(devices);
        }

        /// <summary>
        /// 批量连接方法：接收 IConnectable 接口
        /// 不管是什么类型的设备，只要有 Connect 方法就能用
        /// </summary>
        static void ConnectAll(IConnectable[] devices)
        {
            foreach (var device in devices)
            {
                device.Connect();  // 多态调用
            }
        }
    }
}
```

### 5.4 抽象类 vs 接口对比

| 对比项 | 抽象类（abstract class） | 接口（interface） |
|--------|-------------------------|------------------|
| 实例化 | 不能直接实例化 | 不能直接实例化 |
| 字段 | 可以有字段 | 不能有字段（C# 8.0+ 可以有） |
| 构造函数 | 可以有构造函数 | 不能有构造函数 |
| 方法实现 | 可以有已实现的方法 | 默认没有实现（C# 8.0+ 可以有默认实现） |
| 访问修饰符 | 成员可以有各种访问修饰符 | 默认 public |
| 继承 | 单继承（只能继承一个抽象类） | 多实现（可以实现多个接口） |
| 适用场景 | 有共同状态和行为的"是"关系 | 定义能力契约的"能"关系 |

```
PlcDevice "是一个" DeviceBase      → 用抽象类（继承）
ModbusTcpDevice "能" Connect       → 用接口
ModbusTcpDevice "能" Read/Write  → 用接口
```

### 5.5 注意事项

- 抽象方法只能在抽象类中声明，子类必须用 `override` 实现
- 接口的命名规范以 `I` 开头，如 `IConnectable`、`IReadableWritable`
- 一个类可以实现多个接口，但只能继承一个抽象类
- 接口方法默认是 `public abstract` 的，不需要写访问修饰符
- C# 8.0+ 支持接口的默认实现（`default interface methods`），但初学阶段了解即可
- 上位机开发中，接口常用于定义通信协议的统一接口，方便切换不同品牌设备

### 练习建议

1. 定义一个 `ISensor` 接口，包含 `ReadValue()`、`GetUnit()`、`IsNormal()` 方法，然后创建 `TemperatureSensor` 和 `PressureSensor` 两个实现类
2. 定义 `IAlarmHandler` 接口，包含 `OnAlarm(string message)` 方法，让多个设备类实现该接口
3. 用抽象类和接口结合的方式，设计一个上位机设备管理框架

## 6. 综合实战：封装 PlcDevice 类

下面是一个完整的、贴近实际项目的 `PlcDevice` 类封装，综合运用了本节所有知识点。

```csharp
using System;

namespace FullPlcDeviceDemo
{
    /// <summary>
    /// PLC 设备抽象基类
    /// 定义所有 PLC 设备的公共属性和方法
    /// </summary>
    public abstract class PlcDeviceBase
    {
        // ===== 属性 =====
        public string Name { get; protected set; }
        public string IpAddress { get; protected set; }
        public int Port { get; protected set; }
        public byte StationId { get; protected set; }
        public bool IsConnected { get; protected set; }
        public int Timeout { get; set; }
        public int MaxRetryCount { get; set; }
        public abstract string ProtocolName { get; }

        // ===== 事件（模拟）=====
        // 事件用于通知外部发生了某些事情（如连接成功、报警等）
        // 这里用简单的委托模拟，后续章节会详细讲解事件
        public Action<string> OnMessage { get; set; }

        // ===== 构造函数 =====
        protected PlcDeviceBase(string name, string ip, int port, byte stationId)
        {
            Name = name;
            IpAddress = ip;
            Port = port;
            StationId = stationId;
            Timeout = 3000;
            MaxRetryCount = 3;
            IsConnected = false;
        }

        // ===== 抽象方法（子类必须实现）=====
        public abstract bool DoConnect();
        public abstract void DoDisconnect();
        public abstract short DoReadRegister(int address);
        public abstract void DoWriteRegister(int address, short value);

        // ===== 公共方法（所有子类共享）=====

        /// <summary>
        /// 带重试的连接
        /// </summary>
        public bool Connect()
        {
            Log($"[{Name}] 开始连接 ({IpAddress}:{Port})...");

            for (int retry = 1; retry <= MaxRetryCount; retry++)
            {
                bool success = DoConnect();  // 调用子类的具体实现

                if (success)
                {
                    IsConnected = true;
                    Log($"[{Name}] 连接成功");
                    return true;
                }

                Log($"[{Name}] 第 {retry}/{MaxRetryCount} 次连接失败");
            }

            Log($"[{Name}] 连接失败（已重试 {MaxRetryCount} 次）");
            return false;
        }

        /// <summary>
        /// 断开连接
        /// </summary>
        public void Disconnect()
        {
            if (IsConnected)
            {
                DoDisconnect();
                IsConnected = false;
                Log($"[{Name}] 已断开连接");
            }
        }

        /// <summary>
        /// 带重试的读取
        /// </summary>
        public short ReadRegister(int address)
        {
            if (!IsConnected)
            {
                Log($"[{Name}] 错误: 设备未连接，无法读取寄存器 {address}");
                return -1;
            }

            try
            {
                return DoReadRegister(address);
            }
            catch (Exception ex)
            {
                Log($"[{Name}] 读取寄存器 {address} 异常: {ex.Message}");
                return -1;
            }
        }

        /// <summary>
        /// 带重试的写入
        /// </summary>
        public bool WriteRegister(int address, short value)
        {
            if (!IsConnected)
            {
                Log($"[{Name}] 错误: 设备未连接，无法写入寄存器 {address}");
                return false;
            }

            try
            {
                DoWriteRegister(address, value);
                return true;
            }
            catch (Exception ex)
            {
                Log($"[{Name}] 写入寄存器 {address} 异常: {ex.Message}");
                return false;
            }
        }

        /// <summary>
        /// 批量读取
        /// </summary>
        public short[] ReadMultipleRegisters(int startAddress, int count)
        {
            short[] result = new short[count];
            for (int i = 0; i < count; i++)
            {
                result[i] = ReadRegister(startAddress + i);
            }
            return result;
        }

        /// <summary>
        /// 获取设备信息
        /// </summary>
        public virtual string GetFullInfo()
        {
            return $"[{Name}] 协议={ProtocolName}, 地址={IpAddress}:{Port}, " +
                   $"站号={StationId}, 状态={(IsConnected ? "在线" : "离线")}, " +
                   $"超时={Timeout}ms";
        }

        // ===== 受保护方法 =====
        protected void Log(string message)
        {
            string log = $"[{DateTime.Now:HH:mm:ss}] {message}";
            Console.WriteLine(log);
            OnMessage?.Invoke(log);  // 触发消息事件
        }
    }

    /// <summary>
    /// Modbus TCP 设备实现
    /// </summary>
    public class ModbusTcpDevice : PlcDeviceBase
    {
        private Random _random = new Random();

        public override string ProtocolName => "Modbus TCP";

        public ModbusTcpDevice(string name, string ip, int port, byte stationId = 1)
            : base(name, ip, port, stationId)
        {
        }

        public override bool DoConnect()
        {
            // 模拟连接（80% 概率成功）
            return _random.Next(1, 6) != 1;
        }

        public override void DoDisconnect()
        {
            // 模拟断开
        }

        public override short DoReadRegister(int address)
        {
            // 模拟读取
            short value = (short)_random.Next(0, 10000);
            Log($"[{Name}] 读取寄存器 {address} = {value}");
            return value;
        }

        public override void DoWriteRegister(int address, short value)
        {
            Log($"[{Name}] 写入寄存器 {address} = {value}");
        }

        public override string GetFullInfo()
        {
            return $"{base.GetFullInfo()}, 站号={StationId}";
        }
    }

    /// <summary>
    /// 西门子 S7 设备实现
    /// </summary>
    public class SiemensS7Device : PlcDeviceBase
    {
        private Random _random = new Random();

        public override string ProtocolName => "S7";

        public SiemensS7Device(string name, string ip, int port = 102, byte rack = 0, byte slot = 1)
            : base(name, ip, port, 0)
        {
        }

        public override bool DoConnect()
        {
            return _random.Next(1, 4) != 1;
        }

        public override void DoDisconnect() { }

        public override short DoReadRegister(int address)
        {
            short value = (short)_random.Next(0, 5000);
            Log($"[{Name}] S7读取 DB1.DBD{address} = {value}");
            return value;
        }

        public override void DoWriteRegister(int address, short value)
        {
            Log($"[{Name}] S7写入 DB1.DBD{address} = {value}");
        }
    }

    // ===== 使用示例 =====
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("===========================================");
            Console.WriteLine("   上位机 PLC 设备管理系统");
            Console.WriteLine("===========================================\n");

            // 创建不同协议的设备（多态）
            PlcDeviceBase[] devices =
            {
                new ModbusTcpDevice("1号Modbus设备", "192.168.1.100", 502, 1),
                new ModbusTcpDevice("2号Modbus设备", "192.168.1.101", 502, 2),
                new SiemensS7Device("西门子PLC", "192.168.1.10", 102),
            };

            // ===== 连接所有设备 =====
            Console.WriteLine("--- 第一阶段：连接所有设备 ---\n");
            foreach (var device in devices)
            {
                device.Connect();
                Console.WriteLine($"  → {device.GetFullInfo()}\n");
            }

            // ===== 读写操作 =====
            Console.WriteLine("--- 第二阶段：数据采集 ---\n");
            int[] addresses = { 40100, 40101, 40102 };

            foreach (var device in devices)
            {
                if (!device.IsConnected) continue;

                Console.WriteLine($"[{device.Name}] 采集数据:");
                foreach (int addr in addresses)
                {
                    short value = device.ReadRegister(addr);
                    Console.WriteLine($"  寄存器 {addr} = {value}");
                }
                Console.WriteLine();
            }

            // ===== 断开所有设备 =====
            Console.WriteLine("--- 第三阶段：断开所有设备 ---\n");
            foreach (var device in devices)
            {
                device.Disconnect();
            }

            Console.WriteLine("\n[系统] 程序执行完毕");
        }
    }
}
```

### 注意事项

- 基类中定义"模板方法"（如带重试的 `Connect`），子类只需实现具体的连接逻辑（`DoConnect`），这就是**模板方法设计模式**
- 基类的公共方法负责通用逻辑（重试、日志、异常处理），抽象方法留给子类实现具体细节
- 这种设计方式在上位机开发中非常常用，可以方便地添加新的设备类型（只需新建子类）

## 7. 练习建议

### 基础练习

1. **类设计**：定义一个 `Sensor` 类，包含名称、类型、当前值、上限、下限等属性，以及 `Read()`、`IsAlarm()` 方法
2. **封装练习**：为 `Sensor` 类的所有属性添加 setter 验证逻辑，确保数据范围合法
3. **构造函数**：为 `Sensor` 类设计多个重载构造函数（无参、全参、部分参数）

### 进阶练习

4. **继承练习**：创建 `DeviceBase` 基类和 `TcpDevice`、`SerialDevice` 子类，分别实现 TCP 和串口通信
5. **接口练习**：定义 `IConnectable` 接口，让 3 个不同的设备类实现该接口，用统一的代码管理它们
6. **多态练习**：用抽象类+接口设计一个设备管理器，支持动态添加不同类型的设备并批量操作

### 挑战练习

7. **完整封装**：参考第 6 节的示例，封装一个完整的 `ModbusTcpDevice` 类，包含连接、读写、批量操作、CRC 计算、异常处理等功能
8. **设计模式**：用抽象类实现模板方法模式，让基类定义通信流程（连接→读取→校验→断开），子类实现各步骤的具体逻辑

## 8. 常见错误汇总

| 错误类型 | 错误示例 | 正确写法 | 说明 |
|---------|---------|---------|------|
| 忘记 new | `PlcDevice p;` 然后用 `p.Connect()` | `PlcDevice p = new PlcDevice(...)` | 引用类型必须 new 创建实例 |
| 访问 private | `plc._ipAddress = "..."` | `plc.IpAddress = "..."` | private 字段只能通过属性访问 |
| abstract 未实现 | 子类没有实现抽象方法 | 用 `override` 实现所有抽象成员 | 抽象方法必须在子类中实现 |
| override 拼写错误 | `public overide void Connect()` | `public override void Connect()` | 关键字拼写错误 |
| 忘记 base 调用 | 子类构造函数不调用父类构造函数 | `: base(...)` | 子类构造函数应调用父类 |
| sealed 继承 | 继承一个 sealed 类 | 不能继承 sealed 类 | sealed 类禁止被继承 |
| 虚方法未 virtual | 子类 override 非虚方法 | 父类方法加 `virtual` | 只有 virtual 方法才能 override |
| 接口未实现 | 类声明接口但没实现方法 | 实现所有接口成员 | 接口成员必须全部实现 |
| 对象引用为 null | `PlcDevice p = null; p.Connect();` | 检查 `if (p != null)` | null 对象调用方法会抛异常 |
| 值类型 vs 引用类型 | 期望修改原对象但修改了副本 | 注意 struct 是值类型 | struct 赋值是复制，class 是引用 |
