# 02 - 配置管理

> 本文讲解上位机项目中的配置管理技术，包括配置文件的读写、自定义配置类、配置热更新等实战技巧。

---

## 一、知识讲解

### 1.1 为什么需要配置管理？

上位机软件的很多参数不是固定的，例如：
- PLC的IP地址、端口号、站号
- 数据采集周期
- 报警阈值
- 数据库连接字符串
- 日志保存路径

如果这些参数写死在代码中，每次修改都需要重新编译。**配置管理**就是将这些参数外部化，保存到配置文件中，运行时读取。

### 1.2 配置文件类型对比

| 配置文件格式 | 适用框架 | 优点 | 缺点 |
|-------------|----------|------|------|
| **app.config (XML)** | .NET Framework | 原生支持、类型安全 | 格式冗长、不直观 |
| **appsettings.json (JSON)** | .NET Core / .NET 5+ | 格式简洁、层次清晰 | .NET Framework需要额外库 |
| **自定义JSON配置** | 所有框架 | 灵活自由 | 需要自己实现读写逻辑 |

> **推荐方案**：在.NET Framework上位机项目中，推荐使用**自定义JSON配置文件**，简单灵活且跨框架通用。

### 1.3 配置分类

| 配置类型 | 说明 | 存储位置 | 示例 |
|----------|------|----------|------|
| **应用配置** | 与程序逻辑相关的配置，所有用户共享 | 程序目录下 | PLC连接参数、采集周期、报警阈值 |
| **用户配置** | 与用户个人偏好相关的配置，每个用户不同 | 用户数据目录 | 窗体位置大小、最近打开的文件、界面主题 |

### 1.4 配置热更新

**配置热更新**是指在不重启程序的情况下修改配置并立即生效。这在工业现场非常重要，因为上位机通常需要7x24小时运行，不能因为修改一个参数就重启程序。

**实现思路：**
1. 使用 `FileSystemWatcher` 监听配置文件的变化
2. 文件变化时重新读取配置内容
3. 通过事件通知相关模块配置已更新
4. 各模块根据新配置调整行为

```csharp
// ============================================================
// 文件：AppConfigHelper.cs
// 说明：读取app.config配置的帮助类
// ============================================================
using System.Configuration;

namespace HwPlcMonitor.Core.Configuration
{
    /// <summary>
    /// app.config配置帮助类
    /// 封装配置的读取，并提供默认值
    /// </summary>
    public static class AppConfigHelper
    {
        /// <summary>
        /// 读取字符串配置值
        /// </summary>
        /// <param name="key">配置键名</param>
        /// <param name="defaultValue">默认值（配置不存在时返回）</param>
        /// <returns>配置值</returns>
        public static string GetString(string key, string defaultValue = "")
        {
            return ConfigurationManager.AppSettings[key] ?? defaultValue;
        }

        /// <summary>
        /// 读取整数配置值
        /// </summary>
        public static int GetInt(string key, int defaultValue = 0)
        {
            var value = GetString(key);
            return int.TryParse(value, out int result) ? result : defaultValue;
        }

        /// <summary>
        /// 读取浮点数配置值
        /// </summary>
        public static double GetDouble(string key, double defaultValue = 0)
        {
            var value = GetString(key);
            return double.TryParse(value, out double result) ? result : defaultValue;
        }

        // ---- 上位机专用配置读取方法 ----

        /// <summary>获取PLC的IP地址</summary>
        public static string PlcIpAddress => GetString("PlcIpAddress", "192.168.1.100");

        /// <summary>获取PLC端口号</summary>
        public static int PlcPort => GetInt("PlcPort", 502);

        /// <summary>获取采集周期（毫秒）</summary>
        public static int PollInterval => GetInt("PollInterval", 1000);

        /// <summary>获取温度上限报警值</summary>
        public static double TempHighLimit => GetDouble("TempHighLimit", 85.0);
    }
}
```

### 2.3 配置管理器（支持热更新）

```csharp
// ============================================================
// 文件：ConfigManager.cs
// 说明：配置管理器 - 支持读取、保存和热更新
// ============================================================
using Newtonsoft.Json;
using System.IO;

namespace HwPlcMonitor.Core.Configuration
{
    /// <summary>
    /// 配置管理器（单例模式）
    /// 负责配置文件的加载、保存和热更新
    /// </summary>
    public class ConfigManager : IDisposable
    {
        // 单例实例
        private static ConfigManager _instance;
        private static readonly object _lock = new object();

        /// <summary>获取单例实例</summary>
        public static ConfigManager Instance
        {
            get
            {
                if (_instance == null)
                {
                    lock (_lock)
                    {
                        if (_instance == null)
                            _instance = new ConfigManager();
                    }
                }
                return _instance;
            }
        }

        // 配置文件路径
        private readonly string _configFilePath;
        // 文件变化监视器
        private FileSystemWatcher _fileWatcher;

        /// <summary>当前配置对象</summary>
        public AppSettings Settings { get; private set; }

        /// <summary>
        /// 配置变化事件 - 通知外部配置已更新
        /// </summary>
        public event EventHandler<AppSettings> SettingsChanged;

        private ConfigManager()
        {
            // 配置文件放在程序目录下
            var appDir = AppDomain.CurrentDomain.BaseDirectory;
            _configFilePath = Path.Combine(appDir, "appsettings.json");

            // 加载配置
            Load();

            // 启动文件监听（热更新）
            StartFileWatcher();
        }

        /// <summary>
        /// 加载配置文件
        /// 如果文件不存在，使用默认配置并创建文件
        /// </summary>
        public void Load()
        {
            try
            {
                if (File.Exists(_configFilePath))
                {
                    // 读取JSON文件内容
                    var json = File.ReadAllText(_configFilePath);
                    // 反序列化为AppSettings对象
                    Settings = JsonConvert.DeserializeObject<AppSettings>(json);
                }
                else
                {
                    // 文件不存在，使用默认配置
                    Settings = new AppSettings();
                    Save(); // 创建默认配置文件
                }
            }
            catch (Exception ex)
            {
                // 解析失败时使用默认配置
                Settings = new AppSettings();
                Console.WriteLine($"加载配置失败: {ex.Message}，使用默认配置");
            }
        }

        /// <summary>
        /// 保存配置到文件
        /// </summary>
        public void Save()
        {
            try
            {
                // 格式化输出JSON，方便人工阅读和编辑
                var json = JsonConvert.SerializeObject(Settings, Formatting.Indented);
                File.WriteAllText(_configFilePath, json);
            }
            catch (Exception ex)
            {
                Console.WriteLine($"保存配置失败: {ex.Message}");
            }
        }

        /// <summary>
        /// 更新配置并保存
        /// </summary>
        public void UpdateSettings(AppSettings newSettings)
        {
            Settings = newSettings;
            Save();
            SettingsChanged?.Invoke(this, Settings);
        }

        /// <summary>
        /// 启动文件监听，实现配置热更新
        /// </summary>
        private void StartFileWatcher()
        {
            try
            {
                var fileDir = Path.GetDirectoryName(_configFilePath);
                var fileName = Path.GetFileName(_configFilePath);

                _fileWatcher = new FileSystemWatcher(fileDir)
                {
                    Filter = fileName,           // 只监听配置文件
                    EnableRaisingEvents = true,
                    NotifyFilter = NotifyFilters.LastWrite | NotifyFilters.Size
                };

                // 文件修改事件（注意：文件保存可能触发多次）
                _fileWatcher.Changed += OnFileChanged;
            }
            catch (Exception ex)
            {
                Console.WriteLine($"启动文件监听失败: {ex.Message}");
            }
        }

        // 防抖定时器：避免文件保存过程中多次触发
        private Timer _debounceTimer;
        private bool _isReloading;

        /// <summary>
        /// 文件变化回调
        /// </summary>
        private void OnFileChanged(object sender, FileSystemEventArgs e)
        {
            // 防抖处理：文件保存时可能触发多次Changed事件
            // 使用定时器，最后一次变化后300ms再重新加载
            if (_isReloading) return;

            _isReloading = true;
            _debounceTimer?.Dispose();
            _debounceTimer = new Timer(state =>
            {
                _isReloading = false;
                Load(); // 重新加载配置
                SettingsChanged?.Invoke(this, Settings);
            }, null, 300, Timeout.Infinite);
        }

        public void Dispose()
        {
            _fileWatcher?.Dispose();
            _debounceTimer?.Dispose();
        }
    }
}
```

```csharp

// ============================================================
using Newtonsoft.Json;
using System.IO;

namespace HwPlcMonitor.Core.Configuration
{
    /// <summary>
    /// 用户配置
    /// 保存用户个人偏好，与AppSettings分开存储
    /// </summary>
    public class UserSettings
    {
        /// <summary>主窗口位置X</summary>
        public int MainFormX { get; set; } = 100;

        /// <summary>主窗口位置Y</summary>
        public int MainFormY { get; set; } = 100;

        /// <summary>主窗口宽度</summary>
        public int MainFormWidth { get; set; } = 1200;

        /// <summary>主窗口高度</summary>
        public int MainFormHeight { get; set; } = 800;

        /// <summary>上次连接的PLC地址</summary>
        public string LastPlcAddress { get; set; } = "";

        /// <summary>界面主题</summary>
        public string Theme { get; set; } = "Light";

        /// <summary>图表显示的点数</summary>
        public int ChartPointCount { get; set; } = 100;
    }

    /// <summary>
    /// 用户配置管理器
    /// 用户配置保存在用户数据目录（%AppData%），与程序配置分离
    /// </summary>
    public class UserSettingsManager
    {
        private static UserSettingsManager _instance;
        public static UserSettingsManager Instance
        {
            get => _instance ??= new UserSettingsManager();
        }

        // 用户配置保存在 %AppData%\HwPlcMonitor\ 目录下
        private readonly string _userSettingsPath;
        public UserSettings Settings { get; private set; }

        private UserSettingsManager()
        {
            // 获取AppData路径
            var appDataPath = Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData);
            var appFolder = Path.Combine(appDataPath, "HwPlcMonitor");

            // 确保目录存在
            if (!Directory.Exists(appFolder))
                Directory.CreateDirectory(appFolder);

            _userSettingsPath = Path.Combine(appFolder, "usersettings.json");
            Load();
        }

        public void Load()
        {
            try
            {
                if (File.Exists(_userSettingsPath))
                {
                    var json = File.ReadAllText(_userSettingsPath);
                    Settings = JsonConvert.DeserializeObject<UserSettings>(json);
                }
                else
                {
                    Settings = new UserSettings();
                }
            }
            catch
            {
                Settings = new UserSettings();
            }
        }

        public void Save()
        {
            try
            {
                var json = JsonConvert.SerializeObject(Settings, Formatting.Indented);
                File.WriteAllText(_userSettingsPath, json);
            }
            catch (Exception ex)
            {
                Console.WriteLine($"保存用户配置失败: {ex.Message}");
            }
        }
    }
}
```

## 三、注意事项

### 3.1 配置管理常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 配置文件读取失败 | 文件路径错误或编码问题 | 使用绝对路径，统一UTF-8编码 |
| JSON解析报错 | 配置格式错误（缺少逗号/括号） | 提供默认值兜底，添加格式校验 |
| 热更新触发多次 | 文件保存时触发多次Changed事件 | 使用防抖机制（Debounce） |
| 配置被误改 | 非技术人员直接编辑JSON出错 | 在UI中提供配置编辑界面 |
| 配置项不存在 | 新版本添加了配置项但旧配置文件没有 | 配置类提供默认值 |

### 3.2 配置安全注意事项

| 注意点 | 说明 |
|--------|------|
| **敏感信息不要明文存储** | 密码等敏感信息应加密存储或使用系统凭据管理 |
| **配置文件权限控制** | 确保配置文件只有授权用户可修改 |
| **配置校验** | 加载配置后进行有效性校验（IP格式、端口号范围等） |
| **配置备份** | 修改配置前先备份旧配置 |

### 3.3 最佳实践

| 实践 | 说明 |
|------|------|
| **默认值不可少** | 所有配置项必须有合理的默认值 |
| **配置与代码分离** | 绝不要在代码中硬编码配置值 |
| **统一管理** | 使用配置管理器统一管理，不要在各个类中分散读取 |
| **热更新友好** | 设计配置时考虑热更新场景，避免配置更新需要重启 |
| **注释清晰** | JSON配置中每个字段的含义要一目了然 |

```csharp
namespace HwPlcMonitor.UI
{
    public partial class SettingForm : Form
    {
        private void btnSave_Click(object sender, EventArgs e)
        {
            // 从界面控件读取用户输入
            var config = ConfigManager.Instance;

            config.Settings.PlcConnection.IpAddress = txtIpAddress.Text;
            config.Settings.PlcConnection.Port = int.Parse(txtPort.Text);
            config.Settings.PlcConnection.SlaveId = byte.Parse(txtSlaveId.Text);

            config.Settings.DataCollect.PollIntervalMs = int.Parse(txtPollInterval.Text);

            config.Settings.Alarm.Thresholds.Clear();
            foreach (DataGridViewRow row in dgvAlarmThresholds.Rows)
            {
                config.Settings.Alarm.Thresholds.Add(new AlarmThreshold
                {
                    TagName = row.Cells["TagName"].Value?.ToString(),
                    Address = row.Cells["Address"].Value?.ToString(),
                    HighLimit = Convert.ToDouble(row.Cells["HighLimit"].Value),
                    LowLimit = Convert.ToDouble(row.Cells["LowLimit"].Value),
                    Unit = row.Cells["Unit"].Value?.ToString(),
                });
            }

            // 保存配置到文件
            config.Save();

            MessageBox.Show("配置保存成功！", "提示",
                MessageBoxButtons.OK, MessageBoxIcon.Information);
        }
    }
}
```

> **提示**：配置管理的核心是**配置与代码分离**和**统一管理**。所有配置参数都通过ConfigManager统一读取和保存，各模块不要自己直接读配置文件。这样既保证了代码的整洁，也方便后续扩展热更新等功能。
