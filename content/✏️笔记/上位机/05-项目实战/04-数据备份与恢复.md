# 04 - 数据备份与恢复

> 本文讲解上位机项目中数据备份与恢复的实现方案，包括定时备份、文件压缩、数据库备份等核心功能。

---

## 一、知识讲解

### 1.1 为什么需要数据备份？

上位机系统采集的数据是企业的宝贵资产，数据丢失会造成严重后果：

| 风险场景 | 后果 |
|----------|------|
| 磁盘损坏 | 所有历史数据丢失，无法追溯产品质量问题 |
| 误操作删除 | 报警记录或关键数据被清空 |
| 数据库文件损坏 | 程序无法启动，数据无法读取 |
| 电脑中毒/勒索软件 | 数据被加密或破坏 |
| 人为覆盖安装 | 升级程序时旧数据被覆盖 |

### 1.2 数据备份策略

| 策略 | 说明 | 适用场景 | 优缺点 |
|------|------|----------|--------|
| **全量备份** | 每次备份完整的数据库文件 | 数据量小（<500MB） | 实现简单，恢复快速；占用空间大 |
| **增量备份** | 只备份自上次备份以来变化的数据 | 数据量大 | 节省空间；恢复复杂 |
| **定时备份** | 按固定时间间隔自动备份 | 7x24运行的上位机 | 自动化，无需人工干预 |
| **手动备份** | 用户手动触发备份 | 重要操作前 | 用户可控；依赖人为操作 |
| **混合策略** | 定时全量 + 事件触发备份 | 推荐方案 | 兼顾自动化和安全性 |

> **推荐方案**：定时全量备份（每天一次）+ 手动备份（重要操作前）

### 1.3 备份文件管理

| 管理项 | 说明 | 建议 |
|--------|------|------|
| **文件命名** | 包含日期时间和备份类型 | `plcdata_backup_20240115_080000.zip` |
| **目录结构** | 备份文件与数据库分开存储 | 最好备份到不同的磁盘或网络位置 |
| **保留策略** | 自动清理过旧的备份文件 | 保留最近N份备份（如7份） |
| **压缩格式** | 使用ZIP压缩减小文件体积 | .NET内置ZipArchive，无需第三方库 |
| **完整性校验** | 备份后校验文件完整性 | 检查文件大小、校验和 |

### 1.4 恢复流程

```
恢复流程：
1. 确认当前数据库已关闭（停止数据采集和写入）
2. 选择备份文件
3. 验证备份文件完整性
4. 备份当前数据库（防止恢复失败）
5. 解压备份文件
6. 用备份文件覆盖当前数据库
7. 验证恢复后的数据库完整性
8. 重新启动数据采集
```

### 2.1 SQLite数据库备份（使用SQLite原生API）

```csharp
// ============================================================
// 文件：SqliteBackupHelper.cs
// 说明：SQLite数据库备份帮助类
// 使用SQLite自带的备份API，安全可靠
// 需要NuGet包：System.Data.SQLite
// ============================================================
using System.Data.SQLite;

namespace HwPlcMonitor.Core.Backup
{
    /// <summary>
    /// SQLite数据库备份帮助类
    /// 使用SQLite原生备份API，在数据库运行时也能安全备份
    /// </summary>
    public class SqliteBackupHelper
    {
        /// <summary>
        /// 备份数据库
        /// 使用SQLite的Online Backup API，支持热备份（不需要关闭数据库）
        /// </summary>
        /// <param name="sourceDbPath">源数据库文件路径</param>
        /// <param name="backupDbPath">备份文件路径</param>
        /// <returns>备份是否成功</returns>
        public static bool BackupDatabase(string sourceDbPath, string backupDbPath)
        {
            try
            {
                // 确保源数据库文件存在
                if (!File.Exists(sourceDbPath))
                {
                    Console.WriteLine($"源数据库不存在: {sourceDbPath}");
                    return false;
                }

                // 如果备份目标文件已存在，先删除
                if (File.Exists(backupDbPath))
                    File.Delete(backupDbPath);

                // 连接源数据库
                using (var sourceConn = new SQLiteConnection($"Data Source={sourceDbPath}"))
                {
                    sourceConn.Open();

                    // 连接目标数据库（备份文件）
                    using (var backupConn = new SQLiteConnection($"Data Source={backupDbPath}"))
                    {
                        backupConn.Open();

                        // 使用SQLite的备份API
                        sourceConn.BackupDatabase(
                            backupConn,
                            "main",     // 源数据库名（默认main）
                            "main",     // 目标数据库名（默认main）
                            -1,         // 备份所有页（-1表示全部）
                            null,       // 无进度回调
                            -1          // 无超时限制
                        );
                    }
                }

                Console.WriteLine($"数据库备份成功: {backupDbPath}");
                return true;
            }
            catch (Exception ex)
            {
                Console.WriteLine($"数据库备份失败: {ex.Message}");
                return false;
            }
        }

        /// <summary>
        /// 备份数据库并压缩为ZIP文件
        /// </summary>
        /// <param name="sourceDbPath">源数据库路径</param>
        /// <param name="zipFilePath">ZIP文件路径</param>
        /// <returns>备份是否成功</returns>
        public static bool BackupAndCompress(string sourceDbPath, string zipFilePath)
        {
            // 先备份到临时文件
            var tempBackupPath = zipFilePath + ".tmp";

            if (!BackupDatabase(sourceDbPath, tempBackupPath))
                return false;

            try
            {
                // 压缩为ZIP
                if (File.Exists(zipFilePath))
                    File.Delete(zipFilePath);

                using (var archive = ZipFile.Open(zipFilePath, ZipArchiveMode.Create))
                {
                    archive.CreateEntryFromFile(tempBackupPath, Path.GetFileName(sourceDbPath));
                }

                // 删除临时备份文件
                File.Delete(tempBackupPath);
                Console.WriteLine($"数据库备份并压缩成功: {zipFilePath}");
                return true;
            }
            catch (Exception ex)
            {
                Console.WriteLine($"压缩备份文件失败: {ex.Message}");
                // 清理临时文件
                if (File.Exists(tempBackupPath)) File.Delete(tempBackupPath);
                return false;
            }
        }
    }
}
```

### 2.2 自动备份服务

```csharp
// ============================================================
// 文件：AutoBackupService.cs
// 说明：自动备份服务 - 定时自动执行数据库备份
// ============================================================
using System.IO.Compression;

namespace HwPlcMonitor.Core.Backup
{
    /// <summary>
    /// 自动备份服务
    /// 定期自动执行数据库备份，并管理备份文件的生命周期
    /// </summary>
    public class AutoBackupService : IDisposable
    {
        // 定时器（使用System.Timers.Timer，比WinForms.Timer更适合后台任务）
        private System.Timers.Timer _backupTimer;
        private readonly BackupConfig _config;

        /// <summary>备份完成事件</summary>
        public event EventHandler<BackupResult> BackupCompleted;

        /// <summary>备份失败事件</summary>
        public event EventHandler<string> BackupFailed;

        public AutoBackupService(BackupConfig config)
        {
            _config = config;

            // 创建备份目录
            if (!Directory.Exists(_config.BackupDirectory))
                Directory.CreateDirectory(_config.BackupDirectory);

            // 启动定时器
            _backupTimer = new System.Timers.Timer(_config.IntervalMs);
            _backupTimer.Elapsed += OnBackupTimerElapsed;
            _backupTimer.AutoReset = true;
            _backupTimer.Start();
        }

        /// <summary>
        /// 定时器触发时执行备份
        /// </summary>
        private async void OnBackupTimerElapsed(object sender, System.Timers.ElapsedEventArgs e)
        {
            await ExecuteBackupAsync();
        }

        /// <summary>
        /// 执行备份
        /// </summary>
        public async Task<BackupResult> ExecuteBackupAsync()
        {
            var result = new BackupResult
            {
                BackupTime = DateTime.Now
            };

            try
            {
                // 生成备份文件名：plcdata_backup_20240115_080000.zip
                var timestamp = DateTime.Now.ToString("yyyyMMdd_HHmmss");
                var zipFileName = $"plcdata_backup_{timestamp}.zip";
                var zipFilePath = Path.Combine(_config.BackupDirectory, zipFileName);

                // 检查磁盘空间（至少需要数据库文件大小的2倍空间）
                var dbFileInfo = new FileInfo(_config.DatabasePath);
                var driveInfo = new DriveInfo(Path.GetPathRoot(_config.BackupDirectory));
                if (driveInfo.AvailableFreeSpace < dbFileInfo.Length * 2)
                {
                    result.Success = false;
                    result.ErrorMessage = "磁盘空间不足";
                    BackupFailed?.Invoke(this, result.ErrorMessage);
                    return result;
                }

                // 执行备份并压缩
                result.Success = SqliteBackupHelper.BackupAndCompress(
                    _config.DatabasePath, zipFilePath);

                if (result.Success)
                {
                    result.BackupFilePath = zipFilePath;
                    result.FileSize = new FileInfo(zipFilePath).Length;

                    // 清理过期的备份文件
                    CleanOldBackups();

                    BackupCompleted?.Invoke(this, result);
                }
                else
                {
                    result.ErrorMessage = "数据库备份失败";
                    BackupFailed?.Invoke(this, result.ErrorMessage);
                }
            }
            catch (Exception ex)
            {
                result.Success = false;
                result.ErrorMessage = ex.Message;
                BackupFailed?.Invoke(this, ex.Message);
            }

            return result;
        }

        /// <summary>
        /// 清理过期的备份文件，保留最近N份
        /// </summary>
        private void CleanOldBackups()
        {
            try
            {
                var backupFiles = new DirectoryInfo(_config.BackupDirectory)
                    .GetFiles("plcdata_backup_*.zip")
                    .OrderByDescending(f => f.CreationTime)
                    .ToList();

                // 超出保留数量的文件需要删除
                var filesToDelete = backupFiles
                    .Skip(_config.KeepCount)  // 保留最新的N份
                    .ToList();

                foreach (var file in filesToDelete)
                {
                    file.Delete();
                    Console.WriteLine($"删除过期备份: {file.Name}");
                }
            }
            catch (Exception ex)
            {
                Console.WriteLine($"清理过期备份失败: {ex.Message}");
            }
        }

        /// <summary>
        /// 获取所有备份文件列表
        /// </summary>
        public List<BackupFileInfo> GetBackupList()
        {
            return new DirectoryInfo(_config.BackupDirectory)
                .GetFiles("plcdata_backup_*.zip")
                .OrderByDescending(f => f.CreationTime)
                .Select(f => new BackupFileInfo
                {
                    FileName = f.Name,
                    FilePath = f.FullName,
                    FileSize = f.Length,
                    CreateTime = f.CreationTime,
                    SizeDisplay = FormatFileSize(f.Length)
                })
                .ToList();
        }

        /// <summary>
        /// 格式化文件大小显示
        /// </summary>
        private string FormatFileSize(long bytes)
        {
            if (bytes < 1024) return $"{bytes} B";
            if (bytes < 1024 * 1024) return $"{bytes / 1024.0:F1} KB";
            return $"{bytes / (1024.0 * 1024):F2} MB";
        }

        public void Dispose()
        {
            _backupTimer?.Stop();
            _backupTimer?.Dispose();
        }
    }

    /// <summary>
    /// 备份配置
    /// </summary>
    public class BackupConfig
    {
        /// <summary>数据库文件路径</summary>
        public string DatabasePath { get; set; }

        /// <summary>备份文件目录</summary>
        public string BackupDirectory { get; set; } = "backup\\";

        /// <summary>备份间隔（毫秒）</summary>
        public long IntervalMs { get; set; } = 24 * 60 * 60 * 1000; // 默认24小时

        /// <summary>保留备份份数</summary>
        public int KeepCount { get; set; } = 7;
    }

    /// <summary>
    /// 备份结果
    /// </summary>
    public class BackupResult
    {
        public bool Success { get; set; }
        public DateTime BackupTime { get; set; }
        public string BackupFilePath { get; set; }
        public long FileSize { get; set; }
        public string ErrorMessage { get; set; }
    }

    /// <summary>
    /// 备份文件信息
    /// </summary>
    public class BackupFileInfo
    {
        public string FileName { get; set; }
        public string FilePath { get; set; }
        public long FileSize { get; set; }
        public DateTime CreateTime { get; set; }
        public string SizeDisplay { get; set; }
    }
}
```

### 2.3 数据恢复

```csharp
// ============================================================
// 文件：DataRestoreHelper.cs
// 说明：数据恢复帮助类 - 从备份文件恢复数据库
// ============================================================
using System.IO.Compression;

namespace HwPlcMonitor.Core.Backup
{
    /// <summary>
    /// 数据恢复帮助类
    /// 负责从ZIP备份文件中恢复SQLite数据库
    /// </summary>
    public class DataRestoreHelper
    {
        /// <summary>
        /// 从ZIP备份文件恢复数据库
        /// </summary>
        /// <param name="zipFilePath">备份ZIP文件路径</param>
        /// <param name="targetDbPath">目标数据库路径</param>
        /// <param name="backupCurrentDb">是否在恢复前备份当前数据库</param>
        /// <returns>恢复是否成功</returns>
        public static RestoreResult RestoreFromBackup(
            string zipFilePath, string targetDbPath, bool backupCurrentDb = true)
        {
            var result = new RestoreResult { RestoreTime = DateTime.Now };

            try
            {
                // 1. 验证备份文件存在且完整
                if (!File.Exists(zipFilePath))
                {
                    result.Success = false;
                    result.ErrorMessage = "备份文件不存在";
                    return result;
                }

                // 检查文件大小是否合理（不能为0）
                var zipFileInfo = new FileInfo(zipFilePath);
                if (zipFileInfo.Length == 0)
                {
                    result.Success = false;
                    result.ErrorMessage = "备份文件大小为0，文件已损坏";
                    return result;
                }

                result.BackupFileTime = zipFileInfo.CreationTime;

                // 2. 如果需要，先备份当前数据库
                if (backupCurrentDb && File.Exists(targetDbPath))
                {
                    var timestamp = DateTime.Now.ToString("yyyyMMdd_HHmmss");
                    var preRestoreBackup = Path.Combine(
                        Path.GetDirectoryName(targetDbPath),
                        $"pre_restore_{timestamp}.db.bak"
                    );
                    File.Copy(targetDbPath, preRestoreBackup, true);
                    result.PreRestoreBackupPath = preRestoreBackup;
                }

                // 3. 解压备份文件到临时目录
                var tempDir = Path.Combine(Path.GetTempPath(), "HwPlcMonitor_Restore");
                if (Directory.Exists(tempDir))
                    Directory.Delete(tempDir, true);
                Directory.CreateDirectory(tempDir);

                ZipFile.ExtractToDirectory(zipFilePath, tempDir);

                // 4. 查找解压后的数据库文件
                var extractedDbFile = Directory.GetFiles(tempDir, "*.db")
                    .FirstOrDefault();

                if (extractedDbFile == null)
                {
                    result.Success = false;
                    result.ErrorMessage = "备份文件中未找到数据库文件";
                    return result;
                }

                // 5. 验证解压后的数据库文件完整性
                result.Success = ValidateDatabaseFile(extractedDbFile);
                if (!result.Success)
                {
                    result.ErrorMessage = "数据库文件完整性验证失败";
                    return result;
                }

                // 6. 关闭当前数据库连接（需要外部确保）
                // 注意：调用此方法前，外部必须先关闭所有数据库连接！

                // 7. 用备份文件替换当前数据库
                File.Copy(extractedDbFile, targetDbPath, true);

                // 8. 清理临时文件
                Directory.Delete(tempDir, true);

                result.Success = true;
                return result;
            }
            catch (Exception ex)
            {
                result.Success = false;
                result.ErrorMessage = $"恢复失败: {ex.Message}";
                return result;
            }
        }

        /// <summary>
        /// 验证SQLite数据库文件完整性
        /// </summary>
        private static bool ValidateDatabaseFile(string dbPath)
        {
            try
            {
                // 检查文件头（SQLite文件头为 "SQLite format 3\000"）
                using (var fs = new FileStream(dbPath, FileMode.Open, FileAccess.Read))
                {
                    var header = new byte[16];
                    fs.Read(header, 0, 16);
                    var headerText = System.Text.Encoding.ASCII.GetString(header);

                    if (!headerText.StartsWith("SQLite format 3"))
                    {
                        Console.WriteLine("数据库文件头校验失败");
                        return false;
                    }
                }

                // 尝试打开并执行完整性检查
                using (var conn = new System.Data.SQLite.SQLiteConnection($"Data Source={dbPath}"))
                {
                    conn.Open();
                    using (var cmd = conn.CreateCommand())
                    {
                        cmd.CommandText = "PRAGMA integrity_check;";
                        var result = cmd.ExecuteScalar()?.ToString();
                        return result == "ok";
                    }
                }
            }
            catch (Exception ex)
            {
                Console.WriteLine($"数据库验证失败: {ex.Message}");
                return false;
            }
        }
    }

    /// <summary>
    /// 恢复结果
    /// </summary>
    public class RestoreResult
    {
        public bool Success { get; set; }
        public DateTime RestoreTime { get; set; }
        public string ErrorMessage { get; set; }
        public DateTime? BackupFileTime { get; set; }
        public string PreRestoreBackupPath { get; set; }
    }
}
```

```csharp
// ============================================================
// 文件：BackupRestoreForm.cs（UI部分代码）
// 说明：备份恢复界面的核心逻辑
// ============================================================
namespace HwPlcMonitor.UI.Forms
{
    public partial class BackupRestoreForm : Form
    {
        private AutoBackupService _backupService;

        public BackupRestoreForm()
        {
            InitializeComponent();

            // 初始化备份服务
            var config = new BackupConfig
            {
                DatabasePath = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "data\\plcdata.db"),
                BackupDirectory = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "backup\\"),
                KeepCount = 7,
                IntervalMs = 24 * 60 * 60 * 1000 // 24小时
            };
            _backupService = new AutoBackupService(config);

            // 加载备份列表
            LoadBackupList();
        }

        /// <summary>
        /// 加载备份文件列表到DataGridView
        /// </summary>
        private void LoadBackupList()
        {
            var backupList = _backupService.GetBackupList();

            dgvBackups.DataSource = backupList.Select(b => new
            {
                b.FileName,
                b.SizeDisplay,
                创建时间 = b.CreateTime.ToString("yyyy-MM-dd HH:mm:ss")
            }).ToList();
        }

        /// <summary>
        /// 手动备份按钮
        /// </summary>
        private async void btnManualBackup_Click(object sender, EventArgs e)
        {
            btnManualBackup.Enabled = false;
            lblStatus.Text = "正在备份...";

            var result = await _backupService.ExecuteBackupAsync();

            if (result.Success)
            {
                lblStatus.Text = $"备份成功: {Path.GetFileName(result.BackupFilePath)}";
                LoadBackupList(); // 刷新列表
            }
            else
            {
                lblStatus.Text = $"备份失败: {result.ErrorMessage}";
            }
            btnManualBackup.Enabled = true;
        }

        /// <summary>
        /// 数据恢复按钮
        /// </summary>
        private async void btnRestore_Click(object sender, EventArgs e)
        {
            // 确认操作
            var selectedRow = dgvBackups.SelectedRows[0];
            var fileName = selectedRow.Cells["FileName"].Value.ToString();
            var zipPath = Path.Combine(_backupService.GetBackupDirectory(), fileName);

            var confirmResult = MessageBox.Show(
                $"确定要从以下备份恢复数据库吗？\n\n备份文件: {fileName}\n\n注意：恢复操作将覆盖当前数据库！",
                "确认恢复",
                MessageBoxButtons.YesNo,
                MessageBoxIcon.Warning
            );

            if (confirmResult != DialogResult.Yes) return;

            // 1. 停止数据采集
            btnRestore.Enabled = false;
            lblStatus.Text = "正在停止数据采集...";

            // 通知主界面停止采集（通过事件或回调）
            DataCollectionStopped?.Invoke(this, EventArgs.Empty);
            await Task.Delay(2000); // 等待采集完全停止

            // 2. 执行恢复
            lblStatus.Text = "正在恢复数据...";
            var result = DataRestoreHelper.RestoreFromBackup(
                zipPath,
                _backupService.DatabasePath,
                backupCurrentDb: true  // 恢复前先备份当前数据库
            );

            // 3. 显示结果
            if (result.Success)
            {
                lblStatus.Text = "恢复成功！请重启数据采集。";
                MessageBox.Show(
                    $"数据恢复成功！\n恢复前备份已保存到: {result.PreRestoreBackupPath}",
                    "恢复成功",
                    MessageBoxButtons.OK,
                    MessageBoxIcon.Information
                );
            }
            else
            {
                lblStatus.Text = $"恢复失败: {result.ErrorMessage}";
                MessageBox.Show($"恢复失败: {result.ErrorMessage}", "恢复失败",
                    MessageBoxButtons.OK, MessageBoxIcon.Error);
            }

            btnRestore.Enabled = true;
        }

        /// <summary>数据采集停止后的事件</summary>
        public event EventHandler DataCollectionStopped;
    }
}
```

## 三、注意事项

### 3.1 备份注意事项

| 注意点 | 说明 |
|--------|------|
| **备份前验证磁盘空间** | 备份文件可能很大，需要确保有足够空间 |
| **备份前关闭写操作** | SQLite支持热备份，但建议在低负载时执行 |
| **备份文件压缩** | 使用ZIP压缩减小文件体积，节省存储空间 |
| **备份文件校验** | 备份完成后验证文件完整性 |
| **不要备份到同一磁盘** | 磁盘损坏时备份也会丢失，最好备份到其他磁盘或网络位置 |
| **记录备份日志** | 每次备份操作都应记录到日志文件 |

### 3.2 恢复注意事项

| 注意点 | 说明 |
|--------|------|
| **恢复前必须停止写入** | 确保没有进程在操作数据库文件 |
| **恢复前先备份当前数据** | 防止恢复失败后数据更糟糕 |
| **验证备份文件完整性** | 恢复前检查ZIP文件和数据库文件是否损坏 |
| **恢复后验证数据** | 恢复后打开数据库检查表结构和数据完整性 |
| **恢复前通知用户** | 恢复操作会覆盖当前数据，必须得到用户确认 |
| **恢复过程记录日志** | 详细记录恢复操作的过程和结果 |

### 3.3 SQLite备份特别注意事项

| 注意点 | 说明 |
|--------|------|
| **WAL模式备份** | 如果使用WAL模式，备份时需要同时复制.db和-wal文件 |
| **使用原生API备份** | SQLite的Backup API是最安全的备份方式 |
| **不要直接复制文件** | 在数据库运行时直接复制.db文件可能导致数据不一致 |
| **文件锁问题** | 备份时注意SQLite的文件锁，不要在备份过程中强行操作文件 |

## 四、实战案例

### 案例：自动备份SQLite数据库到指定目录

**完整场景描述：**
上位机系统使用SQLite数据库保存PLC采集数据和报警记录，需要实现以下功能：
1. 每天凌晨2点自动备份一次数据库
2. 手动备份功能（随时可以触发）
3. 备份文件保存为ZIP格式，包含时间戳
4. 自动清理超过7天的旧备份
5. 恢复功能（从备份文件恢复数据库）

**程序启动时初始化备份服务：**

```csharp
static class Program
{
    [STAThread]
    static void Main()
    {
        LogHelper.Init();

        try
        {
            // ... 其他初始化代码 ...

            // 初始化自动备份服务
            var dbPath = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "data\\plcdata.db");
            var backupConfig = new BackupConfig
            {
                DatabasePath = dbPath,
                BackupDirectory = "D:\\PlcBackup\\",  // 备份到D盘（与程序分开）
                IntervalMs = 24 * 60 * 60 * 1000,     // 每24小时备份一次
                KeepCount = 7                          // 保留7份备份
            };

            var backupService = new AutoBackupService(backupConfig);
            backupService.BackupCompleted += (s, r) =>
            {
                LogHelper.Info("自动备份完成: {File}, 大小: {Size}",
                    Path.GetFileName(r.BackupFilePath), FormatSize(r.FileSize));
            };
            backupService.BackupFailed += (s, err) =>
            {
                LogHelper.Error($"自动备份失败: {err}");
            };

            LogHelper.Info("自动备份服务已启动，备份间隔: {Interval}h，保留: {Keep}份",
                backupConfig.IntervalMs / 3600000, backupConfig.KeepCount);

            Application.Run(new MainForm());
        }
        catch (Exception ex)
        {
            LogHelper.Fatal(ex, "程序启动失败");
        }
        finally
        {
            Log.CloseAndFlush();
        }
    }
}
```
