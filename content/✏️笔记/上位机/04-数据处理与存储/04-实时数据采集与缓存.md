# 04 - 实时数据采集与缓存

---

## 一、知识讲解

### 1.1 环形缓冲区（Circular Buffer）实现

环形缓冲区（也称循环队列）是固定大小的先进先出（FIFO）数据结构。当缓冲区满时，新数据会覆盖最旧的数据。

#### 为什么上位机需要环形缓冲区

- **限流保护**：高频采集（如1000Hz）产生的数据量巨大，不能全部存入内存
- **固定内存**：内存占用固定，不会因运行时间增长而无限增长
- **保留最新**：始终保留最近N条数据，旧数据自动被覆盖
- **高效读写**：入队和出队都是O(1)时间复杂度

#### 环形缓冲区原理

```
固定大小为8的环形缓冲区：

初始状态（head=0, tail=0, count=0）：
[ ] [ ] [ ] [ ] [ ] [ ] [ ] [ ]

写入5个元素后（head=0, tail=5, count=5）：
[A][B][C][D][E][ ] [ ] [ ]

继续写入到满（head=0, tail=0, count=8）：
[A][B][C][D][E][F][G][H]   ← 已满

再写入1个（head=1, tail=1, count=8，A被覆盖）：
[I][B][C][D][E][F][G][H]
  ↑head(读)          ↑tail(写)
```

### 1.2 ConcurrentQueue 线程安全队列

`System.Collections.Concurrent.ConcurrentQueue<T>` 是 .NET 提供的线程安全队列，支持多线程环境下的安全入队和出队操作。

#### ConcurrentQueue vs Queue

| 特性 | Queue | ConcurrentQueue |
|------|-------|-----------------|
| 线程安全 | 否（需手动加锁） | 是 |
| 性能 | 单线程更快 | 多线程更快 |
| 使用场景 | 单线程操作 | 多线程（生产者-消费者） |
| 大小限制 | 无（动态增长） | 无（动态增长） |

### 1.3 生产者-消费者模式

上位机数据采集中的经典模式：

```
生产者线程（采集）            消费者线程（处理/存储）
    │                              │
    │── 采集PLC数据 ──> Queue ──>── │
    │── 采集PLC数据 ──> Queue ──>── │  从队列取出数据
    │── 采集PLC数据 ──> Queue ──>── │  写入数据库/更新UI
    │                              │
    │（高速采集）              （相对较慢的处理）│
```

**优势**：
- 采集线程不会被存储/显示操作阻塞
- 处理线程按自己的节奏消费数据
- 队列作为缓冲，平衡生产和消费的速度差异

### 1.4 数据压缩与降采样

当数据量极大时（如1000Hz持续采集数天），需要压缩或降采样以减少存储量。

#### 降采样策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 固定间隔采样 | 每N条数据保留1条 | 数据变化平缓 |
| 最大-最小-平均 | 每段取最大值、最小值、平均值 | 趋势分析、报表 |
| 变化检测 | 只在数据变化超过阈值时保存 | 数据变化不频繁 |
| 时间窗口聚合 | 每分钟/每小时取统计值 | 长期历史数据 |

### 2.1 环形缓冲区实现

```csharp
using System;
using System.Collections.Generic;

/// <summary>
/// 泛型环形缓冲区（循环队列）实现
/// 固定大小，满时自动覆盖最旧的数据
/// 线程安全版本（加锁）
/// </summary>
public class CircularBuffer<T>
{
    private readonly T[] _buffer;     // 底层数组
    private readonly int _capacity;  // 缓冲区容量
    private int _head;               // 读指针（最旧数据的位置）
    private int _count;              // 当前元素数量
    private readonly object _lock = new object();

    /// <summary>缓冲区容量</summary>
    public int Capacity => _capacity;

    /// <summary>当前元素数量</summary>
    public int Count
    {
        get { lock (_lock) { return _count; } }
    }

    /// <summary>是否为空</summary>
    public bool IsEmpty => Count == 0;

    /// <summary>是否已满</summary>
    public bool IsFull => Count == _capacity;

    /// <summary>
    /// 创建环形缓冲区
    /// </summary>
    /// <param name="capacity">最大容量（必须 > 0）</param>
    public CircularBuffer(int capacity)
    {
        if (capacity <= 0)
            throw new ArgumentException("容量必须大于0", nameof(capacity));

        _capacity = capacity;
        _buffer = new T[capacity];
        _head = 0;
        _count = 0;
    }

    /// <summary>
    /// 写入一个元素
    /// 如果缓冲区已满，自动覆盖最旧的元素
    /// </summary>
    public void Write(T item)
    {
        lock (_lock)
        {
            // 计算写入位置
            int tail = (_head + _count) % _capacity;

            _buffer[tail] = item;

            if (_count < _capacity)
            {
                _count++;  // 未满，计数+1
            }
            else
            {
                _head = (_head + 1) % _capacity;  // 已满，移动读指针（丢弃最旧数据）
            }
        }
    }

    /// <summary>
    /// 批量写入多个元素
    /// </summary>
    public void WriteRange(T[] items)
    {
        if (items == null || items.Length == 0) return;

        lock (_lock)
        {
            foreach (var item in items)
            {
                int tail = (_head + _count) % _capacity;
                _buffer[tail] = item;

                if (_count < _capacity)
                    _count++;
                else
                    _head = (_head + 1) % _capacity;
            }
        }
    }

    /// <summary>
    /// 读取最新写入的一个元素（不移除）
    /// </summary>
    public T PeekLatest()
    {
        lock (_lock)
        {
            if (_count == 0)
                throw new InvalidOperationException("缓冲区为空");

            int tail = (_head + _count - 1) % _capacity;
            return _buffer[tail];
        }
    }

    /// <summary>
    /// 读取并移除最旧的一个元素
    /// </summary>
    public T Read()
    {
        lock (_lock)
        {
            if (_count == 0)
                throw new InvalidOperationException("缓冲区为空");

            T item = _buffer[_head];
            _buffer[_head] = default;  // 清除引用（帮助GC）
            _head = (_head + 1) % _capacity;
            _count--;
            return item;
        }
    }

    /// <summary>
    /// 读取所有元素（不移除，按时间顺序从旧到新）
    /// </summary>
    public T[] ReadAll()
    {
        lock (_lock)
        {
            T[] result = new T[_count];
            for (int i = 0; i < _count; i++)
            {
                result[i] = _buffer[(_head + i) % _capacity];
            }
            return result;
        }
    }

    /// <summary>
    /// 读取最近N条数据（不移除）
    /// </summary>
    public T[] ReadLatest(int count)
    {
        lock (_lock)
        {
            int actualCount = Math.Min(count, _count);
            T[] result = new T[actualCount];

            for (int i = 0; i < actualCount; i++)
            {
                int idx = (_head + _count - actualCount + i) % _capacity;
                result[i] = _buffer[idx];
            }
            return result;
        }
    }

    /// <summary>
    /// 清空缓冲区
    /// </summary>
    public void Clear()
    {
        lock (_lock)
        {
            Array.Clear(_buffer, 0, _capacity);
            _head = 0;
            _count = 0;
        }
    }

    /// <summary>
    /// 尝试读取（不抛异常）
    /// </summary>
    public bool TryRead(out T item)
    {
        lock (_lock)
        {
            if (_count == 0)
            {
                item = default;
                return false;
            }

            item = _buffer[_head];
            _buffer[_head] = default;
            _head = (_head + 1) % _capacity;
            _count--;
            return true;
        }
    }
}
```

### 2.2 ConcurrentQueue 线程安全队列

```csharp
using System;
using System.Collections.Concurrent;
using System.Threading;
using System.Threading.Tasks;

/// <summary>
/// ConcurrentQueue 基本使用示例
/// 多线程安全的生产者-消费者模式
/// </summary>
public class ConcurrentQueueExample
{
    private ConcurrentQueue<double> _dataQueue = new ConcurrentQueue<double>();
    private volatile bool _isRunning;

    /// <summary>
    /// 启动生产者和消费者
    /// </summary>
    public void Run()
    {
        _isRunning = true;

        // 启动生产者线程（模拟PLC数据采集）
        Task.Run(() => Producer());

        // 启动消费者线程（数据处理/存储）
        Task.Run(() => Consumer());

        Console.WriteLine("按任意键停止...");
        Console.ReadKey();
        _isRunning = false;
    }

    /// <summary>
    /// 生产者：模拟高频数据采集
    /// </summary>
    private void Producer()
    {
        var random = new Random();
        int count = 0;

        while (_isRunning)
        {
            // 模拟采集到的PLC数据
            double value = 25.0 + (random.NextDouble() - 0.5) * 10;

            // 线程安全地入队
            _dataQueue.Enqueue(value);
            count++;

            // 模拟1000Hz采集频率
            Thread.Sleep(1);

            // 如果队列过长，说明消费跟不上，丢弃旧数据
            if (_dataQueue.Count > 10000)
            {
                _dataQueue.TryDequeue(out _);
                Console.WriteLine($"[警告] 队列过长({_dataQueue.Count})，丢弃旧数据");
            }
        }

        Console.WriteLine($"生产者停止，共生产 {count} 条数据");
    }

    /// <summary>
    /// 消费者：处理并存储数据
    /// </summary>
    private void Consumer()
    {
        int processedCount = 0;

        while (_isRunning || !_dataQueue.IsEmpty)
        {
            // 尝试取出数据
            if (_dataQueue.TryDequeue(out double value))
            {
                // 处理数据（如写入数据库、更新UI）
                processedCount++;

                // 模拟处理耗时（每100条输出一次）
                if (processedCount % 100 == 0)
                {
                    Console.WriteLine($"已处理 {processedCount} 条, " +
                        $"当前值: {value:F2}, 队列长度: {_dataQueue.Count}");
                }

                // 模拟处理耗时（比采集慢，所以队列会积压）
                Thread.Sleep(2);
            }
            else
            {
                // 队列为空，短暂等待
                Thread.Sleep(10);
            }
        }

        Console.WriteLine($"消费者停止，共处理 {processedCount} 条数据");
    }
}
```

### 2.3 生产者-消费者模式（完整封装）

```csharp
using System;
using System.Collections.Concurrent;
using System.Threading;
using System.Threading.Tasks;

/// <summary>
/// 生产者-消费者数据管道
/// 采集线程（生产者）将数据写入队列
/// 存储线程（消费者）从队列取出并写入数据库
/// 支持背压控制（队列过长时自动丢弃）
/// </summary>
public class DataPipeline : IDisposable
{
    // ========== 数据结构 ==========
    private ConcurrentQueue<DataPoint> _queue = new ConcurrentQueue<DataPoint>();
    private volatile bool _isRunning;
    private Task _consumerTask;

    // ========== 配置 ==========
    public int MaxQueueSize { get; set; } = 50000;    // 队列最大长度
    public int BatchSize { get; set; } = 100;          // 每批写入数量
    public int BatchIntervalMs { get; set; } = 1000;   // 批量写入间隔

    // ========== 事件 ==========
    public event Action<string> OnLog;
    public event Action<int> OnQueueOverflow;           // 队列溢出事件
    public event Action<long> OnDataStored;             // 数据已存储事件
    public event Action<DataPoint> OnDataReceived;      // 数据接收事件

    // ========== 统计 ==========
    private long _totalProduced;
    private long _totalConsumed;
    private long _totalDropped;

    /// <summary>当前队列长度</summary>
    public int QueueCount => _queue.Count;

    /// <summary>总生产量</summary>
    public long TotalProduced => Interlocked.Read(ref _totalProduced);

    /// <summary>总消费量</summary>
    public long TotalConsumed => Interlocked.Read(ref _totalConsumed);

    /// <summary>总丢弃量</summary>
    public long TotalDropped => Interlocked.Read(ref _totalDropped);

    /// <summary>
    /// 数据点结构
    /// </summary>
    public class DataPoint
    {
        public string DeviceId { get; set; }
        public string TagName { get; set; }
        public double Value { get; set; }
        public int Quality { get; set; }
        public DateTime Timestamp { get; set; }
    }

    /// <summary>
    /// 启动数据管道
    /// </summary>
    public void Start()
    {
        _isRunning = true;
        _consumerTask = Task.Run(ConsumerLoop);
        Log("数据管道已启动");
    }

    /// <summary>
    /// 停止数据管道
    /// </summary>
    public async Task StopAsync()
    {
        _isRunning = false;
        if (_consumerTask != null)
        {
            await _consumerTask;
        }
        Log("数据管道已停止");
    }

    /// <summary>
    /// 生产者：写入数据点
    /// </summary>
    public void Enqueue(DataPoint data)
    {
        if (!_isRunning) return;

        // 背压控制：队列过长时丢弃旧数据
        while (_queue.Count >= MaxQueueSize)
        {
            _queue.TryDequeue(out _);
            Interlocked.Increment(ref _totalDropped);
        }

        _queue.Enqueue(data);
        Interlocked.Increment(ref _totalProduced);
        OnDataReceived?.Invoke(data);
    }

    /// <summary>
    /// 批量写入
    /// </summary>
    public void EnqueueRange(DataPoint[] dataPoints)
    {
        foreach (var dp in dataPoints)
        {
            Enqueue(dp);
        }
    }

    /// <summary>
    /// 消费者循环：批量取出数据并处理
    /// </summary>
    private void ConsumerLoop()
    {
        var batch = new DataPoint[BatchSize];
        var timer = DateTime.UtcNow;

        while (_isRunning || !_queue.IsEmpty)
        {
            // 批量取出数据
            int batchCount = 0;
            while (batchCount < BatchSize && _queue.TryDequeue(out var item))
            {
                batch[batchCount++] = item;
                Interlocked.Increment(ref _totalConsumed);
            }

            // 如果有数据，处理
            if (batchCount > 0)
            {
                ProcessBatch(batch, batchCount);
            }

            // 如果队列为空且未停止，短暂等待
            if (_queue.IsEmpty && _isRunning)
            {
                Thread.Sleep(50);
            }
        }
    }

    /// <summary>
    /// 处理一批数据（实际项目中写入数据库）
    /// </summary>
    private void ProcessBatch(DataPoint[] batch, int count)
    {
        try
        {
            // 这里执行实际的存储操作
            // 例如：使用Dapper批量写入SQLite
            /*
            using var conn = new SqliteConnection(connString);
            conn.Execute(@"
                INSERT INTO plc_data (DeviceId, TagName, Value, Quality, Timestamp)
                VALUES (@DeviceId, @TagName, @Value, @Quality, @Timestamp)",
                batch.Take(count));
            */

            OnDataStored?.Invoke(count);
        }
        catch (Exception ex)
        {
            Log($"批量存储失败: {ex.Message}");
        }
    }

    private void Log(string msg) => OnLog?.Invoke(msg);

    public void Dispose()
    {
        _isRunning = false;
    }
}
```

### 2.4 数据压缩与降采样

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

/// <summary>
/// 数据降采样工具类
/// 用于减少存储数据量，同时保留数据的关键特征
/// </summary>
public class DataDownsampler
{
    /// <summary>
    /// 策略1：固定间隔采样
    /// 每N条数据保留1条
    /// 适合：数据变化平缓的场景
    /// </summary>
    public static List<(DateTime Time, double Value)> FixedIntervalSample(
        List<(DateTime Time, double Value)> data, int interval)
    {
        if (data == null || data.Count == 0) return new List<(DateTime, double)>();

        var result = new List<(DateTime, double)>();
        for (int i = 0; i < data.Count; i += interval)
        {
            result.Add(data[i]);
        }
        return result;
    }

    /// <summary>
    /// 策略2：最大-最小-平均降采样（LTTB简化版）
    /// 每段数据保留最大值、最小值和平均值
    /// 适合：趋势图显示、报表统计
    /// </summary>
    public static List<(DateTime Time, double Max, double Min, double Avg)>
        MinMaxAvgDownsample(
        List<(DateTime Time, double Value)> data, int pointsPerSegment)
    {
        if (data == null || data.Count == 0)
            return new List<(DateTime, double, double, double)>();

        var result = new List<(DateTime Time, double Max, double Min, double Avg)>();
        int totalSegments = (data.Count + pointsPerSegment - 1) / pointsPerSegment;

        for (int seg = 0; seg < totalSegments; seg++)
        {
            int start = seg * pointsPerSegment;
            int end = Math.Min(start + pointsPerSegment, data.Count);

            double max = double.MinValue;
            double min = double.MaxValue;
            double sum = 0;
            DateTime segmentTime = data[start].Time;

            for (int i = start; i < end; i++)
            {
                if (data[i].Value > max) max = data[i].Value;
                if (data[i].Value < min) min = data[i].Value;
                sum += data[i].Value;
            }

            double avg = sum / (end - start);
            result.Add((segmentTime, max, min, avg));
        }

        return result;
    }

    /// <summary>
    /// 策略3：基于变化检测的压缩
    /// 只在数据变化超过阈值时保留
    /// 适合：数据大部分时间不变，偶尔变化的场景
    /// </summary>
    public static List<(DateTime Time, double Value)>
        ChangeDetectionCompress(
        List<(DateTime Time, double Value)> data, double threshold)
    {
        if (data == null || data.Count == 0)
            return new List<(DateTime, double)>();

        var result = new List<(DateTime, double)>();
        result.Add(data[0]);  // 保留第一个点

        double lastValue = data[0].Value;

        for (int i = 1; i < data.Count; i++)
        {
            if (Math.Abs(data[i].Value - lastValue) >= threshold)
            {
                result.Add(data[i]);
                lastValue = data[i].Value;
            }
        }

        // 确保保留最后一个点
        if (result.Count > 0 && result.Last().Time != data.Last().Time)
        {
            result.Add(data.Last());
        }

        return result;
    }

    /// <summary>
    /// 策略4：时间窗口聚合
    /// 将数据按固定时间窗口聚合为统计值
    /// 适合：将高频数据降为分钟级/小时级数据
    /// </summary>
    public static List<(DateTime WindowStart, double Avg, double Max, double Min, int Count)>
        TimeWindowAggregate(
        List<(DateTime Time, double Value)> data, TimeSpan windowSize)
    {
        if (data == null || data.Count == 0)
            return new List<(DateTime, double, double, double, int)>();

        var result = new List<(DateTime, double, double, double, int)>();

        // 按窗口分组
        var groups = data.GroupBy(d =>
        {
            // 计算该数据点属于哪个时间窗口
            long ticks = d.Time.Ticks / windowSize.Ticks;
            return new DateTime(ticks * windowSize.Ticks);
        });

        foreach (var group in groups.OrderBy(g => g.Key))
        {
            var values = group.Select(g => g.Value).ToList();
            result.Add((
                group.Key,
                values.Average(),
                values.Max(),
                values.Min(),
                values.Count
            ));
        }

        return result;
    }
}
```

### 2.5 上位机场景案例：高频率 PLC 数据采集与缓存

```csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.Linq;
using System.Threading;
using System.Threading.Tasks;
using Dapper;
using Microsoft.Data.Sqlite;

/// <summary>
/// 上位机高频数据采集完整案例
/// 场景：以1000Hz频率采集PLC数据，使用环形缓冲区+生产者消费者模式
/// 特点：
///   1. 采集线程不受存储影响（零阻塞采集）
///   2. 环形缓冲区保留最近10000条实时数据（用于界面显示）
///   3. 生产者消费者管道负责异步存储
///   4. 降采样保存历史趋势数据
///   5. 完善的统计和监控
/// </summary>
public class HighFrequencyDataCollector : IDisposable
{
    // ========== 核心组件 ==========
    private CircularBuffer<CollectedData> _realtimeBuffer;  // 实时数据缓冲区（供UI显示）
    private ConcurrentQueue<CollectedData> _storageQueue; // 存储队列（供数据库写入）
    private Timer _collectionTimer;                         // 采集定时器
    private Task _storageTask;                               // 存储任务
    private Timer _statsTimer;                               // 统计定时器
    private volatile bool _isRunning;

    // ========== 配置 ==========
    public int BufferSize { get; set; } = 10000;       // 环形缓冲区大小
    public int MaxQueueSize { get; set; } = 100000;     // 存储队列最大长度
    public int StorageBatchSize { get; set; } = 500;     // 每批存储数量
    public int CollectionIntervalMs { get; set; } = 10;  // 采集间隔（10ms = 100Hz）
    public string DbPath { get; set; } = "highfreq_data.db";

    // ========== 事件 ==========
    public event Action<CollectedData> OnNewData;         // 新数据事件（供UI实时显示）
    public event Action<string> OnLog;
    public event Action<CollectorStats> OnStatsUpdated;

    // ========== 统计 ==========
    private long _totalCollected;
    private long _totalStored;
    private long _totalDropped;
    private int _collectionRate;                           // 实际采集速率（次/秒）

    /// <summary>
    /// 采集到的数据结构
    /// </summary>
    public class CollectedData
    {
        public DateTime Timestamp { get; set; }
        public double Temperature { get; set; }
        public double Pressure { get; set; }
        public double FlowRate { get; set; }
        public double MotorSpeed { get; set; }
    }

    /// <summary>
    /// 采集器统计信息
    /// </summary>
    public class CollectorStats
    {
        public long TotalCollected { get; set; }
        public long TotalStored { get; set; }
        public long TotalDropped { get; set; }
        public int BufferCount { get; set; }
        public int QueueCount { get; set; }
        public int CollectionRate { get; set; }
        public double DropRate { get; set; }  // 丢弃率(%)
    }

    /// <summary>
    /// 初始化数据库
    /// </summary>
    public void Initialize()
    {
        // 创建环形缓冲区
        _realtimeBuffer = new CircularBuffer<CollectedData>(BufferSize);

        // 创建存储队列
        _storageQueue = new ConcurrentQueue<CollectedData>();

        // 初始化数据库
        using var conn = new SqliteConnection($"Data Source={DbPath}");
        conn.Open();
        conn.Execute(@"
            CREATE TABLE IF NOT EXISTS realtime_data (
                Id INTEGER PRIMARY KEY AUTOINCREMENT,
                Timestamp TEXT NOT NULL,
                Temperature REAL,
                Pressure REAL,
                FlowRate REAL,
                MotorSpeed REAL
            );
            CREATE INDEX IF NOT EXISTS idx_realtime_ts ON realtime_data(Timestamp);
        ");

        Log($"初始化完成: 缓冲区={BufferSize}, 队列上限={MaxQueueSize}, " +
            $"采集间隔={CollectionIntervalMs}ms");
    }

    /// <summary>
    /// 启动采集
    /// </summary>
    public void Start()
    {
        _isRunning = true;

        // 启动采集定时器
        _collectionTimer = new Timer(OnCollectionTick, null, 0, CollectionIntervalMs);

        // 启动存储任务
        _storageTask = Task.Run(StorageLoop);

        // 启动统计定时器
        var sw = new Stopwatch();
        sw.Start();
        long lastCount = 0;
        _statsTimer = new Timer(_ =>
        {
            long currentCount = _totalCollected;
            _collectionRate = (int)((currentCount - lastCount) * 1000 / sw.ElapsedMilliseconds);
            lastCount = currentCount;
            sw.Restart();

            OnStatsUpdated?.Invoke(new CollectorStats
            {
                TotalCollected = _totalCollected,
                TotalStored = _totalStored,
                TotalDropped = _totalDropped,
                BufferCount = _realtimeBuffer.Count,
                QueueCount = _storageQueue.Count,
                CollectionRate = _collectionRate,
                DropRate = _totalCollected > 0
                    ? (double)_totalDropped / _totalCollected * 100
                    : 0
            });
        }, null, 1000, 1000);

        Log("采集已启动");
    }

    /// <summary>
    /// 停止采集
    /// </summary>
    public async Task StopAsync()
    {
        _isRunning = false;
        _collectionTimer?.Dispose();
        _statsTimer?.Dispose();

        if (_storageTask != null)
            await _storageTask;

        Log("采集已停止");
    }

    /// <summary>
    /// 采集回调（定时器触发）
    /// 模拟PLC数据读取（实际项目中替换为Modbus/OPC UA通信）
    /// </summary>
    private void OnCollectionTick(object state)
    {
        try
        {
            // 模拟采集（实际替换为真实PLC读取）
            var data = new CollectedData
            {
                Timestamp = DateTime.Now,
                Temperature = 25.0 + new Random().NextDouble() * 10,
                Pressure = 1.5 + new Random().NextDouble() * 0.5,
                FlowRate = 100 + new Random().NextDouble() * 50,
                MotorSpeed = 1500 + new Random().NextDouble() * 200
            };

            // 写入环形缓冲区（供实时显示）
            _realtimeBuffer.Write(data);

            // 写入存储队列（供数据库存储）
            // 背压控制
            while (_storageQueue.Count >= MaxQueueSize)
            {
                _storageQueue.TryDequeue(out _);
                Interlocked.Increment(ref _totalDropped);
            }
            _storageQueue.Enqueue(data);

            Interlocked.Increment(ref _totalCollected);
            OnNewData?.Invoke(data);
        }
        catch (Exception ex)
        {
            Log($"采集异常: {ex.Message}");
        }
    }

    /// <summary>
    /// 存储循环（消费者）
    /// 批量从队列取出数据，写入数据库
    /// </summary>
    private void StorageLoop()
    {
        var batch = new CollectedData[StorageBatchSize];

        while (_isRunning || !_storageQueue.IsEmpty)
        {
            int batchCount = 0;

            // 批量取出
            while (batchCount < StorageBatchSize &&
                   _storageQueue.TryDequeue(out var item))
            {
                batch[batchCount++] = item;
            }

            if (batchCount > 0)
            {
                try
                {
                    // 批量写入数据库
                    using var conn = new SqliteConnection($"Data Source={DbPath}");
                    conn.Open();
                    using var tx = conn.BeginTransaction();

                    for (int i = 0; i < batchCount; i++)
                    {
                        conn.Execute(@"
                            INSERT INTO realtime_data
                            (Timestamp, Temperature, Pressure, FlowRate, MotorSpeed)
                            VALUES (@Timestamp, @Temperature, @Pressure, @FlowRate, @MotorSpeed)",
                            batch[i], tx);
                    }

                    tx.Commit();
                    Interlocked.Add(ref _totalStored, batchCount);
                }
                catch (Exception ex)
                {
                    Log($"存储失败: {ex.Message}");
                }
            }
            else if (_isRunning)
            {
                Thread.Sleep(100);  // 队列空时短暂等待
            }
        }
    }

    /// <summary>
    /// 获取最新的N条实时数据（供UI图表显示）
    /// </summary>
    public CollectedData[] GetLatestData(int count = 100)
    {
        return _realtimeBuffer.ReadLatest(count);
    }

    private void Log(string msg) => OnLog?.Invoke(msg);

    public void Dispose()
    {
        _collectionTimer?.Dispose();
        _statsTimer?.Dispose();
    }
}
```

## 三、注意事项

1. **线程安全优先**：多线程环境下使用 `ConcurrentQueue` 或 `lock` 保护共享数据结构，避免竞态条件。
2. **背压控制**：当消费速度跟不上生产速度时，必须有限流机制（丢弃旧数据、阻塞生产者或降低采集频率），否则内存会无限增长。
3. **GC压力**：高频采集产生大量短生命周期对象，会增加GC压力。考虑使用对象池（`ArrayPool<T>`）或预分配数组。
4. **环形缓冲区大小**：设置合理的缓冲区大小。太小会丢失数据，太大浪费内存。通常设为几秒到几十秒的数据量。
5. **数据库批量写入**：SQLite单次事务有语句数量限制，建议每批200-500条，不要一次写太多。
6. **异常隔离**：采集线程、存储线程的异常不应互相影响。每个线程独立捕获和处理异常。

## 五、常见错误

### 错误1：内存持续增长
```
现象：程序运行时间越长，内存占用越大
```
**原因**：使用了普通Queue或List存储数据，没有大小限制。
**解决**：使用环形缓冲区（固定大小）或设置队列最大长度并定期清理。

### 错误2：数据丢失
```
现象：采集到的数据没有全部存储到数据库
```
**原因**：存储速度跟不上采集速度，队列溢出时数据被丢弃。
**解决**：增大BatchSize、使用WAL模式SQLite、降低采集频率或接受部分丢弃。

### 错误3：竞态条件导致数据错乱
```
现象：数据出现莫名其妙的错误值
```
**原因**：多线程访问共享数据结构时没有加锁。
**解决**：使用线程安全的集合（`ConcurrentQueue`）或使用 `lock` 保护临界区。

### 错误4：UI卡顿
```
现象：高频更新UI时界面卡死
```
**原因**：采集线程直接更新UI控件，或者每次更新都传递大量数据。
**解决**：使用 `Invoke` 更新UI；降采样后再显示；限制UI更新频率（如每200ms更新一次）。

### 错误5：SQLite database is locked
```
原因：SQLite同一时刻只允许一个写入者
```
**解决**：确保所有写入操作在同一个线程/事务中；启用WAL模式；使用批量写入减少事务次数。

### 错误6：程序退出时数据丢失
```
原因：队列中还有未存储的数据，程序直接退出了
```
**解决**：在程序退出前先停止采集，等待存储线程处理完队列中的所有数据，然后再退出。使用 `await StopAsync()` 而非直接终止。
