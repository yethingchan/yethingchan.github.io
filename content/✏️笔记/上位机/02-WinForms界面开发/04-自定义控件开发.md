## 1. UserControl 用户控件

### 知识讲解

`UserControl` 是 WinForms 中创建自定义复合控件的标准方式。它继承自 `ContainerControl`，可以像设计普通窗体一样在 UserControl 中放置多个内置控件，然后将整个 UserControl 当作一个可复用的控件使用。

**创建步骤：**

1. 在 Visual Studio 中，右键项目 →「添加」→「新建项」
2. 选择「用户控件」模板
3. 命名（如 `PlcStatusPanel.cs`）
4. 在设计器中拖拽子控件、设置属性、编写事件处理

**UserControl vs 自定义控件（继承 Control）对比：**

| 特性 | UserControl | 自定义控件（继承 Control） |
|------|-------------|------------------------|
| 开发方式 | 设计器拖拽 | 纯代码绘制（OnPaint） |
| 组成 | 组合多个内置控件 | 从零绘制 |
| 性能 | 一般（子控件较多时） | 更好（单一绘制） |
| 适用场景 | 复合功能面板、表单区域 | 仪表盘、LED灯、图表等 |

### 代码示例

```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

namespace PlcMonitorApp.Controls
{
    /// <summary>
    /// PLC 设备状态面板 —— UserControl 示例
    /// 综合展示一个 PLC 设备的关键状态信息
    /// 场景：上位机中每台 PLC 设备的状态卡片
    /// </summary>
    public partial class PlcStatusPanel : UserControl
    {
        #region ===== 自定义属性 =====

        /// <summary>设备名称</summary>
        public string DeviceName
        {
            get => lblDeviceName.Text;
            set => lblDeviceName.Text = value;
        }

        /// <summary>设备 IP 地址</summary>
        public string IpAddress
        {
            get => lblIp.Text;
            set => lblIp.Text = value;
        }

        /// <summary>是否在线</summary>
        public bool IsOnline
        {
            get => _isOnline;
            set
            {
                _isOnline = value;
                UpdateOnlineStatus();
            }
        }
        private bool _isOnline;

        /// <summary>温度值</summary>
        public double Temperature
        {
            get => _temperature;
            set
            {
                _temperature = value;
                lblTempValue.Text = $"{value:F1}°C";
                UpdateTemperatureColor();
            }
        }
        private double _temperature;

        /// <summary>压力值</summary>
        public double Pressure
        {
            get => _pressure;
            set
            {
                _pressure = value;
                lblPressureValue.Text = $"{value:F1} MPa";
            }
        }
        private double _pressure;

        /// <summary>报警数量</summary>
        public int AlarmCount
        {
            get => _alarmCount;
            set
            {
                _alarmCount = value;
                lblAlarmCount.Text = value.ToString();
                lblAlarmCount.ForeColor = value > 0 ? Color.Red : Color.Green;
            }
        }
        private int _alarmCount;

        #endregion

        #region ===== 自定义事件 =====

        /// <summary>
        /// 用户点击此面板时触发的事件
        /// </summary>
        public event EventHandler PanelClicked;

        /// <summary>
        /// 用户请求查看详情时触发的事件
        /// </summary>
        public event EventHandler DetailRequested;

        #endregion

        #region ===== 子控件声明 =====

        private Label lblDeviceName;
        private Label lblIp;
        private Panel picStatusLed;
        private Label lblStatusText;
        private Label lblTempValue;
        private Label lblPressureValue;
        private Label lblAlarmCount;
        private Button btnDetail;

        #endregion

        public PlcStatusPanel()
        {
            InitializeComponent();
            InitializeCustomControls();
        }

        private void InitializeComponent()
        {
            this.SuspendLayout();

            // 面板基本设置
            this.Size = new Size(280, 140);
            this.BackColor = Color.White;
            this.BorderStyle = BorderStyle.FixedSingle;
            this.Padding = new Padding(10);
            this.Cursor = Cursors.Hand;  // 鼠标移入时显示手型

            this.ResumeLayout(true);
        }

        /// <summary>
        /// 初始化子控件布局
        /// </summary>
        private void InitializeCustomControls()
        {
            // ====== 顶部区域：设备名称 + 状态 ======
            // 状态 LED 指示灯
            picStatusLed = new Panel
            {
                Size = new Size(12, 12),
                Location = new Point(15, 12),
                BackColor = Color.Green
            };

            // 设备名称
            lblDeviceName = new Label
            {
                Text = "1#PLC - 主站",
                Location = new Point(35, 8),
                AutoSize = true,
                Font = new Font("微软雅黑", 10, FontStyle.Bold),
                ForeColor = Color.FromArgb(50, 50, 50)
            };

            // 状态文字
            lblStatusText = new Label
            {
                Text = "在线",
                Location = new Point(35, 28),
                AutoSize = true,
                Font = new Font("微软雅黑", 8),
                ForeColor = Color.Green
            };

            // IP 地址
            lblIp = new Label
            {
                Text = "192.168.1.10",
                Location = new Point(140, 28),
                AutoSize = true,
                Font = new Font("Consolas", 8),
                ForeColor = Color.Gray
            };

            // ====== 中部区域：数据展示 ======
            // 使用 TableLayoutPanel 对齐数据
            var dataTable = new TableLayoutPanel
            {
                Location = new Point(15, 55),
                Size = new Size(250, 50),
                ColumnCount = 3,
                RowCount = 2,
                CellBorderStyle = TableLayoutPanelCellBorderStyle.None
            };
            dataTable.ColumnStyles.Add(new ColumnStyle(SizeType.AutoSize));
            dataTable.ColumnStyles.Add(new ColumnStyle(SizeType.Percent, 100F));
            dataTable.ColumnStyles.Add(new ColumnStyle(SizeType.AutoSize));
            dataTable.RowStyles.Add(new RowStyle(SizeType.Percent, 50F));
            dataTable.RowStyles.Add(new RowStyle(SizeType.Percent, 50F));

            // 温度
            var lblTempLabel = new Label { Text = "温度：", Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleRight, Font = new Font("微软雅黑", 8), ForeColor = Color.Gray };
            lblTempValue = new Label { Text = "0.0°C", Dock = DockStyle.Fill, Font = new Font("Consolas", 10, FontStyle.Bold), ForeColor = Color.FromArgb(0, 120, 215) };
            var lblTempUnit = new Label { Text = "", Dock = DockStyle.Fill };

            // 压力
            var lblPressureLabel = new Label { Text = "压力：", Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleRight, Font = new Font("微软雅黑", 8), ForeColor = Color.Gray };
            lblPressureValue = new Label { Text = "0.0 MPa", Dock = DockStyle.Fill, Font = new Font("Consolas", 10, FontStyle.Bold), ForeColor = Color.FromArgb(0, 120, 215) };

            // 报警数
            var lblAlarmLabel = new Label { Text = "报警：", Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleRight, Font = new Font("微软雅黑", 8), ForeColor = Color.Gray };
            lblAlarmCount = new Label { Text = "0", Dock = DockStyle.Fill, Font = new Font("Consolas", 10, FontStyle.Bold), ForeColor = Color.Green };

            dataTable.Controls.Add(lblTempLabel, 0, 0);
            dataTable.Controls.Add(lblTempValue, 1, 0);
            dataTable.Controls.Add(lblPressureLabel, 0, 1);
            dataTable.Controls.Add(lblPressureValue, 1, 1);
            dataTable.Controls.Add(lblAlarmLabel, 2, 0);
            dataTable.Controls.Add(lblAlarmCount, 2, 1);

            // ====== 底部：详情按钮 ======
            btnDetail = new Button
            {
                Text = "查看详情",
                Location = new Point(170, 110),
                Size = new Size(90, 25),
                FlatStyle = FlatStyle.Flat,
                BackColor = Color.FromArgb(230, 230, 230),
                Font = new Font("微软雅黑", 8)
            };

            // ====== 添加所有控件 ======
            this.Controls.AddRange(new Control[]
            {
                picStatusLed, lblDeviceName, lblStatusText, lblIp,
                dataTable, btnDetail
            });

            // ====== 事件绑定 ======
            btnDetail.Click += (s, e) => DetailRequested?.Invoke(this, EventArgs.Empty);
            this.Click += (s, e) => PanelClicked?.Invoke(this, EventArgs.Empty);

            // 鼠标悬停效果
            this.MouseEnter += (s, e) =>
            {
                if (!IsOnline)
                    this.BackColor = Color.FromArgb(255, 250, 245);
                else
                    this.BackColor = Color.FromArgb(240, 248, 255);
            };
            this.MouseLeave += (s, e) =>
            {
                this.BackColor = Color.White;
            };
        }

        #region ===== 私有方法 =====

        /// <summary>
        /// 更新在线状态显示
        /// </summary>
        private void UpdateOnlineStatus()
        {
            if (_isOnline)
            {
                picStatusLed.BackColor = Color.Green;
                lblStatusText.Text = "在线";
                lblStatusText.ForeColor = Color.Green;
            }
            else
            {
                picStatusLed.BackColor = Color.Red;
                lblStatusText.Text = "离线";
                lblStatusText.ForeColor = Color.Red;
            }
        }

        /// <summary>
        /// 根据温度更新颜色
        /// </summary>
        private void UpdateTemperatureColor()
        {
            lblTempValue.ForeColor = _temperature < 30 ? Color.Green :
                                       _temperature < 60 ? Color.Orange : Color.Red;
        }

        #endregion
    }
}
```

### 注意事项

- **自定义属性**：通过 C# 属性暴露关键数据，外部使用时可以像普通控件属性一样在属性窗口或代码中设置。
- **自定义事件**：使用 `event EventHandler` 定义事件，在控件内部通过 `?.Invoke()` 触发，外部通过 `+=` 订阅。
- **Dock 布局**：在 UserControl 内部使用 Dock 和 TableLayoutPanel 实现子控件的自动排列。
- **设计器支持**：继承 UserControl 后，Visual Studio 的设计器可以直接打开进行可视化编辑。

### 练习建议

1. 创建一个 `PlcStatusPanel` 用户控件，包含设备名称、状态 LED、温度值、压力值和详情按钮。
2. 添加自定义属性 `DeviceName`、`IsOnline`、`Temperature`，在属性窗口中可编辑。
3. 在主窗体中动态创建 4 个 `PlcStatusPanel` 实例，使用 FlowLayoutPanel 自动排列。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 属性窗口不显示自定义属性 | 属性没有公开的 get/set 或缺少特性 | 确保属性为 public 且有 get/set |
| 设计时控件空白 | InitializeComponent 顺序问题 | 确保 SuspendLayout/ResumeLayout 配对 |
| 事件未触发 | 事件未使用 ?.Invoke() 调用 | 检查事件触发代码 |

## 2. GDI+ 绘图基础

### 知识讲解

GDI+（Graphics Device Interface Plus）是 .NET 中的 2D 图形绘制 API。在 WinForms 自定义控件中，所有自定义绘制都通过 GDI+ 完成。理解 GDI+ 是开发自定义控件的基础。

**核心类：**

| 类 | 说明 | 是否需要 Dispose |
|----|------|-----------------|
| `Graphics` | 绘图表面（画布） | 自动管理 |
| `Pen` | 画笔（绘制线条、边框） | **是** |
| `Brush` | 画刷（填充区域） | **是** |
| `SolidBrush` | 纯色画刷 | **是** |
| `LinearGradientBrush` | 线性渐变画刷 | **是** |
| `Color` | 颜色结构体 | 值类型，不需要 |
| `Font` | 字体 | **是** |
| `Image` / `Bitmap` | 图像 | **是** |
| `StringFormat` | 文字格式 | **是** |

**坐标系统：**

```
(0,0) ───────────→ X（向右）
  │
  │
  │
  ↓
  Y（向下）
```

**注意**：WinForms 的坐标系原点在**左上角**，Y 轴向**下**增长（与数学坐标系相反）。

### 代码示例

```csharp
using System.Drawing;
using System.Drawing.Drawing2D;

/// <summary>
    /// GDI+ 绘图基础示例
    /// </summary>
    public partial class GdiPlusDemo : Form
    {
        public GdiPlusDemo()
        {
            InitializeComponent();
            this.DoubleBuffered = true;  // 开启双缓冲，减少闪烁
            this.Paint += GdiPlusDemo_Paint;
        }

        private void GdiPlusDemo_Paint(object sender, PaintEventArgs e)
        {
            var g = e.Graphics;  // 获取绘图对象
            g.SmoothingMode = SmoothingMode.AntiAlias;  // 抗锯齿

            DrawBasicShapes(g);
            DrawTextDemo(g);
            DrawGradientDemo(g);
        }

        /// <summary>
        /// 基本图形绘制
        /// </summary>
        private void DrawBasicShapes(Graphics g)
        {
            // ========== 画线 ==========
            using (var pen = new Pen(Color.Blue, 2))
            {
                // 实线
                g.DrawLine(pen, 10, 10, 200, 10);

                // 虚线
                pen.DashStyle = DashStyle.Dash;
                g.DrawLine(pen, 10, 30, 200, 30);

                // 点线
                pen.DashStyle = DashStyle.Dot;
                g.DrawLine(pen, 10, 50, 200, 50);
            }

            // ========== 矩形 ==========
            // 描边矩形
            using (var pen = new Pen(Color.Red, 2))
            {
                g.DrawRectangle(pen, 220, 10, 100, 50);
            }

            // 填充矩形
            using (var brush = new SolidBrush(Color.FromArgb(0, 150, 200)))
            {
                g.FillRectangle(brush, 340, 10, 100, 50);
            }

            // ========== 圆角矩形（需要自定义路径）==========
            using (var path = CreateRoundedRectPath(10, 80, 150, 60, 10))
            using (var brush = new SolidBrush(Color.FromArgb(0, 153, 255)))
            using (var pen = new Pen(Color.FromArgb(0, 120, 215), 1))
            {
                g.FillPath(brush, path);   // 填充
                g.DrawPath(pen, path);      // 描边
            }

            // ========== 圆形/椭圆 ==========
            using (var brush = new SolidBrush(Color.Green))
            {
                g.FillEllipse(brush, 180, 80, 50, 50);  // 圆形
            }
            using (var pen = new Pen(Color.Orange, 2))
            {
                g.DrawEllipse(pen, 250, 80, 80, 50);    // 椭圆
            }

            // ========== 扇形/弧形 ==========
            using (var pen = new Pen(Color.Purple, 2))
            {
                g.DrawArc(pen, 350, 80, 60, 60, 0, 270);  // 270 度弧
            }
            using (var brush = new SolidBrush(Color.FromArgb(255, 200, 0)))
            {
                g.FillPie(brush, 430, 80, 60, 60, 45, 90); // 扇形
            }
        }

        /// <summary>
        /// 文字绘制
        /// </summary>
        private void DrawTextDemo(Graphics g)
        {
            // 基本文字绘制
            using (var font = new Font("微软雅黑", 12, FontStyle.Bold))
            using (var brush = new SolidBrush(Color.Black))
            {
                g.DrawString("PLC 监控系统", font, brush, 10, 170);
            }

            // 居中对齐文字
            using (var font = new Font("Consolas", 10))
            using (var brush = new SolidBrush(Color.FromArgb(0, 120, 215)))
            using (var format = new StringFormat())
            {
                format.Alignment = StringAlignment.Center;
                format.LineAlignment = StringAlignment.Center;

                // 在指定矩形区域内居中绘制
                var rect = new RectangleF(10, 200, 200, 40);
                g.DrawString("温度：45.2°C", font, brush, rect, format);
            }

            // 测量文字大小
            using (var font = new Font("微软雅黑", 14))
            {
                SizeF size = g.MeasureString("Hello WinForms", font);
                // size.Width = 文字宽度, size.Height = 文字高度
            }
        }

        /// <summary>
        /// 渐变效果绘制
        /// </summary>
        private void DrawGradientDemo(Graphics g)
        {
            // 线性渐变矩形
            using (var brush = new LinearGradientBrush(
                new Rectangle(10, 260, 200, 50),
                Color.FromArgb(0, 120, 215),     // 起始颜色
                Color.FromArgb(0, 200, 255),     // 结束颜色
                LinearGradientMode.Horizontal)) // 水平渐变
            {
                g.FillRectangle(brush, 10, 260, 200, 50);
            }

            // 渐变文字
            using (var font = new Font("微软雅黑", 16, FontStyle.Bold))
            using (var brush = new LinearGradientBrush(
                new Rectangle(230, 260, 200, 50),
                Color.FromArgb(255, 100, 50),
                Color.FromArgb(255, 200, 50),
                LinearGradientMode.Horizontal))
            {
                g.DrawString("渐变文字", font, brush, 230, 268);
            }
        }

        /// <summary>
        /// 创建圆角矩形路径（辅助方法）
        /// </summary>
        private GraphicsPath CreateRoundedRectPath(float x, float y, float width, float height, float radius)
        {
            var path = new GraphicsPath();
            path.AddArc(x, y, radius * 2, radius * 2, 180, 90);       // 左上角
            path.AddArc(x + width - radius * 2, y, radius * 2, radius * 2, 270, 90); // 右上角
            path.AddArc(x + width - radius * 2, y + height - radius * 2, radius * 2, radius * 2, 0, 90); // 右下角
            path.AddArc(x, y + height - radius * 2, radius * 2, radius * 2, 90, 90);  // 左下角
            path.CloseFigure();
            return path;
        }
    }
}
```

### 注意事项

- **using 语句释放资源**：Pen、Brush、Font、GraphicsPath 等实现了 `IDisposable`，必须使用 `using` 语句或手动 `Dispose()`，否则会导致 GDI+ 句柄泄漏。
- **SmoothingMode.AntiAlias**：开启抗锯齿使图形更平滑，但对性能有一定影响。
- **DoubleBuffered = true**：在自定义绘制控件中开启双缓冲，可以大幅减少重绘时的闪烁。
- **坐标系方向**：Y 轴向下增长，计算角度时需要注意方向（顺时针为正方向）。

### 练习建议

1. 在窗体的 Paint 事件中绘制一个蓝色边框的圆角矩形，内部居中显示文字。
2. 绘制一个简单的仪表表盘（一个半圆弧 + 几个刻度标记）。
3. 使用 LinearGradientBrush 绘制一个从蓝色到绿色的渐变矩形。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 界面闪烁严重 | 未开启双缓冲 | 设置 `DoubleBuffered = true` |
| GDI+ 句柄泄漏 | Pen/Brush 未 Dispose | 使用 `using` 语句 |
| 文字位置偏移 | StringFormat 未设置对齐 | 设置 Alignment 和 LineAlignment |

## 3. 绘制基本图形

### 知识讲解

在前一节的基础上，本节将更系统地学习绘制各种基本图形的方法和技巧，为后续开发自定义控件打下坚实基础。

### 代码示例

```csharp
/// <summary>
/// 基本图形绘制技巧集合
/// </summary>
public static class DrawingHelper
{
    /// <summary>
    /// 绘制圆角矩形
    /// </summary>
    public static void DrawRoundedRectangle(Graphics g, Pen pen, RectangleF rect, float radius)
    {
        if (radius <= 0) { g.DrawRectangle(pen, rect.X, rect.Y, rect.Width, rect.Height); return; }
        radius = Math.Min(radius, Math.Min(rect.Width, rect.Height) / 2); // 防止半径过大

        using (var path = CreateRoundedRectPath(rect.X, rect.Y, rect.Width, rect.Height, radius))
        {
            g.DrawPath(pen, path);
        }
    }

    /// <summary>
    /// 填充圆角矩形
    /// </summary>
    public static void FillRoundedRectangle(Graphics g, Brush brush, RectangleF rect, float radius)
    {
        if (radius <= 0) { g.FillRectangle(brush, rect.X, rect.Y, rect.Width, rect.Height); return; }
        radius = Math.Min(radius, Math.Min(rect.Width, rect.Height) / 2);

        using (var path = CreateRoundedRectPath(rect.X, rect.Y, rect.Width, rect.Height, radius))
        {
            g.FillPath(brush, path);
        }
    }

    /// <summary>
    /// 绘制阴影矩形
    /// </summary>
    public static void DrawShadowRectangle(Graphics g, Rectangle rect, int shadowOffset, Color shadowColor)
    {
        // 先绘制偏移的阴影
        var shadowRect = new Rectangle(rect.X + shadowOffset, rect.Y + shadowOffset, rect.Width, rect.Height);
        using (var brush = new SolidBrush(shadowColor))
        {
            g.FillRectangle(brush, shadowRect);
        }
    }

    /// <summary>
    /// 绘制仪表弧线
    /// </summary>
    public static void DrawGaugeArc(Graphics g, RectangleF rect, float startAngle, float sweepAngle, Pen pen, float lineWidth)
    {
        pen.Width = lineWidth;
        // 圆弧的起始和结束角度需要转换为浮点数
        g.DrawArc(pen, rect.X + lineWidth / 2, rect.Y + lineWidth / 2,
            rect.Width - lineWidth, rect.Height - lineWidth,
            startAngle, sweepAngle);
    }

    /// <summary>
    /// 绘制带箭头的线
    /// </summary>
    public static void DrawArrow(Graphics g, Pen pen, PointF start, PointF end, float arrowSize)
    {
        // 绘制主线
        g.DrawLine(pen, start, end);

        // 计算箭头角度
        float angle = (float)Math.Atan2(end.Y - start.Y, end.X - start.X);

        // 绘制箭头两翼
        using (var arrowBrush = new SolidBrush(pen.Color))
        {
            var arrowPath = new GraphicsPath();
            arrowPath.AddLine(end, 
                new PointF(end.X - arrowSize * (float)Math.Cos(angle - Math.PI / 6),
                           end.Y - arrowSize * (float)Math.Sin(angle - Math.PI / 6)));
            arrowPath.AddLine(end,
                new PointF(end.X - arrowSize * (float)Math.Cos(angle + Math.PI / 6),
                           end.Y - arrowSize * (float)Math.Sin(angle + Math.PI / 6)));
            arrowPath.CloseFigure();
            g.FillPath(arrowBrush, arrowPath);
        }
    }

    /// <summary>
    /// 创建圆角矩形路径
    /// </summary>
    public static GraphicsPath CreateRoundedRectPath(float x, float y, float w, float h, float r)
    {
        var path = new GraphicsPath();
        path.AddArc(x, y, r * 2, r * 2, 180, 90);
        path.AddArc(x + w - r * 2, y, r * 2, r * 2, 270, 90);
        path.AddArc(x + w - r * 2, y + h - r * 2, r * 2, r * 2, 0, 90);
        path.AddArc(x, y + h - r * 2, r * 2, r * 2, 90, 90);
        path.CloseFigure();
        return path;
    }
}
```

### 注意事项

- 圆角矩形的半径不能超过宽度和高度的一半，需要做 `Math.Min` 限制。
- 绘制阴影时，先绘制阴影部分，再绘制主体部分（阴影在下面）。
- GDI+ 中角度以度为单位（不是弧度），从 X 轴正方向开始顺时针计算。

### 练习建议

1. 将 `DrawingHelper` 工具类复制到项目中，使用其中的方法绘制各种图形。
2. 练习绘制一个带阴影的圆角矩形卡片。
3. 绘制一个简单的箭头指向某个控件。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 圆角矩形变形 | 半径超过宽高的一半 | 使用 Math.Min 限制半径 |
| 角度方向不对 | GDI+ 角度顺时针为正 | 注意 GDI+ 的角度方向 |

## 4. 自定义绘制控件（OnPaint 重写）

### 知识讲解

自定义绘制控件是继承 `Control` 类并重写 `OnPaint` 方法，在控件表面上使用 GDI+ 绘制所有内容。这是开发仪表盘、LED 灯、进度环等特殊控件的必要技术。

**开发步骤：**

1. 创建一个类，继承 `Control`
2. 定义自定义属性（值、颜色、范围等）
3. 重写 `OnPaint` 方法，在其中使用 GDI+ 绘制
4. 在属性值变化时调用 `Invalidate()` 触发重绘
5. 设置 `DoubleBuffered = true` 减少闪烁
6. 设置合适的 `DefaultSize`

**OnPaint 方法的工作原理：**

```
属性值变化 → Invalidate() → 系统安排重绘 → 触发 OnPaint → 使用 GDI+ 绘制 → 控件显示新内容
```

### 代码示例

```csharp
using System;
using System.ComponentModel;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.Windows.Forms;

namespace PlcMonitorApp.Controls
{
    /// <summary>
    /// 自定义数值显示控件 —— 重写 OnPaint 示例
    /// 场景：上位机中显示 PLC 寄存器的实时数值（带单位、状态颜色、边框）
    /// </summary>
    public class NumericDisplay : Control
    {
        #region ===== 字段 =====

        private double _value = 0;
        private string _unit = "";
        private string _label = "";
        private Color _normalColor = Color.Green;
        private Color _warningColor = Color.Orange;
        private Color _alarmColor = Color.Red;
        private double _warningThreshold = 60;
        private double _alarmThreshold = 80;

        #endregion

        #region ===== 属性 =====

        [Description("显示的数值")]
        [DefaultValue(0)]
        [Category("数据")]
        public double Value
        {
            get => _value;
            set { _value = value; Invalidate(); }  // 值变化时触发重绘
        }

        [Description("数值单位")]
        [DefaultValue("")]
        [Category("数据")]
        public string Unit
        {
            get => _unit;
            set { _unit = value; Invalidate(); }
        }

        [Description("标签文字（如"温度"）")]
        [DefaultValue("")]
        [Category("外观")]
        public string Label
        {
            get => _label;
            set { _label = value; Invalidate(); }
        }

        [Description("正常状态颜色")]
        [Category("外观")]
        public Color NormalColor
        {
            get => _normalColor;
            set { _normalColor = value; Invalidate(); }
        }

        [Description("警告阈值")]
        [Category("数据")]
        public double WarningThreshold
        {
            get => _warningThreshold;
            set { _warningThreshold = value; Invalidate(); }
        }

        [Description("报警阈值")]
        [Category("数据")]
        public double AlarmThreshold
        {
            get => _alarmThreshold;
            set { _alarmThreshold = value; Invalidate(); }
        }

        #endregion

        #region ===== 构造函数 =====

        public NumericDisplay()
        {
            // 基本设置
            this.DoubleBuffered = true;    // 双缓冲减少闪烁
            this.Size = new Size(150, 70); // 默认大小
            this.MinimumSize = new Size(100, 50);
            this.BackColor = Color.White;
            this.Font = new Font("Consolas", 16, FontStyle.Bold);
        }

        #endregion

        #region ===== 重写 OnPaint =====

        protected override void OnPaint(PaintEventArgs e)
        {
            base.OnPaint(e);  // 先调用基类方法（重要）

            var g = e.Graphics;
            g.SmoothingMode = SmoothingMode.AntiAlias;
            g.TextRenderingHint = System.Drawing.Text.TextRenderingHint.ClearTypeGridFit;

            float w = this.ClientSize.Width;
            float h = this.ClientSize.Height;

            // 确定数值颜色
            Color valueColor = GetValueColor();

            // ---- 绘制背景 ----
            using (var bgBrush = new SolidBrush(this.BackColor))
            {
                g.FillRectangle(bgBrush, 0, 0, w, h);
            }

            // ---- 绘制边框 ----
            float borderWidth = 1.5f;
            using (var borderPen = new Pen(valueColor, borderWidth))
            {
                g.DrawRectangle(borderPen, borderWidth / 2, borderWidth / 2,
                    w - borderWidth, h - borderWidth);
            }

            // ---- 绘制标签（左上角小字）----
            if (!string.IsNullOrEmpty(_label))
            {
                using (var labelFont = new Font("微软雅黑", 8))
                using (var labelBrush = new SolidBrush(Color.Gray))
                {
                    g.DrawString(_label, labelFont, labelBrush, 5, 3);
                }
            }

            // ---- 绘制数值（居中大字）----
            string valueText = $"{_value:F1}";
            if (!string.IsNullOrEmpty(_unit))
                valueText += $" {_unit}";

            using (var valueFont = new Font("Consolas", 16, FontStyle.Bold))
            using (var valueBrush = new SolidBrush(valueColor))
            using (var format = new StringFormat())
            {
                format.Alignment = StringAlignment.Center;
                format.LineAlignment = StringAlignment.Center;
                g.DrawString(valueText, valueFont, valueBrush, new RectangleF(0, -2, w, h - 5), format);
            }

            // ---- 绘制底部状态指示条 ----
            float barHeight = 3;
            using (var barBrush = new SolidBrush(valueColor))
            {
                g.FillRectangle(barBrush, 1, h - barHeight - 1, w - 2, barHeight);
            }
        }

        #endregion

        #region ===== 辅助方法 =====

        /// <summary>
        /// 根据当前值和阈值确定显示颜色
        /// </summary>
        private Color GetValueColor()
        {
            double absValue = Math.Abs(_value);
            if (absValue >= _alarmThreshold) return _alarmColor;
            if (absValue >= _warningThreshold) return _warningColor;
            return _normalColor;
        }

        #endregion
    }
}
```

### 注意事项

- **`Invalidate()` 触发重绘**：每次属性值变化后调用 `Invalidate()`，系统会在下一次消息循环时调用 `OnPaint`。
- **不要在 OnPaint 中创建对象**：Font、Pen、Brush 等应该在 OnPaint 外部创建（作为字段），或在 OnPaint 内部使用 `using` 即时创建和释放。频繁创建大对象会影响性能。
- **使用 `ClientSize` 而非 `Size`**：`ClientSize` 是控件的可绘制区域（不含边框），`Size` 包含了非客户区。
- **`base.OnPaint(e)`**：通常在自定义 OnPaint 的开头调用基类方法，确保基类的绘制逻辑也执行。

### 练习建议

1. 创建一个 `NumericDisplay` 控件，显示带单位、带颜色标识的数值。
2. 添加一个 `DecimalPlaces` 属性，控制小数位数。
3. 在主窗体中放置 4 个 `NumericDisplay`，分别显示温度、压力、转速、电流，并用 Timer 定时更新值。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 属性变化后控件不更新 | 忘记调用 Invalidate() | 在属性 setter 中调用 Invalidate() |
| 重绘闪烁 | 未开启双缓冲 | 构造函数中设置 DoubleBuffered = true |
| GDI+ 泄漏 | 在 OnPaint 中创建 Brush/Pen 未 Dispose | 使用 using 语句 |

## 5. 创建带动画效果的仪表盘控件

### 知识讲解

仪表盘（Gauge）控件是上位机中常见的数据可视化元素，用于以弧形指针的方式展示数值。本节将创建一个带平滑动画效果的仪表盘控件，指针移动使用插值算法实现丝滑过渡。

### 代码示例

```csharp
namespace PlcMonitorApp.Controls
{
    /// <summary>
    /// 仪表盘控件 —— 带动画效果
    /// 场景：上位机中展示温度、压力、转速等关键参数
    /// </summary>
    public class GaugeControl : Control
    {
        #region ===== 字段 =====

        private double _minimum = 0;
        private double _maximum = 100;
        private double _value = 0;
        private double _displayValue = 0;     // 当前显示值（用于动画插值）
        private string _label = "温度";
        private string _unit = "°C";
        private float _startAngle = -225;     // 起始角度（7 点半方向）
        private float _sweepAngle = 270;      // 扫过的角度
        private Color _needleColor = Color.FromArgb(220, 50, 50);
        private System.Windows.Forms.Timer _animationTimer;
        private double _animationSpeed = 0.1;  // 动画速度（0~1，越大越快）

        // 分段阈值（用于弧形颜色分区）
        private double _greenZoneStart = 0;
        private double _greenZoneEnd = 60;
        private double _yellowZoneEnd = 80;
        private double _redZoneEnd = 100;

        #endregion

        #region ===== 属性 =====

        [Description("最小值")]
        [DefaultValue(0)]
        [Category("数据")]
        public double Minimum
        {
            get => _minimum;
            set { _minimum = value; Invalidate(); }
        }

        [Description("最大值")]
        [DefaultValue(100)]
        [Category("数据")]
        public double Maximum
        {
            get => _maximum;
            set { _maximum = value; Invalidate(); }
        }

        [Description("当前值（设置后自动动画过渡）")]
        [DefaultValue(0)]
        [Category("数据")]
        public double Value
        {
            get => _value;
            set
            {
                _value = Math.Max(_minimum, Math.Min(_maximum, value));
                StartAnimation();
            }
        }

        [Description("标签文字")]
        [DefaultValue("温度")]
        [Category("外观")]
        public string Label
        {
            get => _label;
            set { _label = value; Invalidate(); }
        }

        [Description("单位")]
        [DefaultValue("°C")]
        [Category("数据")]
        public string Unit
        {
            get => _unit;
            set { _unit = value; Invalidate(); }
        }

        [Description("指针颜色")]
        [Category("外观")]
        public Color NeedleColor
        {
            get => _needleColor;
            set { _needleColor = value; Invalidate(); }
        }

        [Description("动画速度 (0.01~1.0)")]
        [DefaultValue(0.1)]
        [Category("行为")]
        public double AnimationSpeed
        {
            get => _animationSpeed;
            set { _animationSpeed = Math.Max(0.01, Math.Min(1.0, value)); }
        }

        #endregion

        #region ===== 构造函数 =====

        public GaugeControl()
        {
            this.DoubleBuffered = true;
            this.Size = new Size(220, 160);
            this.BackColor = Color.Transparent;

            // 动画定时器
            _animationTimer = new System.Windows.Forms.Timer { Interval = 16 }; // ~60FPS
            _animationTimer.Tick += AnimationTimer_Tick;
        }

        #endregion

        #region ===== 动画逻辑 =====

        /// <summary>
        /// 启动动画
        /// </summary>
        private void StartAnimation()
        {
            if (!_animationTimer.Enabled)
                _animationTimer.Start();
        }

        /// <summary>
        /// 动画帧更新（线性插值）
        /// </summary>
        private void AnimationTimer_Tick(object sender, EventArgs e)
        {
            double diff = _value - _displayValue;

            // 使用线性插值逐渐趋近目标值
            _displayValue += diff * _animationSpeed;

            // 当差距足够小时停止动画
            if (Math.Abs(diff) < 0.01)
            {
                _displayValue = _value;
                _animationTimer.Stop();
            }

            Invalidate(); // 触发重绘
        }

        #endregion

        #region ===== OnPaint 绘制 =====

        protected override void OnPaint(PaintEventArgs e)
        {
            base.OnPaint(e);
            var g = e.Graphics;
            g.SmoothingMode = SmoothingMode.AntiAlias;
            g.TextRenderingHint = System.Drawing.Text.TextRenderingHint.ClearTypeGridFit;

            float w = this.ClientSize.Width;
            float h = this.ClientSize.Height;
            float cx = w / 2;                     // 圆心 X
            float cy = h * 0.65f;                 // 圆心 Y（偏下，给标签留空间）
            float radius = Math.Min(w, h) * 0.38f; // 半径

            DrawBackground(g, cx, cy, radius);
            DrawScaleArcs(g, cx, cy, radius);
            DrawTickMarks(g, cx, cy, radius);
            DrawNeedle(g, cx, cy, radius);
            DrawCenterCap(g, cx, cy);
            DrawLabels(g, w, h);
        }

        /// <summary>
        /// 绘制背景
        /// </summary>
        private void DrawBackground(Graphics g, float cx, float cy, float radius)
        {
            // 外圈阴影
            using (var shadowBrush = new SolidBrush(Color.FromArgb(200, 200, 200)))
            {
                g.FillEllipse(shadowBrush, cx - radius - 3, cy - radius - 1,
                    (radius + 3) * 2, (radius + 3) * 2);
            }

            // 白色底盘
            using (var bgBrush = new SolidBrush(Color.White))
            {
                g.FillEllipse(bgBrush, cx - radius, cy - radius, radius * 2, radius * 2);
            }

            // 外圈边框
            using (var borderPen = new Pen(Color.FromArgb(200, 200, 200), 2))
            {
                g.DrawEllipse(borderPen, cx - radius, cy - radius, radius * 2, radius * 2);
            }
        }

        /// <summary>
        /// 绘制分段弧线（绿-黄-红）
        /// </summary>
        private void DrawScaleArcs(Graphics g, float cx, float cy, float radius)
        {
            float arcWidth = 12;
            float innerRadius = radius - arcWidth - 5;

            // 绿色区域
            DrawArcSegment(g, cx, cy, innerRadius, arcWidth,
                ValueToAngle(_greenZoneStart),
                ValueToAngle(_greenZoneEnd) - ValueToAngle(_greenZoneStart),
                Color.FromArgb(0, 200, 80));

            // 黄色区域
            DrawArcSegment(g, cx, cy, innerRadius, arcWidth,
                ValueToAngle(_greenZoneEnd),
                ValueToAngle(_yellowZoneEnd) - ValueToAngle(_greenZoneEnd),
                Color.FromArgb(255, 200, 0));

            // 红色区域
            DrawArcSegment(g, cx, cy, innerRadius, arcWidth,
                ValueToAngle(_yellowZoneEnd),
                ValueToAngle(_redZoneEnd) - ValueToAngle(_yellowZoneEnd),
                Color.FromArgb(255, 50, 50));
        }

        /// <summary>
        /// 绘制弧线段
        /// </summary>
        private void DrawArcSegment(Graphics g, float cx, float cy, float radius, float width, float startAngle, float sweepAngle, Color color)
        {
            using (var pen = new Pen(color, width))
            {
                pen.StartCap = LineCap.Round;
                pen.EndCap = LineCap.Round;
                g.DrawArc(pen, cx - radius, cy - radius, radius * 2, radius * 2,
                    startAngle, sweepAngle);
            }
        }

        /// <summary>
        /// 绘制刻度线
        /// </summary>
        private void DrawTickMarks(Graphics g, float cx, float cy, float radius)
        {
            float majorTickLength = 10;
            float minorTickLength = 5;
            float outerRadius = radius - 20;

            for (double val = _minimum; val <= _maximum; val += (_maximum - _minimum) / 10)
            {
                float angle = ValueToAngle(val);
                float radian = (float)(angle * Math.PI / 180);
                bool isMajor = ((int)val % (int)((_maximum - _minimum) / 10)) == 0;
                float tickLen = isMajor ? majorTickLength : minorTickLength;

                float x1 = cx + (float)Math.Sin(radian) * outerRadius;
                float y1 = cy - (float)Math.Cos(radian) * outerRadius;
                float x2 = cx + (float)Math.Sin(radian) * (outerRadius - tickLen);
                float y2 = cy - (float)Math.Cos(radian) * (outerRadius - tickLen);

                using (var pen = new Pen(Color.FromArgb(100, 100, 100), isMajor ? 2 : 1))
                {
                    g.DrawLine(pen, x1, y1, x2, y2);
                }

                // 主刻度数字
                if (isMajor)
                {
                    float textR = outerRadius - tickLen - 10;
                    float tx = cx + (float)Math.Sin(radian) * textR;
                    float ty = cy - (float)Math.Cos(radian) * textR;

                    using (var font = new Font("Consolas", 7))
                    using (var brush = new SolidBrush(Color.FromArgb(80, 80, 80)))
                    using (var format = new StringFormat { Alignment = StringAlignment.Center, LineAlignment = StringAlignment.Center })
                    {
                        g.DrawString($"{val:F0}", font, brush, tx, ty, format);
                    }
                }
            }
        }

        /// <summary>
        /// 绘制指针
        /// </summary>
        private void DrawNeedle(Graphics g, float cx, float cy, float radius)
        {
            float angle = ValueToAngle(_displayValue);
            float radian = (float)(angle * Math.PI / 180);
            float needleLength = radius - 25;

            float tipX = cx + (float)Math.Sin(radian) * needleLength;
            float tipY = cy - (float)Math.Cos(radian) * needleLength;

            // 指针尾部（短的一端）
            float tailX = cx - (float)Math.Sin(radian) * 10;
            float tailY = cy + (float)Math.Cos(radian) * 10;

            // 绘制指针阴影
            using (var shadowPen = new Pen(Color.FromArgb(100, 100, 100), 4))
            {
                shadowPen.StartCap = LineCap.Round;
                g.DrawLine(shadowPen, tailX + 1, tailY + 1, tipX + 1, tipY + 1);
            }

            // 绘制指针主体
            using (var needlePen = new Pen(_needleColor, 3))
            {
                needlePen.StartCap = LineCap.Round;
                g.DrawLine(needlePen, tailX, tailY, tipX, tipY);
            }

            // 指针尖端圆点
            using (var tipBrush = new SolidBrush(_needleColor))
            {
                g.FillEllipse(tipBrush, tipX - 3, tipY - 3, 6, 6);
            }
        }

        /// <summary>
        /// 绘制中心盖
        /// </summary>
        private void DrawCenterCap(Graphics g, float cx, float cy)
        {
            using (var capBrush = new SolidBrush(Color.FromArgb(60, 60, 60)))
            {
                g.FillEllipse(capBrush, cx - 6, cy - 6, 12, 12);
            }
            using (var innerBrush = new SolidBrush(Color.FromArgb(120, 120, 120)))
            {
                g.FillEllipse(innerBrush, cx - 3, cy - 3, 6, 6);
            }
        }

        /// <summary>
        /// 绘制文字标签
        /// </summary>
        private void DrawLabels(Graphics g, float w, float h)
        {
            // 标签（如"温度"）
            using (var labelFont = new Font("微软雅黑", 9))
            using (var labelBrush = new SolidBrush(Color.FromArgb(80, 80, 80)))
            using (var format = new StringFormat { Alignment = StringAlignment.Center })
            {
                g.DrawString(_label, labelFont, labelBrush, w / 2, h - 30, format);
            }

            // 数值 + 单位
            string valueText = $"{_displayValue:F1} {_unit}";
            using (var valueFont = new Font("Consolas", 12, FontStyle.Bold))
            using (var valueBrush = new SolidBrush(Color.FromArgb(50, 50, 50)))
            using (var format = new StringFormat { Alignment = StringAlignment.Center })
            {
                g.DrawString(valueText, valueFont, valueBrush, w / 2, h - 18, format);
            }
        }

        #endregion

        #region ===== 辅助方法 =====

        /// <summary>
        /// 将数值转换为角度
        /// </summary>
        private float ValueToAngle(double value)
        {
            double ratio = (value - _minimum) / (_maximum - _minimum);
            return _startAngle + (float)(ratio * _sweepAngle);
        }

        #endregion

        #region ===== 清理 =====

        protected override void Dispose(bool disposing)
        {
            if (disposing)
            {
                _animationTimer?.Stop();
                _animationTimer?.Dispose();
            }
            base.Dispose(disposing);
        }

        #endregion
    }
}
```

### 注意事项

- **动画使用线性插值**：`displayValue += (target - displayValue) * speed`，这种方式越接近目标值移动越慢，产生自然的减速效果。
- **Timer 频率**：16ms 约 60FPS，这是流畅动画的最低要求。不要太快（浪费 CPU），也不要太慢（卡顿）。
- **Dispose 释放 Timer**：控件销毁时必须停止并释放定时器，否则会内存泄漏。
- **角度计算**：GDI+ 中角度从 3 点钟方向（X 轴正方向）开始，顺时针增加。仪表盘通常从 7 点半方向开始（-225 度）。

### 练习建议

1. 创建 GaugeControl 控件，设置范围为 0~100，标签为"温度"，单位为"°C"。
2. 使用 Timer 每 1 秒更新 Value，观察指针的平滑动画效果。
3. 修改 `_animationSpeed` 参数，体验不同速度的动画效果。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 指针不移动 | 忘记调用 Invalidate() | 动画 Timer 中调用 Invalidate() |
| 动画不停 | 差距判断阈值太小 | 设置合理的停止阈值（如 0.01） |
| 控件销毁后报异常 | Timer 未释放 | 在 Dispose 中 Stop 和 Dispose Timer |

## 6. 创建 LED 指示灯控件

### 知识讲解

LED 指示灯是上位机中无处不在的元素，用于直观地显示设备在线/离线、通信正常/异常、运行/停止等状态。本节将创建一个支持多种颜色和闪烁动画的 LED 指示灯控件。

### 代码示例

```csharp
namespace PlcMonitorApp.Controls
{
    /// <summary>
    /// LED 指示灯控件
    /// 场景：上位机中显示 PLC 设备、通信通道、I/O 状态的在线/离线指示
    /// 支持颜色切换、闪烁动画、不同大小
    /// </summary>
    public class LedIndicator : Control
    {
        #region ===== 枚举 =====

        /// <summary>LED 颜色预设</summary>
        public enum LedColor
        {
            Off,        // 灰色（关闭）
            Green,      // 绿色（正常/在线）
            Red,        // 红色（报警/离线）
            Yellow,     // 黄色（警告）
            Orange,     // 橙色
            Blue,       // 蓝色（通信中）
            Custom      // 自定义颜色
        }

        /// <summary>闪烁模式</summary>
        public enum BlinkMode
        {
            None,       // 不闪烁
            Slow,       // 慢闪（1Hz）
            Fast,       // 快闪（2Hz）
            Custom      // 自定义频率
        }

        #endregion

        #region ===== 字段 =====

        private LedColor _ledColor = LedColor.Off;
        private Color _customColor = Color.Purple;
        private BlinkMode _blinkMode = BlinkMode.None;
        private int _blinkInterval = 500;     // 闪烁间隔(ms)
        private bool _isBlinkOn = true;        // 当前闪烁状态
        private bool _isGlowEnabled = true;    // 是否启用发光效果
        private System.Windows.Forms.Timer _blinkTimer;

        #endregion

        #region ===== 属性 =====

        [Description("LED 颜色")]
        [DefaultValue(LedColor.Off)]
        [Category("外观")]
        public LedColor LedColorValue
        {
            get => _ledColor;
            set { _ledColor = value; Invalidate(); }
        }

        [Description("自定义颜色（LedColor 设为 Custom 时生效）")]
        [Category("外观")]
        public Color CustomColor
        {
            get => _customColor;
            set { _customColor = value; Invalidate(); }
        }

        [Description("闪烁模式")]
        [DefaultValue(BlinkMode.None)]
        [Category("行为")]
        public BlinkMode Blink
        {
            get => _blinkMode;
            set
            {
                _blinkMode = value;
                UpdateBlinkTimer();
            }
        }

        [Description("自定义闪烁间隔(ms)")]
        [DefaultValue(500)]
        [Category("行为")]
        public int BlinkInterval
        {
            get => _blinkInterval;
            set { _blinkInterval = value; UpdateBlinkTimer(); }
        }

        [Description("是否启用发光效果")]
        [DefaultValue(true)]
        [Category("外观")]
        public bool GlowEnabled
        {
            get => _isGlowEnabled;
            set { _isGlowEnabled = value; Invalidate(); }
        }

        #endregion

        #region ===== 构造函数 =====

        public LedIndicator()
        {
            this.DoubleBuffered = true;
            this.Size = new Size(20, 20);
            this.MinimumSize = new Size(10, 10);

            _blinkTimer = new System.Windows.Forms.Timer();
            _blinkTimer.Tick += (s, e) =>
            {
                _isBlinkOn = !_isBlinkOn;
                Invalidate();
            };
        }

        #endregion

        #region ===== 闪烁控制 =====

        private void UpdateBlinkTimer()
        {
            _blinkTimer.Stop();
            _isBlinkOn = true;

            switch (_blinkMode)
            {
                case BlinkMode.Slow:
                    _blinkTimer.Interval = 1000;
                    _blinkTimer.Start();
                    break;
                case BlinkMode.Fast:
                    _blinkTimer.Interval = 500;
                    _blinkTimer.Start();
                    break;
                case BlinkMode.Custom:
                    _blinkTimer.Interval = Math.Max(50, _blinkInterval);
                    _blinkTimer.Start();
                    break;
            }
        }

        #endregion

        #region ===== OnPaint =====

        protected override void OnPaint(PaintEventArgs e)
        {
            base.OnPaint(e);
            var g = e.Graphics;
            g.SmoothingMode = SmoothingMode.AntiAlias;

            float w = this.ClientSize.Width;
            float h = this.ClientSize.Height;
            float cx = w / 2;
            float cy = h / 2;
            float radius = Math.Min(w, h) / 2 - 1;

            // 如果正在闪烁且当前处于"灭"状态
            if (_blinkMode != BlinkMode.None && !_isBlinkOn)
            {
                DrawLed(g, cx, cy, radius, Color.FromArgb(180, 180, 180)); // 暗灰色
                return;
            }

            // 获取当前颜色
            Color color = GetActualColor();
            DrawLed(g, cx, cy, radius, color);
        }

        /// <summary>
        /// 绘制 LED
        /// </summary>
        private void DrawLed(Graphics g, float cx, float cy, float radius, Color color)
        {
            if (radius <= 0) return;

            // ---- 发光效果（外圈光晕）----
            if (_isGlowEnabled && color != Color.FromArgb(180, 180, 180))
            {
                for (int i = 3; i >= 1; i--)
                {
                    float glowRadius = radius + i * 2;
                    using (var glowBrush = new SolidBrush(Color.FromArgb(
                        30 / i,
                        color.R,
                        color.G,
                        color.B)))
                    {
                        g.FillEllipse(glowBrush,
                            cx - glowRadius, cy - glowRadius,
                            glowRadius * 2, glowRadius * 2);
                    }
                }
            }

            // ---- LED 主体 ----
            using (var ledBrush = new SolidBrush(color))
            {
                g.FillEllipse(ledBrush,
                    cx - radius, cy - radius,
                    radius * 2, radius * 2);
            }

            // ---- 高光效果（左上角白色亮点）----
            float highlightRadius = radius * 0.3f;
            float highlightX = cx - radius * 0.3f;
            float highlightY = cy - radius * 0.3f;

            using (var highlightBrush = new SolidBrush(Color.FromArgb(120, 255, 255, 255)))
            {
                g.FillEllipse(highlightBrush,
                    highlightX - highlightRadius, highlightY - highlightRadius,
                    highlightRadius * 2, highlightRadius * 2);
            }

            // ---- 边框 ----
            using (var borderPen = new Pen(Color.FromArgb(150, 150, 150), 1))
            {
                g.DrawEllipse(borderPen,
                    cx - radius, cy - radius,
                    radius * 2, radius * 2);
            }
        }

        #endregion

        #region ===== 辅助方法 =====

        private Color GetActualColor()
        {
            return _ledColor switch
            {
                LedColor.Off => Color.FromArgb(180, 180, 180),
                LedColor.Green => Color.FromArgb(0, 200, 0),
                LedColor.Red => Color.FromArgb(220, 30, 30),
                LedColor.Yellow => Color.FromArgb(255, 220, 0),
                LedColor.Orange => Color.FromArgb(255, 150, 0),
                LedColor.Blue => Color.FromArgb(30, 144, 255),
                LedColor.Custom => _customColor,
                _ => Color.FromArgb(180, 180, 180)
            };
        }

        /// <summary>
        /// 便捷方法：设置在线状态
        /// </summary>
        public void SetOnline(bool online)
        {
            if (online)
            {
                LedColorValue = LedColor.Green;
                Blink = BlinkMode.None;
            }
            else
            {
                LedColorValue = LedColor.Red;
                Blink = BlinkMode.Slow;
            }
        }

        /// <summary>
        /// 便捷方法：设置通信中状态
        /// </summary>
        public void SetCommunicating()
        {
            LedColorValue = LedColor.Blue;
            Blink = BlinkMode.Fast;
        }

        #endregion

        #region ===== 清理 =====

        protected override void Dispose(bool disposing)
        {
            if (disposing)
            {
                _blinkTimer?.Stop();
                _blinkTimer?.Dispose();
            }
            base.Dispose(disposing);
        }

        #endregion
    }
}
```

### 注意事项

- **发光效果实现**：通过多层半透明椭圆叠加实现 LED 的光晕效果，层数越多效果越柔和，但性能消耗也越大。
- **高光效果**：在 LED 的左上角绘制一个小的白色半透明椭圆，模拟光源反射，让 LED 更有立体感。
- **闪烁状态管理**：使用 `_isBlinkOn` 标志位控制闪烁，闪烁时在亮色和暗色之间切换。
- **Dispose**：释放 Timer 资源，防止内存泄漏。

### 练习建议

1. 创建 LedIndicator 控件，测试不同颜色（Green/Red/Yellow/Blue）的显示效果。
2. 设置 `Blink = BlinkMode.Fast`，测试闪烁动画效果。
3. 创建 6 个 LED 指示灯，分别模拟 6 个 PLC 站点的状态。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| LED 控件不显示 | Size 太小或背景与控件同色 | 设置合适的 Size 和 BackColor |
| 闪烁不停止 | 控件销毁时未释放 Timer | 在 Dispose 中 Stop/Dispose Timer |
| 发光效果不自然 | 光晕层数太少或透明度不对 | 调整层数和 Alpha 值 |

## 7. 综合案例：PLC 状态指示与数据面板控件

### 知识讲解

本案例综合运用前面学习的 UserControl、GDI+ 绘图、自定义控件技术，创建一个完整的 PLC 状态指示面板和数据展示面板控件。

### 代码示例

```csharp
namespace PlcMonitorApp.Controls
{
    /// <summary>
    /// PLC 状态指示面板 —— 综合案例
    /// 集成设备信息、通信状态、关键参数指示
    /// 场景：上位机侧边栏或首页的设备概览面板
    /// </summary>
    public partial class PlcDevicePanel : UserControl
    {
        #region ===== 自定义属性 =====

        public string DeviceName
        {
            get => lblName.Text;
            set => lblName.Text = value;
        }

        public string IpAddress
        {
            get => lblIp.Text;
            set => lblIp.Text = value;
        }

        /// <summary>设备状态（在线/离线/通信中）</summary>
        public DeviceStatus Status
        {
            get => _status;
            set
            {
                _status = value;
                UpdateStatusDisplay();
            }
        }
        private DeviceStatus _status;

        /// <summary>温度值</summary>
        public double Temperature
        {
            get => gaugeTemp.Value;
            set => gaugeTemp.Value = value;
        }

        /// <summary>压力值</summary>
        public double Pressure
        {
            get => gaugePressure.Value;
            set => gaugePressure.Value = value;
        }

        #endregion

        #region ===== 子控件 =====

        private Label lblName;
        private Label lblIp;
        private Label lblStatus;
        private LedIndicator ledOnline;
        private LedIndicator ledComm;
        private GaugeControl gaugeTemp;
        private GaugeControl gaugePressure;

        #endregion

        public enum DeviceStatus
        {
            Online,
            Offline,
            Communicating,
            Error
        }

        public PlcDevicePanel()
        {
            this.Size = new Size(300, 200);
            this.BackColor = Color.White;
            this.BorderStyle = BorderStyle.FixedSingle;
            this.Padding = new Padding(8);
            this.DoubleBuffered = true;

            InitializeControls();
        }

        private void InitializeControls()
        {
            // ====== 顶部区域 ======
            ledOnline = new LedIndicator
            {
                Size = new Size(14, 14),
                Location = new Point(10, 10),
                LedColorValue = LedIndicator.LedColor.Green
            };

            ledComm = new LedIndicator
            {
                Size = new Size(14, 14),
                Location = new Point(30, 10),
                LedColorValue = LedIndicator.LedColor.Blue,
                Blink = LedIndicator.BlinkMode.Fast
            };

            lblName = new Label
            {
                Text = "1#PLC - 主站",
                Location = new Point(50, 5),
                AutoSize = true,
                Font = new Font("微软雅黑", 10, FontStyle.Bold),
                ForeColor = Color.FromArgb(50, 50, 50)
            };

            lblIp = new Label
            {
                Text = "192.168.1.10",
                Location = new Point(50, 25),
                AutoSize = true,
                Font = new Font("Consolas", 8),
                ForeColor = Color.Gray
            };

            lblStatus = new Label
            {
                Text = "● 在线",
                Location = new Point(170, 10),
                AutoSize = true,
                Font = new Font("微软雅黑", 8),
                ForeColor = Color.Green
            };

            // ====== 底部区域：仪表盘 ======
            gaugeTemp = new GaugeControl
            {
                Location = new Point(10, 55),
                Size = new Size(130, 100),
                Label = "温度",
                Unit = "°C",
                Minimum = 0,
                Maximum = 100,
                AnimationSpeed = 0.15
            };

            gaugePressure = new GaugeControl
            {
                Location = new Point(150, 55),
                Size = new Size(130, 100),
                Label = "压力",
                Unit = "MPa",
                Minimum = 0,
                Maximum = 5,
                AnimationSpeed = 0.15
            };

            // ====== 底部信息栏 ======
            var lblUpdateTime = new Label
            {
                Text = "最后更新：--",
                Location = new Point(10, 170),
                AutoSize = true,
                Font = new Font("微软雅黑", 7),
                ForeColor = Color.FromArgb(150, 150, 150)
            };

            this.Controls.AddRange(new Control[]
            {
                ledOnline, ledComm, lblName, lblIp, lblStatus,
                gaugeTemp, gaugePressure, lblUpdateTime
            });
        }

        /// <summary>
        /// 更新状态显示
        /// </summary>
        private void UpdateStatusDisplay()
        {
            switch (_status)
            {
                case DeviceStatus.Online:
                    ledOnline.SetOnline(true);
                    ledComm.LedColorValue = LedIndicator.LedColor.Green;
                    ledComm.Blink = LedIndicator.BlinkMode.None;
                    lblStatus.Text = "● 在线";
                    lblStatus.ForeColor = Color.Green;
                    this.BackColor = Color.White;
                    break;

                case DeviceStatus.Offline:
                    ledOnline.SetOnline(false);
                    ledComm.LedColorValue = LedIndicator.LedColor.Off;
                    ledComm.Blink = LedIndicator.BlinkMode.None;
                    lblStatus.Text = "● 离线";
                    lblStatus.ForeColor = Color.Red;
                    this.BackColor = Color.FromArgb(255, 248, 245);
                    break;

                case DeviceStatus.Communicating:
                    ledOnline.SetOnline(true);
                    ledComm.SetCommunicating();
                    lblStatus.Text = "● 通信中...";
                    lblStatus.ForeColor = Color.FromArgb(0, 120, 215);
                    break;

                case DeviceStatus.Error:
                    ledOnline.LedColorValue = LedIndicator.LedColor.Red;
                    ledOnline.Blink = LedIndicator.BlinkMode.Fast;
                    lblStatus.Text = "● 通信错误";
                    lblStatus.ForeColor = Color.Red;
                    this.BackColor = Color.FromArgb(255, 240, 240);
                    break;
            }
        }

        /// <summary>
        /// 更新最后通信时间
        /// </summary>
        public void UpdateLastCommTime(DateTime time)
        {
            foreach (Control c in this.Controls)
            {
                if (c is Label lbl && lbl.Text.StartsWith("最后更新"))
                {
                    lbl.Text = $"最后更新：{time:HH:mm:ss}";
                    break;
                }
            }
        }
    }
}
```

### 注意事项

- 本案例将 `LedIndicator` 和 `GaugeControl` 作为子控件嵌入到 `PlcDevicePanel` 中，体现了 UserControl 复合控件的优势——可以组合使用多个自定义控件。
- 状态变化时，同步更新 LED 颜色、闪烁模式、文字颜色和背景颜色，确保视觉一致性。
- 在实际项目中，可以将 `PlcDevicePanel` 放入工具箱，在设计器中拖拽使用。

### 练习建议

1. 将前面创建的 `LedIndicator`、`GaugeControl` 和 `PlcDevicePanel` 集成到一个测试窗体中。
2. 使用 Timer 模拟 PLC 数据变化，观察仪表盘指针动画和 LED 状态切换。
3. 创建 4 个 `PlcDevicePanel`，分别模拟不同状态（在线、离线、通信中、错误）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 自定义控件在设计器中不显示 | 缺少默认构造函数或属性异常 | 确保有公共无参构造函数 |
| 控件嵌套后性能差 | 子控件过多或动画 Timer 过多 | 优化绘制频率，合并定时器 |

## 总结

本章学习了 WinForms 自定义控件开发的核心技术：

| 技术 | 核心概念 | 上位机典型应用 |
|------|---------|--------------|
| UserControl | 复合控件（设计器拖拽） | 设备状态面板、参数设置面板 |
| GDI+ 基础 | Graphics、Pen、Brush、Color | 所有自定义绘制的基础 |
| OnPaint 重写 | 自定义绘制控件 | 仪表盘、LED灯、进度环 |
| 动画效果 | Timer + 插值算法 | 仪表指针平滑过渡、LED 闪烁 |
| 自定义属性/事件 | 暴露接口给外部使用 | 设备名称、值、状态变化通知 |

**自定义控件开发的核心原则：**
1. 总是设置 `DoubleBuffered = true` 减少闪烁
2. 属性值变化时调用 `Invalidate()` 触发重绘
3. GDI+ 资源（Pen、Brush、Font）务必 using 释放
4. 控件销毁时释放 Timer 和其他 IDisposable 资源
5. 使用 `[Category]`、`[Description]`、`[DefaultValue]` 特性让属性在属性窗口中更友好
