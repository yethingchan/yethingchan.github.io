## 1. 现代化 UI 设计原则

### 知识讲解

工业上位机界面的设计目标是**信息密度高、层次分明、一目了然**。虽然不需要像消费类软件那样追求极致美观，但专业的视觉设计可以显著提升操作员的工作效率和用户体验。

**四大设计原则：**

| 原则 | 说明 | 上位机中的体现 |
|------|------|--------------|
| **简洁** | 去除不必要的装饰，信息优先 | 减少花边装饰，数据区域最大化 |
| **层次感** | 通过颜色深浅、大小、间距建立视觉层级 | 标题 > 正文 > 辅助文字；重要数据突出显示 |
| **一致性** | 所有页面/控件使用统一的设计语言 | 统一的颜色方案、字体、间距、图标风格 |
| **对比度** | 重要信息与背景有足够对比 | 数据用亮色，背景用暗色；报警用高对比色 |

**配色建议（工业风格）：**

```
主色调：深蓝 #0078D7 或深灰 #333333
背景色：浅灰 #F5F5F5 或深色 #1E1E2E（暗色主题）
强调色：亮绿 #00C853（正常）、橙色 #FF9800（警告）、红色 #F44336（报警）
文字色：深灰 #333333 或浅灰 #CCCCCC（暗色主题）
边框色：#E0E0E0 或 #444444（暗色主题）
```

### 注意事项

- 工业上位机通常运行在工控机上，屏幕亮度可能不高，确保文字和重要数据有足够的对比度。
- 颜色不要超过 5~6 种，过多的颜色会让人眼花缭乱。
- 报警颜色（红色）应保持全局一致，不能在不同地方使用不同深浅的红色。

### 练习建议

1. 浏览几个知名 SCADA/HMI 软件的界面截图（如 WinCC、iFIX、Ignition），分析它们的配色方案和布局特点。
2. 使用取色工具提取你喜欢的上位机界面的主色调、背景色、强调色。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 界面花哨不专业 | 使用了过多的颜色和装饰 | 限制颜色数量，减少装饰 |
| 数据看不清 | 文字颜色与背景对比度不足 | 确保对比度 >= 4.5:1 |
| 风格不统一 | 不同页面使用不同的字体和颜色 | 制定统一的 UI 规范 |

## 2. 圆角控件实现

### 知识讲解

圆角是现代 UI 设计的标志性特征。WinForms 默认的控件都是方角，通过 `Region` 属性或自定义绘制可以实现圆角效果。

**实现方式：**

| 方式 | 原理 | 适用场景 |
|------|------|---------|
| `Region` 裁剪 | 设置控件的可见区域为圆角路径 | Panel、Button、GroupBox 等容器 |
| `OnPaint` 绘制 | 在自定义控件中绘制圆角矩形 | 完全自定义的控件 |
| `Paint` 事件 | 在现有控件的 Paint 事件中绘制 | 快速美化现有控件 |

### 代码示例

```csharp
using System;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.Windows.Forms;

namespace PlcMonitorApp.UI
{
    /// <summary>
    /// 圆角 Panel 控件
    /// 通过 Region 属性实现圆角裁剪
    /// </summary>
    public class RoundedPanel : Panel
    {
        private int _cornerRadius = 8;

        [Description("圆角半径")]
        [DefaultValue(8)]
        [Category("外观")]
        public int CornerRadius
        {
            get => _cornerRadius;
            set
            {
                _cornerRadius = Math.Max(0, Math.Min(value, Math.Min(this.Width, this.Height) / 2));
                UpdateRegion();
            }
        }

        private Color _borderColor = Color.FromArgb(220, 220, 220);
        private float _borderWidth = 1;

        [Description("边框颜色")]
        [Category("外观")]
        public Color BorderColor
        {
            get => _borderColor;
            set { _borderColor = value; Invalidate(); }
        }

        public RoundedPanel()
        {
            this.DoubleBuffered = true;
        }

        protected override void OnResize(EventArgs e)
        {
            base.OnResize(e);
            UpdateRegion();
        }

        protected override void OnPaint(PaintEventArgs e)
        {
            base.OnPaint(e);
            var g = e.Graphics;
            g.SmoothingMode = SmoothingMode.AntiAlias;

            // 绘制圆角边框
            if (_borderWidth > 0)
            {
                using (var pen = new Pen(_borderColor, _borderWidth))
                {
                    using (var path = CreateRoundedRectPath(
                        _borderWidth / 2, _borderWidth / 2,
                        this.ClientSize.Width - _borderWidth,
                        this.ClientSize.Height - _borderWidth,
                        _cornerRadius))
                    {
                        g.DrawPath(pen, path);
                    }
                }
            }
        }

        /// <summary>
        /// 更新控件 Region（裁剪区域）
        /// </summary>
        private void UpdateRegion()
        {
            if (this.Width <= 0 || this.Height <= 0) return;

            using (var path = CreateRoundedRectPath(0, 0, this.ClientSize.Width, this.ClientSize.Height, _cornerRadius))
            {
                this.Region = new Region(path);
            }
            Invalidate();
        }

        private GraphicsPath CreateRoundedRectPath(float x, float y, float w, float h, float r)
        {
            var path = new GraphicsPath();
            r = Math.Min(r, Math.Min(w, h) / 2);

            if (r <= 0)
            {
                path.AddRectangle(new RectangleF(x, y, w, h));
            }
            else
            {
                path.AddArc(x, y, r * 2, r * 2, 180, 90);
                path.AddArc(x + w - r * 2, y, r * 2, r * 2, 270, 90);
                path.AddArc(x + w - r * 2, y + h - r * 2, r * 2, r * 2, 0, 90);
                path.AddArc(x, y + h - r * 2, r * 2, r * 2, 90, 90);
                path.CloseFigure();
            }
            return path;
        }
    }

    /// <summary>
    /// 圆角按钮控件
    /// </summary>
    public class RoundedButton : Button
    {
        private int _cornerRadius = 6;
        private Color _hoverColor = Color.FromArgb(0, 120, 215);

        [Description("圆角半径")]
        [DefaultValue(6)]
        [Category("外观")]
        public int CornerRadius
        {
            get => _cornerRadius;
            set { _cornerRadius = value; UpdateRegion(); }
        }

        [Description("悬停颜色")]
        [Category("外观")]
        public Color HoverColor
        {
            get => _hoverColor;
            set { _hoverColor = value; }
        }

        public RoundedButton()
        {
            this.FlatStyle = FlatStyle.Flat;
            this.FlatAppearance.BorderSize = 0;
            this.FlatAppearance.MouseOverBackColor = _hoverColor;
            this.DoubleBuffered = true;
            this.Size = new Size(100, 35);
            this.BackColor = Color.FromArgb(0, 153, 255);
            this.ForeColor = Color.White;
            this.Cursor = Cursors.Hand;
            this.Font = new Font("微软雅黑", 9);
        }

        protected override void OnResize(EventArgs e)
        {
            base.OnResize(e);
            UpdateRegion();
        }

        private void UpdateRegion()
        {
            using (var path = new GraphicsPath())
            {
                int r = Math.Min(_cornerRadius, Math.Min(this.Width, this.Height) / 2);
                path.AddArc(0, 0, r * 2, r * 2, 180, 90);
                path.AddArc(this.Width - r * 2, 0, r * 2, r * 2, 270, 90);
                path.AddArc(this.Width - r * 2, this.Height - r * 2, r * 2, r * 2, 0, 90);
                path.AddArc(0, this.Height - r * 2, r * 2, r * 2, 90, 90);
                path.CloseFigure();
                this.Region = new Region(path);
            }
        }
    }
}
```

### 注意事项

- **Region 裁剪的局限性**：设置 Region 后，控件的某些区域将不可见（被裁剪掉）。如果子控件靠近边缘，可能会被部分裁剪。
- **Resize 时更新 Region**：控件大小改变时必须重新计算 Region，否则圆角不正确。
- **Region 与 OnPaint 的配合**：Region 负责裁剪形状，OnPaint 负责绘制边框和背景，两者配合使用效果最好。

### 练习建议

1. 创建一个 `RoundedPanel`，设置 `CornerRadius = 10`，在内部放置几个 Label 和 TextBox，观察圆角效果。
2. 创建一个 `RoundedButton`，测试不同 `CornerRadius` 值的效果（0=方角，20=大圆角）。
3. 实现窗体本身的圆角效果（通过 Form 的 Region 属性）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 调整大小后圆角消失 | 未在 Resize 事件中更新 Region | 在 OnResize 中调用 UpdateRegion() |
| 子控件被裁剪 | Region 裁剪了子控件所在区域 | 增加 Padding 留出圆角空间 |
| Region 报异常 | Width 或 Height 为 0 时创建路径 | 添加尺寸检查 |

## 3. 颜色主题系统

### 知识讲解

颜色主题系统是一套统一管理界面颜色的方案，支持一键切换亮色/暗色主题。对于上位机软件，暗色主题更适合长时间盯屏幕的操作员（减少眼睛疲劳）。

### 代码示例

```csharp
namespace PlcMonitorApp.UI
{
    /// <summary>
    /// 颜色主题定义
    /// </summary>
    public static class ThemeManager
    {
        #region ===== 主题颜色定义 =====

        // 亮色主题
        public static readonly ThemeColors LightTheme = new ThemeColors
        {
            Name = "亮色",
            IsDark = false,

            // 背景颜色
            FormBackColor       = Color.FromArgb(240, 240, 245),
            PanelBackColor      = Color.White,
            GroupBoxBackColor   = Color.White,
            ControlBackColor   = Color.White,
            TextBoxBackColor    = Color.White,
            DataGridViewBgColor = Color.White,

            // 文字颜色
            PrimaryText         = Color.FromArgb(50, 50, 50),
            SecondaryText       = Color.FromArgb(100, 100, 100),
            DisabledText        = Color.FromArgb(180, 180, 180),

            // 表头
            HeaderBackColor     = Color.FromArgb(45, 45, 55),
            HeaderForeColor     = Color.White,

            // 强调色
            PrimaryAccent       = Color.FromArgb(0, 153, 255),    // 主色：蓝色
            SuccessColor        = Color.FromArgb(0, 180, 0),      // 成功：绿色
            WarningColor        = Color.FromArgb(255, 165, 0),    // 警告：橙色
            ErrorColor          = Color.FromArgb(220, 50, 50),    // 错误：红色
            InfoColor           = Color.FromArgb(0, 120, 215),    // 信息：蓝色

            // 边框
            BorderColor         = Color.FromArgb(220, 220, 220),
            GridColor           = Color.FromArgb(235, 235, 235),

            // 交替行
            AlternatingRowColor  = Color.FromArgb(245, 245, 250),
        };

        // 暗色主题
        public static readonly ThemeColors DarkTheme = new ThemeColors
        {
            Name = "暗色",
            IsDark = true,

            FormBackColor       = Color.FromArgb(30, 30, 40),
            PanelBackColor      = Color.FromArgb(40, 40, 55),
            GroupBoxBackColor   = Color.FromArgb(40, 40, 55),
            ControlBackColor    = Color.FromArgb(50, 50, 65),
            TextBoxBackColor    = Color.FromArgb(45, 45, 60),
            DataGridViewBgColor = Color.FromArgb(30, 30, 40),

            PrimaryText         = Color.FromArgb(220, 220, 220),
            SecondaryText       = Color.FromArgb(160, 160, 160),
            DisabledText        = Color.FromArgb(100, 100, 100),

            HeaderBackColor     = Color.FromArgb(55, 55, 75),
            HeaderForeColor     = Color.FromArgb(220, 220, 220),

            PrimaryAccent       = Color.FromArgb(0, 153, 255),
            SuccessColor        = Color.FromArgb(0, 200, 80),
            WarningColor        = Color.FromArgb(255, 180, 0),
            ErrorColor          = Color.FromArgb(255, 70, 70),
            InfoColor           = Color.FromArgb(80, 160, 255),

            BorderColor         = Color.FromArgb(70, 70, 90),
            GridColor           = Color.FromArgb(50, 50, 70),

            AlternatingRowColor  = Color.FromArgb(35, 35, 48),
        };

        #endregion

        // 当前主题
        private static ThemeColors _currentTheme = DarkTheme;  // 默认暗色主题

        /// <summary>当前主题</summary>
        public static ThemeColors Current => _currentTheme;

        /// <summary>主题切换事件</summary>
        public static event Action<ThemeColors> ThemeChanged;

        /// <summary>
        /// 切换主题
        /// </summary>
        public static void SwitchTheme(bool dark)
        {
            _currentTheme = dark ? DarkTheme : LightTheme;
            ThemeChanged?.Invoke(_currentTheme);
        }

        /// <summary>
        /// 切换到指定主题
        /// </summary>
        public static void ApplyTheme(ThemeColors theme)
        {
            _currentTheme = theme;
            ThemeChanged?.Invoke(_currentTheme);
        }
    }

    /// <summary>
    /// 主题颜色集合
    /// </summary>
    public class ThemeColors
    {
        public string Name { get; set; }
        public bool IsDark { get; set; }

        // 背景
        public Color FormBackColor { get; set; }
        public Color PanelBackColor { get; set; }
        public Color GroupBoxBackColor { get; set; }
        public Color ControlBackColor { get; set; }
        public Color TextBoxBackColor { get; set; }
        public Color DataGridViewBgColor { get; set; }

        // 文字
        public Color PrimaryText { get; set; }
        public Color SecondaryText { get; set; }
        public Color DisabledText { get; set; }

        // 表头
        public Color HeaderBackColor { get; set; }
        public Color HeaderForeColor { get; set; }

        // 强调色
        public Color PrimaryAccent { get; set; }
        public Color SuccessColor { get; set; }
        public Color WarningColor { get; set; }
        public Color ErrorColor { get; set; }
        public Color InfoColor { get; set; }

        // 边框
        public Color BorderColor { get; set; }
        public Color GridColor { get; set; }

        // 交替行
        public Color AlternatingRowColor { get; set; }
    }

    /// <summary>
    /// 主题应用扩展方法
    /// 将主题颜色应用到常用控件
    /// </summary>
    public static class ThemeExtensions
    {
        /// <summary>
        /// 将主题应用到窗体
        /// </summary>
        public static void ApplyTheme(this Form form)
        {
            var theme = ThemeManager.Current;

            form.BackColor = theme.FormBackColor;
            form.ForeColor = theme.PrimaryText;
            form.Font = new Font("微软雅黑", 9);

            // 递归应用到所有子控件
            ApplyThemeToControls(form.Controls, theme);
        }

        /// <summary>
        /// 递归应用主题到控件集合
        /// </summary>
        private static void ApplyThemeToControls(Control.ControlCollection controls, ThemeColors theme)
        {
            foreach (Control ctrl in controls)
            {
                switch (ctrl)
                {
                    case Panel panel:
                        panel.BackColor = theme.PanelBackColor;
                        break;

                    case GroupBox grp:
                        grp.BackColor = theme.GroupBoxBackColor;
                        grp.ForeColor = theme.PrimaryText;
                        break;

                    case TextBox txt:
                        txt.BackColor = theme.TextBoxBackColor;
                        txt.ForeColor = theme.PrimaryText;
                        txt.BorderStyle = BorderStyle.FixedSingle;
                        break;

                    case ComboBox cmb:
                        cmb.BackColor = theme.ControlBackColor;
                        cmb.ForeColor = theme.PrimaryText;
                        break;

                    case Button btn:
                        // 按钮保持自身颜色，不做主题化
                        break;

                    case Label lbl:
                        lbl.BackColor = Color.Transparent;
                        lbl.ForeColor = theme.PrimaryText;
                        break;

                    case CheckBox chk:
                        chk.BackColor = Color.Transparent;
                        chk.ForeColor = theme.PrimaryText;
                        break;

                    case RadioButton rdo:
                        rdo.BackColor = Color.Transparent;
                        rdo.ForeColor = theme.PrimaryText;
                        break;

                    case DataGridView dgv:
                        ApplyThemeToDataGridView(dgv, theme);
                        break;

                    case TreeView tree:
                        tree.BackColor = theme.PanelBackColor;
                        tree.ForeColor = theme.PrimaryText;
                        tree.BorderStyle = BorderStyle.None;
                        tree.LineColor = theme.BorderColor;
                        break;

                    case ListView lv:
                        lv.BackColor = theme.PanelBackColor;
                        lv.ForeColor = theme.PrimaryText;
                        break;

                    case TabControl tab:
                        ApplyThemeToTabControl(tab, theme);
                        break;

                    case StatusStrip _:
                    case MenuStrip _:
                    case ToolStrip _:
                        // 菜单和状态栏需要特殊处理
                        break;
                }

                // 递归处理子控件
                if (ctrl.HasChildren)
                {
                    ApplyThemeToControls(ctrl.Controls, theme);
                }
            }
        }

        /// <summary>
        /// 应用主题到 DataGridView
        /// </summary>
        private static void ApplyThemeToDataGridView(DataGridView dgv, ThemeColors theme)
        {
            dgv.BackgroundColor = theme.DataGridViewBgColor;
            dgv.GridColor = theme.GridColor;
            dgv.DefaultCellStyle.BackColor = theme.PanelBackColor;
            dgv.DefaultCellStyle.ForeColor = theme.PrimaryText;
            dgv.DefaultCellStyle.SelectionBackColor = theme.PrimaryAccent;
            dgv.DefaultCellStyle.SelectionForeColor = Color.White;
            dgv.AlternatingRowsDefaultCellStyle.BackColor = theme.AlternatingRowColor;
            dgv.ColumnHeadersDefaultCellStyle.BackColor = theme.HeaderBackColor;
            dgv.ColumnHeadersDefaultCellStyle.ForeColor = theme.HeaderForeColor;
            dgv.EnableHeadersVisualStyles = false;
            dgv.BorderStyle = BorderStyle.None;
        }

        /// <summary>
        /// 应用主题到 TabControl
        /// </summary>
        private static void ApplyThemeToTabControl(TabControl tab, ThemeColors theme)
        {
            // TabControl 的 OwnerDrawFixed 模式可以自定义绘制选项卡
            tab.DrawMode = TabDrawMode.OwnerDrawFixed;
            tab.Paint += (s, e) =>
            {
                // 绘制选项卡背景
                for (int i = 0; i < tab.TabPages.Count; i++)
                {
                    var tabPage = tab.TabPages[i];
                    var rect = tab.GetTabRect(i);

                    using (var brush = new SolidBrush(
                        i == tab.SelectedIndex ? theme.PanelBackColor : theme.FormBackColor))
                    {
                        e.Graphics.FillRectangle(brush, rect);
                    }

                    // 绘制选项卡文字
                    using (var font = new Font("微软雅黑", 9))
                    using (var brush = new SolidBrush(
                        i == tab.SelectedIndex ? theme.PrimaryText : theme.SecondaryText))
                    using (var format = new StringFormat { Alignment = StringAlignment.Center, LineAlignment = StringAlignment.Center })
                    {
                        e.Graphics.DrawString(tabPage.Text, font, brush, rect, format);
                    }
                }
            };
        }
    }
}
```

### 注意事项

- **主题切换时机**：建议在窗体的 `Load` 事件中应用主题，并在程序运行中通过菜单项切换。
- **递归应用**：使用递归遍历所有子控件，确保嵌套容器内的控件也被应用主题。
- **按钮特殊处理**：按钮通常有自己的设计颜色（如蓝色连接按钮、绿色开始按钮），不应被主题覆盖。
- **OwnerDraw 模式**：TabControl 和 MenuStrip 需要使用 OwnerDraw 模式才能完全自定义外观。

### 练习建议

1. 创建一个简单的主题切换功能（菜单项「亮色主题」/「暗色主题」），切换后所有控件颜色同步更新。
2. 在 DataGridView 上测试亮色和暗色主题的效果。
3. 添加一个自定义主题颜色（如「蓝色主题」），通过 `ThemeColors` 类定义并切换。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 部分控件颜色未变 | 递归遗漏了某些控件类型 | 检查 switch-case 是否覆盖所有控件类型 |
| 切换后闪烁严重 | 主题应用过程中频繁重绘 | 使用 SuspendLayout/ResumeLayout |

## 4. 渐变背景效果

### 知识讲解

渐变背景可以让界面更有层次感和专业感。GDI+ 提供了 `LinearGradientBrush`（线性渐变）和 `PathGradientBrush`（路径渐变）两种渐变画刷。

### 代码示例

```csharp
/// <summary>
/// 渐变背景绘制示例
/// </summary>
public class GradientPanel : Panel
{
    public enum GradientType
    {
        Vertical,        // 垂直渐变（从上到下）
        Horizontal,      // 水平渐变（从左到右）
        Diagonal,        // 对角线渐变
        Radial           // 径向渐变
    }

    private GradientType _gradientType = GradientType.Vertical;
    private Color _startColor = Color.FromArgb(0, 120, 215);
    private Color _endColor = Color.FromArgb(0, 200, 255);

    public GradientType Type
    {
        get => _gradientType;
        set { _gradientType = value; Invalidate(); }
    }

    public Color StartColor
    {
        get => _startColor;
        set { _startColor = value; Invalidate(); }
    }

    public Color EndColor
    {
        get => _endColor;
        set { _endColor = value; Invalidate(); }
    }

    public GradientPanel()
    {
        this.DoubleBuffered = true;
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        base.OnPaint(e);
        var g = e.Graphics;

        using (var brush = CreateGradientBrush(this.ClientRectangle))
        {
            g.FillRectangle(brush, this.ClientRectangle);
        }
    }

    private Brush CreateGradientBrush(Rectangle rect)
    {
        switch (_gradientType)
        {
            case GradientType.Vertical:
                return new LinearGradientBrush(rect, _startColor, _endColor, LinearGradientMode.Vertical);

            case GradientType.Horizontal:
                return new LinearGradientBrush(rect, _startColor, _endColor, LinearGradientMode.Horizontal);

            case GradientType.Diagonal:
                return new LinearGradientBrush(rect, _startColor, _endColor, LinearGradientMode.ForwardDiagonal);

            case GradientType.Radial:
                // 径向渐变需要使用 PathGradientBrush
                using (var path = new GraphicsPath())
                {
                    path.AddEllipse(rect);
                    var radialBrush = new PathGradientBrush(path);
                    radialBrush.CenterColor = _startColor;
                    radialBrush.SurroundColors = new[] { _endColor };
                    return radialBrush;
                }

            default:
                return new SolidBrush(_startColor);
        }
    }
}
```

### 注意事项

- **性能**：渐变绘制比纯色填充消耗更多性能，建议对大面积区域使用简单的线性渐变，避免复杂的径向渐变。
- **线性渐变模式**：`Vertical`（垂直）、`Horizontal`（水平）、`ForwardDiagonal`（左上到右下）、`BackwardDiagonal`（右上到左下）。

### 练习建议

1. 创建一个 `GradientPanel`，设置垂直渐变背景（深蓝到浅蓝），在上方放置标题文字。
2. 实现对角线渐变背景效果。
3. 创建一个标题栏，使用渐变背景 + 白色文字。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 渐变方向不对 | LinearGradientMode 设置错误 | 选择正确的渐变模式 |

## 5. 阴影效果

### 知识讲解

阴影效果可以给控件增加立体感和层次感，让界面看起来更现代。WinForms 中通过绘制偏移的半透明图形来模拟阴影。

### 代码示例

```csharp
/// <summary>
    /// 阴影绘制辅助类
    /// </summary>
    public static class ShadowHelper
    {
        /// <summary>
        /// 绘制矩形阴影
        /// </summary>
        public static void DrawRectangleShadow(Graphics g, Rectangle rect, int offset, int blur)
        {
            // 绘制多层半透明矩形模拟模糊阴影
            for (int i = blur; i >= 1; i--)
            {
                int alpha = (int)(30.0 / i);  // 越外层越透明
                using (var brush = new SolidBrush(Color.FromArgb(alpha, 0, 0, 0)))
                {
                    var shadowRect = new Rectangle(
                        rect.X + offset + i, rect.Y + offset + i,
                        rect.Width, rect.Height);
                    g.FillRectangle(brush, shadowRect);
                }
            }
        }

        /// <summary>
        /// 绘制圆角矩形阴影
        /// </summary>
        public static void DrawRoundedShadow(Graphics g, Rectangle rect, int radius, int offset, int blur)
        {
            for (int i = blur; i >= 1; i--)
            {
                int alpha = (int)(25.0 / i);
                using (var brush = new SolidBrush(Color.FromArgb(alpha, 0, 0, 0)))
                {
                    var shadowRect = new Rectangle(
                        rect.X + offset + i, rect.Y + offset + i,
                        rect.Width, rect.Height);

                    using (var path = CreateRoundedRectPath(
                        shadowRect.X, shadowRect.Y, shadowRect.Width, shadowRect.Height, radius))
                    {
                        g.FillPath(brush, path);
                    }
                }
            }
        }

        /// <summary>
        /// 绘制文字阴影
        /// </summary>
        public static void DrawTextWithShadow(Graphics g, string text, Font font, RectangleF rect,
            Color textColor, Color shadowColor, int offsetX, int offsetY)
        {
            using (var format = new StringFormat { Alignment = StringAlignment.Center, LineAlignment = StringAlignment.Center })
            {
                // 先绘制阴影
                using (var shadowBrush = new SolidBrush(shadowColor))
                {
                    var shadowRect = new RectangleF(rect.X + offsetX, rect.Y + offsetY, rect.Width, rect.Height);
                    g.DrawString(text, font, shadowBrush, shadowRect, format);
                }

                // 再绘制文字
                using (var textBrush = new SolidBrush(textColor))
                {
                    g.DrawString(text, font, textBrush, rect, format);
                }
            }
        }

        private static GraphicsPath CreateRoundedRectPath(float x, float y, float w, float h, float r)
        {
            var path = new GraphicsPath();
            r = Math.Min(r, Math.Min(w, h) / 2);
            if (r <= 0) { path.AddRectangle(new RectangleF(x, y, w, h)); }
            else
            {
                path.AddArc(x, y, r * 2, r * 2, 180, 90);
                path.AddArc(x + w - r * 2, y, r * 2, r * 2, 270, 90);
                path.AddArc(x + w - r * 2, y + h - r * 2, r * 2, r * 2, 0, 90);
                path.AddArc(x, y + h - r * 2, r * 2, r * 2, 90, 90);
                path.CloseFigure();
            }
            return path;
        }
    }
}
```

### 注意事项

- 阴影绘制需要在目标控件**之前**绘制（先画阴影，再画控件），否则阴影会被覆盖。
- 阴影层数越多，模糊效果越自然，但性能消耗也越大。建议不超过 5 层。
- 阴影的偏移量和模糊半径应根据控件大小调整，小控件用小阴影。

### 练习建议

1. 在一个 `RoundedPanel` 的 `OnPaint` 中先绘制阴影，再绘制面板背景和边框。
2. 为标题 Label 添加文字阴影效果。
3. 创建一个悬浮卡片效果：白色圆角面板 + 阴影。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 阴影被控件覆盖 | 阴影绘制在控件之后 | 先绘制阴影，再绘制控件内容 |
| 阴影太重/太轻 | 透明度设置不当 | 调整 Alpha 值（推荐 10~40） |

## 6. 字体选择

### 知识讲解

合理的字体选择对上位机界面的专业度影响很大。不同的文字类型应该使用不同的字体。

**推荐字体：**

| 用途 | 推荐字体 | 说明 |
|------|---------|------|
| UI 文字 | 微软雅黑 | Windows 系统自带，清晰易读 |
| 数据显示 | Consolas / JetBrains Mono | 等宽字体，数据对齐整齐 |
| 标题 | 微软雅黑 Bold | 粗体突出 |
| 英文/代码 | Segoe UI / Consolas | Windows 系统字体 |
| 日志区 | Consolas / Courier New | 等宽字体适合日志 |

**字号建议：**

| 元素 | 推荐字号 |
|------|---------|
| 窗体标题 | 10~12pt Bold |
| 正文 | 9pt |
| 数据值 | 10~12pt Bold |
| 辅助文字 | 8pt |
| 表头 | 9pt Bold |
| 状态栏 | 8~9pt |

### 注意事项

- 使用系统自带字体（微软雅黑、Consolas），避免使用需要额外安装的字体。
- 数据显示务必使用等宽字体，确保数字对齐。
- 在代码中统一管理字体，避免每个控件单独设置字体（方便全局修改）。

### 练习建议

1. 统一窗体的字体为「微软雅黑 9pt」，日志区字体为「Consolas 9pt」。
2. 对比 Consolas 和微软雅黑显示数据的效果差异。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 数据不对齐 | 使用了非等宽字体 | 数据值使用 Consolas 等等宽字体 |
| 字体显示不一致 | 部分控件未设置字体 | 在窗体级别设置 Font 属性 |

## 7. 图标与图片资源管理

### 知识讲解

图标是界面美化的重要组成部分。WinForms 支持将图片嵌入到程序资源中，避免外部文件依赖。

**图标获取途径：**

| 途径 | 说明 |
|------|------|
| 系统图标 | `System.Drawing.SystemIcons` |
| 内嵌资源 | 项目 Resources.resx |
| 图标库 | Font Awesome、Material Icons、Fluent UI Icons |
| 自制 | 使用绘图工具制作（如 Figma、Illustrator） |

### 代码示例

```csharp
/// <summary>
/// 图标资源管理
/// </summary>
public static class IconManager
{
    /// <summary>
    /// 从资源文件加载图标
    /// </summary>
    public static Image GetIcon(string name)
    {
        return Properties.Resources.ResourceManager.GetObject(name) as Image;
    }

    /// <summary>
    /// 创建纯色圆形图标（运行时生成）
    /// </summary>
    public static Bitmap CreateCircleIcon(Color color, int size = 16)
    {
        var bmp = new Bitmap(size, size);
        using (var g = Graphics.FromImage(bmp))
        using (var brush = new SolidBrush(color))
        {
            g.SmoothingMode = SmoothingMode.AntiAlias;
            g.FillEllipse(brush, 0, 0, size, size);
        }
        return bmp;
    }

    /// <summary>
    /// 创建带文字的图标
    /// </summary>
    public static Bitmap CreateTextIcon(string text, Color bgColor, Color textColor, int size = 32)
    {
        var bmp = new Bitmap(size, size);
        using (var g = Graphics.FromImage(bmp))
        {
            g.SmoothingMode = SmoothingMode.AntiAlias;
            g.TextRenderingHint = System.Drawing.Text.TextRenderingHint.ClearTypeGridFit;

            // 圆形背景
            using (var bgBrush = new SolidBrush(bgColor))
            {
                g.FillEllipse(bgBrush, 0, 0, size, size);
            }

            // 文字
            using (var font = new Font("微软雅黑", size / 3, FontStyle.Bold))
            using (var textBrush = new SolidBrush(textColor))
            using (var format = new StringFormat { Alignment = StringAlignment.Center, LineAlignment = StringAlignment.Center })
            {
                g.DrawString(text, font, textBrush, new RectangleF(0, 0, size, size), format);
            }
        }
        return bmp;
    }
}
```

### 注意事项

- 嵌入到 Resources.resx 中的图片会随程序编译到 DLL 中，不依赖外部文件。
- 运行时生成的图标（如圆形 LED 图标）适合简单的状态指示，复杂图标应使用预制的 PNG/SVG。
- 图标大小建议使用 16x16（工具栏）、24x24（菜单）、32x32（大按钮）三种规格。

### 练习建议

1. 将几个常用的图标（连接、断开、开始、停止）添加到项目资源中，在按钮上显示。
2. 使用 `CreateCircleIcon` 方法动态生成不同颜色的圆形图标。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 运行时找不到图标 | 资源名称拼写错误 | 检查 Resources.resx 中的资源名称 |
| 图标模糊 | 位图尺寸不够（缩放导致） | 使用足够大的图标（如 32x32） |

## 8. WinForms 中实现流畅动画

### 知识讲解

WinForms 中实现动画的核心是使用 `System.Windows.Forms.Timer`，在每次 Tick 中更新动画参数（如位置、透明度、角度），然后调用 `Invalidate()` 触发重绘。

**常用插值算法：**

| 算法 | 特点 | 适用场景 |
|------|------|---------|
| 线性插值 | 匀速运动 | 简单的数值变化 |
| 缓动插值（EaseOut） | 开始快、结束慢 | 仪表指针、进度条 |
| 缓入插值（EaseIn） | 开始慢、结束快 | 弹出效果 |
| 缓入缓出（EaseInOut） | 两端慢、中间快 | 通用动画 |

### 代码示例

```csharp
/// <summary>
/// 缓动函数工具类
/// </summary>
public static class EasingFunctions
{
    /// <summary>线性（匀速）</summary>
    public static double Linear(double t) => t;

    /// <summary>缓出（开始快，结束慢）—— 最常用</summary>
    public static double EaseOutQuad(double t) => 1 - (1 - t) * (1 - t);

    /// <summary>缓入（开始慢，结束快）</summary>
    public static double EaseInQuad(double t) => t * t;

    /// <summary>缓入缓出</summary>
    public static double EaseInOutCubic(double t)
    {
        return t < 0.5 ? 4 * t * t * t : 1 - Math.Pow(-2 * t + 2, 3) / 2;
    }

    /// <summary>弹性效果</summary>
    public static double EaseOutElastic(double t)
    {
        if (t == 0 || t == 1) return t;
        return Math.Pow(2, -10 * t) * Math.Sin((t * 10 - 0.75) * (2 * Math.PI / 3)) + 1;
    }
}

/// <summary>
/// 动画控件示例 —— 淡入淡出
/// </summary>
public class FadePanel : Panel
{
    private double _opacity = 1.0;
    private System.Windows.Forms.Timer _fadeTimer;

    public FadePanel()
    {
        this.DoubleBuffered = true;
        _fadeTimer = new System.Windows.Forms.Timer { Interval = 16 };
        _fadeTimer.Tick += FadeTimer_Tick;
    }

    /// <summary>
    /// 淡入
    /// </summary>
    public void FadeIn(int durationMs = 500)
    {
        _fadeTimer.Stop();
        int frames = durationMs / 16;
        _fadeTimer.Tag = new { Target = 1.0, Step = 1.0 / frames };
        _fadeTimer.Start();
    }

    /// <summary>
    /// 淡出
    /// </summary>
    public void FadeOut(int durationMs = 500)
    {
        _fadeTimer.Stop();
        int frames = durationMs / 16;
        _fadeTimer.Tag = new { Target = 0.0, Step = 1.0 / frames };
        _fadeTimer.Start();
    }

    private void FadeTimer_Tick(object sender, EventArgs e)
    {
        var anim = (dynamic)_fadeTimer.Tag;

        if (_opacity < anim.Target)
            _opacity = Math.Min(anim.Target, _opacity + anim.Step);
        else
            _opacity = Math.Max(anim.Target, _opacity - anim.Step);

        Invalidate();

        if (Math.Abs(_opacity - anim.Target) < 0.01)
        {
            _opacity = anim.Target;
            _fadeTimer.Stop();
        }
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        var g = e.Graphics;

        // 绘制半透明内容
        using (var matrix = new System.Drawing.Drawing2D.Matrix())
        {
            matrix.Scale(1, 1);
            g.Transform = matrix;
        }

        // 先绘制所有子控件到内存位图
        using (var bmp = new Bitmap(this.ClientSize.Width, this.ClientSize.Height))
        using (var memG = Graphics.FromImage(bmp))
        {
            // 绘制背景
            using (var bgBrush = new SolidBrush(this.BackColor))
            {
                memG.FillRectangle(bgBrush, 0, 0, bmp.Width, bmp.Height);
            }

            // 将子控件绘制到位图
            this.InvokePaint(this, new PaintEventArgs(memG, this.ClientRectangle));

            // 按透明度将位图绘制到控件
            using (var imgAttr = new System.Drawing.Imaging.ImageAttributes())
            {
                var cm = new System.Drawing.Imaging.ColorMatrix
                {
                    Matrix00 = 1,  // R
                    Matrix11 = 1,  // G
                    Matrix22 = 1,  // B
                    Matrix33 = (float)_opacity,  // Alpha
                    Matrix44 = 1   // w
                };
                imgAttr.SetColorMatrix(cm);
                g.DrawImage(bmp, this.ClientRectangle, 0, 0, bmp.Width, bmp.Height,
                    GraphicsUnit.Pixel, imgAttr);
            }
        }
    }
}
```

### 注意事项

- **Timer 间隔 16ms**：约 60FPS，是流畅动画的标准帧率。
- **缓动函数**：使用缓动函数可以让动画更自然。`EaseOut`（先快后慢）是最常用的效果。
- **ColorMatrix 透明度**：通过 `ImageAttributes.SetColorMatrix` 可以实现控件的半透明效果。
- **性能**：动画控件的 `OnPaint` 中避免复杂的计算，预计算好参数。

### 练习建议

1. 创建一个面板，点击按钮时执行淡入淡出动画（500ms）。
2. 使用 `EaseOutQuad` 缓动函数实现数值从 0 变到 100 的动画。
3. 在仪表盘控件中使用缓动函数替代简单的线性插值。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 动画卡顿 | Timer 间隔太大或 OnPaint 中有耗时操作 | 间隔设为 16ms，OnPaint 保持轻量 |
| 动画结束后还在跑 | 停止条件判断不正确 | 使用绝对值判断差距是否足够小 |

```csharp
            // 压力仪表
            var gaugePressure = new GaugeControl
            {
                Size = new Size(180, 130),
                Label = "压力",
                Unit = "MPa",
                Minimum = 0, Maximum = 5,
                Value = 2.8
            };

            // 转速仪表
            var gaugeRpm = new GaugeControl
            {
                Size = new Size(180, 130),
                Label = "转速",
                Unit = "RPM",
                Minimum = 0, Maximum = 3000,
                Value = 1500
            };

            gaugeFlow.Controls.AddRange(new Control[] { gaugeTemp, gaugePressure, gaugeRpm });
            rightPanel.Controls.Add(gaugeFlow);

            split.Panel2.Controls.Add(rightPanel);

            return split;
        }

        /// <summary>
        /// 主题切换事件处理
        /// </summary>
        private void OnThemeChanged(ThemeColors theme)
        {
            // 重新应用主题到所有控件
            this.Invoke(new Action(() =>
            {
                this.SuspendLayout();
                this.ApplyTheme();
                this.ResumeLayout(true);
            }));
        }
    }
}
```

### 注意事项

- 主题切换时使用 `SuspendLayout` / `ResumeLayout` 包裹，减少闪烁。
- `Invoke` 确保在 UI 线程上执行主题切换。
- 自定义控件（如 `LedIndicator`、`GaugeControl`）的主题适配需要在控件内部读取 `ThemeManager.Current`。

### 练习建议

1. 完整实现本案例代码，测试亮色/暗色主题的切换效果。
2. 在主题中添加第三个主题（如「蓝色科技风」）。
3. 为 GaugeControl 添加主题支持（深色主题下使用深色背景）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 切换主题后部分控件未变色 | 递归应用遗漏了某些控件 | 检查所有控件类型是否都已覆盖 |
| 切换时界面闪烁 | 未使用 SuspendLayout | 用 SuspendLayout/ResumeLayout 包裹 |

## 总结

本章学习了 WinForms 界面美化的核心技术：

| 技术 | 核心方法 | 效果 |
|------|---------|------|
| 圆角控件 | Region 裁剪 + GraphicsPath | 现代、柔和的外观 |
| 主题系统 | ThemeManager + 递归应用 | 一键切换亮色/暗色 |
| 渐变背景 | LinearGradientBrush | 增加层次感和质感 |
| 阴影效果 | 多层半透明图形叠加 | 立体感和浮动效果 |
| 字体选择 | 微软雅黑 + Consolas 组合 | 清晰、专业、数据对齐 |
| 图标管理 | Resources + 动态生成 | 美化按钮和状态指示 |
| 流畅动画 | Timer + 插值算法 | 平滑过渡、丝滑交互 |

**界面美化的核心原则：**
1. 统一性：所有页面使用同一套颜色方案和字体
2. 层次感：通过颜色深浅、大小、间距建立视觉层级
3. 对比度：重要数据与背景有足够对比
4. 适度：装饰服务于功能，不要过度美化
5. 性能：美化的同时注意绘制性能
