## 1. DataGridView 表格控件

### 知识讲解

`DataGridView` 是 WinForms 中最强大的数据显示控件，用于以表格形式展示和编辑数据。在上位机中，它是展示 PLC 寄存器数据、报警记录、历史数据的核心控件。

**常用属性：**

| 属性 | 说明 |
|------|------|
| `Columns` | 列集合 |
| `Rows` | 行集合 |
| `DataSource` | 数据源（支持 List、DataTable、BindingList 等） |
| `ReadOnly` | 是否只读 |
| `AllowUserToAddRows` | 是否允许用户添加行 |
| `SelectionMode` | 选择模式（`FullRowSelect`、`CellSelect`、`ColumnHeaderSelect`） |
| `MultiSelect` | 是否允许多选 |
| `BackgroundColor` | 背景色（空白区域颜色） |
| `GridColor` | 网格线颜色 |
| `RowHeadersVisible` | 是否显示行头 |
| `AutoSizeColumnsMode` | 自动调整列宽模式 |
| `AlternatingRowsDefaultCellStyle` | 交替行样式 |

**列类型：**

| 列类型 | 说明 |
|--------|------|
| `DataGridViewTextBoxColumn` | 文本列（默认） |
| `DataGridViewCheckBoxColumn` | 复选框列 |
| `DataGridViewButtonColumn` | 按钮列 |
| `DataGridViewComboBoxColumn` | 下拉框列 |
| `DataGridViewImageColumn` | 图片列 |
| `DataGridViewLinkColumn` | 链接列 |

**常用事件：**

| 事件 | 说明 |
|------|------|
| `CellFormatting` | 单元格格式化（修改显示内容/样式） |
| `CellClick` | 单击单元格 |
| `CellDoubleClick` | 双击单元格 |
| `SelectionChanged` | 选择变化 |
| `DataError` | 数据绑定错误 |
| `RowPostPaint` | 行绘制后（自定义行号等） |

```csharp
    /// 场景：根据状态值改变文字颜色、根据数值范围高亮显示
    /// </summary>
    private void Dgv_CellFormatting(object sender, DataGridViewCellFormattingEventArgs e)
    {
        var dgv = (DataGridView)sender;

        // 只处理数据行（跳过表头）
        if (e.RowIndex < 0) return;

        // ---- 状态列：根据状态文字改变颜色 ----
        if (dgv.Columns[e.ColumnIndex].Name == "colStatus")
        {
            string status = e.Value?.ToString() ?? "";
            switch (status)
            {
                case "正常":
                    e.CellStyle.ForeColor = Color.Green;
                    e.CellStyle.Font = new Font("微软雅黑", 9, FontStyle.Bold);
                    break;
                case "警告":
                    e.CellStyle.ForeColor = Color.Orange;
                    e.CellStyle.Font = new Font("微软雅黑", 9, FontStyle.Bold);
                    break;
                case "报警":
                    e.CellStyle.ForeColor = Color.Red;

                    e.CellStyle.BackColor = Color.FromArgb(255, 230, 230); // 浅红背景
                    break;
                case "离线":
                    e.CellStyle.ForeColor = Color.Gray;
                    break;

        if (dgv.Columns[e.ColumnIndex].Name == "colValue")
        {
            if (e.Value is double value && value > 80)
            {
                e.CellStyle.ForeColor = Color.Red;
                e.CellStyle.Font = new Font("Consolas", 10, FontStyle.Bold);
            }
        }
    }

    /// <summary>
    /// 使用 BindingList 绑定数据（数据变化时自动更新界面）
    /// </summary>
    private void BindDataWithBindingList()
    {
        var data = new BindingList<RegisterData>
        {
            new RegisterData { Index = 1, Device = "1#PLC", Address = "D100", Value = 45.2, Unit = "°C", Status = "正常" },
            new RegisterData { Index = 2, Device = "1#PLC", Address = "D101", Value = 3.5, Unit = "MPa", Status = "正常" },
            new RegisterData { Index = 3, Device = "1#PLC", Address = "D102", Value = 1200, Unit = "RPM", Status = "警告" },
        };

        var dgv = new DataGridView
        {
            Dock = DockStyle.Fill,
            AutoGenerateColumns = true,   // 自动根据数据模型生成列
            ReadOnly = true
        };

        dgv.DataSource = data;  // 绑定数据源

        // 数据变化时自动更新界面
        data[0].Value = 46.8;  // 界面会自动刷新
        data.Add(new RegisterData { Index = 4, Device = "2#PLC", Address = "D100", Value = 22.1, Unit = "°C", Status = "正常" });
    }
```

### 注意事项

- **虚拟模式（VirtualMode）**：当数据量很大（上万行）时，使用 `VirtualMode = true` + `CellValueNeeded` 事件按需提供数据，避免内存占用过大。
- **冻结列**：使用 `Columns[i].Frozen = true` 可以冻结左侧列，水平滚动时不随之移动。
- **禁止自动排序**：设置 `dgv.SortMode = DataGridViewColumnSortMode.NotSortable` 可以禁止列头的点击排序。
- **性能优化**：大量数据刷新时，先调用 `dgv.SuspendLayout()`，刷新完后调用 `dgv.ResumeLayout()`，避免界面闪烁。

### 练习建议

1. 创建一个 DataGridView，包含序号、设备名称、寄存器地址、当前值、状态五列，实现交替行样式和状态颜色标识。
2. 使用 `BindingList<T>` 绑定数据源，实现数据变化自动刷新界面。
3. 在 CellFormatting 事件中，根据数值列的值动态改变颜色（正常绿色、警告橙色、报警红色）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 绑定数据源后列消失 | AutoGenerateColumns 覆盖了手动创建的列 | 先绑定数据源，再自定义列；或关闭 AutoGenerateColumns |
| 数据更新界面不刷新 | 使用了 List 而不是 BindingList | 使用 `BindingList<T>` 或手动调用 `Refresh()` |
| 大量数据更新时闪烁 | 未使用 SuspendLayout | 更新前 SuspendLayout，更新后 ResumeLayout |

## 2. ListView 列表视图

### 知识讲解

`ListView` 控件以列表形式展示数据，支持多种显示模式。在上位机中常用于显示设备列表、报警记录、通信日志等。

**View 模式：**

| 模式 | 说明 | 典型场景 |
|------|------|---------|
| `LargeIcon` | 大图标 | 设备状态面板 |
| `SmallIcon` | 小图标 | 文件列表 |
| `List` | 列表（无表头） | 简单列表 |
| `Details` | 详细列表（带表头，类似表格） | **上位机中最常用** |
| `Tile` | 平铺视图 | 设备卡片 |

**常用属性：**

| 属性 | 说明 |
|------|------|
| `View` | 显示模式 |
| `Columns` | 列头集合（Details 模式） |
| `Items` | 数据项集合 |
| `FullRowSelect` | 是否整行选择 |
| `GridLines` | 是否显示网格线 |
| `MultiSelect` | 是否允许多选 |
| `CheckBoxes` | 是否显示复选框 |
| `SmallImageList` / `LargeImageList` | 图标列表 |

### 代码示例

```csharp
public partial class ListViewDemo : Form
{
    public ListViewDemo()
    {
        InitializeComponent();
        CreateAlarmListView();
        CreateDeviceListView();
    }

    /// <summary>
    /// 创建报警记录列表（Details 模式）
    /// 场景：上位机报警记录展示
    /// </summary>
    private void CreateAlarmListView()
    {
        var listView = new ListView
        {
            View = View.Details,              // 详细列表模式
            FullRowSelect = true,             // 整行选择
            GridLines = true,                 // 显示网格线
            MultiSelect = false,               // 单选
            BorderStyle = BorderStyle.FixedSingle,
            Location = new Point(10, 10),
            Size = new Size(600, 250),
            Font = new Font("微软雅黑", 9)
        };

        // ====== 添加列头 ======
        listView.Columns.AddRange(new ColumnHeader[]
        {
            new ColumnHeader { Text = "时间",       Width = 130, TextAlign = HorizontalAlignment.Center },
            new ColumnHeader { Text = "级别",       Width = 60,  TextAlign = HorizontalAlignment.Center },
            new ColumnHeader { Text = "设备",       Width = 120, TextAlign = HorizontalAlignment.Left },
            new ColumnHeader { Text = "报警内容",   Width = 200, TextAlign = HorizontalAlignment.Left },
            new ColumnHeader { Text = "当前值",     Width = 80,  TextAlign = HorizontalAlignment.Right },
            new ColumnHeader { Text = "状态",       Width = 80,  TextAlign = HorizontalAlignment.Center }
        });

        // ====== 添加数据 ======
        var alarms = new (string Time, string Level, string Device, string Content, string Value, string Status)[]
        {
            ("2024-01-15 14:32:15", "严重", "1#PLC-主站",  "温度超过上限报警",  "85.6°C",  "未处理"),
            ("2024-01-15 14:30:08", "一般", "2#PLC-从站",  "通信超时",        "--",     "已确认"),
            ("2024-01-15 14:25:33", "警告", "4#PLC-电机",  "转速偏高",        "1200RPM", "未处理"),
            ("2024-01-15 14:20:00", "提示", "3#PLC-温控",  "温度接近上限",     "78.5°C",  "已处理"),
            ("2024-01-15 14:15:22", "严重", "1#PLC-主站",  "通信中断",        "--",     "已恢复"),
        };

        foreach (var (time, level, device, content, value, status) in alarms)
        {
            var item = new ListViewItem(time);  // 第 1 列（SubItems[0]）
            item.SubItems.Add(level);             // 第 2 列
            item.SubItems.Add(device);            // 第 3 列
            item.SubItems.Add(content);           // 第 4 列
            item.SubItems.Add(value);             // 第 5 列
            item.SubItems.Add(status);            // 第 6 列

            // 根据报警级别设置图标颜色（通过字体颜色模拟）
            switch (level)
            {
                case "严重":
                    item.ForeColor = Color.Red;
                    item.Font = new Font("微软雅黑", 9, FontStyle.Bold);
                    break;
                case "一般":
                    item.ForeColor = Color.OrangeRed;
                    break;
                case "警告":
                    item.ForeColor = Color.Orange;
                    break;
                case "提示":
                    item.ForeColor = Color.FromArgb(0, 120, 215);
                    break;
            }

            // 根据状态设置背景色
            if (status == "未处理")
                item.BackColor = Color.FromArgb(255, 245, 230); // 浅橙色背景

            listView.Items.Add(item);
        }

        // ====== 事件 ======
        listView.SelectedIndexChanged += (s, e) =>
        {
            if (listView.SelectedItems.Count > 0)
            {
                var selected = listView.SelectedItems[0];
                LogMessage($"查看报警详情：{selected.SubItems[3].Text}");
            }
        };

        // ====== 双击查看详情 ======
        listView.DoubleClick += (s, e) =>
        {
            if (listView.SelectedItems.Count > 0)
            {
                var selected = listView.SelectedItems[0];
                MessageBox.Show(
                    $"报警详情\n\n" +
                    $"时间：{selected.SubItems[0].Text}\n" +
                    $"级别：{selected.SubItems[1].Text}\n" +
                    $"设备：{selected.SubItems[2].Text}\n" +
                    $"内容：{selected.SubItems[3].Text}\n" +
                    $"当前值：{selected.SubItems[4].Text}\n" +
                    $"状态：{selected.SubItems[5].Text}",
                    "报警详情"
                );
            }
        };

        this.Controls.Add(listView);
    }

    /// <summary>
    /// 创建带图标的设备列表
    /// 场景：上位机设备状态总览
    /// </summary>
    private void CreateDeviceListView()
    {
        var listView = new ListView
        {
            View = View.Details,
            FullRowSelect = true,
            GridLines = true,
            Location = new Point(10, 280),
            Size = new Size(600, 200),
            CheckBoxes = true  // 显示复选框（可以选择多个设备进行批量操作）
        };

        // 创建图标列表（使用系统图标）
        var imageList = new ImageList
        {
            ImageSize = new Size(16, 16),
            ColorDepth = ColorDepth.Depth32Bit
        };

        // 添加状态图标（用简单的彩色方块代替真实图标）
        using (var bmpOnline = new Bitmap(16, 16))
        using (var g = Graphics.FromImage(bmpOnline))
        {
            g.FillEllipse(Brushes.Green, 0, 0, 16, 16);
            imageList.Images.Add("online", bmpOnline);
        }
        using (var bmpOffline = new Bitmap(16, 16))
        using (var g = Graphics.FromImage(bmpOffline))
        {
            g.FillEllipse(Brushes.Red, 0, 0, 16, 16);
            imageList.Images.Add("offline", bmpOffline);
        }

        listView.SmallImageList = imageList;

        // 列头
        listView.Columns.AddRange(new ColumnHeader[]
        {
            new ColumnHeader { Text = "",           Width = 25 },   // 图标列
            new ColumnHeader { Text = "设备名称",   Width = 150 },
            new ColumnHeader { Text = "IP 地址",    Width = 130 },
            new ColumnHeader { Text = "状态",       Width = 80 },
            new ColumnHeader { Text = "最后通信",   Width = 130 }
        });

        // 数据
        var devices = new (string Name, string Ip, bool Online, string LastComm)[]
        {
            ("1#PLC-主站",   "192.168.1.10", true,  "2024-01-15 14:32:15"),
            ("2#PLC-从站",   "192.168.1.11", true,  "2024-01-15 14:32:10"),
            ("3#PLC-温控",   "192.168.1.12", false, "2024-01-15 13:00:00"),
            ("4#PLC-电机",   "192.168.1.13", true,  "2024-01-15 14:32:08"),
        };

        foreach (var (name, ip, online, lastComm) in devices)
        {
            var item = new ListViewItem("", online ? 0 : 1); // 设置图标索引
            item.SubItems.Add(name);
            item.SubItems.Add(ip);
            item.SubItems.Add(online ? "在线" : "离线");
            item.SubItems.Add(lastComm);
            item.Checked = online;  // 在线设备默认勾选

            if (!online)
                item.ForeColor = Color.Gray;

            listView.Items.Add(item);
        }

        this.Controls.Add(listView);
    }

    // ========== 动态添加报警记录（异步安全）==========
    /// <summary>
    /// 向报警列表添加新记录（可从后台线程调用）
    /// </summary>
    public void AddAlarmRecord(ListView listView, string level, string device, string content, string value)
    {
        if (listView.InvokeRequired)
        {
            listView.Invoke(new Action(() => AddAlarmRecord(listView, level, device, content, value)));
            return;
        }

        string time = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");
        var item = new ListViewItem(time);
        item.SubItems.Add(level);
        item.SubItems.Add(device);
        item.SubItems.Add(content);
        item.SubItems.Add(value);
        item.SubItems.Add("未处理");

        // 根据级别设置颜色
        if (level == "严重") { item.ForeColor = Color.Red; item.Font = new Font("微软雅黑", 9, FontStyle.Bold); }
        else if (level == "警告") item.ForeColor = Color.Orange;

        listView.Items.Insert(0, item);  // 插入到列表顶部

        // 限制最大记录数
        while (listView.Items.Count > 500)
            listView.Items.RemoveAt(listView.Items.Count - 1);
    }
}
```

### 注意事项

- ListView 的 `Items.Insert(0, item)` 可以将新记录插入到列表顶部（最新的在最上面），这在报警记录中很常用。
- `CheckBoxes = true` 配合 `Checked` 属性可以实现批量选择设备进行操作（如批量读取、批量导出）。
- 使用 `InvokeRequired` / `Invoke` 确保从后台线程添加记录时的线程安全（详见多线程章节）。
- `ImageList` 需要提前创建并添加图标，再赋值给 ListView 的 `SmallImageList` 属性。

### 练习建议

1. 创建一个报警记录 ListView（Details 模式），包含时间、级别、设备、内容四列，不同级别用不同颜色显示。
2. 实现双击报警记录弹出详情对话框。
3. 添加一个「清除已处理」按钮，删除所有状态为「已处理」的记录。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 新记录不显示 | 忘记 `Items.Add()` | 检查是否正确添加了 ListViewItem |
| 图标不显示 | 未设置 ImageList 或图标索引不对 | 创建 ImageList 并赋值给 SmallImageList |
| 后台线程添加报异常 | 跨线程操作 UI 控件 | 使用 `Invoke` 跨线程更新 |

## 3. TreeView 树形控件

### 知识讲解

`TreeView` 用于显示树形层次结构数据。在上位机中常用于设备树（产线→PLC→模块→寄存器）、配置项导航、报警分类等。

**核心概念：**

| 概念 | 说明 |
|------|------|
| `Nodes` | 根节点集合 |
| `TreeNode` | 树节点 |
| `Parent` | 父节点 |
| `Nodes` | 子节点集合 |
| `Level` | 层级（根节点为 0） |
| `Tag` | 附加数据（可存储任意对象） |

**常用属性：**

| 属性 | 说明 |
|------|------|
| `ShowLines` | 显示连接线 |
| `ShowPlusMinus` | 显示展开/折叠按钮 |
| `ShowRootLines` | 显示根节点连接线 |
| `ImageList` | 图标列表 |
| `SelectedNode` | 当前选中节点 |
| `CheckBoxes` | 是否显示复选框 |
| `HideSelection` | 失去焦点时是否保持选中高亮 |

**常用事件：**

| 事件 | 说明 |
|------|------|
| `NodeMouseClick` | 节点点击 |
| `AfterSelect` | 选中节点变化后 |
| `BeforeExpand` / `AfterExpand` | 展开/折叠前后 |
| `AfterCheck` | 勾选状态变化后 |

```csharp
        // （注意设置 TreeViewEventArgs 中的 Cancel 不会阻止事件，

    }

    /// <summary>
    /// 更新设备在线/离线状态
    /// </summary>
    private void UpdateDeviceStatus(TreeNode rootNode, string deviceName, bool isOnline, bool hasAlarm)
    {
        foreach (TreeNode lineNode in rootNode.Nodes)
        {
            foreach (TreeNode deviceNode in lineNode.Nodes)
            {
                if (deviceNode.Text.Contains(deviceName))
                {
                    if (hasAlarm)
                        deviceNode.ImageKey = "device_alarm";
                    else if (isOnline)
                        deviceNode.ImageKey = "device_online";
                    else
                        deviceNode.ImageKey = "device_offline";
                    return;
                }
            }
        }
    }

    // ========== 搜索节点 ==========
    /// <summary>
    /// 在树中查找节点
    /// </summary>
    private TreeNode FindNode(TreeNode parent, string text)
    {
        foreach (TreeNode node in parent.Nodes)
        {
            if (node.Text == text) return node;
            var found = FindNode(node, text);
            if (found != null) return found;
        }
        return null;
    }
```

### 注意事项

- **Tag 属性**：利用 `Tag` 属性可以给节点附加任意自定义数据（如设备 ID、IP 地址等），比解析文字更可靠。
- **递归设置 Checked 时的事件循环**：在 `AfterCheck` 事件中修改子节点的 `Checked` 属性会再次触发 `AfterCheck`，需要使用标志位防止无限循环。
- **BeforeExpand 延迟加载**：对于大量数据，可以在 `BeforeExpand` 事件中动态加载子节点，而不是一次性加载所有节点。
- **ImageKey vs ImageIndex**：`ImageKey` 通过图标名称引用，`ImageIndex` 通过索引引用，推荐使用 `ImageKey` 更直观。

### 练习建议

1. 创建一个三级设备树（车间→产线→设备），每个节点设置 Tag 存储附加信息。
2. 实现节点点击事件，点击设备节点时在右侧显示该设备的详细信息。
3. 实现动态更新设备节点图标（在线/离线/报警三种状态）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 图标不显示 | 未创建 ImageList 或 ImageKey 名称不匹配 | 确保创建 ImageList 并设置正确的 ImageKey |
| AfterCheck 事件循环 | 递归设置 Checked 触发事件 | 使用标志位防止重入 |
| 节点展开后空白 | 延迟加载未正确实现 | 在 BeforeExpand 中添加子节点 |

## 4. Chart 图表控件

### 知识讲解

`Chart` 控件是 .NET 中用于数据可视化的图表控件，支持折线图、柱状图、饼图、面积图等多种图表类型。在上位机中，实时数据曲线是最典型的应用场景——将 PLC 采集的温度、压力、转速等数据以实时曲线形式展示。

> **注意**：`System.Windows.Forms.DataVisualization.Charting.Chart` 需要添加 NuGet 包引用：
> `System.Windows.Forms.DataVisualization`（.NET 6+）或框架自带（.NET Framework 4.x）。

**图表区域概念：**

```
Chart
├── ChartAreas[0]           // 图表区域（可以有多个）
│   ├── AxisX              // X 轴
│   ├── AxisY              // Y 轴
│   └── ...
├── Series[0]              // 数据系列（可以有多个，每条线一个 Series）
├── Series[1]              // 第二条线
├── Legends               // 图例
└── Titles                 // 标题
```

### 代码示例

```csharp
using System.Windows.Forms.DataVisualization.Charting;

public partial class ChartDemo : Form
{
    private Chart _chart;                 // 图表控件
    private int _maxPoints = 100;        // 最大显示点数
    private System.Windows.Forms.Timer _timerChart; // 数据更新定时器
    private Random _random = new Random();
    private int _tickCount = 0;

    public ChartDemo()
    {
        InitializeComponent();

    }

    /// <summary>
    /// 创建实时数据曲线图
    /// 场景：上位机中展示 PLC 温度、压力实时变化曲线
    /// </summary>
    private void CreateRealtimeChart()
    {
        _chart = new Chart
        {
            Dock = DockStyle.Fill,

            BorderlineWidth = 1
        };

        // ====== 图表区域设置 ======
        var chartArea = new ChartArea("MainArea")
        {
            BackColor = Color.FromArgb(30, 30, 40),
            AxisX =
            {
                Title = "时间",
                TitleForeColor = Color.FromArgb(180, 180, 180),
                TitleFont = new Font("微软雅黑", 9),
                LabelStyle =
                {
                    ForeColor = Color.FromArgb(150, 150, 150),
                    Font = new Font("Consolas", 8)
                },
                LineColor = Color.FromArgb(80, 80, 100),
                MajorGrid =
                {
                    LineColor = Color.FromArgb(50, 50, 70),

                },
                Minimum = 0,
                Maximum = 100  // 初始 X 轴范围
            },
            AxisY =
            {
                Title = "温度 (°C)",
                TitleForeColor = Color.FromArgb(180, 180, 180),
                TitleFont = new Font("微软雅黑", 9),
                LabelStyle =
                {
                    ForeColor = Color.FromArgb(150, 150, 150),

                LineColor = Color.FromArgb(80, 80, 100),

                IsUserEnabled = true,           // 允许用户拖拽 X 轴
                IsUserSelectionEnabled = true,   // 允许用户框选 X 轴区域
                LineColor = Color.FromArgb(200, 200, 200),
                LineWidth = 1,
                LineDashStyle = ChartDashStyle.Dash
            },
            CursorY =
            {
                IsUserEnabled = true,

                LineColor = Color.FromArgb(200, 200, 200),

                LineDashStyle = ChartDashStyle.Dash
            }
        };

        _chart.ChartAreas.Add(chartArea);

        // ====== 数据系列 1：温度曲线 ======

            ChartType = SeriesChartType.Line,           // 折线图

        {
            seriesAlarm.Points.AddXY(i, 80);  // 阈值 80°C

    /// <summary>
    /// 初始化图表数据更新定时器
    /// </summary>
    private void InitializeChartTimer()
    {
        _timerChart = new System.Windows.Forms.Timer
        {
            Interval = 500  // 每 500ms 更新一次（2Hz）
        };
        _timerChart.Tick += TimerChart_Tick;
        _timerChart.Start();
    }

    /// <summary>
    /// 定时更新图表数据
    /// </summary>
    private void TimerChart_Tick(object sender, EventArgs e)
    {
        _tickCount++;

        // 模拟数据（实际项目中从 PLC 读取）
        double temp = 50 + 20 * Math.Sin(_tickCount * 0.1) + _random.NextDouble() * 5;
        double pressure = 2.5 + 1.5 * Math.Sin(_tickCount * 0.08 + 1) + _random.NextDouble() * 0.3;

        // ---- 添加数据点 ----
        _chart.Series["温度"].Points.AddXY(_tickCount, temp);
        _chart.Series["压力"].Points.AddXY(_tickCount, pressure);
        _chart.Series["报警阈值"].Points.AddXY(_tickCount, 80);

        // ---- 限制最大点数（移除最早的数据）----
        while (_chart.Series["温度"].Points.Count > _maxPoints)
            _chart.Series["温度"].Points.RemoveAt(0);
        while (_chart.Series["压力"].Points.Count > _maxPoints)
            _chart.Series["压力"].Points.RemoveAt(0);
        while (_chart.Series["报警阈值"].Points.Count > _maxPoints)
            _chart.Series["报警阈值"].Points.RemoveAt(0);

        // ---- 调整 X 轴范围（滚动效果）----
        if (_tickCount > _maxPoints)
        {
            _chart.ChartAreas["MainArea"].AxisX.Minimum = _tickCount - _maxPoints;
            _chart.ChartAreas["MainArea"].AxisX.Maximum = _tickCount;
        }
        else
        {
            _chart.ChartAreas["MainArea"].AxisX.Minimum = 0;
            _chart.ChartAreas["MainArea"].AxisX.Maximum = _maxPoints;
        }

        // ---- 自动调整 Y 轴范围（可选）----
        // 双 Y 轴场景：温度和压力共用一个 Y 轴不合理，实际应使用双 Y 轴
    }

    /// <summary>
    /// 清除图表数据
    /// </summary>
    private void ClearChartData()
    {
        foreach (var series in _chart.Series)
        {
            series.Points.Clear();
        }
        _tickCount = 0;
    }

    /// <summary>
    /// 创建柱状图（示例）
    /// 场景：各设备的产量/运行时间对比
    /// </summary>
    private void CreateBarChart()
    {
        var chart = new Chart
        {
            Dock = DockStyle.Fill,
            BackColor = Color.White
        };

        chart.ChartAreas.Add(new ChartArea());

        var series = new Series("产量")
        {
            ChartType = SeriesChartType.Column  // 柱状图
        };

        // 添加数据
        var data = new[] { ("1#PLC", 1200), ("2#PLC", 980), ("3#PLC", 1500), ("4#PLC", 750) };
        foreach (var (name, value) in data)
        {
            var point = new DataPoint(value) { AxisLabel = name };
            series.Points.Add(point);
        }

        chart.Series.Add(series);
    }
}
```

### 注意事项

- **Chart 控件性能**：频繁添加大量数据点时，Chart 控件的性能会下降。建议限制最大显示点数（如 100~200 点），超出时移除最早的数据。
- **使用 SuspendLayout/ResumeLayout**：批量更新数据时先暂停重绘，完成后恢复，可以大幅提升性能。
- **双 Y 轴**：当多条数据系列的量纲不同时（如温度和压力），应使用 `AxisY2` 创建第二 Y 轴，设置 `Series.YAxisType = AxisType.Secondary`。
- **深色主题**：工业上位机通常使用深色背景的图表，需要手动设置所有文字、网格线、背景的颜色。
- **Chart 控件引用**：在 .NET 6+ 项目中需要通过 NuGet 安装 `System.Windows.Forms.DataVisualization` 包。

### 练习建议

1. 创建一个实时折线图，显示 3 条模拟数据曲线（温度、压力、转速），每 500ms 更新一次，最多显示 100 个点。
2. 添加一条红色虚线作为报警阈值线（水平线）。

## 5. ProgressBar 进度条

### 知识讲解

`ProgressBar` 用于显示操作进度。在上位机中常用于数据导出进度、PLC 批量读写进度、固件升级进度等。

**常用属性：**

| 属性 | 说明 |
|------|------|
| `Value` | 当前值（0~Maximum） |
| `Minimum` / `Maximum` | 最小值 / 最大值 |
| `Step` | 每次增加的步长 |
| `Style` | 样式（`Blocks`、`Continuous`、`Marquee`） |
| `MarqueeAnimationSpeed` | 跑马灯动画速度（ms） |

### 代码示例

```csharp
public partial class ProgressBarDemo : Form
{
    public ProgressBarDemo()
    {
        InitializeComponent();
        CreateProgressDemo();
    }

    /// <summary>
    /// 批量读取 PLC 寄存器进度条示例
    /// </summary>
    private void CreateProgressDemo()
    {
        // 标准进度条
        var progressBar = new ProgressBar
        {
            Location = new Point(20, 20),
            Size = new Size(400, 25),
            Minimum = 0,
            Maximum = 100,
            Value = 0,
            Style = ProgressBarStyle.Continuous,  // 连续样式
            Step = 1
        };

        // 进度标签
        var lblProgress = new Label
        {
            Text = "0%",
            Location = new Point(430, 23),
            AutoSize = true
        };

        // 开始按钮
        var btnStart = new Button
        {
            Text = "开始批量读取",
            Location = new Point(20, 60),
            Size = new Size(120, 35)
        };
        btnStart.Click += async (s, e) =>
        {
            btnStart.Enabled = false;
            int totalRegisters = 100;  // 总共 100 个寄存器

            progressBar.Minimum = 0;
            progressBar.Maximum = totalRegisters;
            progressBar.Value = 0;

            for (int i = 0; i < totalRegisters; i++)
            {
                // 模拟异步读取每个寄存器
                await Task.Run(() => System.Threading.Thread.Sleep(50));

                // 更新进度
                progressBar.Value = i + 1;
                lblProgress.Text = $"{(i + 1) * 100 / totalRegisters}%";
                lblProgress.Refresh();  // 强制刷新文字
            }

            btnStart.Enabled = true;
            MessageBox.Show("批量读取完成！", "完成");
        };

        // 跑马灯进度条（不确定进度时使用）
        var marqueeBar = new ProgressBar
        {
            Location = new Point(20, 120),
            Size = new Size(400, 25),
            Style = ProgressBarStyle.Marquee,     // 跑马灯样式
            MarqueeAnimationSpeed = 30              // 动画速度（ms）
        };

        var btnMarquee = new Button
        {
            Text = "开始通信扫描",
            Location = new Point(20, 160),
            Size = new Size(120, 35)
        };
        btnMarquee.Click += async (s, e) =>
        {
            btnMarquee.Enabled = false;
            marqueeBar.Style = ProgressBarStyle.Marquee;  // 开始跑马灯

            // 模拟不确定时长的扫描操作
            await Task.Run(() => System.Threading.Thread.Sleep(3000));

            marqueeBar.Style = ProgressBarStyle.Continuous; // 停止跑马灯
            marqueeBar.Value = marqueeBar.Maximum;
            btnMarquee.Enabled = true;
            MessageBox.Show("扫描完成！", "完成");
        };

        this.Controls.AddRange(new Control[] 
        { 
            progressBar, lblProgress, btnStart, 
            marqueeBar, btnMarquee 
        });
    }

    /// <summary>
    /// 更新进度条的辅助方法（线程安全）
    /// </summary>
    public void UpdateProgress(ProgressBar progressBar, Label label, int current, int total)
    {
        if (progressBar.InvokeRequired)
        {
            progressBar.Invoke(new Action(() => UpdateProgress(progressBar, label, current, total)));
            return;
        }

        int percent = total > 0 ? current * 100 / total : 0;
        progressBar.Value = Math.Min(current, progressBar.Maximum);
        if (label != null)
            label.Text = $"{percent}% ({current}/{total})";
    }
}
```

### 注意事项

- **Marquee 样式**用于不确定操作时长时显示动画效果，告诉用户"程序正在工作"。通过在 `Style` 和 `Continuous` 之间切换来启动/停止动画。
- **Value 不能超过 Maximum**：设置 `Value` 时确保不超过 `Maximum`，否则会抛出异常。
- `Step` 属性配合 `PerformStep()` 方法可以按固定步长递增。

### 练习建议

1. 创建一个进度条，模拟批量读取 100 个寄存器的过程，实时显示百分比。
2. 创建一个跑马灯进度条，模拟不确定时长的网络扫描操作。
3. 实现进度条的「取消」功能（使用 CancellationToken）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| ArgumentOutOfRangeException | Value 超过了 Maximum | 设置前检查范围，或先更新 Maximum |
| 进度条不动 | 在子线程直接更新（WinForms 需要 Invoke） | 使用 Invoke 或 async/await |

```csharp
        // ========== 数据轮询 ==========
        private async System.Threading.Tasks.Task PollDataAsync()
        {
            _tickCount++;

            try
            {
                // 模拟读取 PLC 数据
                var newData = await Task.Run(() =>
                {
                    return new RegisterData[]
                    {
                        new RegisterData { Index = 1, Address = "D100", Value = 45 + 10 * Math.Sin(_tickCount * 0.1) + _random.NextDouble() * 3, Unit = "°C" },
                        new RegisterData { Index = 2, Address = "D101", Value = 3.5 + Math.Sin(_tickCount * 0.08) * 0.5, Unit = "MPa" },
                        new RegisterData { Index = 3, Address = "D102", Value = 1200 + _random.Next(-50, 50), Unit = "RPM" },
                        new RegisterData { Index = 4, Address = "D103", Value = 22.5 + _random.NextDouble() * 2, Unit = "°C" },
                    };
                });

                // 更新数据列表
                foreach (var item in newData)
                {
                    item.Status = item.Value > 80 ? "报警" : item.Value > 60 ? "警告" : "正常";
                    item.UpdateTime = DateTime.Now.ToString("HH:mm:ss");
                }

                // 刷新 BindingList
                _dataList.Clear();
                foreach (var item in newData) _dataList.Add(item);

                _lblStatus.Text = $"数据更新中... | 第 {_tickCount} 次轮询 | {DateTime.Now:HH:mm:ss}";
            }
            catch (Exception ex)
            {
                _lblStatus.Text = $"通信异常：{ex.Message}";
            }
        }

        // ========== 图表更新 ==========
        private void UpdateChartData()
        {
            var series1 = _chartTrend.Series["温度 D100"];
            var series2 = _chartTrend.Series["温度 D101"];

            // 模拟数据
            double temp1 = 45 + 10 * Math.Sin(_tickCount * 0.1) + _random.NextDouble() * 3;
            double temp2 = 22.5 + _random.NextDouble() * 2;

            series1.Points.AddXY(_tickCount, temp1);
            series2.Points.AddXY(_tickCount, temp2);

            int maxPts = 60;
            while (series1.Points.Count > maxPts) series1.Points.RemoveAt(0);
            while (series2.Points.Count > maxPts) series2.Points.RemoveAt(0);

            // 滚动 X 轴
            var area = _chartTrend.ChartAreas["Main"];
            area.AxisX.Minimum = Math.Max(0, _tickCount - maxPts);
            area.AxisX.Maximum = Math.Max(maxPts, _tickCount);
        }

        // ========== 加载设备数据 ==========

        {
            _lblStatus.Text = $"加载设备数据：{deviceName}";
            LogMessage($"切换到设备：{deviceName}");
        }

        // ========== 窗体关闭 ==========
        protected override void OnFormClosing(FormClosingEventArgs e)
        {
            _timerPoll?.Stop();
            _timerChart?.Stop();
            base.OnFormClosing(e);
        }

        private void LogMessage(string msg)
        {
            _lblStatus.Text = msg;
        }
    }
```

### 注意事项

- 本案例中 `BindingList<T>` 配合 `DataGridView.DataSource` 实现了数据绑定，每次刷新数据只需清空并重新添加，界面会自动更新。
- 图表使用独立定时器更新（与数据轮询定时器分离），两者的更新频率可以不同。
- 窗体关闭时必须停止所有定时器。

### 练习建议

1. 在本案例基础上添加「暂停/继续」数据采集功能。
2. 实现设备树点击时，根据选中的设备加载对应的寄存器数据。
3. 添加报警逻辑：当数值超过阈值时自动向报警列表中添加记录。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 图表 X 轴不滚动 | 未更新 AxisX.Minimum/Maximum | 每次添加数据后同步更新 X 轴范围 |
| DataGridView 数据不更新 | BindingList 操作不正确 | 使用 Clear() + Add() 或直接修改属性 |
| 定时器关窗后报异常 | 未停止定时器 | 在 FormClosing 中 Stop 所有定时器 |

## 总结

本章学习了 WinForms 中的数据展示控件：

| 控件 | 核心用途 | 上位机典型场景 |
|------|---------|--------------|
| DataGridView | 表格数据展示 | PLC 寄存器数据表、报警记录表、历史数据 |
| ListView | 列表视图 | 设备列表、报警记录、通信日志 |
| TreeView | 树形层次结构 | 设备树、配置项导航、报警分类 |
| Chart | 数据可视化图表 | 实时温度/压力曲线、产量柱状图 |
| ProgressBar | 操作进度显示 | 批量读写进度、数据导出进度 |

**数据展示的核心原则：**
1. 使用 BindingList/T 绑定数据源，实现数据变化自动更新界面
2. 数据量大时限制显示数量（列表不超过 500 条，图表不超过 200 点）
3. 使用 CellFormatting/NodeMouseClick 等事件实现数据驱动的样式变化
4. 后台线程更新数据时必须通过 Invoke 回到 UI 线程
5. 工业风格建议使用深色背景（Chart、DataGridView）配合亮色数据线
