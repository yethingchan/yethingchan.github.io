## 1. 布局的重要性

### 知识讲解

很多初学者在 WinForms 开发中使用**拖拽定位**（Absolute Positioning）来布局控件，即通过设置每个控件的 `Location`（x, y）坐标来手动排列。这种方式存在严重的缺陷：

**拖拽定位的问题：**

| 问题 | 说明 |
|------|------|
| **窗口缩放失效** | 用户拉大/拉小窗口时，控件位置和大小不会跟随变化 |
| **分辨率适配困难** | 在 1920x1080 屏幕上开发，在 1366x768 屏幕上可能显示不全 |
| **维护成本高** | 增减一个控件后，需要手动调整所有相关控件的坐标 |
| **DPI 缩放问题** | 在高 DPI 显示器上，控件位置可能错乱 |
| **不专业** | 正式产品几乎不会使用纯拖拽定位 |

**正确的布局策略：**

WinForms 提供了多种布局方式，正确的做法是**组合使用容器控件和布局属性**：

- **TableLayoutPanel**：网格布局，精确控制行列
- **FlowLayoutPanel**：流式布局，自动排列
- **SplitContainer**：可拖拽分割的区域
- **Dock / Anchor**：控件停靠和锚定
- **Panel / GroupBox**：逻辑分组

### 注意事项

- 工业上位机通常部署在固定分辨率的工控机上，但仍应考虑缩放适配，因为工控机分辨率可能各不相同。
- 推荐以 1920x1080 为基准设计，最低支持 1366x768。
- 设计时保持窗体 `AutoSize = false`，手动控制大小。

### 练习建议

1. 打开一个旧项目（如果有），将窗体的 `Font` 改大，观察拖拽定位的控件是否错位。
2. 体验一下 TableLayoutPanel，用表格布局重新排列之前拖拽定位的控件。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 拉大窗口控件不跟随 | 使用了绝对定位 | 使用 Dock/Anchor 或布局容器 |
| 换显示器控件位置错乱 | DPI 缩放不一致 | 使用布局容器代替绝对定位 |

## 2. TableLayoutPanel 表格布局

### 知识讲解

`TableLayoutPanel` 是 WinForms 中最强大的布局容器，类似于 HTML 的 `<table>`。它将容器划分为行和列的网格，每个单元格可以放入一个控件，控件可以设置 Dock/Fill 自动填满单元格。

**常用属性：**

| 属性 | 说明 |
|------|------|
| `ColumnCount` | 列数 |
| `RowCount` | 行数 |
| `Columns` | 列集合（可设置每列的宽度类型） |
| `Rows` | 行集合（可设置每行的高度类型） |
| `CellBorderStyle` | 单元格边框样式 |
| `BorderStyle` | 外边框样式 |
| `Padding` | 内边距 |
| `Margin` | 外边距 |

**列/行大小类型：**

| 类型 | 说明 | 场景 |
|------|------|------|
| `Absolute` | 固定像素值 | 固定宽度的标签 |
| `Percent` | 百分比（相对剩余空间） | 自适应的内容区域 |
| `AutoSize` | 根据内容自动调整 | 动态宽度的标签 |

### 代码示例

```csharp
public partial class TableLayoutPanelDemo : Form
{
    public TableLayoutPanelDemo()
    {
        InitializeComponent();
        CreateParameterPanel();
    }

    /// <summary>
    /// 使用 TableLayoutPanel 创建 PLC 参数设置面板
    /// 场景：上位机连接参数输入区域
    /// </summary>
    private void CreateParameterPanel()
    {
        // 创建表格布局：4 行 2 列
        var table = new TableLayoutPanel
        {
            ColumnCount = 2,
            RowCount = 4,
            Location = new Point(20, 20),
            Size = new Size(400, 150),
            BackColor = Color.White,
            CellBorderStyle = TableLayoutPanelCellBorderStyle.None  // 无边框（默认）
        };

        // ========== 设置列宽 ==========
        // 第 1 列：AutoSize（根据内容自动调整，适合 Label）
        // 第 2 列：100%（占据所有剩余空间，适合输入控件）
        table.ColumnStyles.Add(new ColumnStyle(SizeType.AutoSize));  // 第 1 列
        table.ColumnStyles.Add(new ColumnStyle(SizeType.Percent, 100F)); // 第 2 列

        // ========== 设置行高 ==========
        // 每行固定高度 35px
        for (int i = 0; i < 4; i++)
        {
            table.RowStyles.Add(new RowStyle(SizeType.Absolute, 35));
        }

        // ========== 第 1 行：IP 地址 ==========
        var lblIp = new Label
        {
            Text = "IP 地址：",
            Dock = DockStyle.Fill,        // 填满单元格
            TextAlign = ContentAlignment.MiddleLeft,
            Margin = new Padding(5, 5, 5, 5)
        };
        var txtIp = new TextBox
        {
            Text = "192.168.1.10",
            Dock = DockStyle.Fill,        // 填满单元格
            Margin = new Padding(5, 5, 5, 5)
        };
        table.Controls.Add(lblIp, 0, 0);  // 第 0 列，第 0 行
        table.Controls.Add(txtIp, 1, 0);  // 第 1 列，第 0 行

        // ========== 第 2 行：端口号 ==========
        var lblPort = new Label
        {
            Text = "端  口：",
            Dock = DockStyle.Fill,
            TextAlign = ContentAlignment.MiddleLeft,
            Margin = new Padding(5, 5, 5, 5)
        };
        var nudPort = new NumericUpDown
        {
            Minimum = 1, Maximum = 65535, Value = 502,
            Dock = DockStyle.Fill,
            Margin = new Padding(5, 5, 5, 5)
        };
        table.Controls.Add(lblPort, 0, 1);
        table.Controls.Add(nudPort, 1, 1);

        // ========== 第 3 行：PLC 型号 ==========
        var lblPlc = new Label
        {
            Text = "PLC 型号：",
            Dock = DockStyle.Fill,
            TextAlign = ContentAlignment.MiddleLeft,
            Margin = new Padding(5, 5, 5, 5)
        };
        var cmbPlc = new ComboBox
        {
            DropDownStyle = ComboBoxStyle.DropDownList,
            Dock = DockStyle.Fill,
            Margin = new Padding(5, 5, 5, 5)
        };
        cmbPlc.Items.AddRange(new object[] { "汇川 IN100", "汇川 IN200", "西门子 S7-1200" });
        cmbPlc.SelectedIndex = 0;
        table.Controls.Add(lblPlc, 0, 2);
        table.Controls.Add(cmbPlc, 1, 2);

        // ========== 第 4 行：连接按钮（跨两列合并）==========
        var btnConnect = new Button
        {
            Text = "连接 PLC",
            Dock = DockStyle.Fill,
            Height = 30,
            BackColor = Color.FromArgb(0, 153, 255),
            ForeColor = Color.White,
            FlatStyle = FlatStyle.Flat,
            Margin = new Padding(5, 5, 5, 5)
        };
        table.Controls.Add(btnConnect, 0, 3);

        // ====== 合并单元格：让按钮跨两列 ======
        // 设置按钮在列方向上跨越 2 列
        table.SetColumnSpan(btnConnect, 2);

        // 将表格添加到窗体
        this.Controls.Add(table);
    }

    /// <summary>
    /// 创建更复杂的布局：比例列 + 固定列
    /// 场景：上位机数据表格区域（编号列固定宽度，数据列自适应）
    /// </summary>
    private void CreateComplexTable()
    {
        var table = new TableLayoutPanel
        {
            ColumnCount = 3,
            RowCount = 5,
            Dock = DockStyle.Fill  // 填满父容器
        };

        // 列宽设置：固定 60px + 固定 120px + 剩余全部
        table.ColumnStyles.Add(new ColumnStyle(SizeType.Absolute, 60));  // 编号
        table.ColumnStyles.Add(new ColumnStyle(SizeType.Absolute, 120)); // 地址
        table.ColumnStyles.Add(new ColumnStyle(SizeType.Percent, 100F)); // 数据值

        // 添加表头
        var headers = new[] { "编号", "寄存器地址", "当前值" };
        for (int col = 0; col < headers.Length; col++)
        {
            var header = new Label
            {
                Text = headers[col],
                Dock = DockStyle.Fill,
                TextAlign = ContentAlignment.MiddleCenter,
                BackColor = Color.FromArgb(0, 153, 255),
                ForeColor = Color.White,
                Font = new Font("微软雅黑", 9, FontStyle.Bold),
                Margin = new Padding(1)
            };
            table.Controls.Add(header, col, 0);
        }

        // 添加数据行
        for (int row = 1; row <= 4; row++)
        {
            var lblNo = new Label { Text = row.ToString(), Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleCenter, Margin = new Padding(1) };
            var lblAddr = new Label { Text = $"D{100 + row}", Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleCenter, Margin = new Padding(1) };
            var lblValue = new TextBox { Text = "0.00", Dock = DockStyle.Fill, ReadOnly = true, TextAlign = HorizontalAlignment.Center, Margin = new Padding(1) };

            table.Controls.Add(lblNo, 0, row);
            table.Controls.Add(lblAddr, 1, row);
            table.Controls.Add(lblValue, 2, row);
        }

        this.Controls.Add(table);
    }
}
```

### 注意事项

- **单元格内只能放一个控件**：如果需要在同一单元格放多个控件，先放一个 `Panel`，然后在 Panel 中添加子控件。
- **SetColumnSpan / SetRowSpan**：合并单元格的核心方法。注意合并后，被合并的单元格不能再放控件。
- **使用 Dock = DockStyle.Fill**：放入 TableLayoutPanel 的控件通常设置 `Dock = DockStyle.Fill`，让它自动填满单元格。
- **Margin 的作用**：每个控件的 `Margin` 属性决定了它在单元格内的边距，利用 Margin 可以留出控件间距。

### 练习建议

1. 使用 TableLayoutPanel 创建一个 4 行 2 列的参数设置面板，标签在左列（AutoSize），输入控件在右列（Percent 100%），最后一行按钮跨两列。
2. 创建一个表格，第一行为表头（蓝色背景白色文字），数据行交替使用白色和浅灰色背景。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 控件没有填满单元格 | 未设置 `Dock = DockStyle.Fill` | 设置控件的 Dock 属性 |
| SetColumnSpan 后布局错乱 | 被合并的单元格中有控件 | 先移除被合并单元格中的控件 |
| 列宽不符合预期 | 列的宽度类型设置不对 | 检查 ColumnStyle 的 SizeType |

## 3. FlowLayoutPanel 流式布局

### 知识讲解

`FlowLayoutPanel` 会按照控件添加的顺序自动排列子控件，类似于 HTML 中的 Flexbox（默认 flex-direction 为 row，换行为 wrap）。当控件超出容器宽度时，会自动换行。

**常用属性：**

| 属性 | 说明 |
|------|------|
| `FlowDirection` | 流向（`LeftToRight`、`TopDown`、`RightToLeft`、`BottomUp`） |
| `WrapContents` | 是否自动换行（默认 `true`） |
| `AutoScroll` | 内容超出时是否显示滚动条 |

### 代码示例

```csharp
public partial class FlowLayoutPanelDemo : Form
{
    public FlowLayoutPanelDemo()
    {
        InitializeComponent();
        CreateStatusPanel();
    }

    /// <summary>
    /// 创建设备状态面板
    /// 场景：上位机中显示多个 PLC 站点的连接状态指示灯
    /// </summary>
    private void CreateStatusPanel()
    {
        var flowPanel = new FlowLayoutPanel
        {
            FlowDirection = FlowDirection.LeftToRight,  // 从左到右排列
            WrapContents = true,                          // 自动换行
            AutoScroll = true,                           // 内容超出时显示滚动条
            Location = new Point(10, 10),
            Size = new Size(500, 150),
            BackColor = Color.FromArgb(245, 245, 245),
            BorderStyle = BorderStyle.FixedSingle,
            Padding = new Padding(5)
        };

        // 添加多个设备状态卡片
        var devices = new[]
        {
            new { Name = "1#PLC", Ip = "192.168.1.10", Online = true },
            new { Name = "2#PLC", Ip = "192.168.1.11", Online = true },
            new { Name = "3#PLC", Ip = "192.168.1.12", Online = false },
            new { Name = "4#PLC", Ip = "192.168.1.13", Online = true },
            new { Name = "5#PLC", Ip = "192.168.1.14", Online = false },
            new { Name = "6#PLC", Ip = "192.168.1.15", Online = true },
        };

        foreach (var device in devices)
        {
            // 创建一个 Panel 作为单个设备的卡片
            var card = CreateDeviceCard(device.Name, device.Ip, device.Online);
            flowPanel.Controls.Add(card);
        }

        this.Controls.Add(flowPanel);
    }

    /// <summary>
    /// 创建单个设备状态卡片
    /// </summary>
    private Panel CreateDeviceCard(string name, string ip, bool isOnline)
    {
        var card = new Panel
        {
            Size = new Size(140, 55),
            BackColor = Color.White,
            BorderStyle = BorderStyle.FixedSingle,
            Margin = new Padding(5),   // 卡片之间的间距
            Padding = new Padding(5)   // 卡片内边距
        };

        // 设备名称
        var lblName = new Label
        {
            Text = name,
            Font = new Font("微软雅黑", 9, FontStyle.Bold),
            ForeColor = isOnline ? Color.FromArgb(0, 150, 0) : Color.FromArgb(200, 50, 50),
            Location = new Point(25, 5),
            AutoSize = true
        };

        // 状态指示灯（用 Panel 模拟圆形）
        var led = new Panel
        {
            Size = new Size(12, 12),
            Location = new Point(5, 8),
            BackColor = isOnline ? Color.FromArgb(0, 200, 0) : Color.FromArgb(200, 0, 0)
        };

        // IP 地址
        var lblIp = new Label
        {
            Text = ip,
            Font = new Font("Consolas", 8),
            ForeColor = Color.Gray,
            Location = new Point(5, 30),
            AutoSize = true
        };

        card.Controls.AddRange(new Control[] { led, lblName, lblIp });
        return card;
    }

    /// <summary>
    /// 创建垂直排列的操作按钮组
    /// </summary>
    private void CreateVerticalButtonGroup()
    {
        var flowPanel = new FlowLayoutPanel
        {
            FlowDirection = FlowDirection.TopDown,  // 从上到下排列
            WrapContents = false,                    // 不换行
            Location = new Point(530, 10),
            Size = new Size(120, 250),
            BackColor = Color.FromArgb(245, 245, 245),
            BorderStyle = BorderStyle.FixedSingle,
            Padding = new Padding(5)
        };

        var buttons = new[]
        {
            ("连接", Color.FromArgb(0, 153, 255)),
            ("读取", Color.FromArgb(40, 167, 69)),
            ("写入", Color.FromArgb(255, 193, 7)),
            ("断开", Color.FromArgb(200, 50, 50)),
        };

        foreach (var (text, color) in buttons)
        {
            var btn = new Button
            {
                Text = text,
                Size = new Size(100, 35),
                BackColor = color,
                ForeColor = text == "写入" ? Color.Black : Color.White,
                FlatStyle = FlatStyle.Flat,
                Margin = new Padding(0, 5, 0, 5)  // 按钮之间的垂直间距
            };
            flowPanel.Controls.Add(btn);
        }

        this.Controls.Add(flowPanel);
    }
}
```

### 注意事项

- FlowLayoutPanel 中的控件默认使用 `AutoSize` 大小，控件会按照自身内容确定尺寸。
- 使用 `Margin` 属性控制控件之间的间距，使用容器的 `Padding` 控制与容器边缘的间距。
- `FlowDirection = TopDown` 适合创建侧边栏按钮组，`LeftToRight` 适合创建卡片网格。
- 在 FlowLayoutPanel 中不建议使用 `Dock`，因为 FlowLayoutPanel 自行管理控件的布局。

### 练习建议

1. 创建一个 FlowLayoutPanel，自动排列 10 个设备状态卡片，观察换行效果。
2. 使用 `FlowDirection.TopDown` 创建一个垂直排列的工具栏按钮组。
3. 测试 `WrapContents = false` 和 `AutoScroll = true` 的效果。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 控件排列方向不对 | FlowDirection 设置错误 | 设置正确的 FlowDirection |
| 控件重叠 | 未设置 Margin | 给每个控件设置合理的 Margin |
| 控件超出容器不可见 | AutoScroll = false 且 WrapContents = false | 设置 AutoScroll = true |

## 4. SplitContainer 分割面板

### 知识讲解

`SplitContainer` 是一个包含两个面板的可拖拽分割容器，用户可以通过拖拽分割条来调整两个面板的大小比例。在上位机中常用于创建**左右分栏**（设备树 + 数据区）或**上下分栏**（列表区 + 详情区）。

**常用属性：**

| 属性 | 说明 |
|------|------|
| `Orientation` | 方向（`Vertical` 竖直/`Horizontal` 水平） |
| `SplitterDistance` | 分割条的位置（像素） |
| `SplitterWidth` | 分割条宽度 |
| `FixedPanel` | 固定哪个面板（`None`、`Panel1`、`Panel2`） |
| `Panel1MinSize` / `Panel2MinSize` | 面板最小尺寸 |
| `IsSplitterFixed` | 是否禁止拖拽 |

### 代码示例

```csharp
public partial class SplitContainerDemo : Form
{
    public SplitContainerDemo()
    {
        InitializeComponent();
        CreateMainLayout();
    }

    /// <summary>
    /// 创建上位机经典左右分栏布局
    /// 左侧：设备树 + 控制面板
    /// 右侧：数据展示区
    /// </summary>
    private void CreateMainLayout()
    {
        // 主分割容器：左右分栏
        var mainSplit = new SplitContainer
        {
            Dock = DockStyle.Fill,                          // 填满窗体
            Orientation = Orientation.Vertical,             // 水平分割条（左右分栏）
            SplitterDistance = 250,                          // 左侧面板宽度 250px
            SplitterWidth = 6,                               // 分割条宽度
            FixedPanel = FixedPanel.None,                    // 两侧都可调整
            Panel1MinSize = 150,                             // 左侧最小 150px
            Panel2MinSize = 400,                             // 右侧最小 400px
            BackColor = Color.FromArgb(240, 240, 240)       // 分割条颜色
        };

        // ====== 左侧面板（Panel1）：设备树 ======
        var grpDevices = new GroupBox
        {
            Text = "设备列表",
            Dock = DockStyle.Fill,
            Padding = new Padding(3)
        };

        var treeDevices = new TreeView
        {
            Dock = DockStyle.Fill,
            Font = new Font("微软雅黑", 9)
        };

        // 添加设备节点
        var rootNode = treeDevices.Nodes.Add("生产车间");
        rootNode.Nodes.Add("1#PLC - 主站");
        rootNode.Nodes.Add("2#PLC - 从站1");
        rootNode.Nodes.Add("3#PLC - 从站2");
        rootNode.Nodes.Add("4#PLC - 温控单元");
        rootNode.Expand();  // 展开根节点

        grpDevices.Controls.Add(treeDevices);

        // 左侧底部：控制面板（嵌套一个垂直 SplitContainer）
        var leftSplit = new SplitContainer
        {
            Dock = DockStyle.Fill,
            Orientation = Orientation.Horizontal,        // 垂直分割条（上下分栏）
            SplitterDistance = 300,                       // 上半部分高度 300px
            SplitterWidth = 4,
            BackColor = Color.FromArgb(220, 220, 220)
        };

        // 上半部分：设备树
        leftSplit.Panel1.Controls.Add(grpDevices);

        // 下半部分：连接控制
        var grpControl = new GroupBox
        {
            Text = "连接控制",
            Dock = DockStyle.Fill,
            Padding = new Padding(3)
        };

        var table = new TableLayoutPanel
        {
            Dock = DockStyle.Fill,
            ColumnCount = 2,
            RowCount = 3
        };
        table.ColumnStyles.Add(new ColumnStyle(SizeType.AutoSize));
        table.ColumnStyles.Add(new ColumnStyle(SizeType.Percent, 100F));
        for (int i = 0; i < 3; i++)
            table.RowStyles.Add(new RowStyle(SizeType.Absolute, 35));

        table.Controls.Add(new Label { Text = "IP：", Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleLeft }, 0, 0);
        table.Controls.Add(new TextBox { Text = "192.168.1.10", Dock = DockStyle.Fill }, 1, 0);
        table.Controls.Add(new Label { Text = "端口：", Dock = DockStyle.Fill, TextAlign = ContentAlignment.MiddleLeft }, 0, 1);
        table.Controls.Add(new NumericUpDown { Minimum = 1, Maximum = 65535, Value = 502, Dock = DockStyle.Fill }, 1, 1);

        var btnConnect = new Button { Text = "连接", Dock = DockStyle.Fill, FlatStyle = FlatStyle.Flat };
        table.Controls.Add(btnConnect, 0, 2);
        table.SetColumnSpan(btnConnect, 2);

        grpControl.Controls.Add(table);
        leftSplit.Panel2.Controls.Add(grpControl);

        {

            Orientation = Orientation.Horizontal,
            SplitterDistance = 300,
            SplitterWidth = 4,

        // 右侧上半：数据表格

        var chart = new Chart
        {
            Dock = DockStyle.Fill
        };
        rightSplit.Panel2.Controls.Add(chart);

        grpData.Controls.Add(rightSplit);

        this.Controls.Add(mainSplit);
    }

### 注意事项

- **SplitContainer 可以嵌套**：一个 SplitContainer 的 Panel 中可以再放一个 SplitContainer，实现复杂的多区域布局。
- **Panel1MinSize 和 Panel2MinSize**：必须设置，防止用户将分割条拖到极端位置导致面板消失。
- **FixedPanel**：设置为 `FixedPanel.Panel1` 可以固定左侧面板宽度，只允许调整右侧。这在左侧为设备树时很有用。
- **访问子面板**：通过 `split.Panel1.Controls.Add()` 向面板中添加控件。

### 练习建议

1. 创建一个左右分栏的界面（左侧 250px 设备树，右侧数据区），实现拖拽分割条调整比例。
2. 在右侧面板中嵌套一个上下分割的 SplitContainer（上面表格，下面图表）。
3. 设置 `FixedPanel = FixedPanel.Panel1`，测试固定左侧面板的效果。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 拖拽分割条后面板消失 | 未设置 MinSize | 设置 Panel1MinSize 和 Panel2MinSize |
| 控件添加后看不到 | 控件添加到了 SplitContainer 本身而不是 Panel | 添加到 `split.Panel1` 或 `split.Panel2` |
| 分割条位置不对 | SplitterDistance 设置不合理 | 根据容器大小调整初始值 |

## 5. Panel 与 GroupBox 分组容器

### 知识讲解

**Panel** 和 **GroupBox** 都是用于对控件进行逻辑分组的容器控件。两者的主要区别：

| 特性 | Panel | GroupBox |
|------|-------|----------|
| 标题 | 无 | 有标题文字 |
| 边框 | 可选 | 默认有 3D 边框 |
| 滚动条 | 支持 `AutoScroll` | 不直接支持 |
| 外观 | 简洁 | 自带分组框 |

**常用场景：**
- Panel：通用容器，用于布局、滚动区域、自定义绘图面板
- GroupBox：逻辑分组，如「连接设置」「参数配置」「操作按钮」

### 代码示例

## 6. TabControl 选项卡

### 知识讲解

`TabControl` 用于创建多页界面，每个选项卡（TabPage）是一页内容。在上位机中常用于将不同功能模块组织在同一窗口的不同页面中，如「实时监控」「参数配置」「历史查询」「系统设置」等。

**常用属性：**

| 属性 | 说明 |
|------|------|
| `TabPages` | 选项卡页面集合 |
| `SelectedIndex` | 当前选中页的索引 |
| `SelectedTab` | 当前选中的TabPage |
| `TabAlign` | 选项卡位置（Top、Bottom、Left、Right） |
| `Appearance` | 外观样式（Normal、Buttons、FlatButtons） |
| `HotTrack` | 鼠标悬停时高亮选项卡 |
| `ImageList` | 选项卡图标列表 |

## 7. Anchor 与 Dock 属性详解

### 知识讲解

`Anchor`（锚定）和 `Dock`（停靠）是 WinForms 控件自适应布局的两个核心属性。

### Dock 属性

Dock 让控件紧贴容器的某个边缘并自动拉伸填满：

| DockStyle 值 | 效果 |
|-------------|------|
| `None` | 不停靠，使用 Location 定位（默认） |
| `Top` | 贴顶部，宽度填满 |
| `Bottom` | 贴底部，宽度填满 |
| `Left` | 贴左侧，高度填满 |
| `Right` | 贴右侧，高度填满 |
| `Fill` | 填满整个容器 |

**Dock 的优先级顺序**（后设置的会覆盖先设置的）：Top → Bottom → Left → Right → Fill

### Anchor 属性

Anchor 让控件与容器的指定边缘保持固定距离，容器缩放时控件跟随移动和调整大小：

| Anchor 值 | 效果 |
|-----------|------|
| `Top, Left` | 固定在左上角（默认），不随容器缩放变化 |
| `Top, Bottom` | 左右固定，上下跟随拉伸 |
| `Left, Right` | 上下固定，左右跟随拉伸 |
| `Top, Bottom, Left, Right` | 四个方向全部跟随（等同于 Fill） |

### 代码示例

        {
            Text = "PLC 参数配置",
            Location = new Point(20, 20),
            Font = new Font("微软雅黑", 14, FontStyle.Bold),
            // Anchor = Top, Left（默认值，不需要显式设置）
        };
        this.Controls.Add(lblTitle);

        // 文本框：锚定左右，宽度跟随窗口变化
        var txtValue = new TextBox
        {
            Text = "192.168.1.10",
            Location = new Point(100, 70),
            Width = 350,
            Anchor = AnchorStyles.Left | AnchorStyles.Right  // 左右锚定
        };
        this.Controls.Add(txtValue);

        // 按钮：锚定右下，始终在窗口右下角
        var btnCancel = new Button
        {
            Text = "取消",
            Location = new Point(390, 270),
            Anchor = AnchorStyles.Bottom | AnchorStyles.Right  // 右下锚定
        };
        this.Controls.Add(btnCancel);

        var btnOk = new Button
        {
            Text = "确定",
            Location = new Point(300, 270),
            Anchor = AnchorStyles.Bottom | AnchorStyles.Right  // 右下锚定
        };
        this.Controls.Add(btnOk);

        // DataGridView：锚定四边，完全跟随窗口缩放
        var dgv = new DataGridView
        {
            Location = new Point(20, 100),
            Size = new Size(440, 150),
            Anchor = AnchorStyles.Top | AnchorStyles.Bottom | AnchorStyles.Left | AnchorStyles.Right
        };
        this.Controls.Add(dgv);
    }

```

### 注意事项

- **Dock 控件的添加顺序很重要**：`Dock = Top` 的控件按照添加顺序从上到下排列。先添加的在上面，后添加的在下面。
- **Dock 和 Anchor 不要混用**：一个控件同时设置了 Dock 和 Anchor 时，Dock 优先。通常建议在容器层面用 Dock，在具体控件层面用 Anchor。
- **Dock = Fill 的嵌套**：在复杂的布局中，`Fill` 经常嵌套使用（外层 Fill 占满容器，内层再进行 Top/Bottom/Fill 的细分）。
- **设计器中使用**：在 Visual Studio 设计器中，可以通过点击控件中间的蓝色箭头图标快速设置 Dock。

### 练习建议

1. 创建一个窗体，使用 Dock 属性实现：上方菜单栏、左侧导航（200px 固定）、右侧内容区（Fill）、底部状态栏。
2. 创建一个设置对话框，使用 Anchor 属性确保输入框跟随窗口宽度缩放，确定/取消按钮始终在右下角。
3. 尝试手动拉伸窗体，观察不同 Anchor/Dock 设置的控件的行为。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| Dock 控件位置不对 | 添加顺序有误 | 调整控件添加到 Controls 的顺序 |
| 控件未随窗口缩放 | 未设置 Anchor 或 Dock | 设置合适的 Anchor 或 Dock |
| Dock 后控件消失 | 被 Dock=Fill 的控件覆盖 | 调整添加顺序，Fill 最后添加 |

## 8. StatusStrip 状态栏

### 知识讲解

`StatusStrip` 是底部状态栏控件，用于显示应用程序的运行状态、提示信息、时间和计数等。在上位机中，状态栏通常显示连接状态、轮询次数、错误计数、通信耗时等关键信息。

**子控件类型：**

| 控件 | 说明 |
|------|------|
| `ToolStripStatusLabel` | 文字标签（最常用） |
| `ToolStripProgressBar` | 进度条 |
| `ToolStripSplitButton` | 分割按钮 |
| `ToolStripDropDownButton` | 下拉按钮 |

### 代码示例

```csharp
public partial class StatusStripDemo : Form
{
    private ToolStripStatusLabel _lblStatus;         // 主状态
    private ToolStripStatusLabel _lblConnection;      // 连接状态
    private ToolStripStatusLabel _lblPollCount;      // 轮询次数
    private ToolStripStatusLabel _lblErrorCount;     // 错误次数
    private ToolStripStatusLabel _lblTime;           // 当前时间
    private ToolStripStatusLabel _lblResponseTime;    // 响应时间

    public StatusStripDemo()
    {
        InitializeComponent();
        CreateStatusStrip();
    }

    /// <summary>
    /// 创建上位机状态栏
    /// </summary>
    private void CreateStatusStrip()
    {
        var statusStrip = new StatusStrip();

        // ====== 状态图标 + 文字（左侧）======
        _lblConnection = new ToolStripStatusLabel
        {

            ForeColor = Color.Red,

        };

        // ====== 主状态信息（自动拉伸占满空间）======
        _lblStatus = new ToolStripStatusLabel
        {
            Text = "就绪",
            Spring = true  // 自动拉伸，占据所有剩余空间
        };

        // ====== 统计信息（右侧）======
        _lblPollCount = new ToolStripStatusLabel

        };

        };

        _lblResponseTime = new ToolStripStatusLabel
        {
            Text = "耗时：0ms",

        };

        {
            Text = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss")
        };

            _lblConnection,
            _lblStatus,
            _lblPollCount,
            _lblErrorCount,
            _lblResponseTime,
            _lblTime

            _lblTime.Text = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");

    // ========== 状态更新方法 ==========

    /// 更新连接状态

        if (connected)

            _lblConnection.Text = "● 未连接";

        _lblErrorCount.Text = $"错误：{errorCount}";

    }

    /// <summary>
    /// 设置主状态文字
    /// </summary>
    public void SetStatusMessage(string message)
    {
        _lblStatus.Text = message;
    }
}
```

### 注意事项

- `Spring = true` 的 `ToolStripStatusLabel` 会自动占据所有剩余水平空间，通常只设置一个。
- `BorderSides` 和 `BorderStyle` 用于在状态栏项目之间添加分隔线，使布局更清晰。
- 状态栏的更新频率不应过高，避免频繁刷新导致性能问题。

### 练习建议

1. 创建一个状态栏，包含连接状态指示（带颜色）、主状态信息、轮询次数、当前时间。
2. 实现状态更新方法，在按钮点击时模拟更新连接状态和统计信息。
3. 在状态栏中添加一个进度条（`ToolStripProgressBar`），模拟操作进度。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 状态栏不显示 | 被 Dock=Fill 的控件覆盖 | 确保 StatusStrip 在 Fill 控件之前添加 |
| 文字被截断 | Spring 未设置或多个控件都设置了 Spring | 只在一个 Label 上设置 Spring = true |

## 9. MenuStrip 菜单栏

### 知识讲解

`MenuStrip` 是顶部菜单栏控件，提供下拉菜单和子菜单功能。在上位机中，菜单栏通常包含「文件」「设备」「视图」「工具」「帮助」等菜单项。

### 代码示例

```csharp
public partial class MenuStripDemo : Form
{
    public MenuStripDemo()
    {
        InitializeComponent();
        CreateMenuStrip();
    }

    /// <summary>
    /// 创建上位机菜单栏
    /// </summary>
    private void CreateMenuStrip()
    {
        var menuStrip = new MenuStrip { Dock = DockStyle.Top };

        // ========== 文件菜单 ==========
        var menuFile = new ToolStripMenuItem("文件(&F)");

            {
                ShortcutKeys = Keys.Alt | Keys.F4
            }
        });

        // ========== 设备菜单 ==========
        var menuDevice = new ToolStripMenuItem("设备(&D)");
        menuDevice.DropDownItems.AddRange(new ToolStripItem[]
        {
            new ToolStripMenuItem("连接 PLC...", null, (s, e) => LogMessage("连接 PLC")),
            new ToolStripMenuItem("断开连接", null, (s, e) => LogMessage("断开连接")),
            new ToolStripSeparator(),
            new ToolStripMenuItem("扫描设备", null, (s, e) => LogMessage("扫描设备")),
            new ToolStripMenuItem("设备管理...", null, (s, e) => LogMessage("设备管理"))
        });

        // ========== 视图菜单 ==========
        var menuView = new ToolStripMenuItem("视图(&V)");
        var menuItemFullScreen = new ToolStripMenuItem("全屏显示", null, (s, e) => ToggleFullScreen());
        menuItemFullScreen.ShortcutKeys = Keys.F11;

        var menuItemStatusBar = new ToolStripMenuItem("状态栏");
        menuItemStatusBar.CheckOnClick = true;  // 可以勾选/取消
        menuItemStatusBar.Checked = true;        // 默认选中

        menuView.DropDownItems.AddRange(new ToolStripItem[]
        {
            menuItemFullScreen,
            menuItemStatusBar,
            new ToolStripSeparator(),
            new ToolStripMenuItem("刷新数据", null, (s, e) => LogMessage("刷新数据"))

                ShortcutKeys = Keys.F5

        // ========== 工具菜单 ==========
        var menuTools = new ToolStripMenuItem("工具(&T)");
        menuTools.DropDownItems.AddRange(new ToolStripItem[]
        {
            new ToolStripMenuItem("寄存器监控器...", null, (s, e) => LogMessage("寄存器监控器")),

        var menuHelp = new ToolStripMenuItem("帮助(&H)");
        menuHelp.DropDownItems.AddRange(new ToolStripItem[]
        {

        menuStrip.Items.AddRange(new ToolStripItem[]
        {
            menuFile,
            menuDevice,
            menuView,
            menuTools,
            menuHelp
        });

        this.Controls.Add(menuStrip);

        // 注意：MenuStrip 的 MainMenuStrip 属性需要设置，
        // 以支持 Alt 键激活菜单
        this.MainMenuStrip = menuStrip;
    }

    /// <summary>
    /// 切换全屏
    /// </summary>
    private void ToggleFullScreen()
    {
        if (this.FormBorderStyle == FormBorderStyle.None)
        {
            // 退出全屏
            this.FormBorderStyle = FormBorderStyle.Sizable;
            this.WindowState = FormWindowState.Normal;
            this.MaximizeBox = true;
        }
        else
        {
            // 进入全屏
            this.FormBorderStyle = FormBorderStyle.None;
            this.WindowState = FormWindowState.Maximized;
            this.MaximizeBox = false;
        }
    }
}
```

### 注意事项

- **设置 `MainMenuStrip`**：必须将 MenuStrip 赋值给 `Form.MainMenuStrip` 属性，否则 Alt 键快捷键不生效。
- **快捷键**：通过 `ShortcutKeys` 属性设置菜单项的快捷键（如 `Keys.Control | Keys.S`）。
- **助记符**：菜单文字中的 `(&F)` 表示 Alt+F 可以快速打开该菜单。
- **CheckOnClick**：设置 `true` 后，点击菜单项会自动切换勾选状态，适合「显示/隐藏」类的开关菜单。

### 练习建议

1. 创建完整的菜单栏：文件、设备、视图、工具、帮助，每个菜单至少有 3 个菜单项。
2. 为关键菜单项设置快捷键（如 Ctrl+S 保存、F5 刷新、F11 全屏）。
3. 实现一个可勾选的菜单项（如「显示/隐藏状态栏」）。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| Alt+F 无法打开文件菜单 | 未设置 MainMenuStrip | `this.MainMenuStrip = menuStrip` |
| 快捷键被按钮拦截 | 按钮的 Click 事件先处理了快捷键 | 使用 MenuStrip 的 ShortcutKeys |

### 注意事项

- **Dock 控件的添加顺序**：MenuStrip（Top）→ ToolStrip（Top）→ StatusStrip（Bottom）→ 主内容区（Fill），这个顺序确保各部分正确排列。
- **MinimumSize**：设置最小窗口尺寸可以防止用户将窗口缩到太小导致布局混乱。
- **SplitContainer 的嵌套**：左侧设备树 + 右侧选项卡内再嵌套上下分割（表格 + 图表），形成三层布局。
- 视图菜单中的「设备树」勾选项控制左侧面板的显示/隐藏。

### 练习建议

1. 按照本案例的布局结构，完整创建一个上位机主界面。
2. 在「参数配置」页中使用 TableLayoutPanel 实现两列参数表单。
3. 实现视图菜单中「设备树」的显示/隐藏功能。
4. 尝试调整 SplitContainer 的 SplitterDistance，找到最佳的默认比例。

### 常见错误

| 错误现象 | 原因 | 解决方法 |
|---------|------|---------|
| 状态栏被覆盖 | 主内容区 Fill 先于 StatusStrip 添加 | 按 Top→Bottom→Fill 的顺序添加 |
| 左右比例不正确 | SplitterDistance 设置过大或过小 | 根据容器大小合理设置 |
| 设备树隐藏后分割条仍然可见 | 只隐藏了 TreeView 而非 Panel | 隐藏整个 Panel1 或将 SplitterDistance 设为 0 |

## 总结

本章学习了 WinForms 中的布局与容器控件，核心知识点：

| 控件/属性 | 核心用途 | 典型场景 |
|-----------|---------|---------|
| TableLayoutPanel | 网格布局，精确控制行列 | 参数表单、数据表格 |
| FlowLayoutPanel | 自动流式排列 | 设备状态卡片、按钮组 |
| SplitContainer | 可拖拽分割面板 | 左右分栏、上下分栏 |
| Panel | 通用容器，支持滚动 | 内容分组、滚动区域 |
| GroupBox | 带标题的分组容器 | 功能区域分组 |
| TabControl | 多页选项卡 | 功能模块分页 |
| Anchor | 控件锚定，跟随缩放 | 对话框控件自适应 |
| Dock | 控件停靠，填满边缘 | 整体框架布局 |
| MenuStrip | 顶部菜单栏 | 功能菜单、快捷键 |
| StatusStrip | 底部状态栏 | 状态信息、统计显示 |

**布局设计的核心原则：**
1. 不要使用拖拽定位（绝对定位），使用容器和 Dock/Anchor
2. Dock 按顺序添加：Top → Bottom → Left → Right → Fill
3. TableLayoutPanel 是最精确的布局工具，优先使用
4. SplitContainer 用于可调整大小的区域划分
5. 设置 MinimumSize 防止窗口过小导致布局混乱
